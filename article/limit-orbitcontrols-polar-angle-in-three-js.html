Limit OrbitControls Polar Angle in Three.js

In Three.js applications, default camera controls allow users to orbit freely, which often results in the camera dipping beneath the ground plane and breaking scene immersion. This guide explains how to constrain vertical camera rotation using the maxPolarAngle property in OrbitControls. By restricting this angle, you can keep the camera strictly at or above ground level, ensuring a clean and controlled viewing experience.

Understanding Polar Angles in OrbitControls

OrbitControls uses spherical coordinates to determine the camera's position relative to its target. The vertical rotation is governed by the polar angle:

  • 0 radians (0°): The camera looks directly down from above (the zenith / North Pole).
  • Math.PI / 2 radians (90°): The camera is parallel to the ground plane (the equator / horizon).
  • Math.PI radians (180°): The camera looks directly up from below (the nadir / South Pole).

By default, maxPolarAngle is set to Math.PI, permitting the camera to rotate fully underneath the scene.

Restricting the Maximum Polar Angle

To prevent the camera from dropping below a flat ground plane, set controls.maxPolarAngle to Math.PI / 2 (90 degrees).

import * as THREE from 'three';
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';

// Setup camera and renderer
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();

// Initialize OrbitControls
const controls = new OrbitControls(camera, renderer.domElement);

// Prevent the camera from going below the ground plane
controls.maxPolarAngle = Math.PI / 2;

Avoiding Ground Clipping Artifacts

Setting maxPolarAngle exactly to Math.PI / 2 positions the camera flush with the ground at its lowest point. Depending on your camera's near clipping plane and the geometry of your terrain, the camera frustum may still intersect with ground geometry or cause visual clipping artifacts (Z-fighting).

To maintain a safe clearance above the floor, subtract a small offset from Math.PI / 2:

// Stops the camera slightly above the ground plane
controls.maxPolarAngle = Math.PI / 2 - 0.05;

Alternatively, you can specify a specific degree limit by converting degrees to radians:

// Limit vertical rotation to 85 degrees
const degrees = 85;
controls.maxPolarAngle = THREE.MathUtils.degToRad(degrees);

Additional Configuration

If you also need to stop users from looking straight down from directly overhead, pair maxPolarAngle with minPolarAngle:

// Limit camera movement between 30 degrees and 85 degrees
controls.minPolarAngle = THREE.MathUtils.degToRad(30);
controls.maxPolarAngle = THREE.MathUtils.degToRad(85);

Ensure that your animation loop calls controls.update() if you enable smooth damping (controls.enableDamping = true) to ensure these boundaries are respected smoothly during deceleration.
