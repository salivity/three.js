Extract Absolute Scale of Nested Child in Three.js

Extracting the absolute scale of an object nested three levels deep in a Three.js hierarchy requires resolving the cumulative transformations applied by each ancestor. Because Three.js uses a scene graph where children inherit their parents' transformations through matrix multiplication, an object's true world scale is represented within its global model matrix. This article explains the underlying mathematics behind hierarchical matrix concatenation and details how to extract the exact scale vector using matrix decomposition and vector magnitude calculations.

Understanding Hierarchical Transformations

When an object is nested within groups (e.g., Scene -> Group1 -> Group2 -> Group3 -> Child), each entity possesses its own local transformation matrix, \(M_{local}\), derived from its local position, rotation (quaternion), and scale:

\[M_{local} = T \cdot R \cdot S\]

To determine the child’s absolute position, orientation, and scale in the global world space, local transformation matrices must be multiplied sequentially from the root to the leaf node:

\[M_{world} = M_{Group1} \times M_{Group2} \times M_{Group3} \times M_{Child}\]

Before extracting scale values mathematically, the transformation chain must be evaluated by ensuring the world matrices are updated:

child.updateWorldMatrix(true, false);

Mathematical Extraction via Basis Vector Magnitudes

In Three.js, \(M_{world}\) is represented as a 4x4 column-major matrix stored in a 16-element flat array (matrixWorld.elements). The upper-left 3x3 submatrix encodes both rotation and scale:

\[M_{3\times3} = \begin{bmatrix} m_{0} & m_{4} & m_{8} \\ m_{1} & m_{5} & m_{9} \\ m_{2} & m_{6} & m_{10} \end{bmatrix}\]

Each column represents the transformed local coordinate basis vectors:

  • Column 0 (\(v_x = [m_0, m_1, m_2]^T\)): Transformed X-axis basis vector
  • Column 1 (\(v_y = [m_4, m_5, m_6]^T\)): Transformed Y-axis basis vector
  • Column 2 (\(v_z = [m_8, m_9, m_{10}]^T\)): Transformed Z-axis basis vector

Because rotation preserves vector length (isometry), any stretching or shrinking of these basis vectors is solely the result of cumulative scaling across all parent tiers. Therefore, the absolute scale along each axis is the Euclidean norm (length) of the corresponding column vector:

\[S_x = \|v_x\| = \sqrt{m_0^2 + m_1^2 + m_2^2}\]

\[S_y = \|v_y\| = \sqrt{m_4^2 + m_5^2 + m_6^2}\]

\[S_z = \|v_z\| = \sqrt{m_8^2 + m_9^2 + m_{10}^2}\]

Direct Mathematical Implementation

You can compute this directly using the raw array elements of the child’s world matrix:

// Ensure hierarchy transforms are evaluated
child.updateWorldMatrix(true, false);

const e = child.matrixWorld.elements;

// Calculate the length of each basis column
const scaleX = Math.sqrt(e[0] * e[0] + e[1] * e[1] + e[2] * e[2]);
const scaleY = Math.sqrt(e[4] * e[4] + e[5] * e[5] + e[6] * e[6]);
const scaleZ = Math.sqrt(e[8] * e[8] + e[9] * e[9] + e[10] * e[10]);

const absoluteScale = new THREE.Vector3(scaleX, scaleY, scaleZ);

Using Three.js Built-in Methods

Three.js executes this exact vector magnitude operation internally within its utility methods:

const absoluteScale = new THREE.Vector3();

// Method 1: Using getWorldScale directly
child.getWorldScale(absoluteScale);

// Method 2: Decomposing matrixWorld
const position = new THREE.Vector3();
const quaternion = new THREE.Quaternion();
child.matrixWorld.decompose(position, quaternion, absoluteScale);

Both approaches yield identical results. When dealing with non-uniform scaling combined with rotations in ancestral nodes, shear (skew) can be introduced. In standard transformation setups without shearing, computing the Euclidean length of the matrix columns provides the mathematically precise absolute scale of the nested child.
