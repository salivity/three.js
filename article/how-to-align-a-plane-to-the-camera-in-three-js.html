How to Align a Plane to the Camera in Three.js

This article explains how to use the Object3D.lookAt method in Three.js to align a 2D plane mesh so that it continually faces the active camera. While Three.js provides a built-in Sprite class that automatically faces the viewpoint, using a standard PlaneGeometry offers greater control over shaders, lighting, and textures. You will learn the mechanics of lookAt, how to fix standard orientation mismatch issues with plane geometries, and how to execute this alignment inside the render loop.

Understanding Object3D.lookAt

In Three.js, every 3D object inherits from THREE.Object3D. The lookAt method accepts a Vector3 position (or x, y, z coordinates) and rotates the object so that its local front vector points toward that position.

By default, lookAt points an object's negative Z-axis (-Z) toward the target.

The PlaneGeometry Orientation Problem

A default THREE.PlaneGeometry in Three.js is created facing the positive Z-axis (+Z).

Because lookAt directs the -Z axis toward the camera, calling planeMesh.lookAt(camera.position) directly will cause the plane to face its back away from the camera. If your material uses standard single-sided rendering (THREE.FrontSide), the plane will appear invisible or inside out.

There are two primary ways to resolve this:

  1. Pre-rotate the geometry: Rotate the underlying geometry 180 degrees around the Y-axis so its front aligns with -Z.
  2. Enable Double-Sided Rendering: Set side: THREE.DoubleSide on the material (though this can carry a minor performance cost).

Pre-rotating the geometry is the recommended, high-performance approach.

Implementation Example

Here is how to set up the plane and keep it aligned with the active camera:

import * as THREE from 'three';

// 1. Create the plane geometry
const geometry = new THREE.PlaneGeometry(2, 2);

// 2. Rotate the geometry so its front face matches the -Z lookAt vector
geometry.rotateY(Math.PI);

// 3. Create the material and mesh
const material = new THREE.MeshBasicMaterial({ 
    map: textureLoader.load('path/to/sprite.png'),
    transparent: true 
});

const planeMesh = new THREE.Mesh(geometry, material);
scene.add(planeMesh);

// 4. Update the alignment in your render loop
function animate() {
    requestAnimationFrame(animate);

    // Make the plane look directly at the active camera's world position
    planeMesh.lookAt(camera.position);

    renderer.render(scene, camera);
}

animate();

Locking Axes (Cylindrical Billboarding)

If you need the plane to rotate only around the vertical Y-axis (ideal for trees, ground characters, or markers that should not tilt up or down when the camera moves above them), lock the Y coordinate before applying lookAt:

const targetPosition = new THREE.Vector3();

function animate() {
    requestAnimationFrame(animate);

    // Copy camera position but maintain the plane's Y-height
    targetPosition.set(camera.position.x, planeMesh.position.y, camera.position.z);
    
    planeMesh.lookAt(targetPosition);

    renderer.render(scene, camera);
}

Alternative: Copying Camera Quaternion

If you want the plane to mimic a true THREE.Sprite by matching the exact screen plane rather than angling towards a single perspective point, you can copy the camera's rotation instead of using lookAt:

planeMesh.quaternion.copy(camera.quaternion);

For standard 3D tracking where the plane aims directly at the camera's lens, planeMesh.lookAt(camera.position) combined with a pre-rotated geometry remains the most direct and effective approach.
