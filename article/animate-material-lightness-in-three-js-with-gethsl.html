Animate Material Lightness in Three.js with getHSL

Dynamically adjusting a material's lightness over time in Three.js allows developers to create pulsing, breathing, or day-to-night shading effects without altering the base hue and saturation. By querying a material's current color using the Color.getHSL() method, you can extract its underlying Hue, Saturation, and Lightness components, modify the lightness dynamically inside an animation loop, and reapply the updated values using Color.setHSL().

Understanding Color.getHSL()

In Three.js, colors are internally represented in linear RGB. The Color.getHSL(target) method converts these RGB values into HSL (Hue, Saturation, Lightness) space and populates a user-provided target object. The components inside this object range from 0.0 to 1.0:

  • h (Hue): The color type (from red through green and blue, back to red).
  • s (Saturation): The intensity of the color (0.0 being grayscale, 1.0 being fully saturated).
  • l (Lightness): The brightness of the color (0.0 being complete black, 1.0 being complete white).

Implementation

To ensure optimal performance and avoid garbage collection overhead, instantiate a temporary holder object outside the animation loop rather than creating a new object on every frame.

import * as THREE from 'three';

// 1. Setup scene, camera, renderer, and clock
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ antialias: true });
const clock = new THREE.Clock();

// 2. Create a mesh with a colored material
const geometry = new THREE.BoxGeometry();
const material = new THREE.MeshStandardMaterial({ color: 0x3498db });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 3. Pre-allocate an object to store HSL values
const hsl = { h: 0, s: 0, l: 0 };

// 4. Animation loop
function animate() {
  requestAnimationFrame(animate);

  const elapsedTime = clock.getElapsedTime();

  // Retrieve current HSL values into the pre-allocated object
  material.color.getHSL(hsl);

  // Compute a new lightness value between 0.2 and 0.8 using a sine wave
  const newLightness = 0.5 + 0.3 * Math.sin(elapsedTime * 2);

  // Apply the updated lightness while retaining the original hue and saturation
  material.color.setHSL(hsl.h, hsl.s, newLightness);

  renderer.render(scene, camera);
}

animate();

Key Considerations

  • Object Reuse: Always pass a pre-existing target object to getHSL(target). Invoking methods that allocate new objects at 60 frames per second will trigger frequent garbage collection pauses.
  • Lightness Range: The lightness parameter in setHSL(h, s, l) expects a normalized floating-point value between 0.0 and 1.0. Ensure any mathematical functions used to drive animation (like Math.sin()) are scaled and clamped appropriately to avoid out-of-bounds rendering artifacts.
  • Preserving Original Hue: If your animation is intended to loop indefinitely around a base color, read the base color's HSL parameters once during initialization rather than querying them every frame, preventing floating-point precision drift over time.
