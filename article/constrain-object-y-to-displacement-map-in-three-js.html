Constrain Object Y to Displacement Map in Three.js

In Three.js, displacement maps are typically processed on the GPU via vertex shaders, leaving the CPU unaware of the updated surface geometry. To mathematically constrain an object's Y-axis position to follow a displacement map's terrain, you must extract the displacement map's pixel data on the CPU, map the object's world \((X, Z)\) coordinates to the terrain's UV space, sample the corresponding height value, and scale that value using the material's displacement parameters.

1. The GPU Displacement Formula

Standard Three.js materials calculate vertex displacement along normals using the formula:

\[Y_{\text{surface}} = \text{displacementBias} + (\text{Luminance} \times \text{displacementScale})\]

For a standard greyscale displacement map, luminance is normalized between \(0.0\) and \(1.0\):

\[\text{Luminance} = \frac{\text{Pixel Value}}{255}\]

To align your object on the CPU, you must replicate this exact formula.

2. Extracting Displacement Data on the CPU

Because GPU textures cannot be read synchronously on the CPU without severe performance penalties, draw the displacement image to an offscreen HTML <canvas> once at load time to access raw pixel arrays:

function getPixelDataFromImage(image) {
  const canvas = document.createElement('canvas');
  canvas.width = image.width;
  canvas.height = image.height;
  const ctx = canvas.getContext('2d');
  ctx.drawImage(image, 0, 0);
  return {
    data: ctx.getImageData(0, 0, image.width, image.height).data,
    width: image.width,
    height: image.height
  };
}

3. Transforming World Coordinates to UV Space

Assuming a terrain mesh generated with PlaneGeometry(width, height) oriented horizontally on the XZ-plane and centered at \((0, 0, 0)\):

  • World \(X\) range: \(\left[-\frac{\text{width}}{2}, \frac{\text{width}}{2}\right]\)
  • World \(Z\) range: \(\left[-\frac{\text{height}}{2}, \frac{\text{height}}{2}\right]\)

To calculate UV coordinates \((U, V) \in [0, 1]\) from an object's world \((X, Z)\) position:

\[U = \frac{X + \frac{\text{width}}{2}}{\text{width}}\]

\[V = 1.0 - \left(\frac{Z + \frac{\text{height}}{2}}{\text{height}}\right)\]

(Note: UV coordinates invert the vertical axis relative to image coordinate row indexing).

Clamp \(U\) and \(V\) between \(0\) and \(1\) to ensure queries outside mesh boundaries do not read out-of-bounds memory:

\[U_{\text{clamped}} = \max(0, \min(1, U))\] \[V_{\text{clamped}} = \max(0, \min(1, V))\]

4. Sampling the Height Value

Convert the normalized UV coordinates to discrete pixel coordinates \((P_x, P_y)\):

\[P_x = \lfloor U_{\text{clamped}} \times (\text{imageWidth} - 1) \rfloor\] \[P_y = \lfloor (1.0 - V_{\text{clamped}}) \times (\text{imageHeight} - 1) \rfloor\]

Locate the index in the 1D Uint8ClampedArray (RGBA format):

\[\text{index} = (P_y \times \text{imageWidth} + P_x) \times 4\]

Extract the red channel (since greyscale images have identical RGB values):

\[\text{Luminance} = \frac{\text{data}[\text{index}]}{255}\]

For smoother transitions between texels, use bilinear interpolation between the four adjacent pixels surrounding \((U, V)\) instead of nearest-neighbor clamping.

5. Final Mathematical Y-Position Calculation

Combine the plane's world Y-position, the displacement offset, and any optional vertical offset (such as half the object's height so it sits on top of the terrain rather than inside it):

\[Y_{\text{object}} = Y_{\text{plane}} + \text{displacementBias} + (\text{Luminance} \times \text{displacementScale}) + \text{ObjectOffset}\]

Complete Implementation Function

class DisplacementSampler {
  constructor(image, planeWidth, planeHeight, scale, bias) {
    this.planeWidth = planeWidth;
    this.planeHeight = planeHeight;
    this.scale = scale;
    this.bias = bias;

    const canvas = document.createElement('canvas');
    canvas.width = image.width;
    canvas.height = image.height;
    const ctx = canvas.getContext('2d');
    ctx.drawImage(image, 0, 0);

    this.pixelData = ctx.getImageData(0, 0, image.width, image.height).data;
    this.imgWidth = image.width;
    this.imgHeight = image.height;
  }

  getHeightAt(worldX, worldZ, planeY = 0) {
    // 1. Calculate UV
    let u = (worldX + this.planeWidth / 2) / this.planeWidth;
    let v = (worldZ + this.planeHeight / 2) / this.planeHeight;

    // Clamp coordinates
    u = Math.max(0, Math.min(1, u));
    v = Math.max(0, Math.min(1, v));

    // 2. Map UV to pixel coordinates
    const px = Math.floor(u * (this.imgWidth - 1));
    const py = Math.floor(v * (this.imgHeight - 1));

    // 3. Read pixel index
    const index = (py * this.imgWidth + px) * 4;
    const luminance = this.pixelData[index] / 255.0;

    // 4. Calculate world Y
    return planeY + this.bias + (luminance * this.scale);
  }
}
