WebXR Laser Pointer Selection in Three.js

Implementing an interactive laser-pointer selection tool in WebXR with Three.js requires accessing the controller space, creating a visual ray, and handling user inputs through specific XR input events. By binding a listener to the selectstart event on the XR controller object, you can capture trigger presses and perform 3D raycasting along the controller's pointing axis to interact with objects in your virtual scene.

1. Initialize the WebXR Controller

Three.js manages WebXR controllers through its XR manager on the WebGLRenderer. You retrieve a controller instance using renderer.xr.getController(index). This object tracks the position and orientation of the user's hand or hardware controller.

const controller = renderer.xr.getController(0);
scene.add(controller);

2. Create the Visual Laser Pointer

A standard laser pointer consists of a line extending along the controller's local negative Z-axis, which is the default forward direction in Three.js WebXR.

const geometry = new THREE.BufferGeometry().setFromPoints([
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(0, 0, -5) // 5 units forward
]);

const material = new THREE.LineBasicMaterial({
  color: 0xff0000,
  linewidth: 2
});

const laser = new THREE.Line(geometry, material);
laser.name = 'laser';
controller.add(laser);

3. Attach the selectstart Event Listener

The selectstart event fires as soon as the user presses the primary selection button (such as the trigger on an Oculus/Meta Quest or HTC Vive controller) or taps the screen in AR. Add an event listener directly to the controller instance:

controller.addEventListener('selectstart', onSelectStart);

4. Perform Raycasting on Selection

Inside the event handler, configure a THREE.Raycaster using the controller’s world transform. Extract the position and forward orientation of the controller to detect which interactive objects intersect the laser beam.

const raycaster = new THREE.Raycaster();
const tempMatrix = new THREE.Matrix4();

function onSelectStart(event) {
  const controller = event.target;

  // Extract the controller's world position and rotation
  tempMatrix.identity().extractRotation(controller.matrixWorld);
  raycaster.ray.origin.setFromMatrixPosition(controller.matrixWorld);
  raycaster.ray.direction.set(0, 0, -1).applyMatrix4(tempMatrix);

  // Check intersections with your interactive scene objects
  const intersects = raycaster.intersectObjects(interactiveObjects, false);

  if (intersects.length > 0) {
    const selectedObject = intersects[0].object;
    
    // Trigger interaction logic (e.g., change color)
    if (selectedObject.material.color) {
      selectedObject.material.color.set(Math.random() * 0xffffff);
    }
  }
}

5. Managing Button Release

To handle continuous interactions or release behavior (such as releasing a grabbed object), listen for the companion event selectend:

controller.addEventListener('selectend', onSelectEnd);

function onSelectEnd(event) {
  // Handle end of selection
}

By leveraging getController(), attaching a directional line geometry, and sampling intersections inside the selectstart callback via raycaster, you obtain a performant, accurate laser-pointer interaction system for any WebXR experience built with Three.js.
