Bind Custom Uniforms in Three.js NodeMaterial

This article explains how to define, bind, and dynamically update custom uniform values in Three.js using the NodeMaterial system and UniformNode. By using the uniform helper function from the Three.js shading language (TSL) module, you can feed arbitrary variables—such as floats, vectors, and colors—directly into node-based shader graphs and update them per frame without triggering shader recompilations.

Understanding Uniform Nodes in Three.js

In Three.js's node-based rendering architecture (used for both WebGL and WebGPU), shader inputs that change over time or per-instance are represented as uniform nodes. The uniform() function (an alias for instantiating a UniformNode) wraps standard JavaScript data types or Three.js math classes (THREE.Color, THREE.Vector2, THREE.Vector3, THREE.Matrix4, etc.) so that the node graph can treat them as reactive GPU uniforms.

1. Import the Node System

Import the required node components from 'three/tsl' (or 'three/nodes' depending on your Three.js version):

import * as THREE from 'three';
import { uniform, timerLocal } from 'three/tsl';
import { MeshStandardNodeMaterial } from 'three/webgpu';

2. Create the Uniform Node

Pass your initial value into the uniform() function. Three.js automatically infers the GLSL/WGSL uniform type from the provided value.

// A scalar float uniform
const intensity = uniform( 1.0 );

// A color uniform
const tintColor = uniform( new THREE.Color( 0x00ffcc ) );

// A 3D vector uniform
const lightDirection = uniform( new THREE.Vector3( 0, 1, 0 ) );

3. Assign the Uniform to a NodeMaterial

Connect your uniform node to properties of a node material. You can attach it directly to dedicated material slots (like colorNode, roughnessNode, or positionNode) or combine it with other nodes using operator overloads.

const material = new MeshStandardNodeMaterial();

// Direct assignment to a slot
material.roughnessNode = intensity;

// Combining nodes via arithmetic
material.colorNode = tintColor.mul( intensity );

const mesh = new THREE.Mesh( new THREE.BoxGeometry(), material );
scene.add( mesh );

4. Updating Uniform Values at Runtime

To update a custom uniform, modify the .value property of the node reference. You do not need to recompile the material or set material.needsUpdate = true.

function animate() {
    requestAnimationFrame( animate );

    // Update a scalar float
    intensity.value = Math.sin( performance.now() * 0.002 ) * 0.5 + 0.5;

    // Update a color
    tintColor.value.setRGB( 1.0, 0.5, 0.0 );

    renderer.render( scene, camera );
}

animate();

Complete Implementation Example

import * as THREE from 'three';
import { uniform } from 'three/tsl';
import { MeshBasicNodeMaterial } from 'three/webgpu';

// Setup uniform
const pulseUniform = uniform( 0.0 );

// Setup material with uniform logic
const material = new MeshBasicNodeMaterial();
const baseColor = uniform( new THREE.Color( 0x3366ff ) );

// Modulate the color by the pulse uniform
material.colorNode = baseColor.mul( pulseUniform );

const mesh = new THREE.Mesh( new THREE.SphereGeometry( 1, 32, 32 ), material );
scene.add( mesh );

// Render loop
function render( time ) {
    // Pulse between 0.2 and 1.0
    pulseUniform.value = Math.sin( time * 0.003 ) * 0.4 + 0.6;

    renderer.render( scene, camera );
}
renderer.setAnimationLoop( render );
