How to Use Three.js Scene autoUpdate Property

In Three.js, the scene graph updates its transformation matrices before rendering each frame, which can introduce unnecessary overhead in applications with large, static hierarchies. By reading and toggling the autoUpdate property on a Scene instance, you can disable automatic matrix calculations and manually trigger updates only when objects move, scale, or rotate.

Reading and Disabling scene.autoUpdate

The autoUpdate property is a boolean flag defined on the Scene object that defaults to true. You can read its current status directly:

const scene = new THREE.Scene();

// Read the current autoUpdate state
console.log(scene.autoUpdate); // Output: true

When autoUpdate is true, the WebGLRenderer invokes scene.updateMatrixWorld() automatically on every call to renderer.render(scene, camera).

To disable this behavior and take manual control over matrix calculations, assign the property to false:

scene.autoUpdate = false;

Manually Updating the Scene Graph

Once autoUpdate is set to false, modifications made to the position, rotation, or scale of objects inside the scene will not be reflected visually until their world matrices are explicitly recalculated.

To propagate changes down the scene graph, manually invoke updateMatrixWorld() on the scene when transformations occur:

// Transform an object
mesh.position.set(10, 0, 5);
mesh.rotation.y += Math.PI / 4;

// Manually recalculate world matrices for the entire scene graph
scene.updateMatrixWorld();

// Render the updated scene
renderer.render(scene, camera);

If you only modify a specific object or a isolated branch of your scene, you can optimize performance further by calling updateMatrixWorld() directly on that sub-tree instead of the entire Scene:

mesh.updateMatrixWorld();

Note on Recent Three.js Versions

In Three.js release 144 and later, scene.autoUpdate has been largely unified under scene.matrixWorldAutoUpdate across all Object3D instances. If you are working in a modern version of Three.js, you can read and assign matrixWorldAutoUpdate using the identical pattern:

// Check current state
console.log(scene.matrixWorldAutoUpdate);

// Disable automatic scene-level matrix updates
scene.matrixWorldAutoUpdate = false;

// Trigger manually when necessary
scene.updateMatrixWorld();
