Load VRML WRL Files in Three.js Using VRMLoader

This guide explains how to convert legacy Virtual Reality Modeling Language (VRML 2.0 / VRML97) .wrl files into modern WebGL scene graphs using Three.js. By utilizing the built-in VRMLoader add-on, developers can import historical 3D assets directly into a standard Three.js render loop without requiring third-party conversion software.

1. Import the Required Modules

VRMLoader is not included in the Three.js core bundle; it is distributed as an add-on. Import both three and VRMLoader from the three/addons directory.

import * as THREE from 'three';
import { VRMLoader } from 'three/addons/loaders/VRMLoader.js';

If you are using script tags with an import map, ensure your mapping points correctly to your three/addons/ path.

2. Set Up the Loader and Load the Asset

Instantiate the VRMLoader and use its .load() method. The loader parses the textual .wrl syntax into a standard THREE.Group or THREE.Scene object containing meshes, materials, and hierarchy.

// Initialize the basic Three.js scene
const scene = new THREE.Scene();

// Instantiate the VRMLoader
const loader = new VRMLoader();

// Load the .wrl file
loader.load(
    'models/legacy_model.wrl',
    function (object) {
        // 'object' is a THREE.Scene/THREE.Group containing the parsed scene graph
        scene.add(object);
    },
    function (xhr) {
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    function (error) {
        console.error('An error occurred while loading the VRML file:', error);
    }
);

3. Parse In-Memory Data

If the .wrl file is retrieved as a raw string (e.g., via fetch or user file upload), use the synchronous .parse() method instead:

const wrlText = "..."; // Raw VRML file text
const parsedScene = loader.parse(wrlText);
scene.add(parsedScene);

4. Critical Considerations for Legacy WRL Files

  • VRML Version Support: The Three.js VRMLoader strictly supports VRML 2.0 (VRML97) syntax. It cannot parse older VRML 1.0 files. Check the header line of your .wrl file; it must start with #VRML V2.0 utf8. Files beginning with #VRML V1.0 must be converted to VRML 2.0 or modern formats using external tools like Blender or MeshLab first.
  • Texture Paths: VRML files often use relative paths to reference external image files (such as .jpg or .png). Ensure that textures are hosted relative to the loading script or configure a loading manager to resolve resource URLs properly using loader.setResourcePath('textures/').
  • Scale and Orientation: Many legacy CAD and VRML tools use different unit standards (such as millimeters or inches) and coordinate system orientations (Z-up instead of Three.js's Y-up). Apply transforms directly to the loaded group if the asset appears misaligned or disproportionately sized:
object.scale.set(0.01, 0.01, 0.01); // Adjust scale if needed
object.rotation.x = -Math.PI / 2;    // Correct orientation if exported as Z-up

5. Transitioning to Modern Formats

VRML parsing involves heavy text interpretation in JavaScript at runtime. For production environments, serialize the parsed Three.js object to glTF/GLB using GLTFExporter to optimize load times, memory consumption, and runtime performance.
