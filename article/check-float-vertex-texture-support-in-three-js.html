Check Float Vertex Texture Support in Three.js

This guide explains how to query WebGLCapabilities in Three.js to detect whether a client GPU supports floating-point textures inside vertex shaders. Knowing this hardware capability allows developers to reliably run GPU particle simulations, heightmap displacements, and compute-like algorithms while providing fallbacks for unsupported systems.

Accessing WebGLCapabilities

In Three.js, all hardware and context features are exposed through the capabilities property of your WebGLRenderer instance. Internally, this instantiates a WebGLCapabilities object that inspects the active WebGL context.

To explicitly test if the device supports reading floating-point textures in vertex shaders, query the boolean property renderer.capabilities.floatVertexTextures:

import * as THREE from 'three';

// Initialize the renderer
const renderer = new THREE.WebGLRenderer();

// Query support for floating-point vertex textures
const supportsFloatVertexTextures = renderer.capabilities.floatVertexTextures;

if (supportsFloatVertexTextures) {
  console.log('Floating-point vertex textures are supported.');
  // Initialize shaders utilizing floating-point vertex texture lookups
} else {
  console.warn('Floating-point vertex textures are not supported on this device.');
  // Provide a fallback (e.g., standard textures, CPU-side processing)
}

How Three.js Evaluates the Property

When renderer.capabilities.floatVertexTextures is queried, Three.js verifies two conditions behind the scenes:

  1. Vertex Texture Units: The GPU must support at least one texture unit accessible to vertex shaders (maxVertexTextures > 0).
  2. Float Texture Extension/Format: The underlying context must support floating-point textures. In WebGL 1, this relies on the OES_texture_float extension. In WebGL 2, basic 32-bit floating-point textures are part of the core specification, but filtering and vertex sampling still require appropriate driver capabilities.

If both conditions are met, renderer.capabilities.floatVertexTextures returns true.

Related Vertex Texture Checks

When implementing advanced vertex-texture techniques, you may also need to check the maximum number of simultaneous texture units available in the vertex shader:

const maxVertexTextures = renderer.capabilities.maxVertexTextures;

console.log(`Available vertex texture units: ${maxVertexTextures}`);

If maxVertexTextures is 0, the hardware cannot sample any textures inside a vertex shader, regardless of whether float textures are supported in fragment shaders. Always evaluate renderer.capabilities.floatVertexTextures before compiling shaders that rely on functions like texture2D() or texture() within the vertex stage using FloatType or HalfFloatType textures.
