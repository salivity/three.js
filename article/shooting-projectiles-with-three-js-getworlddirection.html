Shooting Projectiles with Three.js getWorldDirection

Firing a projectile directly forward from the player's perspective in Three.js requires determining the camera's orientation in 3D world space. This guide explains how to extract the forward-facing vector using the camera.getWorldDirection() method, initialize a projectile at the camera's position, and update its position along that trajectory within your render loop.

How getWorldDirection Works

In Three.js, local rotations do not always directly represent an object's orientation in the global scene. The camera.getWorldDirection(target) method extracts the camera's forward vector in world coordinates and stores it into a provided THREE.Vector3 object. By default, this returns a normalized vector (a unit vector with a length of 1) pointing directly where the camera is looking.

Step-by-Step Implementation

  1. Extract the Forward Vector: Create a reusable THREE.Vector3 variable and pass it to camera.getWorldDirection().
  2. Spawn the Projectile: Instantiate your projectile mesh and position it at the camera's current world position.
  3. Assign Velocity: Multiply the direction vector by the desired speed scalar and store it with the projectile.
  4. Update the Position: In the animation loop, add the velocity vector to the projectile's position vector on every frame.

Complete Code Example

// Reusable vector to avoid garbage collection overhead
const shootDirection = new THREE.Vector3();

// Array to hold active projectiles
const projectiles = [];

function shootProjectile(camera, scene, speed = 2.0) {
  // 1. Get the direction the camera is facing
  camera.getWorldDirection(shootDirection);

  // 2. Create the projectile mesh
  const geometry = new THREE.SphereGeometry(0.1, 8, 8);
  const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
  const projectile = new THREE.Mesh(geometry, material);

  // 3. Set the starting position to the camera position
  // An optional offset can be added to prevent spawning inside the camera
  projectile.position.copy(camera.position).addScaledVector(shootDirection, 0.5);

  // 4. Calculate velocity and attach it to the projectile
  projectile.userData.velocity = shootDirection.clone().multiplyScalar(speed);

  // 5. Track lifetime to handle cleanup
  projectile.userData.aliveTime = 0;
  projectile.userData.maxLife = 120; // Frames before removal

  scene.add(projectile);
  projectiles.push(projectile);
}

// Call this function inside your requestAnimationFrame loop
function updateProjectiles(scene) {
  for (let i = projectiles.length - 1; i >= 0; i--) {
    const p = projectiles[i];

    // Move the projectile forward
    p.position.add(p.userData.velocity);

    // Track lifetime and remove dead projectiles
    p.userData.aliveTime++;
    if (p.userData.aliveTime > p.userData.maxLife) {
      scene.remove(p);
      p.geometry.dispose();
      p.material.dispose();
      projectiles.splice(i, 1);
    }
  }
}

Key Considerations

  • Spawn Offsets: Spawning a projectile directly at camera.position can cause visual clipping if the projectile intersects the camera's near clipping plane. Using .addScaledVector(shootDirection, offset) shifts the spawn point slightly in front of the lens.
  • Memory Management: Always dispose of geometries and materials when removing projectiles to prevent memory leaks in WebGL.
  • Frame-Rate Independence: For consistent movement across different refresh rates, multiply the velocity by delta time (clock.getDelta()) rather than applying a fixed scalar per frame.
