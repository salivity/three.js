Custom Box3 Collision Detection in Three.js

This article explains how to implement custom collision logic in Three.js by mathematically calculating the intersection of two THREE.Box3 axis-aligned bounding boxes (AABB). While standard Three.js methods provide a simple boolean check to determine if two boxes overlap, calculating the exact overlapping volume allows you to determine penetration depth, collision normals, and contact points necessary for custom physics responses.

Setting Up Bounding Boxes

In Three.js, a Box3 represents an axis-aligned bounding box defined by a min and a max vector in 3D space. You can construct them manually or compute them directly from meshes.

import * as THREE from 'three';

// Create bounding boxes from existing meshes
const boxA = new THREE.Box3().setFromObject(meshA);
const boxB = new THREE.Box3().setFromObject(meshB);

Checking for an Intersection

Before running complex mathematical calculations, confirm whether an overlap exists using the built-in intersectsBox method:

const isColliding = boxA.intersectsBox(boxB);

Calculating the Overlap Region

To calculate the exact mathematical intersection, use the intersect method. This method updates the calling Box3 to represent the overlapping region bounded by both boxes:

if (boxA.intersectsBox(boxB)) {
  // Clone boxA to avoid mutating the original bounding box
  const intersectionBox = boxA.clone().intersect(boxB);

  // Calculate the dimensions of the overlapping region
  const overlapSize = new THREE.Vector3();
  intersectionBox.getSize(overlapSize);

  // Calculate the center point of the collision
  const collisionCenter = new THREE.Vector3();
  intersectionBox.getCenter(collisionCenter);
}

Determining Penetration Depth and Collision Normal

For physical collision resolution (such as pushing an object out of an obstacle), you must find the axis of minimum penetration. The smallest component of overlapSize indicates the direction from which the collision occurred.

function resolveCollision(boxA, boxB, meshA) {
  if (!boxA.intersectsBox(boxB)) return;

  const intersection = boxA.clone().intersect(boxB);
  const overlapSize = new THREE.Vector3();
  intersection.getSize(overlapSize);

  const normal = new THREE.Vector3();
  let minOverlap = overlapSize.x;
  normal.set(Math.sign(meshA.position.x - boxB.getCenter(new THREE.Vector3()).x), 0, 0);

  if (overlapSize.y < minOverlap) {
    minOverlap = overlapSize.y;
    normal.set(0, Math.sign(meshA.position.y - boxB.getCenter(new THREE.Vector3()).y), 0);
  }

  if (overlapSize.z < minOverlap) {
    minOverlap = overlapSize.z;
    normal.set(0, 0, Math.sign(meshA.position.z - boxB.getCenter(new THREE.Vector3()).z));
  }

  // Positional correction: shift meshA out of boxB
  meshA.position.addScaledVector(normal, minOverlap);
  boxA.setFromObject(meshA); // Update bounding box after moving
}

Key Considerations

  • Axis-Aligned Limitation: THREE.Box3 does not support rotation. If your objects rotate, their bounding boxes will resize dynamically when recalculated, which may lead to imprecise collision volumes. For rotated objects, use Oriented Bounding Boxes (THREE.OBB).
  • Performance: Instantiating new THREE.Box3() and new THREE.Vector3() in an animation loop generates garbage collection overhead. Pre-allocate these variables outside the loop and reuse them with the .copy() and .set() methods.
