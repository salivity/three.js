How to Set Vertex Colors in Three.js BufferGeometry

Assigning unique vertex colors to a BufferGeometry in Three.js involves defining a Float32Array containing normalized RGB values for every vertex, attaching this array to the geometry using a THREE.BufferAttribute named 'color', and enabling the vertexColors property on the material. This guide outlines the exact implementation steps and provides a complete code example to render per-vertex colors correctly.

1. Define the Color Data Array

In Three.js, color components are normalized float values between 0.0 and 1.0. For every vertex defined in your geometry's 'position' attribute, you must provide three consecutive values (Red, Green, and Blue) in a Float32Array.

If your geometry has \(N\) vertices, your color array must contain \(N \times 3\) elements:

// Example for a triangle with 3 vertices
const colors = new Float32Array([
  1.0, 0.0, 0.0, // Vertex 1: Red
  0.0, 1.0, 0.0, // Vertex 2: Green
  0.0, 0.0, 1.0  // Vertex 3: Blue
]);

2. Add the BufferAttribute to the Geometry

Wrap the Float32Array in a THREE.BufferAttribute with an item size of 3 (representing the 3 color channels: R, G, B), then assign it to the 'color' attribute of your BufferGeometry:

geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));

3. Enable Vertex Colors on the Material

By default, Three.js materials ignore vertex colors and rely solely on their uniform color property or maps. To render the per-vertex colors, you must explicitly set vertexColors: true on your material:

const material = new THREE.MeshBasicMaterial({
  vertexColors: true
});

You can use vertexColors: true on standard materials like MeshStandardMaterial or MeshPhongMaterial as well, where vertex colors will interact with the scene's lighting.

Complete Working Example

Below is a complete implementation that constructs a custom triangle with unique colors at each vertex:

import * as THREE from 'three';

// 1. Create a BufferGeometry
const geometry = new THREE.BufferGeometry();

// 2. Define vertices (3 vertices for a single triangle)
const positions = new Float32Array([
  -1.0, -1.0,  0.0, // Bottom-left
   1.0, -1.0,  0.0, // Bottom-right
   0.0,  1.0,  0.0  // Top-center
]);
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));

// 3. Define unique RGB colors for each vertex
const colors = new Float32Array([
  1.0, 0.0, 0.0, // Red for bottom-left
  0.0, 1.0, 0.0, // Green for bottom-right
  0.0, 0.0, 1.0  // Blue for top-center
]);
geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));

// 4. Create a material with vertexColors enabled
const material = new THREE.MeshBasicMaterial({
  vertexColors: true,
  side: THREE.DoubleSide
});

// 5. Create mesh and add to your scene
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Updating Colors Dynamically

If you modify the values inside your color array after the initial render, notify Three.js of the change by setting the attribute's update flag:

geometry.attributes.color.needsUpdate = true;

Working with Built-in Geometries

When using built-in geometries (such as THREE.BoxGeometry or THREE.SphereGeometry), you can populate the 'color' attribute by checking the vertex count from the existing position attribute:

const geometry = new THREE.BoxGeometry(1, 1, 1);
const count = geometry.attributes.position.count;

const colors = new Float32Array(count * 3);
const colorHelper = new THREE.Color();

for (let i = 0; i < count; i++) {
  // Generate or assign a color
  colorHelper.setHSL(i / count, 1.0, 0.5);
  
  colors[i * 3]     = colorHelper.r;
  colors[i * 3 + 1] = colorHelper.g;
  colors[i * 3 + 2] = colorHelper.b;
}

geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));
