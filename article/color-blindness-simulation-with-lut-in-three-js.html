Color Blindness Simulation with LUT in Three.js

Simulating color vision deficiencies—such as protanopia, deuteranopia, and tritanopia—in a WebGL application ensures your 3D visual designs remain accessible to all users. This article explains how to parse custom 3D Lookup Tables (LUTs) representing color blindness algorithms and apply them to a Three.js scene using post-processing passes. By leveraging precomputed .cube files and Three.js's post-processing stack, you can efficiently transform scene colors in real time with minimal runtime performance overhead.

1. Understanding 3D LUTs for Color Blindness

A 3D Lookup Table maps an input RGB color to an altered output RGB color within a discrete 3D grid (typically sized \(16 \times 16 \times 16\), \(32 \times 32 \times 32\), or \(64 \times 64 \times 64\)). Color blindness algorithms apply mathematical matrices (such as Brettel or Machado models) to simulate the loss of specific photoreceptor cone cells. By baking these matrix calculations into a .cube file, the GPU avoids complex per-pixel matrix math during rendering, reading the final transformed color directly from a 3D texture lookup instead.

2. Required Three.js Modules

To load, parse, and render a 3D LUT, import the core Three.js library alongside the necessary post-processing and loader add-ons from three/addons:

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { LUTPass } from 'three/addons/postprocessing/LUTPass.js';
import { LUTCubeLoader } from 'three/addons/loaders/LUTCubeLoader.js';

3. Initializing the Post-Processing Pipeline

Set up the EffectComposer to manage the rendering passes. The pipeline requires a RenderPass to capture the base scene and a LUTPass to apply the color remapping.

// Set up renderer, scene, and camera
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);

// Initialize composer and passes
const composer = new EffectComposer(renderer);
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

const lutPass = new LUTPass();
lutPass.enabled = false; // Disabled until a LUT is loaded
composer.addPass(lutPass);

4. Parsing and Applying the LUT File

Use LUTCubeLoader to fetch and parse your color blindness .cube file. The loader returns an object containing the parsed 3D texture, which must be assigned directly to the lutPass.

const lutLoader = new LUTCubeLoader();

function applyColorBlindnessLUT(lutUrl) {
    lutLoader.load(lutUrl, (result) => {
        // Assign the 3D texture output to the LUT pass
        lutPass.lut = result.texture3D;
        lutPass.intensity = 1.0;
        lutPass.enabled = true;
    }, undefined, (error) => {
        console.error('An error occurred loading the LUT:', error);
    });
}

// Example: Load a deuteranopia simulation LUT
applyColorBlindnessLUT('/luts/deuteranopia.cube');

5. Managing Simulation Switching at Runtime

In interactive applications or accessibility preview tools, users frequently toggle between regular sight and various deficiency simulations. Maintain a dictionary of preloaded textures to prevent network latency when switching modes.

const lutTextures = {};
const deficiencies = ['protanopia', 'deuteranopia', 'tritanopia', 'achromatopsia'];

// Preload LUT textures
deficiencies.forEach((type) => {
    lutLoader.load(`/luts/${type}.cube`, (result) => {
        lutTextures[type] = result.texture3D;
    });
});

// Function to switch deficiency mode
function setColorDeficiencyMode(type) {
    if (type === 'normal' || !lutTextures[type]) {
        lutPass.enabled = false;
        return;
    }

    lutPass.lut = lutTextures[type];
    lutPass.enabled = true;
}

6. Updating the Render Loop

Replace renderer.render(scene, camera) with composer.render() in your animation loop. Also ensure the composer updates its size when handling window resize events.

function animate() {
    requestAnimationFrame(animate);
    composer.render();
}
animate();

window.addEventListener('resize', () => {
    const width = window.innerWidth;
    const height = window.innerHeight;
    
    camera.aspect = width / height;
    camera.updateProjectionMatrix();
    
    renderer.setSize(width, height);
    composer.setSize(width, height);
});

Using this setup, standard 3D LUT files transform your canvas output to accurately simulate color vision deficiencies with optimal GPU rendering speeds.
