Extract Translation with setFromMatrixColumn in Three.js

Extracting position and translation data from a 4x4 transformation matrix is a frequent operation in Three.js rendering loops and physics calculations. While Vector3.setFromMatrixPosition() is commonly used, you can also extract translation vectors directly using Vector3.setFromMatrixColumn(). This guide explains how matrix column mapping works in Three.js and demonstrates how to quickly extract translation components by targeting the fourth column of a Matrix4.

Understanding the Matrix Layout

Three.js represents 3D transformations using a column-major 4x4 matrix (THREE.Matrix4). The internal elements array stores values in a specific order where the first three columns define rotation and scale (the local coordinate axes), and the fourth column defines the world-space or parent-space translation:

  • Column 0: Basis Vector X (\(X_x, X_y, X_z, 0\))
  • Column 1: Basis Vector Y (\(Y_x, Y_y, Y_z, 0\))
  • Column 2: Basis Vector Z (\(Z_x, Z_y, Z_z, 0\))
  • Column 3: Translation (\(T_x, T_y, T_z, 1\))

Extracting Translation Using setFromMatrixColumn

The Vector3.setFromMatrixColumn(matrix, index) method populates a Vector3 using the values of a specified column index (from 0 to 3) in a given Matrix4. Because array indices are zero-based, passing 3 as the second argument extracts the translation components (\(T_x, T_y, T_z\)) directly into the target vector.

import * as THREE from 'three';

// Assume 'objectMatrix' is an existing THREE.Matrix4 instance
const objectMatrix = new THREE.Matrix4();

// Create or reuse a Vector3 instance to prevent garbage collection overhead
const translation = new THREE.Vector3();

// Extract the translation components (Column Index 3)
translation.setFromMatrixColumn(objectMatrix, 3);

console.log(translation); // Outputs: Vector3 { x: Tx, y: Ty, z: Tz }

Why Use This Approach?

  1. Memory Efficiency: Reusing an existing THREE.Vector3 instance with setFromMatrixColumn avoids allocating new objects during hot loops or tick functions.
  2. Bypasses Full Decomposition: Unlike matrix.decompose(), which calculates position, quaternion, and scale simultaneously through complex floating-point operations, setFromMatrixColumn performs three direct array lookups (elements[12], elements[13], elements[14]).
  3. Loop Uniformity: If you are reading out basis vectors and translation sequentially (for example, building custom physics bodies or export formats), using indices 0, 1, 2, and 3 with setFromMatrixColumn keeps code clean and standardized across all coordinate axes and the position vector.
