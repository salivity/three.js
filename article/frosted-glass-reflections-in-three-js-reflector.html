Frosted Glass Reflections in Three.js Reflector

This guide explains how to configure the internal render target and shader parameters of the Three.js Reflector component to achieve a frosted, blurred reflection effect. By downsampling the internal render target, manipulating texture filtering, and introducing UV jitter to the internal reflector material, you can transform the default mirror-like reflection into a realistic frosted glass surface.

1. Downsample the Internal Render Target

The default Reflector creates an internal WebGLRenderTarget matching the screen or specified canvas dimensions, which yields a sharp reflection. Reducing the dimensions of this render target forces the reflection to render at a lower resolution, creating an inherent soft blur when upscaled.

When instantiating the Reflector, pass smaller dimensions via the options object:

import { Reflector } from 'three/addons/objects/Reflector.js';

const frostedReflector = new Reflector(geometry, {
  clipBias: 0.003,
  textureWidth: window.innerWidth / 4,
  textureHeight: window.innerHeight / 4,
  color: 0x889999
});
scene.add(frostedReflector);

Downscaling by a factor of 4 to 8 produces an immediate diffuse quality with minimal performance overhead.

2. Configure Texture Filtering on the Render Target

Ensure that the texture attached to the internal render target uses linear interpolation so the downsampled texture renders smoothly instead of pixelated.

Access the internal render target using getRenderTarget():

const renderTarget = frostedReflector.getRenderTarget();

renderTarget.texture.minFilter = THREE.LinearFilter;
renderTarget.texture.magFilter = THREE.LinearFilter;
renderTarget.texture.generateMipmaps = false;

LinearFilter blends adjacent texels during magnification, softening edges across the surface.

3. Inject UV Jitter into the Material Shader

Resolution downsampling alone creates a low-frequency blur. Frosted glass also exhibits micro-surface dispersion (roughness). To achieve this, perturb the reflection UV coordinates in the reflector's fragment shader using random noise or an offset function.

Modify the reflector's internal material before rendering:

const reflectorMaterial = frostedReflector.material;

// Add a blur strength uniform
reflectorMaterial.uniforms.blurStrength = { value: 0.005 };

// Patch the vertex/fragment shaders
reflectorMaterial.onBeforeCompile = (shader) => {
  shader.uniforms.blurStrength = reflectorMaterial.uniforms.blurStrength;

  // Insert a pseudo-random hash function into the fragment shader
  shader.fragmentShader = `
    uniform float blurStrength;
    
    float rand(vec2 co) {
      return fract(sin(dot(co.xy, vec2(12.9898, 78.233))) * 43758.5453);
    }
  ` + shader.fragmentShader;

  // Perturb projection coordinates before texture sampling
  shader.fragmentShader = shader.fragmentShader.replace(
    'vec4 diffuse = texture2DProj( tDiffuse, vUv );',
    `
    vec4 coord = vUv;
    vec2 jitter = vec2(
      rand(vUv.xy) - 0.5,
      rand(vUv.yx) - 0.5
    ) * blurStrength;
    
    coord.xy += jitter * coord.w;
    vec4 diffuse = texture2DProj( tDiffuse, coord );
    `
  );
};

4. Handle Dynamic Resizing

If your scene resizes dynamically, update the internal render target size proportionally to preserve the blur intensity:

window.addEventListener('resize', () => {
  const width = window.innerWidth / 4;
  const height = window.innerHeight / 4;

  frostedReflector.getRenderTarget().setSize(width, height);
});

Combining render target downsampling with shader-level UV jitter produces a convincing frosted glass surface while avoiding the heavy performance cost of multi-pass Gaussian blur filters.
