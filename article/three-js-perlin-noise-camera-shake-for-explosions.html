Three.js Perlin Noise Camera Shake for Explosions

This article provides a direct guide to implementing a realistic, procedural camera shake effect for a Three.js PerspectiveCamera using Perlin noise. Rather than relying on erratic, pure-random offsets, this approach uses continuous noise combined with an exponential decay curve to simulate the high-energy shockwave and subsequent stabilization caused by an in-game explosion.

Why Perlin Noise?

Using Math.random() to jitter camera coordinates produces harsh, disconnected frame-to-frame jumps that look unnatural. Perlin (or Simplex) noise generates smooth, continuous pseudo-random values. By sampling this noise along a timeline, the camera smoothly traverses a turbulent path, yielding an organic, cinematic rumble.

The Trauma and Decay System

The standard industry technique for camera shake uses a variable often termed trauma (\(T \in [0, 1]\)):

  1. Trigger: An explosion sets trauma to \(1.0\) (or adds to current trauma, clamped to \(1.0\)).
  2. Decay: Trauma decreases linearly or exponentially over time (\(T = \max(0, T - \text{decay} \times \Delta t)\)).
  3. Shake Factor: The actual amplitude applied to the camera is typically non-linear, often calculated as \(T^2\) or \(T^3\). This gives high-intensity displacement initially that quickly softens.

Implementation

To sample continuous noise, you can use any standard 1D/2D Perlin or Simplex noise library (such as simplex-noise or three/addons/math/SimplexNoise.js).

1. The Camera Shake Class

import { SimplexNoise } from 'three/addons/math/SimplexNoise.js';
import * as THREE from 'three';

export class CameraShake {
  constructor(camera) {
    this.camera = camera;
    this.noise = new SimplexNoise();

    // Configuration
    this.trauma = 0;
    this.decayRate = 1.2; // How fast the shake dissipates
    this.frequency = 25.0; // Speed of the noise sample traversal

    // Maximum offsets
    this.maxPitch = THREE.MathUtils.degToRad(4); // Rotation X
    this.maxYaw = THREE.MathUtils.degToRad(4);   // Rotation Y
    this.maxRoll = THREE.MathUtils.degToRad(6);  // Rotation Z
    this.maxOffset = 0.5;                        // Positional displacement (units)

    // Base transform references
    this.initialPosition = camera.position.clone();
    this.initialRotation = camera.rotation.clone();
    
    this.time = 0;
  }

  addTrauma(amount) {
    this.trauma = Math.min(1.0, this.trauma + amount);
  }

  update(delta) {
    if (this.trauma <= 0) return;

    // Decay trauma over time
    this.trauma = Math.max(0, this.trauma - this.decayRate * delta);
    const shake = Math.pow(this.trauma, 2); // Non-linear response curve

    this.time += delta * this.frequency;

    // Sample noise at different offsets to ensure axes remain decorrelated
    const offsetX = this.noise.noise(this.time, 0) * this.maxOffset * shake;
    const offsetY = this.noise.noise(0, this.time) * this.maxOffset * shake;

    const yaw = this.noise.noise(this.time, 10) * this.maxYaw * shake;
    const pitch = this.noise.noise(10, this.time) * this.maxPitch * shake;
    const roll = this.noise.noise(this.time, 20) * this.maxRoll * shake;

    // Apply translation
    this.camera.position.x = this.initialPosition.x + offsetX;
    this.camera.position.y = this.initialPosition.y + offsetY;

    // Apply rotation
    this.camera.rotation.x = this.initialRotation.x + pitch;
    this.camera.rotation.y = this.initialRotation.y + yaw;
    this.camera.rotation.z = this.initialRotation.z + roll;
  }
}

Integrating into the Animation Loop

To prevent the shake calculation from overriding gameplay camera motion (such as follow-cam logic or mouse controls), attach the camera to a parent THREE.Group or store and update the base coordinates dynamically:

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const shaker = new CameraShake(camera);
const clock = new THREE.Clock();

// Trigger an explosion
function onExplosion() {
  shaker.addTrauma(1.0);
}

// Render loop
function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();

  // Update base camera controls/movements here if needed
  // shaker.initialPosition.copy(targetPosition);

  // Apply procedural Perlin shake
  shaker.update(delta);

  renderer.render(scene, camera);
}

Key Tuning Variables

  • Frequency: Higher values make the camera shudder faster (ideal for sharp, metallic impacts or nearby explosions); lower values create an earthquake-like rolling motion.
  • Rotation vs. Translation: Rotational shake (yaw, pitch, roll) contributes far more to the perception of violent impact than positional translation. Keep translational values subtle and prioritize angular displacement.
  • Noise Offsets: Always sample each degree of freedom (X, Y, Pitch, Yaw, Roll) with distinct offset seeds on the noise timeline to prevent synchronized axis motion.
