Get Angle Between Vector2 and X-Axis in Three.js

Calculating the angle between a 2D vector and the positive X-axis in Three.js is an essential task for handling orientation, trajectories, and directional sprites. This guide explains how to compute this precise angle using the native THREE.Vector2 math methods, how to interpret the resulting radian measurement, and how to convert the value into degrees or signed angle ranges.

Using the Built-In .angle() Method

The standard Three.js math library includes a built-in method on the Vector2 class named .angle(). This method calculates the counter-clockwise angle in radians between the vector and the positive X-axis:

import * as THREE from 'three';

const dir = new THREE.Vector2(1, 1);
const angleInRadians = dir.angle();

console.log(angleInRadians); // ~0.785398 (PI / 4)

The .angle() method handles positive and negative components automatically by internally using Math.atan2(-y, -x) + Math.PI. It returns a normalized value ranging from 0 to 2 * Math.PI radians (0° to 360°).

Converting Radians to Degrees

Three.js outputs angles in radians by default. To convert the radian output to standard degrees, use the THREE.MathUtils.radToDeg() utility method:

const angleInDegrees = THREE.MathUtils.radToDeg(dir.angle());

console.log(angleInDegrees); // 45

Getting a Signed Angle Range (-π to π)

If your implementation requires a signed angle range between -Math.PI and Math.PI (-180° to 180°) instead of 0 to 2 * Math.PI, you can calculate the angle using Math.atan2 directly with the vector components:

const signedAngleInRadians = Math.atan2(dir.y, dir.x);
const signedAngleInDegrees = THREE.MathUtils.radToDeg(signedAngleInRadians);

This returns 0 along the positive X-axis, positive values turning counter-clockwise toward the positive Y-axis, and negative values turning clockwise toward the negative Y-axis.
