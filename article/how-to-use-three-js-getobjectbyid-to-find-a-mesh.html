How to Use Three.js getObjectById to Find a Mesh

In Three.js, dynamically generated meshes can be efficiently tracked and retrieved from the scene graph using the getObjectById method. Every Object3D instance, including standard meshes, is automatically assigned a unique integer id upon instantiation. This article explains how to capture this runtime identifier when spawning meshes programmatically and how to query your scene using scene.getObjectById(id) to update, transform, or remove those objects later in your application.

Understanding Object IDs in Three.js

When you instantiate any 3D object in Three.js—such as a THREE.Mesh—the engine assigns a unique, auto-incrementing integer to its id property. Because this identifier is generated automatically at runtime, it does not conflict with other objects in the same session.

The getObjectById method is available on any class inheriting from THREE.Object3D, including the top-level THREE.Scene. When called, it traverses the hierarchy downwards starting from the caller, returning the first child element whose .id matches the provided argument.

Step 1: Capture the ID at Creation

Because dynamically generated meshes are created at runtime, you must store or associate their generated id somewhere accessible if you plan to search for them later by ID.

// Function to dynamically spawn a mesh
function createDynamicMesh(geometry, material, scene) {
    const mesh = new THREE.Mesh(geometry, material);
    
    // Position or configure the mesh
    mesh.position.set(Math.random() * 10, 0, Math.random() * 10);
    
    // Add the mesh to the scene
    scene.add(mesh);
    
    // Return or store the unique runtime ID
    return mesh.id;
}

// Example usage
const sphereGeo = new THREE.SphereGeometry(1, 16, 16);
const sphereMat = new THREE.MeshBasicMaterial({ color: 0xff0000 });

// Store the ID in a variable, array, or state management system
const dynamicMeshId = createDynamicMesh(sphereGeo, sphereMat, scene);

Step 2: Retrieve the Mesh Using getObjectById

When you need to modify, animate, or delete the dynamically created mesh, pass the saved ID to scene.getObjectById().

function updateMeshColor(meshId, newColorHex) {
    // Search the scene graph for the mesh with the matching ID
    const targetMesh = scene.getObjectById(meshId);

    // Verify the mesh exists before manipulating it
    if (targetMesh && targetMesh.isMesh) {
        targetMesh.material.color.setHex(newColorHex);
    } else {
        console.warn(`Mesh with ID ${meshId} was not found in the scene.`);
    }
}

// Update the mesh created earlier
updateMeshColor(dynamicMeshId, 0x00ff00);

Step 3: Removing the Dynamically Found Mesh

If you need to dispose of or remove the object dynamically using only its ID, retrieve the reference, remove it from its parent, and clean up its resources:

function removeMeshById(meshId) {
    const targetMesh = scene.getObjectById(meshId);

    if (targetMesh) {
        // Remove from parent (usually the scene)
        targetMesh.parent.remove(targetMesh);

        // Dispose geometry and materials to free GPU memory
        if (targetMesh.geometry) targetMesh.geometry.dispose();
        if (targetMesh.material) {
            if (Array.isArray(targetMesh.material)) {
                targetMesh.material.forEach(mat => mat.dispose());
            } else {
                targetMesh.material.dispose();
            }
        }
    }
}

Key Considerations

  • Fast Traversal: getObjectById performs a fast depth-first traversal of the scene graph, making it more efficient than parsing custom arrays for deeply nested children.
  • Session Lifespan: The id property is transient and strictly sequential. It resets when the browser session or JavaScript environment reloads. For saving objects across sessions, store persistent identifiers like UUIDs (mesh.uuid) or names (mesh.name) using getObjectByProperty('uuid', val) or getObjectByName('name') instead.
  • Return Value: If no matching element is found, getObjectById returns undefined. Always implement an existence check prior to reading or modifying properties on the returned object.
