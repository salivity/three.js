Control 3D Audio Volume Drop-Off in Three.js

In Three.js, spatial audio realism depends heavily on how quickly sound attenuates over distance. This guide explains how to use refDistance and rolloffFactor on a THREE.PositionalAudio object to fine-tune volume drop-off, allowing you to create immersive, natural-sounding acoustic environments in your 3D scenes.

Setting Up Positional Audio

To use spatial sound attenuation, you must attach a THREE.AudioListener to a camera and instantiate a THREE.PositionalAudio object attached to a scene mesh. Three.js exposes the underlying Web Audio API PannerNode properties through dedicated setter methods on the PositionalAudio instance.

// Initialize listener and positional sound
const listener = new THREE.AudioListener();
camera.add(listener);

const sound = new THREE.PositionalAudio(listener);

// Load and set the audio buffer
const audioLoader = new THREE.AudioLoader();
audioLoader.load('sound.mp3', (buffer) => {
  sound.setBuffer(buffer);
  sound.play();
});

mesh.add(sound);

Understanding and Defining refDistance

The refDistance property defines the reference distance at which the sound volume is at its maximum (100% gain). As long as the listener is closer to the audio source than the refDistance, no volume reduction occurs. Attenuation begins only after the listener moves past this distance.

To define this value, use the setRefDistance() method:

sound.setRefDistance(5); // Maximum volume within 5 units

Use smaller values (such as 1 or 2) for quiet, localized sounds like a ticking clock, and larger values (such as 20 or 50) for louder sources like an explosion or a concert speaker.

Understanding and Defining rolloffFactor

The rolloffFactor determines how quickly the sound drops off as the listener moves further away from the source beyond the refDistance.

  • A rolloffFactor of 0 disables distance attenuation entirely (volume remains constant).
  • A standard value of 1 simulates natural real-world physical drop-off.
  • A value greater than 1 causes the sound to fade away dramatically faster.
  • A value between 0 and 1 produces a more gradual, subtle volume reduction.

Set this value using the setRolloffFactor() method:

sound.setRolloffFactor(1.5); // Steeper volume decay

Choosing the Distance Model

The behavior of refDistance and rolloffFactor depends directly on the distance model assigned to the audio source via setDistanceModel(). The three supported models are:

  • 'inverse' (Default): Calculates drop-off using the formula:
    1 / (1 + rolloffFactor * (distance - refDistance) / refDistance). This closely models natural acoustic behavior.
  • 'linear': Reduces the volume at a steady rate until reaching maxDistance, calculated as:
    1 - rolloffFactor * (distance - refDistance) / (maxDistance - refDistance).
  • 'exponential': Causes an extreme exponential volume drop-off using:
    pow((distance / refDistance), -rolloffFactor).

Complete Implementation Example

// Configure drop-off settings
sound.setDistanceModel('inverse');
sound.setRefDistance(10);       // Full volume within 10 units
sound.setRolloffFactor(1.2);    // Drop-off rate
sound.setMaxDistance(500);      // Distance beyond which volume ceases to change

By balancing refDistance (the range of maximum clarity) and rolloffFactor (the steepness of the fade), you can accurately replicate both intimate ambient noises and powerful, wide-reaching audio sources.
