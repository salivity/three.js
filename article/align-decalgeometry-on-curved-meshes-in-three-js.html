Align DecalGeometry on Curved Meshes in Three.js

Aligning a DecalGeometry to a curved surface in Three.js requires deriving an oriented bounding box from the target mesh's surface geometry. This process involves calculating an intersection point and normal vector via raycasting, transforming these vectors from world space into the target mesh’s local object space, and constructing a rotation matrix that aligns the decal's projection axis with the surface topology. This article details the mathematical steps and matrix calculations necessary to project decals seamlessly onto complex, curved 3D geometry without stretching or clipping artifacts.

1. Retrieve the Hit Point and Surface Normal

To align a decal, you must first determine where the decal sits on the target geometry and which direction it should face. Use a THREE.Raycaster to capture the intersection data from the curved mesh:

const raycaster = new THREE.Raycaster();
raycaster.setFromCamera(mousePosition, camera);

const intersects = raycaster.intersectObject(targetMesh, true);

if (intersects.length === 0) return;
const hit = intersects[0];

The hit object provides:

  • hit.point: The exact intersection coordinate in world space.
  • hit.face.normal: The normal vector perpendicular to the hit triangular face.

2. Transform Vectors to Local Mesh Space

DecalGeometry constructs its vertices relative to the local coordinate system of the target mesh. If the target mesh is scaled, rotated, or translated, world-space raycast data will cause misalignments.

Convert both the intersection point and the surface normal into the target mesh's local space:

const localPosition = hit.point.clone();
targetMesh.worldToLocal(localPosition);

// Transform the normal using the Normal Matrix (inverse transpose of the world matrix)
const normalMatrix = new THREE.Matrix3().getNormalMatrix(targetMesh.matrixWorld);
const worldNormal = hit.face.normal.clone().applyMatrix3(normalMatrix).normalize();

// Invert target mesh rotation to get local normal direction
const localNormal = worldNormal.clone().applyQuaternion(targetMesh.quaternion.clone().invert());

3. Compute the Projection Orientation Matrix

DecalGeometry requires an orientation expressed as a THREE.Euler rotation. To calculate this, construct a rotation matrix (THREE.Matrix4) that aligns the default projection direction (typically the positive Z-axis (0, 0, 1)) with the calculated surface normal.

// Step 1: Define an arbitrary up-vector to avoid gimbal lock
const targetNormal = localNormal.clone();
const up = new THREE.Vector3(0, 1, 0);

// If the normal is nearly parallel to the up vector, use an alternate reference vector
if (Math.abs(targetNormal.dot(up)) > 0.999) {
    up.set(1, 0, 0);
}

// Step 2: Compute tangent (X) and bitangent (Y) vectors
const tangent = new THREE.Vector3().crossVectors(up, targetNormal).normalize();
const bitangent = new THREE.Vector3().crossVectors(targetNormal, tangent).normalize();

// Step 3: Build the 4x4 orientation matrix
const orientationMatrix = new THREE.Matrix4();
orientationMatrix.makeBasis(tangent, bitangent, targetNormal);

// Step 4: Extract Euler angles
const orientationEuler = new THREE.Euler().setFromRotationMatrix(orientationMatrix);

If you wish to rotate the decal around its projection axis (roll), rotate the tangent and bitangent around the targetNormal before building the basis matrix.

4. Construct the DecalGeometry

Pass the computed local position, orientation, and decal dimensions to DecalGeometry. The projection acts as an oriented bounding box that clips target triangles intersecting its volume.

import { DecalGeometry } from 'three/examples/jsm/geometries/DecalGeometry.js';

const decalSize = new THREE.Vector3(1, 1, 1); // Width, Height, Depth (Projection depth)

const decalGeometry = new DecalGeometry(
    targetMesh,
    localPosition,
    orientationEuler,
    decalSize
);

const decalMaterial = new THREE.MeshStandardMaterial({
    map: decalTexture,
    transparent: true,
    depthTest: true,
    depthWrite: false,
    polygonOffset: true,
    polygonOffsetFactor: -4,
    polygonOffsetUnits: -4
});

const decalMesh = new THREE.Mesh(decalGeometry, decalMaterial);
targetMesh.add(decalMesh);

5. Preventing Artifacts on Curved Surfaces

When mapping onto sharp or high-curvature geometry:

  • Z-Fighting: Always enable polygonOffset on the decal material to displace the decal slightly outward in screen space without altering world coordinates.
  • Projection Depth: Keep the Z-component of decalSize (the projection depth) as shallow as possible. Excess depth causes the projection to clip through the back sides of thin, curved meshes.
  • Vertex Normal Interpolation: If the base mesh uses smooth shading, face normals might create visible angular discrepancies. To achieve smoother alignment, compute the barycentric coordinates of hit.point on hit.face to interpolate the vertex normals rather than relying strictly on the flat face normal.
