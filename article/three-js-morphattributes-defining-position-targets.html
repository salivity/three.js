Three.js morphAttributes: Defining Position Targets

In Three.js, morph targets—often called blend shapes—allow meshes to deform smoothly between different geometric states. This article provides a concise, step-by-step guide on how to utilize the morphAttributes property of a BufferGeometry to define secondary position targets. You will learn how to structure target vertex data, register secondary attributes, and control the resulting deformation dynamically at runtime using target influence weights.

Understanding morphAttributes

The morphAttributes property on a BufferGeometry is an object that stores arrays of BufferAttribute instances for various vertex channels, such as position, normal, and color.

To define secondary position targets, you populate an array under geometry.morphAttributes.position. Each entry in this array must contain the exact same number of vertices as the primary geometry.attributes.position. Modern Three.js shader implementations calculate morph targets as relative offsets (deltas) added to the base positions, meaning target values represent the displacement (targetPosition - basePosition).

Step-by-Step Implementation

1. Create the Base Geometry

Start with a standard BufferGeometry or any built-in geometry primitive:

import * as THREE from 'three';

// Create a simple base plane
const geometry = new THREE.PlaneGeometry(2, 2, 4, 4);

2. Generate the Target Position Data

To morph the geometry, create an array of vertex positions representing the deformation offset. Every vertex in the base geometry must have a corresponding delta vector in the target array.

const positionAttribute = geometry.attributes.position;
const targetPositions = [];

for (let i = 0; i < positionAttribute.count; i++) {
  // Read the original vertex position
  const x = positionAttribute.getX(i);
  const y = positionAttribute.getY(i);
  const z = positionAttribute.getZ(i);

  // Compute a target position (e.g., displacing vertices along the Z axis)
  const targetX = x;
  const targetY = y;
  const targetZ = z + Math.sin(x * Math.PI) * 0.5;

  // Modern Three.js expects relative deltas: (target - base)
  targetPositions.push(
    targetX - x,
    targetY - y,
    targetZ - z
  );
}

3. Attach the BufferAttribute to morphAttributes

Wrap your target array into a Float32BufferAttribute with an item size of 3 (for X, Y, and Z components), and assign it to the morphAttributes.position array:

// Convert array to Float32BufferAttribute
const morphTarget = new THREE.Float32BufferAttribute(targetPositions, 3);

// Assign the target to the geometry's morphAttributes
geometry.morphAttributes.position = [morphTarget];

You can define multiple position targets by pushing additional Float32BufferAttribute instances into this array.

4. Create the Mesh and Enable Morphing

Instantiate a Mesh using your geometry and a compatible material. Standard materials (such as MeshBasicMaterial, MeshStandardMaterial, or MeshPhongMaterial) support morph targets automatically.

const material = new THREE.MeshStandardMaterial({
  color: 0x3498db,
  wireframe: true
});

const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

5. Control Target Influences

Once attached to a mesh, Three.js automatically exposes a morphTargetInfluences array on the mesh object. Each index in this array corresponds to the target at the same index in geometry.morphAttributes.position. Values range from 0 (no deformation) to 1 (full deformation).

// Set the first morph target to 50% influence
mesh.morphTargetInfluences[0] = 0.5;

// Animate the deformation inside your render loop
function animate() {
  requestAnimationFrame(animate);

  // Oscillate the morph target influence between 0 and 1
  mesh.morphTargetInfluences[0] = (Math.sin(Date.now() * 0.003) + 1) / 2;

  renderer.render(scene, camera);
}

Considerations for Normals

When morphing surfaces that require lighting calculations, changing only the position channel can cause shading artifacts because surface normals will not reflect the deformed shape. To fix this, you can compute or supply corresponding morph normals under geometry.morphAttributes.normal using the same indexing and sizing pattern used for positions.
