Realistic Ocean Waves with Water.js in Three.js

This guide explains how to simulate dynamic ocean waves and planar reflections using the official Water shader component (Water.js) in Three.js. You will learn how to import the required modules, configure surface geometry, load wave normal maps, adjust reflection and sun parameters, and animate the surface displacement inside the render loop.

1. Import Dependencies

The Water class is not bundled in the core Three.js library; it resides in the add-ons directory. Import Three.js along with Water from the three/addons path:

import * as THREE from 'three';
import { Water } from 'three/addons/objects/Water.js';
import { Sky } from 'three/addons/objects/Sky.js'; // Optional, recommended for realistic reflections

2. Load the Water Normal Map

Realistic surface distortion relies on a normal map (commonly waternormals.jpg). The texture must repeat continuously across the surface:

const textureLoader = new THREE.TextureLoader();
const waterNormals = textureLoader.load('textures/waternormals.jpg', function (texture) {
    texture.wrapS = texture.wrapT = THREE.RepeatWrapping;
});

3. Create the Water Mesh

Construct a large flat plane geometry and pass it to the Water constructor alongside a configuration object:

const waterGeometry = new THREE.PlaneGeometry(10000, 10000);

const water = new Water(waterGeometry, {
    textureWidth: 512,
    textureHeight: 512,
    waterNormals: waterNormals,
    sunDirection: new THREE.Vector3(),
    sunColor: 0xffffff,
    waterColor: 0x001e0f,
    distortionScale: 3.7,
    fog: scene.fog !== undefined
});

// Rotate the plane horizontally
water.rotation.x = -Math.PI / 2;

scene.add(water);

Key Configuration Parameters:

  • textureWidth / textureHeight: Resolution of the internal render target used for real-time planar reflections. Higher values yield sharper reflections at the cost of performance.
  • waterNormals: The repeating normal texture driving the wave perturbation.
  • distortionScale: Controls the intensity and choppiness of the wave reflections.
  • waterColor: The deep base color of the water body.
  • sunColor and sunDirection: Dictates specular highlights and sun glare on the wave crests.

4. Align Sun Direction and Lighting

Planar reflections dynamically mirror objects in the scene above the water plane. To ensure accurate specular highlights, bind the water shader's sunDirection uniform to your primary directional light source or sky system:

const sun = new THREE.Vector3();
const directionalLight = new THREE.DirectionalLight(0xffffff, 1.5);
scene.add(directionalLight);

// Update sun vector (example angles: elevation and azimuth)
const phi = THREE.MathUtils.degToRad(90 - 2);
const theta = THREE.MathUtils.degToRad(180);
sun.setFromSphericalCoords(1, phi, theta);

directionalLight.position.copy(sun);
water.material.uniforms['sunDirection'].value.copy(sun).normalize();

5. Animate Wave Motion

To produce flowing waves, update the time uniform inside your application's request animation frame loop:

function animate() {
    requestAnimationFrame(animate);

    // Increment time uniform to scroll normal maps
    water.material.uniforms['time'].value += 1.0 / 60.0;

    renderer.render(scene, camera);
}

animate();

Complete Implementation Example

import * as THREE from 'three';
import { Water } from 'three/addons/objects/Water.js';

// Scene, Camera, Renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(55, window.innerWidth / window.innerHeight, 1, 20000);
camera.position.set(30, 30, 100);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.toneMapping = THREE.ACESFilmicToneMapping;
document.body.appendChild(renderer.domElement);

// Sunlight
const sun = new THREE.Vector3();
const light = new THREE.DirectionalLight(0xffffff, 2.0);
scene.add(light);

// Water Mesh
const waterGeometry = new THREE.PlaneGeometry(10000, 10000);
const textureLoader = new THREE.TextureLoader();

const water = new Water(waterGeometry, {
    textureWidth: 512,
    textureHeight: 512,
    waterNormals: textureLoader.load('textures/waternormals.jpg', (t) => {
        t.wrapS = t.wrapT = THREE.RepeatWrapping;
    }),
    sunDirection: new THREE.Vector3(),
    sunColor: 0xffffff,
    waterColor: 0x001e0f,
    distortionScale: 3.7
});

water.rotation.x = -Math.PI / 2;
scene.add(water);

// Position Light and Update Water Uniform
sun.set(100, 10, -100).normalize();
light.position.copy(sun);
water.material.uniforms['sunDirection'].value.copy(sun).normalize();

// Animation Loop
function animate() {
    requestAnimationFrame(animate);
    water.material.uniforms['time'].value += 1.0 / 60.0;
    renderer.render(scene, camera);
}

animate();
