Three.js DodecahedronGeometry Detail Levels

This guide demonstrates how to construct and configure a DodecahedronGeometry with varying levels of detail in Three.js. By adjusting the detail parameter in the geometry constructor, you can transform a standard 12-sided platonic solid into an increasingly complex, spherical polyhedron. You will learn the syntax, observe code examples across multiple detail settings, and understand how subdivisions affect vertex counts and rendering performance.

The DodecahedronGeometry Constructor

In Three.js, the DodecahedronGeometry class creates a dodecahedron mesh using two primary parameters:

new THREE.DodecahedronGeometry(radius, detail);
  • radius (Float): The distance from the center of the shape to its vertices. The default value is 1.
  • detail (Integer): The number of subdivisions added to the faces. The default value is 0.

Understanding the Detail Parameter

When detail is set to 0, Three.js renders a standard dodecahedron composed of 12 pentagonal faces (split into triangles for GPU rendering).

Increasing the detail value subdivides each original face into smaller triangles and projects the new vertices outward to match the specified radius. This process turns the flat-faced geometric shape into a geodesic sphere.

Implementation Examples

1. Default Dodecahedron (Detail = 0)

Setting the detail to 0 maintains the sharp, classic 12-faced polyhedron profile.

import * as THREE from 'three';

// Radius: 5, Detail: 0
const geometryLevel0 = new THREE.DodecahedronGeometry(5, 0);
const material = new THREE.MeshStandardMaterial({ color: 0x0077ff, flatShading: true });
const meshLevel0 = new THREE.Mesh(geometryLevel0, material);
scene.add(meshLevel0);

2. Intermediate Subdivisions (Detail = 1 or 2)

Setting the detail to 1 or 2 creates a faceted, "low-poly" sphere aesthetic.

// A slightly subdivided dodecahedron
const geometryLevel1 = new THREE.DodecahedronGeometry(5, 1);
const meshLevel1 = new THREE.Mesh(geometryLevel1, material);

// A denser low-poly geodesic mesh
const geometryLevel2 = new THREE.DodecahedronGeometry(5, 2);
const meshLevel2 = new THREE.Mesh(geometryLevel2, material);

3. Smooth Geodesic Sphere (Detail = 3 to 5)

Increasing the detail to 3 or higher generates enough triangles to create a visually smooth sphere, while preserving an underlying geodesic pattern rather than the standard latitude/longitude lines of a SphereGeometry.

// High-detail spherical mesh
const geometryHighDetail = new THREE.DodecahedronGeometry(5, 4);
const smoothMaterial = new THREE.MeshStandardMaterial({ color: 0x0077ff, flatShading: false });
const smoothSphereMesh = new THREE.Mesh(geometryHighDetail, smoothMaterial);
scene.add(smoothSphereMesh);

Performance Considerations

Each increment of the detail integer multiplies the polygon count significantly. While detail values between 0 and 3 are lightweight, values above 5 can rapidly inflate triangle and vertex counts, leading to memory overhead and reduced frame rates. For dynamic Level of Detail (LOD) systems, use THREE.LOD to swap between low-detail (detail: 0 or 1) and high-detail versions based on the camera's distance.
