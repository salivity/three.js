Disable depthWrite for Transparent Particles in Three.js

When rendering transparent particles in Three.js, artifacts often occur where transparent regions erroneously hide or cut off geometry behind them. This article explains why the depth buffer causes these visual glitches and demonstrates how to disable the depthWrite property on particle materials to ensure background objects remain visible through transparent areas.

The Cause of Transparent Occlusion

By default, Three.js materials have the depthWrite property enabled (true). The WebGL renderer uses the depth buffer (Z-buffer) to track how close each rendered pixel is to the camera. When a transparent particle renders, it writes its depth values into the Z-buffer.

If geometry behind the particle is rendered after the particle itself, the depth test compares the new pixel against the particle's depth value. Because the particle is closer, the GPU discards the background pixels—even if the particle's texture is fully transparent at that spot. This results in transparent textures appearing as opaque boxes or silhouettes blocking objects behind them.

The Solution: Setting depthWrite to False

To prevent transparent particles from occluding objects behind them, set depthWrite: false on the particle's material. This informs the WebGL renderer not to record the particle's position in the Z-buffer, allowing any subsequently drawn geometry behind the particle to render without being discarded.

Here is an example using THREE.PointsMaterial:

import * as THREE from 'three';

// Load the particle texture
const textureLoader = new THREE.TextureLoader();
const particleTexture = textureLoader.load('path/to/particle.png');

// Create the particle material with depthWrite disabled
const particleMaterial = new THREE.PointsMaterial({
    size: 0.5,
    map: particleTexture,
    transparent: true,
    depthWrite: false,      // Disables writing to the Z-buffer
    depthTest: true,       // Keeps depth testing active so particles hide behind solid objects
    blending: THREE.NormalBlending // Or THREE.AdditiveBlending for glowing effects
});

// Create the particle geometry and system
const particleGeometry = new THREE.BufferGeometry();
// ... populate geometry vertices ...

const particleSystem = new THREE.Points(particleGeometry, particleMaterial);
scene.add(particleSystem);

Key Considerations

  • Keep depthTest: true: Do not disable depthTest. Disabling depthTest would cause particles to render on top of all solid geometry in the scene, regardless of distance from the camera. Leaving depthTest: true ensures particles are still properly occluded by solid foreground objects.
  • Enable transparent: true: The depthWrite: false property must be paired with transparent: true to enable alpha blending.
  • Additive Blending: For particle effects like fire, magic, or smoke, setting blending: THREE.AdditiveBlending alongside depthWrite: false eliminates sorting order issues completely by adding color values together regardless of draw order.
