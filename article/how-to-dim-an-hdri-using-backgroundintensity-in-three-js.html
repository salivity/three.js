How to Dim an HDRI Using backgroundIntensity in Three.js

Controlling the brightness of an HDRI environment map is essential for creating balanced visual contrast and proper aesthetic tone in 3D scenes. This guide demonstrates how to use the native scene.backgroundIntensity property in Three.js to globally dim or brighten the visual background without needing to alter the source texture or write custom shaders.

Understanding backgroundIntensity

In Three.js, a scene can use an HDRI texture for two distinct purposes: as a visible backdrop via scene.background, and as a source for image-based lighting (IBL) via scene.environment.

The scene.backgroundIntensity property is a scalar multiplier that applies directly to the RGB values of whatever texture or color is assigned to scene.background. Its default value is 1.0. Setting this value below 1.0 dims the visual background, while setting it above 1.0 increases its brightness.

Crucially, adjusting backgroundIntensity only modifies the visible skybox; it does not reduce the light emitted onto your 3D objects if the same texture is assigned to scene.environment.

Step-by-Step Implementation

To apply and dim an HDRI background, load the texture using RGBELoader, assign it to the scene, and adjust the backgroundIntensity scalar.

import * as THREE from 'three';
import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';

// 1. Initialize your scene and renderer
const scene = new THREE.Scene();
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.toneMapping = THREE.ACESFilmicToneMapping;

// 2. Load the HDRI file
const rgbeLoader = new RGBELoader();
rgbeLoader.load('textures/environment.hdr', (texture) => {
    texture.mapping = THREE.EquirectangularReflectionMapping;

    // Apply the HDRI to both the visible background and lighting
    scene.background = texture;
    scene.environment = texture;

    // 3. Globally dim the visual background
    scene.backgroundIntensity = 0.25; // Lowers brightness to 25%
});

Decoupling Background and Lighting Intensity

If your goal is to dim the entire environment—both what the camera sees in the background and the light that reflects off your meshes—you can combine scene.backgroundIntensity with scene.environmentIntensity:

  • scene.backgroundIntensity = 0.3; Dims only the visual backdrop behind your models.
  • scene.environmentIntensity = 0.3; Dims the ambient lighting, reflections, and irradiance cast onto PBR materials.

Adjusting these two properties independently allows you to achieve high-contrast setups, such as keeping a dark, moody background while maintaining vivid reflections on foreground objects.
