How to Enable Physically Correct Lighting in Three.js

This guide explains how to configure the WebGLRenderer and light sources in modern Three.js to achieve physically accurate lighting. In recent releases (r155 and newer), Three.js enables physically correct lighting formulas by default, removing legacy lighting modes and flags. To fully utilize this native pipeline, developers must configure appropriate color spaces, tone mapping operators, and physical light properties such as decay and real-world luminous units.

The Native Paradigm in Modern Three.js

In earlier versions of Three.js, physically accurate attenuation required setting renderer.physicallyCorrectLights = true or renderer.useLegacyLights = false. In modern Three.js, these properties are deprecated and removed. Physically correct lighting is the standard, native behavior. Light intensity now reflects physical units:

  • PointLight and SpotLight: Measured in Lumens (lm) or Candela (cd).
  • DirectionalLight: Measured in Lux (\(\text{lm}/\text{m}^2\)).
  • AmbientLight and HemisphereLight: Measured in Lux or nits.

Step 1: Configure WebGLRenderer Color Space

Physically correct calculations must take place in linear color space and be converted to sRGB for display. Ensure your renderer outputs to the correct color space:

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);

// Ensure output color space is set to sRGB (default in modern versions)
renderer.outputColorSpace = THREE.SRGBColorSpace;

Step 2: Implement Tone Mapping

Because physically correct lights use significantly higher intensity values than legacy arbitrary ranges, high dynamic range (HDR) values can blow out surface highlights. Configure tone mapping to compress the dynamic range:

// ACES Filmic is the industry standard for realistic filmic contrast
renderer.toneMapping = THREE.ACESFilmicToneMapping;

// Adjust exposure to tune scene brightness
renderer.toneMappingExposure = 1.0;

Step 3: Configure Light Attenuation and Units

For physically accurate falloff, lights must adhere to the inverse-square law. Three.js achieves this through specific decay and distance values:

  1. Set decay to 2: This models physical inverse-square falloff (\(I / d^2\)). While 2 is now the default, always verify this property is not altered.
  2. Set distance to 0: A distance of 0 ensures the light attenuation is purely mathematical without an arbitrary cutoff distance.
// Point Light example
const pointLight = new THREE.PointLight(0xffffff, 1000); // 1,000 Lumens
pointLight.decay = 2; // Physical inverse-square falloff
pointLight.distance = 0; // Infinite range with natural attenuation
pointLight.position.set(0, 5, 0);
scene.add(pointLight);

// Directional Light example (Sunlight)
const sunLight = new THREE.DirectionalLight(0xffffff, 5); // Measured in Lux
sunLight.position.set(10, 20, 10);
scene.add(sunLight);

Complete Setup Example

import * as THREE from 'three';

// 1. Initialize Renderer
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.0;
document.body.appendChild(renderer.domElement);

// 2. Initialize Scene and Camera
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 2, 5);

// 3. Add Physically Accurate Light
const pointLight = new THREE.PointLight(0xffeedd, 1500, 0, 2);
pointLight.position.set(2, 3, 2);
scene.add(pointLight);

// 4. Mesh with Standard Physical Material
const material = new THREE.MeshStandardMaterial({ roughness: 0.2, metalness: 0.5 });
const geometry = new THREE.SphereGeometry(1, 32, 32);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// 5. Render Loop
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();
