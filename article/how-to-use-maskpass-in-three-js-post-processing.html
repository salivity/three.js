How to Use MaskPass in Three.js Post-Processing

This article explains how to configure MaskPass and ClearMaskPass within Three.js post-processing pipelines using EffectComposer. You will learn how to leverage the WebGL stencil buffer to confine visual effects—such as blurs, color grading, or bloom—to specific geometric shapes or screen regions, preventing them from affecting the rest of the rendered scene.

1. Enable the Stencil Buffer

MaskPass relies directly on the hardware stencil buffer to determine which pixels receive subsequent shader effects. You must ensure the stencil buffer is enabled in both the renderer and the render target used by EffectComposer.

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';

// Initialize the WebGLRenderer with stencil enabled
const renderer = new THREE.WebGLRenderer({ stencil: true, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Ensure the render target supports the stencil buffer
const renderTarget = new THREE.WebGLRenderTarget(
  window.innerWidth,
  window.innerHeight,
  {
    stencilBuffer: true
  }
);

const composer = new EffectComposer(renderer, renderTarget);

2. Create the Masking Scene

A MaskPass uses a dedicated THREE.Scene containing the meshes that define the shape of the masked region. The material used on these meshes does not need complex shading, as only their geometry writes to the stencil buffer.

const maskScene = new THREE.Scene();

// Define a shape to act as the mask area (e.g., a centered circle)
const maskGeometry = new THREE.CircleGeometry(2, 32);
const maskMaterial = new THREE.MeshBasicMaterial({ color: 0xffffff });
const maskMesh = new THREE.Mesh(maskGeometry, maskMaterial);
maskMesh.position.z = -5;

maskScene.add(maskMesh);

3. Assemble the Post-Processing Chain

To apply effects only within the mask, add passes to EffectComposer in a specific execution order:

  1. Base RenderPass: Renders the main scene normally.
  2. MaskPass: Writes the mask scene geometry to the stencil buffer.
  3. Effect Passes: Shaders or effects inserted here are restricted to the masked region.
  4. ClearMaskPass: Disables and resets the stencil buffer so subsequent passes apply globally again.
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { MaskPass, ClearMaskPass } from 'three/addons/postprocessing/MaskPass.js';
import { ShaderPass } from 'three/addons/postprocessing/ShaderPass.js';
import { DotScreenShader } from 'three/addons/shaders/DotScreenShader.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

// 1. Render primary scene
const mainRenderPass = new RenderPass(scene, camera);
composer.addPass(mainRenderPass);

// 2. Activate the mask
const maskPass = new MaskPass(maskScene, camera);
composer.addPass(maskPass);

// 3. Add effects restricted to the mask area
const effectPass = new ShaderPass(DotScreenShader);
composer.addPass(effectPass);

// 4. Clear the mask
const clearMaskPass = new ClearMaskPass();
composer.addPass(clearMaskPass);

// 5. Final output
const outputPass = new OutputPass();
composer.addPass(outputPass);

4. Invert the Mask (Optional)

If an effect should affect everything except the designated area, invert the masking operation by setting the inverse property on the MaskPass instance:

maskPass.inverse = true;

When set to true, the effect pass executes exclusively on pixels outside the geometry defined in maskScene.

5. Render Loop

Call composer.render() within the animation loop instead of renderer.render():

function animate() {
  requestAnimationFrame(animate);
  composer.render();
}
animate();
