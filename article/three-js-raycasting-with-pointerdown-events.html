Three.js Raycasting with Pointerdown Events

This article explains how to migrate from legacy mouse events to the modern Pointer Events API for raycasting in Three.js. By replacing mousedown with pointerdown, you can streamline your 3D interaction logic into a single, unified workflow that supports mice, touchscreens, and digital pens without duplicating code.

Why Switch to Pointer Events

Historically, handling cross-platform user input in Three.js required listening to both mousedown and touchstart. Modern web standards replace this dual approach with the Pointer Events API. Using pointerdown provides a consistent event model across desktop and mobile devices, eliminates touch-emulation delays, and avoids issues where mobile browsers fire both touch and simulated mouse events.

Step-by-Step Implementation

To perform raycasting using pointerdown, you need an instance of THREE.Raycaster, a THREE.Vector2 to store normalized device coordinates (NDC), and an event listener attached to the canvas or window.

1. Initialize Raycaster and Vector2

Set up the raycaster and pointer vector outside the event listener to avoid unnecessary memory allocations on every interaction:

import * as THREE from 'three';

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

2. Create the Event Handler

Map the pointer coordinates from screen space into Normalized Device Coordinates, where \(x\) and \(y\) range from -1 to +1. Once normalized, update the raycaster with the active camera and query the scene for intersected objects:

function onPointerDown(event) {
  // Calculate pointer position in normalized device coordinates (-1 to +1)
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;

  // Update the picking ray with the camera and pointer position
  raycaster.setFromCamera(pointer, camera);

  // Calculate objects intersecting the picking ray
  const intersects = raycaster.intersectObjects(scene.children);

  if (intersects.length > 0) {
    const selectedObject = intersects[0].object;
    // Perform actions on the clicked object
    console.log('Intersected object:', selectedObject);
  }
}

3. Bind the Listener

Attach the pointerdown listener to the renderer's DOM element rather than the global window object when possible. This prevents raycasting calculations when clicking on UI overlays outside the 3D canvas:

renderer.domElement.addEventListener('pointerdown', onPointerDown);

If your canvas does not occupy the full screen, calculate the pointer coordinates relative to the canvas bounding box instead of window.innerWidth and window.innerHeight:

const rect = renderer.domElement.getBoundingClientRect();
pointer.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
pointer.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;

Best Practices

  • Touch Action CSS: When handling pointer events on a canvas, add touch-action: none; to your CSS for the canvas element. This prevents the browser from intercepting touch gestures for default behaviors like scrolling or pinch-to-zoom.
  • Recursive Checks: By default, intersectObjects only checks top-level objects. Pass true as the second argument (raycaster.intersectObjects(scene.children, true)) to traverse nested meshes in THREE.Group structures.
