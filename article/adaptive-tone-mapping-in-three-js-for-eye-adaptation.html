Adaptive Tone Mapping in Three.js for Eye Adaptation

Simulating the human eye's ability to adjust between dark shadows and blinding highlights requires High Dynamic Range (HDR) rendering paired with dynamic luminance adaptation. In Three.js, this optical effect is achieved using the AdaptiveToneMappingPass within the EffectComposer post-processing pipeline. This guide covers how to configure the pass, integrate it into a scene, and adjust its parameters to recreate realistic visual adaptation.

1. Import the Required Modules

Dynamic tone mapping relies on Three.js post-processing addons. Import the standard renderer passes along with AdaptiveToneMappingPass:

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { AdaptiveToneMappingPass } from 'three/addons/postprocessing/AdaptiveToneMappingPass.js';

2. Set Up the Renderer and EffectComposer

Because tone mapping operates on HDR values, you must ensure your scene utilizes wide dynamic ranges (e.g., lights with intensities exceeding standard 1.0 limits) and that the render targets can store floating-point precision values.

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(window.devicePixelRatio);
renderer.toneMapping = THREE.NoToneMapping; // Defer tone mapping to the composer
document.body.appendChild(renderer.domElement);

// Use HalfFloatType render target for HDR range
const renderTarget = new THREE.WebGLRenderTarget(
  window.innerWidth,
  window.innerHeight,
  {
    type: THREE.HalfFloatType
  }
);

const composer = new EffectComposer(renderer, renderTarget);

3. Add the Passes

To evaluate luminance continuously, add the basic RenderPass followed by the AdaptiveToneMappingPass.

const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// Initialize pass: adaptive, tone mapping texture size (must be power of two)
const adaptiveToneMappingPass = new AdaptiveToneMappingPass(true, 256);
composer.addPass(adaptiveToneMappingPass);

The second argument to AdaptiveToneMappingPass sets the resolution of the luminance downsampling texture. A resolution of 256 balances performance and accuracy.

4. Configure Adaptation Parameters

The behavior of the virtual eye is defined by four core properties:

  • adaptationRate: Determines how fast the visual adjustment occurs. Lower values yield slower adaptation (like walking into a pitch-black room), while higher values produce rapid adjustments.
  • minLuminance: The lower bound of luminance the pass can adapt to. Prevents the scene from over-amplifying low-light noise.
  • maxLuminance: The maximum light cap. Prevents excessively intense lights from bleaching out the entire screen permanently.
  • middleGrey: Controls overall scene exposure target (key value). Increasing this makes the final adapted scene brighter.
adaptiveToneMappingPass.adaptationRate = 1.5; // Speed of adjustment
adaptiveToneMappingPass.minLuminance = 0.01;  // Dark room floor
adaptiveToneMappingPass.maxLuminance = 16.0;  // Bright sunlight ceiling
adaptiveToneMappingPass.middleGrey = 0.6;     // Target brightness

5. Render Loop Implementation

In the animation loop, call composer.render() instead of renderer.render(). Pass the frame delta time to ensure smooth, frame-rate-independent adaptation transitions.

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  
  // EffectComposer handles the adaptive pass internal timing
  composer.render(delta);
}

animate();

When resizing the window, make sure to resize both the renderer and the composer:

window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();

  renderer.setSize(window.innerWidth, window.innerHeight);
  composer.setSize(window.innerWidth, window.innerHeight);
});
