Transform Vector3 Direction with Matrix4 in Three.js

Transforming a directional vector in Three.js requires a different mathematical approach than transforming a spatial position because directional vectors represent orientation without a fixed origin. Applying a standard 4x4 affine matrix directly via translation-aware methods will corrupt directional data. This guide explains how to correctly apply a Matrix4 to a Vector3 representing a direction using built-in Three.js methods, covering standard rotations and handling complex scenarios involving non-uniform scaling.

Why Standard applyMatrix4 Fails for Directions

A standard affine transformation matrix (THREE.Matrix4) encodes translation, rotation, and scale. When you use vector.applyMatrix4(matrix), Three.js treats the vector as a point in 3D space by implicitly setting its homogeneous coordinate \(w\) to 1:

\[[x, y, z, 1]\]

This causes any translation components within the matrix to be added directly to the vector's components. Because a direction vector has no position, translation must be ignored by setting the homogeneous coordinate \(w\) to 0:

\[[x, y, z, 0]\]

Method 1: Using Vector3.transformDirection()

For standard transformations where the matrix contains rotations, translations, and uniform scaling, Three.js provides the native transformDirection() method.

This method extracts the upper-left 3x3 rotation-scale component of the Matrix4, multiplies it by the vector, and automatically normalizes the resulting vector to preserve unit length.

import * as THREE from 'three';

// Define a direction vector (e.g., pointing forward along the Z-axis)
const direction = new THREE.Vector3(0, 0, 1);

// Assume object has undergone complex rotations and translations
const matrix = object.matrixWorld;

// Transform the direction
direction.transformDirection(matrix);

transformDirection() ignores the translation column entirely, ensuring the vector only rotates and retains a length of 1.

Method 2: Handling Non-Uniform Scaling with a Normal Matrix

If your transformation matrix contains non-uniform scaling (e.g., scaling by (1, 2, 1)), the upper-left 3x3 submatrix will distort the direction, causing surface normals and perpendicular vectors to lose their correct orientations.

To preserve the true orientation under non-uniform scaling, you must transform the vector using the inverse transpose of the 3x3 transformation matrix, commonly known as the Normal Matrix.

import * as THREE from 'three';

const direction = new THREE.Vector3(0, 1, 0); // e.g., a surface normal
const matrix4 = object.matrixWorld;

// 1. Create a Matrix3 to store the normal matrix
const normalMatrix = new THREE.Matrix3();

// 2. Compute the inverse transpose of the 4x4 matrix
normalMatrix.getNormalMatrix(matrix4);

// 3. Apply the normal matrix to the direction and re-normalize
direction.applyMatrix3(normalMatrix).normalize();

Choosing the Right Method

  • Use vector.transformDirection(matrix4) when working with raycasting directions, camera forward vectors, or meshes that only experience translation, rotation, and uniform scaling.
  • Use normalMatrix.getNormalMatrix(matrix4) with vector.applyMatrix3() when transforming surface normals or perpendicular vectors for objects subjected to non-uniform scaling.
