Combining Parent and Child Quaternions in Three.js

In Three.js, calculating the combined orientation of a hierarchical relationship requires multiplying the parent and child rotations in a specific sequence. Because quaternion multiplication is non-commutative, reversing the order of operands yields an incorrect transformation. This guide explains how to properly sequence parent and child rotations using the Quaternion.multiplyQuaternions method to achieve accurate hierarchical results.

Understanding the Multiplication Order

When compounding rotations in 3D graphics, transformations are applied from right to left relative to the vector being transformed. To apply a local rotation (\(Q_{\text{child}}\)) and then rotate that result by a parent's orientation (\(Q_{\text{parent}}\)), the mathematical expression is:

\[Q_{\text{combined}} = Q_{\text{parent}} \times Q_{\text{child}}\]

In Three.js, the multiplyQuaternions(a, b) method sets the calling quaternion to the product of \(a \times b\). Therefore, the parent quaternion must be passed as the first argument, and the child quaternion must be passed as the second argument:

const combinedQuaternion = new THREE.Quaternion();
combinedQuaternion.multiplyQuaternions(parentQuaternion, childQuaternion);

Step-by-Step Implementation

To combine independent parent and child rotations manually without relying on the Three.js scene graph hierarchy, follow this pattern:

import * as THREE from 'three';

// 1. Define parent rotation (e.g., rotating 45 degrees around the Y axis)
const parentQuaternion = new THREE.Quaternion();
parentQuaternion.setFromAxisAngle(new THREE.Vector3(0, 1, 0), Math.PI / 4);

// 2. Define child rotation (e.g., rotating 30 degrees around the X axis)
const childQuaternion = new THREE.Quaternion();
childQuaternion.setFromAxisAngle(new THREE.Vector3(1, 0, 0), Math.PI / 6);

// 3. Multiply: Parent * Child
const resultQuaternion = new THREE.Quaternion();
resultQuaternion.multiplyQuaternions(parentQuaternion, childQuaternion);

// 4. Apply the compounded orientation to a target mesh
const childMesh = new THREE.Mesh(geometry, material);
childMesh.quaternion.copy(resultQuaternion);

Global vs. Local Sequencing

The order of arguments directly determines the coordinate frame of the applied rotation:

  • Parent * Child (multiplyQuaternions(parent, child)): Rotates the child around its own local axes, followed by the parent's rotation. This represents the standard parent-child hierarchy found in scene graphs.
  • Child * Parent (multiplyQuaternions(child, parent)): Applies the parent's rotation in the child's local frame, which creates an extrinsic, inverted behavior rarely used in standard object hierarchies.

If you are modifying an existing quaternion in-place instead of using a separate target object, you can also use premultiply or multiply:

  • childQuaternion.premultiply(parentQuaternion) is equivalent to childQuaternion = parentQuaternion * childQuaternion.
  • parentQuaternion.multiply(childQuaternion) is equivalent to parentQuaternion = parentQuaternion * childQuaternion.
