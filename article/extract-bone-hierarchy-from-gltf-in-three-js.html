Extract Bone Hierarchy from GLTF in Three.js

Extracting the structural hierarchy of a complex skeletal rig loaded via GLTFLoader in Three.js requires traversing the loaded scene graph, identifying the skeleton, and building a tree representation of parent-child bone relationships. This guide explains how to locate the rig's components from a GLTF asset, identify root bones, and recursively serialize the bone hierarchy into a clean JavaScript object for debugging, inverse kinematics, or animation retargeting.

1. Locate the Rig and Root Bone

When GLTFLoader parses a rigged model, it creates THREE.SkinnedMesh and THREE.Bone instances. A SkinnedMesh contains a Skeleton object which holds a flat array of all associated bones via skinnedMesh.skeleton.bones.

To establish the hierarchy, find the SkinnedMesh and determine its true root bone by traversing upwards until a parent node is no longer a THREE.Bone.

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

loader.load('path/to/model.glb', (gltf) => {
    let skinnedMesh = null;

    // Traverse the scene to find the first SkinnedMesh
    gltf.scene.traverse((node) => {
        if (node.isSkinnedMesh && !skinnedMesh) {
            skinnedMesh = node;
        }
    });

    if (!skinnedMesh) {
        console.error('No SkinnedMesh found in model.');
        return;
    }

    const rootBone = findRootBone(skinnedMesh.skeleton.bones);
    const hierarchy = buildBoneTree(rootBone);
    
    console.log(hierarchy);
});

function findRootBone(bones) {
    // Pick the first bone and navigate up to the highest parent that is still a Bone
    let root = bones[0];
    while (root.parent && root.parent.isBone) {
        root = root.parent;
    }
    return root;
}

2. Recursively Extract the Tree Structure

Once the root bone is isolated, write a recursive function to capture the bone names, transform data, and nested child bones while ignoring non-bone nodes such as attachments or mesh fragments.

function buildBoneTree(bone) {
    const boneData = {
        name: bone.name,
        uuid: bone.uuid,
        position: bone.position.toArray(),
        quaternion: bone.quaternion.toArray(),
        scale: bone.scale.toArray(),
        children: []
    };

    // Filter and recurse only on children that are THREE.Bone instances
    for (let i = 0; i < bone.children.length; i++) {
        const child = bone.children[i];
        if (child.isBone) {
            boneData.children.push(buildBoneTree(child));
        }
    }

    return boneData;
}

3. Extracting an Adjacency List or Flat Parent Map

For certain tasks like animation retargeting or constraint solving, a flat dictionary mapping each bone to its parent is more practical than a deeply nested tree.

function extractBoneParentMap(skeleton) {
    const boneMap = {};

    skeleton.bones.forEach((bone) => {
        boneMap[bone.name] = {
            index: skeleton.bones.indexOf(bone),
            parent: bone.parent && bone.parent.isBone ? bone.parent.name : null,
            children: bone.children.filter((c) => c.isBone).map((c) => c.name)
        };
    });

    return boneMap;
}

Key Considerations for GLTF Rigs

  • Multiple Roots: Some complex rigs feature multiple root bones (e.g., separate weapon roots or floating props). In this case, iterate through skinnedMesh.skeleton.bones, filter for bones where !bone.parent || !bone.parent.isBone, and build trees for each discovered root.
  • Transform Normalization: The local transforms (position, quaternion, scale) reflect the bind pose if extracted prior to playback, or the current frame pose if extracted while an AnimationAction is actively updating.
