Three.js Sprite Sheet Animation Using Texture Offset

This guide demonstrates how to create a 2D sprite sheet animation in Three.js by manipulating the offset and repeat properties of a Texture. You will learn how to divide a single texture grid into individual frames, configure the proper texture wrapping parameters, and cycle through the frames inside the render loop based on elapsed time.

1. Configure Texture Repeat and Wrapping

A sprite sheet consists of multiple animation frames arranged in a grid of rows and columns. To isolate a single frame, tell Three.js to scale the UV coordinates by setting texture.repeat.

Divide 1 by the number of horizontal columns and vertical rows:

import * as THREE from 'three';

const textureLoader = new THREE.TextureLoader();
const spriteSheet = textureLoader.load('path/to/spritesheet.png');

const totalCols = 4;
const totalRows = 4;
const totalFrames = 16;

// Display only one cell at a time
spriteSheet.repeat.set(1 / totalCols, 1 / totalRows);

// Ensure the texture wraps properly when offsets exceed 1
spriteSheet.wrapS = THREE.RepeatWrapping;
spriteSheet.wrapT = THREE.RepeatWrapping;

2. Create the Plane or Sprite

Apply the configured texture to a material and mesh. A THREE.Mesh with a PlaneGeometry or a THREE.Sprite works well for this:

const material = new THREE.MeshBasicMaterial({
  map: spriteSheet,
  transparent: true,
  side: THREE.DoubleSide
});

const geometry = new THREE.PlaneGeometry(1, 1);
const spriteMesh = new THREE.Mesh(geometry, material);
scene.add(spriteMesh);

3. Calculate Frame Offsets in the Render Loop

In WebGL, UV coordinates begin at the bottom-left (0, 0), whereas standard sprite sheets typically start at the top-left. When moving through rows, you must invert the vertical calculation so the animation reads from top to bottom.

Use a clock to update the texture.offset vector at a fixed frame rate:

const clock = new THREE.Clock();
const fps = 12; // Speed of animation
let currentFrame = 0;
let elapsedTime = 0;

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  elapsedTime += delta;

  if (elapsedTime > 1 / fps) {
    currentFrame = (currentFrame + 1) % totalFrames;
    elapsedTime = 0;

    // Calculate current column and row
    const col = currentFrame % totalCols;
    const row = Math.floor(currentFrame / totalCols);

    // Update the offset vector
    spriteSheet.offset.x = col / totalCols;
    spriteSheet.offset.y = 1 - (row + 1) / totalRows;
  }

  renderer.render(scene, camera);
}

animate();

Key Considerations

  • Texture Filtering: If you are using pixel art, set spriteSheet.magFilter = THREE.NearestFilter to prevent frames from blurring.
  • Aspect Ratio: Match the PlaneGeometry width and height ratio to the dimensions of an individual sprite frame to avoid unwanted stretching.
