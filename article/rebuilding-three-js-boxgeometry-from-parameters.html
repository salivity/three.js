Rebuilding Three.js BoxGeometry from Parameters

This article explains how to extract configuration data from the BoxGeometry.parameters object in Three.js to mathematically construct a customized BufferGeometry from scratch. By reading the original width, height, depth, and segment dimensions, you can reconstruct the six faces of a cuboid algorithmically, allowing you to inject custom vertex transformations, non-linear deformations, or procedural modifications into the raw geometry buffers.

Accessing BoxGeometry.parameters

When you instantiate a THREE.BoxGeometry, Three.js attaches a parameters property containing the values used during construction:

const originalBox = new THREE.BoxGeometry(2, 4, 6, 2, 2, 2);

const {
    width,
    height,
    depth,
    widthSegments,
    heightSegments,
    depthSegments
} = originalBox.parameters;

This metadata provides the foundational measurements required to recompute the grid divisions, vertex coordinates, normals, and UV layouts across all six cube faces (+X, -X, +Y, -Y, +Z, and -Z).

Mathematical Reconstruction Logic

A standard box consists of six distinct planar faces. To build the geometry mathematically:

  1. Axes Definition: Each face is aligned to two spatial axes (representing local X and Y for the plane) while a third axis remains constant (representing the face depth offset).
  2. Vertex Generation: For each face, iterate through the row and column segments to calculate vertex coordinates.
  3. Vertex Modification: Apply mathematical transformations directly to the calculated coordinates (such as tapering, rounding, or displacement).
  4. Topology Generation: Construct the index array using two triangles per grid cell.

Complete Implementation

The following function extracts parameters from an existing box, modifies the vertices during generation (in this example, applying a height-based taper), and returns a completely new THREE.BufferGeometry:

import * as THREE from 'three';

function rebuildModifiedBox(sourceBox) {
    const p = sourceBox.parameters;

    const indices = [];
    const positions = [];
    const normals = [];
    const uvs = [];

    let numberOfVertices = 0;

    // Helper to generate each of the 6 faces
    function buildPlane(uAxis, vAxis, wAxis, uDir, vDir, width, height, depth, gridX, gridY) {
        const segmentWidth = width / gridX;
        const segmentHeight = height / gridY;
        const widthHalf = width / 2;
        const heightHalf = height / 2;
        const depthHalf = depth / 2;

        const gridX1 = gridX + 1;
        const gridY1 = gridY + 1;

        let vertexCounter = 0;

        // Generate vertices, normals, and UVs
        for (let iy = 0; iy < gridY1; iy++) {
            const y = iy * segmentHeight - heightHalf;

            for (let ix = 0; ix < gridX1; ix++) {
                const x = ix * segmentWidth - widthHalf;

                const vector = new THREE.Vector3();
                vector[uAxis] = x * uDir;
                vector[vAxis] = y * vDir;
                vector[wAxis] = depthHalf;

                // --- Mathematical Modification Zone ---
                // Example: Taper vertices inward along the Y axis
                if (vector.y > 0) {
                    const taperFactor = 1 - (vector.y / (p.height / 2)) * 0.3;
                    vector.x *= taperFactor;
                    vector.z *= taperFactor;
                }

                positions.push(vector.x, vector.y, vector.z);

                // Normal vector
                const normal = new THREE.Vector3();
                normal[wAxis] = depthHalf > 0 ? 1 : -1;
                normals.push(normal.x, normal.y, normal.z);

                // UV coordinates
                uvs.push(ix / gridX);
                uvs.push(1 - (iy / gridY));

                vertexCounter += 1;
            }
        }

        // Generate face indices
        for (let iy = 0; iy < gridY; iy++) {
            for (let ix = 0; ix < gridX; ix++) {
                const a = numberOfVertices + ix + gridX1 * iy;
                const b = numberOfVertices + ix + gridX1 * (iy + 1);
                const c = numberOfVertices + (ix + 1) + gridX1 * (iy + 1);
                const d = numberOfVertices + (ix + 1) + gridX1 * iy;

                indices.push(a, b, d);
                indices.push(b, c, d);
            }
        }

        numberOfVertices += vertexCounter;
    }

    // Build each side using orientation mappings:
    // +Z, -Z, +X, -X, +Y, -Y
    buildPlane('x', 'y', 'z',  1, -1, p.width, p.height,  p.depth, p.widthSegments, p.heightSegments);
    buildPlane('x', 'y', 'z', -1, -1, p.width, p.height, -p.depth, p.widthSegments, p.heightSegments);
    buildPlane('z', 'y', 'x',  1, -1, p.depth, p.height,  p.width, p.depthSegments, p.heightSegments);
    buildPlane('z', 'y', 'x', -1, -1, p.depth, p.height, -p.width, p.depthSegments, p.heightSegments);
    buildPlane('x', 'z', 'y',  1,  1, p.width, p.depth,   p.height, p.widthSegments, p.depthSegments);
    buildPlane('x', 'z', 'y',  1, -1, p.width, p.depth,  -p.height, p.widthSegments, p.depthSegments);

    // Assemble new BufferGeometry
    const newGeometry = new THREE.BufferGeometry();
    newGeometry.setIndex(indices);
    newGeometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3));
    newGeometry.setAttribute('normal', new THREE.Float32BufferAttribute(normals, 3));
    newGeometry.setAttribute('uv', new THREE.Float32BufferAttribute(uvs, 2));

    // Recompute normals if vertex modifications altered surface angles
    newGeometry.computeVertexNormals();

    return newGeometry;
}

Usage

Pass any parameterized box instance into the function to produce the regenerated mesh:

const baseBox = new THREE.BoxGeometry(10, 20, 10, 4, 8, 4);
const modifiedGeometry = rebuildModifiedBox(baseBox);

const material = new THREE.MeshStandardMaterial({ color: 0x2194ce, wireframe: true });
const mesh = new THREE.Mesh(modifiedGeometry, material);
scene.add(mesh);

This workflow ensures complete programmatic control over vertex density, layout, and spatial mapping while relying on initial measurements stored within BoxGeometry.parameters.
