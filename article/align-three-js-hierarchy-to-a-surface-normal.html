Align Three.js Hierarchy to a Surface Normal

Aligning a complex hierarchy of 3D objects to match a target surface normal while maintaining their internal relative transforms is a common challenge in Three.js. This article explains how to accomplish this by encapsulating your hierarchy within a single root object and using quaternions to calculate and apply the rotation from a reference vector to the target normal, ensuring child transforms remain completely intact.

Step 1: Encapsulate the Hierarchy Under a Root Group

To preserve the local spatial relationships between child objects, never rotate child objects individually. Instead, group the entire hierarchy inside a single parent THREE.Group or THREE.Object3D. When you rotate this root object, all nested children will retain their local positions, rotations, and scales relative to one another.

const rootGroup = new THREE.Group();

// Add your complex hierarchy
rootGroup.add(chassisMesh);
rootGroup.add(turretMesh); // turret preserves its relative offset and orientation
scene.add(rootGroup);

Step 2: Define Reference and Target Vectors

Determine the default directional axis of your root group (the axis you want to align with the surface normal, typically the Y-axis (0, 1, 0) or Z-axis (0, 0, 1)) and normalize both this reference vector and the target surface normal.

const defaultNormal = new THREE.Vector3(0, 1, 0); // Assuming the group's "up" is Y
const targetNormal = new THREE.Vector3(x, y, z).normalize(); // The surface normal

Step 3: Compute the Alignment Quaternion

Use THREE.Quaternion.setFromUnitVectors to compute the rotation that rotates the default directional vector to match the surface normal.

const alignmentQuaternion = new THREE.Quaternion();
alignmentQuaternion.setFromUnitVectors(defaultNormal, targetNormal);

Step 4: Apply the Rotation to the Root Object

Apply this quaternion directly to the root group. If you need to position the object at the contact point on the surface, set its position at the same time:

// Set position to the surface contact point
rootGroup.position.copy(surfaceHitPoint);

// Apply the alignment rotation
rootGroup.quaternion.copy(alignmentQuaternion);

Handling Additional Yaw/Heading Rotation

Directly using setFromUnitVectors aligns the group's up-vector with the surface normal, but it may unpredictably spin the object around that normal axis. If your object needs to maintain a specific heading (such as facing forward along a path), compose the rotation:

function alignHierarchy(rootObject, targetNormal, forwardDirection) {
  // 1. Align the Y-axis with the surface normal
  const upAxis = new THREE.Vector3(0, 1, 0);
  const normalQuat = new THREE.Quaternion().setFromUnitVectors(upAxis, targetNormal);

  // 2. Project the desired forward direction onto the surface plane
  const projectedForward = forwardDirection.clone()
    .projectOnPlane(targetNormal)
    .normalize();

  // 3. Create a look-at orientation
  const rotationMatrix = new THREE.Matrix4();
  const sideAxis = new THREE.Vector3().crossVectors(targetNormal, projectedForward).normalize();
  
  rotationMatrix.makeBasis(sideAxis, targetNormal, projectedForward.negate());

  // 4. Apply combined transform to root
  rootObject.quaternion.setFromRotationMatrix(rotationMatrix);
}

By concentrating all alignment transformations strictly on the root container and working with quaternions or basis matrices, the internal coordinate spaces of all child objects stay unchanged.
