Distance Between Ray and Point in Three.js

Calculating the shortest distance between a 3D ray and an arbitrary point in Three.js can be achieved either directly through the built-in THREE.Ray API or manually using vector projection mathematics. This guide covers both the native method for rapid implementation and the step-by-step mathematical breakdown for custom shaders or performance-critical pipelines.

The Built-in Three.js Method

Three.js provides an optimized, native method on the Ray class called .distanceToPoint(). This method automatically handles the projection and edge cases (such as points located behind the ray's origin).

import * as THREE from 'three';

// Define the ray with an origin and a normalized direction
const rayOrigin = new THREE.Vector3(0, 0, 0);
const rayDirection = new THREE.Vector3(0, 1, 0).normalize();
const ray = new THREE.Ray(rayOrigin, rayDirection);

// Define an arbitrary target point
const point = new THREE.Vector3(3, 4, 0);

// Calculate the shortest distance
const distance = ray.distanceToPoint(point);

console.log(distance); // Outputs: 3

If you only need the squared distance to avoid a costly square root operation (e.g., inside an animation loop or sorting routine), use ray.distanceSqToPoint(point).

The Underlying Mathematical Calculation

To compute the shortest Euclidean distance from a point \(\mathbf{P}\) to a ray defined by an origin \(\mathbf{O}\) and a normalized direction vector \(\mathbf{D}\):

  1. Calculate the displacement vector from the ray origin to the point: \[\mathbf{v} = \mathbf{P} - \mathbf{O}\]

  2. Project \(\mathbf{v}\) onto the ray direction using the dot product to find the scalar distance \(t\) along the ray: \[t = \mathbf{v} \cdot \mathbf{D}\]

  3. Clamp the scalar \(t\) to account for the semi-infinite nature of a ray: \[t_{\text{clamped}} = \max(0, t)\]

    • If \(t < 0\), the closest point on the ray is the ray origin itself (\(\mathbf{O}\)).
    • If \(t \ge 0\), the closest point lies along the ray's trajectory.

  4. Compute the closest point (\(\mathbf{C}\)) on the ray: \[\mathbf{C} = \mathbf{O} + (t_{\text{clamped}} \times \mathbf{D})\]

  5. Determine the distance: Calculate the Euclidean distance between point \(\mathbf{P}\) and point \(\mathbf{C}\): \[\text{distance} = \|\mathbf{P} - \mathbf{C}\|\]

Manual Implementation in JavaScript

Here is the exact manual implementation of the vector math using pure Three.js vector functions:

function getShortestDistance(ray, point) {
    const v = new THREE.Vector3().subVectors(point, ray.origin);
    const t = v.dot(ray.direction);

    // If point is behind the ray origin, clamp projection to origin
    const clampedT = Math.max(0, t);

    // Find the closest point along the ray
    const closestPoint = new THREE.Vector3()
        .copy(ray.direction)
        .multiplyScalar(clampedT)
        .add(ray.origin);

    // Return the distance from target point to closest point
    return point.distanceTo(closestPoint);
}
