Three.js Linecap and Linejoin for Architectural Drawings

Stylizing architectural line drawings in Three.js requires fine control over line terminations and corners to achieve aesthetics ranging from sharp technical blueprints to soft, hand-drawn schematics. The linecap and linejoin properties in Three.js LineBasicMaterial govern the shape of segment endpoints and the vertices where two segments meet. This guide explains how to configure these two properties, the visual styles they produce, and the practical implementation details needed to render clean architectural line work.

Understanding Linecap and Linejoin

In 2D vector drafting and 3D wireframe presentation, line styling depends on two visual parameters defined in LineBasicMaterial:

  • linecap: Defines the appearance of line ends. It accepts three string values:
    • 'butt': The stroke ends immediately at the coordinate with a flat edge perpendicular to the line direction.
    • 'round': Adds a semicircle at the end of the line with a diameter equal to the line width.
    • 'square': Extends the line past the endpoint by half the line width, ending in a squared-off edge.
  • linejoin: Controls the shape of the corner formed where two line segments meet. It accepts three string values:
    • 'miter': Extends the outer edges until they meet at a sharp point, ideal for crisp structural corners.
    • 'round': Rounds off the corner with a smooth arc.
    • 'bevel': Cuts off the sharp corner with a straight diagonal segment.

Configuring LineBasicMaterial

To apply these properties, pass them directly into the constructor of LineBasicMaterial or assign them dynamically to an existing material instance:

import * as THREE from 'three';

// Create material for sharp, technical drafting lines
const technicalLineMaterial = new THREE.LineBasicMaterial({
  color: 0x1a1a1a,
  linewidth: 2,
  linecap: 'square',
  linejoin: 'miter'
});

// Create geometry and line object
const points = [
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(10, 0, 0),
  new THREE.Vector3(10, 10, 0)
];

const geometry = new THREE.BufferGeometry().setFromPoints(points);
const architecturalOutline = new THREE.Line(geometry, technicalLineMaterial);

Architectural Aesthetics and Preset Configurations

Different combinations of linecap and linejoin evoke distinct architectural drawing styles:

1. CAD and Blueprint Style (Crisp & Orthogonal)

For structural plans, elevations, and CAD-style views, sharp corners and predictable boundaries are critical.

  • Settings: linecap: 'butt', linejoin: 'miter'
  • Visual Result: Lines do not spill past coordinate boundaries, and 90-degree wall intersections produce sharp, precise corners.

2. Conceptual Sketch Style (Soft & Organic)

For early-stage design reviews, soft landscape edges, or hand-drafted visuals, hard intersections can feel overly rigid.

  • Settings: linecap: 'round', linejoin: 'round'
  • Visual Result: Intersections flow smoothly into one another, and open-ended lines terminate without harsh geometric cuts, resembling ink or felt-tip pen drawings.

3. Chiseled or Faceted Drafting (Modernist/Industrial)

For schematic diagrams emphasizing faceted surfaces or beveled structural members.

  • Settings: linecap: 'square', linejoin: 'bevel'
  • Visual Result: Corners appear chamfered, reducing visual weight at dense junction nodes while maintaining geometric rigidity.

WebGL Limitations and Fat Lines Alternative

Standard WebGL implementations generally enforce a maximum line width of 1 pixel regardless of the linewidth property, meaning the visual impact of linecap and linejoin within standard LineBasicMaterial may be invisible in hardware-accelerated rasterization.

When your architectural visualization requires lines wider than 1 pixel with fully rendered caps and joins in 3D space, use the "fat lines" module provided by Three.js addons (Line2, LineGeometry, and LineMaterial):

import { Line2 } from 'three/addons/lines/Line2.js';
import { LineMaterial } from 'three/addons/lines/LineMaterial.js';
import { LineGeometry } from 'three/addons/lines/LineGeometry.js';

const fatLineGeometry = new LineGeometry();
fatLineGeometry.setPositions([0, 0, 0, 10, 0, 0, 10, 10, 0]);

const fatLineMaterial = new LineMaterial({
  color: 0x0055ff,
  linewidth: 5, // Width in screen pixels
  worldUnits: false,
  alphaToCoverage: true
});

const stylizedLine = new Line2(fatLineGeometry, fatLineMaterial);
stylizedLine.computeLineDistances();

For applications exporting Three.js scenes to 2D vector formats via SVGRenderer, the linecap and linejoin settings on standard LineBasicMaterial translate directly to SVG stroke attributes (stroke-linecap and stroke-linejoin), preserving line styling during export.
