Toggle Visibility with BooleanKeyframeTrack in Three.js

This article explains how to toggle an object's visibility property during an animation in Three.js using THREE.BooleanKeyframeTrack. You will learn how to define keyframe times, specify boolean states, package the track into an AnimationClip, and play the animation using an AnimationMixer.

Creating the BooleanKeyframeTrack

To toggle the visibility of a Three.js object, create an instance of THREE.BooleanKeyframeTrack. The constructor requires three arguments: the track name path targeting the .visible property, an array of keyframe timestamps (in seconds), and an array of boolean values corresponding to those timestamps.

import * as THREE from 'three';

// 1. Create your 3D object
const geometry = new THREE.BoxGeometry();
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const mesh = new THREE.Mesh(geometry, material);
mesh.name = 'AnimatedBox';
scene.add(mesh);

// 2. Define keyframe times (in seconds) and visibility states
const times = [0, 1, 2, 3, 4];
const values = [true, false, true, false, true];

// 3. Create the BooleanKeyframeTrack
// Targeting '.visible' toggles the mesh.visible property
const visibilityTrack = new THREE.BooleanKeyframeTrack(
  '.visible', 
  times, 
  values
);

Binding to an AnimationClip and AnimationMixer

Once the track is created, package it inside a THREE.AnimationClip and control it through an AnimationMixer.

// 4. Create an AnimationClip
const duration = 4; // Total duration in seconds
const clip = new THREE.AnimationClip('VisibilityToggleClip', duration, [visibilityTrack]);

// 5. Set up the AnimationMixer and run the action
const mixer = new THREE.AnimationMixer(mesh);
const action = mixer.clipAction(clip);
action.setLoop(THREE.LoopRepeat);
action.play();

Updating the Animation in the Render Loop

An AnimationMixer requires continuous updates in your render loop using delta time so that keyframes are processed at the correct intervals.

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  mixer.update(delta);

  renderer.render(scene, camera);
}

animate();

Important Considerations

  • Interpolation: Unlike numeric tracks (such as VectorKeyframeTrack), BooleanKeyframeTrack does not interpolate between values. The state switches instantaneously at the specified timestamp.
  • Targeting Hierarchy: If you attach the mixer to a parent object or a whole scene instead of the mesh directly, prepend the track path with the target mesh's name (e.g., 'AnimatedBox.visible').
