What Is Three.js ShadowMaterial and How It Works

In Three.js, ShadowMaterial is a specialized material designed to receive and render shadows while keeping the underlying surface entirely invisible. This article explains what ShadowMaterial is, how it utilizes alpha channels and shadow maps to capture shadows over transparent planes, and how to implement it effectively in real-world scenarios such as Augmented Reality (AR) or 3D compositing over HTML backgrounds.

What Is ShadowMaterial?

ShadowMaterial is an internal shader material provided by Three.js specifically engineered for shadow reception. Unlike standard materials such as MeshStandardMaterial or MeshBasicMaterial, ShadowMaterial does not calculate standard diffuse, specular, or ambient reflections. Instead, it renders an invisible surface that darkens only in regions occluded from light sources.

How It Catches Shadows Invisibly

The mechanism behind ShadowMaterial relies on the Three.js shadow mapping pipeline combined with custom fragment shader logic:

  1. Automatic Transparency: ShadowMaterial has its transparent property set to true by default. Under normal lighting conditions, the fragment shader outputs an alpha (opacity) value of 0.0. This makes the geometry fully see-through.
  2. Shadow Map Evaluation: When a light source with castShadow = true illuminates the scene, Three.js generates a depth texture (shadow map) from the light's point of view. During the rendering pass of the mesh using ShadowMaterial, the fragment shader compares the fragment's depth relative to the light against the values stored in the shadow map.
  3. Selective Opacity Modulation: When the shader detects that a fragment is in shadow (i.e., occluded by another object), it increases the alpha value of that fragment. Instead of drawing a solid surface, it applies a shadow color (typically black) multiplied by the material's opacity property. Unshadowed fragments remain completely transparent.

Because only the shadowed pixels are drawn with partial opacity, the plane itself remains invisible while the cast shadow is seamlessly rendered on top of whatever lies behind the canvas or mesh.

Basic Implementation

To use ShadowMaterial, assign it to a mesh configured to receive shadows:

// 1. Create a shadow-receiving plane
const geometry = new THREE.PlaneGeometry(10, 10);
const material = new THREE.ShadowMaterial({
    opacity: 0.4 // Controls the darkness of the shadow
});

const groundPlane = new THREE.Mesh(geometry, material);
groundPlane.rotation.x = -Math.PI / 2;
groundPlane.receiveShadow = true; // Crucial for receiving shadows
scene.add(groundPlane);

// 2. Configure a shadow-casting light
const directionalLight = new THREE.DirectionalLight(0xffffff, 1);
directionalLight.position.set(5, 10, 5);
directionalLight.castShadow = true;
scene.add(directionalLight);

// 3. Enable shadows in the renderer
renderer.shadowMap.enabled = true;

Common Use Cases

  • Augmented Reality (AR): When placing 3D models onto real-world flat surfaces detected by AR frameworks (such as WebXR), ShadowMaterial can be placed over a detected floor plane. This creates grounded, realistic shadows beneath virtual objects without obscuring the camera feed.
  • HTML and CSS Background Integration: If a 3D scene sits over an existing webpage layout, video, or background image, ShadowMaterial enables 3D elements to cast shadows directly onto the 2D background.
  • Complex Scene Compositing: It allows developers to separate the shadow pass from base geometry passes for advanced post-processing or multi-pass rendering.
