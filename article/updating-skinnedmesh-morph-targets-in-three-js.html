Updating SkinnedMesh Morph Targets in Three.js

When manipulating 3D character facial expressions or shape keys in Three.js, modifying the morph target weights of a SkinnedMesh directly via JavaScript sometimes fails to visually update or causes frustum culling issues. This article explains how to properly modify morph target weights, force Three.js to register these changes, and ensure the bounding volumes update accurately to prevent rendering artifacts.

Accessing and Modifying Morph Target Influences

Every SkinnedMesh with morph targets maintains two key properties: morphTargetInfluences (an array of numerical weights, typically between 0.0 and 1.0) and morphTargetDictionary (a map matching string names to array indices).

To alter a morph target, locate its index using the dictionary and adjust the influence value:

const index = skinnedMesh.morphTargetDictionary['smile'];
if (index !== undefined) {
    skinnedMesh.morphTargetInfluences[index] = 1.0;
}

Forcing the WebGL Pipeline to Acknowledge Updates

In standard render loops (requestAnimationFrame), altering morphTargetInfluences sends updated uniform arrays or texture data to the GPU automatically on the subsequent renderer.render(scene, camera) call. If the mesh is not animating or rendering continuously, you must explicitly trigger a render pass:

renderer.render(scene, camera);

If morph target influences are updated outside continuous rendering loops or the geometry structure was altered after initialization, execute updateMorphTargets() on the mesh:

skinnedMesh.updateMorphTargets();

This method rebuilds the internal mapping between the geometry's morph attributes and the mesh's influence array.

Updating Bounding Volumes to Prevent Frustum Culling

A frequent issue when altering morph targets significantly is the mesh disappearing from certain camera angles. Three.js performs frustum culling using the static bounding sphere of the base geometry, which does not expand automatically when morph targets or skeletal bones deform the vertices.

To force Three.js to recompute the bounding volumes, call:

skinnedMesh.geometry.computeBoundingBox();
skinnedMesh.geometry.computeBoundingSphere();

If morph targets dramatically expand the mesh beyond its base shape, disable frustum culling entirely on the SkinnedMesh to ensure it is never culled prematurely:

skinnedMesh.frustumCulled = false;

Material Configuration and Recompilation

If you toggle morph targets dynamically on a mesh that was not initially configured with them, the underlying shader must be recompiled. Set the needsUpdate flag on the material:

skinnedMesh.material.needsUpdate = true;

Ensure the material explicitly supports morph targets. For built-in materials (MeshStandardMaterial, MeshPhysicalMaterial, etc.), Three.js handles morph targets automatically, provided the geometry contains morphAttributes at the time of material assignment.
