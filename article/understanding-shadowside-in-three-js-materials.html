Understanding shadowSide in Three.js Materials

In Three.js, the shadowSide property determines which side of a geometry's faces casts shadows in the scene. This article explains the purpose of shadowSide, outlines its available settings, and demonstrates how configuring it correctly helps eliminate rendering artifacts like shadow acne and improves shadow accuracy for single-sided or complex meshes.

What is shadowSide?

The shadowSide property is a configuration option available on THREE.Material. When Three.js generates shadow maps, it renders the scene from the perspective of the light source. The shadowSide property specifies which face of a polygon—front, back, or both—is rendered during this shadow map generation pass.

By default, shadowSide is set to null. When null, Three.js falls back to whatever value is defined in the material's side property (which defaults to THREE.FrontSide).

Available Values

You can explicitly set shadowSide using standard Three.js side constants:

  • THREE.FrontSide: Only the front-facing polygons cast shadows.
  • THREE.BackSide: Only the back-facing (interior) polygons cast shadows.
  • THREE.DoubleSide: Both front and back faces cast shadows.

Common Use Cases

1. Preventing Shadow Acne

A frequent issue in real-time shadow mapping is "shadow acne"—an artifact where surfaces incorrectly cast shadows onto themselves due to depth-map precision limits. A common technique to resolve this on watertight, closed meshes is setting shadowSide to THREE.BackSide. Because the back faces inside the mesh cast the shadow, the exterior front faces will not shadow themselves, producing clean outer surfaces without altering normal rendering.

2. Shadows for Flat and Single-Sided Objects

Planes, leaves, foliage, and cloth often use single-sided geometry to save performance. If the light source hits the back of a single-sided plane configured with THREE.FrontSide, it will not cast a shadow. Setting shadowSide: THREE.DoubleSide ensures the object casts a shadow regardless of the light angle, even if the visual material side remains THREE.FrontSide.

3. Decoupling Appearance from Shadow Behavior

shadowSide allows you to decouple how a mesh is rendered to the camera from how it interacts with the light. You can keep material.side = THREE.FrontSide for optimal back-face culling during the main render pass while assigning material.shadowSide = THREE.DoubleSide or THREE.BackSide strictly for shadow map calculations.

Code Example

import * as THREE from 'three';

// Create a material that renders front faces to the camera
// but uses back faces for shadow casting to prevent shadow acne
const material = new THREE.MeshStandardMaterial({
    color: 0x2194ce,
    side: THREE.FrontSide,
    shadowSide: THREE.BackSide
});

const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, material);
mesh.castShadow = true;
mesh.receiveShadow = true;

Using shadowSide provides fine-grained control over shadow map rendering, allowing you to fix visual artifacts and handle complex lighting scenarios without modifying the underlying geometry.
