Scattering Light in Dense Fluids Using Three.js

Simulating the way light scatters and absorbs inside dense fluids requires physically based volume rendering techniques. In Three.js, this effect is achieved using MeshPhysicalMaterial by combining transmission with subsurface volume properties: thickness, attenuationColor, and attenuationDistance. This guide details how to configure these parameters to model materials like milk, murky water, amber, or honey accurately.

Enabling Transmission

Before thickness and attenuation properties take effect, you must enable volumetric transmission. Set the transmission property to a high value (typically between 0.9 and 1.0), which permits light to pass through the surface of the mesh into its interior volume.

const fluidMaterial = new THREE.MeshPhysicalMaterial({
  transmission: 1.0,
  roughness: 0.1,
  ior: 1.333 // Typical index of refraction for water-based liquids
});

Understanding the Volume Properties

To simulate dense fluids, Three.js implements the Beer-Lambert law, which dictates that light loses intensity and changes color as it travels through an absorbing medium:

  • thickness: Defines the perceived depth of the volume along the surface normal. It sets an upper bound on how far light travels inside the object before exiting. A higher thickness means light spends more time traversing the medium.
  • attenuationColor: The color that white light shifts toward as it penetrates the volume. For dense liquids, this represents the internal absorption tint (for example, deep amber for honey or cloudy off-white for diluted milk).
  • attenuationDistance: The average distance light must travel inside the object before it completely transitions to the attenuationColor. A smaller distance produces a denser, more opaque liquid because light is absorbed rapidly.

Configuring Dense Fluids

Dense liquids require a short attenuationDistance relative to the mesh dimensions and the material's thickness. When attenuationDistance is significantly smaller than thickness, light cannot penetrate deeply, resulting in a dense, murky appearance.

Here is an example setup for a dense amber fluid:

const denseFluidMaterial = new THREE.MeshPhysicalMaterial({
  color: 0xffffff,              // Keep base color white to let attenuation define tint
  transmission: 1.0,            // Allow light into the volume
  opacity: 1.0,
  transparent: false,           // Set transparent to false for optimal transmission rendering
  roughness: 0.15,              // Slight surface roughness to soften reflections
  ior: 1.45,                    // Dense fluid refractive index (e.g., oils, syrups)
  thickness: 2.0,               // Maximum depth of the fluid volume
  attenuationColor: new THREE.Color(0xd97b26), // Amber tint
  attenuationDistance: 0.4      // Short distance creates high density and rapid absorption
});

Tuning Tips for Realism

  1. Scale Dependence: attenuationDistance and thickness are expressed in world units. If your mesh has a radius of 10 units, an attenuationDistance of 0.5 will make it look completely opaque, while the same value on a mesh with a radius of 0.2 units will look clear. Match these values to your scene's real-world scale.
  2. Roughness for Turbidity: Pure liquids have a low roughness (0.0 to 0.05). For colloids or suspensions with suspended particles like milk, increase roughness to 0.2 or 0.3 to diffuse light across the surface.
  3. Environment Maps: Transmission materials rely heavily on refracted light from the surrounding environment. Ensure an HDRI environment map is applied to scene.environment to provide realistic light paths through the dense volume.
