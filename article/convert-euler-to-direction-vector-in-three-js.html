Convert Euler to Direction Vector in Three.js

Converting a standard Euler rotation into a directional Vector3 in Three.js is an essential technique for handling camera orientations, raycasting, and projectile physics. Because Three.js does not provide a native Vector3.setFromEuler() method, this conversion is achieved by creating a Quaternion, populating it from your Euler angles using the setFromEuler method, and then applying that rotation to a forward-facing reference vector.

Understanding the Forward Direction

In Three.js, the default forward direction for cameras and objects in local space is generally along the negative Z-axis (0, 0, -1). If you are working with custom meshes, your defined forward direction might alternatively be the positive Z-axis (0, 0, 1) or positive X-axis (1, 0, 0). Determine your reference vector before applying rotations.

Step-by-Step Implementation

To perform the conversion:

  1. Define or retrieve your THREE.Euler instance.
  2. Initialize an empty THREE.Quaternion.
  3. Call quaternion.setFromEuler(euler) to transfer the rotation.
  4. Create a forward THREE.Vector3 and transform it using vector.applyQuaternion(quaternion).

Code Example

import * as THREE from 'three';

// 1. Define the rotation using Euler angles (pitch, yaw, roll in radians)
const euler = new THREE.Euler(
  THREE.MathUtils.degToRad(45), // X-axis (Pitch)
  THREE.MathUtils.degToRad(90), // Y-axis (Yaw)
  0,                            // Z-axis (Roll)
  'YXZ'                         // Rotation order
);

// 2. Instantiate the Quaternion and apply setFromEuler
const quaternion = new THREE.Quaternion();
quaternion.setFromEuler(euler);

// 3. Define the base forward direction (commonly 0, 0, -1 in Three.js)
const direction = new THREE.Vector3(0, 0, -1);

// 4. Apply the rotated quaternion to the directional vector
direction.applyQuaternion(quaternion);

// The 'direction' vector is now a normalized Vector3 pointing where the Euler angles rotate
console.log(direction);

Alternative Direct Method

If you do not explicitly need an intermediate Quaternion object, Three.js provides a shorthand method called Vector3.applyEuler():

const direction = new THREE.Vector3(0, 0, -1).applyEuler(euler);

Internally, applyEuler() executes the exact same process: it initializes an internal quaternion, calls quaternion.setFromEuler(euler), and applies the quaternion to the vector. Using setFromEuler explicitly via a dedicated Quaternion is beneficial when reusing rotation calculations across multiple objects or performing smooth slerp interpolations.
