Three.js Box Wireframe Without Diagonal Lines

Rendering wireframes in Three.js often results in unwanted diagonal lines across flat faces because 3D engines process geometry as triangles. To achieve a clean, outline-style wireframe overlay specifically along the outer boundary edges of a BoxGeometry without triangular diagonals, you must use THREE.EdgesGeometry combined with THREE.LineSegments. This article demonstrates how to construct and overlay this clean wireframe over a standard mesh.

Why Standard Wireframes Show Diagonals

Setting { wireframe: true } on a material tells Three.js to render every triangle edge in the geometry. Because each rectangular face of a BoxGeometry consists of two triangles, the shared hypotenuse is rendered as a diagonal line. Similarly, THREE.WireframeGeometry outlines every polygon edge regardless of face angles.

The Solution: Using THREE.EdgesGeometry

THREE.EdgesGeometry automatically inspects adjacent faces and only generates line segments for edges where the angle between face normals exceeds a defined threshold (default is 1 degree). For flat coplanar triangles—like the two halves of a cube face—the angle is 0 degrees, so the internal diagonal edge is omitted.

Implementation

Here is the complete code to create a solid box with a clean edge overlay:

import * as THREE from 'three';

// 1. Create the base BoxGeometry
const geometry = new THREE.BoxGeometry(2, 2, 2);

// 2. Create the solid mesh
const material = new THREE.MeshStandardMaterial({ color: 0x156289 });
const cube = new THREE.Mesh(geometry, material);

// 3. Generate edge-only geometry (filters out coplanar diagonal edges)
const edges = new THREE.EdgesGeometry(geometry);

// 4. Create line segments using LineBasicMaterial
const lineMaterial = new THREE.LineBasicMaterial({ color: 0xffffff, linewidth: 2 });
const wireframeOverlay = new THREE.LineSegments(edges, lineMaterial);

// 5. Attach the wireframe directly to the cube
cube.add(wireframeOverlay);

// 6. Add the cube to your scene
scene.add(cube);

Key Considerations

  • Hierarchy: Adding wireframeOverlay as a child of cube (cube.add(wireframeOverlay)) ensures that any rotation, scaling, or translation applied to the primary cube is automatically reflected in the wireframe.
  • Line Thickness: WebGL implementations typically do not support a linewidth property greater than 1 due to hardware limitations across platforms.
  • Depth Conflicts (Z-Fighting): If the wireframe lines flicker against the solid mesh, set polygonOffset: true, polygonOffsetFactor: 1, and polygonOffsetUnits: 1 on the solid mesh's material to push the mesh rendering slightly behind the wireframe lines.
