Three.js BufferGeometry Index for Vertex Snapping

This article explains how to extract the index array from a Three.js BufferGeometry and use it alongside vertex position attributes to implement custom vertex snapping logic. You will learn how to verify indexed geometry, read vertex data efficiently using index pointers, compute distances to find the nearest vertex, and apply snapping transformations directly to your 3D models or interactive cursors.

Accessing the Index Array in BufferGeometry

In Three.js, a BufferGeometry can be either indexed or non-indexed. An indexed geometry shares vertex data across multiple faces using a dedicated index buffer, reducing redundant data.

To access this index array, check the .index property of your geometry:

const indexAttribute = geometry.index;

if (indexAttribute !== null) {
    const indices = indexAttribute.array; // TypedArray (e.g., Uint16Array or Uint32Array)
    console.log(`Total indices: ${indices.length}`);
} else {
    console.warn("Geometry is not indexed.");
}

If your geometry is non-indexed, you can generate an indexed version using the utility function mergeVertices from three/addons/utils/BufferGeometryUtils.js.

Extracting Vertex Positions via the Index

The index array contains integer pointers that correspond to vertex components inside the geometry.attributes.position buffer. To evaluate coordinates, loop through the indices and extract positions using THREE.Vector3:

const positionAttribute = geometry.attributes.position;
const indexAttribute = geometry.index;
const vertex = new THREE.Vector3();

// Unique vertex tracking using a Set to avoid redundant checks
const checkedIndices = new Set();

for (let i = 0; i < indexAttribute.count; i++) {
    const vertexIndex = indexAttribute.getX(i);

    if (!checkedIndices.has(vertexIndex)) {
        checkedIndices.add(vertexIndex);
        
        // Extract the (x, y, z) components for this specific index
        vertex.fromBufferAttribute(positionAttribute, vertexIndex);
        
        // Transform to world space if geometry belongs to an Object3D
        vertex.applyMatrix4(mesh.matrixWorld);
    }
}

Implementing Custom Snapping Logic

Vertex snapping commonly involves two scenarios: snapping an external point (like a cursor or another object) to the nearest vertex, or snapping the mesh's existing vertices to a custom coordinate grid.

1. Snapping an External Point to the Closest Vertex

To snap an arbitrary point (such as a raycaster intersection point) to the nearest vertex of an indexed mesh:

function snapToNearestVertex(targetPoint, mesh, threshold = 0.5) {
    const geometry = mesh.geometry;
    const positionAttribute = geometry.attributes.position;
    const indexAttribute = geometry.index;

    if (!indexAttribute) return null;

    // Convert the target point into the mesh's local coordinate space
    const inverseMatrix = mesh.matrixWorld.clone().invert();
    const localTarget = targetPoint.clone().applyMatrix4(inverseMatrix);

    let closestVertex = null;
    let minDistanceSq = threshold * threshold;
    const tempVertex = new THREE.Vector3();
    const visited = new Uint8Array(positionAttribute.count);

    for (let i = 0; i < indexAttribute.count; i++) {
        const vertexIndex = indexAttribute.getX(i);

        // Skip vertices that have already been evaluated
        if (visited[vertexIndex]) continue;
        visited[vertexIndex] = 1;

        tempVertex.fromBufferAttribute(positionAttribute, vertexIndex);
        const distSq = localTarget.distanceToSquared(tempVertex);

        if (distSq < minDistanceSq) {
            minDistanceSq = distSq;
            closestVertex = tempVertex.clone();
        }
    }

    if (closestVertex) {
        // Return snapped position in world space
        return closestVertex.applyMatrix4(mesh.matrixWorld);
    }

    return null; // No vertex found within the threshold
}

2. Snapping Geometry Vertices to a Grid

To quantize the vertices of an indexed geometry to a specified grid size, iterate through unique indices and update the underlying buffer directly:

function snapGeometryToGrid(geometry, gridSize = 1.0) {
    const positionAttribute = geometry.attributes.position;
    const indexAttribute = geometry.index;

    if (!indexAttribute) return;

    const visited = new Uint8Array(positionAttribute.count);
    const vertex = new THREE.Vector3();

    for (let i = 0; i < indexAttribute.count; i++) {
        const vertexIndex = indexAttribute.getX(i);

        if (visited[vertexIndex]) continue;
        visited[vertexIndex] = 1;

        vertex.fromBufferAttribute(positionAttribute, vertexIndex);

        // Snap values to grid increments
        vertex.x = Math.round(vertex.x / gridSize) * gridSize;
        vertex.y = Math.round(vertex.y / gridSize) * gridSize;
        vertex.z = Math.round(vertex.z / gridSize) * gridSize;

        positionAttribute.setXYZ(vertexIndex, vertex.x, vertex.y, vertex.z);
    }

    // Flag position buffer for GPU re-upload and recompute normals/bounds
    positionAttribute.needsUpdate = true;
    geometry.computeVertexNormals();
    geometry.computeBoundingBox();
    geometry.computeBoundingSphere();
}

Best Practices

  • Avoid Redundant Computations: Because multiple faces share indices, always track visited vertex indices using a lookup array or Set when iterating through geometry.index.
  • Transform Coordinates Accurately: Always compare points in the same coordinate space—either transform your reference point to local space using the object's inverse world matrix, or transform vertices to world space.
  • Buffer Updates: Whenever modifying the positions referenced by the index array, set positionAttribute.needsUpdate = true and call geometry.computeVertexNormals() to maintain correct lighting and shading.
