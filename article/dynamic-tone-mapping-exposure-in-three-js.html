Dynamic Tone Mapping Exposure in Three.js

Dynamically adjusting renderer.toneMappingExposure in Three.js simulates human eye adaptation—commonly known as auto-exposure—by evaluating the scene's current luminance and compensating accordingly. This article details how to downsample the rendered view to read its average brightness using a low-resolution WebGLRenderTarget, calculate the perceived luminance, and smoothly interpolate the renderer's exposure value frame by frame.

The Mechanism

To determine the average brightness of the view without causing performance bottlenecks, you should avoid reading every pixel of the full-resolution canvas. Instead, render or copy the scene into a tiny offscreen render target (such as 1x1 or 4x4 pixels). This relies on GPU hardware linear filtering to aggregate the overall scene luminance into a small set of pixels.

Once read into CPU memory via readRenderTargetPixels, convert the RGB values into relative luminance, determine the difference from your target middle-gray brightness, and adjust renderer.toneMappingExposure smoothly using linear interpolation (lerp).

Step-by-Step Implementation

1. Setup the Downsample Render Target

Create a small render target and a buffer to store the downsampled pixel data:

import * as THREE from 'three';

// 1x1 target aggregates the entire screen if mipmapping/bilinear downscaling is applied, 
// or a small 2x2 target can be averaged manually.
const sampleWidth = 2;
const sampleHeight = 2;

const luminanceTarget = new THREE.WebGLRenderTarget(sampleWidth, sampleHeight, {
  minFilter: THREE.LinearFilter,
  magFilter: THREE.LinearFilter,
  format: THREE.RGBAFormat,
  type: THREE.UnsignedByteType,
});

const pixelBuffer = new Uint8Array(sampleWidth * sampleHeight * 4);

2. Downsample and Read Average Luminance

Render the camera view into this smaller target, read back the pixel values, and calculate the average perceived luminance using standard photometric weights (\(0.2126R + 0.7152G + 0.0722B\)):

function getAverageLuminance(renderer, scene, camera) {
  // Render current scene directly to the tiny target
  const currentTarget = renderer.getRenderTarget();
  renderer.setRenderTarget(luminanceTarget);
  renderer.render(scene, camera);
  
  // Read pixel data from the render target
  renderer.readRenderTargetPixels(
    luminanceTarget,
    0,
    0,
    sampleWidth,
    sampleHeight,
    pixelBuffer
  );

  // Restore the original render target (screen or post-processing chain)
  renderer.setRenderTarget(currentTarget);

  let totalLuminance = 0;
  const numPixels = sampleWidth * sampleHeight;

  for (let i = 0; i < pixelBuffer.length; i += 4) {
    const r = pixelBuffer[i] / 255;
    const g = pixelBuffer[i + 1] / 255;
    const b = pixelBuffer[i + 2] / 255;

    // Standard relative luminance formula
    const lum = 0.2126 * r + 0.7152 * g + 0.0722 * b;
    totalLuminance += lum;
  }

  return totalLuminance / numPixels;
}

3. Dynamically Adjust the Exposure

Incorporate the luminance measurement into your animation loop. Calculate the target exposure using an optimal midpoint luminance (typically around 0.18 for middle gray) and interpolate the change over time:

// Target exposure settings
const targetMiddleGray = 0.18;
const minExposure = 0.1;
const maxExposure = 4.0;
const adaptationSpeed = 0.05; // Lower values create slower, more realistic eye adaptation

function updateAutoExposure(renderer, scene, camera, delta) {
  const avgLuminance = getAverageLuminance(renderer, scene, camera);

  // Prevent divide-by-zero in pitch black scenes
  const safeLuminance = Math.max(avgLuminance, 0.001);

  // Calculate ideal target exposure
  let targetExposure = targetMiddleGray / safeLuminance;

  // Clamp exposure to predefined bounds
  targetExposure = THREE.MathUtils.clamp(targetExposure, minExposure, maxExposure);

  // Smoothly interpolate current exposure towards the target exposure
  const lerpFactor = 1 - Math.exp(-adaptationSpeed * delta * 60);
  renderer.toneMappingExposure = THREE.MathUtils.lerp(
    renderer.toneMappingExposure,
    targetExposure,
    lerpFactor
  );
}

4. The Render Loop

Execute the auto-exposure update in your main requestAnimationFrame callback:

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();

  // Update exposure dynamically
  updateAutoExposure(renderer, scene, camera, delta);

  // Render main scene to canvas
  renderer.render(scene, camera);
}

animate();

Performance Considerations

  • CPU-GPU Synchronization: Calling readRenderTargetPixels forces a GPU pipeline stall because the CPU must wait for the GPU to finish rendering to return the pixel data. To minimize overhead, keep the sample target extremely small (\(1\times1\) or \(2\times2\)) or execute the measurement once every few frames rather than on every tick.
  • Tone Mapping Selection: Dynamic exposure works in conjunction with tone mapping operators. Ensure a tone mapping method like THREE.ACESFilmicToneMapping or THREE.AgXToneMapping is enabled via renderer.toneMapping to prevent high exposure values from blowing out highlight details abruptly.
