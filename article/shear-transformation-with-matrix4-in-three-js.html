Shear Transformation with Matrix4 in Three.js

This article explains how to mathematically skew a 3D object in Three.js by constructing a custom affine shear matrix using THREE.Matrix4. You will learn the underlying linear algebra of 3D shearing, how Three.js maps matrix elements, and the exact code required to apply the transformation directly to meshes or geometries.

Mathematical Definition of a Shear Matrix

In 3D affine space, a shear (or skew) transformation shifts one coordinate relative to another along a specified axis. The general 4x4 shear matrix is represented as:

|  1   Syx  Szx   0 |
| Sxy   1   Szy   0 |
| Sxz  Syz   1    0 |
|  0    0    0    1 |

Where:

  • Syx shears \(x\) based on \(y\).
  • Szx shears \(x\) based on \(z\).
  • Sxy shears \(y\) based on \(x\).
  • Szy shears \(y\) based on \(z\).
  • Sxz shears \(z\) based on \(x\).
  • Syz shears \(z\) based on \(y\).

Constructing the Matrix in Three.js

Three.js provides the THREE.Matrix4 class to represent 4x4 transformation matrices. The .set() method accepts 16 arguments in row-major order:

import * as THREE from 'three';

// Define shear factors (e.g., skew x along the y-axis by 0.5)
const Syx = 0.5; 
const Szx = 0.0;
const Sxy = 0.0;
const Szy = 0.0;
const Sxz = 0.0;
const Syz = 0.0;

const shearMatrix = new THREE.Matrix4();

shearMatrix.set(
     1,  Syx,  Szx,    0,
   Sxy,    1,  Szy,    0,
   Sxz,  Syz,    1,    0,
     0,    0,    0,    1
);

Applying the Shear Matrix to an Object

Three.js automatically recalculates an object's local matrix every frame from its position, rotation, and scale properties if matrixAutoUpdate is enabled. Because standard Euler rotations and scale vectors cannot represent shear, you must apply the transformation using one of two approaches:

Approach 1: Apply Directly to the Geometry (Recommended)

Baking the shear directly into the vertex attributes transforms the geometry once on the CPU, allowing standard position, rotation, and scaling to function normally without interfering with the shear:

const geometry = new THREE.BoxGeometry(1, 1, 1);

// Apply shear directly to vertex coordinates
geometry.applyMatrix4(shearMatrix);

// Recalculate normals to ensure correct lighting
geometry.computeVertexNormals();

const material = new THREE.MeshStandardMaterial({ color: 0x00ff00 });
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Approach 2: Apply to the Mesh Matrix

If you need to shear the entire object hierarchy dynamically without mutating the underlying buffer geometry, disable matrixAutoUpdate on the mesh and apply the matrix manually:

const mesh = new THREE.Mesh(geometry, material);

// Prevent Three.js from overwriting manual matrix updates
mesh.matrixAutoUpdate = false;

// Multiply the mesh's current transform by the shear matrix
mesh.matrix.multiply(shearMatrix);

// Flag the matrix for update in the renderer
mesh.matrixWorldNeedsUpdate = true;
scene.add(mesh);
