How to Create Metaballs in Three.js with Marching Cubes

This article explains how to implement dynamic, merging metaballs in Three.js using the Marching Cubes algorithm. You will learn how to import and configure the MarchingCubes addon, generate dynamic scalar fields by calculating metaball positions, animate their paths to make them fuse organically, and apply appropriate materials and lighting for a polished visual result.

1. Import Dependencies

Three.js includes an optimized Marching Cubes implementation in its examples repository. You need to import the core Three.js library alongside the MarchingCubes addon.

import * as THREE from 'three';
import { MarchingCubes } from 'three/addons/objects/MarchingCubes.js';

2. Set Up the Scene, Camera, and Renderer

Establish the fundamental components of a Three.js project:

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(
  45,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);
camera.position.set(0, 0, 30);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(window.devicePixelRatio);
document.body.appendChild(renderer.domElement);

// Add lighting to illuminate the metaball surfaces
const ambientLight = new THREE.AmbientLight(0xffffff, 0.4);
scene.add(ambientLight);

const directionalLight = new THREE.DirectionalLight(0xffffff, 1.2);
directionalLight.position.set(10, 20, 15);
scene.add(directionalLight);

3. Instantiate the MarchingCubes Object

The MarchingCubes class creates a volumetric grid (voxel space) and evaluates the isosurface according to the scalar field generated by the metaballs.

const resolution = 48; // Grid resolution; higher values improve detail but reduce performance
const material = new THREE.MeshStandardMaterial({
  color: 0x2194ce,
  roughness: 0.1,
  metalness: 0.2,
});

const maxPolyCount = 100000;
const enableUvs = false;
const enableColors = false;

const effect = new MarchingCubes(
  resolution,
  material,
  enableUvs,
  enableColors,
  maxPolyCount
);

// Scale the bounding volume in the scene
effect.scale.set(10, 10, 10);
effect.position.set(0, 0, 0);
scene.add(effect);

4. Define and Update Metaball Positions

To create the merging liquid effect, clear the field on each frame, calculate new coordinates for each ball within normalized coordinate space (0.0 to 1.0), and inject them using addBall().

const numBalls = 5;

function updateCubes(time) {
  // Clear the scalar field
  effect.reset();

  // Define metaball parameters: addBall(x, y, z, strength, subtract)
  const strength = 1.2 / ((Math.sqrt(numBalls) - 1) / 4 + 1);
  const subtract = 12;

  for (let i = 0; i < numBalls; i++) {
    // Generate organic motion paths using trigonometric functions
    const ballX = Math.sin(i + 1.26 * time * (1.03 + 0.5 * Math.cos(0.21 * i))) * 0.27 + 0.5;
    const ballY = Math.abs(Math.cos(i + 1.12 * time * Math.cos(1.22 + 0.1424 * i))) * 0.77;
    const ballZ = Math.cos(i + 1.32 * time * 0.1 * Math.sin(0.92 + 0.53 * i)) * 0.27 + 0.5;

    effect.addBall(ballX, ballY, ballZ, strength, subtract);
  }

  // Update the mesh geometry
  effect.update();
}

Parameter Breakdown

  • x, y, z: Normalized positions between 0 and 1 relative to the local bounding box of the MarchingCubes mesh.
  • strength: Determines the sphere radius and influence area of the metaball.
  • subtract: Influences how quickly the scalar value drops off; helps tighten or loosen the merging threshold.

5. Implement the Animation Loop

Run the animation loop to evaluate the field at each frame and render the scene.

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  const time = clock.getElapsedTime() * 0.5;

  updateCubes(time);

  renderer.render(scene, camera);
}

animate();

6. Performance and Visual Tuning

  • Resolution vs. Performance: The first argument in MarchingCubes(resolution, ...) dictates the voxel density. A resolution between 28 and 64 provides a good balance between polygon smoothness and frame rates.
  • Material Selection: Dynamic isosurfaces benefit strongly from materials using environmental reflections, such as MeshPhysicalMaterial with transmission or MeshStandardMaterial with an environment map, which accentuates the curving organic geometry.
