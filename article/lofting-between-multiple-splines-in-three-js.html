Lofting Between Multiple Splines in Three.js

Lofting multiple splines to create a smooth 3D surface in Three.js requires sampling a series of cross-sectional curves and bridging them using a custom BufferGeometry. Because Three.js does not provide a native lofting class, developers must generate a structured vertex grid from parametric splines, calculate corresponding texture coordinates, and assemble the index buffer for triangular faces. This guide provides a direct, step-by-step implementation for building a procedural lofted surface from an arbitrary sequence of 3D curves.

1. Understanding the Lofting Logic

Lofting functions by taking an ordered array of curves (cross-sections) positioned in 3D space and connecting adjacent curves with a polygonal mesh skin. To achieve this in Three.js:

  1. Define two or more THREE.Curve instances (commonly THREE.CatmullRomCurve3).
  2. Sample each curve at equal intervals to create a uniform \((U \times V)\) grid of 3D points.
  3. Push these coordinates into a flat Float32Array of vertex positions.
  4. Calculate UV coordinates for each vertex to ensure proper texture mapping.
  5. Generate triangular faces by connecting the grid points using an index array.
  6. Compute vertex normals for correct lighting and shading.

2. Implementation: Creating a Custom Loft Geometry

The following function accepts an array of curves, along with sampling resolutions along the curve paths (\(U\)) and across the lofted sequence (\(V\)), returning a complete THREE.BufferGeometry.

import * as THREE from 'three';

function createLoftGeometry(curves, segmentsU = 50, segmentsV = null) {
  // If intermediate curve interpolation is not specified, 
  // segmentsV defaults to the number of provided curves minus one.
  const numCurves = curves.length;
  if (numCurves < 2) {
    throw new Error('Lofting requires at least two curves.');
  }

  const vCount = segmentsV || (numCurves - 1);
  const uCount = segmentsU;

  const positions = [];
  const uvs = [];
  const indices = [];

  // 1. Sample points across curves
  for (let i = 0; i <= vCount; i++) {
    const v = i / vCount;
    
    // Map parameter v to the input curves
    const curveIndex = v * (numCurves - 1);
    const lowerIndex = Math.floor(curveIndex);
    const upperIndex = Math.min(lowerIndex + 1, numCurves - 1);
    const lerpFactor = curveIndex - lowerIndex;

    const lowerCurvePoints = curves[lowerIndex].getPoints(uCount);
    const upperCurvePoints = curves[upperIndex].getPoints(uCount);

    for (let j = 0; j <= uCount; j++) {
      const u = j / uCount;

      // Linear interpolation between consecutive curves
      const ptLower = lowerCurvePoints[j];
      const ptUpper = upperCurvePoints[j];

      const x = THREE.MathUtils.lerp(ptLower.x, ptUpper.x, lerpFactor);
      const y = THREE.MathUtils.lerp(ptLower.y, ptUpper.y, lerpFactor);
      const z = THREE.MathUtils.lerp(ptLower.z, ptUpper.z, lerpFactor);

      positions.push(x, y, z);
      uvs.push(u, v);
    }
  }

  // 2. Generate quad face indices
  for (let i = 0; i < vCount; i++) {
    for (let j = 0; j < uCount; j++) {
      const a = i * (uCount + 1) + j;
      const b = (i + 1) * (uCount + 1) + j;
      const c = (i + 1) * (uCount + 1) + (j + 1);
      const d = i * (uCount + 1) + (j + 1);

      // Two triangles per grid cell (counter-clockwise winding)
      indices.push(a, b, d);
      indices.push(b, c, d);
    }
  }

  // 3. Build Three.js BufferGeometry
  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3));
  geometry.setAttribute('uv', new THREE.Float32BufferAttribute(uvs, 2));
  geometry.setIndex(indices);

  // Compute smooth surface normals
  geometry.computeVertexNormals();

  return geometry;
}

3. Setting Up the Splines and Rendering the Mesh

To generate the surface, define cross-sectional profiles at different points in space, pass them to the generator, and assign a material.

// Define three profile curves
const curve1 = new THREE.CatmullRomCurve3([
  new THREE.Vector3(-10, 0, 0),
  new THREE.Vector3(0, 5, 0),
  new THREE.Vector3(10, 0, 0)
]);

const curve2 = new THREE.CatmullRomCurve3([
  new THREE.Vector3(-12, 5, 10),
  new THREE.Vector3(0, 15, 10),
  new THREE.Vector3(12, 5, 10)
]);

const curve3 = new THREE.CatmullRomCurve3([
  new THREE.Vector3(-8, 2, 20),
  new THREE.Vector3(0, 4, 20),
  new THREE.Vector3(8, 2, 20)
]);

// Generate the lofted surface geometry
const loftGeometry = createLoftGeometry([curve1, curve2, curve3], 64, 32);

// Create material with double-sided rendering to view both interior and exterior
const material = new THREE.MeshStandardMaterial({
  color: 0x2194ce,
  side: THREE.DoubleSide,
  roughness: 0.4,
  metalness: 0.1
});

// Create mesh and add to scene
const loftMesh = new THREE.Mesh(loftGeometry, material);
scene.add(loftMesh);

4. Technical Considerations

  • Vertex Matching: Ensure that all input curves are oriented in the same direction (e.g., left-to-right). If one curve starts on the right while another starts on the left, the surface will twist on itself.
  • Interpolation Curves: The implementation uses linear interpolation between adjacent profiles. For non-linear transitions across the \(V\) direction, you can extract points across a secondary set of spine curves oriented perpendicularly to the cross-sections.
  • Closed Surfaces: To make a closed tubular shape, set the first and last points of each curve to match, or connect the first and last curves in the index generation step.
