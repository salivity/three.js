How to Use AnimationAction.warp in Three.js

In Three.js, dynamically altering an animation's speed can cause jarring visual jumps if the playback rate changes instantaneously. The AnimationAction.warp method solves this by smoothly interpolating the animation's timeScale from an initial value to a target value over a specified duration. This guide demonstrates how the method works, its syntax, and how to implement it effectively for seamless slow-motion, acceleration, or playback reversal effects.

Method Signature and Parameters

The warp method belongs to the THREE.AnimationAction class and uses the following syntax:

action.warp(startTimeScale, endTimeScale, duration);
  • startTimeScale (Number): The initial playback speed of the animation action. A value of 1.0 is normal speed, 0.5 is half-speed, and negative values play the animation in reverse.
  • endTimeScale (Number): The final target playback speed to be reached once the transition ends.
  • duration (Number): The duration of the transition in seconds.

Step-by-Step Implementation

To use warp, obtain an AnimationAction from your AnimationMixer and invoke the method during your application lifecycle.

import * as THREE from 'three';

// 1. Initialize the mixer with a 3D model or root object
const mixer = new THREE.AnimationMixer(model);

// 2. Extract an animation clip and create an action
const clip = gltf.animations[0];
const action = mixer.clipAction(clip);

// 3. Start the animation at normal speed
action.setEffectiveTimeScale(1.0);
action.play();

// 4. Smoothly transition to slow motion over 2 seconds
function activateSlowMotion() {
    const currentScale = action.getEffectiveTimeScale();
    const targetScale = 0.2;
    const transitionDuration = 2.0;

    action.warp(currentScale, targetScale, transitionDuration);
}

// 5. Render loop must update the mixer
const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);
    
    const delta = clock.getDelta();
    mixer.update(delta);
    
    renderer.render(scene, camera);
}
animate();

Key Considerations

  • Current TimeScale: Instead of hardcoding startTimeScale, use action.getEffectiveTimeScale() to ensure smooth transitions from whatever speed the animation is currently running.
  • Completion Events: The parent AnimationMixer dispatches a warp event when the transition completes. You can listen for this to trigger subsequent logic: 
    mixer.addEventListener('warp', (event) => {
    if (event.action === action) {
        console.log('Timescale transition completed');
    }
});
  • Stopping or Pausing: Setting endTimeScale to 0 slows the animation to a complete halt, but the action remains active. To pause entirely after stopping, pause the action inside the warp event callback.
