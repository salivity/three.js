Culling Projectiles in Three.js with Sphere.containsPoint

Managing hundreds of active projectiles in a Three.js game can quickly lead to performance bottlenecks if off-screen or out-of-bounds entities are continuously updated and rendered. This guide demonstrates how to establish a central boundary sphere and leverage the built-in THREE.Sphere.containsPoint method to rapidly detect, cull, or recycle incoming projectiles that stray outside your playable area.

Setting Up the Bounding Sphere

Instead of running expensive distance calculations manually using Math.sqrt, Three.js provides the THREE.Sphere class. You can define a boundary around your player, camera, or the center of the world:

import * as THREE from 'three';

// Define the center of your gameplay area and the despawn radius
const arenaCenter = new THREE.Vector3(0, 0, 0);
const arenaRadius = 150;

// Create the boundary sphere
const boundarySphere = new THREE.Sphere(arenaCenter, arenaRadius);

Implementing the Culling Loop

During your main animation loop, iterate through your active projectiles. Use containsPoint against each projectile's current Vector3 position. If the method returns false, the projectile has exited the valid play zone and should be removed or returned to an object pool.

When removing elements from an array during iteration, always traverse the array in reverse to avoid skipping indices after deletion:

const activeProjectiles = []; // Array of projectile meshes or custom objects

function updateProjectiles(delta) {
    for (let i = activeProjectiles.length - 1; i >= 0; i--) {
        const projectile = activeProjectiles[i];

        // Move the projectile forward
        projectile.position.addScaledVector(projectile.velocity, delta);

        // Check if the projectile is outside the sphere boundary
        if (!boundarySphere.containsPoint(projectile.position)) {
            // Remove from the scene to stop rendering
            scene.remove(projectile);

            // Dispose resources if not pooling
            projectile.geometry.dispose();
            projectile.material.dispose();

            // Remove from the active tracking array
            activeProjectiles.splice(i, 1);
        }
    }
}

Moving Boundaries Dynamic with the Player

If your game features a moving player and projectiles need to be culled relative to the player's position, dynamically update the sphere’s center property each frame:

function update(delta) {
    // Keep the culling volume centered on the player
    boundarySphere.center.copy(player.position);

    updateProjectiles(delta);
}

Performance Advantages

The containsPoint method is computationally lightweight. Internally, Three.js calculates the squared Euclidean distance between the target point and the sphere's center (center.distanceToSquared(point)), then checks if it is less than or equal to radius * radius. By avoiding square root operations, you can evaluate hundreds of projectiles per frame with negligible impact on your frame rate.
