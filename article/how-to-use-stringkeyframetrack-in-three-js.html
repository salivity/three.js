How to Use StringKeyframeTrack in Three.js

Three.js provides StringKeyframeTrack to handle non-numeric, discrete data within its animation system. Unlike tracks that interpolate positions or colors smoothly, StringKeyframeTrack swaps string values instantly at designated timestamps using discrete interpolation. This guide covers how to instantiate a StringKeyframeTrack, integrate it with an AnimationClip and AnimationMixer, and apply it to manipulate text strings or swap material states across a timeline.

Understanding StringKeyframeTrack

A StringKeyframeTrack is constructed using three arguments: a target property path, an array of keyframe times in seconds, and an array of corresponding string values.

new THREE.StringKeyframeTrack(trackName, times, values);

Because string values cannot blend mathematically, this track enforces discrete stepping: a value remains active until the timeline reaches the next keyframe timestamp.

Animating Text Changes

To animate text content over time, define a target property on your mesh or a custom data holder that your rendering loop can read to rebuild or update your displayed text.

import * as THREE from 'three';

// 1. Create a container object holding the text property
const textHolder = new THREE.Object3D();
textHolder.name = "TextNode";
textHolder.userData.currentText = "Intro";
scene.add(textHolder);

// 2. Define keyframe times (seconds) and matching string values
const times = [0, 2, 4, 6];
const values = ["Intro", "Stage 1", "Stage 2", "Conclusion"];

// 3. Create the StringKeyframeTrack targeting the property path
const textTrack = new THREE.StringKeyframeTrack(
  'TextNode.userData[currentText]',
  times,
  values
);

// 4. Wrap the track in an AnimationClip
const clip = new THREE.AnimationClip('TextSequence', 6, [textTrack]);

// 5. Initialize the AnimationMixer
const mixer = new THREE.AnimationMixer(textHolder);
const action = mixer.clipAction(clip);
action.play();

Inside your animation loop, monitor textHolder.userData.currentText. Whenever the value changes during playback, trigger an update to your text rendering mechanism (such as updating a Canvas texture, HTML overlay, or TextGeometry).

let lastText = "";

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  mixer.update(delta);

  if (textHolder.userData.currentText !== lastText) {
    lastText = textHolder.userData.currentText;
    updateTextDisplay(lastText);
  }

  renderer.render(scene, camera);
}

Animating Material Properties

You can use StringKeyframeTrack to alter discrete material properties, such as a material's name or custom uniform identifiers, to trigger texture swaps or shader state transitions.

// Target a specific mesh named "DisplayMesh"
const displayMesh = new THREE.Mesh(geometry, material);
displayMesh.name = "DisplayMesh";
scene.add(displayMesh);

// Define tracks targeting material metadata
const materialTimes = [0, 3, 6];
const materialStates = ["diffuse_state", "damaged_state", "destroyed_state"];

const materialTrack = new THREE.StringKeyframeTrack(
  'DisplayMesh.material.name',
  materialTimes,
  materialStates
);

const materialClip = new THREE.AnimationClip('MaterialChange', 6, [materialTrack]);
const materialMixer = new THREE.AnimationMixer(displayMesh);

materialMixer.clipAction(materialClip).play();

In your update loop or via change detection, evaluate displayMesh.material.name to execute relevant asset swaps, such as changing texture maps when the state switches.

Execution and Playback

For all keyframe-driven property animations:

  1. Ensure the root object passed to THREE.AnimationMixer contains the child hierarchy specified in your track name paths.
  2. Advance playback by invoking mixer.update(clock.getDelta()) within your requestAnimationFrame loop.
  3. Configure timeline looping through action.setLoop(THREE.LoopRepeat) or action.setLoop(THREE.LoopOnce).
