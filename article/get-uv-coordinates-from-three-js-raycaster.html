Get UV Coordinates from Three.js Raycaster

Extracting UV coordinates from a mouse click in Three.js allows developers to implement features like 3D painting, interactive canvas textures, decals, and in-game interface interactions directly on 3D surfaces. When performing raycasting against a mesh, Three.js automatically calculates and populates the interpolated UV coordinates of the intersection point if the underlying geometry supports them. This guide explains how to capture user input, perform a raycast, and extract the exact uv coordinate vector from the intersection data.

1. Normalize Mouse Coordinates

Three.js Raycaster expects normalized device coordinates (NDC), where both x and y range from -1 to +1. Convert standard DOM mouse or pointer event coordinates into NDC:

const mouse = new THREE.Vector2();

function onPointerDown(event) {
    mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
    mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
}

2. Perform the Raycast

Initialize a THREE.Raycaster instance. Update its ray using your camera and the normalized mouse position, then intersect the target mesh:

const raycaster = new THREE.Raycaster();

function getIntersectionUV(event, camera, targetMesh) {
    mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
    mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

    raycaster.setFromCamera(mouse, camera);

    const intersects = raycaster.intersectObject(targetMesh);

    if (intersects.length > 0) {
        const intersection = intersects[0];
        
        // The uv property is an instance of THREE.Vector2
        if (intersection.uv) {
            return intersection.uv;
        }
    }

    return null;
}

3. Accessing and Using the UV Values

The intersection.uv property is a THREE.Vector2 where x corresponds to the horizontal texture coordinate (\(U\)) and y corresponds to the vertical texture coordinate (\(V\)). Both values generally range from 0.0 to 1.0.

const uv = getIntersectionUV(event, camera, myMesh);

if (uv) {
    console.log(`U coordinate: ${uv.x}`);
    console.log(`V coordinate: ${uv.y}`);
}

Converting UVs to Texture Pixel Coordinates

To translate UV coordinates to a specific pixel location on a dynamic canvas texture:

const textureWidth = 1024;
const textureHeight = 1024;

if (uv) {
    const pixelX = Math.floor(uv.x * textureWidth);
    // Invert the Y-axis if your texture coordinate space runs top-to-bottom
    const pixelY = Math.floor((1 - uv.y) * textureHeight);

    console.log(`Pixel: ${pixelX}, ${pixelY}`);
}

Key Requirements

  • Geometry UV Attribute: The target mesh's BufferGeometry must have a defined uv attribute (geometry.attributes.uv). Default primitives such as THREE.BoxGeometry, THREE.PlaneGeometry, and standard imported models (GLTF/OBJ) include this by default.
  • Skinned and Morphing Meshes: Raycasting against SkinnedMesh instances calculates intersections against the original, un-skinned bind pose by default. Standard raycaster UV extraction on dynamic skinned meshes will reflect the bind pose rather than the visually animated surface without specialized GPU-to-CPU readbacks or bone-space transformations.
