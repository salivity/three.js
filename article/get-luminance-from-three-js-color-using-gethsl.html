Get Luminance from Three.js Color Using getHSL

In Three.js, obtaining the normalized luminance of a Color instance is directly handled by the getHSL() method. This function converts the internal RGB color representation into the HSL (Hue, Saturation, Lightness) color space and writes the values into a provided target object. This guide demonstrates how to invoke getHSL() properly, retrieve the normalized lightness value (l), and understand its range.

Using getHSL to Extract Luminance

The getHSL() method requires a target object with h, s, and l properties to store the calculated components. Reusing an existing object prevents unnecessary memory allocations and garbage collection overhead in render loops.

Here is the standard implementation:

import * as THREE from 'three';

// 1. Instantiate the color
const color = new THREE.Color('#3498db');

// 2. Prepare a target object to hold the HSL values
const hslTarget = { h: 0, s: 0, l: 0 };

// 3. Populate the target object with HSL data
color.getHSL(hslTarget);

// 4. Access the normalized luminance (lightness)
const normalizedLuminance = hslTarget.l;

console.log(`Luminance: ${normalizedLuminance}`);

Understanding the Output

  • hslTarget.l (Lightness/Luminance): Represents the normalized luminance value on a scale from 0.0 to 1.0. A value of 0.0 represents pure black, 0.5 represents full color intensity, and 1.0 represents pure white.
  • hslTarget.h (Hue): The color type mapped from 0.0 to 1.0 (representing 0° to 360°).
  • hslTarget.s (Saturation): The intensity or purity of the color from 0.0 (grayscale) to 1.0 (fully saturated).

Note on HSL Lightness vs. Perceived Luminance

The l property obtained through getHSL() represents mathematical lightness within cylindrical HSL color geometry. If your application specifically requires perceived photometric luminance (accounting for human eye sensitivity to green light over blue light), calculate relative luminance from linear RGB components instead:

// Perceived relative luminance (Rec. 709 standard)
const perceivedLuminance = 0.2126 * color.r + 0.7152 * color.g + 0.0722 * color.b;

For standard HSL manipulations, transitions, and brightness checks in Three.js, hslTarget.l from color.getHSL() provides the standard normalized value.
