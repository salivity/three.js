Three.js setViewOffset Split Screen Aspect Ratio

This guide details how to strictly lock and enforce an aspect ratio during split-screen rendering in Three.js using the PerspectiveCamera.setViewOffset() method. By decoupling the overall virtual frustum from individual physical rendering viewports, you can create seamless multi-view layouts—such as two-player split-screens or multi-monitor simulations—without stretching, cropping, or introducing aspect ratio distortion.

Understanding setViewOffset

The PerspectiveCamera.setViewOffset() function modifies the camera projection matrix to render an off-axis sub-rectangle of a larger virtual screen:

camera.setViewOffset(fullWidth, fullHeight, x, y, width, height);
  • fullWidth and fullHeight: The total resolution of the master virtual display. The ratio fullWidth / fullHeight dictates the strict aspect ratio of the combined projection.
  • x and y: The top-left offset coordinates of the sub-view within that virtual display.
  • width and height: The dimensions of the active sub-view segment.

When using setViewOffset, Three.js calculates the camera's internal projection matrix based on fullWidth / fullHeight, completely bypassing the default camera.aspect property.

Enforcing the Aspect Ratio

To guarantee that each split viewport maintains a strict aspect ratio (for instance, a combined \(16:9\) canvas split into two side-by-side views, or two independent views each strictly locked to \(16:9\)), you must mathematically derive the virtual bounds before applying viewport offsets.

Example: Horizontal Split-Screen (Two Equal Halves)

In a horizontal split-screen where two viewports sit side-by-side and each viewport must maintain a locked aspect ratio of \(16:9\):

  1. Each individual view requires a target aspect ratio \(A = 16 / 9\).
  2. The combined virtual canvas containing both views side-by-side has an aspect ratio of \(2A = 32 / 9\).
  3. Calculate the largest master dimensions (fullWidth, fullHeight) that fit inside the actual window dimensions (window.innerWidth, window.innerHeight) without distorting the \(32:9\) ratio.
const targetAspectPerView = 16 / 9;
const totalAspect = targetAspectPerView * 2; // Side-by-side split

function updateSplitScreen(renderer, cameraLeft, cameraRight) {
    const windowWidth = window.innerWidth;
    const windowHeight = window.innerHeight;
    const windowAspect = windowWidth / windowHeight;

    let fullWidth, fullHeight;

    // Pillarbox or letterbox the total viewport to preserve the strict ratio
    if (windowAspect > totalAspect) {
        fullHeight = windowHeight;
        fullWidth = windowHeight * totalAspect;
    } else {
        fullWidth = windowWidth;
        fullHeight = windowWidth / totalAspect;
    }

    const halfWidth = fullWidth / 2;

    // Left View: offset x = 0, y = 0
    cameraLeft.setViewOffset(fullWidth, fullHeight, 0, 0, halfWidth, fullHeight);
    cameraLeft.updateProjectionMatrix();

    // Right View: offset x = halfWidth, y = 0
    cameraRight.setViewOffset(fullWidth, fullHeight, halfWidth, 0, halfWidth, fullHeight);
    cameraRight.updateProjectionMatrix();
}

Rendering with Viewport and Scissor

setViewOffset alters the projection matrix, but you must also isolate the physical pixels on the canvas using setViewport and setScissor to prevent viewports from overwriting one another.

function render() {
    const windowWidth = window.innerWidth;
    const windowHeight = window.innerHeight;

    // Center the rendering area inside the window (letterboxing/pillarboxing)
    let fullWidth, fullHeight;
    const totalAspect = (16 / 9) * 2;

    if (windowWidth / windowHeight > totalAspect) {
        fullHeight = windowHeight;
        fullWidth = windowHeight * totalAspect;
    } else {
        fullWidth = windowWidth;
        fullHeight = windowWidth / totalAspect;
    }

    const offsetX = (windowWidth - fullWidth) / 2;
    const offsetY = (windowHeight - fullHeight) / 2;
    const halfWidth = fullWidth / 2;

    renderer.setScissorTest(true);

    // --- Render Left View ---
    renderer.setViewport(offsetX, offsetY, halfWidth, fullHeight);
    renderer.setScissor(offsetX, offsetY, halfWidth, fullHeight);
    renderer.render(scene, cameraLeft);

    // --- Render Right View ---
    renderer.setViewport(offsetX + halfWidth, offsetY, halfWidth, fullHeight);
    renderer.setScissor(offsetX + halfWidth, offsetY, halfWidth, fullHeight);
    renderer.render(scene, cameraRight);
}

Key Considerations

  • Projection Updates: Always call camera.updateProjectionMatrix() after executing camera.setViewOffset().
  • Resetting the Offset: If you need to revert a camera back to standard full-screen rendering, call camera.clearViewOffset() and manually assign camera.aspect = window.innerWidth / window.innerHeight.
  • Scissor Test: Always enable renderer.setScissorTest(true). Without scissoring, clear calls and draw operations for the second camera will bleed into or clear the first viewport.
