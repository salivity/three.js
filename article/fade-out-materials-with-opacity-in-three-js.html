Fade Out Materials with Opacity in Three.js

Fading a 3D object out smoothly in Three.js requires setting the material's transparent property to true and animating its opacity property from 1.0 down to 0.0. This guide covers how to properly configure the material flags to avoid common rendering glitches, how to set up an opacity tween using an animation library, and best practices for managing depth testing and visibility once the fade completes.

Configuring the Material

By default, materials in Three.js have transparent: false. When transparency is disabled, changing the opacity property has no visual effect because the renderer discards alpha blending.

To prepare a material for a fade-out transition, initialize it with transparent: true:

const material = new THREE.MeshStandardMaterial({
  color: 0x00ff00,
  transparent: true,
  opacity: 1.0
});
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

If you enable transparency on an already-rendered material dynamically, you must flag it for an update so WebGL can recompile the shader program:

material.transparent = true;
material.needsUpdate = true;

Animating Opacity with a Tween

Once transparent is set to true, you can tween the opacity value between 1.0 (fully visible) and 0.0 (fully transparent) using an animation library like GSAP or Tween.js.

Here is an implementation using GSAP:

gsap.to(material, {
  opacity: 0,
  duration: 1.5,
  ease: "power2.out",
  onComplete: () => {
    mesh.visible = false;
  }
});

Here is an implementation using @tweenjs/tween.js:

new TWEEN.Tween(material)
  .to({ opacity: 0 }, 1500)
  .easing(TWEEN.Easing.Quadratic.Out)
  .onComplete(() => {
    mesh.visible = false;
  })
  .start();

Setting mesh.visible = false upon completion removes the object from the rendering pipeline, saving GPU cycles and preventing invisible objects from blocking raycasting or interacting with depth buffers.

Handling Depth Buffer Artifacts

Fading semi-transparent objects often leads to sorting artifacts, where objects behind the fading mesh disappear or render out of order. This occurs because the depth buffer still writes the mesh's depth even when it is semi-transparent.

To resolve this issue, adjust the depthWrite property:

material.transparent = true;
material.depthWrite = false;

Disabling depthWrite ensures that objects located behind the fading mesh remain visible throughout the transition. If your object only needs to be transparent during the transition, keep depthWrite: true while it is opaque, set depthWrite = false right before the fade starts, and restore it if the object fades back in.
