Premultiplied Alpha in Three.js Fragment Shaders

This guide demonstrates how to manually handle premultiplied alpha blending within a custom RawShaderMaterial in Three.js. By understanding the underlying mathematical equations and the necessary WebGL state configurations, you will learn how to write GLSL fragment code that correctly scales color components by opacity and configure Three.js material blend factors to eliminate dark fringe artifacts along transparent boundaries.

The Premultiplied Alpha Equation

In standard (straight) alpha blending, the color values (\(RGB\)) and opacity (\(A\)) are stored independently. The rendering engine calculates the output pixel on screen using the following equation:

\[\text{Final Color} = (\text{Source Color} \times \text{Source Alpha}) + (\text{Destination Color} \times (1 - \text{Source Alpha}))\]

When using premultiplied alpha, the source RGB values are multiplied by the source alpha inside the fragment shader before the hardware blending stage:

\[\text{RGB}_{\text{premultiplied}} = \text{RGB}_{\text{straight}} \times \text{A}\]

Because the color is already scaled by its alpha, the blending hardware no longer needs to multiply the source color by the source alpha. The hardware blending equation becomes:

\[\text{Final Color} = (\text{RGB}_{\text{premultiplied}} \times 1) + (\text{Destination Color} \times (1 - \text{Source Alpha}))\]

This technique prevents interpolation artifacts (such as dark borders around semi-transparent edges) that occur when texture filtering or color blending blends fully transparent black (0, 0, 0, 0) with non-zero colors.

Fragment Shader Implementation

In a RawShaderMaterial, Three.js does not inject default precision qualifiers, variables, or built-in chunks. You must explicitly declare precision and calculate the premultiplication before writing to gl_FragColor.

precision mediump float;

varying vec2 vUv;
uniform sampler2D uTexture;
uniform float uOpacity;

void main() {
    // 1. Sample straight alpha texture or define base color
    vec4 texColor = texture2D(uTexture, vUv);

    // 2. Compute final straight alpha
    float alpha = texColor.a * uOpacity;

    // 3. Premultiply RGB components by alpha
    vec3 premultipliedRGB = texColor.rgb * alpha;

    // 4. Output the final premultiplied vector
    gl_FragColor = vec4(premultipliedRGB, alpha);
}

If you are computing colors procedurally (e.g., gradients or anti-aliased geometry with fwidth or smoothstep), calculate the final color and alpha, then multiply the RGB channels by the resulting alpha factor:

precision mediump float;

uniform vec3 uColor;
uniform float uAlpha;

void main() {
    // Explicit premultiplication
    gl_FragColor = vec4(uColor * uAlpha, uAlpha);
}

Configuring Three.js Material Blend Modes

For WebGL to correctly display premultiplied output, you must set the blend function factors to match the equation: Source Factor = ONE, Destination Factor = ONE_MINUS_SRC_ALPHA.

You can configure this using THREE.CustomBlending on the RawShaderMaterial:

import * as THREE from 'three';

const material = new THREE.RawShaderMaterial({
    vertexShader: customVertexShader,
    fragmentShader: customFragmentShader,
    uniforms: {
        uTexture: { value: loadedTexture },
        uOpacity: { value: 0.8 }
    },
    transparent: true,
    depthWrite: false,
    
    // Explicit blending factors for premultiplied alpha
    blending: THREE.CustomBlending,
    blendSrc: THREE.OneFactor,
    blendDst: THREE.OneMinusSrcAlphaFactor,
    blendSrcAlpha: THREE.OneFactor,
    blendDstAlpha: THREE.OneMinusSrcAlphaFactor
});

Alternatively, Three.js provides a built-in flag that automatically updates NormalBlending to use OneFactor for the source:

const material = new THREE.RawShaderMaterial({
    vertexShader: customVertexShader,
    fragmentShader: customFragmentShader,
    uniforms: {
        uTexture: { value: loadedTexture },
        uOpacity: { value: 0.8 }
    },
    transparent: true,
    premultipliedAlpha: true
});

When premultipliedAlpha: true is combined with standard blending: THREE.NormalBlending, Three.js sets the source blend factor to gl.ONE and destination blend factor to gl.ONE_MINUS_SRC_ALPHA under the hood.
