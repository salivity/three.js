Clone Standard Material Uniforms Using UniformsUtils

When extending built-in Three.js shaders, developers often need to access and duplicate standard material properties such as lighting, roughness, and map values without altering the global shader defaults. This guide provides a direct, practical walkthrough of how to extract default uniforms from MeshStandardMaterial via THREE.ShaderLib and safely deep-clone them using THREE.UniformsUtils.clone to prevent global state mutation in your custom ShaderMaterial implementations.

Accessing Default Uniforms via ShaderLib

Three.js stores the source GLSL and uniform definitions for its built-in materials inside THREE.ShaderLib. For a standard material, the default uniform structure is stored under THREE.ShaderLib.standard.uniforms.

Directly referencing this object causes unintended side effects because it is a shared global reference. Mutating a property directly on THREE.ShaderLib.standard.uniforms modifies it across every subsequent material that references that library definition.

Duplicating Uniforms with UniformsUtils.clone

To avoid mutating shared definitions, Three.js provides THREE.UniformsUtils.clone(). This method performs a deep copy of uniform objects, cloning nested structures, textures, colors, and vectors correctly.

import * as THREE from 'three';

// 1. Retrieve the base uniforms
const baseStandardUniforms = THREE.ShaderLib.standard.uniforms;

// 2. Clone the uniforms to create an independent instance
const customUniforms = THREE.UniformsUtils.clone(baseStandardUniforms);

Adding Custom Uniforms and Implementation

Once duplicated, you can add custom uniforms directly onto your cloned object or use THREE.UniformsUtils.merge to combine multiple sets.

import * as THREE from 'three';

// Clone default standard uniforms
const uniforms = THREE.UniformsUtils.clone(THREE.ShaderLib.standard.uniforms);

// Add custom uniform properties
uniforms.uTime = { value: 0 };
uniforms.uCustomColor = { value: new THREE.Color(0xff0000) };

// Create the custom ShaderMaterial
const customMaterial = new THREE.ShaderMaterial({
  uniforms: uniforms,
  vertexShader: THREE.ShaderLib.standard.vertexShader,
  fragmentShader: THREE.ShaderLib.standard.fragmentShader,
  lights: true, // Required for standard lighting uniforms to function
  defines: {
    STANDARD: ''
  }
});

When duplicating standard uniforms for use with standard vertex and fragment shaders, ensure lights: true is enabled on the ShaderMaterial. This guarantees that internal Three.js directional, point, and ambient light values are continuously populated into your cloned uniform dictionaries during each render pass.
