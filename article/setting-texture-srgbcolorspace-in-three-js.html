Setting Texture SRGBColorSpace in Three.js

In modern Three.js releases (version r152 and later), color management underwent a major overhaul, replacing the legacy encoding property with colorSpace. This article demonstrates how to explicitly assign SRGBColorSpace to your textures using the modern API, ensuring your materials render with accurate colors and gamma correction without relying on deprecated syntax.

The Modern Syntax

To explicitly set a texture to use the sRGB color space, assign the THREE.SRGBColorSpace constant to the texture's colorSpace property.

Here is how to do it when loading a standard image texture:

import * as THREE from 'three';

// 1. Initialize the TextureLoader
const textureLoader = new THREE.TextureLoader();

// 2. Load the texture
const diffuseTexture = textureLoader.load('path/to/diffuse.jpg', (texture) => {
    // 3. Explicitly assign the color space
    texture.colorSpace = THREE.SRGBColorSpace;
    texture.needsUpdate = true;
});

// 4. Assign the texture to a material
const material = new THREE.MeshStandardMaterial({
    map: diffuseTexture
});

If you prefer named imports to keep your bundle size minimal, you can import SRGBColorSpace directly:

import { TextureLoader, SRGBColorSpace, MeshStandardMaterial } from 'three';

const textureLoader = new TextureLoader();
const texture = textureLoader.load('path/to/diffuse.jpg');
texture.colorSpace = SRGBColorSpace;

Why the Change Was Made

In older versions of Three.js (prior to r152), textures used texture.encoding = THREE.sRGBEncoding. The Three.js team replaced this system to align the library with industry standards (such as WebGL, WebGPU, and glTF standards). The property name changed from encoding to colorSpace, and THREE.sRGBEncoding became THREE.SRGBColorSpace.

When to Use SRGBColorSpace vs. NoColorSpace

Color management depends entirely on the purpose of the texture:

  • Use THREE.SRGBColorSpace for visual/color data: Any texture that contributes directly to the visible color seen by the human eye must be marked as sRGB. This includes map (diffuse/albedo), emissiveMap, and background environment maps.
  • Use THREE.NoColorSpace (Linear) for mathematical data: Textures that store scalar values or vectors rather than colors should remain in linear space (which is THREE.NoColorSpace, the default). This includes normalMap, roughnessMap, metalnessMap, alphaMap, aoMap, and displacementMap. Setting these to SRGBColorSpace will distort lighting calculations and produce incorrect rendering results.
