Fit Vector3 Points to OrthographicCamera in Three.js

This guide explains how to mathematically map an array of arbitrary 3D points (THREE.Vector3) to a THREE.OrthographicCamera so that every point stays within view regardless of camera orientation or canvas dimensions. To achieve this, the points are transformed into the camera’s local view space to calculate an aligned bounding box, adjusted to match the viewport's aspect ratio, and applied directly to the camera's frustum boundaries.

Step 1: Transform Points into Camera View Space

Calculating an axis-aligned bounding box (AABB) in world space is insufficient if the camera is tilted or rotated. Instead, every point must be mapped into the camera's local coordinate space (view space). In Three.js, this is achieved by multiplying each point by the camera's inverse world matrix (camera.matrixWorldInverse).

camera.updateMatrixWorld();

const viewPoints = points.map(p => p.clone().applyMatrix4(camera.matrixWorldInverse));

In view space, the camera sits at the origin \((0, 0, 0)\), the X-axis points right, the Y-axis points up, and the camera looks along the negative Z-axis.

Step 2: Compute View-Space Bounds

Iterate over the transformed points to find the minimum and maximum extents along the \(X\), \(Y\), and \(Z\) axes:

let minX = Infinity, maxX = -Infinity;
let minY = Infinity, maxY = -Infinity;
let minZ = Infinity, maxZ = -Infinity;

for (const p of viewPoints) {
    if (p.x < minX) minX = p.x;
    if (p.x > maxX) maxX = p.x;
    if (p.y < minY) minY = p.y;
    if (p.y > maxY) maxY = p.y;
    if (p.z < minZ) minZ = p.z;
    if (p.z > maxZ) maxZ = p.z;
}

const width = maxX - minX;
const height = maxY - minY;
const centerX = (minX + maxX) / 2;
const centerY = (minY + maxY) / 2;

Step 3: Match the Viewport Aspect Ratio

An orthographic camera's view frustum must match the aspect ratio of the rendering canvas (\(A = \text{viewportWidth} / \text{viewportHeight}\)). If the bounding box aspect ratio does not match the viewport, points on the narrower dimension will be clipped.

Compare the bounding box aspect ratio \((W / H)\) to the viewport aspect ratio (\(A\)):

  • If \(\frac{W}{H} > A\), the bounding box is wider than the viewport. Set the visible width to \(W\) and expand the visible height to \(W / A\).
  • If \(\frac{W}{H} \le A\), the bounding box is taller than the viewport. Set the visible height to \(H\) and expand the visible width to \(H \times A\).

Multiply by a padding multiplier (e.g., 1.1 for a 10% margin) to prevent points on the edge from touching the viewport boundaries:

const boxAspect = width / height;
let halfWidth, halfHeight;

if (boxAspect > viewportAspect) {
    halfWidth = (width / 2) * padding;
    halfHeight = (halfWidth / viewportAspect);
} else {
    halfHeight = (height / 2) * padding;
    halfWidth = (halfHeight * viewportAspect);
}

Step 4: Apply Bounds and Update Camera Matrix

Set the frustum extents relative to the computed center coordinate (centerX, centerY), configure the near and far planes based on the \(Z\) extents, and invoke updateProjectionMatrix():

camera.left = centerX - halfWidth;
camera.right = centerX + halfWidth;
camera.top = centerY + halfHeight;
camera.bottom = centerY - halfHeight;

// In view space, objects in front of the camera have negative Z values
const depthPadding = 10;
camera.near = -maxZ - depthPadding;
camera.far = -minZ + depthPadding;

camera.updateProjectionMatrix();

Complete Implementation Function

import * as THREE from 'three';

function fitPointsToOrthographicCamera(points, camera, viewportAspect, padding = 1.1) {
    if (!points || points.length === 0) return;

    camera.updateMatrixWorld();

    let minX = Infinity, maxX = -Infinity;
    let minY = Infinity, maxY = -Infinity;
    let minZ = Infinity, maxZ = -Infinity;

    const tempVec = new THREE.Vector3();

    for (let i = 0; i < points.length; i++) {
        tempVec.copy(points[i]).applyMatrix4(camera.matrixWorldInverse);

        if (tempVec.x < minX) minX = tempVec.x;
        if (tempVec.x > maxX) maxX = tempVec.x;
        if (tempVec.y < minY) minY = tempVec.y;
        if (tempVec.y > maxY) maxY = tempVec.y;
        if (tempVec.z < minZ) minZ = tempVec.z;
        if (tempVec.z > maxZ) maxZ = tempVec.z;
    }

    const width = maxX - minX || 1;
    const height = maxY - minY || 1;
    const centerX = (minX + maxX) / 2;
    const centerY = (minY + maxY) / 2;

    const boxAspect = width / height;
    let halfWidth, halfHeight;

    if (boxAspect > viewportAspect) {
        halfWidth = (width / 2) * padding;
        halfHeight = halfWidth / viewportAspect;
    } else {
        halfHeight = (height / 2) * padding;
        halfWidth = halfHeight * viewportAspect;
    }

    camera.left = centerX - halfWidth;
    camera.right = centerX + halfWidth;
    camera.top = centerY + halfHeight;
    camera.bottom = centerY - halfHeight;

    const depthPadding = Math.max((maxZ - minZ) * 0.1, 10);
    camera.near = -maxZ - depthPadding;
    camera.far = -minZ + depthPadding;

    camera.updateProjectionMatrix();
}
