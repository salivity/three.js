How to Load MTL Files in Three.js with MTLLoader

Loading Wavefront 3D models into Three.js often requires pairing an .obj geometry file with an .mtl (Material Template Library) file to correctly render colors, shininess, and image textures. This guide explains how to properly import and use MTLLoader alongside OBJLoader to fetch, preload, and apply material files to your 3D assets in a Three.js scene.

1. Import the Required Loaders

Neither MTLLoader nor OBJLoader is included in the core Three.js bundle. You must import them from the Three.js addons directory:

import * as THREE from 'three';
import { MTLLoader } from 'three/addons/loaders/MTLLoader.js';
import { OBJLoader } from 'three/addons/loaders/OBJLoader.js';

2. The Loading Workflow

To properly apply an MTL file to an OBJ model, follow this sequence:

  1. Create an instance of MTLLoader.
  2. Load the .mtl file.
  3. Call materials.preload() on the loaded materials creator object.
  4. Pass the preloaded materials into OBJLoader using objLoader.setMaterials(materials).
  5. Load the .obj file and add the resulting object to the scene.

3. Implementation Example

Here is a complete implementation demonstrating how to load and attach the material library:

// Initialize the loaders
const mtlLoader = new MTLLoader();
const objLoader = new OBJLoader();

// Optional: Define a base path for textures referenced inside the MTL
mtlLoader.setPath('models/');

// Step 1: Load the MTL file
mtlLoader.load(
  'model.mtl',
  (materials) => {
    // Step 2: Preload the materials to make them ready for the OBJ loader
    materials.preload();

    // Step 3: Assign the materials to the OBJLoader
    objLoader.setMaterials(materials);
    objLoader.setPath('models/');

    // Step 4: Load the OBJ file with materials attached
    objLoader.load(
      'model.obj',
      (object) => {
        scene.add(object);
      },
      (xhr) => {
        console.log(`OBJ: ${(xhr.loaded / xhr.total) * 100}% loaded`);
      },
      (error) => {
        console.error('An error occurred loading the OBJ file:', error);
      }
    );
  },
  (xhr) => {
    console.log(`MTL: ${(xhr.loaded / xhr.total) * 100}% loaded`);
  },
  (error) => {
    console.error('An error occurred loading the MTL file:', error);
  }
);

4. Key Considerations for MTL Loading

  • Preloading is Mandatory: Calling materials.preload() prepares internal Three.js materials from the parsed definitions. Skipping this step will result in missing textures or rendering errors.
  • Managing Texture Paths: If your .mtl references external texture files (such as .png or .jpg), the loader attempts to resolve them relative to the MTL file's location. Use mtlLoader.setResourcePath('textures/') if your texture files reside in a different folder than the .mtl file.
  • Material Side Configuration: By default, materials loaded via MTLLoader render on the front side only. If internal surfaces or double-sided planes appear invisible, iterate through materials.materials and set .side = THREE.DoubleSide on the relevant materials before loading the OBJ.
