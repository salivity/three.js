Parse glTF Hierarchies with Three.js SceneUtils

Parsing deeply nested glTF models in Three.js can become challenging when handling compound transformations, multi-level parent-child relationships, and scene graph operations. This guide explains how to import a glTF asset, systematically traverse and parse its node tree, use the SceneUtils utility class to manipulate or reparent nodes without breaking global transformations, and visually represent the underlying hierarchy inside your 3D viewport.

Loading the glTF Asset

To work with glTF node hierarchies, first load the model using GLTFLoader. Ensure both GLTFLoader and SceneUtils are imported from the three/addons/ directory.

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import * as SceneUtils from 'three/addons/utils/SceneUtils.js';

const loader = new GLTFLoader();

loader.load('path/to/model.gltf', (gltf) => {
    const rootNode = gltf.scene;
    scene.add(rootNode);

    parseAndVisualizeHierarchy(rootNode);
});

Parsing the Node Hierarchy

A glTF scene is composed of an Object3D tree containing meshes, groups, bones, and cameras. Use the built-in traverse method on the root node to iterate through all descendants and extract structural details like node names, types, and transform matrices.

function parseHierarchy(root) {
    const nodeTree = [];

    root.traverse((node) => {
        nodeTree.push({
            name: node.name || 'Unnamed_Node',
            type: node.type,
            uuid: node.uuid,
            parent: node.parent ? node.parent.name : null,
            childrenCount: node.children.length
        });
    });

    return nodeTree;
}

Restructuring Nodes with SceneUtils

When parsing complex assemblies, you often need to isolate a sub-tree, pull deeply nested parts out for individual animation, or reparent nodes to different hierarchies without disturbing their global scale, position, or rotation.

SceneUtils.attach() and SceneUtils.detach() allow you to move nodes between different parent spaces dynamically while recalculating local transform matrices relative to the new parent:

// Detaching a deeply nested node to the root scene while preserving its world transform
const targetNode = rootNode.getObjectByName('Engine_Piston');
if (targetNode) {
    SceneUtils.detach(targetNode, targetNode.parent, scene);
}

// Attaching the node to a new parent without causing transform jumps
const newParent = rootNode.getObjectByName('SubAssembly_Carrier');
if (targetNode && newParent) {
    SceneUtils.attach(targetNode, scene, newParent);
}

Visualizing the Node Graph in 3D

To visually debug and inspect the hierarchical connections of the parsed glTF model, attach visible markers and directional connection lines between each parent and its children.

function parseAndVisualizeHierarchy(root) {
    const lineMaterial = new THREE.LineBasicMaterial({ 
        color: 0x00ff88, 
        depthTest: false, 
        transparent: true 
    });

    root.traverse((node) => {
        // Add a localized coordinate frame helper to each node
        const axesHelper = new THREE.AxesHelper(0.2);
        axesHelper.renderOrder = 1;
        node.add(axesHelper);

        // Draw visual links to children to display the structural tree
        node.children.forEach((child) => {
            // Ignore the newly added axes helpers
            if (child instanceof THREE.AxesHelper) return;

            const parentPos = new THREE.Vector3();
            const childPos = new THREE.Vector3();

            node.getWorldPosition(parentPos);
            child.getWorldPosition(childPos);

            const points = [
                node.worldToLocal(parentPos),
                node.worldToLocal(childPos)
            ];

            const geometry = new THREE.BufferGeometry().setFromPoints(points);
            const connectionLine = new THREE.Line(geometry, lineMaterial);
            
            node.add(connectionLine);
        });
    });
}

Summary of Workflow

  1. Load: Import the model using GLTFLoader to generate the default scene graph.
  2. Inspect: Use recursive traversal on the glTF root to map parent-child indices and verify identity names.
  3. Re-index / Transform: Use SceneUtils.attach and SceneUtils.detach to restructure or flatten complex sub-branches without distorting world coordinates.
  4. Debug: Generate AxesHelper and geometry line primitives between parsed parent-child pairs to clearly visualize node chains in 3D space.
