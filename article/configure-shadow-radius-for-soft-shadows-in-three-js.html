Configure shadow.radius for Soft Shadows in Three.js

Simulating soft shadow edges in Three.js improves visual realism by preventing sharp, pixelated shadow borders. This guide explains how to use the shadow.radius property on a DirectionalLight, configure the correct shadow map type on the WebGLRenderer, and adjust shadow camera settings to achieve smooth, blurred shadows across your 3D scene.

1. Enable Soft Shadow Maps on the Renderer

By default, Three.js uses THREE.PCFShadowMap, which produces hard-edged shadows. To allow the shadow.radius property to blur the shadow boundaries, configure your WebGLRenderer to use THREE.PCFSoftShadowMap or THREE.VSMShadowMap.

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // Enables soft shadow filtering

2. Configure the DirectionalLight and shadow.radius

Create a DirectionalLight, enable shadow casting, and assign a value to shadow.radius. The radius property controls the blur radius applied to the shadow map samples.

const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(10, 20, 10);
dirLight.castShadow = true;

// Set shadow blur radius
dirLight.shadow.radius = 3; // Default is 1; higher values increase softness

scene.add(dirLight);

A value between 2 and 5 produces naturally soft edges. Setting the radius too high can cause visual artifacts, such as light leaking or excessive banding, especially if the shadow map resolution is low.

3. Adjust Shadow Map Resolution and Camera Bounds

The effectiveness of shadow.radius depends heavily on the shadow camera's frustum and the texture resolution:

  • shadow.mapSize: Higher resolutions (e.g., 2048x2048) create cleaner gradients, whereas lower resolutions (e.g., 512x512) may appear noisy or blocky when blurred.
  • Shadow Camera Frustum: Because a DirectionalLight uses an orthographic camera (OrthographicCamera) to calculate shadows, fit the camera bounds tightly around your scene to maximize pixel density.
// Shadow map resolution
dirLight.shadow.mapSize.width = 2048;
dirLight.shadow.mapSize.height = 2048;

// Tighten the shadow camera bounds to fit the scene
dirLight.shadow.camera.near = 0.5;
dirLight.shadow.camera.far = 50;
dirLight.shadow.camera.left = -10;
dirLight.shadow.camera.right = 10;
dirLight.shadow.camera.top = 10;
dirLight.shadow.camera.bottom = -10;

// Reduce self-shadowing artifacts
dirLight.shadow.bias = -0.0005;

4. Enable Shadows on Meshes

Ensure that the meshes in your scene are explicitly configured to cast and receive shadows to display the softened edges correctly.

// Geometry that casts the shadow
const object = new THREE.Mesh(geometry, material);
object.castShadow = true;
scene.add(object);

// Surface that receives the shadow
const ground = new THREE.Mesh(planeGeometry, planeMaterial);
ground.receiveShadow = true;
scene.add(ground);
