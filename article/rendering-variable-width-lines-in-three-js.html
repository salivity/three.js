Rendering Variable Width Lines in Three.js

Standard Three.js lines are constrained to a fixed width of one pixel across most platforms due to WebGL limitations. To achieve wide lines, developers rely on Line2 and LineMaterial from the Three.js addons library. While LineMaterial natively supports a single uniform width across the entire mesh, you can render lines with varying thickness by extending LineGeometry with custom instanced vertex attributes and injecting dynamic thickness calculations into LineMaterial via its onBeforeCompile hook.

1. Import Required Modules

To implement fat lines, import the necessary modules from the Three.js examples directory:

import * as THREE from 'three';
import { Line2 } from 'three/addons/lines/Line2.js';
import { LineGeometry } from 'three/addons/lines/LineGeometry.js';
import { LineMaterial } from 'three/addons/lines/LineMaterial.js';

2. Prepare Geometry and Segment Width Data

Line2 operates on segments defined by pairs of points. To create variable thickness, define start and end widths for each individual segment using an InstancedBufferAttribute.

const points = [
  new THREE.Vector3(-10, 0, 0),
  new THREE.Vector3(-5, 5, 0),
  new THREE.Vector3(0, -2, 0),
  new THREE.Vector3(5, 4, 0),
  new THREE.Vector3(10, 0, 0)
];

const positions = [];
for (let i = 0; i < points.length; i++) {
  positions.push(points[i].x, points[i].y, points[i].z);
}

const geometry = new LineGeometry();
geometry.setPositions(positions);

// Define start and end thickness for each segment
const segmentCount = points.length - 1;
const startWidths = new Float32Array(segmentCount);
const endWidths = new Float32Array(segmentCount);

// Example: line widens from 2px up to 20px along its path
for (let i = 0; i < segmentCount; i++) {
  startWidths[i] = 2 + (i / segmentCount) * 18;
  endWidths[i] = 2 + ((i + 1) / segmentCount) * 18;
}

geometry.setAttribute('instanceWidthStart', new THREE.InstancedBufferAttribute(startWidths, 1));
geometry.setAttribute('instanceWidthEnd', new THREE.InstancedBufferAttribute(endWidths, 1));

3. Extend LineMaterial via Shader Injection

By default, LineMaterial calculates extrusion in its vertex shader using a global linewidth uniform. Use onBeforeCompile to declare your attributes and interpolate the width based on whether the current vertex is at the start or end of the segment.

const material = new LineMaterial({
  color: 0x00ffcc,
  worldUnits: false, // Set to true if widths are defined in world coordinates
  resolution: new THREE.Vector2(window.innerWidth, window.innerHeight)
});

material.onBeforeCompile = (shader) => {
  // Inject attributes into vertex shader declaration
  shader.vertexShader = `
    attribute float instanceWidthStart;
    attribute float instanceWidthEnd;
  ` + shader.vertexShader;

  // Replace uniform linewidth with interpolated per-segment width
  shader.vertexShader = shader.vertexShader.replace(
    'float w = linewidth;',
    `
    // position.y in LineSegmentsGeometry corresponds to segment interpolation (0.0 or 1.0)
    float w = mix(instanceWidthStart, instanceWidthEnd, position.y);
    `
  );
};

4. Construct the Line2 Object and Handle Resizing

Create the Line2 mesh by passing the configured geometry and material. Ensure the material's viewport resolution is updated during browser window resize events to maintain correct screen-space calculations.

const line = new Line2(geometry, material);
line.computeLineDistances();
scene.add(line);

window.addEventListener('resize', () => {
  material.resolution.set(window.innerWidth, window.innerHeight);
});

Using this approach, the vertex shader extrudes each segment quad smoothly from its starting width to its ending width without requiring heavy procedural tube geometries.
