How to Use ColorManagement.enabled in Three.js

This article explains how to use the ColorManagement.enabled setting in Three.js to achieve physically correct color blending and lighting. You will learn what color management does, how to explicitly toggle it in your codebase, and how to configure textures and renderer output settings to ensure colors display accurately across your 3D scenes.

What is ColorManagement in Three.js?

In modern Three.js (r152+), THREE.ColorManagement manages color space conversions automatically. Physically accurate rendering requires lighting calculations, material blending, and shaders to operate in a linear color space, while display devices expect an sRGB output. Enabling ColorManagement ensures that Three.js automatically converts color inputs (like hex codes, CSS colors, and sRGB textures) into linear space for processing, and then outputs them back to sRGB for screen presentation.

Toggling ColorManagement.enabled

To toggle color management, modify the THREE.ColorManagement.enabled boolean flag before instantiating materials, textures, or renderers.

Enabling Color Management

import * as THREE from 'three';

// Enable automatic color conversions for physically correct blending
THREE.ColorManagement.enabled = true;

When set to true, Three.js automatically converts colors defined on materials and lights (such as new THREE.Color('#ff0000')) from sRGB into linear space internally.

Disabling Color Management

import * as THREE from 'three';

// Disable color management (legacy behavior)
THREE.ColorManagement.enabled = false;

Setting this to false reverts Three.js to legacy rendering behavior where color values are treated as unmanaged raw values. This is generally not recommended unless you are maintaining older projects that depend on uncorrected color blending.

Required Supporting Configurations

To achieve fully correct rendering when ColorManagement.enabled is active, configure your renderer and textures to match.

1. Configure the WebGLRenderer

Set the renderer's outputColorSpace to THREE.SRGBColorSpace so linear computations are correctly encoded for display monitors:

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.outputColorSpace = THREE.SRGBColorSpace;

2. Set Texture Color Spaces

Ensure input textures are tagged with the appropriate color space:

  • Color textures (albedo, diffuse, emissive, map): Use THREE.SRGBColorSpace.
  • Data textures (normal, roughness, metalness, displacement): Use THREE.NoColorSpace or THREE.LinearSRGBColorSpace.
const textureLoader = new THREE.TextureLoader();

// Albedo map
const colorMap = textureLoader.load('textures/diffuse.jpg');
colorMap.colorSpace = THREE.SRGBColorSpace;

// Normal map
const normalMap = textureLoader.load('textures/normal.jpg');
normalMap.colorSpace = THREE.NoColorSpace;

Why Physically Correct Blending Matters

Without active color management, mixing two colors or applying light attenuation happens directly in non-linear sRGB space. This causes dark bands at color borders, overly saturated highlights, and inaccurate falloff curves. Enabling ColorManagement.enabled ensures all mathematical additions and multiplications occur in linear space, resulting in natural gradients, realistic light distribution, and consistent asset appearance between 3D software (like Blender) and the web.
