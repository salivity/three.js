How to Use Varyings in Three.js ShaderMaterial

Passing custom data from a vertex shader to a fragment shader in Three.js requires the use of GLSL varying variables. This article explains how to define a custom varying, assign calculated data to it in the vertex shader, and read its interpolated value within the fragment shader using Three.js's ShaderMaterial.

Understanding the Varying Workflow

In the WebGL rendering pipeline, the vertex shader executes first for every vertex, while the fragment shader runs later for every generated fragment (pixel). A varying variable acts as a bridge between them. When you write a value to a varying in the vertex shader, WebGL smoothly interpolates that value across the surface of the geometry primitive before passing it into the fragment shader.

To successfully use a varying, you must declare it with the exact same name and data type in both the vertex and fragment shader code.

Implementation Example

Below is a complete implementation demonstrating how to pass a custom 3D vector representing vertex positions to the fragment shader to generate a color gradient.

import * as THREE from 'three';

// 1. Define the Vertex Shader
const vertexShader = `
  // Declare the custom varying variable
  varying vec3 vPosition;

  void main() {
    // Assign data to the varying variable
    vPosition = position;

    // Standard projection transformation
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

// 2. Define the Fragment Shader
const fragmentShader = `
  // Declare the identical varying variable
  varying vec3 vPosition;

  void main() {
    // Use the interpolated varying value to set the pixel color
    // Normalizing values to a 0.0 - 1.0 range for RGB output
    gl_FragColor = vec4(vPosition * 0.5 + 0.5, 1.0);
  }
`;

// 3. Create the ShaderMaterial
const customMaterial = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  wireframe: false
});

// 4. Apply the material to a mesh
const geometry = new THREE.BoxGeometry(2, 2, 2);
const mesh = new THREE.Mesh(geometry, customMaterial);

Key Rules for Custom Varyings

  • Matching Identifiers: The variable name (e.g., vPosition) and type (e.g., vec3, float, vec2) must match exactly in both shaders.
  • Write in Vertex, Read in Fragment: You can only assign values to a varying inside the vertex shader. In the fragment shader, varyings are strictly read-only.
  • Naming Conventions: While not required by GLSL, prefixing varying variables with v (such as vUv, vNormal, or vPosition) is standard convention in Three.js to distinguish them from attributes (a) and uniforms (u).
  • Built-in Attributes: Three.js automatically provides standard attributes like position, normal, and uv to the vertex shader, making them immediately available to assign to your custom varyings without extra setup.
