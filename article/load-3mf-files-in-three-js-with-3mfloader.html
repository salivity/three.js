Load 3MF Files in Three.js with 3MFLoader

This guide explains how to use the 3MFLoader in Three.js to import and display 3D Manufacturing Format (3MF) files within a WebGL scene. You will learn how to import the loader module, set up a basic scene with appropriate lighting, load the 3MF model asynchronously, and handle common 3D printing-specific issues such as scale discrepancies and model centering.

What is 3MF?

The 3D Manufacturing Format (3MF) is an XML-based file format specifically designed for additive manufacturing. Unlike standard STL files, which only store raw surface geometry, 3MF files can contain full material properties, colors, textures, and assembly structures. Three.js supports this format via the official 3MFLoader add-on.

1. Import Dependencies

To use 3MFLoader, import both the core Three.js library and the loader from the three/addons/ directory.

import * as THREE from 'three';
import { 3MFLoader } from 'three/addons/loaders/3MFLoader.js';

2. Set Up the Scene and Lights

3MF models often contain mesh materials that require proper illumination to be visible. Set up a standard scene, camera, renderer, and adequate lighting:

const scene = new THREE.Scene();
scene.background = new THREE.Color(0xf0f0f0);

const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 50, 100);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Lighting
const ambientLight = new THREE.AmbientLight(0xffffff, 0.8);
scene.add(ambientLight);

const directionalLight = new THREE.DirectionalLight(0xffffff, 1.0);
directionalLight.position.set(50, 100, 50);
scene.add(directionalLight);

3. Load the 3MF File

Instantiate 3MFLoader and invoke the .load() method. The loader parses the 3MF archive and returns a THREE.Group containing the meshes and materials defined inside the file.

const loader = new 3MFLoader();

loader.load(
    'path/to/model.3mf',
    function (object) {
        // Center the geometry if necessary
        const box = new THREE.Box3().setFromObject(object);
        const center = box.getCenter(new THREE.Vector3());
        object.position.sub(center);

        // Add the loaded object to the scene
        scene.add(object);
        
        console.log('3MF model loaded successfully');
    },
    function (xhr) {
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    function (error) {
        console.error('An error occurred while loading the 3MF file:', error);
    }
);

4. Important Considerations for 3D Printing Assets

  • Unit Scale: 3MF files are generally authored in millimeters because they are targeted at 3D printers. Three.js uses arbitrary units, which are conventionally interpreted as meters. A model exported as 100 mm might appear as 100 units across in Three.js, appearing enormous or clipping outside the camera frustum. If your scene uses meters, scale the object down: 
    object.scale.setScalar(0.001); // Millimeters to meters
  • Materials and Vertex Colors: 3MFLoader automatically reconstructs materials packaged in the archive. If a model uses color groups or vertex colors, ensure your rendering pipeline does not override these materials with default shaders.
  • Camera Clipping: Because 3D printing geometries can vary wildly in physical bounding dimensions, automatically adjust your camera's near and far planes based on the bounding box of the loaded object to prevent rendering artifacts.
