How to Soften SpotLight Edges in Three.js

In Three.js, achieving a soft-edged spotlight requires adjusting two primary properties: angle and penumbra. While angle defines the overall spread and boundary of the light cone, penumbra controls the percentage of that cone dedicated to feathering the light transition from maximum intensity to zero. By configuring these parameters together, you can transform a harsh, artificial circle of light into a smooth, natural-looking beam.

Understanding angle and penumbra

A THREE.SpotLight projects light in the shape of a cone originating from its position toward its target.

  • angle: Defined in radians (between 0 and Math.PI / 2), this sets the maximum angular extent of the spotlight's cone from its central direction vector. A larger angle creates a wider light footprint, while a smaller angle creates a tight beam.
  • penumbra: Defined as a floating-point value between 0.0 and 1.0, this specifies the fraction of the light cone's outer edge that is softened by attenuation.
    • A value of 0.0 results in a razor-sharp edge with no fade.
    • A value of 0.5 causes the outer 50% of the light cone to fade out smoothly.
    • A value of 1.0 starts the fade right from the center of the cone, creating the maximum possible edge softness.

Implementation Example

To create a spotlight with soft, gradual edges, instantiate the light and adjust the properties as follows:

import * as THREE from 'three';

// Create a spotlight: color, intensity, distance, angle, penumbra, decay
const spotLight = new THREE.SpotLight(0xffffff, 2);

// Position the light
spotLight.position.set(0, 10, 0);

// Set the width of the beam (in radians)
spotLight.angle = Math.PI / 4; // 45-degree total spread from center

// Set the edge softness (0.0 = hard edge, 1.0 = fully feathered edge)
spotLight.penumbra = 0.5;

// Add to the scene
scene.add(spotLight);

Tips for Fine-Tuning

  • Calculate with Degrees: If you prefer working in degrees rather than radians, use THREE.MathUtils.degToRad() to set the angle: 
    spotLight.angle = THREE.MathUtils.degToRad(30);
  • Use the Helper: Visualizing penumbra changes in real-time can be difficult without context. Attach a THREE.SpotLightHelper to your scene to see visual wireframes of both the core beam and the penumbra boundary: 
    const spotLightHelper = new THREE.SpotLightHelper(spotLight);
scene.add(spotLightHelper);

// Remember to call update if you modify the angle in an animation loop
spotLightHelper.update();
  • Penumbra vs. Shadow Softness: Note that the penumbra property only softens the circular falloff edge of the light cone itself. It does not soften shadows cast by objects within the beam. To soften shadows cast by the spotlight, configure the shadow map type on the renderer (such as THREE.PCFSoftShadowMap) or adjust spotLight.shadow.radius.
