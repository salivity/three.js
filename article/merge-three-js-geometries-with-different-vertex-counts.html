Merge Three.js Geometries With Different Vertex Counts

This guide explains how to merge BufferGeometry instances with different vertex counts in Three.js. In Three.js, a single BufferGeometry requires every attached attribute (such as position, normal, and uv) to share the exact same vertex count. Consequently, handling geometries with differing counts depends on whether you are concatenating two distinct geometries into a single combined mesh or attempting to share attribute data between them.

The Rule of BufferGeometry Attributes

Every BufferAttribute attached to a single BufferGeometry instance must contain the same number of vertices. If your geometry has 100 vertices, its position attribute has a count of 100 (300 floats), and its uv attribute must also have a count of 100 (200 floats). You cannot directly attach an attribute with count \(A\) and an attribute with count \(B\) to the same geometry without padding, truncating, or interpolating the data.

Concatenating Geometries Using BufferGeometryUtils

If your goal is to combine two distinct geometries (Geometry A with \(N\) vertices and Geometry B with \(M\) vertices) into a single geometry containing \(N + M\) vertices, use the BufferGeometryUtils.mergeGeometries function.

1. Ensure Matching Attributes

mergeGeometries requires both geometries to share the same set of attributes. If Geometry A has position, normal, and uv, Geometry B must also possess position, normal, and uv.

If one geometry lacks an attribute, you must generate it or fill it with default values prior to merging:

import * as THREE from 'three';
import * as BufferGeometryUtils from 'three/addons/utils/BufferGeometryUtils.js';

// Ensure both geometries have identical attributes
if (geometryA.hasAttribute('uv') && !geometryB.hasAttribute('uv')) {
    const count = geometryB.attributes.position.count;
    const emptyUvs = new Float32Array(count * 2);
    geometryB.setAttribute('uv', new THREE.BufferAttribute(emptyUvs, 2));
}

2. Merge the Geometries

Pass the array of geometries into BufferGeometryUtils.mergeGeometries. The utility automatically handles index offsets and concatenates the attribute buffers:

const geometries = [geometryA, geometryB];

// Merge into a single BufferGeometry
const mergedGeometry = BufferGeometryUtils.mergeGeometries(geometries, false);

if (!mergedGeometry) {
    console.error('Failed to merge geometries. Ensure attribute formats match.');
}

Setting the second argument (useGroups) to true creates groups within the merged geometry, allowing you to apply multiple materials to the resulting mesh.

Merging Geometries Manually

If you cannot use BufferGeometryUtils, you can manually allocate a new Float32Array that sums the counts of both geometries:

const countA = geometryA.attributes.position.count;
const countB = geometryB.attributes.position.count;
const totalCount = countA + countB;

// Combine positions
const mergedPositions = new Float32Array(totalCount * 3);
mergedPositions.set(geometryA.attributes.position.array, 0);
mergedPositions.set(geometryB.attributes.position.array, countA * 3);

const mergedGeometry = new THREE.BufferGeometry();
mergedGeometry.setAttribute('position', new THREE.BufferAttribute(mergedPositions, 3));

// Handle indices if present
if (geometryA.index && geometryB.index) {
    const indexA = geometryA.index.array;
    const indexB = geometryB.index.array;
    const mergedIndices = new Uint32Array(indexA.length + indexB.length);

    mergedIndices.set(indexA, 0);
    for (let i = 0; i < indexB.length; i++) {
        mergedIndices[indexA.length + i] = indexB[i] + countA;
    }

    mergedGeometry.setIndex(new THREE.BufferAttribute(mergedIndices, 1));
}

Transferring Attributes Between Different Meshes

If your goal is to transfer attribute values from a mesh with \(N\) vertices onto an existing mesh with \(M\) vertices (such as transferring vertex colors or UVs), direct assignment is impossible. You must sample or interpolate the data:

  1. Raycasting / Nearest Neighbor: For every vertex in the target geometry, find the nearest vertex or surface point on the source geometry and sample the attribute value.
  2. Padding / Truncating: If the vertex counts differ simply because of unused buffer space, resize the smaller array using new Float32Array(targetCount * itemSize) and copy the relevant values, populating remainder slots with zero or default coordinates.
