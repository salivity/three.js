Create an RGB DataTexture in Three.js with Float32Array

This guide provides a quick overview and step-by-step walkthrough for manually generating an RGB DataTexture in Three.js using a Float32Array. You will learn how to calculate the correct buffer size, structure interleaved red, green, and blue color channels, configure the texture parameters with floating-point precision, and apply the resulting texture to a material.

1. Calculate Array Size

An RGB texture requires three color channels per pixel: Red, Green, and Blue. To store this data, your Float32Array must have a length equal to the total number of pixels multiplied by 3:

const width = 256;
const height = 256;
const size = width * height;
const data = new Float32Array(size * 3);

2. Populate the Float32Array

Iterate through every pixel to populate the array. Each pixel occupies three consecutive indices:

  • stride + 0: Red component
  • stride + 1: Green component
  • stride + 2: Blue component

Because you are using Float32Array, color values are typically floating-point numbers between 0.0 and 1.0, though values greater than 1.0 can be used for High Dynamic Range (HDR) workflows.

for (let i = 0; i < size; i++) {
  const stride = i * 3;

  // Example: generate a gradient
  const x = (i % width) / width;
  const y = Math.floor(i / width) / height;

  data[stride] = x;       // Red
  data[stride + 1] = y;   // Green
  data[stride + 2] = 0.5; // Blue
}

3. Instantiate the DataTexture

Pass the array, dimensions, format, and type into the THREE.DataTexture constructor.

  • Set the format to THREE.RGBFormat (for older Three.js versions) or THREE.RGBAFormat if using four channels. Note that WebGL implementations increasingly require 4-channel textures (RGBA), but when 3-channel RGB float textures are supported, use THREE.RGBFormat.
  • Set the type to THREE.FloatType.
import * as THREE from 'three';

const texture = new THREE.DataTexture(
  data,
  width,
  height,
  THREE.RGBFormat,
  THREE.FloatType
);

// Inform Three.js that the buffer needs to be uploaded to the GPU
texture.needsUpdate = true;

4. Configure Texture Filtering

Floating-point textures often require specific filtering depending on your GPU's capabilities and enabled extensions:

// NearestFilter is supported on all devices for float textures
texture.minFilter = THREE.NearestFilter;
texture.magFilter = THREE.NearestFilter;
texture.generateMipmaps = false;

If you require linear filtering (THREE.LinearFilter), ensure the WebGL context supports the OES_texture_float_linear extension.

5. Apply the Texture to a Material

Once the texture is created, assign it to any compatible Three.js material map:

const material = new THREE.MeshBasicMaterial({ map: texture });
const geometry = new THREE.PlaneGeometry(5, 5);
const mesh = new THREE.Mesh(geometry, material);

scene.add(mesh);
