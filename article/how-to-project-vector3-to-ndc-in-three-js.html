How to Project Vector3 to NDC in Three.js

Projecting a 3D Vector3 into 2D Normalized Device Coordinates (NDC) in Three.js is a fundamental technique used for positioning HTML overlays, processing raycasting queries, and translating 3D object positions to the 2D viewport. This guide explains how to use the built-in Vector3.project() method to map world coordinates directly into the camera's [-1, 1] NDC space quickly and accurately.

The Vector3.project() Method

In Three.js, the Vector3 class provides a native .project() method. It transforms a vector from 3D world space into Normalized Device Coordinate space by multiplying the vector by the camera's view matrix (world matrix inverse) and then by the camera's projection matrix.

import * as THREE from 'three';

// 1. Define the 3D position in world space
const worldPosition = new THREE.Vector3(x, y, z);

// 2. Project the vector onto NDC space using your camera
const ndcPosition = worldPosition.clone().project(camera);

Note: Calling .project() mutates the original vector in place. Always call .clone() first if you need to preserve the original world-space coordinate.

Understanding the Output Range

Once transformed, the components of ndcPosition represent normalized coordinates:

  • x: Ranges from -1.0 (far left of the viewport) to +1.0 (far right of the viewport).
  • y: Ranges from -1.0 (bottom of the viewport) to +1.0 (top of the viewport).
  • z: Represents the depth relative to the camera's clipping planes, typically ranging from -1.0 (near plane) to +1.0 (far plane) in standard WebGL.

Converting NDC to 2D Screen Pixel Coordinates

If your goal is to map the projected NDC coordinate to screen pixels (for example, to position an absolute HTML <div> over a 3D object), map the [-1, 1] range to the window's pixel dimensions:

const width = window.innerWidth;
const height = window.innerHeight;

const screenX = (ndcPosition.x * 0.5 + 0.5) * width;
const screenY = (-(ndcPosition.y * 0.5) + 0.5) * height;

Because DOM coordinates measure (0, 0) from the top-left corner and the y-axis increases downward, the y component must be inverted.

Key Considerations

  • Camera Matrices: Ensure the camera's transformation matrices are up to date before projecting. If the camera or target object moved within the current frame, call camera.updateMatrixWorld() and camera.updateProjectionMatrix() prior to projection.
  • Objects Behind the Camera: Check the resulting z value or whether the coordinate lies in front of the camera plane. If ndcPosition.z > 1.0, the point extends beyond the camera's far clipping plane; if it lies behind the camera, the projection will produce inverted screen values.
