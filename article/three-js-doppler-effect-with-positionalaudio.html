Three.js Doppler Effect with PositionalAudio

This guide demonstrates how to attach a PositionalAudio node directly to a moving mesh in Three.js and calculate a realistic Doppler effect. By binding spatial audio directly to a mesh's transform hierarchy and calculating relative velocity toward the scene's listener in the animation loop, you can dynamically pitch-shift the audio to simulate authentic Doppler shifts.

1. Set Up the AudioListener

The AudioListener represents the ears of the scene and must be attached to the camera so spatial panning corresponds to the user's viewpoint.

import * as THREE from 'three';

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const listener = new THREE.AudioListener();
camera.add(listener);

2. Create the Mesh and Attach PositionalAudio

Three.js PositionalAudio inherits from Object3D. When you add it as a child of a Mesh, it automatically inherits the position and orientation of that mesh.

// Create moving mesh
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const movingMesh = new THREE.Mesh(geometry, material);
scene.add(movingMesh);

// Create PositionalAudio
const sound = new THREE.PositionalAudio(listener);

// Load an audio file
const audioLoader = new THREE.AudioLoader();
audioLoader.load('path/to/engine_sound.mp3', (buffer) => {
  sound.setBuffer(buffer);
  sound.setRefDistance(10);
  sound.setLoop(true);
  sound.setVolume(1.0);
  sound.play();
});

// Attach directly to the mesh
movingMesh.add(sound);

3. Implement the Doppler Pitch Shift

The native Web Audio API deprecated its built-in Doppler parameters in modern browsers. To achieve a realistic Doppler effect, manually calculate the relative velocity between the audio source and the listener, then adjust the playbackRate of the PositionalAudio source using the Doppler formula:

\[\text{Frequency Factor} = \frac{c}{c - v_s}\]

Where \(c\) is the speed of sound (approximately \(343\text{ m/s}\)) and \(v_s\) is the velocity of the source relative to the listener.

const SPEED_OF_SOUND = 343; // meters per second
const prevSourcePos = new THREE.Vector3();
const clock = new THREE.Clock();

function updateDoppler(sourceMesh, listenerCamera, soundNode, deltaTime) {
  if (!soundNode.isPlaying || deltaTime === 0) return;

  const currentSourcePos = new THREE.Vector3();
  sourceMesh.getWorldPosition(currentSourcePos);

  const listenerPos = new THREE.Vector3();
  listenerCamera.getWorldPosition(listenerPos);

  // Vector from source to listener
  const toListener = new THREE.Vector3().subVectors(listenerPos, currentSourcePos).normalize();

  // Calculate source velocity vector
  const velocity = new THREE.Vector3()
    .subVectors(currentSourcePos, prevSourcePos)
    .divideScalar(deltaTime);

  // Project velocity onto the direction vector to get relative speed
  const relativeSpeed = velocity.dot(toListener);

  // Calculate Doppler factor
  const dopplerFactor = SPEED_OF_SOUND / (SPEED_OF_SOUND - relativeSpeed);

  // Clamp values to prevent distortion at extreme speeds
  const clampedRate = THREE.MathUtils.clamp(dopplerFactor, 0.5, 2.0);

  // Apply pitch shift
  soundNode.setPlaybackRate(clampedRate);

  // Store current position for the next frame
  prevSourcePos.copy(currentSourcePos);
}

4. Drive the Effect in the Render Loop

Call your movement logic and the Doppler calculation inside the main animation loop using the frame's delta time.

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();

  // Move the mesh along an axis
  movingMesh.position.z += Math.sin(clock.getElapsedTime() * 2) * 0.5;

  // Update Doppler shift
  updateDoppler(movingMesh, camera, sound, delta);

  renderer.render(scene, camera);
}

animate();

Because sound is a child node of movingMesh, its local 3D transform updates concurrently with the mesh. Updating the playback rate relative to velocity creates the pitch change of a real-world object approaching and passing the listener.
