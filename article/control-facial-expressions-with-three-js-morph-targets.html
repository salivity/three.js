Control Facial Expressions with Three.js Morph Targets

Controlling facial expressions in Three.js relies on manipulating the morphTargetInfluences array of a 3D mesh. This guide explains how to locate a model's facial mesh, map expression names to array indices using morphTargetDictionary, and programmatically adjust influence values between 0.0 and 1.0 to create real-time facial animations such as smiles, blinks, and visemes.

Understanding the Core Properties

Two properties on a THREE.Mesh or THREE.SkinnedMesh manage morph targets:

  1. morphTargetInfluences: An array of floating-point numbers, typically ranging from 0.0 (target has no effect) to 1.0 (target is fully applied). Values can occasionally exceed 1.0 or drop below 0.0 depending on the mesh setup, but 0.0 to 1.0 is standard.
  2. morphTargetDictionary: An object acting as a key-value lookup table that maps target names (such as "mouthSmile" or "eyeBlinkLeft") to their corresponding integer indices in the morphTargetInfluences array.

Accessing the Mesh

When importing models (such as GLTF/GLB files), the morph targets are stored on specific sub-meshes within the model hierarchy. You must find the mesh that contains the targets:

let faceMesh = null;

loader.load('model.glb', (gltf) => {
  const model = gltf.scene;
  scene.add(model);

  model.traverse((child) => {
    if (child.isMesh && child.morphTargetInfluences) {
      // Check for facial morph targets
      if (child.morphTargetDictionary && child.morphTargetDictionary['mouthSmile'] !== undefined) {
        faceMesh = child;
      }
    }
  });
});

Setting Expression Influences

To update an expression, map the name of the target to the correct index in morphTargetInfluences using the dictionary, then assign the desired weight.

Direct Value Assignment

function setExpression(mesh, targetName, value) {
  if (!mesh || !mesh.morphTargetDictionary || !mesh.morphTargetInfluences) {
    return;
  }

  const index = mesh.morphTargetDictionary[targetName];
  if (index !== undefined) {
    mesh.morphTargetInfluences[index] = THREE.MathUtils.clamp(value, 0.0, 1.0);
  } else {
    console.warn(`Morph target "${targetName}" not found on mesh.`);
  }
}

// Example usage:
setExpression(faceMesh, 'mouthSmile', 1.0);  // Fully smile
setExpression(faceMesh, 'eyeBlinkLeft', 0.5); // Half-closed eye

Modifying via Raw Index

If the target indices are static and known in advance, you can bypass the dictionary lookup entirely:

// Sets the first morph target influence to maximum
faceMesh.morphTargetInfluences[0] = 1.0;

Smooth Transitions and Animation Loops

Direct assignment snaps the mesh immediately to the target pose. For natural movements, interpolate values inside the render loop using linear interpolation (THREE.MathUtils.lerp):

const targets = {
  mouthSmile: 0.0,
  eyeBlinkLeft: 0.0,
  eyeBlinkRight: 0.0
};

// Update target state
function triggerBlink() {
  targets.eyeBlinkLeft = 1.0;
  targets.eyeBlinkRight = 1.0;

  // Reset blink after 150ms
  setTimeout(() => {
    targets.eyeBlinkLeft = 0.0;
    targets.eyeBlinkRight = 0.0;
  }, 150);
}

// In the animation loop
function animate() {
  requestAnimationFrame(animate);

  if (faceMesh) {
    for (const [name, targetValue] of Object.entries(targets)) {
      const index = faceMesh.morphTargetDictionary[name];
      if (index !== undefined) {
        const currentValue = faceMesh.morphTargetInfluences[index];
        // Smoothly interpolate towards the target value
        faceMesh.morphTargetInfluences[index] = THREE.MathUtils.lerp(currentValue, targetValue, 0.1);
      }
    }
  }

  renderer.render(scene, camera);
}
animate();

Inspecting Available Targets

To see all available morph targets on a loaded model, print the keys of the dictionary:

console.log('Available expressions:', Object.keys(faceMesh.morphTargetDictionary));
