Using DataArrayTexture for 3D Data in Three.js

This guide explains how to construct and use a DataArrayTexture in Three.js to transfer a 3D grid of data into a custom GLSL shader. By organizing structured grid or volumetric data into a typed array, creating a layered 2D array texture, and sampling it with WebGL 2, you can efficiently read slice-based or 3D-oriented data directly within your fragment shaders.

1. Populate the Raw Data Buffer

A DataArrayTexture requires a flat typed array (such as Float32Array or Uint8Array) representing layers stacked along the Z-axis. The length of the array must equal width * height * depth * componentCount.

import * as THREE from 'three';

const width = 32;
const height = 32;
const depth = 16; // Number of slices along the Z-axis

// Example: single-channel (RedFormat) 32-bit float values
const size = width * height * depth;
const data = new Float32Array(size);

for (let z = 0; z < depth; z++) {
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const index = x + y * width + z * width * height;
      // Populate with custom grid data or normalized coordinates
      data[index] = Math.sin((x / width) * Math.PI) * Math.cos((y / height) * Math.PI);
    }
  }
}

2. Instantiate the DataArrayTexture

Construct the texture object using the typed array, dimensions, and appropriate texture configuration options.

const texture = new THREE.DataArrayTexture(data, width, height, depth);

// Define the data format and type
texture.format = THREE.RedFormat;
texture.type = THREE.FloatType;

// Define filtering behavior
texture.minFilter = THREE.LinearFilter;
texture.magFilter = THREE.LinearFilter;
texture.wrapS = THREE.ClampToEdgeWrapping;
texture.wrapT = THREE.ClampToEdgeWrapping;

// Signal Three.js to upload the data to the GPU
texture.needsUpdate = true;

3. Pass the Texture to a Custom Shader

Assign the texture as a uniform to a THREE.ShaderMaterial or THREE.RawShaderMaterial. Three.js relies on WebGL 2 by default, which natively supports 2D array textures.

const material = new THREE.ShaderMaterial({
  uniforms: {
    uGridData: { value: texture },
    uDepth: { value: depth }
  },
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    precision highp float;
    precision highp sampler2DArray;

    uniform sampler2DArray uGridData;
    uniform float uDepth;
    varying vec2 vUv;

    void main() {
      // Third coordinate is the unnormalized layer/slice index [0.0, depth - 1.0]
      float layerIndex = 4.0;
      
      // Sample the layer
      float value = texture(uGridData, vec3(vUv, layerIndex)).r;

      gl_FragColor = vec4(vec3(value), 1.0);
    }
  `
});

4. GLSL Sampling Rules

When sampling a sampler2DArray in GLSL:

  • The lookup coordinate passed to texture() must be a vec3.
  • The first two components (x, y) represent standard normalized UV coordinates ranging from 0.0 to 1.0.
  • The third component (z) represents the zero-based layer index. OpenGL automatically rounds or blends between layers depending on the texture filtering parameters.
