Embed YouTube iFrames in Three.js with CSS3D

This article provides a direct, technical walkthrough on integrating an interactive, fully functional YouTube iframe into a Three.js scene. Standard WebGL textures cannot capture interactive HTML elements like iframes due to browser security restrictions and rendering limitations. To solve this, you will learn how to set up CSS3DRenderer, wrap a YouTube <iframe> DOM element inside a CSS3DObject, coordinate the CSS3D scene with the standard Three.js camera, and ensure pointer events remain functional for video playback controls.

Understanding CSS3DRenderer

Three.js includes an add-on renderer called CSS3DRenderer. Rather than drawing pixels on a <canvas>, CSS3DRenderer applies CSS3 transform-style: preserve-3d matrix transforms directly to HTML elements to match the perspective and orientation of a Three.js camera. This allows HTML elements like iframes to respond to 3D rotation, scaling, and positioning while preserving native browser events like clicks and typing.

Step 1: Import Required Modules

To get started, import the standard Three.js library alongside CSS3DRenderer and CSS3DObject.

import * as THREE from 'three';
import { CSS3DRenderer, CSS3DObject } from 'three/examples/jsm/renderers/CSS3DRenderer.js';
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';

Step 2: Initialize the Scene, Camera, and CSS3DRenderer

Create the core Three.js components. The CSS3DRenderer creates its own DOM element, which should cover the entire viewport.

const scene = new THREE.Scene();

const camera = new THREE.PerspectiveCamera(
    75,
    window.innerWidth / window.innerHeight,
    0.1,
    1000
);
camera.position.set(0, 0, 500);

const renderer = new CSS3DRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.domElement.style.position = 'absolute';
renderer.domElement.style.top = '0';
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);

Step 3: Construct the YouTube iFrame and CSS3DObject

Create a native HTML div container and an iframe element. Configure the iframe attributes, set its size, and pass the container element into a CSS3DObject.

function createYouTubeObject(videoId, width, height) {
    // Outer container to manage CSS sizing
    const container = document.createElement('div');
    container.style.width = `${width}px`;
    container.style.height = `${height}px`;
    container.style.background = '#000000';

    // Native iframe element
    const iframe = document.createElement('iframe');
    iframe.style.width = '100%';
    iframe.style.height = '100%';
    iframe.style.border = '0';
    iframe.src = `https://www.youtube.com/embed/${videoId}?enablejsapi=1`;
    iframe.allow = 'accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture';
    iframe.allowFullscreen = true;

    container.appendChild(iframe);

    // Encapsulate in CSS3DObject
    const cssObject = new CSS3DObject(container);
    return cssObject;
}

// Instantiate and add to scene
const youtubeObject = createYouTubeObject('dQw4w9WgXcQ', 480, 270);
youtubeObject.position.set(0, 0, 0);
scene.add(youtubeObject);

Step 4: Add the Animation Loop and Resize Handling

Drive the scene rendering using requestAnimationFrame and ensure the camera aspect ratio updates when the browser window is resized.

window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize(window.innerWidth, window.innerHeight);
});

    requestAnimationFrame(animate);
    controls.update();
    renderer.render(scene, camera);

Handling Pointer Events and Layering

If your application combines both standard WebGL objects and CSS3D objects, place the CSS3DRenderer DOM element underneath the WebGLRenderer canvas. Set the WebGLRenderer canvas style pointer-events: none or place invisible WebGL planes with pointer-events: auto to allow mouse interactions to pass directly through to the YouTube iframe.
