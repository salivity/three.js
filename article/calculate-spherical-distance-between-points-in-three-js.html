Calculate Spherical Distance Between Points in Three.js

Calculating the shortest distance over the surface of a sphere—known as the great-circle distance—requires determining the central angle between two points and scaling it by the sphere's radius. In Three.js, you can achieve this efficiently by converting geographical coordinates (latitude and longitude) into Cartesian vectors using THREE.Spherical and THREE.Vector3, and then using built-in vector methods like angleTo() to compute the angular separation in radians.

1. Converting Coordinates to THREE.Vector3

To work with Three.js math utilities, points defined by latitude and longitude must first be represented as 3D direction vectors. In Three.js, THREE.Spherical uses physics conventions:

  • radius: Distance from the center.
  • phi (polar angle): Angle down from the positive Y-axis (\(0\) to \(\pi\)). Latitude maps to phi as (90 - lat) * (Math.PI / 180).
  • theta (azimuthal angle): Angle around the Y-axis (\(0\) to \(2\pi\)). Longitude maps to theta as (lon + 180) * (Math.PI / 180) (or simply converted to radians depending on your prime meridian orientation).
import * as THREE from 'three';

function latLonToVector3(lat, lon, radius = 1) {
  const phi = THREE.MathUtils.degToRad(90 - lat);
  const theta = THREE.MathUtils.degToRad(lon + 180);

  const spherical = new THREE.Spherical(radius, phi, theta);
  return new THREE.Vector3().setFromSpherical(spherical);
}

2. Calculating the Angular Separation

The shortest route between two points on a sphere lies along the perimeter of the circle formed by the intersection of the sphere and the plane passing through both points and the center of the sphere.

The angle \(\Delta\sigma\) between two unit vectors \(\vec{v_1}\) and \(\vec{v_2}\) can be obtained using the dot product: \[\cos(\Delta\sigma) = \frac{\vec{v_1} \cdot \vec{v_2}}{\|\vec{v_1}\| \|\vec{v_2}\|}\]

Three.js abstracts this calculation via the Vector3.angleTo() method, which computes the angle in radians between two vectors while automatically handling numerical precision limits.

const v1 = latLonToVector3(lat1, lon1);
const v2 = latLonToVector3(lat2, lon2);

const centralAngle = v1.angleTo(v2); // returns angle in radians

3. Computing the Arc Length

Once the central angle in radians is known, the spherical distance \(d\) is the product of the sphere's radius \(R\) and the central angle \(\Delta\sigma\):

\[d = R \times \Delta\sigma\]

Full Implementation

Here is the complete utility function to calculate the surface distance between two latitude and longitude points on a globe with a given radius:

import * as THREE from 'three';

function getSphericalDistance(lat1, lon1, lat2, lon2, globeRadius = 6371) {
  const phi1 = THREE.MathUtils.degToRad(90 - lat1);
  const theta1 = THREE.MathUtils.degToRad(lon1);
  const v1 = new THREE.Vector3().setFromSpherical(new THREE.Spherical(1, phi1, theta1));

  const phi2 = THREE.MathUtils.degToRad(90 - lat2);
  const theta2 = THREE.MathUtils.degToRad(lon2);
  const v2 = new THREE.Vector3().setFromSpherical(new THREE.Spherical(1, phi2, theta2));

  const angle = v1.angleTo(v2);

  return angle * globeRadius;
}

// Example: Distance between New York (40.7128° N, 74.0060° W) and London (51.5074° N, 0.1278° W)
const earthRadiusKm = 6371;
const distance = getSphericalDistance(40.7128, -74.0060, 51.5074, -0.1278, earthRadiusKm);

console.log(`Distance: ${distance.toFixed(2)} km`); // Output: ~5570.22 km

Pre-existing 3D Points

If your points are already placed in 3D space on a sphere centered at the origin:

function getDistanceBetweenPoints(pointA, pointB, radius) {
  const angle = pointA.angleTo(pointB);
  return angle * radius;
}

Ensure that pointA and pointB are measured from the sphere's center. If the sphere is translated in world space, subtract the sphere's center vector from each point vector before calling .angleTo().
