Colorize Three.js Reflections with SpecularColorMap

In Three.js, creating complex, tinted reflections on metallic surfaces requires the advanced lighting capabilities of MeshPhysicalMaterial. By pairing this material with a specularColorMap, you can map distinct reflection colors across different regions of a 3D model, allowing for realistic effects such as heat-treated metals, oil slicks, or specialized industrial coatings. This guide outlines how to configure a texture, assign it as a specular color map, and balance material settings to properly tint metallic reflections.

Understanding SpecularColorMap in MeshPhysicalMaterial

While standard PBR workflows in Three.js use metalness and color (albedo) to define simple metallic tints, MeshPhysicalMaterial introduces dedicated specular parameters. The specularColorMap property accepts a 2D texture map where each pixel defines the specular reflectance tint (F0) at that coordinate.

When applied to a metallic surface (metalness close to 1.0), the specularColorMap modulates specular highlights and environment reflections directly, enabling localized control over reflection hue and intensity.

Implementation Steps

Follow these steps to load an image texture and apply it to a MeshPhysicalMaterial.

1. Load the Reflection Color Texture

Load an RGB image containing the colors you want your reflections to display. In modern Three.js (r152+), color textures must use the sRGB color space to render correctly.

import * as THREE from 'three';

const textureLoader = new THREE.TextureLoader();
const reflectionMap = textureLoader.load('path/to/specular-color-map.png');
reflectionMap.colorSpace = THREE.SRGBColorSpace;

2. Configure the MeshPhysicalMaterial

Create the MeshPhysicalMaterial and assign the loaded texture to specularColorMap. Set a low roughness and high metalness to make the specular reflections prominent.

const material = new THREE.MeshPhysicalMaterial({
    color: 0x222222, // Base color
    metalness: 1.0,  // High metalness ensures reflections dominate
    roughness: 0.15, // Low roughness produces sharp, visible reflections
    
    // Apply the map
    specularColorMap: reflectionMap,
    
    // Default specular color acts as a multiplier; keep white to preserve map colors
    specularColor: new THREE.Color(0xffffff), 
    
    // Specular intensity factor (defaults to 1.0)
    specularIntensity: 1.0 
});

3. Ensure an Environment Map is Present

Specular reflection color maps require an environment to reflect. Without an environment map (envMap) or strong directional light sources, metallic reflections will appear black.

// Provide an HDR or CubeTexture environment to the scene
scene.environment = hdrEquirectangularTexture;

const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Key Material Properties

  • specularColor: Multiplies the color values provided by the specularColorMap. Setting this to 0xffffff allows the map's original colors to display accurately.
  • specularIntensity / specularIntensityMap: Controls the strength or brightness of the specular reflections independently of their color.
  • roughness: Controls the blurriness of the tinted reflections. Lower values (e.g., 0.0 to 0.2) showcase sharp colorized reflections, while higher values diffuse the tinted highlights.
