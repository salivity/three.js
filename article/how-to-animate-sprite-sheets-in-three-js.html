How to Animate Sprite Sheets in Three.js

Animating a 2D sprite sheet in Three.js can be achieved cleanly by mathematically manipulating a texture's repeat and offset properties inside your render loop. Instead of loading separate image files for each frame, you load a single grid-based texture, scale the UV coordinates down to the size of a single frame using repeat, and then translate the UV coordinates via offset over time to cycle through rows and columns.

1. Configure the Texture Repeat

A sprite sheet is laid out in a grid of horizontal columns and vertical rows. To display only a single frame on a mesh (such as a PlaneGeometry or Sprite), scale the texture coordinates using texture.repeat.set(x, y).

The scale factors are the reciprocal of your grid dimensions:

const cols = 4;
const rows = 4;
const totalFrames = 16;

const textureLoader = new THREE.TextureLoader();
const spriteTexture = textureLoader.load('path/to/spritesheet.png');

// Isolate a single cell in the grid
spriteTexture.repeat.set(1 / cols, 1 / rows);

2. Understand Three.js UV Coordinate Orientation

In Three.js, UV coordinates start at (0, 0) in the bottom-left corner and extend to (1, 1) at the top-right. However, most 2D sprite sheets are authored to be read from top-left to bottom-right.

To account for this:

  • X-axis offset: Moves left-to-right from 0 to 1.
  • Y-axis offset: Must start at the top row (1 - (1 / rows)) and decrease downward toward 0.

3. Calculate UV Offsets Mathematically

Given a zero-indexed currentFrame, derive the current column and row indices:

const colIndex = currentFrame % cols;
const rowIndex = Math.floor(currentFrame / cols);

Convert these grid coordinates into UV offsets:

const offsetX = colIndex / cols;
const offsetY = 1 - (1 / rows) - (rowIndex / rows);

spriteTexture.offset.set(offsetX, offsetY);

4. Implement the Frame Update in the Render Loop

To control the playback speed independently of the monitor's refresh rate, track elapsed time using THREE.Clock. Advance the frame only when the accumulated time exceeds your desired frame duration.

import * as THREE from 'three';

// Scene, Camera, Renderer Setup
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 2;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Sprite Sheet Configuration
const cols = 4;
const rows = 4;
const totalFrames = 16;
const fps = 12; // Playback speed
const frameDuration = 1 / fps;

const textureLoader = new THREE.TextureLoader();
const texture = textureLoader.load('spritesheet.png');

// Set texture filtering for pixel art (optional)
texture.magFilter = THREE.NearestFilter;
texture.minFilter = THREE.NearestFilter;

// Scale UVs to display one frame
texture.repeat.set(1 / cols, 1 / rows);

// Create Mesh
const geometry = new THREE.PlaneGeometry(1, 1);
const material = new THREE.MeshBasicMaterial({ 
    map: texture, 
    transparent: true 
});
const spriteMesh = new THREE.Mesh(geometry, material);
scene.add(spriteMesh);

// Animation State
let currentFrame = 0;
let elapsedTime = 0;
const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();
    elapsedTime += delta;

    if (elapsedTime >= frameDuration) {
        // Advance frame and wrap around
        currentFrame = (currentFrame + Math.floor(elapsedTime / frameDuration)) % totalFrames;
        elapsedTime %= frameDuration;

        // Calculate column and row
        const col = currentFrame % cols;
        const row = Math.floor(currentFrame / cols);

        // Calculate and apply offset
        const xOffset = col / cols;
        const yOffset = 1 - (1 / rows) - (row / rows);
        texture.offset.set(xOffset, yOffset);
    }

    renderer.render(scene, camera);
}

animate();

This mathematical approach prevents the overhead of creating multiple materials or updating geometry UV buffers dynamically, offloading coordinate transformation entirely to the GPU's texture sampling stage.
