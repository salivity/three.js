How to Use onBeforeRender in Three.js

In Three.js, executing custom logic immediately before a mesh is drawn allows developers to update uniforms, manipulate matrix transformations, or modify rendering states per draw call. This article provides a direct guide on how to implement the onBeforeRender callback on a Three.js mesh, explains the parameters available within the callback, and demonstrates practical implementations with clear code examples.

Understanding the onBeforeRender Callback

The onBeforeRender method is an empty callback defined on THREE.Object3D. Because THREE.Mesh inherits from Object3D, every mesh can implement this method. The WebGLRenderer automatically triggers this function right before drawing the geometry using the current camera, scene, and material.

Function Signature

The callback receives six parameters when invoked by the renderer:

mesh.onBeforeRender = function (
  renderer,
  scene,
  camera,
  geometry,
  material,
  group
) {
  // Custom logic here
};
  • renderer: The active THREE.WebGLRenderer instance.
  • scene: The THREE.Scene instance being rendered.
  • camera: The THREE.Camera currently rendering the view (useful for calculating distance or camera-relative positions).
  • geometry: The THREE.BufferGeometry attached to the mesh.
  • material: The THREE.Material currently assigned to the mesh.
  • group: The geometry group being drawn, if applicable.

Practical Example: Updating Custom Shader Uniforms

The most common use case for onBeforeRender is updating custom shader uniforms dynamically without having to manually manage the mesh inside the main animation loop.

import * as THREE from 'three';

// 1. Create a custom ShaderMaterial
const customMaterial = new THREE.ShaderMaterial({
  uniforms: {
    uTime: { value: 0 },
    uDistanceToCamera: { value: 0 }
  },
  vertexShader: `
    uniform float uTime;
    void main() {
      vec3 pos = position;
      pos.y += sin(pos.x * 5.0 + uTime) * 0.1;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    }
  `,
  fragmentShader: `
    uniform float uDistanceToCamera;
    void main() {
      gl_FragColor = vec4(vec3(uDistanceToCamera * 0.1), 1.0);
    }
  `
});

// 2. Create the mesh
const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, customMaterial);

// 3. Attach the onBeforeRender callback
mesh.onBeforeRender = function (renderer, scene, camera, geometry, material) {
  // Advance time-based uniform
  material.uniforms.uTime.value = performance.now() * 0.001;

  // Calculate distance between camera and mesh
  const distance = camera.position.distanceTo(mesh.position);
  material.uniforms.uDistanceToCamera.value = distance;
};

// 4. Add the mesh to the scene
scene.add(mesh);

Best Practices and Considerations

  • Performance: Because this function runs every frame right before the draw call, avoid instantiating new objects (such as new THREE.Vector3()) inside the callback. Allocate reusable variables outside the callback scope to avoid garbage collection overhead.
  • Shared Materials: If multiple meshes share the same material instance, modifying uniform values in onBeforeRender can cause state conflicts unless uniforms are unique per instance or explicitly scoped.
  • Frustum Culling: If mesh.frustumCulled is true and the mesh falls outside the camera's view frustum, onBeforeRender will not execute for that frame.
  • Removal: To remove the custom logic, set the callback to an empty function or null:
mesh.onBeforeRender = function () {};
