Three.js 2D UI Collision Detection with Box2

This article demonstrates how to use the THREE.Box2 class to implement lightweight, high-performance 2D collision detection for flat user interface (UI) layers in Three.js. By leveraging axis-aligned bounding boxes (AABB) in an orthographic projection or screen-space coordinate system, you can determine overlaps between UI elements, cursor interactions, or moving HUD components without resorting to expensive 3D raycasting.

Understanding THREE.Box2

The THREE.Box2 class represents a 2D axis-aligned bounding box defined by two points: min and max (both instances of THREE.Vector2). Unlike raycasting against 3D geometries, calculating overlaps with Box2 relies on simple scalar comparisons along the X and Y axes, making it exceptionally fast for 2D UI layers.

Setting Up the Orthographic UI Layer

A common approach for rendering a 2D UI in Three.js is using an OrthographicCamera matching the screen's pixel dimensions:

import * as THREE from 'three';

const width = window.innerWidth;
const height = window.innerHeight;

// Camera configured so 1 unit = 1 pixel
const uiCamera = new THREE.OrthographicCamera(
  -width / 2, width / 2,
  height / 2, -height / 2,
  0.1, 10
);
uiCamera.position.z = 1;

const uiScene = new THREE.Scene();

Defining and Updating Bounding Boxes

To test collisions between UI elements, associate each element with its own THREE.Box2. You can derive the box bounds directly from the element's position and size using the setFromCenterAndSize method.

// Pre-allocate to prevent garbage collection in the animation loop
const elementABox = new THREE.Box2();
const elementBBox = new THREE.Box2();

const centerA = new THREE.Vector2();
const sizeA = new THREE.Vector2(120, 40); // width, height in pixels

const centerB = new THREE.Vector2();
const sizeB = new THREE.Vector2(80, 80);

function updateBoxes(meshA, meshB) {
  // Update centers based on mesh positions
  centerA.set(meshA.position.x, meshA.position.y);
  centerB.set(meshB.position.x, meshB.position.y);

  elementABox.setFromCenterAndSize(centerA, sizeA);
  elementBBox.setFromCenterAndSize(centerB, sizeB);
}

If your UI mesh uses standard geometries such as THREE.PlaneGeometry, you can also compute its 2D bounds manually by inspecting the object's scale and world position.

Checking for Collisions

THREE.Box2 provides native methods to evaluate intersections:

1. Element-to-Element Collision (intersectsBox)

To test if two UI elements overlap, use the intersectsBox method:

function checkUICollision() {
  if (elementABox.intersectsBox(elementBBox)) {
    // Collision detected
    console.log('UI elements are overlapping');
  }
}

2. Pointer/Mouse-to-Element Collision (containsPoint)

To test if a mouse or touch coordinate is hovering over a UI element, convert your screen coordinates to the UI space and test inclusion:

const mousePoint = new THREE.Vector2();

window.addEventListener('pointermove', (event) => {
  // Convert standard window coordinates to centered orthographic coordinates
  mousePoint.x = event.clientX - window.innerWidth / 2;
  mousePoint.y = -(event.clientY - window.innerHeight / 2);

  if (elementABox.containsPoint(mousePoint)) {
    // Pointer is over element A
    document.body.style.cursor = 'pointer';
  } else {
    document.body.style.cursor = 'default';
  }
});

Integration in the Render Loop

Call your update and collision checks inside your render loop to maintain dynamic collision responses:

function animate() {
  requestAnimationFrame(animate);

  // Update animated UI positions here
  // ...

  // Update and evaluate 2D bounding boxes
  updateBoxes(uiMeshA, uiMeshB);
  checkUICollision();

  renderer.render(uiScene, uiCamera);
}

Best Practices

  • Avoid Instantiation in the Loop: Instantiate Vector2 and Box2 instances once outside the loop and mutate them via set(), copy(), or setFromCenterAndSize() to prevent memory churn.
  • Axis Alignment Constraint: Box2 only checks axis-aligned regions. If your UI element rotates on the Z-axis, either enclose the rotated corners within the box using setFromPoints() or switch to an Oriented Bounding Box (OBB) algorithm.
