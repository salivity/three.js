Disable Fog on MeshStandardMaterial in Three.js

In Three.js, adding a global fog to a scene automatically applies atmospheric depth to all standard materials by default. This article explains how to selectively exempt specific meshes from this effect by configuring the fog: false property on a MeshStandardMaterial, ensuring your chosen objects remain fully visible regardless of scene depth.

Understanding Default Fog Behavior

When a scene has its fog property populated with THREE.Fog or THREE.FogExp2, built-in materials automatically incorporate fog calculations into their fragment shaders. The fog parameter defaults to true on standard materials, blending the mesh's color into the fog color based on the camera distance.

Disabling Fog at Initialization

To make a MeshStandardMaterial ignore scene fog from the start, pass fog: false into the material's constructor configuration object.

import * as THREE from 'three';

// Create a scene and add fog
const scene = new THREE.Scene();
scene.fog = new THREE.Fog(0xcccccc, 10, 50);

// Create a material configured to ignore the fog
const unaffectedMaterial = new THREE.MeshStandardMaterial({
    color: 0xff0000,
    roughness: 0.5,
    metalness: 0.1,
    fog: false // Disables fog calculations for this material
});

// Create and add the mesh
const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, unaffectedMaterial);
scene.add(mesh);

Disabling Fog on an Existing Material

If the material has already been instantiated and added to the scene, you can toggle the property directly. Because altering the fog property changes the underlying shader program, you must set needsUpdate to true so Three.js recompiles the shader.

// Disable fog on an active material instance
material.fog = false;
material.needsUpdate = true;

Without setting material.needsUpdate = true, Three.js will continue rendering the mesh using the previously compiled shader that includes fog calculations.

Use Cases

Setting fog: false is particularly useful for:

  • User interface (UI) elements or HUD components rendered directly in the 3D scene.
  • Skyboxes, celestial bodies (such as moons or suns), and distant background landmarks that must stay visible through thick fog.
  • Emissive objects like light fixtures or glowing indicators that should not fade into the background.
