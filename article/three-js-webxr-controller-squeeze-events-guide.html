Three.js WebXR Controller Squeeze Events Guide

This guide demonstrates how to detect and handle WebXR controller squeeze (grip) events in Three.js. You will learn how to configure the Three.js XR manager, listen for high-level squeeze events directly on controller objects, and integrate the WebXR Input Profiles library to access detailed grip component data and analog squeeze values.

Setting Up Squeeze Event Listeners in Three.js

Three.js abstracts WebXR grip interactions into three built-in controller events: squeezestart, squeeze, and squeezeend. These correspond directly to the user pressing, holding, and releasing the primary grip button on a VR/AR controller.

To listen to these events, obtain a controller instance from the WebXRManager:

import * as THREE from 'three';

// Enable XR on the WebGLRenderer
renderer.xr.enabled = true;

// Get the controller instance (0 for primary, 1 for secondary)
const controller = renderer.xr.getController(0);
scene.add(controller);

function onSqueezeStart(event) {
    const controller = event.target;
    console.log('Grip pressed on controller:', controller);
}

function onSqueezeEnd(event) {
    const controller = event.target;
    console.log('Grip released on controller:', controller);
}

// Attach event listeners
controller.addEventListener('squeezestart', onSqueezeStart);
controller.addEventListener('squeezeend', onSqueezeEnd);

Loading Motion Controller Models via WebXR Input Profiles

Three.js uses the WebXR Input Profiles library via XRControllerModelFactory to automatically fetch and render the correct 3D model for the connected hardware. This setup also handles visual animations for buttons and the squeeze trigger.

Add the controller grip space to your scene using the factory:

import { XRControllerModelFactory } from 'three/addons/webxr/XRControllerModelFactory.js';

const controllerModelFactory = new XRControllerModelFactory();

// Retrieve the grip space (represents the physical position of the controller)
const controllerGrip = renderer.xr.getControllerGrip(0);

// Load and add the profile-based model
const model = controllerModelFactory.createControllerModel(controllerGrip);
controllerGrip.add(model);
scene.add(controllerGrip);

When using XRControllerModelFactory, the internal loader matches the device's XRInputSource.profiles array against the WebXR Input Profiles registry, animating the squeeze button asset automatically as the user presses the grip.

Reading Analog Squeeze Values from the Input Source

If you need continuous, analog squeeze data (such as pressure values ranging from 0.0 to 1.0 rather than binary press events), access the underlying XRInputSource gamepad object:

controller.addEventListener('connected', (event) => {
    // Store the input source associated with this controller
    controller.userData.inputSource = event.data;
});

function update() {
    const inputSource = controller.userData.inputSource;

    if (inputSource && inputSource.gamepad) {
        // According to the WebXR Gamepad Profile:
        // Index 0 is usually primary trigger, Index 1 is usually squeeze/grip
        const gripButton = inputSource.gamepad.buttons[1];

        if (gripButton) {
            const squeezePressure = gripButton.value; // Float between 0.0 and 1.0
            const isSqueezed = gripButton.pressed;   // Boolean threshold

            // Apply analog data to your interaction logic
            handleGripInteraction(squeezePressure, isSqueezed);
        }
    }
}

function render() {
    renderer.setAnimationLoop(() => {
        update();
        renderer.render(scene, camera);
    });
}

By combining Three.js controller events for state changes and the gamepad.buttons array for continuous pressure tracking, you can handle any grip interaction while remaining fully compliant with WebXR Input Profiles standards.
