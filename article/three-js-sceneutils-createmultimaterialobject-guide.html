Three.js SceneUtils createMultiMaterialObject Guide

This article explains how to layer multiple materials onto a single geometric shape in Three.js using the SceneUtils.createMultiMaterialObject utility. You will learn how this function works, why it is used for effects like wireframe overlays, how to implement it step-by-step in modern Three.js, and important performance considerations like handling z-fighting.

Understanding SceneUtils.createMultiMaterialObject

In standard Three.js, assigning an array of materials to a single THREE.Mesh maps different materials to specific faces of the geometry via material groups. However, if your goal is to layer multiple materials over the exact same surface area—such as combining a solid shaded color with a distinct wireframe—a single mesh cannot handle this natively.

The SceneUtils.createMultiMaterialObject function solves this by creating a THREE.Group that contains duplicate THREE.Mesh instances sharing the same geometry, with each mesh assigned one material from your provided array. Because all resulting meshes share the same underlying geometry data in memory, modifications or transformations applied to the parent group affect the entire layered object simultaneously.

Importing the Utility

In modern Three.js (using ES modules), SceneUtils is an addon located in the examples directory. Import it alongside the core Three.js library:

import * as THREE from 'three';
import { SceneUtils } from 'three/addons/utils/SceneUtils.js';

Step-by-Step Implementation

To layer materials, define a base geometry, construct an array containing each material layer, pass them to SceneUtils.createMultiMaterialObject, and add the resulting group to your scene.

// 1. Define the geometry
const geometry = new THREE.BoxGeometry(2, 2, 2);

// 2. Define the layered materials
const materials = [
    // Base solid layer
    new THREE.MeshStandardMaterial({
        color: 0x156289,
        roughness: 0.4,
        metalness: 0.2
    }),
    // Transparent wireframe overlay layer
    new THREE.MeshBasicMaterial({
        color: 0xffffff,
        wireframe: true,
        transparent: true
    })
];

// 3. Create the multi-material group
const layeredObject = SceneUtils.createMultiMaterialObject(geometry, materials);

// 4. Add to scene and transform as needed
scene.add(layeredObject);
layeredObject.position.set(0, 0, 0);

Preventing Z-Fighting

When two opaque or semi-opaque surfaces occupy the exact same 3D coordinates, rendering artifacts known as "z-fighting" (flickering pixels) can occur.

To eliminate z-fighting when layering materials, apply polygon offsets to the outer material:

const wireframeMaterial = new THREE.MeshBasicMaterial({
    color: 0x000000,
    wireframe: true,
    polygonOffset: true,
    polygonOffsetFactor: 1, // Pushes geometry away from or toward the camera
    polygonOffsetUnits: 1
});

Practical Considerations

  • Draw Calls: Because createMultiMaterialObject generates a distinct mesh for each material in the array, each layer incurs a separate draw call. Use this technique intentionally to avoid performance bottlenecks in scenes with high object counts.
  • Disposal: When cleaning up resources, iterating over the parent group is required to dispose of both the individual materials and the shared geometry to prevent GPU memory leaks.
