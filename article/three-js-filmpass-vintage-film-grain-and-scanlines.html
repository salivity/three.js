Three.js FilmPass Vintage Film Grain and Scanlines

This guide covers how to set up post-processing in Three.js using the FilmPass shader to recreate retro visual aesthetics. By integrating Three.js's EffectComposer, you will learn how to initialize the pass, fine-tune parameters such as noise intensity, scanline count, and grayscale mode, and animate the grain inside your render loop for an authentic retro monitor or camera effect.

1. Import Post-Processing Modules

To use FilmPass, import the core post-processing modules alongside Three.js:

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { FilmPass } from 'three/addons/postprocessing/FilmPass.js';

2. Initialize EffectComposer and RenderPass

EffectComposer manages the chain of post-processing effects. First, pass your standard WebGL renderer to the composer, then add a RenderPass to capture your scene and camera.

const composer = new EffectComposer(renderer);

const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

3. Configure the FilmPass

The FilmPass constructor accepts four arguments that define the retro effect:

  1. noiseIntensity (float): Controls the strength of the film grain. Typical values range between 0.1 (subtle) and 0.8 (heavy grain).
  2. scanlineIntensity (float): Controls the visibility of horizontal monitor scanlines. Values between 0.05 and 0.5 work best for CRT simulation.
  3. scanlineCount (integer): Specifies the total number of horizontal scanlines across the screen. A value between 512 and 1024 yields a classic television look.
  4. grayscale (boolean): Set to true for monochrome black-and-white footage, or false to keep the original scene colors.
const noiseIntensity = 0.45;
const scanlineIntensity = 0.35;
const scanlineCount = 800;
const grayscale = false;

const filmPass = new FilmPass(
    noiseIntensity,
    scanlineIntensity,
    scanlineCount,
    grayscale
);

composer.addPass(filmPass);

You can also modify these values dynamically via the pass uniforms:

filmPass.uniforms.nIntensity.value = 0.6;   // Grain strength
filmPass.uniforms.sIntensity.value = 0.4;   // Scanline darkness
filmPass.uniforms.sCount.value = 1024;      // Number of scanlines
filmPass.uniforms.grayscale.value = false;  // Toggle monochrome

4. Animate the Grain in the Render Loop

To make the vintage grain move naturally rather than staying frozen, update the time uniform in your requestAnimationFrame loop using a clock delta, and call composer.render() instead of renderer.render().

const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();

    // Animate the film noise
    filmPass.uniforms.time.value += delta;

    // Render through the composer
    composer.render(delta);
}

animate();

5. Handle Screen Resizing

Ensure the composer and pass resize along with the browser window to maintain correct scanline density:

window.addEventListener('resize', () => {
    const width = window.innerWidth;
    const height = window.innerHeight;

    camera.aspect = width / height;
    camera.updateProjectionMatrix();

    renderer.setSize(width, height);
    composer.setSize(width, height);
});
