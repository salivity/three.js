Three.js AlphaMap: Make Black Pixels Transparent

In Three.js, an alphaMap allows you to control the opacity of a surface using a grayscale texture, where black areas become completely transparent and white areas remain fully opaque. To achieve this effect, you must assign the texture to the material's alphaMap property and explicitly enable transparency. This guide details the essential material settings, provides a working code example, and addresses common depth-sorting issues when rendering transparent textures.

1. Load the Grayscale Texture

An alphaMap uses a grayscale image where black (#000000 or RGB 0,0,0) corresponds to an alpha value of 0 (fully transparent), and white (#ffffff or RGB 255,255,255) corresponds to an alpha value of 1 (fully opaque). Load your image using THREE.TextureLoader.

import * as THREE from 'three';

const textureLoader = new THREE.TextureLoader();
const alphaTexture = textureLoader.load('path/to/mask.png');

2. Configure the Material

Assigning the texture to alphaMap alone is not enough. You must set transparent: true on the material. Without this flag, Three.js ignores all alpha calculations, and the object will render as completely opaque.

const material = new THREE.MeshStandardMaterial({
    color: 0xffffff,
    alphaMap: alphaTexture,
    transparent: true
});

const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

3. Handle Binary Transparency with alphaTest

If your texture has hard edges and only needs to be either 100% visible or 100% invisible (such as foliage, fences, or decals), use the alphaTest property.

Setting alphaTest tells the WebGL renderer to discard pixels below a certain alpha threshold rather than blending them. This prevents common depth sorting artifacts where transparent objects incorrectly occlude items behind them.

const material = new THREE.MeshStandardMaterial({
    color: 0xffffff,
    alphaMap: alphaTexture,
    transparent: true,
    alphaTest: 0.5 // Discards any pixel with an alpha lower than 0.5
});

4. Manage Depth Sorting for Smooth Gradients

If your alphaMap contains smooth gradients (semi-transparent values between pure black and pure white) instead of hard cutouts, do not use alphaTest. Instead, manage depth writing:

  • depthWrite: false: Prevents the semi-transparent object from writing to the depth buffer, ensuring objects behind it are drawn properly.
  • side: THREE.DoubleSide: Useful if the back of the geometry should also be visible through the transparent gaps.
const material = new THREE.MeshStandardMaterial({
    color: 0xffffff,
    alphaMap: alphaTexture,
    transparent: true,
    depthWrite: false,
    side: THREE.DoubleSide
});

Summary Checklist

  • Use an image with pure black pixels (#000000) for the areas that should disappear.
  • Set material.alphaMap = alphaTexture.
  • Always set material.transparent = true.
  • Use alphaTest: 0.1 to 0.5 for cutout textures to fix sorting issues.
  • Disable depthWrite: false if using smooth, semi-transparent gradients.
