Three.js Orthographic Camera Fixed Aspect Ratio

This article provides a concise guide on configuring an OrthographicCamera in Three.js so that 3D scenes retain a consistent aspect ratio without stretching or distorting when the browser window is resized. You will learn how to properly calculate the camera’s view frustum bounds based on window dimensions and how to update the projection matrix dynamically inside an event listener.

The Core Concept

Unlike a PerspectiveCamera, an OrthographicCamera defines its viewing volume with a box bounded by left, right, top, bottom, near, and far planes. If these plane values remain static while the canvas changes shape, the rendered scene stretches.

To maintain the correct aspect ratio and prevent distortion, define a fixed vertical (or horizontal) frustum size and compute the opposing bounds using the current window aspect ratio (window.innerWidth / window.innerHeight).

Implementation

1. Initialize the Camera

Choose a base frustumSize that dictates how many units fit vertically in the view. Use the window's aspect ratio to set the horizontal bounds:

import * as THREE from 'three';

const frustumSize = 10;
const aspect = window.innerWidth / window.innerHeight;

const camera = new THREE.OrthographicCamera(
  (frustumSize * aspect) / -2, // left
  (frustumSize * aspect) / 2,  // right
  frustumSize / 2,             // top
  frustumSize / -2,            // bottom
  0.1,                         // near
  1000                         // far
);

camera.position.set(0, 0, 10);

2. Update on Window Resize

Listen for the resize event. Update the camera frustum boundaries using the new aspect ratio, recompute the projection matrix, and adjust the renderer dimensions:

window.addEventListener('resize', onWindowResize);

function onWindowResize() {
  const aspect = window.innerWidth / window.innerHeight;

  // Update frustum bounds
  camera.left = (frustumSize * aspect) / -2;
  camera.right = (frustumSize * aspect) / 2;
  camera.top = frustumSize / 2;
  camera.bottom = frustumSize / -2;

  // Apply changes to the camera
  camera.updateProjectionMatrix();

  // Resize the renderer
  renderer.setSize(window.innerWidth, window.innerHeight);
}

Fixed Virtual Resolution (Letterboxing)

If the scene must strictly preserve an exact aspect ratio (such as 16:9) rather than expanding the field of view horizontally, maintain a target aspect ratio and adjust the renderer's viewport:

const targetAspect = 16 / 9;

function onWindowResize() {
  const width = window.innerWidth;
  const height = window.innerHeight;
  const currentAspect = width / height;

  let viewWidth, viewHeight;

  if (currentAspect > targetAspect) {
    // Window is wider than target
    viewHeight = height;
    viewWidth = height * targetAspect;
  } else {
    // Window is narrower than target
    viewWidth = width;
    viewHeight = width / targetAspect;
  }

  const xOffset = (width - viewWidth) / 2;
  const yOffset = (height - viewHeight) / 2;

  renderer.setSize(width, height);
  renderer.setViewport(xOffset, yOffset, viewWidth, viewHeight);
  renderer.setScissor(xOffset, yOffset, viewWidth, viewHeight);
  renderer.setScissorTest(true);

  camera.left = (frustumSize * targetAspect) / -2;
  camera.right = (frustumSize * targetAspect) / 2;
  camera.top = frustumSize / 2;
  camera.bottom = frustumSize / -2;
  camera.updateProjectionMatrix();
}

This ensures the camera's coordinates match the virtual viewport, preventing any non-uniform scaling while centering the output with black bars when the window dimensions deviate from the target aspect ratio.
