How to Use HemisphereLightHelper in Three.js

In Three.js, a HemisphereLight simulates ambient outdoor illumination by blending distinct colors from the sky and the ground. This article explains how to construct and use the HemisphereLightHelper to visually debug these lighting properties directly inside your 3D scene. You will learn the helper's constructor syntax, its parameters, and how to update its position alongside the light source.

Understanding the HemisphereLightHelper

The HemisphereLightHelper generates a wireframe geometry—typically shaped like a diamond or dual-colored sphere—at the light's position. One hemisphere reflects the light's sky color, while the opposing hemisphere reflects the ground color. This visual aid makes it easy to confirm the light's orientation, intensity, and color distribution without guessing.

Step 1: Create the HemisphereLight

Before creating the helper, instantiate and configure your HemisphereLight:

import * as THREE from 'three';

// Define sky color, ground color, and intensity
const skyColor = 0xb1e1ff;  // Light blue
const groundColor = 0xb97a20; // Brownish orange
const intensity = 1;

const hemisphereLight = new THREE.HemisphereLight(skyColor, groundColor, intensity);
hemisphereLight.position.set(0, 50, 0);
scene.add(hemisphereLight);

Step 2: Construct the Helper

The HemisphereLightHelper takes up to three arguments:

  • light (required): The THREE.HemisphereLight instance to visualize.
  • size (required): A number defining the radius of the helper mesh.
  • color (optional): An override color for the wireframe. If omitted, the helper automatically uses the sky and ground colors defined on the light source itself.

To let the helper visualize both the sky and ground colors accurately, omit the optional third argument:

// Create the helper with a size of 5 units
const helperSize = 5;
const lightHelper = new THREE.HemisphereLightHelper(hemisphereLight, helperSize);

// Add the helper to the scene
scene.add(lightHelper);

Step 3: Updating the Helper

If you animate or dynamically change the position, rotation, or colors of the HemisphereLight during runtime, you must invoke the helper's update method to keep the visualization synchronized:

function animate() {
    requestAnimationFrame(animate);

    // If the light's position or properties change
    hemisphereLight.position.x = Math.sin(Date.now() * 0.001) * 20;

    // Refresh the helper's geometry and alignment
    lightHelper.update();

    renderer.render(scene, camera);
}
animate();

Disposing of the Helper

When the helper is no longer needed, remove it from the scene and dispose of its internal resources to prevent memory leaks:

scene.remove(lightHelper);
lightHelper.dispose();
