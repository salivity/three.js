How to Set Snapping in Three.js TransformControls

This guide explains how to configure precise snapping increments for translation (positioning) and rotation using the TransformControls component in Three.js. By applying snapping properties, you can constrain 3D objects to move in fixed unit steps or rotate at specific angle intervals, which is critical for level editors, CAD tools, and grid-aligned scene design.

Translation Snapping

TransformControls provides both a method and a property for setting positional grid snapping. The value supplied represents the increment in Three.js world units.

You can set translation snapping using either setTranslationSnap() or by assigning a value directly to translationSnap:

// Snap movement to increments of 1 unit
transformControls.setTranslationSnap(1.0);

// Alternatively, set the property directly:
transformControls.translationSnap = 1.0;

When translation snapping is active, dragging the control handles along any axis will restrict object movement to multiples of the specified value.

Rotation Snapping

Rotation snapping defines the step angle for rotating an object around its axes. Three.js calculates rotation in radians, so degree values must be converted using THREE.MathUtils.degToRad().

You can set rotation snapping using setRotationSnap() or by assigning the property directly:

// Snap rotation to 15-degree increments
transformControls.setRotationSnap(THREE.MathUtils.degToRad(15));

// Snap rotation to 45-degree increments
transformControls.rotationSnap = THREE.MathUtils.degToRad(45);

Once set, rotating the object via the gizmo will jump between the specified radian intervals rather than rotating continuously.

Implementation Example

Below is a standard setup applying both translation and rotation snapping to an attached mesh:

import * as THREE from 'three';
import { TransformControls } from 'three/addons/controls/TransformControls.js';

// Initialize TransformControls
const controls = new TransformControls(camera, renderer.domElement);
scene.add(controls.getHelper());

// Attach to a target mesh
controls.attach(targetMesh);

// Configure snapping
controls.setTranslationSnap(0.5);                       // 0.5 unit intervals
controls.setRotationSnap(THREE.MathUtils.degToRad(90)); // 90 degree intervals

// Prevent camera controls from conflicting during drag
controls.addEventListener('dragging-changed', (event) => {
    orbitControls.enabled = !event.value;
});

Disabling Snapping

To return to smooth, continuous transformation without fixed steps, assign null to the snap methods or properties:

// Disable translation snapping
controls.setTranslationSnap(null);

// Disable rotation snapping
controls.setRotationSnap(null);
