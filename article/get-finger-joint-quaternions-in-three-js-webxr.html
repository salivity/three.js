Get Finger Joint Quaternions in Three.js WebXR

Extracting precise quaternion rotations of individual finger joints in Three.js requires utilizing the WebXR Hand Input API via Three.js’s built-in XR controller and hand management system. This guide demonstrates how to configure the WebXR manager, access joint data from the XRHand interface, and read both local and world-space THREE.Quaternion values for individual finger bones during each render frame.

1. Enable Hand Tracking in Three.js

Ensure your WebXR session requests the hand-tracking optional feature when initiating the XR session. In Three.js, you configure the renderer and retrieve the hand input sources:

import * as THREE from 'three';
import { XRHandModelFactory } from 'three/addons/webxr/XRHandModelFactory.js';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.xr.enabled = true;

// Retrieve hand controllers (0 for right/left, 1 for the other)
const hand0 = renderer.xr.getHand(0);
scene.add(hand0);

const hand1 = renderer.xr.getHand(1);
scene.add(hand1);

2. Accessing Individual Joint Objects

Three.js automatically maps the 25 standard WebXR joints to child Object3D instances inside the hand object. These joints are stored in the hand.joints dictionary, indexed by the standard WebXR joint names:

  • Thumb: thumb-metacarpal, thumb-phalanx-proximal, thumb-phalanx-distal, thumb-tip
  • Index: index-finger-metacarpal, index-finger-phalanx-proximal, index-finger-phalanx-intermediate, index-finger-phalanx-distal, index-finger-tip
  • Middle: middle-finger-metacarpal, middle-finger-phalanx-proximal, middle-finger-phalanx-intermediate, middle-finger-phalanx-distal, middle-finger-tip
  • Ring: ring-finger-metacarpal, ring-finger-phalanx-proximal, ring-finger-phalanx-intermediate, ring-finger-phalanx-distal, ring-finger-tip
  • Pinky: pinky-finger-metacarpal, pinky-finger-phalanx-proximal, pinky-finger-phalanx-intermediate, pinky-finger-phalanx-distal, pinky-finger-tip
  • Wrist: wrist

3. Extracting Joint Quaternions

During the animation loop, Three.js updates the transforms of these joint objects whenever tracking data is received. You can read the quaternion directly from the joint object.

const targetQuaternion = new THREE.Quaternion();

function getJointRotation(hand, jointName, useWorldSpace = false) {
  const joint = hand.joints[jointName];

  // Verify the joint exists and is currently tracked
  if (!joint || !joint.visible) {
    return null;
  }

  if (useWorldSpace) {
    // Returns orientation relative to the global scene
    return joint.getWorldQuaternion(targetQuaternion);
  } else {
    // Returns orientation relative to the hand root or parent bone
    return joint.quaternion;
  }
}

4. Implementation in the Render Loop

Place the extraction logic inside the setAnimationLoop callback to continuously monitor finger joint rotations:

const indexProximalQuat = new THREE.Quaternion();

renderer.setAnimationLoop(() => {
  if (renderer.xr.isPresenting) {
    const joint = hand0.joints['index-finger-phalanx-proximal'];

    if (joint && joint.visible) {
      // Get the precise world-space rotation
      joint.getWorldQuaternion(indexProximalQuat);

      // Access individual quaternion components
      const { x, y, z, w } = indexProximalQuat;
      
      // Perform required calculations or mapping here
    }
  }

  renderer.render(scene, camera);
});

5. Direct WebXR Frame Extraction (Alternative Low-Level Access)

If you bypass Three.js's joint graph and require direct raw WebXR orientations relative to the reference space:

renderer.setAnimationLoop((timestamp, frame) => {
  if (!frame) return;

  const referenceSpace = renderer.xr.getReferenceSpace();
  const session = renderer.xr.getSession();

  for (const inputSource of session.inputSources) {
    if (inputSource.hand) {
      const joint = inputSource.hand.get('index-finger-phalanx-proximal');
      if (joint) {
        const jointPose = frame.getJointPose(joint, referenceSpace);
        if (jointPose) {
          // Direct WebXR orientation as a DOMPointReadOnly
          const { x, y, z, w } = jointPose.transform.orientation;
          targetQuaternion.set(x, y, z, w);
        }
      }
    }
  }

  renderer.render(scene, camera);
});

Using hand.joints[jointName].getWorldQuaternion() handles coordinate system conversions between WebXR and Three.js automatically, making it the most robust method for standard scene interactions.
