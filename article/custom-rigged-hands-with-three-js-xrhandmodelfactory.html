Custom Rigged Hands with Three.js XRHandModelFactory

This guide explains how to dynamically bind and animate custom rigged 3D hand models to WebXR tracked hands in Three.js using XRHandModelFactory. By understanding how the factory parses skeleton hierarchies and joint data, you can replace default hand primitives with custom avatars while maintaining accurate real-time tracking across all 25 WebXR joint points.

Understanding WebXR Hand Joint Requirements

WebXR defines a standard hierarchy of 25 joints per hand, spanning from the wrist to the finger tips (metacarpals, phalanxes, and tips). For XRHandModelFactory to dynamically bind your custom rigged SkinnedMesh, your model must follow the WebXR skeleton specification:

  • Wrist: wrist
  • Thumb: thumb-metacarpal, thumb-phalanx-proximal, thumb-phalanx-distal, thumb-tip
  • Index: index-finger-metacarpal, index-finger-phalanx-proximal, index-finger-phalanx-intermediate, index-finger-phalanx-distal, index-finger-tip
  • Middle: middle-finger-metacarpal, middle-finger-phalanx-proximal, middle-finger-phalanx-intermediate, middle-finger-phalanx-distal, middle-finger-tip
  • Ring: ring-finger-metacarpal, ring-finger-phalanx-proximal, ring-finger-phalanx-intermediate, ring-finger-phalanx-distal, ring-finger-tip
  • Pinky: pinky-finger-metacarpal, pinky-finger-phalanx-proximal, pinky-finger-phalanx-intermediate, pinky-finger-phalanx-distal, pinky-finger-tip

Ensure that the bone names in your 3D asset (FBX/GLTF) match these identifiers exactly or follow the standard OpenXR bone hierarchy.

Configuring the Factory for Custom Assets

XRHandModelFactory utilizes XRHandMeshModel under the hood when the "mesh" profile is requested. By default, it retrieves generic GLTF assets from standard repositories. To point the factory to your custom rigged models, pass your custom path using setPath().

import * as THREE from 'three';
import { XRHandModelFactory } from 'three/examples/jsm/webxr/XRHandModelFactory.js';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

// 1. Initialize Loader and Factory
const gltfLoader = new GLTFLoader();
const handModelFactory = new XRHandModelFactory(gltfLoader);

// 2. Set the directory path where your custom left.glb and right.glb reside
handModelFactory.setPath('./assets/models/hands/');

When naming your files, ensure the directory contains left.glb and right.glb (or .gltf), as XRHandMeshModel internally builds the file URL based on hand handedness.

Initializing and Binding Hand Controllers

Attach the hand models generated by the factory to the WebXR hand instances managed by the renderer.

// Enable XR on the WebGLRenderer
renderer.xr.enabled = true;

// Setup Hand 0 (e.g., Left)
const hand0 = renderer.xr.getHand(0);
const handModel0 = handModelFactory.createHandModel(hand0, 'mesh');
hand0.add(handModel0);
scene.add(hand0);

// Setup Hand 1 (e.g., Right)
const hand1 = renderer.xr.getHand(1);
const handModel1 = handModelFactory.createHandModel(hand1, 'mesh');
hand1.add(handModel1);
scene.add(hand1);

When WebXR hand tracking connects, XRHandModelFactory fetches the custom model from your specified path, matches the bone names to the WebXR joint inputs, and begins copying bone transformations automatically on each render tick.

Dynamically Swapping a Rigged Mesh at Runtime

If your custom mesh uses non-standard bone names, or if you need to dynamically switch character hand meshes during a session without reloading assets from disk, you can bypass the default path loader and bind the bones manually within an event listener.

const handJoints = [
  'wrist',
  'thumb-metacarpal', 'thumb-phalanx-proximal', 'thumb-phalanx-distal', 'thumb-tip',
  'index-finger-metacarpal', 'index-finger-phalanx-proximal', 'index-finger-phalanx-intermediate', 'index-finger-phalanx-distal', 'index-finger-tip',
  'middle-finger-metacarpal', 'middle-finger-phalanx-proximal', 'middle-finger-phalanx-intermediate', 'middle-finger-phalanx-distal', 'middle-finger-tip',
  'ring-finger-metacarpal', 'ring-finger-phalanx-proximal', 'ring-finger-phalanx-intermediate', 'ring-finger-phalanx-distal', 'ring-finger-tip',
  'pinky-finger-metacarpal', 'pinky-finger-phalanx-proximal', 'pinky-finger-phalanx-intermediate', 'pinky-finger-phalanx-distal', 'pinky-finger-tip'
];

function applyCustomRig(hand, loadedGltfMesh) {
  const bones = [];
  
  // Cache the corresponding bones from the custom loaded GLTF
  handJoints.forEach(jointName => {
    const bone = loadedGltfMesh.getObjectByName(jointName);
    bones.push(bone);
  });

  // Attach mesh to the hand controller
  hand.add(loadedGltfMesh);

  // Update transformations on render loop
  hand.addEventListener('joint-tracking-updated', () => {
    for (let i = 0; i < handJoints.length; i++) {
      const joint = hand.joints[handJoints[i]];
      const targetBone = bones[i];

      if (joint && targetBone) {
        targetBone.position.copy(joint.position);
        targetBone.quaternion.copy(joint.quaternion);
      }
    }
  });
}

Considerations for Accuracy

  • Rest Pose (Bind Pose): Rig your 3D hand in the standard OpenXR bind pose (palm flat facing forward, fingers extended, thumb angled at roughly 45 degrees). Failing to match the standard rest pose causes rotated or distorted fingers during runtime tracking.
  • Scale: Ensure hand scale is exported at a 1:1 metric scale (1 unit = 1 meter), as WebXR joint offsets represent real-world physical distances.
