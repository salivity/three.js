Using setDrawRange on Indexed BufferGeometry in Three.js

This article explains how to use the setDrawRange method in Three.js to render a specific subset of an indexed BufferGeometry. You will learn how setDrawRange interacts directly with the geometry's index buffer, how to configure the start and count parameters, and how to apply this technique for progressive rendering, visual effects, and performance optimization.

Understanding Indexed BufferGeometry and setDrawRange

In Three.js, a BufferGeometry can be either non-indexed or indexed. In a non-indexed geometry, vertex attributes define faces sequentially. In an indexed geometry, a separate index buffer (geometry.index) contains pointers to the vertices stored in the attribute arrays, allowing vertices to be reused across multiple faces.

The setDrawRange(start, count) method controls which primitives are sent to the GPU for rendering:

  • start: The integer offset in the index buffer from which rendering begins.
  • count: The total number of indices to render.

When applied to an indexed BufferGeometry, setDrawRange targets the indices, not the raw vertex array elements.

Step-by-Step Implementation

1. Create or Obtain an Indexed Geometry

Standard primitives like THREE.PlaneGeometry or THREE.BoxGeometry are indexed by default. You can also create a custom indexed geometry:

import * as THREE from 'three';

// Create an indexed plane geometry (10 segments wide, 10 segments high)
const geometry = new THREE.PlaneGeometry(10, 10, 10, 10);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00, wireframe: true });
const mesh = new THREE.Mesh(geometry, material);

2. Determine Index Count and Multiples

Because standard 3D meshes are composed of triangles, every individual face requires three indices. When calculating the start and count values:

  • start should generally be a multiple of 3 to avoid beginning mid-triangle.
  • count should be a multiple of 3 to ensure complete triangles are drawn.

You can inspect the total number of available indices using:

const totalIndices = geometry.index.count;

3. Apply setDrawRange

To render only the first half of the geometry, set the start to 0 and specify the subset of indices:

// Render only the first 60 indices (20 triangles)
const startIndex = 0;
const indexCount = 60;

geometry.setDrawRange(startIndex, indexCount);

To render an arbitrary window of faces from the middle of the geometry:

// Skip the first 30 indices (10 triangles) and draw the next 90 indices (30 triangles)
geometry.setDrawRange(30, 90);

To reset the draw range and render the entire mesh again:

geometry.setDrawRange(0, geometry.index.count);

Dynamic Usage and Animation

setDrawRange does not modify the underlying buffer data on the GPU; it simply updates the draw parameters passed during the draw call. This makes it an efficient method for animating geometry visibility, such as progressively revealing a mesh over time:

let currentIndices = 0;
const totalIndices = geometry.index.count;
const indicesPerFrame = 6; // Adds 2 triangles per frame

function animate() {
    requestAnimationFrame(animate);

    if (currentIndices < totalIndices) {
        currentIndices = Math.min(currentIndices + indicesPerFrame, totalIndices);
        geometry.setDrawRange(0, currentIndices);
    }

    renderer.render(scene, camera);
}
animate();

Key Considerations

  • No Buffer Re-uploading Needed: Changing setDrawRange does not require setting geometry.index.needsUpdate = true because the buffer contents remain unchanged.
  • Bounding Volumes: geometry.computeBoundingBox() and geometry.computeBoundingSphere() compute limits based on the full vertex set, not the range defined by setDrawRange. If accurate frustum culling is needed for small subsets, update mesh.geometry.boundingSphere manually.
  • Raycasting: Three.js raycasting takes drawRange into account for indexed geometries, meaning intersections will only register on the visible portion of the mesh.
