Render Background Scene with Three.js RenderPass

Rendering a distinct background behind a primary Three.js scene requires setting up two independent scene graphs and sequencing them using RenderPass within an EffectComposer. This guide demonstrates how to configure separate background and foreground scenes with their respective cameras, chain multiple render passes, and prevent the foreground pass from overwriting the background buffer to achieve a seamless layered composition.

Core Concept

By default, a RenderPass clears the color, depth, and stencil buffers before rendering its assigned scene and camera. To display a secondary scene behind the main scene using the post-processing pipeline, you must:

  1. Create a background scene and a main scene.
  2. Create a RenderPass for the background scene that clears the canvas as normal.
  3. Create a secondary RenderPass for the main scene with its clear property set to false, allowing it to draw directly over the background.

Step-by-Step Implementation

1. Set Up Scenes, Cameras, and Renderer

Create instances for both scenes, their corresponding cameras, and the WebGL renderer. An orthographic camera is often used for static 2D backgrounds, while a perspective camera handles the 3D main scene.

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';

// Renderer
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.autoClear = false; // Prevent automatic clearing between passes
document.body.appendChild(renderer.domElement);

// Background Scene and Camera
const backgroundScene = new THREE.Scene();
const backgroundCamera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1);

// Main Scene and Camera
const mainScene = new THREE.Scene();
const mainCamera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);
mainCamera.position.z = 5;

2. Populate the Scenes

Add the background elements (such as a full-screen quad, gradient plane, or distant skybox) to the backgroundScene, and your interactive 3D assets to the mainScene.

// Background plane (covers the entire normalized device coordinate space)
const bgGeometry = new THREE.PlaneGeometry(2, 2);
const bgMaterial = new THREE.MeshBasicMaterial({ color: 0x1a2634 });
const bgMesh = new THREE.Mesh(bgGeometry, bgMaterial);
backgroundScene.add(bgMesh);

// Main 3D content
const cubeGeometry = new THREE.BoxGeometry();
const cubeMaterial = new THREE.MeshNormalMaterial();
const cube = new THREE.Mesh(cubeGeometry, cubeMaterial);
mainScene.add(cube);

3. Configure EffectComposer and RenderPasses

Instantiate the EffectComposer and attach the passes in execution order. The critical configuration is setting mainPass.clear = false and disabling the depth buffer clear on the second pass only if you want depth testing to persist.

const composer = new EffectComposer(renderer);

// First pass: Background scene
const backgroundPass = new RenderPass(backgroundScene, backgroundCamera);
backgroundPass.clear = true; // Clears the canvas before drawing the background
composer.addPass(backgroundPass);

// Second pass: Main scene
const mainPass = new RenderPass(mainScene, mainCamera);
mainPass.clear = false; // Retains the background image
mainPass.clearDepth = true; // Resets depth so main objects do not clip against background elements
composer.addPass(mainPass);

4. The Animation Loop

Replace the standard renderer.render() call in your animation loop with composer.render().

function animate() {
  requestAnimationFrame(animate);

  // Rotate the main scene object
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  // Render both passes sequentially
  composer.render();
}

animate();

Handling Window Resizing

When updating viewport dimensions, ensure both cameras and the composer are updated:

window.addEventListener('resize', () => {
  const width = window.innerWidth;
  const height = window.innerHeight;

  mainCamera.aspect = width / height;
  mainCamera.updateProjectionMatrix();

  renderer.setSize(width, height);
  composer.setSize(width, height);
});

Using this architecture, subsequent post-processing shaders (such as bloom, film grain, or color correction) added to the EffectComposer will process the combined composition of both the background and main scenes simultaneously.
