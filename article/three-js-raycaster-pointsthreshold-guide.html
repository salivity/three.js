Three.js Raycaster pointsThreshold Guide

Interacting with small particles or point clouds in Three.js can be frustrating for users because clicking on a zero-dimensional or sub-pixel point requires extreme precision. This article explains how to increase the interaction hit area of particle systems using the raycaster's point threshold setting, making small points significantly easier to detect, hover over, and click.

The Challenge of Point Picking

When rendering a particle system using THREE.Points, each particle exists mathematically at a single coordinate in 3D space. When a user clicks, a THREE.Raycaster casts an infinite line from the camera through the mouse coordinates into the scene. Because points have no inherent volume or geometric surface area, a standard geometric intersection will almost always fail unless the ray passes directly through the exact coordinate of the particle.

Adjusting the Threshold

To solve this issue, Three.js provides a tolerance setting specifically for point objects. This property is accessed via raycaster.params.Points.threshold.

The threshold value acts as a buffer distance around the ray. Instead of requiring the ray to directly strike the point, the raycaster checks if the distance between the ray and the point falls within this defined threshold. If the distance is less than or equal to the threshold, an intersection is registered.

Implementation Example

To apply a custom threshold, configure the params.Points.threshold property on your raycaster instance before calculating intersections:

import * as THREE from 'three';

// 1. Initialize raycaster and mouse vector
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

// 2. Set the threshold for Points (in world units)
raycaster.params.Points.threshold = 0.5;

// 3. Update mouse coordinates on pointer event
function onPointerDown(event) {
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

  // 4. Update the ray with camera and mouse position
  raycaster.setFromCamera(mouse, camera);

  // 5. Intersect your points object

  if (intersects.length > 0) {
    // Returns the closest intersected particle
    const hitParticle = intersects[0];
    console.log('Particle index clicked:', hitParticle.index);
    console.log('Distance from ray:', hitParticle.distanceToRay);
  }
}

window.addEventListener('pointerdown', onPointerDown);

Best Practices for Choosing a Value

  • Scale in World Units: The threshold value is evaluated in world units, not screen pixels. The visual size of the hit zone will scale according to the distance from the camera when using a perspective camera.
  • Avoid Overlaps: If the threshold is set too high in dense point clouds, a single click may register multiple overlapping points, leading to unintended selections.
  • Sorting by Distance: When an intersection occurs, the intersects array contains all points within the threshold radius. The array is sorted by distance to the camera by default. Inspect intersects[0].distanceToRay if you want to find the particle closest to the cursor line rather than closest to the camera.
