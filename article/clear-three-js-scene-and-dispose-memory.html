Clear Three.js Scene and Dispose Memory

Properly clearing a Three.js scene requires more than just removing objects from the hierarchy; it demands releasing GPU-allocated resources to prevent severe memory leaks. This article provides an efficient, single recursive function designed to traverse a scene, dispose of geometries, materials, and textures, and safely unmount all child elements from memory.

The Memory Challenge in Three.js

In Three.js, calling scene.remove(object) only detaches the object from the CPU-side scene graph. WebGL entities—specifically geometries, materials, and textures—remain allocated directly in GPU memory until their explicit .dispose() methods are invoked. Failing to release these resources will lead to memory bloat and eventual WebGL context crashes.

The Recursive Disposal Function

The most reliable approach is a post-order recursive function that walks down to the deepest leaf nodes first, cleans up their WebGL assets, removes them from their parent, and ascends back up to the root.

function disposeHierarchy(node, canDisposeSelf = false) {
  // Recursively process all children backwards to avoid index shifting
  for (let i = node.children.length - 1; i >= 0; i--) {
    disposeHierarchy(node.children[i], true);
  }

  // Dispose of geometry
  if (node.geometry) {
    node.geometry.dispose();
  }

  // Dispose of material(s) and associated textures
  if (node.material) {
    const cleanMaterial = (material) => {
      // Dispose all active textures assigned to material properties
      for (const key of Object.keys(material)) {
        const value = material[key];
        if (value && typeof value === 'object' && 'minFilter' in value) {
          value.dispose();
        }
      }
      material.dispose();
    };

    if (Array.isArray(node.material)) {
      node.material.forEach(cleanMaterial);
    } else {
      cleanMaterial(node.material);
    }
  }

  // Remove the node from its parent
  if (canDisposeSelf && node.parent) {
    node.parent.remove(node);
  }
}

How It Works

  1. Reverse Traversal: Iterating backwards over node.children (length - 1 down to 0) ensures that removing children from the array during iteration does not skip adjacent elements or cause index-shifting bugs.
  2. Geometry Deallocation: Checks if node.geometry exists and calls its .dispose() method to free vertex buffers, attribute arrays, and index buffers on the GPU.
  3. Material and Texture Cleanup: Handles both single material assignments and multi-material arrays. It checks the material properties for textures (identified by the standard Three.js texture property minFilter) and invokes .dispose() on each texture before finally disposing of the material shader program itself.
  4. Parent Detachment: The canDisposeSelf flag ensures that child nodes are removed from the scene graph via node.parent.remove(node) while leaving the top-level Scene container intact for reuse.

Usage

To wipe the entire scene clean while keeping the root scene instance ready for new objects:

// Clear all assets and children from the scene
disposeHierarchy(scene, false);

// Optional: Inform the renderer to reset state
renderer.renderLists.dispose();
