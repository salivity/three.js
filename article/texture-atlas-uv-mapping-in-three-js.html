Texture Atlas UV Mapping in Three.js

Using a single texture atlas across multiple geometries in Three.js significantly reduces draw calls and improves WebGL rendering performance. This article explains how to map distinct regions of a texture atlas to different geometries by directly reading and recalculating the UV coordinate buffer attributes within THREE.BufferGeometry.

Understanding the Atlas Coordinate System

A UV coordinate space spans normalized values from (0.0, 0.0) at the bottom-left to (1.0, 1.0) at the top-right. When packing multiple sub-textures into an atlas, each individual sub-image occupies a bounding box defined by:

  • uMin: The horizontal starting position (0.0 to 1.0)
  • vMin: The vertical starting position (0.0 to 1.0)
  • width: The width of the tile relative to the atlas (uMax - uMin)
  • height: The height of the tile relative to the atlas (vMax - vMin)

To map standard geometry UV coordinates \((U_{local}, V_{local})\), which normally range from 0 to 1, to a specific tile in the atlas, use the linear transformation formula:

\[U_{atlas} = uMin + (U_{local} \times width)\] \[V_{atlas} = vMin + (V_{local} \times height)\]

Step-by-Step Implementation

Because modifying buffer attributes changes vertex data in-place, each mesh requiring a unique sub-texture must use an independent instance of THREE.BufferGeometry.

1. Define the Atlas Frame Data

Identify the pixel dimensions of your atlas and the bounds of each sub-texture:

const atlasWidth = 1024;
const atlasHeight = 1024;

// Coordinates for a 256x256 sub-texture located at pixel (256, 512)
const frame = {
  x: 256,
  y: 512,
  w: 256,
  h: 256
};

// Normalize to 0.0 - 1.0 range
// Note: In Three.js, V=0 is at the bottom. If the frame data Y is from the top, invert it.
const uMin = frame.x / atlasWidth;
const vMin = (atlasHeight - frame.y - frame.h) / atlasHeight;
const tileWidth = frame.w / atlasWidth;
const tileHeight = frame.h / atlasHeight;

2. Mutate the Geometry UV Buffer

Access the uv attribute array from the geometry, iterate through its pairs of vertex coordinates, and map them to the atlas sub-rectangle:

function applyUVOffset(geometry, uMin, vMin, tileWidth, tileHeight) {
  const uvAttribute = geometry.attributes.uv;
  const count = uvAttribute.count;

  for (let i = 0; i < count; i++) {
    // Read base local coordinates
    const u = uvAttribute.getX(i);
    const v = uvAttribute.getY(i);

    // Calculate atlas mapped coordinates
    const mappedU = uMin + u * tileWidth;
    const mappedV = vMin + v * tileHeight;

    // Write transformed values back to the attribute
    uvAttribute.setXY(i, mappedU, mappedV);
  }

  // Flag the attribute for update by WebGL
  uvAttribute.needsUpdate = true;
}

3. Assemble and Apply to Geometries

Clone the base geometry for each instance so that individual UV modifications do not override one another:

import * as THREE from 'three';

const textureLoader = new THREE.TextureLoader();
const atlasTexture = textureLoader.load('path/to/atlas.png');
const sharedMaterial = new THREE.MeshBasicMaterial({ map: atlasTexture });

// Define geometries
const baseGeometry = new THREE.PlaneGeometry(1, 1);

// Geometry 1
const geom1 = baseGeometry.clone();
applyUVOffset(geom1, 0.0, 0.5, 0.5, 0.5); // Top-left quadrant
const mesh1 = new THREE.Mesh(geom1, sharedMaterial);
mesh1.position.x = -1.2;

// Geometry 2
const geom2 = baseGeometry.clone();
applyUVOffset(geom2, 0.5, 0.0, 0.5, 0.5); // Bottom-right quadrant
const mesh2 = new THREE.Mesh(geom2, sharedMaterial);
mesh2.position.x = 1.2;

scene.add(mesh1);
scene.add(mesh2);

Considerations

  • Bleeding Artifacts: Texture filtering (linear or mipmapping) can sample pixels across adjacent atlas tiles. Prevent bleeding by leaving a 1-to-2-pixel transparent padding between packed textures or setting atlasTexture.minFilter = THREE.NearestFilter.
  • Complex Geometries: For multi-faced shapes like THREE.BoxGeometry, the default UV buffer repeats the 0-to-1 range for each face. The transformation function maps all faces to the specified atlas frame automatically. If distinct faces require different atlas regions, iterate through the buffer in index steps corresponding to each face (typically 4 vertices or 6 indices per rectangular face).
