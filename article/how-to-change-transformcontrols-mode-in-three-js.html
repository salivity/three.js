How to Change TransformControls Mode in Three.js

Dynamically changing the mode of TransformControls in Three.js allows users to switch between translating, rotating, and scaling 3D objects in real time. This guide demonstrates how to configure TransformControls, use the built-in setMode() method, and implement runtime event listeners—such as keyboard shortcuts or UI buttons—to toggle between interaction states seamlessly.

Understanding the setMode() Method

The TransformControls class provides a dedicated method called setMode() to modify its current gizmo behavior. It accepts a single string parameter representing one of the three valid transformation modes:

  • "translate" – Displays arrows to move the object along the X, Y, and Z axes.
  • "rotate" – Displays circular rings to rotate the object around the axes.
  • "scale" – Displays cube-ended handles to resize the object.
// Switching modes directly
transformControls.setMode('translate');
transformControls.setMode('rotate');
transformControls.setMode('scale');

Implementing Dynamic Switching with Keyboard Shortcuts

A standard approach in 3D applications (such as Blender or Unity) is mapping the "W", "E", and "R" keys to translation, rotation, and scaling.

Here is the complete implementation for attaching TransformControls and setting up a keydown event listener:

import * as THREE from 'three';
import { TransformControls } from 'three/examples/jsm/controls/TransformControls.js';

// 1. Initialize TransformControls
const transformControls = new TransformControls(camera, renderer.domElement);
scene.add(transformControls);

// 2. Attach to a target mesh
transformControls.attach(targetMesh);

// 3. Listen for keydown events to swap modes dynamically
window.addEventListener('keydown', (event) => {
  switch (event.key.toLowerCase()) {
    case 'w':
      transformControls.setMode('translate');
      break;
    case 'e':
      transformControls.setMode('rotate');
      break;
    case 'r':
      transformControls.setMode('scale');
      break;
  }
});

Connecting to UI Buttons

If your application uses HTML buttons or a GUI library like lil-gui, bind the click handlers directly to setMode():

document.getElementById('translate-btn').addEventListener('click', () => {
  transformControls.setMode('translate');
});

document.getElementById('rotate-btn').addEventListener('click', () => {
  transformControls.setMode('rotate');
});

document.getElementById('scale-btn').addEventListener('click', () => {
  transformControls.setMode('scale');
});

Preventing OrbitControls Conflicts

When swapping modes and interacting with the gizmos while using OrbitControls, camera movements can conflict with transformation drags. Disable OrbitControls whenever a drag event starts and re-enable it when the drag ends:

transformControls.addEventListener('dragging-changed', (event) => {
  orbitControls.enabled = !event.value;
});

This ensures that clicking and dragging the gizmo in any mode only transforms the object without moving the camera perspective.
