How Box3.expandByObject Works in Three.js

In Three.js, Box3.expandByObject calculates the minimum and maximum coordinates of an axis-aligned bounding box (AABB) that completely encloses an Object3D and all of its descendants in world space. It accomplishes this by traversing the scene graph hierarchy recursively, ensuring world transformation matrices are synchronized, evaluating each node's underlying geometry, and expanding the boundary to include every transformed vertex or sub-bounding volume.

1. Matrix Synchronization and Recursive Traversal

When expandByObject(object, precise) is called, it begins by updating the local and world transformation matrices of the target object using object.updateWorldMatrix(false, false). This ensures that any changes to translation, rotation, or scale across the parent chain are accurately reflected in the node's matrixWorld.

The method then processes the current object and iterates over its children array. For every child in the collection, expandByObject calls itself recursively:

const children = object.children;
for (let i = 0, l = children.length; i < l; i++) {
  this.expandByObject(children[i], precise);
}

This depth-first traversal ensures that nested groups, parent-child offsets, and deep hierarchies are fully accounted for, accumulating bounds into a single shared Box3 instance.

2. Geometry Evaluation and Vertex Transformation

For each visited node that contains a geometry property (such as Mesh, Line, or Points), the method integrates the geometry's spatial coordinates into the bounding box. The method supports two computation paths depending on the precise boolean flag:

Standard Mode (precise = false)

By default, the method optimizes for performance by using the geometry's precomputed local AABB (geometry.boundingBox):

  1. If the local bounding box does not yet exist, it computes it once via geometry.computeBoundingBox().
  2. It clones this local box and transforms it directly by the object's matrixWorld.
  3. The transformed box is merged into the current Box3 instance using this.union(transformedBox).

Note: Transforming an already axis-aligned box by a rotation matrix can result in a bounding box that is slightly larger than the actual geometry volume, but it requires significantly fewer calculations.

Precise Mode (precise = true)

When higher accuracy is required, passing true forces the method to read individual vertex coordinates directly from geometry.attributes.position:

  1. It loops through every vector in the position attribute buffer.
  2. It applies the node's matrixWorld directly to each individual vertex coordinate vector.
  3. It expands the main bounding box point by point using this.expandByPoint(transformedVertex).

This produces the tightest possible world-space AABB for rotated or non-uniformly scaled geometries at the expense of extra CPU processing time.

3. Cumulative Boundary Expansion

The internal expansion mechanism tracks two internal vectors: min and max. As points or bounding volumes are incorporated, the coordinates are updated:

  • min.x = Math.min(min.x, point.x)
  • min.y = Math.min(min.y, point.y)
  • min.z = Math.min(min.z, point.z)
  • max.x = Math.max(max.x, point.x)
  • max.y = Math.max(max.y, point.y)
  • max.z = Math.max(max.z, point.z)

Once the recursive call stack completes and all child branches are resolved, the calling Box3 contains the absolute minimum and maximum world-space coordinates enclosing the entire object tree.
