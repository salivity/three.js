Detect Drag Start in Three.js DragControls

This guide demonstrates how to attach an event listener to a Three.js DragControls instance to detect drag start events. By leveraging the built-in 'dragstart' event type, you can detect when a user initiates a drag gesture, modify the active object's properties, and coordinate with other controls such as OrbitControls to prevent input conflicts.

Setting Up DragControls

To capture interaction events, you first instantiate DragControls by passing an array of interactive 3D meshes, the active camera, and the renderer’s DOM element.

import * as THREE from 'three';
import { DragControls } from 'three/addons/controls/DragControls.js';

// Setup objects, camera, and renderer
const objects = [mesh1, mesh2, mesh3];
const dragControls = new DragControls(objects, camera, renderer.domElement);

Attaching the 'dragstart' Event Listener

DragControls extends the Three.js EventDispatcher, which provides the standard addEventListener method. To detect when dragging begins, register a callback function with the 'dragstart' event string:

dragControls.addEventListener('dragstart', function (event) {
    // Access the specific object being dragged
    const draggedObject = event.object;

    console.log('Drag started on:', draggedObject);
});

Common Implementations on Drag Start

1. Disabling OrbitControls

When using OrbitControls simultaneously, camera rotation can conflict with object dragging. Disable OrbitControls immediately upon drag start:

dragControls.addEventListener('dragstart', function (event) {
    orbitControls.enabled = false;
});

dragControls.addEventListener('dragend', function (event) {
    orbitControls.enabled = true;
});

2. Visual Feedback

You can alter the appearance of an object to indicate that it is actively being manipulated:

dragControls.addEventListener('dragstart', function (event) {
    // Store original color or state
    event.object.userData.originalColor = event.object.material.color.getHex();
    
    // Highlight the object
    event.object.material.color.setHex(0xffaa00);
});

Removing the Event Listener

If you dynamically destroy objects or need to unbind interactions to prevent memory leaks, use removeEventListener:

function onDragStart(event) {
    console.log('Dragging:', event.object);
}

// Add listener
dragControls.addEventListener('dragstart', onDragStart);

// Remove listener
dragControls.removeEventListener('dragstart', onDragStart);
