Three.js Wireframe and Solid Fill with SceneUtils

Rendering both a solid surface and an overlaid wireframe on a single 3D geometry is a common requirement in Three.js visualizations. This guide explains how to use the SceneUtils.createMultiMaterialObject utility to combine multiple materials on identical geometry, walking through module imports, material definition, z-fighting prevention, and adding the composite object to your scene.

Understanding SceneUtils.createMultiMaterialObject

In modern Three.js, a standard THREE.Mesh accepts an array of materials only when the underlying geometry has defined groups (typically for multi-sided cube textures). It cannot render multiple full-coverage materials over the exact same faces simultaneously.

To overcome this, SceneUtils.createMultiMaterialObject takes a single geometry and an array of materials, creating a THREE.Group containing a distinct THREE.Mesh for each material provided. This allows you to stack a wireframe mesh directly over a solid fill mesh while managing them as a single object.

Implementation Steps

1. Import the Utility

SceneUtils is an add-on and must be imported from the addons directory alongside core Three.js.

import * as THREE from 'three';
import { SceneUtils } from 'three/addons/utils/SceneUtils.js';

2. Create the Geometry

Define the geometry you want to render.

const geometry = new THREE.BoxGeometry(2, 2, 2);

3. Define the Solid and Wireframe Materials

Create two materials: one for the solid surface and one for the wireframe. When layering meshes in the same spatial coordinates, depth-buffer precision issues (z-fighting) can occur. To eliminate flickering, apply polygonOffset properties to the solid material.

// Solid fill material
const solidMaterial = new THREE.MeshStandardMaterial({
    color: 0x156289,
    roughness: 0.4,
    metalness: 0.2,
    polygonOffset: true,
    polygonOffsetFactor: 1, // Push the solid mesh back slightly
    polygonOffsetUnits: 1
});

// Wireframe material
const wireframeMaterial = new THREE.MeshBasicMaterial({
    color: 0xffffff,
    wireframe: true
});

const materials = [solidMaterial, wireframeMaterial];

4. Generate and Add the Multi-Material Object

Pass the geometry and materials array to SceneUtils.createMultiMaterialObject, then add the returned group to your scene.

const multiMaterialObject = SceneUtils.createMultiMaterialObject(geometry, materials);

scene.add(multiMaterialObject);

Manipulating the Resulting Object

Because SceneUtils.createMultiMaterialObject returns a THREE.Group, transformations such as position, rotation, and scale apply uniformly to both the solid and wireframe layers:

// Transform both layers simultaneously
multiMaterialObject.position.set(0, 1, 0);
multiMaterialObject.rotation.y = Math.PI / 4;

// Access individual meshes if needed
const solidMesh = multiMaterialObject.children[0];
const wireframeMesh = multiMaterialObject.children[1];
