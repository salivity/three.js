Three.js PositionalAudio PannerNode Configuration

In Three.js, spatial audio attenuation is governed by the Web Audio API's PannerNode, which is wrapped by the THREE.PositionalAudio object. By configuring parameters such as the distance model, reference distance, maximum distance, and rolloff factor, you can explicitly define how sound volume decreases as the listener moves away from the audio source. This article demonstrates how to access and configure these panner node settings directly and via Three.js helper methods to control spatial drop-off in your 3D scene.

Key Drop-Off Properties

Spatial drop-off in the Web Audio API is controlled by four core properties on the PannerNode:

  • distanceModel: Defines the algorithm used to calculate volume reduction over distance. Supported values are 'linear', 'inverse' (default), and 'exponential'.
  • refDistance: The distance from the listener at which the volume begins to attenuate. At this distance or closer, the audio plays at full volume.
  • maxDistance: The maximum distance between the audio source and the listener. In a 'linear' model, audio reaches zero volume here. In 'inverse' and 'exponential' models, volume reduction stops attenuating past this point.
  • rolloffFactor: Determines how rapidly the sound volume decreases as the listener moves away from the source. A higher value causes a steeper drop-off.

Method 1: Using PositionalAudio Helper Methods

Three.js provides native wrapper methods directly on the PositionalAudio instance. This is the cleanest and most common approach to configure attenuation.

import * as THREE from 'three';

// Initialize listener and positional audio
const listener = new THREE.AudioListener();
camera.add(listener);

const sound = new THREE.PositionalAudio(listener);

// Configure the panner parameters via Three.js methods
sound.setDistanceModel('linear');
sound.setRefDistance(1);
sound.setMaxDistance(50);
sound.setRolloffFactor(2);

// Attach sound to a mesh
mesh.add(sound);

Method 2: Direct PannerNode Property Assignment

If you need full control over lower-level Web Audio API features, you can access the underlying PannerNode directly via the .panner property of the PositionalAudio object.

const sound = new THREE.PositionalAudio(listener);

// Access the native Web Audio API PannerNode directly
sound.panner.distanceModel = 'exponential';
sound.panner.refDistance = 2;
sound.panner.maxDistance = 100;
sound.panner.rolloffFactor = 1.5;

// Optional: Define directional sound cones
sound.panner.coneInnerAngle = 60;
sound.panner.coneOuterAngle = 120;
sound.panner.coneOuterGain = 0.1;

Choosing the Right Distance Model

  • Linear ('linear'): Volume drops at a constant rate between refDistance and maxDistance. Best for simple game mechanics where sound must definitively cut off at a specific boundary.
  • Inverse ('inverse'): Mimics real-world sound propagation where volume halves as distance doubles. Best for realistic outdoor and ambient environments.
  • Exponential ('exponential'): Causes a sharp initial drop-off that tapers out slowly. Ideal for small, localized sounds like whispering or ticking clocks that should fade quickly when stepping away.
