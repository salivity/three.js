Transition Perspective to Orthographic Camera in Three.js

Switching between a PerspectiveCamera and an OrthographicCamera in Three.js without jarring the user requires matching the visible dimensions of both cameras at a specific focal distance. This article explains the mathematics behind aligning their view frustums, demonstrates how to synchronize transforms and controls, and details how to animate a seamless visual transition using a dolly-zoom approach or projection matrix interpolation.

Understanding the Frustum Mismatch

A PerspectiveCamera renders scenes with perspective distortion based on a vertical field of view (fov), where objects appear smaller the further they are from the lens. An OrthographicCamera projects parallel rays, meaning an object's screen size remains constant regardless of distance.

To make the transition seamless, you must choose a focal plane—usually the target of your camera controls (such as an OrbitControls target)—and calculate the orthographic frustum so that it covers the exact visible height and width of the perspective camera at that specific distance.

Step 1: Calculate the Matching Frustum Bounds

At a given distance \(d\) from the perspective camera to the target, the visible height \(H\) is defined by:

\[H = 2 \times d \times \tan\left(\frac{\text{fov} \times \pi}{360}\right)\]

The visible width \(W\) depends on the aspect ratio:

\[W = H \times \text{aspect}\]

Use this calculation to configure the orthographic camera's frustum:

function syncOrthographicCamera(perspectiveCam, orthoCam, targetPosition) {
  const distance = perspectiveCam.position.distanceTo(targetPosition);
  const aspect = perspectiveCam.aspect;
  
  // Calculate visible half-height and half-width at the target distance
  const fovInRadians = THREE.MathUtils.degToRad(perspectiveCam.fov);
  const halfHeight = Math.tan(fovInRadians / 2) * distance;
  const halfWidth = halfHeight * aspect;

  // Set orthographic bounds
  orthoCam.left = -halfWidth;
  orthoCam.right = halfWidth;
  orthoCam.top = halfHeight;
  orthoCam.bottom = -halfHeight;

  // Synchronize transforms
  orthoCam.position.copy(perspectiveCam.position);
  orthoCam.quaternion.copy(perspectiveCam.quaternion);
  orthoCam.zoom = 1;

  orthoCam.updateProjectionMatrix();
}

Step 2: Animating the Transition

An instant switch using the synchronized frustum produces an identical view of objects located precisely on the target plane, but objects in front of or behind that plane will instantly jump due to the sudden removal or addition of perspective distortion. To make this change visually continuous, animate the perspective camera using a modified dolly zoom before swapping cameras.

The Dolly Zoom Approach

  1. Perspective to Orthographic: Animate the perspective camera's fov down toward a very low value (e.g., from 50 down to 4 or 5), while simultaneously moving the camera backward to keep the target plane's size constant. Once the fov is minimal, switch to the OrthographicCamera.

  2. Orthographic to Perspective: Place the perspective camera far away with the minimal fov, swap the active camera, and animate the fov back to its original value while moving the camera inward to its original position.

import gsap from 'gsap';

function transitionToOrtho(perspectiveCam, orthoCam, controls, onComplete) {
  const target = controls.target;
  const initialDistance = perspectiveCam.position.distanceTo(target);
  const initialFov = perspectiveCam.fov;
  const targetFov = 4; // Near-orthographic angle

  // Direction vector from target to camera
  const direction = new THREE.Vector3()
    .subVectors(perspectiveCam.position, target)
    .normalize();

  const animState = { fov: initialFov };

  gsap.to(animState, {
    fov: targetFov,
    duration: 1.0,
    ease: "power2.inOut",
    onUpdate: () => {
      perspectiveCam.fov = animState.fov;

      // Compensate position to maintain size at target distance
      const newDistance =
        initialDistance *
        (Math.tan(THREE.MathUtils.degToRad(initialFov / 2)) /
         Math.tan(THREE.MathUtils.degToRad(animState.fov / 2)));

      perspectiveCam.position
        .copy(target)
        .addScaledVector(direction, newDistance);

      perspectiveCam.updateProjectionMatrix();
    },
    onComplete: () => {
      // Sync and activate Orthographic Camera
      syncOrthographicCamera(perspectiveCam, orthoCam, target);
      
      // Reset perspective camera back to standard settings for future use
      perspectiveCam.fov = initialFov;
      perspectiveCam.position
        .copy(target)
        .addScaledVector(direction, initialDistance);
      perspectiveCam.updateProjectionMatrix();

      if (onComplete) onComplete();
    }
  });
}

Step 3: Reattaching OrbitControls

If using OrbitControls, update the controller's active camera reference when swapping cameras to keep interactions consistent.

function setActiveCamera(newCamera, controls) {
  controls.object = newCamera;
  controls.update();
}

When switching back from OrthographicCamera to PerspectiveCamera, recalculate the perspective camera's position based on orthoCam.top and orthoCam.zoom, reassign controls.object, and call controls.update(). This sequence prevents view shifts and ensures seamless interaction across both projection modes.
