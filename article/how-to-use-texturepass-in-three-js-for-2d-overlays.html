How to Use TexturePass in Three.js for 2D Overlays

Overlaying a static 2D image—such as a HUD element, watermark, or frame—over a rendered 3D scene in Three.js can be achieved efficiently using post-processing. By integrating TexturePass into an EffectComposer pipeline alongside a standard RenderPass, developers can composite an image texture directly over the final rendered frame. This guide details how to import the required post-processing components, configure the texture asset, handle transparency, and sequence passes correctly to ensure the 2D image renders on top of the 3D scene without overwriting the underlying render buffer.

Required Modules

To implement TexturePass, import the core post-processing infrastructure from the Three.js addon directory:

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { TexturePass } from 'three/addons/postprocessing/TexturePass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

Configuring the Pipeline

The post-processing pipeline uses an ordered list of passes executed sequentially. To overlay an image over the 3D scene, follow this sequence:

  1. RenderPass: Renders the standard 3D scene and camera to an internal render target.
  2. TexturePass: Draws the 2D texture over the existing render target using a full-screen quad.
  3. OutputPass: Applies standard tone mapping and color space conversions to display on screen.

Step-by-Step Implementation

1. Initialize the Composer and Base RenderPass

Instantiate the EffectComposer using your standard WebGLRenderer. Add the RenderPass representing your main 3D scene:

const composer = new EffectComposer(renderer);

const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

2. Load the Overlay Texture

Load the image using TextureLoader. For overlays requiring transparency (such as PNGs with alpha channels), ensure proper color space configuration:

const textureLoader = new THREE.TextureLoader();
const overlayTexture = textureLoader.load('path/to/overlay.png');
overlayTexture.colorSpace = THREE.SRGBColorSpace;

3. Create and Configure the TexturePass

Initialize TexturePass with the loaded texture and the desired opacity (ranging from 0.0 to 1.0).

By default, TexturePass creates a full-screen quad using a standard material that writes over previous passes. To ensure the 3D scene remains visible beneath the transparent portions of the image, explicitly enable transparency and configure blending on the internal material:

const texturePass = new TexturePass(overlayTexture, 1.0);

// Enable alpha blending over the previous pass
texturePass.material.transparent = true;
texturePass.material.blending = THREE.NormalBlending;

// Prevent clearing the buffer before this pass draws
texturePass.clear = false;

composer.addPass(texturePass);

Setting texturePass.clear = false is critical. If left as true, the pass will wipe out the underlying 3D render from the RenderPass.

4. Add the Output Pass

Append OutputPass to handle final color management:

const outputPass = new OutputPass();
composer.addPass(outputPass);

Complete Code Example

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { TexturePass } from 'three/addons/postprocessing/TexturePass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

// Setup basic renderer, scene, and camera
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 5;

// Add 3D object
const mesh = new THREE.Mesh(
  new THREE.BoxGeometry(),
  new THREE.MeshBasicMaterial({ color: 0x00ff00 })
);
scene.add(mesh);

// Setup EffectComposer
const composer = new EffectComposer(renderer);

// 1. Scene Pass
const renderScene = new RenderPass(scene, camera);
composer.addPass(renderScene);

// 2. Texture Overlay Pass
const textureLoader = new THREE.TextureLoader();
textureLoader.load('overlay.png', (texture) => {
  texture.colorSpace = THREE.SRGBColorSpace;

  const texturePass = new TexturePass(texture, 1.0);
  texturePass.material.transparent = true;
  texturePass.material.blending = THREE.NormalBlending;
  texturePass.clear = false;

  // Insert before the OutputPass
  composer.insertPass(texturePass, 1);
});

// 3. Final Output Pass
const outputPass = new OutputPass();
composer.addPass(outputPass);

// Render loop
function animate() {
  requestAnimationFrame(animate);
  mesh.rotation.x += 0.01;
  mesh.rotation.y += 0.01;
  composer.render();
}
animate();

// Handle window resizing
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
  composer.setSize(window.innerWidth, window.innerHeight);
});

Key Considerations

  • Aspect Ratio: TexturePass stretches the image to fill the entire canvas bounds. If your static asset must preserve a specific aspect ratio, ensure the canvas matches the texture aspect ratio, or use an orthographic overlay scene instead of a standard TexturePass.
  • Execution Order: Always keep TexturePass after your 3D visual passes (like SSAO, Bloom, or standard geometry) and before the final color-correction pass. Placing TexturePass before post-processing effects will result in those effects distorting the static overlay.
