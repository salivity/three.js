How to Use CanvasTexture for Three.js Dynamic UI

This guide explains how to bind an HTML5 canvas element to a THREE.CanvasTexture to build dynamic, real-time user interface (UI) panels within a Three.js scene. You will learn how to initialize an offscreen 2D canvas, render standard 2D graphics onto it, map it to a 3D plane mesh, and dynamically update its visual state during the render loop.

1. Create the HTML Canvas

First, create an HTML canvas element in memory or retrieve an existing one from the DOM. This canvas acts as the 2D surface where your UI elements—such as text, meters, or buttons—will be drawn.

// Create an offscreen 2D canvas
const uiCanvas = document.createElement('canvas');
uiCanvas.width = 512;
uiCanvas.height = 256;
const ctx = uiCanvas.getContext('2d');

// Function to draw the UI state
function drawUI(text, progress) {
  // Clear the canvas
  ctx.clearRect(0, 0, uiCanvas.width, uiCanvas.height);

  // Background
  ctx.fillStyle = 'rgba(20, 20, 30, 0.85)';
  ctx.roundRect(0, 0, uiCanvas.width, uiCanvas.height, 20);
  ctx.fill();

  // Text
  ctx.fillStyle = '#ffffff';
  ctx.font = 'bold 36px sans-serif';
  ctx.fillText(text, 40, 80);

  // Progress Bar
  ctx.fillStyle = '#00ffcc';
  ctx.fillRect(40, 140, (uiCanvas.width - 80) * progress, 30);
}

// Initial draw
drawUI('Status: Active', 0.5);

2. Bind the Canvas to a Three.js Texture

Instantiate THREE.CanvasTexture by passing the canvas element directly into the constructor. This texture serves as the visual map for a 3D material.

import * as THREE from 'three';

// Create the CanvasTexture
const canvasTexture = new THREE.CanvasTexture(uiCanvas);

// Optimize texture filtering
canvasTexture.minFilter = THREE.LinearFilter;
canvasTexture.magFilter = THREE.LinearFilter;

3. Map the Texture to a 3D Mesh

Apply the texture to a flat geometry, such as THREE.PlaneGeometry, using a material that supports texture maps. Set transparent: true if your canvas UI uses transparent or rounded backgrounds.

// Define panel dimensions matching the canvas aspect ratio
const geometry = new THREE.PlaneGeometry(2, 1);

// Attach the CanvasTexture to the material
const material = new THREE.MeshBasicMaterial({
  map: canvasTexture,
  transparent: true,
  side: THREE.DoubleSide
});

// Create and position the UI mesh
const uiMesh = new THREE.Mesh(geometry, material);
uiMesh.position.set(0, 1.5, -2);
scene.add(uiMesh);

4. Trigger Dynamic UI Updates

Three.js does not automatically monitor internal modifications to the 2D canvas context. Whenever you redraw or alter the canvas content, you must explicitly flag the texture for an update by setting texture.needsUpdate = true.

let progress = 0;

function updateUI() {
  progress = (progress + 0.01) % 1;
  
  // Redraw onto the 2D canvas context
  drawUI(`Loading: ${Math.round(progress * 100)}%`, progress);

  // Tell Three.js to re-upload the canvas buffer to the GPU
  canvasTexture.needsUpdate = true;
}

function animate() {
  requestAnimationFrame(animate);

  updateUI();
  renderer.render(scene, camera);
}

animate();

5. Map 3D Clicks to 2D Canvas Coordinates

To make the UI panel interactive, use THREE.Raycaster to capture user clicks on the mesh. You can translate the intersection's UV coordinates directly into 2D pixel coordinates on the canvas:

const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

window.addEventListener('pointerdown', (event) => {
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObject(uiMesh);

  if (intersects.length > 0) {
    const uv = intersects[0].uv;
    
    // Convert normalized UV coordinates (0.0 to 1.0) to canvas pixel coordinates
    const canvasX = uv.x * uiCanvas.width;
    const canvasY = (1 - uv.y) * uiCanvas.height; // Invert Y for 2D canvas space

    console.log(`Clicked canvas at: ${canvasX}, ${canvasY}`);
  }
});
