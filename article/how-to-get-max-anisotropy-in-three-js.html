How to Get Max Anisotropy in Three.js

This article explains how to determine the maximum anisotropic filtering value supported by a user's GPU using Three.js and the underlying WebGL context. Querying this value ensures you can maximize texture sharpness at oblique angles while preventing performance issues or errors caused by requesting unsupported hardware limits.

Using the Three.js Capabilities API

Three.js abstracts WebGL hardware queries through the WebGLRenderer.capabilities object. The most straightforward and recommended way to find the maximum supported anisotropy is by calling renderer.capabilities.getMaxAnisotropy().

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer();

// Query the maximum supported anisotropy
const maxAnisotropy = renderer.capabilities.getMaxAnisotropy();

console.log(`Maximum supported anisotropy: ${maxAnisotropy}`);

Applying the Maximum Anisotropy to a Texture

Once retrieved, you can assign this value directly to any THREE.Texture instance. Typically, graphics hardware supports maximum values of 8 or 16, while lower-end or unsupported hardware returns 1.

const textureLoader = new THREE.TextureLoader();

textureLoader.load('path/to/texture.jpg', (texture) => {
  texture.anisotropy = maxAnisotropy;
  texture.needsUpdate = true;
});

Querying the WebGL Context Directly

If you need to query the raw WebGL context directly without relying entirely on the Three.js abstraction, you can inspect the WebGL anisotropic filtering extension using the renderer's context:

const gl = renderer.getContext();

// Retrieve the anisotropic extension
const ext = gl.getExtension('EXT_texture_filter_anisotropic') ||
            gl.getExtension('MOZ_EXT_texture_filter_anisotropic') ||
            gl.getExtension('WEBKIT_EXT_texture_filter_anisotropic');

let maxAnisotropy = 1;

if (ext) {
  maxAnisotropy = gl.getParameter(ext.MAX_TEXTURE_MAX_ANISOTROPY_EXT);
}

console.log(`Max WebGL Anisotropy: ${maxAnisotropy}`);

Best Practices

  • Clamp Values: If you want to maintain a balance between visual fidelity and performance, clamp the applied anisotropy value (for example, Math.min(maxAnisotropy, 8)).
  • Timing: Always ensure the WebGLRenderer has been initialized before querying renderer.capabilities.getMaxAnisotropy(), as the underlying WebGL context must exist to return an accurate hardware limit.
