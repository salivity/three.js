How to Use Three.js FileLoader for Text and JSON

This guide explains how to use the THREE.FileLoader class to load low-level, generic text, and JSON assets into your Three.js application. You will learn the basic setup, how to configure different response types, manage asynchronous loading using callbacks and Promises, and handle common errors during data fetching.

What is THREE.FileLoader?

THREE.FileLoader is a low-level utility class used internally by many of Three.js's higher-level loaders, such as GLTFLoader and OBJLoader. It relies on the browser's fetch or XMLHttpRequest APIs to retrieve raw data from a given URL or file path. You can use it directly whenever you need to import configuration files, custom shader code, point cloud text formats, or arbitrary JSON structures to configure your 3D scene.

Basic Implementation

To use THREE.FileLoader, instantiate the class and call its .load() method. The method accepts four arguments: the asset URL, an onLoad callback, an optional onProgress callback, and an optional onError callback.

import * as THREE from 'three';

// Instantiate the loader
const fileLoader = new THREE.FileLoader();

// Load a simple text file
fileLoader.load(
  'assets/shaders/customVertexShader.glsl',
  // onLoad callback
  function (data) {
    console.log('File loaded successfully:');
    console.log(data); // Raw text by default
  },
  // onProgress callback
  function (xhr) {
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  // onError callback
  function (err) {
    console.error('An error occurred while loading the file:', err);
  }
);

Configuring Response Types

By default, THREE.FileLoader returns data as a plain string. To change how the response is parsed before reaching the onLoad callback, call .setResponseType() on the loader instance.

Supported response types include:

  • "" or "text" (default): Returns standard string text.
  • "arraybuffer": Returns an ArrayBuffer containing raw binary data.
  • "blob": Returns a Blob object.
  • "document": Parses the file as an XML/HTML document.
  • "json": Automatically parses the response into a JavaScript object via JSON.parse().

Fetching JSON Data

When fetching JSON configuration or level design data, set the response type to 'json'. The parsed JavaScript object will be passed directly to the onLoad callback, eliminating the need to call JSON.parse() manually.

import * as THREE from 'three';

const loader = new THREE.FileLoader();

// Set the expected response type to JSON
loader.setResponseType('json');

loader.load(
  'assets/data/sceneConfig.json',
  function (jsonData) {
    // jsonData is already parsed into a JavaScript object
    console.log('Scene config loaded:', jsonData);
    
    // Example: apply values to your scene
    if (jsonData.backgroundColor) {
      scene.background = new THREE.Color(jsonData.backgroundColor);
    }
  },
  undefined,
  function (error) {
    console.error('Failed to load JSON config:', error);
  }
);

Wrapping FileLoader with Promises / Async-Await

For cleaner application logic and to avoid callback nesting, you can wrap THREE.FileLoader in a Promise:

import * as THREE from 'three';

function loadFileAsync(url, responseType = 'text') {
  const loader = new THREE.FileLoader();
  loader.setResponseType(responseType);

  return new Promise((resolve, reject) => {
    loader.load(url, resolve, undefined, reject);
  });
}

// Usage with async/await
async function initSceneData() {
  try {
    const config = await loadFileAsync('assets/data/sceneConfig.json', 'json');
    const vertexShader = await loadFileAsync('assets/shaders/vertex.glsl', 'text');
    
    // Proceed with creating materials and objects
    const customMaterial = new THREE.ShaderMaterial({
      vertexShader: vertexShader,
      // ...
    });
  } catch (error) {
    console.error('Error during data initialization:', error);
  }
}

initSceneData();

Setting Custom Headers and Paths

THREE.FileLoader provides utility methods to modify how network requests are made:

  • setPath(basePath): Prepends a base URL or path to all subsequent .load() calls.
  • setRequestHeader(headers): Accepts an object of HTTP headers to include with the request, useful when fetching protected assets requiring authentication tokens.
  • setWithCredentials(boolean): Determines whether cross-origin requests should include credentials like cookies.
