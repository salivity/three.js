Custom UV Generator for Three.js ExtrudeGeometry

Default texture mapping on a Three.js ExtrudeGeometry frequently produces stretched, misaligned textures across extruded side walls because the default WorldUVGenerator simply projects coordinates planar-wise along the Z-axis. This article demonstrates how to build and assign a custom UVGenerator to map coordinates proportionally across both the front/back faces and the continuous perimeter walls of an extruded shape.

The UVGenerator Interface

Three.js expects a custom UV generator to be an object implementing two functions:

  1. generateTopUV(geometry, vertices, indexA, indexB, indexC): Generates UVs for the front and back flat faces.
  2. generateSideWallUV(geometry, vertices, indexA, indexB, indexC, indexD): Generates UVs for the quad walls formed along the shape's path during extrusion.

Both functions take the geometry, the raw vertex position array (vertices), and the numerical indices for the face's vertices. Each function must return an array of THREE.Vector2 instances corresponding to the given vertices.

Implementing the Custom Generator

The following implementation normalizes top/bottom faces to world coordinates and uses edge-length projection along side walls to prevent texture stretching regardless of contour complexity:

import * as THREE from 'three';

export const CustomUVGenerator = {
  generateTopUV: function (geometry, vertices, indexA, indexB, indexC) {
    const ax = vertices[indexA * 3];
    const ay = vertices[indexA * 3 + 1];
    const bx = vertices[indexB * 3];
    const by = vertices[indexB * 3 + 1];
    const cx = vertices[indexC * 3];
    const cy = vertices[indexC * 3 + 1];

    return [
      new THREE.Vector2(ax, ay),
      new THREE.Vector2(bx, by),
      new THREE.Vector2(cx, cy)
    ];
  },

  generateSideWallUV: function (geometry, vertices, indexA, indexB, indexC, indexD) {
    const ax = vertices[indexA * 3];
    const ay = vertices[indexA * 3 + 1];
    const az = vertices[indexA * 3 + 2];

    const bx = vertices[indexB * 3];
    const by = vertices[indexB * 3 + 1];
    const bz = vertices[indexB * 3 + 2];

    const cx = vertices[indexC * 3];
    const cy = vertices[indexC * 3 + 1];
    const cz = vertices[indexC * 3 + 2];

    const dx = vertices[indexD * 3];
    const dy = vertices[indexD * 3 + 1];
    const dz = vertices[indexD * 3 + 2];

    // Determine whether the wall segment is predominantly aligned along the X or Y axis
    const isVertical = Math.abs(ax - bx) < Math.abs(ay - by);

    let uMin, uMax;

    if (isVertical) {
      uMin = Math.min(ay, by);
      uMax = Math.max(ay, by);
    } else {
      uMin = Math.min(ax, bx);
      uMax = Math.max(ax, bx);
    }

    const vMin = Math.min(az, cz);
    const vMax = Math.max(az, cz);

    return [
      new THREE.Vector2(uMin, vMin),
      new THREE.Vector2(uMax, vMin),
      new THREE.Vector2(uMax, vMax),
      new THREE.Vector2(uMin, vMax)
    ];
  }
};

Applying the Custom UV Generator

Pass your custom generator to the UVGenerator property inside the extrudeSettings parameter when creating ExtrudeGeometry.

import * as THREE from 'three';
import { CustomUVGenerator } from './CustomUVGenerator.js';

// 1. Define the 2D Shape
const shape = new THREE.Shape();
shape.moveTo(0, 0);
shape.lineTo(10, 0);
shape.lineTo(10, 5);
shape.quadraticCurveTo(5, 10, 0, 5);
shape.closePath();

// 2. Set extrusion options with the custom generator
const extrudeSettings = {
  steps: 1,
  depth: 4,
  bevelEnabled: false,
  UVGenerator: CustomUVGenerator
};

// 3. Create the Geometry and Mesh
const geometry = new THREE.ExtrudeGeometry(shape, extrudeSettings);

// Load texture and enable repeating
const texture = new THREE.TextureLoader().load('texture.jpg');
texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;
texture.repeat.set(0.1, 0.1); // Scale texture density to fit world units

const material = new THREE.MeshStandardMaterial({ map: texture });
const mesh = new THREE.Mesh(geometry, material);

scene.add(mesh);

Key Considerations

  • Beveling: If bevelEnabled: true is set, generateSideWallUV will execute for each bevel step. Calculating UVs using actual coordinate magnitudes rather than indices ensures smooth texture continuity across bevel segments.
  • Texture Repetition: By generating UVs directly from vertex coordinate values, texture sizes remain true to world dimensions. Adjust texture.repeat to control how frequently the texture pattern repeats across both flat surfaces and the extrusion depth.
