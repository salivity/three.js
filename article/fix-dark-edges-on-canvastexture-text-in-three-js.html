Fix Dark Edges on CanvasTexture Text in Three.js

Dark or muddy borders around transparent text rendered via CanvasTexture occur when semi-transparent edge pixels blend with the canvas's default transparent black background. In Three.js, this artifact is typically caused by improper alpha handling during texture filtering and blending. You can eliminate these dark outlines by enabling alpha pre-multiplication on both your CanvasTexture and the corresponding material, ensuring that color interpolation and WebGL blending calculate transparent edges accurately.

Why Dark Edges Appear

When you draw text on an HTML5 <canvas>, the anti-aliasing produces semi-transparent pixels along the edges of each glyph. By default, the untouched areas of the canvas have an RGBA value of (0, 0, 0, 0)—completely transparent black.

When WebGL applies linear filtering to scale the texture, it blends the RGB color of your text with the RGB values of adjacent pixels. Because the adjacent pixels are black, the edge colors are pulled toward black before their transparency is evaluated, creating a noticeable dark halo.

The Solution: Enable Alpha Pre-Multiplication

To fix this issue, you must configure WebGL to premultiply the texture’s RGB channels by its alpha channel during the texture upload, and instruct your Three.js material to use premultiplied blending.

1. Configure the CanvasTexture

Set premultiplyAlpha to true on the CanvasTexture instance:

const canvas = document.createElement('canvas');
const context = canvas.getContext('2d');

// Draw text onto canvas
context.font = 'Bold 48px Arial';
context.fillStyle = 'white';
context.fillText('Hello World', 10, 50);

// Create the texture and enable pre-multiplication
const texture = new THREE.CanvasTexture(canvas);
texture.premultiplyAlpha = true;
texture.needsUpdate = true;

When texture.premultiplyAlpha = true is set, Three.js calls gl.pixelStorei(gl.UNPACK_PREMULTIPLY_ALPHA_WEBGL, true) under the hood, properly preparing the pixel data for premultiplied compositing.

2. Configure the Material

Next, ensure the material receiving the texture is set to handle premultiplied alpha:

const material = new THREE.MeshBasicMaterial({
  map: texture,
  transparent: true,
  premultipliedAlpha: true
});

Setting material.premultipliedAlpha = true changes the WebGL blending factors to gl.ONE for the source factor and gl.ONE_MINUS_SRC_ALPHA for the destination factor. This prevents the GPU from multiplying the alpha channel twice and stops edge pixels from bleeding into black.

Complete Implementation

import * as THREE from 'three';

// 1. Initialize canvas and render text
const canvas = document.createElement('canvas');
canvas.width = 512;
canvas.height = 256;
const ctx = canvas.getContext('2d');

ctx.clearRect(0, 0, canvas.width, canvas.height);
ctx.font = '48px sans-serif';
ctx.fillStyle = '#ffffff';
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
ctx.fillText('Sharp Text', canvas.width / 2, canvas.height / 2);

// 2. Create the CanvasTexture with premultiplyAlpha enabled
const textTexture = new THREE.CanvasTexture(canvas);
textTexture.premultiplyAlpha = true;

// 3. Create the material matching the premultiplied setting
const textMaterial = new THREE.MeshBasicMaterial({
  map: textTexture,
  transparent: true,
  premultipliedAlpha: true,
  depthWrite: false
});

// 4. Attach to a mesh or sprite
const geometry = new THREE.PlaneGeometry(4, 2);
const textMesh = new THREE.Mesh(geometry, textMaterial);
scene.add(textMesh);

By pairing texture.premultiplyAlpha = true with material.premultipliedAlpha = true, Three.js processes the anti-aliased edges in premultiplied space, removing all dark borders and delivering crisp, clean text rendering over any background.
