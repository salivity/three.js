Compute Matrix3 Determinant for Normal Matrix in Three.js

In Three.js, lighting and shading calculations rely on surface normals transformed by a 3x3 normal matrix. If an object undergoes non-uniform scaling, degenerate transformations, or collapses along any axis to zero, the normal matrix can become singular, causing shader errors, black artifacts, or NaN values. This article explains how to safely extract and compute the determinant of a Matrix3 to verify that an object's transformation is invertible before calculating its normal matrix.

Why the Normal Matrix Fails

A normal matrix is calculated as the transpose of the inverse of the upper-left 3x3 portion of an object's transformation matrix (either modelViewMatrix or matrixWorld).

A matrix can only be inverted if its determinant is non-zero. If an object's scale on any axis reaches zero (such as during an animation scale-down), the determinant of this 3x3 submatrix drops to zero. Attempting to invert a singular matrix leads to division by zero, yielding degenerate normal matrices filled with zeros or infinities.

How to Safely Check the Determinant

To ensure an object's normal matrix is valid, extract the linear transformation component (rotation and scale) into a THREE.Matrix3, calculate its determinant, and check it against a small floating-point threshold (EPSILON).

Implementation

import * as THREE from 'three';

const _m3 = new THREE.Matrix3();
const EPSILON = 1e-6;

/**
 * Validates whether an object's transform can produce a valid normal matrix.
 * @param {THREE.Object3D} object - The target 3D object.
 * @returns {boolean} - True if the normal matrix can be safely computed.
 */
function hasValidNormalMatrix(object) {
  // Ensure the object's world matrix is up to date
  object.updateWorldMatrix(true, false);

  // Extract the upper-left 3x3 rotation/scale submatrix from matrixWorld
  _m3.setFromMatrix4(object.matrixWorld);

  // Compute the determinant of the 3x3 matrix
  const det = _m3.determinant();

  // If the absolute determinant is greater than epsilon, the matrix is invertible
  return Math.abs(det) > EPSILON;
}

Safely Generating the Normal Matrix

When working directly with instances of THREE.Matrix3, avoid calling normalMatrix.getNormalMatrix(matrix4) blindly if the source matrix might be invalid. Instead, guard the operation:

import * as THREE from 'three';

const normalMatrix = new THREE.Matrix3();
const tempMatrix3 = new THREE.Matrix3();
const EPSILON = 1e-6;

function safelyUpdateNormalMatrix(matrix4) {
  tempMatrix3.setFromMatrix4(matrix4);

  if (Math.abs(tempMatrix3.determinant()) > EPSILON) {
    // Determinant is valid; safe to compute normal matrix
    normalMatrix.getNormalMatrix(matrix4);
  } else {
    // Fallback strategy: reset to identity or keep previous state
    normalMatrix.identity();
  }

  return normalMatrix;
}

Handling Degenerate Matrices

When a matrix determinant fails the validation check:

  1. Apply a Clamped Scale: Ensure object scale properties never reach absolute zero (e.g., clamp scale to a minimum of 0.0001).
  2. Disable Visibility: Temporarily set object.visible = false when an object scales to zero to avoid running vertex shaders with degenerate normal attributes.
  3. Use an Identity Fallback: When building custom shaders or manual pipelines, fallback to THREE.Matrix3.identity() to prevent non-finite numbers from corrupting the render pipeline.
