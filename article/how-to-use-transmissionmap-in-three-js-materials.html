How to Use TransmissionMap in Three.js Materials

Implementing a transmissionMap in Three.js allows developers to selectively control transparency and light transmission across a 3D mesh surface using a grayscale texture. By pairing a custom texture with MeshPhysicalMaterial, white pixels allow full light transmission like glass, black pixels remain completely opaque, and intermediate gray tones produce varying degrees of semi-transparency. This guide walks through configuring the material, loading the texture, and tuning essential render properties to achieve realistic, localized light transmission.

1. Use MeshPhysicalMaterial

Transmission calculations are computationally physical and are only supported by MeshPhysicalMaterial, an extension of MeshStandardMaterial. Standard, Phong, or Basic materials do not support transmissionMap.

2. Prepare the Texture

The transmissionMap should be a grayscale image. The material reads the red channel (or luminance) of this texture:

  • Pure White (#FFFFFF): Full transmission (maximum glass-like effect).
  • Pure Black (#000000): Zero transmission (fully opaque standard material).
  • Gray Values: Partial transmission.

3. Implementation Code

To apply the map, load it with TextureLoader and assign it to the transmissionMap property of your MeshPhysicalMaterial. You must also set the base transmission property to a value greater than 0 (typically 1.0) to act as the master multiplier.

import * as THREE from 'three';

// 1. Load the transmission mask
const textureLoader = new THREE.TextureLoader();
const maskTexture = textureLoader.load('path/to/transmission-mask.png');

// Ensure proper color space for non-color data maps
maskTexture.colorSpace = THREE.NoColorSpace;

// 2. Create the physical material
const glassMaterial = new THREE.MeshPhysicalMaterial({
  color: 0xffffff,
  metalness: 0,
  roughness: 0.1,
  
  // Enable transmission
  transmission: 1.0, // Master strength multiplier
  transmissionMap: maskTexture, // Texture mask controlling where light passes through
  
  // Physical light-bending properties
  ior: 1.5, // Index of refraction (1.5 is standard glass)
  thickness: 0.5, // Volume thickness for refraction calculations
  transparent: false // Must remain false; transmission handles its own render passes
});

// 3. Apply to a mesh
const geometry = new THREE.SphereGeometry(1, 32, 32);
const mesh = new THREE.Mesh(geometry, glassMaterial);
scene.add(mesh);

4. Key Properties for Realistic Results

  • transmission: Acts as a scalar. If set to 0.5, the maximum transmission on white areas of your map will only reach 50%. Keep it at 1.0 to let the texture control full dynamic range.
  • transparent: Keep this set to false. Three.js handles transmission in a separate physical render pass; enabling standard alpha blending (transparent: true) can cause sorting artifacts and disable internal refraction effects.
  • roughness and roughnessMap: Lower values (near 0.0–0.2) yield clear, transparent surfaces. Higher values produce frosted glass effects.
  • ior (Index of Refraction): Controls how dramatically light bends when passing through the transmissive parts. Air is 1.0, water is 1.333, and glass is approximately 1.5.
  • thickness: Dictates the virtual depth of the mesh volume. A value of 0 treats the object like an infinitesimally thin sheet (like a soap bubble), whereas values above 0 account for volume refraction.

5. Scene Requirements

For transmission to be visible, there must be content behind the object or an environment map for the light to refract. Always provide background meshes or assign an HDR environment map to scene.environment so the transmissive sections have ambient visual data to transmit to the camera.
