Get Normal Vector from Triangle in Three.js

This guide explains how to extract the normal vector of a face directly from a THREE.Triangle object in Three.js. By utilizing the built-in .getNormal() method, you can compute a normalized vector perpendicular to the triangle's surface based on its three vertices. The following sections cover the exact syntax, code implementation, and important considerations regarding vertex winding order.

Using the getNormal() Method

The THREE.Triangle class includes a direct method called .getNormal(). It calculates the face normal using the cross product of the triangle's edge vectors and writes the normalized result into a target THREE.Vector3.

import * as THREE from 'three';

// Define the three vertices of the triangle
const vA = new THREE.Vector3(0, 0, 0);
const vB = new THREE.Vector3(1, 0, 0);
const vC = new THREE.Vector3(0, 1, 0);

// Create the Triangle instance
const triangle = new THREE.Triangle(vA, vB, vC);

// Instantiate a target vector to store the result
const normal = new THREE.Vector3();

// Extract the normal vector
triangle.getNormal(normal);

console.log(normal); // Output: Vector3 { x: 0, y: 0, z: 1 }

Static Method Alternative

If you do not need to persist a THREE.Triangle instance, Three.js provides a static equivalent via THREE.Triangle.getNormal():

const normal = new THREE.Vector3();
THREE.Triangle.getNormal(vA, vB, vC, normal);

This calculates the normal directly from three Vector3 points without instantiating a Triangle object.

Vertex Order and Normal Direction

The direction of the normal vector depends strictly on the winding order of the vertices (\(a \to b \to c\)). Three.js adheres to the right-hand rule:

  • Counter-Clockwise (CCW): When vertices are defined counter-clockwise relative to the viewer, the normal points outward toward the viewer.
  • Clockwise (CW): When defined clockwise, the normal points away from the viewer.

If your resulting normal points in the opposite direction of what you expect, reverse the order of the second and third vertices (e.g., pass \(a, c, b\) instead of \(a, b, c\)).

Performance Tip

The target parameter is mandatory. Instead of creating a new THREE.Vector3 inside tight loops or render functions, allocate a single target vector outside the loop and reuse it to minimize memory allocation and prevent unnecessary garbage collection overhead.
