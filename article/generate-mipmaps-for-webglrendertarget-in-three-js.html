Generate Mipmaps for WebGLRenderTarget in Three.js

Generating mipmaps for an off-screen render target in Three.js ensures that textures rendered to surfaces maintain visual quality without aliasing or shimmering artifacts when scaled down. By configuring the appropriate minification filter on the target's underlying texture and enabling mipmap generation, Three.js will automatically build mipmap chains during your rendering loop, or you can force the process on demand using dedicated renderer methods.

1. Configure the WebGLRenderTarget Options

By default, Three.js often disables mipmap generation for render targets to save performance. To enable automatic mipmapping, you must explicitly set generateMipmaps to true and configure the texture’s minFilter to a mipmap-enabled filter.

import * as THREE from 'three';

const width = 1024;
const height = 1024;

const renderTarget = new THREE.WebGLRenderTarget(width, height, {
    generateMipmaps: true,
    minFilter: THREE.LinearMipmapLinearFilter, // Requires mipmaps to work properly
    magFilter: THREE.LinearFilter
});

If you modify an existing render target after instantiation, update the properties directly on its texture object:

renderTarget.texture.generateMipmaps = true;
renderTarget.texture.minFilter = THREE.LinearMipmapLinearFilter;
renderTarget.texture.needsUpdate = true;

2. Automatic Generation During the Render Loop

Once configured with a mipmap-compatible minFilter and generateMipmaps: true, Three.js automatically triggers gl.generateMipmap() whenever the render target is rendered to via renderer.render():

// Switch output to the render target
renderer.setRenderTarget(renderTarget);

// Draw your scene; Three.js automatically generates mipmaps at the end of the pass
renderer.render(scene, camera);

// Reset output back to the default canvas
renderer.setRenderTarget(null);

3. Forcing Mipmap Generation Manually

If you are modifying the render target outside the standard renderer.render() pass, or using custom shaders that write to it directly without automatic updates, you can force the mipmaps to recalculate using the WebGLRenderer.updateRenderTargetMipmap() method:

renderer.updateRenderTargetMipmap(renderTarget);

This command directly forces the underlying WebGL context to recalculate all mipmap levels immediately for the texture attached to the specified render target.
