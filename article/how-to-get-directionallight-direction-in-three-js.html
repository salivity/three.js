How to Get DirectionalLight Direction in Three.js

This guide explains how to extract and normalize the direction vector of a DirectionalLight in Three.js. In Three.js, a directional light emits parallel light rays from its position toward the position of its target object. By retrieving the world positions of both the light source and its target, you can compute and normalize the exact direction vector in world space for use in custom shaders, calculations, or scene logic.

Understanding DirectionalLight Orientation

A THREE.DirectionalLight does not store its direction as a single rotation or Euler angle. Instead, it relies on two entities:

  1. light.position: The point in space where the light originates.
  2. light.target: A THREE.Object3D representing the point the light shines toward (defaulting to the origin (0, 0, 0)).

Because both the light and its target can be nested inside parent objects, you must calculate their world-space positions rather than relying on local coordinates.

Step-by-Step Implementation

To calculate the normalized direction vector in which the light rays travel, subtract the light's world position from the target's world position, then normalize the result.

import * as THREE from 'three';

// 1. Ensure the scene graph matrices are up to date
scene.updateMatrixWorld(true);

// 2. Allocate reusable Vector3 instances to prevent garbage collection overhead
const lightPosition = new THREE.Vector3();
const targetPosition = new THREE.Vector3();
const lightDirection = new THREE.Vector3();

// 3. Extract world coordinates for both the light and its target
directionalLight.getWorldPosition(lightPosition);
directionalLight.target.getWorldPosition(targetPosition);

// 4. Calculate direction vector: target position minus light position
lightDirection.subVectors(targetPosition, lightPosition);

// 5. Normalize the vector to ensure its length is exactly 1 unit
lightDirection.normalize();

console.log('Light Ray Direction:', lightDirection);

Key Considerations

  • Ray Direction vs. Incident Vector: The calculation targetPosition - lightPosition yields the direction the light rays are traveling. If you are writing custom shaders or lighting calculations requiring the vector pointing toward the light source, invert the subtraction: lightPosition.sub(targetPosition).normalize().
  • Scene Hierarchy: Always ensure directionalLight.target is added to the scene (scene.add(directionalLight.target)) if you plan to move it independently. If it is not part of the scene graph, its world matrix will not update automatically.
  • Matrix Updates: If you query the direction immediately after altering coordinates within the same frame, call scene.updateMatrixWorld() or directionalLight.updateMatrixWorld() prior to extracting world positions.
