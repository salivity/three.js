How to Adjust CatmullRomCurve3 Tension in Three.js

In Three.js, CatmullRomCurve3 creates smooth 3D spline curves passing through a defined set of control points. By configuring the tension property, you can control the curvature dynamics to make the resulting path looser and wider or tighter and more direct. This article explains how the tension parameter works, the crucial prerequisite settings required for it to take effect, and practical code examples to adjust curve tightness.

Understanding the Tension Property

The tension property defines how sharply the curve bends around its control points. In Three.js, the value typically ranges between 0 and 1:

  • Lower Tension (closer to 0): Produces a looser, broader curve with wider arcs between control points.
  • Default Tension (0.5): Generates a balanced, standard Catmull-Rom spline.
  • Higher Tension (closer to 1): Pulls the curve tighter toward the straight line segments connecting the control points, reducing curve overshooting.

Prerequisite: Setting curveType

By default, CatmullRomCurve3 uses the 'centripetal' curve type. Under this default type (as well as 'chordal'), the tension property is ignored.

To enable manual tension control, you must explicitly set the curveType property to 'catmullrom'.

Implementation Example

You can set the tension directly in the constructor or modify it on an existing curve instance.

import * as THREE from 'three';

// 1. Define control points
const points = [
  new THREE.Vector3(-10, 0, 10),
  new THREE.Vector3(-5, 5, 5),
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(5, -5, 5),
  new THREE.Vector3(10, 0, 10)
];

// 2. Create the curve with 'catmullrom' curveType
// Parameters: points, closed, curveType, tension
const looseCurve = new THREE.CatmullRomCurve3(points, false, 'catmullrom', 0.1);
const tightCurve = new THREE.CatmullRomCurve3(points, false, 'catmullrom', 0.9);

Modifying Tension Dynamically

If you need to adjust tension dynamically after instantiation, update the properties and rebuild the geometry accordingly:

// Change an existing curve's tension
curve.curveType = 'catmullrom';
curve.tension = 0.8; // Make path tighter

// Update existing mesh or line geometry using the new points
const updatedPoints = curve.getPoints(50);
lineGeometry.setFromPoints(updatedPoints);

Setting tension to 0 yields maximum looping and smoothness, while values approaching 1 straighten the curve segments between the control vertices.
