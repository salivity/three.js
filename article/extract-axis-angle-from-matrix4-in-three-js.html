Extract Axis-Angle from Matrix4 in Three.js

This guide explains how to extract an axis-angle rotation representation from a complex 4x4 transformation matrix (THREE.Matrix4) in Three.js. You will learn how to isolate pure rotation by stripping translation and scaling components, apply rotation matrix decomposition, and calculate the final 3D unit axis and radian angle.

1. Isolate the Rotation Component

A complex THREE.Matrix4 typically contains combined translation, rotation, and non-uniform or uniform scale. Extracting an axis-angle representation directly from an unnormalized matrix leads to skewed or invalid mathematical results. You must first extract a pure, unscaled rotation matrix using the extractRotation() method:

import * as THREE from 'three';

// Assume complexMatrix is a pre-existing THREE.Matrix4 with scale and position
const pureRotationMatrix = new THREE.Matrix4().extractRotation(complexMatrix);

extractRotation() strips out the translation vector and normalizes the basis column vectors to remove any scaling, leaving an orthonormal 3x3 rotational submatrix inside a new Matrix4.

2. Extract Axis and Angle from the Rotation Matrix

Once the matrix is purified, the rotation can be decomposed into an axis vector (THREE.Vector3) and an angle in radians. The mathematical algorithm reads the diagonal elements to compute the trace for the angle, and the skew-symmetric off-diagonal entries to compute the rotation axis.

You can execute this decomposition via the following implementation of setAxisAngleFromRotationMatrix:

function setAxisAngleFromRotationMatrix(rotMatrix, targetAxis) {
    const te = rotMatrix.elements;

    // Elements of the 4x4 matrix (column-major order)
    const m11 = te[0], m12 = te[4], m13 = te[8];
    const m21 = te[1], m22 = te[5], m23 = te[9];
    const m31 = te[2], m32 = te[6], m33 = te[10];

    // Compute trace to derive angle
    const trace = m11 + m22 + m33;
    let angle = Math.acos(Math.min(Math.max((trace - 1) / 2, -1), 1));

    if (Math.abs(angle) < 1e-6) {
        // No rotation: default to arbitrary normalized axis
        targetAxis.set(1, 0, 0);
        return { axis: targetAxis, angle: 0 };
    }

    if (Math.abs(angle - Math.PI) < 1e-6) {
        // Singularity at 180 degrees (PI radians)
        const x = Math.sqrt(Math.max(0, (m11 + 1) / 2));
        const y = Math.sqrt(Math.max(0, (m22 + 1) / 2));
        const z = Math.sqrt(Math.max(0, (m33 + 1) / 2));

        targetAxis.set(
            x,
            (m12 < 0 || (m12 === 0 && m21 < 0)) ? -y : y,
            (m13 < 0 || (m13 === 0 && m31 < 0)) ? -z : z
        ).normalize();

        return { axis: targetAxis, angle: angle };
    }

    // Standard case
    const s = 2 * Math.sin(angle);
    targetAxis.set(
        (m32 - m23) / s,
        (m13 - m31) / s,
        (m21 - m12) / s
    ).normalize();

    return { axis: targetAxis, angle: angle };
}

3. Alternative Using the Native Three.js Quaternion Pipeline

Because Three.js handles edge cases and matrix singularities internally through its quaternion implementation, you can achieve the exact same result reliably using THREE.Quaternion:

// Step 1: Normalize and isolate rotation
const pureRotation = new THREE.Matrix4().extractRotation(complexMatrix);

// Step 2: Convert rotation matrix to a quaternion
const quaternion = new THREE.Quaternion().setFromRotationMatrix(pureRotation);

// Step 3: Extract axis and angle from the quaternion
const axis = new THREE.Vector3();
const angle = 2 * Math.acos(Math.min(Math.max(quaternion.w, -1), 1));
const s = Math.sqrt(1 - quaternion.w * quaternion.w);

if (s < 0.001) {
    // Rotation is negligible
    axis.set(1, 0, 0);
} else {
    axis.set(quaternion.x / s, quaternion.y / s, quaternion.z / s).normalize();
}

Both approaches guarantee an accurate unit vector for the rotation axis and a scalar rotation angle measured in radians.
