How to Simulate Ear Occlusion in Three.js Audio

This article provides a technical guide on configuring spatial audio in Three.js to simulate human ear occlusion and the head-shadow effect. While Web Audio natively provides HRTF (Head-Related Transfer Function) spatialization, achieving realistic directional attenuation requires understanding how the AudioListener orientation interacts with PositionalAudio directional cones and frequency filtering to mimic the way sound is physically muffled by the human head and pinnae.

The Relationship Between AudioListener and Directional Cones

In the Web Audio API and Three.js, directional cone properties (coneInnerAngle, coneOuterAngle, and coneOuterGain) belong to sound emitters (PositionalAudio wrapping a PannerNode), rather than the AudioListener. The AudioListener represents the virtual ears and defines the coordinate space and orientation of the listener in 3D space, typically bound to a Three.js Camera.

To simulate acoustic occlusion caused by the head and ears, you have two primary methods:

  1. Setting the panningModel to 'HRTF', which uses built-in head-related impulse response filters.
  2. Dynamically applying a directional filter (such as a low-pass BiquadFilterNode) or reverse cone logic based on the relative angle between the listener's forward gaze and the incoming audio vector.

Setting Up the AudioListener and HRTF

The default panning model in Three.js PositionalAudio is HRTF, which performs algorithmic ear-filtering. Ensure your AudioListener is attached to the camera so that orientation updates automatically:

import * as THREE from 'three';

// Create the listener and attach to the camera
const listener = new THREE.AudioListener();
camera.add(listener);

// Create the positional audio source
const sound = new THREE.PositionalAudio(listener);

// Ensure HRTF panning model is active on the underlying PannerNode
sound.panner.panningModel = 'HRTF';
sound.panner.distanceModel = 'inverse';

Configuring Directional Cone Properties

To restrict the angle at which sound radiates or to simulate directional emission, configure the cone parameters using setDirectionalCone():

// Arguments: innerAngle, outerAngle, outerGain
sound.setDirectionalCone(180, 230, 0.2);
  • Inner Angle (coneInnerAngle): The angle (in degrees) within which there is no volume attenuation.
  • Outer Angle (coneOuterAngle): The angle beyond which the sound drops to the minimum gain.
  • Outer Gain (coneOuterGain): The volume multiplier applied when the listener is fully outside the outer angle (e.g., 0.2 represents an 80% reduction in volume).

Simulating Rear-Ear Occlusion with a Dynamic Low-Pass Filter

Human ear occlusion primarily dampens higher frequencies when sounds originate from behind the head. Because standard cones only attenuate overall gain from the emitter's perspective, combining a BiquadFilterNode with the AudioListener produces an accurate acoustic simulation.

Insert a low-pass filter into the audio pipeline:

const audioContext = listener.context;
const occlusionFilter = audioContext.createBiquadFilter();
occlusionFilter.type = 'lowpass';
occlusionFilter.frequency.value = 22050; // Fully open initially

// Connect through filter
sound.setFilter(occlusionFilter);

Update the filter frequency in the animation loop based on the dot product between the camera's forward vector and the direction of the sound source:

const listenerForward = new THREE.Vector3();
const soundDirection = new THREE.Vector3();

function updateEarOcclusion() {
    // Get camera/listener forward direction
    camera.getWorldDirection(listenerForward);

    // Calculate normalized vector from listener to sound
    soundDirection.subVectors(sound.position, camera.position).normalize();

    // Dot product: 1 = directly in front, -1 = directly behind
    const dot = listenerForward.dot(soundDirection);

    if (dot < 0) {
        // Sound is behind the listener's ears; occlude high frequencies
        // Scale frequency between 1000Hz (fully behind) and 22050Hz (sides/front)
        const t = (dot + 1); // 0 to 1 range for rear hemisphere
        occlusionFilter.frequency.setTargetAtTime(
            1000 + t * 21050,
            listener.context.currentTime,
            0.05
        );
    } else {
        // Sound is in front of the listener; clear occlusion
        occlusionFilter.frequency.setTargetAtTime(
            22050,
            listener.context.currentTime,
            0.05
        );
    }
}

Calling updateEarOcclusion() in your render loop modulates the frequency cutoff based on the relative angle of the listener, effectively simulating the dampening effect the physical head creates for sound waves entering the ear canal from behind.
