Wind Displacement in Three.js Using onBeforeCompile

This article demonstrates how to inject dynamic wind displacement into a standard Three.js tree material using the onBeforeCompile hook. By intercepting and altering the built-in GLSL shaders of a MeshStandardMaterial, you can produce realistic, GPU-driven branch and leaf movement via vertex manipulation while entirely preserving Three.js's native physically based rendering, shadow reception, and environment mapping.

Why Use onBeforeCompile?

Creating a custom ShaderMaterial from scratch requires manually implementing PBR lighting, fog, shadow maps, and ambient occlusion. The material.onBeforeCompile hook allows you to modify the existing shader code of built-in materials right before WebGL compiles them. By injecting a uniform for time and a small displacement function, you achieve performant, animated vegetation with minimal code.

1. Defining the Wind Uniforms

First, create a uniform object that holds the animation state. This object must remain accessible in your animation loop so you can update elapsed time on every frame.

const windUniforms = {
  uTime: { value: 0 },
  uSpeed: { value: 1.5 },
  uStrength: { value: 0.25 },
  uFrequency: { value: 1.0 }
};

2. Modifying the Material Shader

Assign a function to material.onBeforeCompile. Inside this function, merge your custom uniforms into the shader's uniform dictionary and use string replacement to inject custom GLSL code into shader.vertexShader.

const treeMaterial = new THREE.MeshStandardMaterial({
  color: 0x2e8b57,
  roughness: 0.8,
  metalness: 0.1
});

treeMaterial.onBeforeCompile = (shader) => {
  // Bind your external uniforms
  shader.uniforms.uTime = windUniforms.uTime;
  shader.uniforms.uSpeed = windUniforms.uSpeed;
  shader.uniforms.uStrength = windUniforms.uStrength;
  shader.uniforms.uFrequency = windUniforms.uFrequency;

  // 1. Inject uniform definitions into the header
  shader.vertexShader = shader.vertexShader.replace(
    '#include <common>',
    `
    #include <common>
    uniform float uTime;
    uniform float uSpeed;
    uniform float uStrength;
    uniform float uFrequency;
    `
  );

  // 2. Inject vertex displacement logic
  shader.vertexShader = shader.vertexShader.replace(
    '#include <begin_vertex>',
    `
    #include <begin_vertex>

    // Prevent the base of the trunk from moving by masking with height
    float heightFactor = max(0.0, position.y);

    // Simple procedural wind wave
    float wave = sin(uTime * uSpeed + (position.x + position.z) * uFrequency);
    
    // Apply sway along the X and Z axes based on height
    transformed.x += wave * uStrength * (heightFactor * 0.1);
    transformed.z += cos(uTime * uSpeed * 0.8 + position.y) * (uStrength * 0.5) * (heightFactor * 0.1);
    `
  );
};

Key Injection Points

  • #include <common>: Ideal for declaring custom attributes, uniforms, and helper functions.
  • #include <begin_vertex>: Defines transformed, which is the local vertex position variable. Altering transformed ensures all subsequent transformations, including skinning and model-view projection, calculate correctly.

3. Updating the Animation Loop

To animate the wind displacement, increment the uTime value using your render loop's delta time or elapsed clock time.

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const elapsedTime = clock.getElapsedTime();
  windUniforms.uTime.value = elapsedTime;

  renderer.render(scene, camera);
}

animate();

4. Synchronizing Dynamic Shadows

If your tree casts shadows, the standard depth pass will still render the static geometry, creating mismatched shadows. To fix this, attach a custom depth material to the tree mesh that contains the exact same vertex displacement logic:

const depthMaterial = new THREE.MeshDepthMaterial({
  depthPacking: THREE.RGBADepthPacking
});

depthMaterial.onBeforeCompile = treeMaterial.onBeforeCompile;

const treeMesh = new THREE.Mesh(treeGeometry, treeMaterial);
treeMesh.customDepthMaterial = depthMaterial;
treeMesh.castShadow = true;

With customDepthMaterial configured, the depth buffer captures the swaying vertices, ensuring the cast shadows mirror the dynamic wind movement.
