Using PropertyBinding.parseTrackName in Three.js

This article provides an overview of how Three.js utilizes PropertyBinding.parseTrackName to resolve complex keyframe animation tracks into actionable scene graph targets. It details the underlying string-matching mechanics, regular expression patterns, and tokenized object models used to evaluate target paths, properties, and indexed vector or array elements.

In Three.js, animation clips target scene graph properties using string-based track identifiers. A complex track name specifies the hierarchical path to an object, the property to modify, and an optional component index. The method PropertyBinding.parseTrackName( trackName ) executes a deterministic syntactic evaluation to break this unified string into a structured component object.

The Formal Grammar of a Track String

A complete track identifier string follows this general structure:

"directory/nodeName.propertyName[subIndex]"

PropertyBinding.parseTrackName mathematically isolates each segment of this format based on structural delimiters: slashes (/), dots (.), and square brackets ([ and ]).

The Underlying Regular Expression Mechanics

Internally, Three.js processes the string using a regular expression designed to capture multiple groups sequentially:

const re = /^((?:[\w\d]+(?:\/[\w\d]+)*))?(\.[\w\d]+)?(?:\[([\w\d]+)\])?$/;

The parsing algorithm decomposes strings through the following capture phases:

  1. Path and Node Extraction (nodeName / objectName): The parser scans from the start of the string up to the first accessor dot (.). If directory separators (/) exist, it treats the string as a nested hierarchy path, resolving intermediate parent objects until the terminal target node is reached. If the node identifier contains brackets (such as scene/mesh[0]), the parser separates the node's base name from the explicit objectIndex.
  2. Property Extraction (propertyName): The parser detects the dot (.) separator to locate the target property, such as position, quaternion, scale, or morphTargetInfluences.
  3. Index Extraction (propertyIndex): The parser checks the end of the property sequence for square brackets enclosing alphanumeric characters. An explicit numerical or accessor index (e.g., [0], [x], [weight]) is isolated to address specific sub-components within vectors, matrices, or arrays.

The Parsed Output Structure

Calling PropertyBinding.parseTrackName( trackName ) returns a plain JavaScript object containing the parsed tokens:

{
  nodeName: string | undefined,
  objectName: string | undefined,
  objectIndex: string | undefined,
  propertyName: string | undefined,
  propertyIndex: string | undefined
}

Practical Evaluation Example

Consider a complex track identifier:

import * as THREE from 'three';

const trackName = "Armature/Hand.morphTargetInfluences[smile]";
const parsed = THREE.PropertyBinding.parseTrackName(trackName);

The parsing pipeline evaluates this string deterministically:

  • nodeName: "Armature/Hand" (the full path to locate the target object).
  • objectName: "Hand" (the terminal node name).
  • objectIndex: undefined (no node array offset provided).
  • propertyName: "morphTargetInfluences" (the property to bind).
  • propertyIndex: "smile" (the morph target identifier within the array).

When given an index accessor for transform vectors, such as "RootNode.position[x]", the parser assigns "position" to propertyName and "x" to propertyIndex. Three.js subsequently maps scalar component channels (x, y, z, w or 0, 1, 2, 3) to contiguous array buffer offsets, establishing a high-performance binding between keyframe timeline values and target memory buffers.
