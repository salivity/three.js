Chaining Bezier Curves in Three.js Shapes

Constructing complex 2D shapes in Three.js often requires chaining multiple cubic Bézier curves together while maintaining smooth transitions across segment boundaries. This article explains the mathematical formulation behind the Path.bezierCurveTo method, details the continuity conditions (\(C^0\) and \(C^1\)) required for smooth joins, and demonstrates how to assemble these curves into a closed THREE.Shape to generate a renderable THREE.ShapeGeometry.

The Cubic Bézier Formulation

A cubic Bézier curve is defined by four points: an origin \(P_0\), two control points \(P_1\) and \(P_2\) that dictate curvature and direction, and a destination \(P_3\). Parametrically, for \(t \in [0, 1]\), the curve \(B(t)\) is expressed as:

\[B(t) = (1 - t)^3 P_0 + 3(1 - t)^2 t P_1 + 3(1 - t) t^2 P_2 + t^3 P_3\]

In Three.js, Path.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y) maps directly to this equation:

  • \(P_0\) is implicitly defined by the current position of the path (either from a prior moveTo or the end point of the preceding segment).
  • \(P_1 = (\text{cp1x}, \text{cp1y})\) acts as the first handle controlling exit velocity from \(P_0\).
  • \(P_2 = (\text{cp2x}, \text{cp2y})\) acts as the second handle controlling entry velocity into \(P_3\).
  • \(P_3 = (x, y)\) is the terminal anchor point of the segment.

Mathematical Conditions for Smooth Chaining

When linking segment \(A\) to segment \(B\), continuity constraints determine how seamless the resulting boundary will appear:

  1. Positional Continuity (\(C^0\)): The endpoint of segment \(A\) must equal the start point of segment \(B\). In Three.js, this is handled automatically because bezierCurveTo starts directly from the previous point: \[P_{0, B} = P_{3, A}\]

  2. Tangential Continuity (\(C^1\)): To prevent sharp corners, the first derivative of segment \(A\) at \(t = 1\) must equal the first derivative of segment \(B\) at \(t = 0\).

The first derivative of a cubic Bézier curve at its boundaries evaluates to: \[B'(0) = 3(P_1 - P_0)\] \[B'(1) = 3(P_3 - P_2)\]

Setting \(B'_A(1) = B'_B(0)\) gives: \[3(P_{3, A} - P_{2, A}) = 3(P_{1, B} - P_{0, B})\]

Because \(P_{0, B} = P_{3, A}\), this simplifies to: \[P_{1, B} = 2P_{3, A} - P_{2, A}\]

Thus, to achieve \(C^1\) continuity, the first control point of the new segment (\(P_{1, B}\)) must be the point reflection of the prior segment's second control point (\(P_{2, A}\)) across the shared anchor point (\(P_{3, A}\)).

Implementation Example

The following code constructs a closed, smooth teardrop-like shape by chaining two cubic curves using the reflection formula, and then creates a 2D mesh:

import * as THREE from 'three';

// Initialize a Shape (which extends THREE.Path)
const shape = new THREE.Shape();

// Segment 1 Definition
const p0 = new THREE.Vector2(0, -50);
const p1 = new THREE.Vector2(60, -50);
const p2 = new THREE.Vector2(80, 50);
const p3 = new THREE.Vector2(0, 100);

// Move to origin of the path
shape.moveTo(p0.x, p0.y);

// Draw the first curve
shape.bezierCurveTo(p1.x, p1.y, p2.x, p2.y, p3.x, p3.y);

// Calculate Segment 2 Control Points for C1 continuity at p3:
// p1_next must be collinear with p2 and p3: p1_next = 2 * p3 - p2
const p1_next = new THREE.Vector2().copy(p3).multiplyScalar(2).sub(p2);

// Choose an arbitrary incoming handle for returning to p0
const p2_next = new THREE.Vector2(-60, -50);

// For C1 continuity at closure (p0), p2_next should ideally align 
// with p1 across p0: p2_next = 2 * p0 - p1
p2_next.copy(p0).multiplyScalar(2).sub(p1);

// Draw the second curve back to p0
shape.bezierCurveTo(p1_next.x, p1_next.y, p2_next.x, p2_next.y, p0.x, p0.y);

// Generate geometry and triangulate the 2D surface
const geometry = new THREE.ShapeGeometry(shape, 32); // 32 curves segments per curve
const material = new THREE.MeshBasicMaterial({ color: 0x007acc, side: THREE.DoubleSide });
const mesh = new THREE.Mesh(geometry, material);

Triangulation and Curve Resolution

THREE.ShapeGeometry uses Earcut internally to triangulate the enclosed region bounded by the path segments. The second parameter of THREE.ShapeGeometry(shape, curveSegments) controls the subdivision resolution of the Bézier curves. A higher value generates more interpolated linear vertices along the curve parameters prior to triangulation, yielding a smoother edge at the expense of a higher polygon count.
