Map 2D Mouse Coordinates to a Sphere in Three.js

Mapping 2D mouse coordinates to the surface of a 3D sphere in Three.js requires converting viewport pixel coordinates into Normalized Device Coordinates (NDC), casting a ray from the camera into 3D world space, and calculating the point where the ray intersects the sphere's surface. This guide covers how to perform this projection using both Three.js built-in utilities and direct ray-sphere intersection mathematics.

Step 1: Normalize Mouse Coordinates

Browsers track mouse events in pixels with the origin \((0,0)\) at the top-left corner. Three.js raycasting requires coordinates in Normalized Device Coordinates (NDC), where both \(X\) and \(Y\) range from \(-1\) to \(+1\), with \((0,0)\) at the center and the \(Y\)-axis inverted.

const mouse = new THREE.Vector2();

function onMouseMove(event) {
    mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
    mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
}
window.addEventListener('mousemove', onMouseMove);

Step 2: Method A — Using THREE.Raycaster

The built-in THREE.Raycaster automatically calculates the camera projection and performs the intersection test against a mesh.

const raycaster = new THREE.Raycaster();

function getSphereIntersectionPoint(sphereMesh, camera) {
    raycaster.setFromCamera(mouse, camera);
    
    const intersects = raycaster.intersectObject(sphereMesh);

    if (intersects.length > 0) {
        // The exact 3D point on the surface of the sphere
        return intersects[0].point; 
    }

    return null; // Mouse does not intersect the sphere
}

Step 3: Method B — Mathematical Ray-Sphere Intersection

If you want to avoid rendering a mesh or need pure mathematical calculation, you can intersect a THREE.Ray directly with a geometric THREE.Sphere.

A ray is defined parametrically as: \[\mathbf{P}(t) = \mathbf{O} + t\mathbf{D}\]

Where \(\mathbf{O}\) is the ray origin, \(\mathbf{D}\) is the normalized direction vector, and \(t \ge 0\) is the distance along the ray.

A sphere centered at point \(\mathbf{C}\) with radius \(r\) satisfies: \[\|\mathbf{P} - \mathbf{C}\|^2 = r^2\]

Substituting the ray equation into the sphere equation yields a quadratic equation: \[t^2(\mathbf{D} \cdot \mathbf{D}) + 2t(\mathbf{D} \cdot (\mathbf{O} - \mathbf{C})) + ((\mathbf{O} - \mathbf{C}) \cdot (\mathbf{O} - \mathbf{C})) - r^2 = 0\]

Because \(\mathbf{D}\) is normalized, \(\mathbf{D} \cdot \mathbf{D} = 1\). Solving for \(t\) using the discriminant \(\Delta = b^2 - 4ac\):

  • If \(\Delta < 0\), the ray misses the sphere.
  • If \(\Delta \ge 0\), the closest intersection is \(t = \frac{-b - \sqrt{\Delta}}{2a}\).

Implementation Using THREE.Ray and THREE.Sphere

Three.js abstracts this quadratic formula internally within the THREE.Ray.intersectSphere() method:

const ray = new THREE.Ray();
const sphere = new THREE.Sphere(new THREE.Vector3(0, 0, 0), 5); // Center and Radius
const intersectionPoint = new THREE.Vector3();

function calculateIntersection(camera) {
    // Generate the ray from camera through the mouse NDC coordinates
    ray.origin.setFromMatrixPosition(camera.matrixWorld);
    ray.direction.set(mouse.x, mouse.y, 0.5)
        .unproject(camera)
        .sub(ray.origin)
        .normalize();

    // Compute the intersection point using ray-sphere math
    const hit = ray.intersectSphere(sphere, intersectionPoint);

    if (hit !== null) {
        return intersectionPoint; // Contains the exact world-space coordinates
    }

    return null; // Ray missed the sphere
}

Handling Misses

When the mouse moves outside the sphere's silhouette, both methods return null. If your application requires a continuous coordinate on the sphere even when the cursor is off the object, clamp the projected ray to the sphere's horizon by normalizing the vector from the sphere's center to the closest point along the ray, then multiplying by the radius:

function getClampedSurfacePoint(ray, sphere) {
    const closestPointOnRay = new THREE.Vector3();
    ray.closestPointToPoint(sphere.center, closestPointOnRay);

    return closestPointOnRay
        .sub(sphere.center)
        .normalize()
        .multiplyScalar(sphere.radius)
        .add(sphere.center);
}
