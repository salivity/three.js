Three.js Object3D Layers: Hide Objects From Cameras

In Three.js, managing which objects are rendered by which cameras can be efficiently achieved using the Object3D.layers property. This article explains how the underlying 32-layer bitmask system works, how to assign meshes and cameras to specific layers, and how to toggle layer visibility to create selective rendering pipelines, such as user interfaces, split-screens, or minimaps.

How Three.js Layers Work

Every instance of Object3D (including meshes, lights, and cameras) possesses a layers property, which is an instance of THREE.Layers. Three.js supports up to 32 distinct layers, indexed from 0 to 31.

Internally, layers use a 32-bit integer bitmask. When a camera renders a scene, it checks whether its own layer mask intersects with the layer mask of each object. An object is only drawn if:

(camera.layers.mask & object.layers.mask) !== 0

By default, all objects and cameras belong exclusively to layer 0.

Key Layer Methods

The THREE.Layers object provides four primary methods:

  • set(channel): Clears all current layers and assigns the entity solely to the specified layer channel (0 to 31).
  • enable(channel): Adds the specified layer channel without removing existing ones.
  • disable(channel): Removes the specified layer channel from the mask.
  • toggle(channel): Flips the state of the specified layer channel.

Setting Up Selective Visibility

To hide specific objects from a specific camera, you assign the objects and the camera to different layers.

import * as THREE from 'three';

// 1. Create meshes
const mainSceneMesh = new THREE.Mesh(geometry, materialA);
const uiMesh = new THREE.Mesh(geometry, materialB);

// 2. Assign layers to objects
// mainSceneMesh stays on default layer 0
uiMesh.layers.set(1); // uiMesh is now ONLY on layer 1

// 3. Configure cameras
const worldCamera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const uiCamera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1);

// worldCamera is on layer 0 by default, so it cannot see uiMesh
// uiCamera is configured to see ONLY layer 1
uiCamera.layers.set(1);

In this setup, worldCamera will ignore uiMesh entirely because their bitmasks do not overlap.

Multi-Layer Visibility

A camera or an object can exist on multiple layers at the same time. If a secondary camera needs to view both default world objects and user interface elements, enable multiple layers:

// Enable layer 1 while keeping layer 0 active
worldCamera.layers.enable(1);

Now, worldCamera renders objects located on layer 0, layer 1, or both.

Recursive Layer Assignment

Assigning a layer to a parent Object3D (such as a THREE.Group or an imported glTF scene) does not automatically propagate to its children. To apply a layer to an entire hierarchy, traverse the object tree:

modelGroup.traverse((child) => {
  if (child.isObject3D) {
    child.layers.set(2);
  }
});

Using Object3D.layers eliminates the overhead of manually toggling object.visible = true/false before and after distinct camera render passes.
