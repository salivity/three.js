Convert Non-Indexed Geometry to Indexed in Three.js

This guide explains how to convert a non-indexed BufferGeometry into an indexed geometry in Three.js by explicitly creating and assigning an index BufferAttribute. In Three.js, non-indexed geometries repeat vertex data for every triangle face, which consumes unnecessary GPU memory. By extracting unique vertices and defining an index array that maps which vertices form each triangle, you can optimize rendering performance and geometry manipulation.

Understanding Non-Indexed vs. Indexed Geometry

A non-indexed geometry defines triangles sequentially. A single quad requires two triangles, meaning six vertices in the position attribute, even though two vertices are identical:

  • Non-indexed: 6 vertex entries (e.g., A, B, C for triangle 1; A, C, D for triangle 2).
  • Indexed: 4 unique vertex entries (A, B, C, D) and an index array of 6 integers ([0, 1, 2, 0, 2, 3]).

Step-by-Step Conversion

To explicitly define an index, you must provide unique vertex data for your attributes and assign an index attribute using geometry.setIndex().

1. Define Unique Vertex Attributes

If you are starting from non-indexed data, remove the duplicate coordinates from your attributes (position, normal, uv) so only unique vertices remain.

import * as THREE from 'three';

const geometry = new THREE.BufferGeometry();

// Define 4 unique vertices for a quad
const vertices = new Float32Array([
  -1.0, -1.0,  0.0, // 0: bottom-left
   1.0, -1.0,  0.0, // 1: bottom-right
   1.0,  1.0,  0.0, // 2: top-right
  -1.0,  1.0,  0.0  // 3: top-left
]);

geometry.setAttribute('position', new THREE.BufferAttribute(vertices, 3));

2. Create the Index Array

Create a typed array containing the indices that form the triangular faces. Use Uint16Array for geometries with up to 65,535 vertices, or Uint32Array for larger meshes.

// Two triangles: (0, 1, 2) and (0, 2, 3)
const indices = new Uint16Array([
  0, 1, 2,
  0, 2, 3
]);

3. Wrap with BufferAttribute and Set the Index

Create a BufferAttribute for the index data (with an item size of 1) and assign it using geometry.setIndex().

// Option A: Using BufferAttribute directly
const indexAttribute = new THREE.BufferAttribute(indices, 1);
geometry.setIndex(indexAttribute);

// Option B: Passing the raw array directly (Three.js wraps it automatically)
geometry.setIndex(new THREE.Uint16BufferAttribute(indices, 1));

Complete Implementation

Here is the complete code to set up an indexed geometry explicitly:

import * as THREE from 'three';

// 1. Initialize geometry
const geometry = new THREE.BufferGeometry();

// 2. Add unique positions
const positions = new Float32Array([
  -1, -1, 0,
   1, -1, 0,
   1,  1, 0,
  -1,  1, 0
]);
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));

// 3. Define index attribute
const indices = new Uint16Array([
  0, 1, 2,
  2, 3, 0
]);
geometry.setIndex(new THREE.BufferAttribute(indices, 1));

// 4. Compute necessary helper attributes
geometry.computeVertexNormals();

// 5. Create the mesh
const material = new THREE.MeshStandardMaterial({ color: 0x00ff00, wireframe: false });
const mesh = new THREE.Mesh(geometry, material);

Automatic Deduplication Alternative

If you have an existing complex non-indexed geometry and do not want to parse unique vertices manually, Three.js provides a built-in utility via the BufferGeometryUtils add-on:

import * as BufferGeometryUtils from 'three/addons/utils/BufferGeometryUtils.js';

// Merges duplicate vertices and generates an index automatically
const indexedGeometry = BufferGeometryUtils.mergeVertices(nonIndexedGeometry);

This method searches for identical vertex positions, removes duplicates, and generates the index attribute automatically.
