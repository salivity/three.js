Three.js OffscreenCanvas with Web Worker Guide

Offloading 3D rendering to a Web Worker using OffscreenCanvas allows Three.js applications to run smooth animations without being blocked by heavy main-thread JavaScript execution. By transferring control of an HTML <canvas> element to a worker thread, the THREE.WebGLRenderer can process geometries, materials, and animation loops independently. This guide covers how to set up the main thread, transfer the canvas to a worker, initialize the Three.js scene, and forward user events for interactivity.

1. Main Thread Setup

The main thread creates the <canvas> element, converts it into an OffscreenCanvas, and passes it to a dedicated Web Worker using the transferable objects API.

// main.js
const canvas = document.getElementById('webgl-canvas');

// Verify browser support
if ('transferControlToOffscreen' in canvas) {
  const offscreen = canvas.transferControlToOffscreen();
  
  // Initialize the worker as an ES module
  const worker = new Worker(new URL('./worker.js', import.meta.url), {
    type: 'module'
  });

  // Transfer canvas ownership to the worker
  worker.postMessage({
    type: 'init',
    canvas: offscreen,
    width: window.innerWidth,
    height: window.innerHeight,
    pixelRatio: window.devicePixelRatio
  }, [offscreen]);

  // Handle window resizing
  window.addEventListener('resize', () => {
    worker.postMessage({
      type: 'resize',
      width: window.innerWidth,
      height: window.innerHeight
    });
  });

  // Forward interaction events (e.g., mouse movement)
  window.addEventListener('mousemove', (event) => {
    worker.postMessage({
      type: 'mousemove',
      clientX: event.clientX,
      clientY: event.clientY
    });
  });
} else {
  console.warn('OffscreenCanvas is not supported in this browser.');
}

2. Worker Thread Implementation

The worker script receives the OffscreenCanvas, instantiates THREE.WebGLRenderer, and manages the render loop. Because workers lack direct access to the DOM, standard controls like OrbitControls cannot be used directly without a proxy; interactions must be managed through forwarded messages.

// worker.js
import * as THREE from 'three';

let renderer, scene, camera, mesh;

self.onmessage = function (event) {
  const data = event.data;

  switch (data.type) {
    case 'init':
      initScene(data);
      break;
    case 'resize':
      resizeRenderer(data.width, data.height);
      break;
    case 'mousemove':
      handleMouseMove(data.clientX, data.clientY);
      break;
  }
};

function initScene({ canvas, width, height, pixelRatio }) {
  // Initialize renderer with the offscreen canvas
  renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
  renderer.setPixelRatio(pixelRatio);
  renderer.setSize(width, height, false);

  // Initialize scene and camera
  scene = new THREE.Scene();
  camera = new THREE.PerspectiveCamera(75, width / height, 0.1, 1000);
  camera.position.z = 5;

  // Add geometry
  const geometry = new THREE.BoxGeometry();
  const material = new THREE.MeshNormalMaterial();
  mesh = new THREE.Mesh(geometry, material);
  scene.add(mesh);

  // Start the render loop
  requestAnimationFrame(animate);
}

function resizeRenderer(width, height) {
  if (!renderer || !camera) return;

  camera.aspect = width / height;
  camera.updateProjectionMatrix();
  renderer.setSize(width, height, false);
}

function handleMouseMove(clientX, clientY) {
  if (!mesh) return;

  // Normalize coordinates and apply simple rotation
  mesh.rotation.y = (clientX / window.innerWidth) * Math.PI;
  mesh.rotation.x = (clientY / window.innerHeight) * Math.PI;
}

function animate(time) {
  requestAnimationFrame(animate);

  mesh.rotation.x += 0.01;
  mesh.rotation.y += 0.01;

  renderer.render(scene, camera);
}

Key Considerations

  • Third-Party Helpers: Utility libraries and controls that directly attach event listeners to window or document (such as OrbitControls or Stats.js) will throw errors in a Web Worker. Use custom event proxies on the main thread to capture and send relevant event data to the worker.
  • Canvas Dimension Management: When calling renderer.setSize(width, height, false), the third argument must be set to false. This instructs Three.js not to alter CSS styles, which are inaccessible on an OffscreenCanvas.
  • Asset Loading: Loaders like TextureLoader or GLTFLoader work inside Web Workers, but ensure that the assets are fetched via URLs accessible from the worker context. Image assets are processed as ImageBitmap objects inside workers instead of HTML Image elements.
