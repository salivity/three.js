Using attenuationColor in Three.js MeshPhysicalMaterial

In Three.js, simulating realistic internal volumetric light absorption and scattering within transparent or translucent objects is achieved using the transmission and attenuation properties of MeshPhysicalMaterial. By pairing attenuationColor with attenuationDistance, you dictate the internal tint and light decay as rays pass through an object's volume rather than simply tinting its surface. This article explains how to configure these properties to control internal volumetric color absorption accurately.

Enabling Volumetric Transmission

To make attenuationColor functional, you must first enable transmission on a MeshPhysicalMaterial. Standard opacity or transparency settings do not activate volumetric absorption; the material must explicitly use the transmission pipeline to calculate light passing through the geometry.

import * as THREE from 'three';

const material = new THREE.MeshPhysicalMaterial({
    roughness: 0.1,
    transmission: 1.0, // Enables volumetric transmission
    ior: 1.5,          // Index of refraction (e.g., standard glass)
    thickness: 1.2     // Thickness of the volume beneath the surface
});

Configuring attenuationColor and attenuationDistance

The attenuationColor property defines the color that white light becomes as it travels through the medium. However, attenuationColor has no visible effect without defining attenuationDistance.

  • attenuationColor: A THREE.Color instance defining the absorbed light's resulting color.
  • attenuationDistance: A float defining the density of the medium in world units. It represents the distance light must travel before it fully takes on the attenuationColor according to Beer's Law. If set to Infinity (the default), no light absorption occurs.
// Set the internal volumetric absorption color
material.attenuationColor = new THREE.Color(0x00aaff); // Tint internal light cyan

// Define the distance over which light attenuates
material.attenuationDistance = 0.5; // Dense medium: light tints rapidly over 0.5 units

The Role of Geometry and Thickness

The visual intensity of the volumetric color is calculated using the distance light travels through the object. You can influence this through:

  1. Actual Geometry: Larger or thicker parts of a mesh naturally absorb more light, resulting in a deeper, more saturated attenuationColor. Thinner edges will remain clearer.
  2. The thickness Property: For non-manifold or simplified geometry, the thickness property provides a virtual depth for ray calculations. If your object appears uniformly colored regardless of geometry, adjust thickness alongside attenuationDistance to achieve the desired gradient.

Full Example Setup

import * as THREE from 'three';

// 1. Create geometry
const geometry = new THREE.TorusKnotGeometry(1, 0.3, 128, 32);

// 2. Configure physical material with volumetric scattering
const physicalMaterial = new THREE.MeshPhysicalMaterial({
    color: 0xffffff,              // Keep surface color neutral to see internal scattering
    roughness: 0.05,
    metalness: 0,
    transmission: 1.0,
    ior: 1.52,
    thickness: 2.0,
    attenuationColor: new THREE.Color('#e02840'), // Rich red interior
    attenuationDistance: 1.5                      // Reaches full red at 1.5 world units
});

// 3. Create mesh and add to scene
const mesh = new THREE.Mesh(geometry, physicalMaterial);
scene.add(mesh);

Best Practices

  • Keep Surface color White: Set the primary color property of MeshPhysicalMaterial to pure white (0xffffff). If the surface color is tinted, it multiplies with the attenuationColor, making it difficult to control the internal scattering independently.
  • Lighting and Environment: Volumetric effects require contrast to be visible. Ensure your scene has an environment map (scene.environment) or bright point/directional lights positioned behind the object to observe transmission and absorption clearly.
  • Scale Awareness: Because attenuationDistance uses absolute three-dimensional units, ensure your 3D models are scaled accurately to avoid having to use abnormally small or large distance values.
