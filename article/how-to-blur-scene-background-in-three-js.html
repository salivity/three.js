How to Blur Scene Background in Three.js

This guide explains how to blur your Three.js scene background independently using the native scene.backgroundBlurriness property without altering foreground meshes. By assigning an environment map to the scene background and adjusting its blur value, you can achieve a realistic depth-of-field look behind your 3D models without the overhead of heavy post-processing passes.

Prerequisites

The backgroundBlurriness property was introduced in Three.js r146. Ensure your project uses Three.js version r146 or newer. Additionally, the background must be set to a texture that supports mipmapping and PMREM generation, such as an equirectangular texture (EquirectangularReflectionMapping) or a cube map (CubeTexture). Standard flat colors (THREE.Color) cannot be blurred using this method.

Step-by-Step Implementation

1. Load an Environment Map

Load your equirectangular texture or HDR image using TextureLoader or RGBELoader. Configure the mapping mode so Three.js can correctly project it into the background.

import * as THREE from 'three';
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

const scene = new THREE.Scene();

const rgbeLoader = new RGBELoader();
rgbeLoader.load('path/to/environment.hdr', (texture) => {
    texture.mapping = THREE.EquirectangularReflectionMapping;

    // Apply the texture as the background
    scene.background = texture;

    // Optional: Use the same texture for foreground lighting and reflections
    scene.environment = texture;

    // Apply the background blur
    scene.backgroundBlurriness = 0.5;
});

2. Configure backgroundBlurriness

The scene.backgroundBlurriness property accepts a float value between 0.0 and 1.0:

  • 0.0: The background is completely sharp with no blur applied (default).
  • 1.0: The background receives the maximum level of mipmap-based blur.

Because this property acts directly on the background rendering step, foreground objects, meshes, and UI elements remain pin-sharp and are completely excluded from the blur calculation.

3. Adjusting Related Background Properties

You can pair backgroundBlurriness with other background-specific properties to fine-tune the visual balance:

  • scene.backgroundIntensity: Controls the brightness/exposure of the background texture independently of scene.environment (available from Three.js r146+).
scene.backgroundBlurriness = 0.6;
scene.backgroundIntensity = 0.8;

Advantages Over Post-Processing

Using scene.backgroundBlurriness is significantly faster than using post-processing depth-of-field shaders (such as BokehPass). It utilizes the pre-filtered mipmaps generated by the GPU, resulting in minimal performance overhead on mobile and lower-end desktop hardware while completely eliminating artifact bleeding between foreground edges and the background.
