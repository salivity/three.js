How to Export and Download GLTF in Three.js

Exporting a 3D scene or object from Three.js and triggering an instant client-side download requires combining Three.js's GLTFExporter with standard browser file-handling APIs. This guide demonstrates how to capture dynamic 3D assets, convert the exported output into a downloadable Blob, and trigger a native browser download using a temporary anchor element—all without sending data back to a server.

1. Import the GLTFExporter

Ensure GLTFExporter is imported into your project. If using ES modules:

import * as THREE from 'three';
import { GLTFExporter } from 'three/examples/jsm/exporters/GLTFExporter.js';

2. Set Up the Export Logic

The GLTFExporter.parse() method serializes your target object or entire scene. It accepts the input object, a callback function for the generated output, an error callback, and an options object.

You can export as either a standard .gltf file (JSON-based) or a binary .glb file (compact and self-contained). The binary format is generally preferred because it packages geometry, materials, and textures into a single file.

3. Generate a Blob and Trigger the Download

Once GLTFExporter completes serialization, wrap the data in a Blob, generate an Object URL, and programmatically click an <a> element to trigger the browser's download prompt.

Here is a complete, reusable function:

function exportAndDownloadGLTF(inputObject, filename = 'model.glb', isBinary = true) {
  const exporter = new GLTFExporter();

  const options = {
    binary: isBinary,
    embedImages: true
  };

  exporter.parse(
    inputObject,
    (gltf) => {
      // Determine MIME type and content based on format
      let blob;
      if (isBinary) {
        blob = new Blob([gltf], { type: 'application/octet-stream' });
      } else {
        const output = JSON.stringify(gltf, null, 2);
        blob = new Blob([output], { type: 'application/json' });
      }

      // Create a temporary link element
      const link = document.createElement('a');
      link.href = URL.createObjectURL(blob);
      link.download = filename;

      // Append to the DOM, trigger click, and clean up
      document.body.appendChild(link);
      link.click();
      document.body.removeChild(link);

      // Free memory
      URL.revokeObjectURL(link.href);
    },
    (error) => {
      console.error('An error occurred while exporting the GLTF:', error);
    },
    options
  );
}

4. Implementation Example

To export an entire scene, call the function by passing your scene reference:

const scene = new THREE.Scene();
// Add meshes, lights, etc.

const downloadButton = document.getElementById('download-btn');
downloadButton.addEventListener('click', () => {
  exportAndDownloadGLTF(scene, 'my-scene.glb', true);
});

To export only a specific mesh or group instead of the full scene, pass that specific THREE.Mesh or THREE.Group as the first argument instead.
