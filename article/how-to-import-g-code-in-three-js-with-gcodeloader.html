How to Import G-Code in Three.js with GCodeLoader

This article explains how to render 3D printing toolpaths directly in a web browser by importing sliced G-code files using the Three.js GCodeLoader. You will learn how to include the loader in your project, parse .gcode files generated by slicing software such as Cura or PrusaSlicer, add the generated line geometry to a scene, and handle common spatial orientation adjustments required for 3D printer coordinates.

Setting Up the Environment

GCodeLoader is an add-on provided within the Three.js package. If you are using modern JavaScript with an npm-based build system, import Three.js alongside GCodeLoader from the three/addons directory:

import * as THREE from 'three';
import { GCodeLoader } from 'three/addons/loaders/GCodeLoader.js';

If you are using a standard HTML <script> tag with an import map:

<script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@latest/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@latest/examples/jsm/"
    }
  }
</script>

Loading and Parsing G-Code

GCodeLoader parses the linear movements (G0, G1) contained in the sliced file and converts them into renderable THREE.LineSegments or THREE.Line objects grouped inside a single THREE.Group.

Here is the implementation to load a file and add it to your scene:

// Initialize Scene, Camera, and Renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 150, 200);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Initialize GCodeLoader
const loader = new GCodeLoader();

loader.load(
    'path/to/model.gcode',
    function (gcodeGroup) {
        // Success callback: gcodeGroup is a THREE.Group
        scene.add(gcodeGroup);
        
        // Center the imported model
        const box = new THREE.Box3().setFromObject(gcodeGroup);
        const center = box.getCenter(new THREE.Vector3());
        gcodeGroup.position.sub(center);
    },
    function (xhr) {
        // Progress callback
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    function (error) {
        // Error callback
        console.error('An error occurred loading the G-code:', error);
    }
);

Coordinate Alignment and Orientation

3D slicers generate coordinates assuming a standard Cartesian 3D printer build plate where the build surface is the XY plane and the height is the Z axis (Z-up).

Three.js uses a Y-up coordinate system by default. To orient the 3D print model correctly on a standard Three.js ground plane, rotate the loaded group by -90 degrees along the X-axis:

loader.load('model.gcode', (gcodeGroup) => {
    gcodeGroup.rotation.x = -Math.PI / 2;
    scene.add(gcodeGroup);
});

Styling the Extrusion Lines

GCodeLoader automatically creates default line materials to distinguish between extrusion moves (plastic being deposited) and travel moves (rapid positioning without extrusion).

To customize the appearance of the paths, traverse the returned group and update the line materials:

loader.load('model.gcode', (gcodeGroup) => {
    gcodeGroup.traverse((child) => {
        if (child.isLineSegments || child.isLine) {
            child.material = new THREE.LineBasicMaterial({
                color: 0x00aaff,
                opacity: 0.8,
                transparent: true
            });
        }
    });

    scene.add(gcodeGroup);
});

Performance Considerations

G-code files from high-detail slices frequently contain hundreds of thousands of movement commands, which creates very large geometry buffers. Keep the following in mind:

  1. File Size: Large .gcode files can take several seconds to download and parse. Compress files using GZIP on the server where possible.
  2. Memory Usage: Consider simplifying slice settings (such as increasing layer height or disabling non-critical travel-move exporting) if the model is intended purely for web preview.
