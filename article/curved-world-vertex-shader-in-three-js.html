Curved World Vertex Shader in Three.js

This article explains how to create a curved world effect in Three.js by intercepting and replacing the standard project_vertex shader chunk. By leveraging the onBeforeCompile hook on standard Three.js materials, you can inject custom GLSL uniforms and displace vertices along an axis relative to the camera's depth, creating stylized spherical horizons or "runner game" curvature without modifying the underlying CPU geometry.

Understanding the project_vertex Chunk

Three.js builds its built-in materials using modular GLSL chunks. The project_vertex chunk is responsible for transforming a mesh's local coordinates into clip space coordinates via the model-view and projection matrices.

By default, the core transformation inside <project_vertex> operates as follows:

vec4 mvPosition = vec4( transformed, 1.0 );

#ifdef USE_BATCHING
    mvPosition = batchingMatrix * mvPosition;
#endif

#ifdef USE_INSTANCING
    mvPosition = instanceMatrix * mvPosition;
#endif

mvPosition = modelViewMatrix * mvPosition;

gl_Position = projectionMatrix * mvPosition;

To create a curved world, the position must be displaced based on its distance from the camera before the final projectionMatrix is applied.

Implementing the Curved World Shader

You can modify any standard material (such as MeshStandardMaterial, MeshBasicMaterial, or MeshLambertMaterial) by modifying its shader source in onBeforeCompile.

import * as THREE from 'three';

const curvatureUniforms = {
    uCurvature: { value: new THREE.Vector2(0.001, 0.001) }
};

const material = new THREE.MeshStandardMaterial({ color: 0x33aa33 });

material.onBeforeCompile = (shader) => {
    // Attach custom uniforms to the shader
    shader.uniforms.uCurvature = curvatureUniforms.uCurvature;

    // Inject uniform declaration at the top of the vertex shader
    shader.vertexShader = `
        uniform vec2 uCurvature;
    \n` + shader.vertexShader;

    // Define the custom replacement for project_vertex
    const customProjectVertex = `
        vec4 mvPosition = vec4( transformed, 1.0 );

        #ifdef USE_BATCHING
            mvPosition = batchingMatrix * mvPosition;
        #endif

        #ifdef USE_INSTANCING
            mvPosition = instanceMatrix * mvPosition;
        #endif

        mvPosition = modelViewMatrix * mvPosition;

        // Apply curvature displacement based on camera-space distance (mvPosition.z)
        // In view space, the camera looks down the negative Z axis.
        float dist = max(0.0, -mvPosition.z);
        
        // Curve downward on Y and outward on X
        mvPosition.y -= dist * dist * uCurvature.y;
        mvPosition.x += dist * dist * uCurvature.x;

        gl_Position = projectionMatrix * mvPosition;
    `;

    // Completely replace the default chunk
    shader.vertexShader = shader.vertexShader.replace(
        '#include <project_vertex>',
        customProjectVertex
    );
};

Curvature Math Explained

In camera (view) space:

  • The camera is located at the origin (0, 0, 0).
  • Visible objects occupy negative values along the Z-axis (mvPosition.z < 0.0).
  • Negating mvPosition.z yields the linear forward distance (dist) from the camera lens.

Squaring this distance (dist * dist) yields a parabolic curve. Multiplying this factor by the curvature uniform smoothly drops the geometry lower on the screen the further away it travels, creating an endless downhill horizon.

Handling Dynamic Shadows

If your scene uses directional light shadows, objects will cast linear shadows that do not match the curved visual meshes. To correct this, assign a matching customDepthMaterial to any shadow-casting mesh using the same shader override:

const depthMaterial = new THREE.MeshDepthMaterial({
    depthPacking: THREE.RGBADepthPacking
});

depthMaterial.onBeforeCompile = (shader) => {
    shader.uniforms.uCurvature = curvatureUniforms.uCurvature;
    shader.vertexShader = `uniform vec2 uCurvature;\n` + shader.vertexShader;
    shader.vertexShader = shader.vertexShader.replace(
        '#include <project_vertex>',
        customProjectVertex
    );
};

mesh.customDepthMaterial = depthMaterial;
mesh.castShadow = true;

This ensures the shadow map generation pipeline curves the vertices identically to the main camera render pass.
