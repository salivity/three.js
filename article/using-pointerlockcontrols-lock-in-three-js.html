Using PointerLockControls.lock() in Three.js

This guide explains how to capture the mouse cursor in a Three.js application using PointerLockControls.lock(). You will learn how to initialize the controls, trigger the lock request safely via user interaction, handle browser security restrictions, and detect lock state changes using built-in event listeners to create seamless first-person navigation.

Understanding PointerLockControls.lock()

In Three.js, PointerLockControls uses the browser's Pointer Lock API to hide the mouse cursor and deliver raw mouse movement delta values directly to the camera. This makes it ideal for first-person perspective (FPS) 3D environments.

Calling controls.lock() initiates this mouse capture. However, modern browsers restrict the Pointer Lock API so that it can only be triggered by a direct user interaction, such as a click or keydown event. Calling controls.lock() automatically on page load will result in an error or be ignored by the browser.

Implementation Steps

1. Import and Initialize the Controls

Import PointerLockControls from the Three.js add-ons directory and instantiate it by passing your scene's camera and the DOM element (typically document.body or the renderer's canvas).

import * as THREE from 'three';
import { PointerLockControls } from 'three/addons/controls/PointerLockControls.js';

// Setup camera and scene
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const scene = new THREE.Scene();

// Initialize controls
const controls = new PointerLockControls(camera, document.body);
scene.add(controls.object);

2. Trigger .lock() on User Action

Create an interactive trigger, such as a "Click to Play" overlay or button, to satisfy the browser's user activation requirement. When the user interacts with this element, call controls.lock().

const blocker = document.getElementById('blocker');
const playButton = document.getElementById('play-button');

playButton.addEventListener('click', () => {
  controls.lock();
});

3. Listen for State Changes

PointerLockControls fires 'lock' and 'unlock' events. Use these listeners to manage game states and UI visibility. The browser automatically exits pointer lock when the user presses the Escape key, triggering the 'unlock' event.

controls.addEventListener('lock', () => {
  // Hide UI instructions and enable in-game mechanics
  blocker.style.display = 'none';
});

controls.addEventListener('unlock', () => {
  // Show UI menu or pause screen
  blocker.style.display = 'block';
});

Complete Working Example

import * as THREE from 'three';
import { PointerLockControls } from 'three/addons/controls/PointerLockControls.js';

// Scene setup
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Controls setup
const controls = new PointerLockControls(camera, renderer.domElement);
scene.add(controls.object);

// User activation trigger
const instructions = document.createElement('div');
instructions.style.cssText = 'position:absolute;top:50%;left:50%;transform:translate(-50%,-50%);cursor:pointer;color:#fff;font-size:24px;font-family:sans-serif;';
instructions.innerText = 'Click to Play';
document.body.appendChild(instructions);

instructions.addEventListener('click', () => {
  controls.lock();
});

// Event handling
controls.addEventListener('lock', () => {
  instructions.style.display = 'none';
});

controls.addEventListener('unlock', () => {
  instructions.style.display = 'block';
});

// Animation loop
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}

animate();

Key Considerations

  • Transient Activation: Always bind controls.lock() to direct event handlers. Calling it inside asynchronous callbacks (like fetch or setTimeout) may break the execution context required by the browser's security model.
  • Exiting Lock Mode: To programmatically release the cursor without requiring the user to hit Escape, call controls.unlock().
  • Lock State Verification: You can check if the pointer is currently locked by inspecting the boolean property controls.isLocked.
