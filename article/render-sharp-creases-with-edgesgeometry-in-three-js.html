Render Sharp Creases with EdgesGeometry in Three.js

This guide explains how to properly configure the thresholdAngle parameter in Three.js's EdgesGeometry to highlight only distinct, hard creases on a 3D model. By tuning this property, you can eliminate unwanted triangulation lines on flat surfaces and ignore gentle curves, rendering only prominent mechanical edges and silhouette contours.

Understanding EdgesGeometry and thresholdAngle

EdgesGeometry generates line primitives by analyzing the angle between the face normals of adjacent triangles in a base BufferGeometry. The constructor accepts two parameters:

THREE.EdgesGeometry( geometry, thresholdAngle )
  • geometry: Any valid instance of THREE.BufferGeometry.
  • thresholdAngle: An angle expressed in degrees (default is 1).

An edge between two adjacent faces is only drawn if the angle between their face normals exceeds the thresholdAngle.

  • If the angle between adjacent face normals is greater than thresholdAngle, the edge is rendered.
  • If the angle between adjacent face normals is less than or equal to thresholdAngle, the edge is hidden.

Configuring for Sharp Creases

The default value of 1 degree causes almost every slight surface deviation—including flat geometry triangulation artifacts—to render as an edge. To isolate sharp creases, you must increase this value.

1. General Hard-Surface Meshes (15° to 30°)

For mechanical or CAD models containing both flat sections and beveled cuts, setting the angle between 15 and 30 degrees removes coplanar triangulation lines while preserving noticeable bends:

const geometry = new THREE.CylinderGeometry(5, 5, 20, 32);

// Only edges with adjacent face normal differences greater than 25 degrees will render
const edges = new THREE.EdgesGeometry(geometry, 25);
const lineMaterial = new THREE.LineBasicMaterial({ color: 0x000000 });
const wireframe = new THREE.LineSegments(edges, lineMaterial);

scene.add(wireframe);

In this cylinder example, a threshold of 25 degrees hides the vertical segments around the curved body (which meet at approximately 11.25 degrees) but retains the sharp 90-degree caps at the top and bottom.

2. Strict Right-Angle and Boxy Meshes (40° to 89°)

If your mesh contains smooth chamfers or higher-density rounding that you want to ignore completely, raise the threshold higher:

// Excludes chamfers under 45 degrees, capturing only primary structural edges
const edges = new THREE.EdgesGeometry(meshGeometry, 45);

Tuning Strategy

  1. Too many wireframe lines visible: The thresholdAngle is set too low. Increase the value in increments of 5° to 10° until internal triangulations on smooth or flat surfaces disappear.
  2. Missing key structural edges: The thresholdAngle is set too high. Lower the value toward the minimum crease angle you wish to highlight.
  3. Flat planar triangulation showing up: Ensure the threshold is at least 1 degree or higher to account for slight floating-point normal differences on flat surfaces.
