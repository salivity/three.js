Limit Three.js Raycaster Distance with Near and Far

In Three.js, raycasting is commonly used for mouse picking, collision detection, and line-of-sight checks. By default, a raycaster tests for intersections indefinitely into the scene from its origin, which can introduce unwanted interactions and degrade performance. This guide explains how to restrict intersection detection to a specific distance window using the near and far properties of the THREE.Raycaster.

Understanding the Near and Far Properties

The THREE.Raycaster object contains two threshold properties that define the active detection segment along the ray:

  • near: The minimum distance from the ray's origin at which an intersection can occur. The default value is 0. Any object closer than this value will be ignored.
  • far: The maximum distance from the ray's origin at which an intersection can occur. The default value is Infinity. Any object farther than this value will be ignored.

Together, these values define a range [near, far]. Only objects with surfaces falling within this specific distance will be returned in the intersection results.

Method 1: Setting Properties Directly

If you have an existing Raycaster instance, you can directly modify its near and far properties at any point before performing an intersection test:

import * as THREE from 'three';

const raycaster = new THREE.Raycaster();

// Restrict detection to objects between 1 and 15 units away
raycaster.near = 1;
raycaster.far = 15;

// Update the ray's origin and direction (e.g., from a camera)
raycaster.setFromCamera(mouse, camera);

// Perform the intersection check
const intersects = raycaster.intersectObjects(scene.children, true);

Method 2: Defining Limits in the Constructor

You can also specify the near and far values directly when instantiating the Raycaster. The constructor accepts four arguments: origin, direction, near, and far.

import * as THREE from 'three';

const origin = new THREE.Vector3(0, 1.5, 0);
const direction = new THREE.Vector3(0, 0, -1).normalize();
const minDistance = 0.5;
const maxDistance = 10;

// Initialize the raycaster with boundary constraints
const raycaster = new THREE.Raycaster(origin, direction, minDistance, maxDistance);

// Check for intersections within the specified 0.5 to 10 unit range
const intersects = raycaster.intersectObjects(targetObjects);

Practical Considerations

  • Units: The values assigned to near and far match the world units defined in your Three.js coordinate system.
  • Performance: Setting a realistic far limit prevents the engine from calculating deep intersection mathematics across distant, irrelevant meshes in large scenes.
  • First-Person Interactions: A common use case is character interaction (e.g., opening a door or picking up an item). Setting near = 0.1 and far = 3.0 ensures the player can only trigger actions when standing immediately in front of the target object.
