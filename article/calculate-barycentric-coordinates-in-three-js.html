Calculate Barycentric Coordinates in Three.js

This article provides an overview of the mathematical principles behind computing the exact barycentric coordinates of a point relative to a 3D triangle, followed by its implementation in Three.js. You will learn the underlying vector algebra based on Cramer's rule, how to handle non-coplanar projections, and how to execute this calculation both manually and using Three.js built-in utilities.

Understanding Barycentric Coordinates

Barycentric coordinates express any point \(P\) lying on the plane of a triangle defined by vertices \(A\), \(B\), and \(C\) as a weighted combination of those vertices:

\[P = uA + vB + wC\]

Subject to the partition of unity:

\[u + v + w = 1 \implies u = 1 - v - w\]

When all three weights (\(u, v, w\)) fall within the range \([0, 1]\), the point \(P\) lies strictly within or on the edges of the triangle.

Mathematical Formulation Using Cramer's Rule

To solve for the coordinates, define edge vectors originating from vertex \(A\):

  • \(\vec{v}_0 = B - A\)
  • \(\vec{v}_1 = C - A\)
  • \(\vec{v}_2 = P - A\)

Substitute \(u = 1 - v - w\) into the barycentric equation:

\[\vec{v}_2 = v \vec{v}_0 + w \vec{v}_1\]

Because this represents an overdetermined system in 3D space, multiply both sides by the dot product with \(\vec{v}_0\) and \(\vec{v}_1\) to project the vectors onto the triangle's 2D plane:

  1. \((\vec{v}_2 \cdot \vec{v}_0) = v (\vec{v}_0 \cdot \vec{v}_0) + w (\vec{v}_1 \cdot \vec{v}_0)\)
  2. \((\vec{v}_2 \cdot \vec{v}_1) = v (\vec{v}_0 \cdot \vec{v}_1) + w (\vec{v}_1 \cdot \vec{v}_1)\)

Let:

  • \(d_{00} = \vec{v}_0 \cdot \vec{v}_0\)
  • \(d_{01} = \vec{v}_0 \cdot \vec{v}_1\)
  • \(d_{11} = \vec{v}_1 \cdot \vec{v}_1\)
  • \(d_{20} = \vec{v}_2 \cdot \vec{v}_0\)
  • \(d_{21} = \vec{v}_2 \cdot \vec{v}_1\)

This forms a linear \(2 \times 2\) system:

\[\begin{bmatrix} d_{00} & d_{01} \\ d_{01} & d_{11} \end{bmatrix} \begin{bmatrix} v \\ w \end{bmatrix} = \begin{bmatrix} d_{20} \\ d_{21} \end{bmatrix}\]

Using Cramer's Rule, calculate the determinant of the matrix:

\[\text{denom} = d_{00} d_{11} - d_{01}^2\]

If \(\text{denom} = 0\), the triangle is degenerate (collinear vertices). Otherwise, solve for \(v\) and \(w\):

\[v = \frac{d_{11} d_{20} - d_{01} d_{21}}{\text{denom}}\]

\[w = \frac{d_{00} d_{21} - d_{01} d_{20}}{\text{denom}}\]

\[u = 1.0 - v - w\]

Implementation in Three.js

1. Manual Vector Calculation

You can implement this mathematical formulation directly using THREE.Vector3 methods:

import * as THREE from 'three';

function computeBarycentric(a, b, c, p, target = new THREE.Vector3()) {
  const v0 = new THREE.Vector3().subVectors(b, a);
  const v1 = new THREE.Vector3().subVectors(c, a);
  const v2 = new THREE.Vector3().subVectors(p, a);

  const d00 = v0.dot(v0);
  const d01 = v0.dot(v1);
  const d11 = v1.dot(v1);
  const d20 = v2.dot(v0);
  const d21 = v2.dot(v1);

  const denom = d00 * d11 - d01 * d01;

  if (Math.abs(denom) < 1e-6) {
    return target.set(0, 0, 0); // Degenerate triangle
  }

  const v = (d11 * d20 - d01 * d21) / denom;
  const w = (d00 * d21 - d01 * d20) / denom;
  const u = 1.0 - v - w;

  return target.set(u, v, w);
}

2. Native Three.js API

Three.js includes this calculation directly inside the THREE.Triangle utility class via .getBarycoord():

import * as THREE from 'three';

const a = new THREE.Vector3(0, 0, 0);
const b = new THREE.Vector3(1, 0, 0);
const c = new THREE.Vector3(0, 1, 0);
const point = new THREE.Vector3(0.25, 0.25, 0);

const triangle = new THREE.Triangle(a, b, c);
const barycoord = new THREE.Vector3();

triangle.getBarycoord(point, barycoord);

// Output: barycoord.x corresponds to u (weight of a)
//         barycoord.y corresponds to v (weight of b)
//         barycoord.z corresponds to w (weight of c)
console.log(barycoord); // Vector3 { x: 0.5, y: 0.25, z: 0.25 }

The native method performs the same algebraic steps, returning an exact set of barycentric coordinates \((u, v, w)\) mapped to the components \((x, y, z)\) of the target THREE.Vector3.
