How to Use KeyframeTrack.optimize in Three.js

In Three.js, complex animation clips imported from digital content creation tools often contain dense, redundant keyframe data that unnecessarily increases memory consumption and degrades runtime performance. This article explains how to utilize the KeyframeTrack.optimize() method to detect and purge duplicate keyframe values, significantly reducing the memory footprint of your animations while keeping their visual fidelity intact.

Understanding KeyframeTrack.optimize()

When animations are baked in 3D modeling software like Blender or Maya, keyframes are frequently placed on every single frame, even if an object remains completely stationary or maintains a constant rate of change. The KeyframeTrack.optimize() method scans a track's times and values arrays, identifying adjacent keys that share identical values or produce zero transformation delta. It then trims these redundant samples in-place.

Optimizing an Individual KeyframeTrack

To optimize a single track, call the .optimize() method directly on an instance of KeyframeTrack (or its derived classes like VectorKeyframeTrack, QuaternionKeyframeTrack, or NumberKeyframeTrack).

// Access a specific track from an AnimationClip
const track = animationClip.tracks[0];

console.log(`Original keyframes: ${track.times.length}`);

// Optimize the track in place
track.optimize();

console.log(`Optimized keyframes: ${track.times.length}`);

Optimizing an Entire AnimationClip

In most production environments, an animation consists of dozens or hundreds of tracks controlling positions, rotations, scales, and morph targets. Rather than iterating through each track manually, you can call AnimationClip.optimize(), which automatically triggers .optimize() on every KeyframeTrack inside the clip's tracks array.

import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

loader.load('character.glb', (gltf) => {
    const model = gltf.scene;
    const animations = gltf.animations;

    animations.forEach((clip) => {
        // Optimize all tracks inside the clip
        clip.optimize();
    });

    // Proceed with setting up the AnimationMixer
    const mixer = new THREE.AnimationMixer(model);
    const action = mixer.clipAction(animations[0]);
    action.play();
});

When to Run the Optimization

Execute .optimize() immediately after loading the animation asset and before instantiating your AnimationAction via the AnimationMixer. Running it before playback setup ensures that the mixer builds its internal interpolation cache using the smallest possible dataset, minimizing both CPU processing cycles and active RAM usage.
