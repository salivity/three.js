How to Load Quake MD2 Animations in Three.js

Loading vintage Quake-era vertex animation formats into a modern WebGL scene allows developers to render retro 3D assets with minimal overhead. This guide details how to import the classic MD2 format into Three.js using the specialized MD2Loader, apply the necessary texture maps, extract morph-target vertex animations, and drive playback inside a standard render loop.

1. Import Dependencies

Because the MD2 format is not part of the Three.js core bundle, you must import MD2Loader from the three/addons directory along with the standard library modules.

import * as THREE from 'three';
import { MD2Loader } from 'three/addons/loaders/MD2Loader.js';

2. Set Up the Scene and Loader

Create your standard Three.js scene, camera, and renderer. Then instantiate the MD2Loader and a TextureLoader to handle the external skin texture. MD2 files contain only mesh geometry and vertex keyframes; textures must be loaded separately (typically converted from vintage .pcx format to .png or .jpg).

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(45, window.innerWidth / window.innerHeight, 1, 1000);
camera.position.set(0, 50, 150);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

const ambientLight = new THREE.AmbientLight(0xffffff, 0.8);
scene.add(ambientLight);

const dirLight = new THREE.DirectionalLight(0xffffff, 1.2);
dirLight.position.set(100, 100, 50);
scene.add(dirLight);

const md2Loader = new MD2Loader();
const textureLoader = new THREE.TextureLoader();

3. Load the Mesh and Configure Materials

Load the texture and the .md2 file. The loader outputs a BufferGeometry populated with morph targets that represent the original per-vertex animation frames. Assign a material that supports vertex morphing, such as MeshStandardMaterial or MeshLambertMaterial.

let mixer;
const clock = new THREE.Clock();

textureLoader.load('models/ogre.png', (texture) => {
    texture.colorSpace = THREE.SRGBColorSpace;

    md2Loader.load('models/ogre.md2', (geometry) => {
        const material = new THREE.MeshLambertMaterial({
            map: texture,
            morphTargets: true
        });

        const mesh = new THREE.Mesh(geometry, material);
        mesh.scale.set(1.5, 1.5, 1.5);
        scene.add(mesh);

        // Set up the animation mixer
        mixer = new THREE.AnimationMixer(mesh);

        // Play the first animation sequence (e.g., 'stand' or 'run')
        if (geometry.animations && geometry.animations.length > 0) {
            const clip = geometry.animations[0];
            const action = mixer.clipAction(clip);
            action.play();
        }
    });
});

4. Drive Playback in the Animation Loop

Vertex keyframes in Three.js MD2 files are controlled via an AnimationMixer. In your continuous render loop, obtain the delta time from THREE.Clock and update the mixer to advance the vertex transitions smoothly.

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();
    if (mixer) {
        mixer.update(delta);
    }

    renderer.render(scene, camera);
}

animate();

5. Managing Named Animation Clips

MD2 files often contain sequential frames corresponding to standard Quake animation sequences (such as stand, run, attack, pain, and death). You can inspect the geometry.animations array returned by the loader to access individual AnimationClip objects by name or index, allowing you to transition between actions using standard AnimationAction.crossFadeTo() methods.
