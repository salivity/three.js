Convert Vector and Angle to Quaternion in Three.js

In Three.js, converting an arbitrary direction vector and an angle into a rotational quaternion is achieved using the Quaternion.setFromAxisAngle() method. This guide demonstrates how to properly prepare an arbitrary axis vector by normalizing it, define the rotation angle in radians, and apply the resulting quaternion to an object in a 3D scene.

Understanding the Requirements

The setFromAxisAngle(axis, angle) method expects two parameters:

  1. axis (THREE.Vector3): The direction vector around which the rotation occurs. This vector must be normalized (unit length of 1). If it is not normalized, the resulting rotation will produce invalid transformations or distorted rendering.
  2. angle (number): The rotation amount around the axis, expressed in radians (not degrees).

Step-by-Step Implementation

1. Define and Normalize the Direction Vector

Start with any arbitrary THREE.Vector3 representing the direction of the rotational axis, then call .normalize() to convert it to a unit vector. If the vector is (0, 0, 0), it cannot be normalized and will cause calculation errors.

import * as THREE from 'three';

// Arbitrary direction vector
const direction = new THREE.Vector3(1, 2, -1);

// Ensure the vector is a unit vector
direction.normalize();

2. Define the Angle in Radians

Angles in Three.js use radians. If your source angle is in degrees, convert it using THREE.MathUtils.degToRad().

// Using an angle in degrees and converting to radians
const angleInDegrees = 45;
const angleInRadians = THREE.MathUtils.degToRad(angleInDegrees);

// Alternatively, set radians directly (e.g., 90 degrees = Math.PI / 2)
// const angleInRadians = Math.PI / 4;

3. Create and Apply the Quaternion

Instantiate a THREE.Quaternion and call .setFromAxisAngle() with your normalized vector and angle.

const quaternion = new THREE.Quaternion();
quaternion.setFromAxisAngle(direction, angleInRadians);

Applying the Quaternion to an Object

You can apply the generated rotation directly to any Three.js Object3D (such as a Mesh or Camera) using either of the following approaches:

Approach A: Copying the Quaternion

mesh.quaternion.copy(quaternion);

Approach B: Setting Directly on the Object's Quaternion You do not need to create an intermediate quaternion instance if you are applying the rotation directly to an object:

mesh.quaternion.setFromAxisAngle(direction, angleInRadians);

Complete Code Example

import * as THREE from 'three';

function setRotationFromDirectionAndAngle(object, arbitraryVector, degrees) {
  // Prevent division by zero if an empty vector is provided
  if (arbitraryVector.lengthSq() === 0) {
    console.warn("Cannot create rotation around a zero-length axis.");
    return;
  }

  // Clone to avoid mutating the original vector, then normalize
  const axis = arbitraryVector.clone().normalize();
  const radians = THREE.MathUtils.degToRad(degrees);

  // Apply rotation
  object.quaternion.setFromAxisAngle(axis, radians);
}

// Usage:
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshBasicMaterial({ color: 0x00ff00 })
);

const arbitraryAxis = new THREE.Vector3(0.5, 1.0, 0.2);
setRotationFromDirectionAndAngle(cube, arbitraryAxis, 60);
