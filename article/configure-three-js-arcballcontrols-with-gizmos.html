Configure Three.js ArcballControls with Gizmos

This guide explains how to set up and configure the ArcballControls class in Three.js to provide intuitive, full-degree-of-freedom rotation using interactive visual gizmos. You will learn how to import the controller, pass the required scene references, toggle gizmo visibility, customize control behaviors, and ensure smooth rendering.

1. Import ArcballControls

ArcballControls is an add-on module and must be imported from the three/addons/ directory.

import * as THREE from 'three';
import { ArcballControls } from 'three/addons/controls/ArcballControls.js';

2. Initialize the Controls with the Scene

Unlike simpler controls like OrbitControls, ArcballControls requires a reference to the active THREE.Scene in its constructor if you want the built-in gizmos to render automatically.

const camera = new THREE.PerspectiveCamera( 45, window.innerWidth / window.innerHeight, 0.01, 1000 );
camera.position.set( 0, 0, 10 );

const renderer = new THREE.WebGLRenderer( { antialias: true } );
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

const scene = new THREE.Scene();

// Pass camera, domElement, and scene
const controls = new ArcballControls( camera, renderer.domElement, scene );

Passing scene as the third parameter automatically attaches the interactive control spheres and axes directly to your scene graph.

3. Enable and Configure Gizmos

The visual gizmo displays circular rings and axes that indicate the arcball sphere. Gizmos are visible by default when a scene is provided, but you can explicitly control their visibility and scale:

// Ensure gizmos are visible
controls.setGizmosVisible( true );

// Set gizmo size relative to the canvas (default is 0.67)
controls.setGizmoScale( 0.75 );

4. Fine-Tune Rotation and Control Behavior

To make rotation seamless, configure parameters that govern sensitivity, damping, and camera focus:

  • Cursor Centering: Set controls.cursorZoom = true to zoom toward the cursor position.
  • Camera Reset Point: Use controls.saveState() after positioning the camera so users can reset back to the default orientation.
  • Near/Far Adjustments: Enable automatic plane adjustment to prevent clipping while orbiting close objects:
controls.adjustNearFar = true;

5. Implement the Animation Loop

When updating the camera manually or relying on control animations, update the controls in your render loop:

function animate() {
    requestAnimationFrame( animate );

    // Required if controls.enableAnimations is true (default)
    controls.update();

    renderer.render( scene, camera );
}

animate();

Alternatively, if you only want to re-render when the user interacts, listen to the control events:

controls.addEventListener( 'change', () => {
    renderer.render( scene, camera );
} );

Complete Example

import * as THREE from 'three';
import { ArcballControls } from 'three/addons/controls/ArcballControls.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 45, window.innerWidth / window.innerHeight, 0.1, 100 );
camera.position.set( 2, 2, 5 );

const renderer = new THREE.WebGLRenderer( { antialias: true } );
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

// Add a mesh to visualize rotation
const geometry = new THREE.BoxGeometry();
const material = new THREE.MeshNormalMaterial();
scene.add( new THREE.Mesh( geometry, material ) );

// Setup ArcballControls
const controls = new ArcballControls( camera, renderer.domElement, scene );
controls.setGizmosVisible( true );
controls.adjustNearFar = true;

window.addEventListener( 'resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize( window.innerWidth, window.innerHeight );
} );

function render() {
    requestAnimationFrame( render );
    controls.update();
    renderer.render( scene, camera );
}

render();
