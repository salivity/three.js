Three.js MeshStandardNodeMaterial Shader Graph Guide

This article provides a practical guide to building complex, procedural shader graphs using MeshStandardNodeMaterial in Three.js. By shifting away from monolithic GLSL strings, the modern Three.js node material system enables developers to construct physically based materials using composable mathematical functions, procedural patterns, and texture nodes. You will learn how to initialize the material, assemble node networks, and bind procedural logic to standard PBR properties like base color, roughness, and normal maps.

Understanding the Three.js Node System

The Three.js node system abstracts GPU shading language operations into modular JavaScript objects. Instead of writing custom vertex and fragment shaders that manually calculate lighting, MeshStandardNodeMaterial retains the full Physically Based Rendering (PBR) pipeline—including environment map reflections, directional lighting, and shadows—while granting you node-level control over its surface inputs.

To build shader graphs, you import node functions directly from the Three.js library:

import { 
  MeshStandardNodeMaterial,
  color,
  float,
  vec2,
  uv,
  texture,
  timerLocal,
  sin,
  mix,
  mul,
  add,
  normalMap
} from 'three/nodes';

Initializing MeshStandardNodeMaterial

MeshStandardNodeMaterial acts as the root of your graph. Rather than accepting plain numeric or texture properties, its attributes accept node representations:

const material = new MeshStandardNodeMaterial();

The core properties you will attach nodes to include:

  • colorNode: Controls diffuse/albedo color.
  • roughnessNode: Modulates the microsurface roughness.
  • metalnessNode: Determines metallic reflectivity.
  • normalNode: Applies procedural or texture-based surface perturbation.
  • positionNode: Modifies vertex positions directly in the shader graph.

Building Procedural Math Chains

Nodes represent operations that evaluate at runtime on the GPU. You can combine vectors, uv coordinates, and mathematical functions to generate complex effects.

For example, to build an animated wave pattern:

// Sample UV coordinates
const uvCoords = uv();

// Animate coordinates using elapsed time
const time = timerLocal(1.0);
const animatedUV = add(uvCoords, vec2(time, time.mul(0.5)));

// Create a rhythmic wave pattern using a sine function
const wavePattern = sin(mul(animatedUV.x, float(20.0)));

Blending and Masking Values

The mix node works like the standard GLSL mix or HLSL lerp function. It blends between two inputs based on a third factor node, which functions as a mask:

const baseColor = color(0x1a365d);   // Deep blue
const accentColor = color(0x00f5d4); // Neon cyan

// Use the wave pattern (remapped between 0 and 1) as a mask
const normalizedWave = add(mul(wavePattern, 0.5), 0.5);
const dynamicColor = mix(baseColor, accentColor, normalizedWave);

// Assign the blended node to the material's albedo
material.colorNode = dynamicColor;

Modulating Roughness and Metallic Properties

Shader graphs achieve realism by linking different PBR channels to shared procedural nodes. For instance, you can use the same wave mask to vary surface reflectivity:

const smoothRoughness = float(0.1);
const roughSurface = float(0.85);

// The accent color areas become highly polished, while the base color remains matte
material.roughnessNode = mix(roughSurface, smoothRoughness, normalizedWave);
material.metalnessNode = float(0.2);

Complete Implementation Example

The following script combines procedural math, UV manipulation, and dynamic property assignment into a complete shader graph:

import * as THREE from 'three';
import {
  MeshStandardNodeMaterial,
  color,
  float,
  uv,
  timerLocal,
  sin,
  cos,
  add,
  mul,
  mix
} from 'three/nodes';

// 1. Instantiate the node material
const material = new MeshStandardNodeMaterial({
  roughness: 0.5,
  metalness: 0.1
});

// 2. Define coordinate inputs
const baseUV = uv();
const time = timerLocal(0.75);

// 3. Construct coordinate distortions
const distortedCoords = add(
  baseUV,
  mul(sin(add(mul(baseUV.y, float(12.0)), time)), float(0.05))
);

// 4. Generate layered patterns
const patternA = sin(mul(distortedCoords.x, float(16.0)));
const patternB = cos(mul(distortedCoords.y, float(16.0)));
const combinedMask = mul(add(patternA, patternB), float(0.5));

// 5. Connect graph outputs to PBR channels
const darkPBRColor = color(0x0f172a);
const lightPBRColor = color(0x38bdf8);

material.colorNode = mix(darkPBRColor, lightPBRColor, combinedMask);
material.roughnessNode = mix(float(0.1), float(0.9), combinedMask);
material.metalnessNode = mix(float(0.8), float(0.0), combinedMask);

// 6. Apply to a mesh
const geometry = new THREE.TorusKnotGeometry(1, 0.3, 128, 32);
const mesh = new THREE.Mesh(geometry, material);

Advantages of the Node-Based Workflow

By constructing shader logic through MeshStandardNodeMaterial, the graph automatically optimizes into underlying shader code targeting WebGL or WebGPU. Math nodes are type-safe and evaluate without parsing errors typical of string-based GLSL. Furthermore, lights, shadows, and environment probes continue to function out-of-the-box, ensuring high visual fidelity without writing boilerplate rendering code.
