Three.js LatheGeometry phiStart and phiLength Guide

In Three.js, LatheGeometry generates a 3D mesh by revolving a 2D profile curve around the Y-axis. While the default behavior produces a closed, 360-degree solid, the phiStart and phiLength parameters allow you to control the exact starting angle and sweep arc of the revolution. By setting these values, you can create partial revolutions such as cross-sections, open bowls, curved shields, or sliced cylinders.

Understanding the Parameters

The constructor for LatheGeometry accepts four arguments:

new THREE.LatheGeometry(points, segments, phiStart, phiLength);
  • points: An array of THREE.Vector2 objects defining the 2D contour to revolve.
  • segments: An integer defining the number of horizontal subdivisions along the circumference (default is 12).
  • phiStart: The starting radian angle of the revolution around the Y-axis (default is 0).
  • phiLength: The radian span of the revolution sweep (default is Math.PI * 2, representing 360 degrees).

Because both parameters are measured in radians rather than degrees, you must use Math.PI or the THREE.MathUtils.degToRad() utility to specify angles.

Creating a Partial Revolution

To create a partial revolution, pass custom radian values for phiStart and phiLength.

For example, to create a half-revolution (180 degrees) starting from the default position:

import * as THREE from 'three';

// 1. Define the 2D profile
const points = [];
for (let i = 0; i < 10; i++) {
  points.push(new THREE.Vector2(Math.sin(i * 0.2) * 3 + 3, (i - 5) * 2));
}

// 2. Set phiStart and phiLength for a 180-degree sweep
const segments = 16;
const phiStart = 0;
const phiLength = Math.PI; // 180 degrees in radians

// 3. Create the geometry
const geometry = new THREE.LatheGeometry(points, segments, phiStart, phiLength);

// 4. Create a mesh with DoubleSide rendering
const material = new THREE.MeshStandardMaterial({ 
  color: 0x2194ce, 
  side: THREE.DoubleSide 
});

const latheMesh = new THREE.Mesh(geometry, material);

Offsetting the Rotation with phiStart

If you want a 90-degree quadrant that begins at a 45-degree angle relative to the positive X-axis, adjust both values accordingly:

const phiStart = THREE.MathUtils.degToRad(45);  // Starts at 45°
const phiLength = THREE.MathUtils.degToRad(90); // Sweeps 90° forward
const geometry = new THREE.LatheGeometry(points, 16, phiStart, phiLength);

Key Considerations

  • Double-Sided Materials: Unlike fully closed meshes, partial revolutions expose both the interior and exterior faces of the generated shape. Always set side: THREE.DoubleSide on your material so the inside faces are not culled during rendering.
  • Segment Distribution: The segments parameter distributes divisions strictly across the span defined by phiLength. A lower phiLength requires fewer segments to maintain a smooth curve compared to a full 360-degree rotation.
