Calculate Polygon Area Using Three.js ShapeUtils

Calculating the 2D area of a polygon in Three.js is straightforward thanks to the built-in ShapeUtils utility class. This guide explains how to pass an array of THREE.Vector2 points to the ShapeUtils.area() method to compute the area of a polygon, how winding order affects the resulting value, and how to ensure you always get an absolute positive area.

Using ShapeUtils.area()

Three.js provides the static method ShapeUtils.area(contour) to compute the area of a 2D closed contour. The contour parameter accepts an array of points containing x and y properties, such as instances of THREE.Vector2.

Here is a complete code example:

import * as THREE from 'three';

// Define the polygon vertices in order
const points = [
    new THREE.Vector2(0, 0),
    new THREE.Vector2(4, 0),
    new THREE.Vector2(4, 3),
    new THREE.Vector2(0, 3)
];

// Calculate the signed area
const signedArea = THREE.ShapeUtils.area(points);

// Calculate the absolute area
const area = Math.abs(signedArea);

console.log(`Polygon Area: ${area}`); // Output: Polygon Area: 12

Understanding Signed Area and Winding Order

The ShapeUtils.area() function uses the Shoelace formula (Gauss's area formula) internally. Because of this, the returned value is a signed number:

  • Positive value: The vertices are ordered counter-clockwise (CCW).
  • Negative value: The vertices are ordered clockwise (CW).

Because the sign indicates the winding orientation of the polygon, you should wrap the output in Math.abs() when you only need the geometric surface area.

Handling Holes and Complex Polygons

If your shape contains interior holes (such as a donut shape), you must calculate the area of the outer contour and subtract the areas of any inner hole contours:

const outerPoints = [
    new THREE.Vector2(0, 0),
    new THREE.Vector2(10, 0),
    new THREE.Vector2(10, 10),
    new THREE.Vector2(0, 10)
];

const holePoints = [
    new THREE.Vector2(2, 2),
    new THREE.Vector2(8, 2),
    new THREE.Vector2(8, 8),
    new THREE.Vector2(2, 8)
];

const outerArea = Math.abs(THREE.ShapeUtils.area(outerPoints));
const holeArea = Math.abs(THREE.ShapeUtils.area(holePoints));

const finalArea = outerArea - holeArea; // 100 - 36 = 64

Key Considerations

  • Self-Intersecting Polygons: The Shoelace formula assumes a simple, non-self-intersecting polygon. Complex or self-crossing shapes will yield incorrect area calculations.
  • Vertex Ordering: The array of THREE.Vector2 points must be provided sequentially along the perimeter of the polygon. Providing points out of order will result in an incorrect calculation.
  • Automatic Closure: You do not need to repeat the starting point at the end of the array; ShapeUtils.area() automatically connects the final vertex back to the first vertex.
