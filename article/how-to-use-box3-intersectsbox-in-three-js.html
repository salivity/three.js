How to Use Box3 intersectsBox in Three.js

Detecting collisions between 3D objects is a fundamental task in game development and interactive 3D applications. In Three.js, you can perform fast, broad-phase collision detection using Axis-Aligned Bounding Boxes (AABB) provided by the Box3 class. This article explains how to compute bounding boxes for your meshes, keep them synchronized with movement, and check for overlaps using the Box3.intersectsBox method.

What is Box3.intersectsBox?

A THREE.Box3 represents an axis-aligned bounding box defined by a min and max point in 3D space. The intersectsBox() method takes another Box3 instance as an argument and returns a boolean value: true if the two bounding boxes overlap, and false if they do not. Because this check only compares numerical coordinates along the X, Y, and Z axes, it is computationally lightweight and ideal for real-time checks.

Basic Implementation

To check for a collision between two objects, create two Box3 instances and wrap each object with setFromObject().

import * as THREE from 'three';

// 1. Create your 3D objects
const geometry = new THREE.BoxGeometry(1, 1, 1);

const meshA = new THREE.Mesh(geometry, new THREE.MeshBasicMaterial());
const meshB = new THREE.Mesh(geometry, new THREE.MeshBasicMaterial());

meshA.position.set(0, 0, 0);
meshB.position.set(0.5, 0, 0); // Positioned to overlap with meshA

scene.add(meshA);
scene.add(meshB);

// 2. Instantiate Box3 objects
const boxA = new THREE.Box3();
const boxB = new THREE.Box3();

// 3. Compute the bounding boxes from the objects
boxA.setFromObject(meshA);
boxB.setFromObject(meshB);

// 4. Test for intersection
const isColliding = boxA.intersectsBox(boxB);

if (isColliding) {
    console.log("Collision detected!");
} else {
    console.log("No collision.");
}

Checking Collisions in the Animation Loop

When objects move or rotate, their bounding boxes must be recalculated to match their updated world positions before performing the collision test. Place the setFromObject() and intersectsBox() calls inside your render or animation loop.

function animate() {
    requestAnimationFrame(animate);

    // Update object positions
    meshA.position.x += 0.01;

    // Update bounding boxes to reflect new world coordinates
    boxA.setFromObject(meshA);
    boxB.setFromObject(meshB);

    // Verify collision
    if (boxA.intersectsBox(boxB)) {
        meshA.material.color.set(0xff0000); // Red on collision
    } else {
        meshA.material.color.set(0x00ff00); // Green when clear
    }

    renderer.render(scene, camera);
}

animate();

Key Considerations

  • Axis Alignment: Box3 boxes are always aligned with the global coordinate axes and do not rotate with the object. If an object rotates, setFromObject() expands the bounding box to encapsulate the rotated shape, which may lead to false positives on elongated objects.
  • Hierarchy: setFromObject() calculates the bounding box for an object and all of its children. Ensure your object hierarchy only contains the meshes you want included in the collision volume.
  • Performance: While intersectsBox() is extremely fast, recalculating setFromObject() involves traversing geometry vertices. For complex geometries, consider using a simplified proxy mesh (such as a low-poly invisible box) to compute the Box3.
