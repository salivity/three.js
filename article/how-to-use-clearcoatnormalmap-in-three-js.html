How to Use clearcoatNormalMap in Three.js

In Three.js, you can add distinct surface imperfections like scratches, scuffs, or an orange-peel effect to an object's protective top coat without affecting the underlying surface by using the clearcoatNormalMap property. This guide explains how to implement MeshPhysicalMaterial, load your normal map texture, and configure clearcoat-specific normal properties to achieve realistic, layered physical materials.

Understanding clearcoatNormalMap

The MeshPhysicalMaterial extends MeshStandardMaterial to provide an advanced clearcoat layer, simulating a thin, transparent protective coating often found on car paint, carbon fiber, or varnished wood.

While the standard normalMap property alters the geometry's base surface normals (affecting the underlying color and roughness), clearcoatNormalMap specifically perturbs the specular highlights of the clearcoat layer alone. This allows the base layer to remain smooth or possess a completely different bump pattern from the outer layer.

Step-by-Step Implementation

1. Initialize the TextureLoader

Load the texture you intend to use for the bumpy clearcoat surface:

import * as THREE from 'three';

const textureLoader = new THREE.TextureLoader();
const clearcoatBumpMap = textureLoader.load('path/to/clearcoat_normal.png');

2. Configure MeshPhysicalMaterial

To enable clearcoat effects, instantiate a MeshPhysicalMaterial. You must set the clearcoat property to a value greater than 0 (typically 1.0 for a fully coated finish) and assign your texture to clearcoatNormalMap.

const material = new THREE.MeshPhysicalMaterial({
  color: 0x156289,
  metalness: 0.1,
  roughness: 0.2,

  // Enable the clearcoat layer
  clearcoat: 1.0,
  clearcoatRoughness: 0.1,

  // Apply the clearcoat normal map
  clearcoatNormalMap: clearcoatBumpMap,
  clearcoatNormalScale: new THREE.Vector2(0.5, 0.5)
});

3. Adjust the Effect with clearcoatNormalScale

You can adjust the depth and intensity of the bumps using clearcoatNormalScale, which takes a THREE.Vector2:

  • Higher values (e.g., (1.0, 1.0) or greater): Produces deeper ridges, heavy scratches, or pronounced lacquer ripples.
  • Lower values (e.g., (0.1, 0.1)): Produces subtle microscopic imperfections like faint wipe marks or mild orange peel.
  • Independent axes: You can scale X and Y independently to stretch or orient the direction of the surface noise.

Combining Base and Clearcoat Normals

You can pair clearcoatNormalMap with a base normalMap for multi-layered realism:

const baseNormal = textureLoader.load('path/to/carbon_weave_normal.png');
const clearcoatScratchNormal = textureLoader.load('path/to/lacquer_scratches.png');

const layeredMaterial = new THREE.MeshPhysicalMaterial({
  color: 0x222222,
  roughness: 0.4,
  normalMap: baseNormal, // Governs the base weave texture
  
  clearcoat: 1.0,
  clearcoatRoughness: 0.05,
  clearcoatNormalMap: clearcoatScratchNormal, // Governs outer lacquer scratches
  clearcoatNormalScale: new THREE.Vector2(0.2, 0.2)
});

In this setup, reflections from lighting will independently catch the deep geometry of the base pattern as well as the fine, high-gloss surface scratches on the protective clearcoat.
