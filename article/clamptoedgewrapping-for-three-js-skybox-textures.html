ClampToEdgeWrapping for Three.js Skybox Textures

Visible seams and edge artifacts in a Three.js skybox typically occur when texture sampling bleeds past the boundary of a face texture. Setting the wrapS (horizontal) and wrapT (vertical) properties of your textures to THREE.ClampToEdgeWrapping ensures that texture coordinates are clamped to the range between 0.0 and 1.0, preventing the renderer from sampling the opposite edge or border pixels. This guide demonstrates how to configure these wrapping properties across skybox textures to produce seamless background environments.

Why Skybox Seams Occur

When a skybox is rendered using standard box geometry and six separate textures, linear filtering and mipmapping can cause the GPU to sample texels outside the boundary of each individual image. By default, textures may repeat or sample undefined border areas, resulting in thin, noticeable lines along the edges where the cube faces meet. Clamping the texture to its edges stretches the outermost pixel row and column to infinity, eliminating edge bleeding.

Configuring wrapS and wrapT on a Box Skybox

If you are constructing a skybox using THREE.BoxGeometry and an array of materials loaded via THREE.TextureLoader, set wrapS and wrapT directly on each loaded texture instance before assigning it to a material.

import * as THREE from 'three';

const loader = new THREE.TextureLoader();

// Array of image paths for the 6 faces: px, nx, py, ny, pz, nz
const skyboxImagePaths = [
  'textures/px.jpg',
  'textures/nx.jpg',
  'textures/py.jpg',
  'textures/ny.jpg',
  'textures/pz.jpg',
  'textures/nz.jpg',
];

const materialArray = skyboxImagePaths.map((path) => {
  const texture = loader.load(path);

  // Configure wrapping modes to clamp to the edge
  texture.wrapS = THREE.ClampToEdgeWrapping;
  texture.wrapT = THREE.ClampToEdgeWrapping;

  // Optional: Prevent mipmap bleeding across cube edges
  texture.minFilter = THREE.LinearFilter;
  texture.generateMipmaps = false;

  return new THREE.MeshBasicMaterial({
    map: texture,
    side: THREE.BackSide,
  });
});

const skyboxGeometry = new THREE.BoxGeometry(1000, 1000, 1000);
const skybox = new THREE.Mesh(skyboxGeometry, materialArray);
scene.add(skybox);

Configuring wrapS and wrapT for Equirectangular Maps

If you are using a single 360-degree panoramic image applied to a sphere or via scene.background, you can apply edge clamping to prevent vertical pole distortion:

import * as THREE from 'three';

const loader = new THREE.TextureLoader();

loader.load('textures/equirectangular_skybox.jpg', (texture) => {
  texture.wrapS = THREE.ClampToEdgeWrapping;
  texture.wrapT = THREE.ClampToEdgeWrapping;
  texture.minFilter = THREE.LinearFilter;

  // Assign to scene background or mapping target
  texture.mapping = THREE.EquirectangularReflectionMapping;
  scene.background = texture;
});

Best Practices for Seamless Skyboxes

  • Disable Mipmaps If Seams Persist: Even with ClampToEdgeWrapping, lower-resolution mipmaps can still blend edge pixels. Setting texture.generateMipmaps = false and texture.minFilter = THREE.LinearFilter guarantees that mipmaps will not generate edge artifacts.
  • Update Texture Flags: If modifying wrapS or wrapT on a texture that has already been uploaded to the GPU, flag it for an update by setting texture.needsUpdate = true.
