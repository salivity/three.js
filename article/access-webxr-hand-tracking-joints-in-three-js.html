Access WebXR Hand Tracking Joints in Three.js

This article explains how to access and extract individual joint transformations—such as position, orientation, and radius—from a hand tracked via WebXR in Three.js. By configuring the WebXR manager, retrieving hand controller instances, and querying specific named joints during the render loop, you can drive custom mechanics, gesture recognition, or interactive physics in your immersive 3D applications.

Enabling WebXR Hand Tracking

To use hand tracking in Three.js, ensure your WebGL renderer has WebXR enabled and is added to an active session that supports the hand-tracking feature.

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.xr.enabled = true;
document.body.appendChild(renderer.domElement);

When requesting the WebXR session (often handled via VRButton.createButton(renderer, { optionalFeatures: ['hand-tracking'] })), the browser requests access to the underlying hardware's hand-tracking data.

Getting the Hand Instances

Three.js abstracts WebXR hands through renderer.xr.getHand(index). The index corresponds to the input source index (0 for the first detected hand, 1 for the second).

const hand0 = renderer.xr.getHand(0);
scene.add(hand0);

const hand1 = renderer.xr.getHand(1);
scene.add(hand1);

When a hand is tracked, Three.js populates the joints property on the hand object. This property maps standard WebXR joint identifiers to Three.js Group or Bone objects, which are automatically updated each frame with the latest spatial transformations.

Standard Joint Names

WebXR defines 25 standard joints for each hand. The most commonly used identifiers include:

  • Wrist: 'wrist'
  • Thumb: 'thumb-metacarpal', 'thumb-phalanx-proximal', 'thumb-phalanx-distal', 'thumb-tip'
  • Index Finger: 'index-finger-metacarpal', 'index-finger-phalanx-proximal', 'index-finger-phalanx-intermediate', 'index-finger-phalanx-distal', 'index-finger-tip'
  • Middle Finger: 'middle-finger-metacarpal', 'middle-finger-phalanx-proximal', 'middle-finger-phalanx-intermediate', 'middle-finger-phalanx-distal', 'middle-finger-tip'
  • Ring Finger: 'ring-finger-metacarpal', 'ring-finger-phalanx-proximal', 'ring-finger-phalanx-intermediate', 'ring-finger-phalanx-distal', 'ring-finger-tip'
  • Pinky Finger: 'pinky-finger-metacarpal', 'pinky-finger-phalanx-proximal', 'pinky-finger-phalanx-intermediate', 'pinky-finger-phalanx-distal', 'pinky-finger-tip'

Reading Transformations via Three.js Joint Objects

Once hand tracking is active, access specific joints directly through the joints dictionary of the hand instance. Each joint provides standard Three.js transformation properties: position, quaternion, rotation, and matrixWorld.

const indexTipPosition = new THREE.Vector3();
const indexTipQuaternion = new THREE.Quaternion();

function checkJointData(hand) {
  // Verify that joints are populated and the specific joint exists
  const indexTip = hand.joints['index-finger-tip'];

  if (indexTip) {
    // Read local transformation
    const localPosition = indexTip.position;
    const localRotation = indexTip.quaternion;

    // Read world transformation
    indexTip.getWorldPosition(indexTipPosition);
    indexTip.getWorldQuaternion(indexTipQuaternion);

    // Read joint radius (in meters) if provided by the device
    const jointRadius = indexTip.jointRadius;

    console.log(`Index Tip World Position: ${indexTipPosition.x}, ${indexTipPosition.y}, ${indexTipPosition.z}`);
  }
}

Reading Joint Data in the Render Loop

Place the extraction logic inside the WebXR-compatible animation loop (setAnimationLoop) to monitor transformations on every frame:

renderer.setAnimationLoop(() => {
  // Check the left or right hand
  if (hand0.visible) {
    const wrist = hand0.joints['wrist'];
    const indexTip = hand0.joints['index-finger-tip'];

    if (wrist && indexTip) {
      const distance = wrist.position.distanceTo(indexTip.position);
      // Perform gameplay mechanics or gesture detection using the distance
    }
  }

  renderer.render(scene, camera);
});

Low-Level Access via Native WebXR Frame

If direct access to the raw WebXR data is required instead of Three.js object wrappers, use renderer.xr.getFrame() and the native XRHand interface:

renderer.setAnimationLoop((timestamp, frame) => {
  if (frame) {
    const referenceSpace = renderer.xr.getReferenceSpace();
    const session = renderer.xr.getSession();

    for (const inputSource of session.inputSources) {
      if (inputSource.hand) {
        const indexTipJoint = inputSource.hand.get('index-finger-tip');
        const jointPose = frame.getJointPose(indexTipJoint, referenceSpace);

        if (jointPose) {
          const { x, y, z } = jointPose.transform.position;
          const orientation = jointPose.transform.orientation;
          const radius = jointPose.radius;
        }
      }
    }
  }

  renderer.render(scene, camera);
});

For most use cases, querying hand.joints[jointName] through the standard Three.js hand object is the most efficient and idiomatic approach.
