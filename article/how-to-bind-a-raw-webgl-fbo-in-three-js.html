How to Bind a Raw WebGL FBO in Three.js

This article explains how to create, bind, and render to a custom raw WebGL Framebuffer Object (FBO) within a Three.js application. While Three.js manages its own render targets and internal state cache, integrating custom WebGL rendering routines requires manually binding your FBO, adjusting the viewport, and synchronizing state using Three.js APIs so the engine does not conflict with direct WebGL draw calls.

Accessing the WebGL Context and Creating the FBO

Three.js abstracts WebGL calls through THREE.WebGLRenderer. To run raw WebGL commands, retrieve the underlying WebGL rendering context directly from the renderer using renderer.getContext().

Once you have the context, generate your standard WebGL texture, renderbuffer (for depth/stencil if needed), and the Framebuffer Object:

const gl = renderer.getContext();

// 1. Create a texture to act as the color attachment
const targetTexture = gl.createTexture();
gl.bindTexture(gl.TEXTURE_2D, targetTexture);
gl.texImage2D(
  gl.TEXTURE_2D, 0, gl.RGBA,
  width, height, 0,
  gl.RGBA, gl.UNSIGNED_BYTE, null
);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);

// 2. Create the Framebuffer Object
const customFBO = gl.createFramebuffer();
gl.bindFramebuffer(gl.FRAMEBUFFER, customFBO);

// 3. Attach the texture to the framebuffer
gl.framebufferTexture2D(
  gl.FRAMEBUFFER,
  gl.COLOR_ATTACHMENT0,
  gl.TEXTURE_2D,
  targetTexture,
  0
);

// 4. Validate completeness
const status = gl.checkFramebufferStatus(gl.FRAMEBUFFER);
if (status !== gl.FRAMEBUFFER_COMPLETE) {
  console.error('Framebuffer is incomplete:', status);
}

// Unbind to prevent accidental modifications
gl.bindFramebuffer(gl.FRAMEBUFFER, null);
gl.bindTexture(gl.TEXTURE_2D, null);

Managing State Synchronization

Three.js tracks the active WebGL state (bound buffers, active programs, blend modes, depth testing, and framebuffers) internally to minimize redundant GPU driver commands. If you alter WebGL state using raw gl calls without notifying Three.js, rendering glitches or crashes occur.

To safely bind your raw FBO:

  1. Tell Three.js to deactivate its current target by calling renderer.setRenderTarget(null).
  2. Bind your raw FBO via gl.bindFramebuffer(gl.FRAMEBUFFER, customFBO).
  3. Set your custom viewport using gl.viewport(0, 0, width, height).
  4. Perform your raw WebGL draw operations.
  5. Notify Three.js that the WebGL state has changed by executing renderer.resetState().

Implementing the Render Loop

Incorporate the raw WebGL execution before or after the standard Three.js render pass:

function render() {
  requestAnimationFrame(render);

  // --- Step 1: Prepare Three.js for raw WebGL passes ---
  renderer.setRenderTarget(null);

  // --- Step 2: Bind Custom Raw FBO ---
  gl.bindFramebuffer(gl.FRAMEBUFFER, customFBO);
  gl.viewport(0, 0, width, height);

  // Optional: Clear custom buffer
  gl.clearColor(0.0, 0.0, 0.0, 1.0);
  gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

  // --- Step 3: Run Native WebGL Calls ---
  gl.useProgram(customShaderProgram);
  gl.bindVertexArray(customVAO);
  gl.drawArrays(gl.TRIANGLES, 0, 3);

  // --- Step 4: Reset Three.js State ---
  // Unbind custom resources
  gl.bindFramebuffer(gl.FRAMEBUFFER, null);

  // Invalidate Three.js state cache to restore consistency
  renderer.resetState();

  // --- Step 5: Render Standard Three.js Scene ---
  renderer.render(scene, camera);
}

Key Technical Considerations

  • renderer.resetState() Overhead: Calling renderer.resetState() forces Three.js to re-bind textures, re-enable attributes, and re-apply blending modes for its own subsequent draw calls. Keep raw WebGL logic grouped together in the frame loop to minimize calls to resetState().
  • Viewport Restorations: Raw WebGL updates to gl.viewport bypass the Three.js viewport cache. When switching back to Three.js, ensure renderer.setViewport() or renderer.resetState() is invoked so Three.js updates the canvas dimensions correctly.
  • Consuming the Raw FBO Texture in Three.js: To use your raw FBO’s color attachment inside a Three.js material, wrap it inside a THREE.WebGLRenderTarget or inject it into a custom shader using rawShaderMaterial via a uniform referencing a wrapped THREE.Texture instance with its isWebGLTexture property set to point to targetTexture.
