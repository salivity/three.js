Enable WebXR Plane Detection in Three.js AR

This article explains how to configure a WebXR immersive-ar session with plane detection capabilities using Three.js. You will learn how to properly request the plane-detection WebXR feature flag, configure the WebGLRenderer, initialize the AR session, and process detected horizontal and vertical planes inside the rendering loop.

1. Enable WebXR on the Three.js Renderer

First, instantiate your Three.js WebGLRenderer and enable the XR system.

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.xr.enabled = true;
document.body.appendChild(renderer.domElement);

2. Request the Plane Detection Feature

WebXR features must be explicitly declared as required or optional when requesting an immersive-ar session. The WebXR Plane Detection API uses the feature identifier 'plane-detection'.

If you are using Three.js's built-in ARButton utility, pass the feature request inside the session options object:

import { ARButton } from 'three/addons/webxr/ARButton.js';

const sessionInit = {
  requiredFeatures: ['plane-detection']
};

document.body.appendChild(ARButton.createButton(renderer, sessionInit));

If you manage the session manually via the browser's WebXR Device API:

navigator.xr.requestSession('immersive-ar', {
  requiredFeatures: ['plane-detection', 'local']
}).then((session) => {
  renderer.xr.setSession(session);
});

3. Retrieve Detected Planes in the Render Loop

Once the session is active, the XRFrame provides access to the detectedPlanes attribute, which returns a Set of XRPlane objects.

Use renderer.setAnimationLoop to access the XRFrame and the current reference space on every frame:

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera();

renderer.setAnimationLoop((timestamp, frame) => {
  if (frame) {
    const referenceSpace = renderer.xr.getReferenceSpace();

    // Check if the plane detection API is supported and active
    if (frame.detectedPlanes) {
      frame.detectedPlanes.forEach((plane) => {
        // Retrieve the pose of the plane relative to the reference space
        const planePose = frame.getPose(plane.planeSpace, referenceSpace);

        if (planePose) {
          // Access plane orientation: 'horizontal' or 'vertical'
          const orientation = plane.orientation;

          // Access the 2D polygon vertices defining the perimeter
          const polygon = plane.polygon; // Array of DOMPointReadOnly

          // Access transformation matrix
          const matrix = planePose.transform.matrix;

          // Update or create your Three.js mesh using the matrix and polygon
        }
      });
    }
  }

  renderer.render(scene, camera);
});

4. Handling Plane Geometry

Each XRPlane updates its polygon and lastChangedTime attributes as the underlying AR tracking system refines its understanding of the environment.

To visualize planes in Three.js:

  1. Create a THREE.BufferGeometry using the 2D coordinates in plane.polygon (using x and z coordinates from the points).
  2. Apply the planePose.transform.matrix directly to a THREE.Mesh by setting mesh.matrixAutoUpdate = false and calling mesh.matrix.fromArray(planePose.transform.matrix).
  3. Check plane.lastChangedTime to avoid re-generating the geometry on frames where the physical boundaries have not changed.
