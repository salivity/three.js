How to Spin a Texture Pattern in Three.js

Rotating a material's texture in Three.js requires adjusting the texture's rotation property and properly defining its pivot point using the center property. By default, textures rotate around their bottom-left corner, causing an off-center sweep rather than a centered spin. By moving the pivot point to the middle of the UV coordinates and incrementally updating the rotation angle within your animation loop, you can smoothly spin any texture pattern across a 3D mesh.

Setting the Pivot with the Center Property

Textures in Three.js use UV coordinates ranging from 0.0 to 1.0. By default, texture.center is initialized to (0, 0), which corresponds to the bottom-left corner of the image.

To spin the texture in place around its own center, set the center property to (0.5, 0.5):

texture.center.set(0.5, 0.5);

If you skip this step, rotating the texture will cause the pattern to swing widely around the corner rather than spinning centrally.

Adjusting Texture Rotation

The texture.rotation property defines the rotation angle measured in radians. A positive value rotates the texture counter-clockwise, while a negative value rotates it clockwise.

To set a static rotation of 45 degrees:

texture.rotation = Math.PI / 4;

Configuring Texture Wrapping

When spinning a pattern, corners of the texture may rotate outside the standard [0, 1] UV boundary. To prevent the edges from stretching or clamping, configure the wrapping modes to repeat:

texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;

Animating the Spin

To create a continuous spinning effect, increment the rotation property inside the render or animation loop.

Here is a complete implementation:

import * as THREE from 'three';

// 1. Load the texture
const textureLoader = new THREE.TextureLoader();
const texture = textureLoader.load('path/to/pattern.jpg');

// 2. Configure wrapping and pivot point
texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;
texture.center.set(0.5, 0.5);

// 3. Apply to a material and mesh
const material = new THREE.MeshStandardMaterial({ map: texture });
const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// 4. Spin the texture in the animation loop
function animate() {
  requestAnimationFrame(animate);

  // Increment rotation angle
  texture.rotation += 0.01;

  renderer.render(scene, camera);
}

animate();

By adjusting the value added to texture.rotation on each frame, you can control the speed and direction of the spinning pattern.
