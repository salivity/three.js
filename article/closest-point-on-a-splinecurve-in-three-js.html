Closest Point on a SplineCurve in Three.js

This article explains how to mathematically calculate the absolute closest point on a Three.js SplineCurve to an arbitrary target point. Because a spline curve consists of piecewise polynomial segments, the exact orthogonal projection cannot be solved with a simple built-in Three.js method alone. Instead, finding the true minimum distance requires formulating a squared-distance objective function, deriving its critical points across piecewise cubic segments, and applying numerical root-finding techniques such as Newton-Raphson iteration.

Mathematical Formulation

A SplineCurve in Three.js is defined parametrically as \(C(t)\), where \(t \in [0, 1]\). In practice, the curve is composed of \(N\) piecewise cubic segments, each defined over a local sub-interval \(u \in [0, 1]\):

\[C(u) = \mathbf{a}u^3 + \mathbf{b}u^2 + \mathbf{c}u + \mathbf{d}\]

Given a query point \(\mathbf{P} = (p_x, p_y)\), the squared Euclidean distance between \(\mathbf{P}\) and any point on the curve is:

\[D(u) = \|\mathbf{C}(u) - \mathbf{P}\|^2 = (\mathbf{C}(u) - \mathbf{P}) \cdot (\mathbf{C}(u) - \mathbf{P})\]

To find the minimum distance, we compute the critical points by taking the derivative with respect to \(u\) and setting it to zero:

\[D'(u) = 2 (\mathbf{C}(u) - \mathbf{P}) \cdot \mathbf{C}'(u) = 0\]

Because \(\mathbf{C}(u)\) is degree 3 (cubic) and \(\mathbf{C}'(u)\) is degree 2 (quadratic), their dot product produces a 5th-degree polynomial (quintic):

\[f(u) = (\mathbf{a}u^3 + \mathbf{b}u^2 + \mathbf{c}u + \mathbf{d} - \mathbf{P}) \cdot (3\mathbf{a}u^2 + 2\mathbf{b}u + \mathbf{c}) = 0\]

By the Abel-Ruffini theorem, general quintic polynomials have no algebraic closed-form solution in radicals. Therefore, finding the exact roots requires a hybrid numerical approach: isolating candidate regions and refining them via root-finding algorithms.

Step-by-Step Numerical Algorithm

To ensure the absolute global minimum is found and avoid local minima traps, the process is split into two phases: coarse discretization and iterative refinement.

1. Coarse Discretization (Interval Isolation)

Sample the curve uniformly at discrete intervals to approximate the global minimum:

  • Sample \(M\) points along \(t \in [0, 1]\) (e.g., \(M = 100\) or using curve.getPoints(divisions)).
  • Measure the distance from \(\mathbf{P}\) to each sample point.
  • Identify the sample \(t_{\text{best}}\) with the minimum Euclidean distance.

2. Local Root Refining (Newton-Raphson Iteration)

Use \(t_{\text{best}}\) as the initial estimate for the Newton-Raphson method to solve \(D'(t) = 0\). The iteration step is:

\[t_{k+1} = t_k - \frac{D'(t_k)}{D''(t_k)}\]

The second derivative \(D''(t)\) is given by:

\[D''(t) = 2 \left( \|\mathbf{C}'(t)\|^2 + (\mathbf{C}(t) - \mathbf{P}) \cdot \mathbf{C}''(t) \right)\]

Three.js provides native methods to evaluate \(\mathbf{C}(t)\) and its tangent vectors:

  • curve.getPoint(t) evaluates \(\mathbf{C}(t)\).
  • curve.getTangent(t) evaluates the normalized tangent. To obtain the exact unnormalized velocity \(\mathbf{C}'(t)\) and acceleration \(\mathbf{C}''(t)\), central finite differences can be used if explicit polynomial coefficients are not extracted directly.

3. Boundary Checks

A minimum on a bounded segment may occur at the boundaries rather than an internal stationary point. Evaluate \(D(0)\) and \(D(1)\) for each segment (or at \(t = 0\) and \(t = 1\) for the global curve), comparing these boundary distances against the refined internal critical points.

Implementation in Three.js

import * as THREE from 'three';

/**
 * Computes the absolute closest point on a SplineCurve to a target point.
 * @param {THREE.SplineCurve} curve
 * @param {THREE.Vector2} targetPoint
 * @param {number} samples - Number of intervals for coarse search
 * @param {number} maxIterations - Maximum Newton-Raphson iterations
 * @param {number} tolerance - Convergence threshold for delta t
 * @returns {{ point: THREE.Vector2, t: number, distance: number }}
 */
export function getClosestPointOnSpline(
  curve,
  targetPoint,
  samples = 100,
  maxIterations = 10,
  tolerance = 1e-6
) {
  let minDistanceSq = Infinity;
  let bestT = 0;

  // Step 1: Coarse search to isolate the closest global region
  for (let i = 0; i <= samples; i++) {
    const t = i / samples;
    const pt = curve.getPoint(t);
    const distSq = pt.distanceToSquared(targetPoint);

    if (distSq < minDistanceSq) {
      minDistanceSq = distSq;
      bestT = t;
    }
  }

  // Step 2: Newton-Raphson refinement
  let t = bestT;
  const h = 1e-4; // Step size for finite difference derivatives

  for (let i = 0; i < maxIterations; i++) {
    // Clamp t to curve domain
    t = Math.max(0, Math.min(1, t));

    // Finite difference approximation for C'(t) and C''(t)
    const tMinus = Math.max(0, t - h);
    const tPlus = Math.min(1, t + h);

    const pt = curve.getPoint(t);
    const ptMinus = curve.getPoint(tMinus);
    const ptPlus = curve.getPoint(tPlus);

    // First derivative C'(t)
    const dC = new THREE.Vector2()
      .subVectors(ptPlus, ptMinus)
      .divideScalar(tPlus - tMinus);

    // Second derivative C''(t)
    const d2C = new THREE.Vector2()
      .addVectors(ptPlus, ptMinus)
      .subScaledVector(pt, 2)
      .divideScalar(h * h);

    const diff = new THREE.Vector2().subVectors(pt, targetPoint);

    // D'(t) = 2 * (C(t) - P) . C'(t)
    const firstDerivative = 2 * diff.dot(dC);

    // D''(t) = 2 * (|C'(t)|^2 + (C(t) - P) . C''(t))
    const secondDerivative = 2 * (dC.lengthSq() + diff.dot(d2C));

    if (Math.abs(secondDerivative) < 1e-12) {
      break;
    }

    const deltaT = firstDerivative / secondDerivative;
    t -= deltaT;

    if (Math.abs(deltaT) < tolerance) {
      break;
    }
  }

  // Final clamping to curve bounds
  t = Math.max(0, Math.min(1, t));
  const finalPoint = curve.getPoint(t);

  return {
    point: finalPoint,
    t: t,
    distance: finalPoint.distanceTo(targetPoint)
  };
}

This hybrid approach guarantees convergence to the absolute closest point by combining global interval search to find the correct catchment basin with the quadratic convergence rate of Newton-Raphson optimization.
