Assign Custom Lightmap UVs in Three.js

This article explains how to configure a custom UV channel for baking and displaying light maps on 3D meshes in Three.js. You will learn how to assign a secondary UV attribute to your geometry, bind a light map texture to a mesh material, and calibrate its visual strength using the lightMapIntensity property.

Understanding Lightmap UV Channels in Three.js

By default, standard materials in Three.js (such as MeshStandardMaterial or MeshBasicMaterial) sample standard diffuse maps using the primary UV channel (geometry.attributes.uv). For lightmaps, the shader pipeline targets a secondary UV channel typically named uv2 (or mapped via the texture's channel property in modern Three.js releases).

To route a light map to a custom UV layout, you must ensure that your geometry contains this secondary UV attribute and that the material is configured to interpret it properly.

Step-by-Step Implementation

1. Define the Custom UV Channel

If your 3D asset already contains a secondary UV set from a modeling package (like Blender), loaders such as GLTFLoader often map these to uv2. If you need to manually assign custom UV coordinates or copy them from an existing attribute, set the uv2 attribute on the BufferGeometry:

// Example: Copying or assigning custom UV data to 'uv2'
const customUvArray = new Float32Array([
  // u, v coordinate pairs for each vertex
  0.0, 0.0,
  1.0, 0.0,
  1.0, 1.0,
  0.0, 1.0
]);

// Assign to the geometry as 'uv2'
geometry.setAttribute('uv2', new THREE.BufferAttribute(customUvArray, 2));

In newer versions of Three.js (r151+), you can also designate which UV channel a texture reads by modifying the texture's channel property directly:

// Sets the texture to read from geometry.attributes.uv2 (channel index 1)
lightMapTexture.channel = 1;

2. Apply the Lightmap and Adjust Intensity

Assign the loaded texture to the lightMap slot of your material. Then, use the lightMapIntensity property to scale the brightness and influence of the baked lighting:

const textureLoader = new THREE.TextureLoader();
const lightMapTexture = textureLoader.load('path/to/lightmap.png');

// Ensure proper color space
lightMapTexture.colorSpace = THREE.LinearSRGBColorSpace;

const material = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  lightMap: lightMapTexture,
  lightMapIntensity: 1.5 // Multiplier for the baked light intensity
});

3. Assemble the Mesh

Combine the geometry containing the custom UV channel with the configured material:

const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Controlling Brightness with lightMapIntensity

The lightMapIntensity property acts as a linear scalar multiplied against the RGB channels of the light map texture in the fragment shader:

  • Default (1.0): Renders the light map at its native texture brightness.
  • Dimming (< 1.0): Values between 0.0 and 1.0 reduce the impact of baked lighting, useful for nighttime or shadowed scenarios.
  • Overdriving (> 1.0): Values greater than 1.0 amplify the baked light intensity, which helps balance baked global illumination against high-intensity direct scene lights.

Changes to lightMapIntensity do not require recompiling the shader, allowing for real-time runtime adjustments during performance or scene transitions.
