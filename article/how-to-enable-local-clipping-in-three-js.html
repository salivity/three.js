How to Enable Local Clipping in Three.js

This guide explains how to configure and toggle localClippingEnabled on a Three.js WebGLRenderer to restrict clipping planes to specific materials. By default, clipping planes affect the entire scene globally unless local clipping is explicitly activated. Enabling this feature allows you to selectively cross-section specific 3D meshes while leaving the rest of the scene intact.

Enabling Local Clipping on the Renderer

To allow materials to manage their own individual clipping planes, set the localClippingEnabled property on your WebGLRenderer instance to true:

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Enable local clipping
renderer.localClippingEnabled = true;

When set to false, any clippingPlanes defined on individual materials will be ignored during rendering.

Defining a Clipping Plane

A clipping plane is defined using THREE.Plane. It requires a normal vector pointing in the direction of the visible side and a constant representing the plane's distance from the origin:

// Create a plane pointing downward along the Y-axis
const localPlane = new THREE.Plane(new THREE.Vector3(0, -1, 0), 0.5);

Assigning Planes to Specific Materials

Attach the plane to the clippingPlanes array of the material you want to clip. Any meshes using this material will be sliced, while objects using other materials will remain unaffected:

// Material with local clipping applied
const clippedMaterial = new THREE.MeshStandardMaterial({
    color: 0xff0000,
    clippingPlanes: [localPlane],
    clipShadows: true // Optional: Clips shadows cast by this mesh
});

const clippedMesh = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), clippedMaterial);
scene.add(clippedMesh);

// Unaffected material
const normalMaterial = new THREE.MeshStandardMaterial({ color: 0x0000ff });
const normalMesh = new THREE.Mesh(new THREE.SphereGeometry(0.5, 32, 32), normalMaterial);
scene.add(normalMesh);

Toggling Local Clipping at Runtime

You can dynamically toggle local clipping on or off by switching the boolean value on the renderer:

function toggleLocalClipping() {
    renderer.localClippingEnabled = !renderer.localClippingEnabled;
}

When renderer.localClippingEnabled is switched to false, the clipped mesh will instantly render as a complete, uncut geometry without needing to remove the plane from the material.

Key Material Properties

  • clipIntersection: Set to true on the material if you assign multiple planes and want to render only the intersection of those planes rather than the union.
  • clipShadows: Set to true to ensure the shadows cast by the clipped geometry match the clipped shape.
  • side: Setting material.side = THREE.DoubleSide ensures the interior surfaces of clipped hollow objects remain visible.
