Import MagicaVoxel Models in Three.js with VOXLoader

This guide provides a straightforward walkthrough on importing voxel models created in MagicaVoxel into a Three.js scene using the built-in VOXLoader. You will learn how to prepare your .vox file, import the necessary loader modules, parse voxel chunks into meshes, and render them efficiently in a WebGL scene.

1. Exporting the Model from MagicaVoxel

MagicaVoxel saves its native files in the .vox format. Unlike other 3D pipelines that require converting voxels to standard polygon formats like .obj or .gltf, VOXLoader directly reads the raw .vox file.

  1. Open your model in MagicaVoxel.
  2. Click Save or Export in the bottom-right panel.
  3. Save your file as a standard .vox file (e.g., model.vox).
  4. Place the .vox file into your project's public or assets directory.

2. Importing Dependencies

VOXLoader and its helper class VOXMesh are available in the Three.js examples add-ons directory. If you are using an npm setup with ES modules, import them alongside the core Three.js library:

import * as THREE from 'three';
import { VOXLoader, VOXMesh } from 'three/addons/loaders/VOXLoader.js';

If you are using a standard script tag with an import map, ensure the path points to three/addons/loaders/VOXLoader.js.

3. Loading the .vox File

The VOXLoader parses the .vox binary structure and returns an array of chunks. Each chunk represents a piece of the voxel grid containing voxel coordinate and color index data. You can pass these chunks to the VOXMesh constructor, which generates the optimized geometry and default vertex-colored material automatically.

Here is the complete implementation to load and add the model to your scene:

// Set up scene, camera, and renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(50, 50, 50);
camera.lookAt(0, 0, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Add lighting
const ambientLight = new THREE.AmbientLight(0xffffff, 0.6);
scene.add(ambientLight);

const dirLight = new THREE.DirectionalLight(0xffffff, 0.8);
dirLight.position.set(100, 100, 50);
scene.add(dirLight);

// Instantiate loader and load file
const loader = new VOXLoader();
loader.load(
    'path/to/model.vox',
    (chunks) => {
        // MagicaVoxel models can contain multiple chunks
        for (let i = 0; i < chunks.length; i++) {
            const chunk = chunks[i];
            
            // VOXMesh automatically builds geometry and material from the chunk
            const mesh = new VOXMesh(chunk);
            
            // Adjust mesh properties if needed
            mesh.castShadow = true;
            mesh.receiveShadow = true;

            scene.add(mesh);
        }
    },
    (xhr) => {
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    (error) => {
        console.error('An error occurred while loading the VOX file:', error);
    }
);

// Animation loop
function animate() {
    requestAnimationFrame(animate);
    renderer.render(scene, camera);
}
animate();

4. Handling Scale and Orientation

  • Coordinates: MagicaVoxel uses a Z-up coordinate system, whereas Three.js defaults to Y-up. If your model appears rotated, apply a rotation on the mesh (mesh.rotation.x = -Math.PI / 2).
  • Scale: Each voxel equals 1 unit by default in Three.js. Large voxel grids (e.g., 128x128x128) may appear massive relative to your camera. Scale the mesh down using mesh.scale.setScalar(0.1) if required.
  • Centering: The pivot point defaults to the corner of the voxel bounding box. To center the model, either adjust mesh.position manually or iterate through the chunk dimensions to compute an offset.
