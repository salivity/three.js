Load UASTC Textures with KTX2Loader in Three.js

This guide explains how to configure and use Three.js's KTX2Loader to load Universal ASTC (UASTC) compressed textures into your 3D scenes. You will learn how to set up the required Basis Universal transcoder binaries, initialize the loader with your rendering context, and load textures optimized for higher visual fidelity compared to standard ETC1S compression.

1. Prepare UASTC KTX2 Assets

UASTC is designed for high-quality textures such as normal maps, roughness maps, and detailed albedo maps. Ensure your textures are explicitly converted to KTX2 with UASTC compression using tools like toktx from the Khronos Group:

toktx --target_type 2D --uastc 2 --zstd 18 output.ktx2 input.png

The --uastc flag instructs the encoder to use Universal ASTC instead of ETC1S, while --zstd provides supercompression to reduce storage and network payload sizes.

2. Set Up the Transcoder Binaries

KTX2Loader relies on WebAssembly binaries to transcode UASTC textures into GPU-native formats (such as native ASTC, BC7, or uncompressed fallbacks) at runtime.

Copy the transcoder files from the Three.js repository (three/examples/jsm/libs/basis/) into your public static assets folder:

  • basis_transcoder.js
  • basis_transcoder.wasm

Ensure you use the standard, full build of the transcoder, as some stripped versions only support ETC1S.

3. Initialize and Configure KTX2Loader

Import KTX2Loader from the three/addons directory. Point the loader to the folder hosting your transcoder files using .setTranscoderPath() and pass your WebGLRenderer to .detectSupport() so the loader knows which compressed formats the client's GPU natively supports.

import * as THREE from 'three';
import { KTX2Loader } from 'three/addons/loaders/KTX2Loader.js';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Initialize KTX2Loader
const ktx2Loader = new KTX2Loader();
ktx2Loader.setTranscoderPath('/basis/');
ktx2Loader.detectSupport(renderer);

4. Load the UASTC Texture

The KTX2 file container embeds metadata indicating whether it is encoded in ETC1S or UASTC format. KTX2Loader reads this metadata automatically and instructs the Web Worker transcoder to use the UASTC decompression path.

ktx2Loader.load(
  'textures/albedo_uastc.ktx2',
  (texture) => {
    // Configure color space (SRGBColorSpace for color maps, NoColorSpace for normal/roughness)
    texture.colorSpace = THREE.SRGBColorSpace;
    texture.needsUpdate = true;

    const material = new THREE.MeshStandardMaterial({ map: texture });
    const mesh = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), material);
    scene.add(mesh);
  },
  undefined,
  (error) => {
    console.error('An error occurred loading the KTX2 texture:', error);
  }
);

Transcoding Behavior and Target Formats

When loading a UASTC texture, KTX2Loader determines the optimal target format based on the client device:

  • Desktop (DirectX/Vulkan/Metal): Transcodes directly to BC7, preserving high quality and alpha channels.
  • Modern Mobile (iOS/Android with ASTC support): Transcodes directly to ASTC 4x4.
  • Older Hardware: Falls back to ETC2 or decodes to uncompressed RGBA32 if native compressed formats are unavailable.

Because UASTC uses direct 1:1 block mapping to ASTC and BC7, transcoding is computationally faster than ETC1S transcoding and avoids heavy generational loss in fine gradients and normal vectors. Dispose of the loader via ktx2Loader.dispose() when it is no longer needed to terminate internal Web Workers.
