Free 360 Tumbling with Three.js TrackballControls

This guide explains how to configure TrackballControls in Three.js to allow unrestricted, 360-degree tumbling across all rotational axes. By default, controls like OrbitControls lock the camera's orientation to a fixed world up vector (usually the positive Y-axis) to prevent flipping. By properly implementing TrackballControls, you can decouple the camera from this fixed orientation and achieve full spherical freedom.

Understanding Up Vector Independence

Unlike OrbitControls, which constrains polar angles to avoid gimbal lock and maintains camera.up = (0, 1, 0), TrackballControls uses quaternion-based rotations around a virtual sphere. It dynamically updates both the camera's position and its internal up vector relative to the target. To preserve this complete freedom, you must avoid resetting camera.up in your render loop and ensure rolling maneuvers are permitted.

Implementation Steps

1. Import and Initialize TrackballControls

Import the controls module from the Three.js add-ons directory and instantiate it using your camera and the WebGL renderer's DOM element:

import * as THREE from 'three';
import { TrackballControls } from 'three/addons/controls/TrackballControls.js';

// Setup Camera
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 0, 10);

// Initialize Controls
const controls = new TrackballControls(camera, renderer.domElement);

2. Configure Key Properties for Smooth Tumbling

To enable fluid, unconstrained tumbling across all axes:

  • Ensure noRoll remains false (default). Setting this to true restricts view-axis rotation.
  • Adjust rotateSpeed to your desired sensitivity.
  • Configure damping using dynamicDampingFactor if smooth inertial tumbling is desired.
// Ensure rotational freedom
controls.noRoll = false;
controls.noPan = false;
controls.noZoom = false;

// Rotational sensitivity
controls.rotateSpeed = 3.0;

// Enable inertia/damping
controls.staticMoving = false;
controls.dynamicDampingFactor = 0.1;

3. Update Controls in the Animation Loop

TrackballControls requires continuous calculation every frame. Call controls.update() inside your requestAnimationFrame loop.

Important: Do not call camera.lookAt() or assign values to camera.up anywhere in the animation loop. Doing so overrides the tumbling calculations and forces the camera back to a fixed orientation.

function animate() {
  requestAnimationFrame(animate);

  // Update controls state
  controls.update();

  renderer.render(scene, camera);
}

animate();

Preventing Axis Snapping

If the camera snaps back to an upright position during interaction, check for these common issues:

  • Third-Party Code Resetting Camera Up: Ensure no post-processing passes or helper utilities reset camera.up.set(0, 1, 0).
  • LookAt Overwrites: Avoid calling camera.lookAt() after user interaction begins, as TrackballControls.target handles aiming internally. Change controls.target directly if you need to reposition the pivot point.
