Three.js CanvasTexture Anisotropy for Sharp Text

When rendering text onto 3D surfaces in Three.js using an HTML canvas, the text frequently becomes heavily blurred when viewed at oblique, grazing angles. This guide provides a straightforward implementation for generating a dynamic text CanvasTexture, configuring proper mipmapping, and enabling anisotropic filtering via the WebGL renderer's hardware capabilities to maintain maximum legibility and sharpness across all viewing perspectives.

The Cause of Grazing Angle Blur

Standard texture filtering assumes a square pixel footprint on screen. When a surface is tilted sharply away from the camera, the projection of a screen pixel onto the texture forms an elongated trapezoid. Standard isotropic filtering (trilinear or bilinear) averages an overly large square area of the texture, resulting in significant blur.

Anisotropic filtering solves this by sampling the texture along the direction of elongation, preserving high-frequency details like text edges.

Step 1: Create the HTML5 Canvas

First, create a 2D canvas element in memory and draw your text. To ensure the text renders sharply even before 3D transformations, create the canvas with high dimensions (ideally powers of two to assist WebGL mipmap generation, such as 1024x512).

function createTextCanvas(text, width = 1024, height = 512) {
  const canvas = document.createElement('canvas');
  canvas.width = width;
  canvas.height = height;

  const ctx = canvas.getContext('2d');
  
  // Clear canvas
  ctx.clearRect(0, 0, width, height);

  // Styling
  ctx.fillStyle = '#ffffff';
  ctx.font = 'bold 72px sans-serif';
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';

  // Draw text
  ctx.fillText(text, width / 2, height / 2);

  return canvas;
}

Step 2: Initialize CanvasTexture with Anisotropic Filtering

Instantiate a THREE.CanvasTexture using the generated canvas. To enable anisotropic filtering, you must query the maximum anisotropy level supported by the client’s GPU via renderer.capabilities.getMaxAnisotropy().

// Assume 'renderer' is an initialized THREE.WebGLRenderer
const canvas = createTextCanvas('Sharp Text at Grazing Angles');
const textTexture = new THREE.CanvasTexture(canvas);

// Enable mipmapping and trilinear filtering (required for anisotropy)
textTexture.generateMipmaps = true;
textTexture.minFilter = THREE.LinearMipmapLinearFilter;
textTexture.magFilter = THREE.LinearFilter;

// Query and apply the maximum supported anisotropy
const maxAnisotropy = renderer.capabilities.getMaxAnisotropy();
textTexture.anisotropy = maxAnisotropy;

// Apply to a material and mesh
const material = new THREE.MeshStandardMaterial({
  map: textTexture,
  transparent: true,
  roughness: 0.2
});

const geometry = new THREE.PlaneGeometry(4, 2);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Step 3: Handling Dynamic Text Updates

When text changes dynamically at runtime, redraw onto the existing 2D canvas context and flag the texture for an update. The texture's anisotropy and filtering settings will remain intact, but Three.js will regenerate the mipmap pyramid on the GPU.

function updateText(newText) {
  const ctx = canvas.getContext('2d');
  
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillText(newText, canvas.width / 2, canvas.height / 2);

  // Notify Three.js to upload the new canvas pixels and rebuild mipmaps
  textTexture.needsUpdate = true;
}

Summary of Requirements for Success

  1. Mipmaps Must Be Active: Anisotropic filtering only operates when mipmaps are generated (texture.generateMipmaps = true) and the minification filter uses mipmapping (THREE.LinearMipmapLinearFilter).
  2. Dimension Constraints: Keeping canvas dimensions to powers of two (e.g., 512, 1024, 2048) ensures optimal WebGL performance and compatibility when generating mipmaps.
  3. Capability Check: Always use renderer.capabilities.getMaxAnisotropy() rather than hardcoding a value, as mobile GPUs and older hardware may support a lower maximum (e.g., 4 or 8) compared to modern desktop GPUs (typically 16).
