Apply HDR to MeshPhysicalMaterial in Three.js

In Three.js, you can illuminate and reflect realistic lighting on a single MeshPhysicalMaterial using a High Dynamic Range (HDR) texture without affecting the global scene background or other objects. By loading an HDR file via RGBELoader, configuring its texture mapping to equirectangular reflection, and assigning it directly to the material's envMap property instead of scene.environment or scene.background, you isolate the lighting effects strictly to that mesh.

1. Load the HDR Texture

To load an .hdr file, use the RGBELoader add-on. Once loaded, set the texture's mapping mode to THREE.EquirectangularReflectionMapping. This tells Three.js to project the 2D spherical image onto a 3D environment volume for surface reflections and refractions.

import * as THREE from 'three';
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

const rgbeLoader = new RGBELoader();

rgbeLoader.load('path/to/environment.hdr', (texture) => {
    texture.mapping = THREE.EquirectangularReflectionMapping;

    // Apply directly to the material
    applyEnvMapToMaterial(texture);
});

2. Assign the Map Directly to the Material

Instead of assigning the texture to scene.environment or scene.background, assign it directly to the envMap property of your MeshPhysicalMaterial.

function applyEnvMapToMaterial(hdrTexture) {
    const material = new THREE.MeshPhysicalMaterial({
        color: 0xffffff,
        metalness: 0.1,
        roughness: 0.1,
        transmission: 0.9,      // Excellent for showing HDR refractions
        ior: 1.5,
        envMap: hdrTexture,     // Assign the HDR map locally
        envMapIntensity: 1.0    // Adjust reflection/lighting strength
    });

    const geometry = new THREE.SphereGeometry(1, 64, 64);
    const mesh = new THREE.Mesh(geometry, material);
    scene.add(mesh);
}

3. Fine-Tune Material Interaction

MeshPhysicalMaterial provides several dedicated properties to control how the HDR environment map renders:

  • envMapIntensity: Controls the brightness and contribution of the HDR reflections without changing scene lights.
  • roughness: Blurs the reflected HDR image across the surface, simulating matte or frosted finishes.
  • transmission and ior: Allows the HDR environment to pass through transparent or glass-like meshes, bending the light based on the Index of Refraction (IOR).
  • clearcoat and clearcoatRoughness: Adds a secondary reflective layer over the base material, utilizing the assigned HDR map.

4. Keeping the Scene Background Independent

Because the texture was never assigned to scene.background, your canvas background remains under your control. You can keep it transparent, set a solid color, or use a completely different background image:

// Leave scene.background undefined for a transparent canvas, or set a solid color:
scene.background = new THREE.Color(0x1a1a1a);

By binding the texture directly to the envMap property, the HDR calculation runs exclusively within the shader of that specific MeshPhysicalMaterial.
