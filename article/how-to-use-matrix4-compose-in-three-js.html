How to Use Matrix4.compose in Three.js

In Three.js, spatial transformations can be efficiently handled using a single 4x4 transformation matrix rather than managing separate translation, rotation, and scale properties. This article explains how to construct a THREE.Matrix4 using the native .compose() method. You will learn the exact method signature, the required input types—Vector3 for position, Quaternion for rotation, and Vector3 for scale—and how to apply the resulting matrix to 3D objects or geometries.

Understanding the compose Method

The compose method updates an existing Matrix4 instance by assembling translation, rotation, and scaling factors into an affine transformation matrix.

Its syntax is:

matrix.compose(position, quaternion, scale);

Parameters

  1. position (THREE.Vector3): The translation vector indicating coordinates along the X, Y, and Z axes.
  2. quaternion (THREE.Quaternion): The rotation represented as a quaternion to avoid gimbal lock and ensure smooth rotational math.
  3. scale (THREE.Vector3): The scaling vector along the X, Y, and Z axes. A default, unscaled state is represented by (1, 1, 1).

Step-by-Step Implementation

1. Initialize Vectors and Quaternion

Before calling compose, instantiate and define the transform components:

import * as THREE from 'three';

// 1. Define Position
const position = new THREE.Vector3(10, 5, -2);

// 2. Define Rotation (using Euler angles converted to a Quaternion)
const euler = new THREE.Euler(0, Math.PI / 4, 0, 'XYZ'); // 45-degree rotation around Y
const quaternion = new THREE.Quaternion().setFromEuler(euler);

// 3. Define Scale
const scale = new THREE.Vector3(2, 2, 2); // Double the size uniformly

2. Compose the Matrix

Create an empty Matrix4 and pass the components into the compose method:

const matrix = new THREE.Matrix4();
matrix.compose(position, quaternion, scale);

The matrix object now holds the combined transformation.

Applying the Composed Matrix

You can apply the composed matrix in multiple ways depending on your use case:

Applying Directly to an Object3D

If you disable automatic matrix updates, you can assign the composed matrix directly to a mesh or 3D object:

const mesh = new THREE.Mesh(geometry, material);

// Prevent Three.js from recalculating the matrix from position/rotation/scale
mesh.matrixAutoUpdate = false;

// Copy the composed matrix directly to the mesh
mesh.matrix.copy(matrix);

Applying to BufferGeometry

You can bake the transformation directly into the geometry vertices:

geometry.applyMatrix4(matrix);

Applying to InstancedMesh

compose is commonly used to position individual instances in an InstancedMesh:

const instancedMesh = new THREE.InstancedMesh(geometry, material, count);

// Set transformation for the first instance (index 0)
instancedMesh.setMatrixAt(0, matrix);
instancedMesh.instanceMatrix.needsUpdate = true;
