Understanding Three.js PointLight Power and Lumens

This article explains the power property of the PointLight in Three.js and its relationship to luminous flux within physically based rendering (PBR). You will learn how luminous flux is measured, how Three.js calculates the relationship between light power and intensity, and how to apply real-world lighting values to your 3D scenes.

What is Luminous Flux?

In photometry and physically based rendering, luminous flux represents the total perceived power of light emitted by a source in all directions. It takes into account the sensitivity of the human eye to different wavelengths of light and is measured in lumens (\(lm\)).

Luminous flux differs from luminous intensity, which measures the perceived light power emitted per unit solid angle in a specific direction and is measured in candelas (\(cd\), equivalent to lumens per steradian, or \(lm/sr\)).

The PointLight power Property in Three.js

A PointLight in Three.js is an omnidirectional light source that radiates light equally in all directions across a full sphere (\(4\pi\) steradians).

The power property of a PointLight directly corresponds to this total luminous flux measured in lumens (\(lm\)). Setting the power property allows you to define lighting using standard physical units rather than arbitrary scalar values.

Three.js internally links the power and intensity properties via a getter and setter. Because an isotropic point light radiates across a full sphere of \(4\pi\) steradians, the mathematical relationship between power (lumens) and intensity (candelas) is:

\[\text{power} = \text{intensity} \times 4\pi\]

Conversely, intensity is derived from power:

\[\text{intensity} = \frac{\text{power}}{4\pi}\]

If you change light.power, Three.js automatically recalculates light.intensity, and vice versa.

Usage in Physically Based Rendering

To use the power property effectively in modern Three.js physically based rendering pipelines, ensure that your lights follow real-world physical behavior:

  1. Light Decay: Set light.decay = 2. Physically correct lighting relies on the inverse-square law, where light attenuation is inversely proportional to the square of the distance from the source.
  2. Infinite Distance Falloff: Set light.distance = 0 so that the light attenuates naturally using the inverse-square law without an artificial cutoff threshold.
const pointLight = new THREE.PointLight(0xffffff);

// Configure physical falloff
pointLight.decay = 2;
pointLight.distance = 0;

// Set light output using lumens (e.g., standard 60W household bulb)
pointLight.power = 800; 

scene.add(pointLight);

Real-World Values for Point Lights

Using the power property makes it straightforward to look up real-world values for lighting assets:

  • Candle: ~12–13 lumens
  • 40W Incandescent Bulb / 6W LED: ~450 lumens
  • 60W Incandescent Bulb / 9W LED: ~800 lumens
  • 100W Incandescent Bulb / 15W LED: ~1600 lumens
  • Car Halogen Headlight: ~1200–1500 lumens

When working with realistic lumen values, scenes may initially appear overexposed or underexposed. In physically based workflows, lighting must be balanced with camera exposure settings, which are typically managed via tone mapping (renderer.toneMappingExposure) to mimic real-world camera apertures and shutter speeds.
