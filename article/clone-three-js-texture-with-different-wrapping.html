Clone Three.js Texture with Different Wrapping

In Three.js, duplicating textures without wasting GPU memory is essential for building performant 3D applications. This guide explains how to use the Texture.clone() method to reuse the underlying image data while applying unique wrapping modes and repeat values to individual texture instances.

Why Use Texture.clone()?

When you load an image using THREE.TextureLoader, it allocates memory for the image bitmap. If you instantiate another texture from the same image via the loader, you risk duplicating that image data in GPU memory.

Calling texture.clone() creates a new THREE.Texture instance that references the exact same underlying ImageBitmap or HTMLImageElement source. This allows you to independently configure properties such as wrapS, wrapT, repeat, and offset on the cloned object without affecting the original texture or increasing texture memory usage.

Step-by-Step Implementation

  1. Load the Source Texture: Load the primary texture using TextureLoader.
  2. Clone the Texture: Call the .clone() method on the loaded texture object.
  3. Configure Wrapping: Change the wrapS and wrapT properties of the cloned texture to your preferred mode (e.g., THREE.RepeatWrapping, THREE.MirroredRepeatWrapping, or THREE.ClampToEdgeWrapping).
  4. Set Repetition: Adjust the repeat property on the cloned texture.
  5. Assign to Materials: Apply each texture instance to distinct materials.

Code Example

import * as THREE from 'three';

const loader = new THREE.TextureLoader();

// 1. Load the base texture
loader.load('path/to/texture.jpg', (baseTexture) => {
  // Base texture setup: Clamped, 1:1 scale
  baseTexture.wrapS = THREE.ClampToEdgeWrapping;
  baseTexture.wrapT = THREE.ClampToEdgeWrapping;

  // 2. Clone the texture to reuse the image data
  const repeatingTexture = baseTexture.clone();

  // 3. Apply different wrapping modes to the clone
  repeatingTexture.wrapS = THREE.RepeatWrapping;
  repeatingTexture.wrapT = THREE.RepeatWrapping;

  // 4. Modify repeat coordinates on the clone
  repeatingTexture.repeat.set(4, 4);

  // Mark for update if modified after initial render
  repeatingTexture.needsUpdate = true;

  // 5. Apply the textures to separate materials
  const materialA = new THREE.MeshBasicMaterial({ map: baseTexture });
  const materialB = new THREE.MeshBasicMaterial({ map: repeatingTexture });

  const meshA = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), materialA);
  const meshB = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), materialB);
});

Key Considerations

  • Shared Source: Since baseTexture.source is shared with repeatingTexture.source, any programmatic modification to the pixel content itself (such as updating an underlying canvas) will reflect across both textures.
  • Property Independence: Non-pixel properties—including wrapS, wrapT, repeat, offset, center, and rotation—are distinct to each texture instance, granting complete control over texture coordinate mapping per material.
