Offset Mesh Pivot Point Without a Group in Three.js

In Three.js, a mesh naturally rotates around its local origin (0, 0, 0). While the standard workflow involves nesting the mesh inside a THREE.Group to create an artificial pivot, you can offset the pivot point directly on a standalone mesh without altering your scene hierarchy. This is accomplished by translating the underlying BufferGeometry vertices relative to the mesh's origin, effectively redefining the center of rotation for that geometry.

Translating the BufferGeometry

The most direct and performance-friendly way to offset a pivot point without a parent group is to use the translate() method on the mesh's geometry.

When you shift the geometry's vertices, the mesh's local (0, 0, 0) origin remains where the mesh's position is set in the world, but the visual geometry moves relative to that point. Any subsequent rotations applied to mesh.rotation or mesh.quaternion will occur around this local origin.

import * as THREE from 'three';

// 1. Create geometry and material
const geometry = new THREE.BoxGeometry(2, 4, 2);
const material = new THREE.MeshStandardMaterial({ color: 0x00ff00 });

// 2. Offset the geometry vertices
// For example, to set the pivot at the bottom center of the box:
// The box height is 4, so shifting Y by +2 moves the origin to the bottom face.
const offsetX = 0;
const offsetY = 2; // Half the height
const offsetZ = 0;

geometry.translate(offsetX, offsetY, offsetZ);

// 3. Create the mesh
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// 4. Rotate the mesh around the new pivot point
mesh.rotation.z = Math.PI / 4;

Compensating for Position Shifts

Shifting the geometry moves the visual representation of the object. If you need the mesh to appear at a specific target position in the world while rotating around the new pivot, place the mesh's position exactly where the pivot should physically exist in the scene.

// Desired pivot location in world space
mesh.position.set(10, 0, 0);

// The mesh will now rotate around (10, 0, 0) instead of its visual center
mesh.rotation.y += 0.01;

Using Matrix Transformations

If your pivot offset requires rotation or non-uniform scaling alongside translation, you can transform the geometry using a Matrix4:

const transformMatrix = new THREE.Matrix4();

// Define translation, rotation, or scale for the pivot adjustment
transformMatrix.makeTranslation(-pivotX, -pivotY, -pivotZ);

// Apply directly to the geometry vertices
geometry.applyMatrix4(transformMatrix);

Important Considerations

  • Shared Geometries: geometry.translate() and geometry.applyMatrix4() mutate the geometry data permanently. If multiple meshes share the same geometry instance, all of them will inherit the offset. If you only want to offset the pivot for one specific mesh, clone the geometry first via const uniqueGeometry = geometry.clone();.
  • Bounding Volumes: After manually translating geometry vertices, Three.js updates the internal vertex positions. If your application relies on accurate raycasting or frustum culling, recompute the bounding volumes: 
    geometry.computeBoundingBox();
geometry.computeBoundingSphere();
