Using 3D Noise with Data3DTexture in Three.js

This guide explains how to generate volumetric procedural noise, load it into a Three.js Data3DTexture, and sample it inside a custom ShaderMaterial. By leveraging WebGL 2.0 capabilities, you can bind a true 3D texture to a sampler3D uniform in GLSL, enabling seamless, artifact-free 3D noise lookups for volumetric rendering, terrain deformation, and dynamic atmospheric effects.

1. Ensure WebGL 2.0 Context

Data3DTexture and 3D samplers require WebGL 2.0. Ensure your renderer is configured for WebGL 2:

const canvas = document.querySelector('canvas');
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });

Three.js defaults to WebGL 2 when supported by the client browser.

2. Generate Volumetric Noise Data

Create a typed array holding the 3D data. You can use an algorithm like Perlin/Simplex noise or generate random values across a three-dimensional grid:

const size = 64; // Resolution: 64x64x64
const data = new Uint8Array(size * size * size);

let i = 0;
for (let z = 0; z < size; z++) {
  for (let y = 0; y < size; y++) {
    for (let x = 0; x < size; x++) {
      // Replace with your preferred 3D noise function
      data[i] = Math.floor(Math.random() * 256);
      i++;
    }
  }
}

3. Instantiate the Data3DTexture

Wrap the raw data in a THREE.Data3DTexture. Set the appropriate format, filtering, and wrap modes:

const noiseTexture = new THREE.Data3DTexture(data, size, size, size);
noiseTexture.format = THREE.RedFormat;
noiseTexture.type = THREE.UnsignedByteType;
noiseTexture.minFilter = THREE.LinearFilter;
noiseTexture.magFilter = THREE.LinearFilter;
noiseTexture.wrapS = THREE.RepeatWrapping;
noiseTexture.wrapT = THREE.RepeatWrapping;
noiseTexture.wrapR = THREE.RepeatWrapping;
noiseTexture.unpackAlignment = 1;
noiseTexture.needsUpdate = true;

4. Create the ShaderMaterial

Specify glslVersion: THREE.GLSL3 on your material. This allows modern GLSL syntax, including the unified texture() function for sampler3D:

const material = new THREE.ShaderMaterial({
  glslVersion: THREE.GLSL3,
  uniforms: {
    uNoiseTex: { value: noiseTexture },
    uTime: { value: 0.0 }
  },
  vertexShader: `
    out vec3 vPosition;
    out vec2 vUv;

    void main() {
      vUv = uv;
      vPosition = position;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    precision highp float;
    precision highp sampler3D;

    uniform sampler3D uNoiseTex;
    uniform float uTime;

    in vec3 vPosition;
    in vec2 vUv;
    out vec4 fragColor;

    void main() {
      // Create animated 3D coordinates based on position and time
      vec3 coord = vPosition * 0.5 + vec3(0.0, 0.0, uTime * 0.1);

      // Sample the 3D texture using vec3 coordinates
      float noise = texture(uNoiseTex, coord).r;

      fragColor = vec4(vec3(noise), 1.0);
    }
  `
});

5. Attach to a Mesh and Animate

Apply the material to any geometry. Update time-based uniforms inside your render loop to animate the texture slicing:

const geometry = new THREE.BoxGeometry(2, 2, 2);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

function animate(time) {
  requestAnimationFrame(animate);
  material.uniforms.uTime.value = time * 0.001;
  renderer.render(scene, camera);
}
requestAnimationFrame(animate);
