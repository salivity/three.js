Fit 3D Model to Viewport in Three.js

When dynamically loading 3D assets in Three.js, models often vary widely in scale and origin, causing them to render off-screen or clipped. This guide outlines how to compute the optimal camera distance to fit any dynamic 3D model within the camera viewport using bounding box calculations, trigonometry, and camera field of view adjustments.

1. Compute the Object's Bounding Box and Center

To frame an object properly, you must first calculate its physical boundaries in 3D world space. Use THREE.Box3 to calculate the axis-aligned bounding box (AABB) of the object, which gives you both its dimensions and center point.

import * as THREE from 'three';

const box = new THREE.Box3().setFromObject(model);
const size = box.getSize(new THREE.Vector3());
const center = box.getCenter(new THREE.Vector3());

2. Calculate the Optimal Distance Using Trigonometry

A perspective camera's vertical field of view (camera.fov) is defined in degrees. To fit the object without clipping:

  1. Determine the maximum dimension of the bounding box.
  2. Convert the vertical FOV to radians.
  3. Calculate the required distance along both the vertical and horizontal planes to account for the viewport aspect ratio.
// Get the maximum dimension of the bounding box
const maxDim = Math.max(size.x, size.y, size.z);

// Convert vertical FOV to radians
const fovInRadians = (camera.fov * Math.PI) / 180;

// Calculate vertical distance required
let cameraDistance = maxDim / (2 * Math.tan(fovInRadians / 2));

// Account for horizontal field of view when aspect ratio is portrait (< 1)
const horizontalFov = 2 * Math.atan(Math.tan(fovInRadians / 2) * camera.aspect);
const horizontalDistance = maxDim / (2 * Math.tan(horizontalFov / 2));

// Use the larger distance to guarantee the object fits inside both axes
cameraDistance = Math.max(cameraDistance, horizontalDistance);

// Add a margin multiplier (e.g., 1.2 for 20% padding)
const padding = 1.2;
cameraDistance *= padding;

3. Update Camera Position, Frustum, and Controls

Position the camera relative to the object's center point along the desired viewing angle. Also adjust the near and far clipping planes based on the computed distance to prevent visual artifacts or z-fighting.

// Position camera along the Z axis relative to object center
camera.position.set(center.x, center.y, center.z + cameraDistance);

// Update clipping planes to prevent clipping large or small objects
camera.near = cameraDistance / 100;
camera.far = cameraDistance * 100;
camera.updateProjectionMatrix();

// Re-orient camera to look directly at the center of the model
camera.lookAt(center);

If you are using OrbitControls, update the control target to the calculated center to allow users to rotate the camera around the model correctly:

if (controls) {
  controls.target.copy(center);
  controls.update();
}

Reusable Implementation Function

Combine these steps into a single reusable helper function:

function frameModel(camera, model, controls = null, padding = 1.25) {
  const box = new THREE.Box3().setFromObject(model);
  const size = box.getSize(new THREE.Vector3());
  const center = box.getCenter(new THREE.Vector3());

  const maxDim = Math.max(size.x, size.y, size.z);
  const vFov = (camera.fov * Math.PI) / 180;
  
  let distance = maxDim / (2 * Math.tan(vFov / 2));
  const hFov = 2 * Math.atan(Math.tan(vFov / 2) * camera.aspect);
  const hDistance = maxDim / (2 * Math.tan(hFov / 2));

  distance = Math.max(distance, hDistance) * padding;

  camera.position.set(center.x, center.y, center.z + distance);
  camera.near = distance / 100;
  camera.far = distance * 100;
  camera.updateProjectionMatrix();

  if (controls) {
    controls.target.copy(center);
    controls.update();
  } else {
    camera.lookAt(center);
  }
}
