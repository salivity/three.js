Build a Spiral Staircase Geometry in Three.js

This guide explains how to construct a procedural, custom geometry generator function for a spiral staircase in Three.js using BufferGeometry. By understanding the parametric equations of a helix, calculating inner and outer radial offsets, and mapping triangle indices, you can generate a single, performant mesh without relying on expensive boolean operations or combining numerous individual meshes.

Mathematical Principles of a Spiral Staircase

A spiral staircase distributes sequential steps along a central vertical axis (\(Y\)) while simultaneously rotating them around that axis at a constant angular interval.

Each step can be modeled as a truncated cylindrical wedge defined by:

  • Inner Radius (\(r_1\)): Distance from the center column to the inner edge.
  • Outer Radius (\(r_2\)): Distance from the center to the outer edge.
  • Start Angle (\(\theta\)): The base orientation of the step around the \(Y\)-axis.
  • Step Arc (\(\Delta\theta\)): The angular width of the tread.
  • Step Height (\(h\)): The thickness of the tread or riser.
  • Vertical Rise (\(\Delta y\)): The elevation gained per step.

For any given step index \(i\), the base angular position and elevation are:

\[\theta_i = i \cdot \Delta\theta_{\text{rise}}\] \[y_i = i \cdot \Delta y\]

Using polar-to-Cartesian conversion, the four corners defining the top surface of a step at height \(y_{\text{top}} = y_i + h\) are calculated as:

\[\mathbf{p}_{\text{inner\_start}} = (r_1 \cos\theta_i, y_{\text{top}}, r_1 \sin\theta_i)\] \[\mathbf{p}_{\text{outer\_start}} = (r_2 \cos\theta_i, y_{\text{top}}, r_2 \sin\theta_i)\] \[\mathbf{p}_{\text{inner\_end}} = (r_1 \cos(\theta_i + \Delta\theta), y_{\text{top}}, r_1 \sin(\theta_i + \Delta\theta))\] \[\mathbf{p}_{\text{outer\_end}} = (r_2 \cos(\theta_i + \Delta\theta), y_{\text{top}}, r_2 \sin(\theta_i + \Delta\theta))\]

The bottom four corners mirror these horizontal coordinates at vertical height \(y_i\).

Step Geometry Topology

Each individual step consists of an 8-vertex hexahedron (a wedge prism). To render proper hard surfaces with correct lighting, each face should have distinct vertices so normals are perpendicular to each plane:

  1. Top Face (Tread): 2 triangles (horizontal, normal pointing \(+Y\)).
  2. Bottom Face: 2 triangles (horizontal, normal pointing \(-Y\)).
  3. Front Face (Riser): 2 triangles (vertical, facing the climbing direction).
  4. Back Face: 2 triangles (vertical, opposite the riser).
  5. Inner Face: 2 triangles (curved or flat side facing center).
  6. Outer Face: 2 triangles (outer rim edge).

A non-indexed BufferGeometry stores 6 faces \(\times\) 2 triangles \(\times\) 3 vertices = 36 vertices (108 float values) per step.

Geometry Generator Function

Below is the complete function to generate the staircase geometry in Three.js:

import * as THREE from 'three';

/**
 * Generates a custom BufferGeometry representing a spiral staircase.
 *
 * @param {Object} options Configuration parameters.
 * @param {number} [options.innerRadius=0.5] Radius of the inner pole/opening.
 * @param {number} [options.outerRadius=2.5] Outer radius of the steps.
 * @param {number} [options.stepCount=30] Total number of steps.
 * @param {number} [options.totalHeight=6.0] Total height of the staircase.
 * @param {number} [options.totalAngle=Math.PI * 2] Total rotation in radians.
 * @param {number} [options.stepOverlap=1.2] Arc multiplier to overlap steps slightly.
 * @returns {THREE.BufferGeometry}
 */
export function createSpiralStaircaseGeometry({
  innerRadius = 0.5,
  outerRadius = 2.5,
  stepCount = 30,
  totalHeight = 6.0,
  totalAngle = Math.PI * 2,
  stepOverlap = 1.1
} = {}) {
  const geometry = new THREE.BufferGeometry();
  
  const anglePerStep = totalAngle / stepCount;
  const heightPerStep = totalHeight / stepCount;
  const stepArc = anglePerStep * stepOverlap;
  const stepThickness = heightPerStep;

  // 6 faces * 2 triangles * 3 vertices = 36 vertices per step
  const verticesPerStep = 36;
  const totalVertices = stepCount * verticesPerStep;
  const positions = new Float32Array(totalVertices * 3);

  let offset = 0;

  function pushQuad(p1, p2, p3, p4) {
    // Triangle 1: p1 -> p2 -> p3
    positions[offset++] = p1.x; positions[offset++] = p1.y; positions[offset++] = p1.z;
    positions[offset++] = p2.x; positions[offset++] = p2.y; positions[offset++] = p2.z;
    positions[offset++] = p3.x; positions[offset++] = p3.y; positions[offset++] = p3.z;

    // Triangle 2: p1 -> p3 -> p4
    positions[offset++] = p1.x; positions[offset++] = p1.y; positions[offset++] = p1.z;
    positions[offset++] = p3.x; positions[offset++] = p3.y; positions[offset++] = p3.z;
    positions[offset++] = p4.x; positions[offset++] = p4.y; positions[offset++] = p4.z;
  }

  for (let i = 0; i < stepCount; i++) {
    const thetaStart = i * anglePerStep;
    const thetaEnd = thetaStart + stepArc;

    const yBottom = i * heightPerStep;
    const yTop = yBottom + stepThickness;

    // Precompute sine/cosine values
    const cosStart = Math.cos(thetaStart);
    const sinStart = Math.sin(thetaStart);
    const cosEnd = Math.cos(thetaEnd);
    const sinEnd = Math.sin(thetaEnd);

    // Bottom 4 points
    const b_in_start = new THREE.Vector3(innerRadius * cosStart, yBottom, innerRadius * sinStart);
    const b_out_start = new THREE.Vector3(outerRadius * cosStart, yBottom, outerRadius * sinStart);
    const b_out_end = new THREE.Vector3(outerRadius * cosEnd, yBottom, outerRadius * sinEnd);
    const b_in_end = new THREE.Vector3(innerRadius * cosEnd, yBottom, innerRadius * sinEnd);

    // Top 4 points
    const t_in_start = new THREE.Vector3(innerRadius * cosStart, yTop, innerRadius * sinStart);
    const t_out_start = new THREE.Vector3(outerRadius * cosStart, yTop, outerRadius * sinStart);
    const t_out_end = new THREE.Vector3(outerRadius * cosEnd, yTop, outerRadius * sinEnd);
    const t_in_end = new THREE.Vector3(innerRadius * cosEnd, yTop, innerRadius * sinEnd);

    // 1. Top face
    pushQuad(t_in_start, t_out_start, t_out_end, t_in_end);

    // 2. Bottom face (reversed winding for downward normal)
    pushQuad(b_in_end, b_out_end, b_out_start, b_in_start);

    // 3. Front riser face (thetaStart)
    pushQuad(b_in_start, b_out_start, t_out_start, t_in_start);

    // 4. Back face (thetaEnd)
    pushQuad(b_out_end, b_in_end, t_in_end, t_out_end);

    // 5. Outer edge face
    pushQuad(b_out_start, b_out_end, t_out_end, t_out_start);

    // 6. Inner edge face
    pushQuad(b_in_end, b_in_start, t_in_start, t_in_end);
  }

  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
  geometry.computeVertexNormals();

  return geometry;
}

Instantiation and Usage

Assign standard materials to the generated geometry and add the mesh directly to a scene:

const staircaseGeo = createSpiralStaircaseGeometry({
  innerRadius: 0.8,
  outerRadius: 3.0,
  stepCount: 40,
  totalHeight: 8.0,
  totalAngle: Math.PI * 3, // 1.5 full turns
  stepOverlap: 1.15
});

const material = new THREE.MeshStandardMaterial({
  color: 0x808080,
  roughness: 0.4,
  metalness: 0.1
});

const staircaseMesh = new THREE.Mesh(staircaseGeo, material);
scene.add(staircaseMesh);

By generating all steps within a single BufferGeometry and calling computeVertexNormals(), the GPU processes the staircase in a single draw call with accurate lighting across all tread and riser surfaces.
