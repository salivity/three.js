How to Find faceIndex with Raycaster in Three.js

In Three.js, determining the exact faceIndex of an intersected 3D mesh is essential for tasks like selecting individual polygons, face-specific coloring, or mesh editing. When a THREE.Raycaster intersects a mesh, it returns an array of intersection objects, each containing a faceIndex property that indicates the exact index of the triangular face that was struck. This guide explains how to set up the raycaster to capture this value, how faceIndex maps to both indexed and non-indexed geometries, and how to extract the corresponding vertex data.

1. Capturing the Intersection

To retrieve the faceIndex, cast a ray from the camera through the mouse coordinates and check for intersections against your target mesh.

const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

function onPointerDown(event) {
  // Normalize mouse coordinates to [-1, 1]
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

  raycaster.setFromCamera(mouse, camera);

  const intersects = raycaster.intersectObject(targetMesh, false);

  if (intersects.length > 0) {
    const hit = intersects[0];
    const faceIndex = hit.faceIndex;

    console.log(`Hit Face Index: ${faceIndex}`);
    getFaceVertices(targetMesh.geometry, faceIndex);
  }
}

If an intersection occurs, hit.faceIndex returns an integer representing the zero-based index of the intersected triangle.

2. Resolving Vertices from faceIndex

Modern Three.js meshes use THREE.BufferGeometry, which stores vertex data in flat typed arrays. Depending on whether the geometry is indexed or non-indexed, the calculation required to access the vertex positions of the face varies.

Indexed BufferGeometry

If geometry.index !== null, the geometry reuses vertices via an index buffer. The faceIndex maps to three consecutive indices in geometry.index.

const index = geometry.index;
const positionAttribute = geometry.attributes.position;

// Each face consists of 3 indices
const a = index.getX(faceIndex * 3);
const b = index.getX(faceIndex * 3 + 1);
const c = index.getX(faceIndex * 3 + 2);

const vA = new THREE.Vector3().fromBufferAttribute(positionAttribute, a);
const vB = new THREE.Vector3().fromBufferAttribute(positionAttribute, b);
const vC = new THREE.Vector3().fromBufferAttribute(positionAttribute, c);

Non-Indexed BufferGeometry

If geometry.index === null, every triangle consists of three unique, sequential vertices in the position attribute.

const positionAttribute = geometry.attributes.position;

const a = faceIndex * 3;
const b = faceIndex * 3 + 1;
const c = faceIndex * 3 + 2;

const vA = new THREE.Vector3().fromBufferAttribute(positionAttribute, a);
const vB = new THREE.Vector3().fromBufferAttribute(positionAttribute, b);
const vC = new THREE.Vector3().fromBufferAttribute(positionAttribute, c);

3. Universal Function to Retrieve Face Vertices

To handle both geometry types reliably, use the following unified function:

function getFaceVertices(geometry, faceIndex) {
  const position = geometry.attributes.position;
  const index = geometry.index;

  let a, b, c;

  if (index !== null) {
    a = index.getX(faceIndex * 3);
    b = index.getX(faceIndex * 3 + 1);
    c = index.getX(faceIndex * 3 + 2);
  } else {
    a = faceIndex * 3;
    b = faceIndex * 3 + 1;
    c = faceIndex * 3 + 2;
  }

  const vertexA = new THREE.Vector3().fromBufferAttribute(position, a);
  const vertexB = new THREE.Vector3().fromBufferAttribute(position, b);
  const vertexC = new THREE.Vector3().fromBufferAttribute(position, c);

  return { vertexA, vertexB, vertexC };
}

Important Considerations

  • Transformations: Vertices retrieved using fromBufferAttribute are in local object space. To convert them to world coordinates, apply the mesh’s world matrix: vertexA.applyMatrix4(mesh.matrixWorld).
  • Undefined faceIndex: The faceIndex property is only valid for meshes (THREE.Mesh). It is undefined for ray intersections with THREE.Points or THREE.LineSegments.
  • InstancedMesh: When using THREE.InstancedMesh, hit.instanceId must be used in conjunction with hit.faceIndex to determine both the instance and the specific face within that instance.
