Align HTML Tooltips to 3D Sprites with CSS2DRenderer

This guide demonstrates how to project 3D coordinates into 2D screen space to attach floating HTML tooltips to Three.js sprites using CSS2DRenderer. By overlaying a dedicated CSS rendering layer on top of the standard WebGL canvas, you can bind native HTML elements directly to 3D objects. This eliminates manual vector projection math (Vector3.project()) while maintaining responsive, fully styleable UI overlays that automatically track camera movements.

1. Setting Up the CSS2DRenderer

The CSS2DRenderer manages DOM nodes wrapped inside CSS2DObject instances. It creates a secondary DOM overlay that matches the dimensions and view transformations of your WebGL canvas.

Import the renderer from the Three.js add-ons:

import * as THREE from 'three';
import { CSS2DRenderer, CSS2DObject } from 'three/addons/renderers/CSS2DRenderer.js';

Initialize both the standard WebGLRenderer and the CSS2DRenderer:

// Scene and Camera
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 5;

// WebGL Renderer
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// CSS2D Renderer
const labelRenderer = new CSS2DRenderer();
labelRenderer.setSize(window.innerWidth, window.innerHeight);
labelRenderer.domElement.style.position = 'absolute';
labelRenderer.domElement.style.top = '0px';
labelRenderer.domElement.style.left = '0px';
labelRenderer.domElement.style.pointerEvents = 'none'; // Allows clicks to pass through to the canvas
document.body.appendChild(labelRenderer.domElement);

2. Creating the Sprite and Tooltip Element

To anchor a tooltip to a 3D sprite, build standard HTML elements, style them via CSS, and instantiate a CSS2DObject.

// 1. Create the 3D Sprite
const spriteMaterial = new THREE.SpriteMaterial({ color: 0x00ff88 });
const sprite = new THREE.Sprite(spriteMaterial);
sprite.scale.set(0.5, 0.5, 1);
sprite.position.set(0, 0, 0);
scene.add(sprite);

// 2. Create the HTML DOM Node for the Tooltip
const tooltipDiv = document.createElement('div');
tooltipDiv.className = 'tooltip';
tooltipDiv.textContent = 'Point of Interest';

// Optional: Enable pointer events on the tooltip itself if it contains interactive links/buttons
tooltipDiv.style.pointerEvents = 'auto';

// 3. Wrap in a CSS2DObject and Attach to the Sprite
const tooltipObject = new CSS2DObject(tooltipDiv);

// Offset the tooltip so it hovers above the sprite center
tooltipObject.position.set(0, 0.4, 0);

// Adding as a child ensures the tooltip inherits the sprite's transform
sprite.add(tooltipObject);

3. Styling the Tooltip for Accurate Alignment

By default, the CSS2DRenderer maps the center of the CSS2DObject position directly to the center of the DOM element using CSS translate(-50%, -50%). If you want the tooltip anchor to be at its bottom-center (hovering directly above the sprite), apply CSS transforms:

.tooltip {
  background: rgba(0, 0, 0, 0.75);
  color: #ffffff;
  padding: 6px 12px;
  border-radius: 4px;
  font-family: sans-serif;
  font-size: 12px;
  white-space: nowrap;
  user-select: none;
  /* Shifts the element so the bottom-center sits on the 3D coordinate */
  transform: translate(-50%, -100%);
  transition: opacity 0.2s ease;
}

4. The Render Loop

Both the WebGL scene and the 2D overlay must be updated inside your animation frame loop.

function animate() {
  requestAnimationFrame(animate);

  // Render 3D WebGL Scene
  renderer.render(scene, camera);

  // Project and update 2D DOM elements
  labelRenderer.render(scene, camera);
}

animate();

5. Handling Window Resizing

Synchronize both renderers during resize events to prevent alignment drift between the 3D projection and the HTML elements:

window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();

  renderer.setSize(window.innerWidth, window.innerHeight);
  labelRenderer.setSize(window.innerWidth, window.innerHeight);
});

Using CSS2DRenderer removes the performance and synchronization overhead of custom raycasting or manual vector projections, producing perfectly aligned DOM tooltips that scale with camera zoom and movement.
