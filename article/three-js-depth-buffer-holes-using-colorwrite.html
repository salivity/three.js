Three.js Depth Buffer Holes Using colorWrite

In Three.js, you can create an invisible "hole" or mask that occludes objects behind it without drawing any pixels to the screen. This optical effect is achieved by configuring a material with colorWrite: false and depthWrite: true, which populates the depth buffer while leaving the color buffer untouched. This guide explains how this mechanism works, how to configure the render pipeline correctly, and how to implement it with a minimal code example.

How the Depth Buffer Trick Works

When rendering a 3D scene, the WebGL pipeline uses two primary buffers:

  1. The Color Buffer: Stores the visible RGB/alpha values displayed on the screen.
  2. The Depth Buffer (Z-Buffer): Stores the distance of each fragment relative to the camera to determine which objects are in front of others.

Setting colorWrite = false prevents the material from writing any color values to the screen, making the mesh completely transparent. Setting depthWrite = true forces the mesh to write its geometric depth directly into the depth buffer. Consequently, any geometry rendered afterward that sits behind this invisible mesh will fail the depth test and be discarded, creating a visible "cutout" or "portal."

The Importance of Render Order

For an occlusion mask to work, the invisible masking mesh must be drawn before the objects it is supposed to hide. If the background objects render first, their pixels are already committed to the color buffer before the mask writes its depth.

In Three.js, you control execution order explicitly using the renderOrder property on the Object3D instance:

  • Masking Object: Set a low renderOrder (e.g., renderOrder = 0 or negative).
  • Occluded Objects: Set a higher renderOrder (e.g., renderOrder = 1).

Implementation Example

The following snippet demonstrates how to configure an invisible cylinder that punches a circular hole into a background cube:

import * as THREE from 'three';

// 1. Create the invisible masking geometry (the hole)
const holeGeometry = new THREE.CylinderGeometry(1, 1, 0.5, 32);
const holeMaterial = new THREE.MeshBasicMaterial({
  colorWrite: false, // Do not draw any color to the screen
  depthWrite: true   // Still write to the depth buffer
});

const holeMesh = new THREE.Mesh(holeGeometry, holeMaterial);
holeMesh.renderOrder = 0; // Ensure it renders first
scene.add(holeMesh);

// 2. Create the target object that will be occluded
const targetGeometry = new THREE.BoxGeometry(4, 4, 1);
const targetMaterial = new THREE.MeshStandardMaterial({ color: 0xff0000 });

const targetMesh = new THREE.Mesh(targetGeometry, targetMaterial);
targetMesh.position.z = -1; // Placed behind the hole
targetMesh.renderOrder = 1; // Renders after the hole mask
scene.add(targetMesh);

Practical Use Cases

  • Portals and Windows: Showing a hidden interior scene through an aperture without rendering complex Boolean geometry operations.
  • Augmented Reality (AR): Occluding virtual 3D objects with real-world obstacles using a reconstructed invisible mesh.
  • Cross-Section Views: Cutting away layers of architectural or mechanical models dynamically in real time.
