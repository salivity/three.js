Using MathNode for GPU Calculations in Three.js

This article provides a practical guide on implementing the MathNode within Three.js's Node Material system to execute complex mathematical calculations directly on the GPU. By leveraging GPU-accelerated node expressions, you can create procedural textures, vertex displacements, and dynamic shader effects without writing raw GLSL or WGSL code.

The Role of MathNode in Three.js

Three.js includes a modern Node Material system (often used with the WebGPURenderer or extended WebGL renderers) that constructs shaders as directed acyclic graphs. At the core of numerical transformations in this system is MathNode. It maps standard mathematical operations—such as trigonometry, exponentiation, clamping, and vector mathematics—directly into compiled shader instructions executed in parallel on the GPU.

While you can instantiate MathNode directly, Three.js provides shorthand mathematical functions (sin, cos, pow, mix, cross, etc.) from the three/nodes module that construct MathNode instances under the hood.

Setting Up Node Imports

To use the Node system, import the required nodes from three/nodes alongside the standard Three.js library:

import * as THREE from 'three';
import { 
  MeshStandardNodeMaterial, 
  MathNode, 
  float, 
  vec3, 
  uv, 
  timerLocal, 
  sin, 
  cos, 
  mul, 
  add 
} from 'three/nodes';

Constructing GPU Math Expressions

You can construct operations using explicit MathNode instances or using the functional syntax.

Method 1: Explicit MathNode Instantiation

MathNode accepts a method name as a string along with input nodes:

// Computes sin(time * 2.0)
const time = timerLocal();
const scaledTime = new MathNode(MathNode.MUL, time, float(2.0));
const wave = new MathNode(MathNode.SIN, scaledTime);

Common methods supported by MathNode include:

  • MathNode.SIN, MathNode.COS, MathNode.TAN
  • MathNode.POW, MathNode.EXP, MathNode.LOG
  • MathNode.MIN, MathNode.MAX, MathNode.CLAMP
  • MathNode.MIX, MathNode.SMOOTHSTEP
  • MathNode.DOT, MathNode.CROSS, MathNode.NORMALIZE

Method 2: Fluent TSL (Three Shading Language) Syntax

The modern idiomatic approach in Three.js wraps MathNode under declarative functions, which allows for cleaner composition:

const coords = uv();
const time = timerLocal(1.0);

// Complex calculation: wave pattern combining multiple frequencies
const frequency = float(10.0);
const waveX = sin(add(mul(coords.x, frequency), time));
const waveY = cos(add(mul(coords.y, frequency), time));

// Combine calculations using MathNode operations
const combined = mul(add(waveX, waveY), float(0.5));

Applying GPU Calculations to a Material

Once the node calculation graph is constructed, bind it to a node material property, such as colorNode for fragment shading or positionNode for vertex displacement.

Example: Vertex Displacement and Dynamic Color

import * as THREE from 'three';
import { 
  MeshStandardNodeMaterial, 
  positionLocal, 
  timerLocal, 
  sin, 
  vec3, 
  mul, 
  add 
} from 'three/nodes';

// 1. Define the calculation graph
const time = timerLocal();
const elevationFactor = float(0.3);

// Calculate displacement: sin(position.x * 4.0 + time) * 0.3
const waveCalculation = mul(
  sin(add(mul(positionLocal.x, float(4.0)), time)),
  elevationFactor
);

// Displace vertices along the Y axis
const displacedPosition = vec3(
  positionLocal.x,
  add(positionLocal.y, waveCalculation),
  positionLocal.z
);

// Dynamic coloring based on elevation
const colorOutput = vec3(
  add(waveCalculation, float(0.5)),
  float(0.2),
  float(0.8)
);

// 2. Create the Node Material
const material = new MeshStandardNodeMaterial();
material.positionNode = displacedPosition;
material.colorNode = colorOutput;

// 3. Attach to Mesh
const geometry = new THREE.PlaneGeometry(10, 10, 64, 64);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Performance Benefits

  • Zero CPU-to-GPU Overhead: Values update per-frame via GPU uniforms (like timerLocal) without transferring geometry or vertex buffers every frame.
  • Compilation Optimization: During the render pass, Three.js optimizes the node tree, eliminating redundant calculations and directly inlining instructions into the target shader stage.
  • Cross-Platform Parity: The same node graph compiles down to GLSL for WebGL or WGSL for WebGPU without altering the calculation logic.
