Enable MSAA on Refractor Render Target in Three.js

This article explains how to enable hardware multisampling (MSAA) on the internal render target used by the Three.js Refractor class. By targeting the samples property of the refractor's underlying WebGLRenderTarget in a WebGL 2 context, you can significantly reduce aliasing artifacts inside refraction textures without implementing costly post-processing passes.

Prerequisites for Hardware MSAA

Hardware multisample anti-aliasing on offscreen framebuffers requires WebGL 2. Modern versions of Three.js utilize WebGL 2 by default when creating a WebGLRenderer. Multisampling is controlled via the samples property on THREE.WebGLRenderTarget. Setting samples to a value greater than 0 (commonly 2, 4, or 8) configures multisampled renderbuffers internally via gl.renderbufferStorageMultisample.

Accessing and Configuring the Refractor Render Target

The Refractor object (imported from three/addons/objects/Refractor.js) manages an internal WebGLRenderTarget used to capture the refracted scene. It exposes this target via the getRenderTarget() method.

Because Refractor does not always expose a direct constructor parameter for multisampling across every Three.js revision, setting the samples property directly on the internal target is the most reliable approach:

import * as THREE from 'three';
import { Refractor } from 'three/addons/objects/Refractor.js';

// 1. Create the refractor geometry and options
const refractorGeometry = new THREE.PlaneGeometry(10, 10);

const refractor = new Refractor(refractorGeometry, {
    color: 0x999999,
    textureWidth: window.innerWidth * window.devicePixelRatio,
    textureHeight: window.innerHeight * window.devicePixelRatio,
    clipBias: 0.003
});

// 2. Access the internal render target
const renderTarget = refractor.getRenderTarget();

// 3. Enable hardware MSAA
renderTarget.samples = 4; // Typical values: 2, 4, 8

// 4. Add the refractor to your scene
scene.add(refractor);

Handling Maximum Sample Limits

GPUs have hardware limits on the maximum number of supported MSAA samples. Attempting to set a sample count higher than the hardware capability will cause the driver to clamp or fail. You can query the maximum supported sample count using the renderer's capabilities:

const maxSamples = renderer.capabilities.maxSamples;
renderTarget.samples = Math.min(4, maxSamples);

Handling Window Resize

When resizing the application window, update the refractor's render target size using setSize(). The samples configuration persists through resize operations:

window.addEventListener('resize', () => {
    const width = window.innerWidth * window.devicePixelRatio;
    const height = window.innerHeight * window.devicePixelRatio;

    const renderTarget = refractor.getRenderTarget();
    renderTarget.setSize(width, height);
});

Enabling MSAA directly on the Refractor target smooths the internal geometry edges seen through the refractive medium while avoiding the blurriness associated with manual screen-space anti-aliasing filters.
