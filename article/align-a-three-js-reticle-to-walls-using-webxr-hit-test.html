Align a Three.js Reticle to Walls Using WebXR Hit Test

This article explains how to use WebXR hit testing in Three.js to detect vertical surfaces and orient a reticle flat against a physical wall. By querying the hit test results relative to the reference space, extracting the hit pose matrix, and adjusting for geometry orientation and surface normals, you can ensure a targeting reticle sits strictly parallel to vertical architecture rather than snapping to the floor.

1. Initialize the WebXR Hit Test Source

To retrieve hit test data, request an XRHitTestSource from the active XRSession. You need to request a reference space (usually 'viewer') to define the ray origin from the device's camera position.

let hitTestSource = null;
let hitTestSourceRequested = false;

function onSessionStarted(session) {
  session.requestReferenceSpace('viewer').then((viewerSpace) => {
    session.requestHitTestSource({ space: viewerSpace }).then((source) => {
      hitTestSource = source;
    });
  });

  session.addEventListener('end', () => {
    hitTestSourceRequested = false;
    hitTestSource = null;
  });
}

2. Create the Reticle Mesh

Create a reticle mesh in Three.js. By default, primitive geometries like THREE.RingGeometry or THREE.PlaneGeometry lie on the local XY plane. When oriented via the WebXR hit pose, the surface normal corresponds to the positive Y axis in standard WebXR transforms. Rotating the ring geometry on the X axis by -Math.PI / 2 ensures that the front face of the mesh points in the direction of the surface normal.

const reticleGeometry = new THREE.RingGeometry(0.1, 0.12, 32);
reticleGeometry.rotateX(-Math.PI / 2);

const reticleMaterial = new THREE.MeshBasicMaterial({ color: 0xffffff });
const reticle = new THREE.Mesh(reticleGeometry, reticleMaterial);
reticle.matrixAutoUpdate = false;
reticle.visible = false;
scene.add(reticle);

3. Retrieve Hit Poses in the Render Loop

In the render loop, pass the hit test source to frame.getHitTestResults(). The pose of the hit provides a transformation matrix that describes both the intersection position and the surface orientation.

function render(timestamp, frame) {
  if (frame && hitTestSource) {
    const referenceSpace = renderer.xr.getReferenceSpace();
    const hitTestResults = frame.getHitTestResults(hitTestSource);

    if (hitTestResults.length > 0) {
      const hit = hitTestResults[0];
      const hitPose = hit.getPose(referenceSpace);

      if (hitPose) {
        reticle.visible = true;
        updateReticleForWall(reticle, hitPose.transform.matrix);
      }
    } else {
      reticle.visible = false;
    }
  }

  renderer.render(scene, camera);
}

4. Filter for Walls and Align the Reticle

The matrix returned by hitPose.transform.matrix contains the orientation where the local Y-axis represents the surface normal pointing away from the detected plane. To make the reticle strictly target walls, isolate the normal vector, verify that it is horizontal (indicating a vertical wall), and constrain the reticle orientation.

const hitMatrix = new THREE.Matrix4();
const normalVector = new THREE.Vector3();
const hitPosition = new THREE.Vector3();
const dummyQuat = new THREE.Quaternion();
const dummyScale = new THREE.Vector3();

function updateReticleForWall(reticleMesh, rawMatrixArray) {
  hitMatrix.fromArray(rawMatrixArray);
  hitMatrix.decompose(hitPosition, dummyQuat, dummyScale);

  // Extract the normal vector from the matrix (the local Y column)
  normalVector.set(
    hitMatrix.elements[4],
    hitMatrix.elements[5],
    hitMatrix.elements[6]
  ).normalize();

  // Check if the surface is vertical: normal.y will be close to 0 on a wall
  const isWall = Math.abs(normalVector.y) < 0.2;

  if (isWall) {
    // Project the normal onto the XZ plane to remove tilt
    normalVector.y = 0;
    normalVector.normalize();

    // Position the reticle at the hit location
    reticleMesh.position.copy(hitPosition);

    // Align the reticle's local up vector (Y-axis) with the surface normal
    reticleMesh.quaternion.setFromUnitVectors(
      new THREE.Vector3(0, 1, 0),
      normalVector
    );

    reticleMesh.updateMatrix();
    reticleMesh.visible = true;
  } else {
    // Hide or handle cases where the detected surface is a floor or ceiling
    reticleMesh.visible = false;
  }
}

Applying this calculation isolates vertical surfaces, discards floor or ceiling hits, and forces the reticle to stay flush and parallel to any detected wall in the WebXR session.
