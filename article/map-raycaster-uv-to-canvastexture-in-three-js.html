Map Raycaster UV to CanvasTexture in Three.js

This article explains how to capture precise intersection points on a 3D mesh using Three.js's Raycaster and translate those normalized UV coordinates into 2D canvas pixel coordinates. By mapping these points directly to an HTML5 canvas element backing a CanvasTexture, you can dynamically paint, stamp, or modify surface textures in real time during user interactions.

1. Initialize the Canvas and CanvasTexture

Create a standard off-screen or hidden HTML5 canvas element, acquire its 2D rendering context, and wrap it within a THREE.CanvasTexture.

const canvas = document.createElement('canvas');
canvas.width = 1024;
canvas.height = 1024;
const ctx = canvas.getContext('2d');

// Fill initial background
ctx.fillStyle = '#ffffff';
ctx.fillRect(0, 0, canvas.width, canvas.height);

const canvasTexture = new THREE.CanvasTexture(canvas);

// Apply to a mesh material
const material = new THREE.MeshStandardMaterial({
  map: canvasTexture
});
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

2. Raycast Against the Target Mesh

Convert mouse or pointer events into normalized device coordinates (NDC) ranging from -1 to +1, then pass them through THREE.Raycaster against the target mesh. The mesh geometry must possess UV attributes for coordinate extraction to work.

const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

function onPointerMove(event) {
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObject(mesh);

  if (intersects.length > 0) {
    const hit = intersects[0];
    if (hit.uv) {
      drawAtUV(hit.uv);
    }
  }
}

3. Translate Normalized UVs to Canvas Coordinates

Three.js returns the hit.uv property as a THREE.Vector2 where values range from 0.0 to 1.0. While WebGL UV coordinates typically place (0, 0) at the bottom-left corner, HTML5 Canvas uses an inverted vertical axis where (0, 0) resides at the top-left corner.

Because THREE.CanvasTexture has flipY = true enabled by default, the texture automatically inverts the Y-axis upon uploading to the GPU. Consequently, you must match the canvas coordinate space:

function drawAtUV(uv) {
  // Map normalized (0.0 to 1.0) values to canvas dimensions
  const x = uv.x * canvas.width;
  const y = (1 - uv.y) * canvas.height;

  // Execute standard 2D canvas drawing operations
  const brushRadius = 20;
  ctx.beginPath();
  ctx.arc(x, y, brushRadius, 0, Math.PI * 2);
  ctx.fillStyle = '#ff0000';
  ctx.fill();

  // Notify WebGL that the texture data has changed
  canvasTexture.needsUpdate = true;
}

If you explicitly set canvasTexture.flipY = false, map the vertical axis directly without inversion: const y = uv.y * canvas.height;.

4. Optimize Updates

Setting canvasTexture.needsUpdate = true forces WebGL to re-upload the canvas bitmap to the GPU on the next render pass. To preserve performance:

  • Only set needsUpdate = true when an actual modification to the canvas context occurs.
  • Keep the canvas resolution as low as practical for your visual fidelity requirements (e.g., 512x512 or 1024x1024), as large pixel buffers increase per-frame texture upload latency.
