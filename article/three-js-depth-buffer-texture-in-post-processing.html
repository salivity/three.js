Three.js Depth Buffer Texture in Post-Processing

Extracting the depth buffer in Three.js allows you to implement advanced screen-space post-processing effects such as depth of field, screen-space ambient occlusion (SSAO), and distance-based fog. By attaching a THREE.DepthTexture instance directly to a THREE.WebGLRenderTarget, Three.js automatically records z-buffer data during the primary render pass. This guide explains how to configure a render target with a depth texture, pass that texture to a custom post-processing shader, and linearize the non-linear depth values inside the fragment shader.

1. Create a Render Target with a Depth Texture

To capture depth, instantiate a THREE.DepthTexture and assign it to the depthTexture property of your THREE.WebGLRenderTarget.

import * as THREE from 'three';

const width = window.innerWidth;
const height = window.innerHeight;

// 1. Create the depth texture
const depthTexture = new THREE.DepthTexture();
depthTexture.type = THREE.UnsignedShortType; // Alternatively, THREE.FloatType for higher precision

// 2. Create the render target and assign the depth texture
const renderTarget = new THREE.WebGLRenderTarget(width, height, {
  minFilter: THREE.NearestFilter,
  magFilter: THREE.NearestFilter,
  depthTexture: depthTexture,
  depthBuffer: true
});

Using THREE.UnsignedShortType provides 16-bit depth precision, which is generally sufficient for most effects. If you require higher precision for large view frustums or complex calculations, use THREE.FloatType or THREE.UnsignedIntType.

2. Configure the Custom Post-Processing Shader

WebGL stores depth buffer values non-linearly due to perspective projection. To use depth values effectively in world space, you must linearize the sample inside the fragment shader using the camera's near and far clipping planes.

Vertex Shader

A simple full-screen quad vertex shader:

varying vec2 vUv;

void main() {
    vUv = uv;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}

Fragment Shader

Sample the depth texture and convert the perspective depth to a linear value between 0.0 and 1.0:

#include <packing>

varying vec2 vUv;
uniform sampler2D tDiffuse;
uniform sampler2D tDepth;
uniform float cameraNear;
uniform float cameraFar;

// Converts non-linear WebGL depth to linear view-space depth
float readDepth(sampler2D depthSampler, vec2 coord) {
    float fragCoordZ = texture2D(depthSampler, coord).x;
    float viewZ = perspectiveDepthToViewZ(fragCoordZ, cameraNear, cameraFar);
    return viewZToOrthographicDepth(viewZ, cameraNear, cameraFar);
}

void main() {
    vec4 sceneColor = texture2D(tDiffuse, vUv);
    float depth = readDepth(tDepth, vUv);

    // Example: visualize depth as grayscale
    gl_FragColor = vec4(vec3(depth), 1.0);
}

3. Build the Post-Processing Scene

Create a secondary scene containing a full-screen quad mapped with a THREE.ShaderMaterial that consumes the depth texture.

const postCamera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1);
const postScene = new THREE.Scene();

const postMaterial = new THREE.ShaderMaterial({
  vertexShader: document.getElementById('vertexShader').textContent,
  fragmentShader: document.getElementById('fragmentShader').textContent,
  uniforms: {
    tDiffuse: { value: renderTarget.texture },
    tDepth: { value: renderTarget.depthTexture },
    cameraNear: { value: camera.near },
    cameraFar: { value: camera.far }
  }
});

const postQuad = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), postMaterial);
postScene.add(postQuad);

4. Execute the Render Loop

In your animation loop, render the main scene to the custom render target first. Then render the post-processing scene directly to the canvas.

function animate() {
  requestAnimationFrame(animate);

  // 1. Render main scene into the render target to populate color and depth textures
  renderer.setRenderTarget(renderTarget);
  renderer.render(scene, camera);

  // 2. Render post-processing quad to the screen (default framebuffer)
  renderer.setRenderTarget(null);
  renderer.render(postScene, postCamera);
}

animate();

5. Handling Window Resizes

Ensure both the color buffer and the depth texture scale whenever the viewport changes:

window.addEventListener('resize', () => {
  const width = window.innerWidth;
  const height = window.innerHeight;

  camera.aspect = width / height;
  camera.updateProjectionMatrix();

  renderer.setSize(width, height);
  renderTarget.setSize(width, height);
});
