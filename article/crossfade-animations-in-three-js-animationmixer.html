Crossfade Animations in Three.js AnimationMixer

This guide demonstrates how to set up a THREE.AnimationMixer to smoothly transition between an idle animation and a running animation in Three.js. You will learn how to initialize the mixer, extract and configure AnimationAction instances for both states, execute a timed crossfade transition, and update the animation state inside the render loop.

1. Initialize the Mixer and Actions

First, instantiate a THREE.AnimationMixer using your loaded 3D model (typically a GLTF or FBX scene root). Once the mixer is initialized, extract your animation clips and generate corresponding AnimationAction references.

// Assume 'model' is your loaded 3D Object3D, and 'gltf.animations' contains clips
const mixer = new THREE.AnimationMixer(model);

// Locate clips by name
const idleClip = THREE.AnimationClip.findByName(gltf.animations, 'Idle');
const runClip = THREE.AnimationClip.findByName(gltf.animations, 'Run');

// Create actions
const idleAction = mixer.clipAction(idleClip);
const runAction = mixer.clipAction(runClip);

2. Set Up the Initial State

Before crossfading, play the idle animation and ensure both actions are configured so they blend without abruptly resetting to default transforms.

// Start playing the idle action
idleAction.play();

// Ensure the running action is ready to blend in
runAction.enabled = true;
runAction.setEffectiveTimeScale(1);
runAction.setEffectiveWeight(0);
runAction.play();

3. Execute the Crossfade

To transition between the two actions over a specific duration (in seconds), you can use the built-in crossFadeTo() method on the current action, or combine fadeIn() and fadeOut().

Method A: Using crossFadeTo

crossFadeTo(targetAction, durationInSeconds, warp) fades out the active action while fading in the target action over the specified duration. Setting the third parameter warp to true scales the time of the actions to synchronize their phase (useful if both are locomotion loops).

function transitionToRun(duration = 0.5) {
    // Reset and prepare the target action
    runAction.enabled = true;
    runAction.setEffectiveTimeScale(1);
    runAction.setEffectiveWeight(1);
    runAction.time = 0;

    // Crossfade from idle to running
    idleAction.crossFadeTo(runAction, duration, false);
}

Method B: Using fadeIn and fadeOut

The direct fade method provides explicit control over each action's weight transitions:

function transitionToRunExplicit(duration = 0.5) {
    runAction.reset();
    runAction.fadeIn(duration);
    idleAction.fadeOut(duration);
}

4. Returning to Idle

To switch back from running to idle, reverse the source and destination actions:

function transitionToIdle(duration = 0.5) {
    idleAction.reset();
    idleAction.fadeIn(duration);
    runAction.fadeOut(duration);
}

5. Update the Mixer in the Animation Loop

An AnimationMixer requires delta time updates on every frame to advance animation frames and interpolate weights during crossfades. Use a THREE.Clock to supply the elapsed time.

const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();
    mixer.update(delta);

    renderer.render(scene, camera);
}

animate();
