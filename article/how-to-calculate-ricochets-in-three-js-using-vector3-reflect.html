How to Calculate Ricochets in Three.js Using Vector3.reflect

Calculating the ricochet trajectory of a bouncing object in Three.js involves determining the collision point on a surface and mathematically reflecting the object's velocity vector across the surface's normal vector. This guide demonstrates how to detect collisions using THREE.Raycaster, extract the face normal of the impacted geometry, and utilize the built-in Vector3.reflect method to calculate the precise angle and direction of deflection for realistic bouncing physics.

1. Understanding Vector Reflection

When an object bounces off a flat barrier, the angle of reflection equals the angle of incidence. In 3D space, this calculation requires two pieces of information:

  • The Incident Vector: The object's incoming direction or velocity vector.
  • The Normal Vector: A unit vector perpendicular to the surface at the point of impact.

The mathematical formula applied internally by Three.js is:

\[v_{reflected} = v - 2(v \cdot n)n\]

Where \(v\) is the incoming velocity and \(n\) is the normalized surface normal.

2. Detecting the Collision and Surface Normal

To reflect a vector, you must first know what the object hits and the orientation of that surface. Using THREE.Raycaster is the most reliable way to find this data in Three.js.

const raycaster = new THREE.Raycaster();
const objectPosition = bullet.position.clone();
const objectVelocity = new THREE.Vector3(5, -2, 0); // Moving downward and right

// Normalize velocity to get the direction for the raycaster
const moveDirection = objectVelocity.clone().normalize();
const moveDistance = objectVelocity.length() * delta; // Distance traveled this frame

raycaster.set(objectPosition, moveDirection);

// Check intersections against collidable scene meshes
const intersects = raycaster.intersectObjects(collidableMeshes, false);

3. Applying Vector3.reflect

When an intersection occurs within the current frame's movement distance, you can access the surface normal via the intersection result's face.normal property.

Before applying the reflection, ensure the normal is transformed into world coordinates if the intersected mesh has been rotated or scaled.

if (intersects.length > 0 && intersects[0].distance <= moveDistance) {
    const hit = intersects[0];

    // 1. Get the surface normal in world space
    const normal = hit.face.normal.clone();
    normal.transformDirection(hit.object.matrixWorld);

    // 2. Position the object at the point of impact
    bullet.position.copy(hit.point);

    // 3. Reflect the velocity vector off the normal
    objectVelocity.reflect(normal);

    // 4. Optional: Account for energy loss (bounciness/restitution)
    const restitution = 0.8; // 80% speed retained
    objectVelocity.multiplyScalar(restitution);

    // 5. Prevent sticking: nudge object slightly along the normal
    bullet.position.addScaledVector(normal, 0.001);
} else {
    // No collision: proceed with normal movement
    bullet.position.addScaledVector(objectVelocity, delta);
}

Key Considerations

  • Unit Length for Normals: The normal parameter passed into Vector3.reflect() must be normalized. Face normals obtained from hit.face.normal and transformed using transformDirection will remain unit vectors, ensuring an accurate bounce.
  • Surface Penetration: Moving objects can sometimes penetrate surfaces if their velocity is high relative to the frame rate. Placing the object directly at hit.point and adding a tiny offset along the normal prevents the object from getting stuck inside the geometry on the subsequent frame.
