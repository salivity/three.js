Three.js Camera Path with CatmullRomCurve3

This article demonstrates how to create a custom camera controller in Three.js that smoothly travels along a predefined 3D path using THREE.CatmullRomCurve3. You will learn how to define spline control points, compute normalized progress over time, sample precise coordinates along the curve, and smoothly orient the camera to look ahead along the trajectory inside the render loop.

1. Define the Spline Path

A CatmullRomCurve3 generates a smooth, continuous cubic spline passing through an array of 3D control points. You can define the path points using THREE.Vector3 instances and decide whether the track should loop.

import * as THREE from 'three';

const points = [
  new THREE.Vector3(-10, 2, -10),
  new THREE.Vector3(-5, 5, 0),
  new THREE.Vector3(0, 3, 10),
  new THREE.Vector3(10, 8, 5),
  new THREE.Vector3(5, 2, -5)
];

// Set the second argument to true for a closed loop
const curve = new THREE.CatmullRomCurve3(points, true);
curve.curveType = 'centripetal'; // Options: 'centripetal', 'chordal', 'catmullrom'

Using 'centripetal' avoids self-intersections and sharp cusps, producing a natural flight path.

2. Implement the Camera Controller

To move the camera smoothly over time, calculate a normalized progress variable \(t \in [0, 1]\) based on the elapsed time and a set travel duration.

Using curve.getPointAt(t) provides the position along the curve. To orient the camera along the direction of travel, sample a point slightly ahead on the curve using curve.getPointAt((t + offset) % 1) and pass it to camera.lookAt().

export class SplineCameraController {
  constructor(camera, curve, duration = 10) {
    this.camera = camera;
    this.curve = curve;
    this.duration = duration; // Loop duration in seconds
    this.progress = 0;
    this.lookAhead = 0.01; // Small offset along curve for look-at target
    this.target = new THREE.Vector3();
    this.position = new THREE.Vector3();
  }

  update(delta) {
    // Increment normalized progress based on frame delta
    this.progress = (this.progress + delta / this.duration) % 1;

    // Retrieve camera position along the curve
    this.curve.getPointAt(this.progress, this.position);
    this.camera.position.copy(this.position);

    // Retrieve look-at target slightly ahead on the curve
    const targetProgress = (this.progress + this.lookAhead) % 1;
    this.curve.getPointAt(targetProgress, this.target);
    
    // Ensure the camera maintains the proper world up-vector
    this.camera.up.set(0, 1, 0);
    this.camera.lookAt(this.target);
  }
}

3. Integrate with the Render Loop

Instantiate the controller and supply the frame's elapsed delta time inside your application's requestAnimationFrame loop using THREE.Clock.

const camera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);

const clock = new THREE.Clock();
const cameraController = new SplineCameraController(camera, curve, 15);

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  cameraController.update(delta);

  renderer.render(scene, camera);
}

animate();

4. Smoothing Orientation Transitions

Directly calling lookAt every frame can cause rapid rotation shifts when entering tight bends. To achieve cinematic damping, interpolate the target vector using linear interpolation (lerp):

update(delta) {
  this.progress = (this.progress + delta / this.duration) % 1;

  // Update position
  this.curve.getPointAt(this.progress, this.position);
  this.camera.position.copy(this.position);

  // Calculate prospective look-at point
  const nextTarget = new THREE.Vector3();
  const targetProgress = (this.progress + this.lookAhead) % 1;
  this.curve.getPointAt(targetProgress, nextTarget);

  // Smoothly damp rotation toward the new target
  this.target.lerp(nextTarget, 0.05);
  this.camera.lookAt(this.target);
}

This ensures the camera's rotational momentum remains steady across curvature changes along the path.
