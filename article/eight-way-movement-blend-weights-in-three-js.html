Eight-Way Movement Blend Weights in Three.js

Creating an eight-way directional movement system in Three.js requires calculating dynamic blend weights for character animations based on a player's directional input vector. By mapping keyboard or joystick inputs onto a 2D plane, normalizing the resulting vector, and evaluating the angular difference or dot product against eight directional reference vectors (Forward, Backward, Left, Right, and the four diagonals), you can adjust each AnimationAction's weight in real-time. This guide details the mathematical approach and provides a direct code implementation for dynamically blending multiple animations using Three.js's AnimationMixer.

Defining the Directional Space

An eight-way movement system relies on eight distinct movement animations:

  • Forward (N): \((0, 1)\)
  • Forward-Right (NE): \((\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})\)
  • Right (E): \((1, 0)\)
  • Backward-Right (SE): \((\frac{\sqrt{2}}{2}, -\frac{\sqrt{2}}{2})\)
  • Backward (S): \((0, -1)\)
  • Backward-Left (SW): \((-\frac{\sqrt{2}}{2}, -\frac{\sqrt{2}}{2})\)
  • Left (W): \((-1, 0)\)
  • Forward-Left (NW): \((-\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})\)

Store your directional clips in an array or map containing the action and its corresponding unit direction vector.

import * as THREE from 'three';

const directions = [
  { name: 'idle', action: actions['idle'], dir: new THREE.Vector2(0, 0) },
  { name: 'forward', action: actions['walk_n'], dir: new THREE.Vector2(0, 1) },
  { name: 'forward_right', action: actions['walk_ne'], dir: new THREE.Vector2(1, 1).normalize() },
  { name: 'right', action: actions['walk_e'], dir: new THREE.Vector2(1, 0) },
  { name: 'backward_right', action: actions['walk_se'], dir: new THREE.Vector2(1, -1).normalize() },
  { name: 'backward', action: actions['walk_s'], dir: new THREE.Vector2(0, -1) },
  { name: 'backward_left', action: actions['walk_sw'], dir: new THREE.Vector2(-1, -1).normalize() },
  { name: 'left', action: actions['walk_w'], dir: new THREE.Vector2(-1, 0) },
  { name: 'forward_left', action: actions['walk_nw'], dir: new THREE.Vector2(-1, 1).normalize() }
];

// Start all actions playing with an initial weight of 0
directions.forEach(({ action }) => {
  action.play();
  action.setEffectiveWeight(0);
});
actions['idle'].setEffectiveWeight(1);

Calculating Dynamic Blend Weights

To blend between the animations, determine the current movement vector from input (such as WASD keys) and calculate how closely it aligns with each reference vector. A common and efficient method uses the clamped dot product or angular distance between the input vector and the direction vectors.

When the input vector is non-zero, calculate the angle \(\theta = \text{atan2}(y, x)\) of the input, locate the two adjacent directional vectors, and interpolate weights between them so their total sum equals 1.0.

const inputVector = new THREE.Vector2();

function updateMovementWeights(inputX, inputY, delta) {
  inputVector.set(inputX, inputY);
  const magnitude = Math.min(inputVector.length(), 1.0);

  if (magnitude > 0.001) {
    inputVector.normalize();

    // Calculate angle in radians [0, 2PI)
    let angle = Math.atan2(inputVector.y, inputVector.x);
    if (angle < 0) angle += 2 * Math.PI;

    // Each segment is PI / 4 radians (45 degrees)
    const segmentAngle = Math.PI / 4;

    directions.forEach(({ name, action, dir }) => {
      if (name === 'idle') {
        const targetWeight = (1.0 - magnitude);
        blendActionWeight(action, targetWeight, delta);
        return;
      }

      let dirAngle = Math.atan2(dir.y, dir.x);
      if (dirAngle < 0) dirAngle += 2 * Math.PI;

      // Find shortest angular difference
      let diff = Math.abs(angle - dirAngle);
      if (diff > Math.PI) diff = 2 * Math.PI - diff;

      // Assign weight if within the 45-degree blending window
      let targetWeight = 0;
      if (diff < segmentAngle) {
        targetWeight = (1.0 - (diff / segmentAngle)) * magnitude;
      }

      blendActionWeight(action, targetWeight, delta);
    });
  } else {
    // Return to idle
    directions.forEach(({ name, action }) => {
      const targetWeight = (name === 'idle') ? 1.0 : 0.0;
      blendActionWeight(action, targetWeight, delta);
    });
  }
}

Smoothing and Applying Weights

Setting weights instantly can produce jerky transitions when inputs switch rapidly. Use linear interpolation (MathUtils.lerp) within your animation loop to transition current action weights toward their target weights.

function blendActionWeight(action, targetWeight, delta, blendSpeed = 10) {
  const currentWeight = action.getEffectiveWeight();
  const newWeight = THREE.MathUtils.lerp(currentWeight, targetWeight, 1 - Math.exp(-blendSpeed * delta));
  
  action.setEffectiveWeight(newWeight);
}

Synchronization Across Movement Clips

For movement animations to blend naturally without foot-sliding or phase discrepancies, all eight movement clips must be synchronized. Synchronize the playback by matching the time parameter of all active movement actions to a reference action or setting their timeScale values proportionally if they vary in length.

function synchronizeActions(masterAction, secondaryActions) {
  const progress = masterAction.time / masterAction.getClip().duration;
  secondaryActions.forEach(action => {
    if (action.getEffectiveWeight() > 0) {
      action.time = progress * action.getClip().duration;
    }
  });
}

Call updateMovementWeights(inputX, inputY, delta), synchronize the clips, and invoke mixer.update(delta) inside the primary render loop to achieve responsive, smooth eight-way directional blending.
