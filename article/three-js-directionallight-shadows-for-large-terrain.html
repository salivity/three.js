Three.js DirectionalLight Shadows for Large Terrain

Configuring clean, high-performance orthographic shadow maps across large terrains in Three.js requires precisely sizing the directional light's shadow frustum, adjusting depth bounds, and eliminating shadow acne. Because a DirectionalLight uses an OrthographicCamera internally to generate its depth map, developers must manually tune the camera's bounding box and bias settings to balance shadow resolution with spatial coverage. This guide provides the exact configuration needed to project crisp shadows over extensive terrain geometry.

1. Enable Shadows in the WebGLRenderer

Before configuring the light, shadow map rendering must be enabled globally on the WebGLRenderer. Setting the shadow type to PCFSoftShadowMap produces smooth edges along the terrain elevation.

renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

2. Configure the Orthographic Frustum Bounds

By default, the shadow camera's orthographic volume is tiny (5 units in each direction). For a large terrain, you must expand the frustum planes (left, right, top, bottom) to tightly wrap the visible play area. Making the bounds excessively large will dilute shadow resolution, causing pixelation.

const dirLight = new THREE.DirectionalLight(0xffffff, 1.5);
dirLight.position.set(100, 150, 50);
dirLight.castShadow = true;

// Shadow map texture resolution
dirLight.shadow.mapSize.width = 4096;
dirLight.shadow.mapSize.height = 4096;

// Define orthographic bounds (e.g., a 200x200 unit coverage area)
const d = 100;
dirLight.shadow.camera.left = -d;
dirLight.shadow.camera.right = d;
dirLight.shadow.camera.top = d;
dirLight.shadow.camera.bottom = -d;

// Keep near and far planes as tight as possible
dirLight.shadow.camera.near = 10;
dirLight.shadow.camera.far = 400;

3. Eliminate Shadow Acne with Bias

Large orthographic projections over uneven surfaces like heightmaps often suffer from shadow acne (self-shadowing artifacts) and peter-panning (detached shadows). Use normalBias alongside a minor bias to fix surface interpolation issues across steep terrain slopes:

dirLight.shadow.bias = -0.0005;
dirLight.shadow.normalBias = 0.05;

4. Enable Shadow Casting and Receiving on Meshes

Ensure the terrain mesh is set to receive shadows, while props, foliage, and characters are configured to cast and receive them:

terrainMesh.castShadow = false;
terrainMesh.receiveShadow = true;

propMesh.castShadow = true;
propMesh.receiveShadow = true;

5. Anchor the Light to the Player for Infinite Terrains

Covering an entire massive world in a single static shadow map is impractical because texture resolution degrades over extreme distances. Instead, move the light and its target in sync with the player in your render loop, snapping coordinates to texel increments to prevent shadow edge shimmering:

function updateShadows(player) {
  const shadowCamSize = 200; // Total width/height of the frustum
  const texelSize = shadowCamSize / dirLight.shadow.mapSize.width;

  // Calculate quantized target position
  const targetX = Math.floor(player.position.x / texelSize) * texelSize;
  const targetZ = Math.floor(player.position.z / texelSize) * texelSize;

  // Offset the light from the quantized target
  dirLight.target.position.set(targetX, 0, targetZ);
  dirLight.position.set(targetX + 100, 150, targetZ + 50);

  dirLight.target.updateMatrixWorld();
  dirLight.shadow.camera.updateProjectionMatrix();
}

This ensures maximum shadow resolution immediately around the viewpoint without wasting texture memory on distant, unseen geometry.
