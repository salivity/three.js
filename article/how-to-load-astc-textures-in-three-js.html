How to Load ASTC Textures in Three.js

Adaptive Scalable Texture Compression (ASTC) is an industry-standard compression format widely supported by modern mobile GPUs to dramatically reduce VRAM usage and memory bandwidth. This article covers how to verify ASTC support in WebGL, load ASTC-compressed textures using Three.js loaders, and apply them directly to 3D materials to optimize rendering performance on mobile devices.

Why Use ASTC for Mobile Devices?

Standard image formats like PNG or JPEG must be fully uncompressed into VRAM, causing large memory footprints and mobile browser crashes. ASTC stays compressed in GPU memory, drastically lowering memory usage, improving cache efficiency, and increasing frame rates on supported iOS and Android hardware.

Step 1: Check for ASTC Hardware Support

Before attempting to use ASTC textures, check if the client device supports the WEBGL_compressed_texture_astc extension using the WebGL renderer.

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer({ antialias: true });

// Check for ASTC extension support
const hasASTC = renderer.extensions.has('WEBGL_compressed_texture_astc');

if (!hasASTC) {
  console.warn('ASTC texture compression is not supported on this device.');
}

Step 2: Use KTX2Loader for Handling ASTC Files

While raw .astc files exist, production workflows typically bundle ASTC textures inside KTX or KTX2 containers. The KTX2Loader is the recommended method in Three.js because it detects hardware capabilities and transcodes universal Basis Universal textures directly into the target ASTC format on mobile GPUs.

import * as THREE from 'three';
import { KTX2Loader } from 'three/addons/loaders/KTX2Loader.js';

// Initialize the KTX2Loader
const ktx2Loader = new KTX2Loader();
ktx2Loader.setTranscoderPath('three/addons/libs/basis/');
ktx2Loader.detectSupport(renderer);

Step 3: Load and Apply the Texture to a Material

Once the loader is configured with the renderer's supported formats, load the texture asynchronously and apply it to a material's map property.

// Load the compressed texture
ktx2Loader.load(
  'textures/diffuse_texture.ktx2',
  (texture) => {
    // Configure texture color space
    texture.colorSpace = THREE.SRGBColorSpace;

    // Create a material and apply the compressed texture
    const material = new THREE.MeshStandardMaterial({
      map: texture,
      roughness: 0.8,
      metalness: 0.2
    });

    // Apply the material to a mesh
    const geometry = new THREE.BoxGeometry(1, 1, 1);
    const mesh = new THREE.Mesh(geometry, material);
    scene.add(mesh);
  },
  undefined,
  (error) => {
    console.error('An error occurred loading the ASTC texture:', error);
  }
);

Loading Direct KTX (ASTC) Textures with KTXLoader

If you are serving pre-compressed .ktx files containing raw ASTC payload without transcoding, use KTXLoader instead:

import { KTXLoader } from 'three/addons/loaders/KTXLoader.js';

const ktxLoader = new KTXLoader();

ktxLoader.load('textures/direct_astc.ktx', (texture) => {
  texture.colorSpace = THREE.SRGBColorSpace;

  const material = new THREE.MeshBasicMaterial({ map: texture });
  const mesh = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), material);
  scene.add(mesh);
});

Best Practices for Production

  • Implement Fallbacks: Always provide desktop-compatible formats (such as BC7/DXT5 via desktop checks) or standard WebP/PNG fallbacks if renderer.extensions.has('WEBGL_compressed_texture_astc') returns false.
  • Dispose Appropriately: Always call texture.dispose() when unloading scenes or changing levels to release VRAM on constrained mobile devices.
