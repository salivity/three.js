Matching Real-World Camera Lenses in Three.js

In Three.js, accurately matching real-world physical cameras is essential for visual effects, architectural visualization, and augmented reality. By leveraging the filmGauge and filmOffset properties along with the setFocalLength() method on a PerspectiveCamera, you can mimic specific sensor sizes, prime lenses, and physical lens shifts rather than relying on arbitrary field-of-view (FOV) values.

Understanding filmGauge (Sensor Size)

In physical photography, the sensor size (or film format) dictates how a lens behaves. In Three.js, camera.filmGauge represents the width of the film or digital sensor in millimeters.

By default, Three.js sets filmGauge to 35 (representing the 35mm full-frame standard with an active width of 35mm). If you are matching a specific physical camera, you must change this value to match your hardware's sensor width:

  • Full Frame (35mm): 36 mm (standard 35mm format commonly approximated as 35 or 36 mm)
  • Super 35: ~24.89 mm
  • APS-C (Canon): ~22.3 mm
  • APS-C (Sony/Nikon): ~23.5 mm
  • Micro Four Thirds: ~17.3 mm

Setting the Focal Length

Instead of manually calculating the vertical field of view (fov), Three.js provides the camera.setFocalLength(focalLength) method. This function computes and updates the camera's fov property internally using the current filmGauge:

\[\text{FOV} = 2 \times \arctan\left(\frac{\text{filmGauge}}{2 \times \text{focalLength}}\right)\]

To configure a camera with a specific real-world lens:

import * as THREE from 'three';

const camera = new THREE.PerspectiveCamera(50, window.innerWidth / window.innerHeight, 0.1, 1000);

// 1. Set sensor size (e.g., Super 35 sensor width in mm)
camera.filmGauge = 24.89;

// 2. Set the focal length in mm (e.g., a 50mm prime lens)
camera.setFocalLength(50);

// 3. Update the projection matrix to apply changes
camera.updateProjectionMatrix();

Utilizing filmOffset for Optical Axis Shifts

The camera.filmOffset property offsets the sensor horizontally relative to the optical axis, measured in the same units as filmGauge (millimeters).

In real-world photography, this technique is used with tilt-shift lenses or large-format view cameras to achieve shift photography. Moving the sensor or lens element off-center alters the perspective without rotating the camera, which is standard practice in architectural photography to keep vertical lines parallel.

To offset the frame:

// Shift the lens/sensor horizontally by 5mm
camera.filmOffset = 5.0;

// Apply changes
camera.updateProjectionMatrix();

If you require vertical lens shifting instead of horizontal shifting, Three.js provides the camera.setViewOffset() method, which performs a similar asymmetric projection adjustment across both X and Y axes using pixel values.

Complete Workflow

To fully replicate a physical camera setup in a Three.js scene:

  1. Identify the camera's physical sensor width and set camera.filmGauge.
  2. Determine the lens focal length and call camera.setFocalLength(focalLength).
  3. If simulating a perspective shift, set camera.filmOffset.
  4. Call camera.updateProjectionMatrix() whenever any of these properties are modified to recalculate the projection frustum.
