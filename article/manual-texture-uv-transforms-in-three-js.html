Manual Texture UV Transforms in Three.js

In Three.js, textures automatically compute their UV transformation matrix every frame based on properties like offset, repeat, rotation, and center. By setting texture.matrixAutoUpdate = false, you disable this automatic calculation, allowing direct manipulation of the texture's 3x3 transformation matrix (texture.matrix). This article explains how to configure this property and manually control texture UV coordinates for advanced transformations, such as shearing or custom matrix chains, while optimizing rendering performance.

Disabling Automatic Matrix Updates

By default, Three.js synchronizes texture.matrix with its individual transform properties inside the internal render loop. To take manual control, set the matrixAutoUpdate flag to false immediately after creating or loading the texture:

import * as THREE from 'three';

const textureLoader = new THREE.TextureLoader();
const texture = textureLoader.load('path/to/texture.jpg');

// Disable automatic recalculation
texture.matrixAutoUpdate = false;

Once matrixAutoUpdate is set to false, changing texture.offset, texture.repeat, texture.rotation, or texture.center will have no effect on how the texture is rendered.

Controlling the UV Matrix Directly

The texture coordinate transformation is stored in texture.matrix, which is an instance of THREE.Matrix3. UV coordinates in Three.js are 2D homogeneous coordinates:

\[\begin{bmatrix} U' \\ V' \\ 1 \end{bmatrix} = \mathbf{M} \begin{bmatrix} U \\ V \\ 1 \end{bmatrix}\]

You can manipulate this matrix using built-in Matrix3 methods or by setting its elements directly.

Method 1: Using setUvTransform

If you want to manually trigger the standard UV calculation without enabling per-frame auto-updates, use the setUvTransform helper:

// Arguments: tx, ty, sx, sy, rotation, cx, cy
// (translateX, translateY, scaleX, scaleY, rotation, centerX, centerY)
texture.matrix.setUvTransform(0.1, 0.2, 2.0, 2.0, Math.PI / 4, 0.5, 0.5);

This method calculates the proper translation, rotation around a center point, and scale, applying the result directly to texture.matrix.

Method 2: Manual Matrix Construction and Shearing

Direct matrix access allows you to apply transformations that Three.js does not support natively through standard properties, such as shearing/skewing:

// Define custom scale, shear, and translation
const sx = 1.0;   // Scale X
const sy = 1.0;   // Scale Y
const kx = 0.5;   // Shear along X
const ky = 0.0;   // Shear along Y
const tx = 0.0;   // Translate X
const ty = 0.0;   // Translate Y

// Matrix elements are stored in column-major order:
// [ sx, ky, 0 ]
// [ kx, sy, 0 ]
// [ tx, ty, 1 ]
texture.matrix.set(
    sx, kx, tx,
    ky, sy, ty,
    0,  0,  1
);

Animating the UV Transform Manually

When animating UVs in a render loop with matrixAutoUpdate = false, update the matrix directly inside your animation cycle.

let offset = 0;

function animate() {
    requestAnimationFrame(animate);

    offset += 0.005;

    // Manually translate UVs along the X-axis
    texture.matrix.identity();
    texture.matrix.translate(offset, 0);

    renderer.render(scene, camera);
}

animate();

Because matrixAutoUpdate is disabled, the GPU uniform for the texture matrix will still receive your manual matrix updates via texture.matrix, avoiding redundant calculations on the CPU while giving you precise mathematical control over your coordinates.
