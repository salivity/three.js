Three.js Anti-Aliasing: SMAAPass vs FXAAPass

Post-processing anti-aliasing in Three.js primarily relies on two techniques: Fast Approximate Anti-Aliasing (FXAAPass) and Subpixel Morphological Anti-Aliasing (SMAAPass). While FXAA uses a single-pass heuristic based on local contrast to blur high-frequency edges rapidly, SMAA utilizes a multi-pass pipeline backed by precomputed lookup tables to accurately reconstruct edge geometry and calculate subpixel coverage. Choosing between them involves balancing FXAA's raw rendering speed against SMAA's superior structural clarity and reduction of visual blur.

Algorithmic and Mathematical Differences

1. FXAA (FXAAPass)

FXAA operates strictly on the final rendered image (LDR color buffer) in a single screen-space pass.

  • Luminance Calculation: FXAA converts RGB values into scalar luminance (\(L\)) using perceptual weights: \[L = 0.299R + 0.587G + 0.114B\]
  • Edge Detection: It computes local contrast by sampling the center pixel and its four direct orthogonal neighbors (North, South, East, West). The local contrast is defined as: \[\text{Range} = \max(L_{\text{neighbors}}, L_{\text{center}}) - \min(L_{\text{neighbors}}, L_{\text{center}})\] If \(\text{Range} < \max(\text{Threshold}_{\text{min}}, \text{Threshold}_{\text{rel}} \times \max(L_{\text{neighbors}}, L_{\text{center}}))\), the pixel is skipped.
  • Edge Orientation and Search: If an edge is confirmed, FXAA calculates horizontal and vertical gradients to determine edge orientation. It then searches along the edge direction in steps to find endpoints where the contrast drops.
  • Filtering: Based on the pixel's relative distance to the detected endpoints, FXAA applies a sub-pixel offset using bilinear texture filtering. Because it relies on localized blurring, it frequently softens high-frequency texture details and text along with aliased edges.

2. SMAA (SMAAPass)

SMAA is a multi-pass morphological approach that analyzes structural patterns (such as lines, corners, and diagonal shapes) rather than relying solely on directional gradients.

  • Pass 1: Edge Detection: SMAA detects color or luminance discontinuities using a perceptual metric with local contrast adaptation. It evaluates differences between adjacent pixels and marks edge locations in an edge-render target.
  • Pass 2: Pattern Recognition and Weight Calculation: Instead of simple gradient sampling, SMAA classifies the morphological nature of edges (e.g., L-junctions, U-shapes, Z-shapes). It measures edge lengths using an iterative search and calculates the exact trapezoidal or triangular area coverage of pixels intersecting the edge. To perform this integration in real time, SMAA uses two precomputed lookup textures:
    • AreaTex: Encodes precomputed analytical coverage areas based on edge length and distance to the edge.
    • SearchTex: Accelerates the detection of horizontal and vertical line endpoints without requiring deep shader branching loops.
  • Pass 3: Neighborhood Blending: SMAA uses the blending weights computed in Pass 2 to blend neighbor colors via bilinear fetches, resulting in sharp, geometrically accurate edge reconstruction without blurring internal texture details.

Performance and Resource Differences

  • Pass Count and Draw Calls: FXAAPass executes in a single fullscreen draw call. In contrast, SMAAPass requires three sequential passes (Edge Detection, Blending Weight Calculation, and Neighborhood Blending), tripling the draw call overhead for the anti-aliasing stage.
  • Memory Bandwidth and VRAM: FXAA requires no auxiliary textures and minimal intermediate memory. SMAA allocates extra render targets for intermediate edge and weight buffers, and requires two static lookup textures (AreaTex and SearchTex) loaded into GPU memory. This significantly increases memory bandwidth demands.
  • GPU Execution Time: FXAA has very low ALU and texture-fetch requirements, making it ideal for mobile devices, integrated GPUs, or scenes with heavy compute budgets elsewhere. SMAA incurs significantly higher ALU workloads and texture samples per pixel.
  • Visual Fidelity vs. Cost: FXAA provides a fast, approximate smoothing pass that can cause noticeable loss of sharpness on textured surfaces. SMAA preserves sharp silhouettes, properly handles diagonal lines, and avoids texture blurring, making it visually superior for desktop environments where the GPU budget allows for multiple render passes.
