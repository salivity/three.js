How to Use iridescenceThicknessMap in Three.js

This guide explains how to implement and configure the iridescenceThicknessMap property on a MeshPhysicalMaterial in Three.js. By mapping a texture to control thin-film interference thickness across different coordinates, you can produce shifting, multi-colored rainbow patterns across a 3D model. The sections below outline the essential material properties, demonstrate a complete configuration with code, and highlight critical setup details for optimal rendering.

Core Properties for Iridescence

The iridescence effect simulates thin-film optical interference, similar to soap bubbles or oil slicks. In Three.js, it is available exclusively on MeshPhysicalMaterial through the following parameters:

  • iridescence: A float ranging from 0.0 to 1.0 that controls the overall intensity of the effect. Set this to 1.0 for full visibility.
  • iridescenceIOR: The index of refraction of the thin film layer, typically set between 1.2 and 1.6 for realistic interference.
  • iridescenceThicknessRange: A two-element array [min, max] defining the minimum and maximum thickness of the film in nanometers (nm). A standard visible spectrum range is [100, 800].
  • iridescenceThicknessMap: A texture where pixel values interpolate between the minimum and maximum values defined in iridescenceThicknessRange.

How the Map Controls Color Variation

Three.js samples the green channel of the iridescenceThicknessMap to determine the local film thickness:

  • A green channel value of 0.0 (black) corresponds to iridescenceThicknessRange[0].
  • A green channel value of 1.0 (white) corresponds to iridescenceThicknessRange[1].

Because different wavelengths of light reflect and cancel out at different film thicknesses, varying this value across a surface creates a spectrum of colors. Smooth gradients in your texture result in flowing rainbow transitions, while high-frequency noise textures produce localized, shimmering effects.

Implementation Example

Below is a complete script demonstrating how to load a thickness map, configure the material properties, and assign it to a mesh:

import * as THREE from 'three';

// 1. Initialize texture loader and load the thickness map
const textureLoader = new THREE.TextureLoader();
const thicknessTexture = textureLoader.load('path/to/thickness_map.png');

// Ensure correct wrapping if your UV coordinates require tiling
thicknessTexture.wrapS = THREE.RepeatWrapping;
thicknessTexture.wrapT = THREE.RepeatWrapping;

// 2. Configure the MeshPhysicalMaterial
const material = new THREE.MeshPhysicalMaterial({
    color: 0x222222,
    roughness: 0.1,
    metalness: 0.1,
    clearcoat: 1.0,
    clearcoatRoughness: 0.1,
    
    // Enable and tune iridescence
    iridescence: 1.0,
    iridescenceIOR: 1.33,
    iridescenceThicknessRange: [100, 800], // in nanometers
    iridescenceThicknessMap: thicknessTexture
});

// 3. Create the mesh
const geometry = new THREE.SphereGeometry(1, 64, 64);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Essential Rendering Considerations

  1. Environment Lighting: Iridescence relies heavily on specular reflection. Without an environment map (scene.environment using an HDR texture or PMREMGenerator), the thin-film interference will appear flat or entirely dark.
  2. Surface Roughness: Keep roughness low (between 0.0 and 0.25). Higher roughness scatters the surface reflections and diminishes the sharpness of the rainbow pattern.
  3. Thickness Range Tuning: If the colors appear too uniform, expand the iridescenceThicknessRange spread (for example, change [300, 500] to [100, 900]). If the color shifts are too rapid and cause banding, narrow the range.
