Interpolate Particle Size Over Lifetime in Three.js

In Three.js, animating the size of individual particles over their lifetime cannot be achieved using the standard PointsMaterial.size property, because that property is a single uniform that affects every point simultaneously. To smoothly interpolate size per particle, you must use a custom ShaderMaterial or modify a built-in material via onBeforeCompile. This article explains how to pass per-particle birth and duration data using BufferAttributes and smoothly scale particle sizes on the GPU using a vertex shader.

Why PointsMaterial Is Limited

The built-in PointsMaterial uses a single size uniform across all vertices in a geometry. While you can update vertex positions individually via a BufferAttribute, size variation over time per particle requires custom vertex logic. Handling this interpolation on the CPU by continuously modifying an array of sizes can drastically lower performance. Offloading the lifecycle and size calculation directly to the vertex shader is the most efficient approach.

Step 1: Set Up Geometry Attributes

To compute a particle’s age on the GPU, provide each vertex with an initial spawn time, a total lifetime duration, and a target scale.

Create a BufferGeometry and populate it with custom attributes alongside the standard position:

import * as THREE from 'three';

const particleCount = 5000;
const geometry = new THREE.BufferGeometry();

const positions = new Float32Array(particleCount * 3);
const startTimes = new Float32Array(particleCount);
const lifetimes = new Float32Array(particleCount);
const baseSizes = new Float32Array(particleCount);

for (let i = 0; i < particleCount; i++) {
  // Random positions
  positions[i * 3] = (Math.random() - 0.5) * 20;
  positions[i * 3 + 1] = (Math.random() - 0.5) * 20;
  positions[i * 3 + 2] = (Math.random() - 0.5) * 20;

  // Stagger start times so particles don't all appear at once
  startTimes[i] = Math.random() * 5.0; 
  lifetimes[i] = 2.0 + Math.random() * 3.0; // Lives between 2 to 5 seconds
  baseSizes[i] = 10.0 + Math.random() * 20.0; // Base size in pixels
}

geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
geometry.setAttribute('aStartTime', new THREE.BufferAttribute(startTimes, 1));
geometry.setAttribute('aLifetime', new THREE.BufferAttribute(lifetimes, 1));
geometry.setAttribute('aBaseSize', new THREE.BufferAttribute(baseSizes, 1));

Step 2: Create the ShaderMaterial

The vertex shader calculates normalized life (\(t \in [0.0, 1.0]\)) using an uTime uniform. You can then apply an interpolation curve—such as a sine wave or a smoothstep curve—so the particle scales up from zero after spawn and shrinks back to zero before dying.

const particleMaterial = new THREE.ShaderMaterial({
  uniforms: {
    uTime: { value: 0.0 }
  },
  vertexShader: `
    uniform float uTime;
    
    attribute float aStartTime;
    attribute float aLifetime;
    attribute float aBaseSize;

    varying float vAlpha;

    void main() {
      // Calculate particle progress (0.0 to 1.0)
      float age = mod(uTime - aStartTime, aLifetime);
      float progress = age / aLifetime;

      // Smoothly scale: 0.0 -> 1.0 -> 0.0 using a sine curve
      float sizeFactor = sin(progress * 3.14159265);

      // Interpolate point size with perspective attenuation
      vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
      gl_PointSize = aBaseSize * sizeFactor * (300.0 / -mvPosition.z);
      gl_Position = projectionMatrix * mvPosition;

      // Pass fade alpha to fragment shader
      vAlpha = sizeFactor;
    }
  `,
  fragmentShader: `
    varying float vAlpha;

    void main() {
      // Make points circular instead of square
      float dist = length(gl_PointCoord - vec2(0.5));
      if (dist > 0.5) discard;

      gl_FragColor = vec4(1.0, 1.0, 1.0, vAlpha);
    }
  `,
  transparent: true,
  depthWrite: false,
  blending: THREE.AdditiveBlending
});

const points = new THREE.Points(geometry, particleMaterial);
scene.add(points);

Step 3: Update the Uniform in the Render Loop

Increment the uTime uniform on every frame using a THREE.Clock to drive the animation:

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const elapsedTime = clock.getElapsedTime();
  particleMaterial.uniforms.uTime.value = elapsedTime;

  renderer.render(scene, camera);
}

animate();

Customizing the Interpolation Curve

The mathematical function applied to progress in the vertex shader determines the shape of the growth:

  • Linear Grow and Shrink: 1.0 - abs(progress * 2.0 - 1.0)
  • Fast Pop and Slow Shrink: sin(sqrt(progress) * 3.14159265)
  • Custom Easing: Two smoothstep calls, such as smoothstep(0.0, 0.2, progress) * (1.0 - smoothstep(0.8, 1.0, progress)) for quick fade-in and sustained maximum size before fading out.
