Three.js PointLight Physically Accurate Decay

This article explains how to configure a PointLight in Three.js to emulate real-world light attenuation using the physical inverse-square law. You will learn the exact properties to adjust on both the PointLight and the WebGLRenderer, how the decay and distance values interact, and how to verify that your scene adheres to physically accurate lighting calculations.

Setting the Decay Property

To follow the physically accurate inverse-square law, set the decay property of the PointLight to 2.

In physics, the intensity of light radiating from a point source decreases inversely with the square of the distance from the source (\(I \propto 1/r^2\)). In Three.js, setting decay to 2 implements this exact quadratic attenuation curve.

const pointLight = new THREE.PointLight(0xffffff, 100);
pointLight.decay = 2;

Configuring the Distance Property

The distance property works alongside decay to define the cutoff point for light calculations:

  • Infinite Range (distance = 0): Setting distance = 0 allows the inverse-square falloff to continue indefinitely without an artificial cutoff. The light simply fades toward zero as distance increases. This is the most physically accurate configuration.
  • Capped Range (distance > 0): Setting a positive value defines a radius where the light's intensity smoothly drops to zero. While mathematically an approximation, this improves rendering performance by allowing Three.js to cull objects beyond the light's effective reach.
// Physically accurate with infinite reach
pointLight.distance = 0;

// Physically accurate curve with a cutoff radius of 50 units for performance
pointLight.distance = 50;

Renderer Configuration

In recent versions of Three.js (r155 and later), physically correct lighting is enabled by default. If you are using an older version of Three.js, you must ensure your WebGLRenderer is not using legacy lighting modes:

  • r150 to r154: Set renderer.useLegacyLights = false;
  • Prior to r150: Set renderer.physicallyCorrectLights = true;

When physical lighting is active, standard PointLight.intensity values will appear much dimmer because the light energy dissipates quadratically. You will need to increase the light's intensity significantly (measured in candela or lumens depending on your color management and unit scale) to properly illuminate your scene.
