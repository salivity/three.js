Calculate Face Area in Three.js with Triangle.getArea

This guide explains how to compute the surface area of a single mesh face in Three.js by extracting vertex coordinates from BufferGeometry and passing them into the THREE.Triangle.getArea method. Whether working with indexed or non-indexed geometries, you will learn the exact steps to retrieve vertex positions and calculate precise polygonal surface measurements.

Understanding the Process

In Three.js, 3D meshes are composed of triangular faces stored inside a BufferGeometry. The positions of the vertices forming these triangles are held within the position attribute. To compute the area of any specific face using Triangle.getArea(), you must identify the three vertex indices that make up the triangle, extract their 3D coordinates into THREE.Vector3 instances, and pass those vectors to a THREE.Triangle object.

Step-by-Step Implementation

  1. Access the Geometry Attributes: Retrieve the position attribute and, if present, the index attribute of the mesh's BufferGeometry.
  2. Resolve Vertex Indices:
    • For indexed geometry, each face consists of three sequential entries in the index buffer (i.e., faceIndex * 3, faceIndex * 3 + 1, and faceIndex * 3 + 2).
    • For non-indexed geometry, vertices directly correspond to the order in the position buffer (using the same offsets).
  3. Populate Vector3 Objects: Read the coordinates of the three vertices using Vector3.fromBufferAttribute().
  4. Instantiate the Triangle and Compute Area: Create a THREE.Triangle using the extracted vectors and call .getArea().

Code Example

Below is a reusable function that handles both indexed and non-indexed geometries to return the area of a specified face index:

import * as THREE from 'three';

function getFaceArea(mesh, faceIndex) {
  const geometry = mesh.geometry;
  const positionAttribute = geometry.attributes.position;
  const indexAttribute = geometry.index;

  let aIndex, bIndex, cIndex;

  if (indexAttribute) {
    // Indexed geometry: read vertex indices from the index buffer
    aIndex = indexAttribute.getX(faceIndex * 3);
    bIndex = indexAttribute.getX(faceIndex * 3 + 1);
    cIndex = indexAttribute.getX(faceIndex * 3 + 2);
  } else {
    // Non-indexed geometry: indices are consecutive in the position buffer
    aIndex = faceIndex * 3;
    bIndex = faceIndex * 3 + 1;
    cIndex = faceIndex * 3 + 2;
  }

  // Create Vector3 instances to hold the coordinates
  const vA = new THREE.Vector3().fromBufferAttribute(positionAttribute, aIndex);
  const vB = new THREE.Vector3().fromBufferAttribute(positionAttribute, bIndex);
  const vC = new THREE.Vector3().fromBufferAttribute(positionAttribute, cIndex);

  // Apply world transformation if scaling or rotation affects the physical size
  vA.applyMatrix4(mesh.matrixWorld);
  vB.applyMatrix4(mesh.matrixWorld);
  vC.applyMatrix4(mesh.matrixWorld);

  // Initialize the Triangle and compute the area
  const triangle = new THREE.Triangle(vA, vB, vC);
  return triangle.getArea();
}

Important Considerations

  • World Transformations: Applying mesh.matrixWorld to the vertices accounts for any scale or rotation transformations applied to the parent object. If you only require the local geometry size, omit the applyMatrix4 calls.
  • Performance: If calculating the surface area across thousands of faces in a loop, avoid instantiating new THREE.Vector3 and THREE.Triangle objects on every iteration. Allocate three vectors and one triangle once, then reuse them using .setFromAttributeAndIndices() or .set() to minimize garbage collection overhead.
