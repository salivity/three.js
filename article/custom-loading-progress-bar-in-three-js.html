Custom Loading Progress Bar in Three.js

This article explains how to create a custom loading progress bar in Three.js by utilizing the global THREE.DefaultLoadingManager. You will learn how to intercept asset loading events across loaders, calculate the loading percentage, update the user interface dynamically, and hide the loading screen once all assets are fully loaded.

Understanding DefaultLoadingManager

Three.js provides THREE.DefaultLoadingManager out of the box. Unless an explicit instance of THREE.LoadingManager is passed into a loader (such as GLTFLoader, TextureLoader, or OBJLoader), all loaders default to using this global manager.

By setting its onProgress callback, you can monitor the loading status of all assets in your scene without having to configure each loader individually.

1. Setting Up HTML and CSS

Create a basic overlay with a progress bar container and an inner element that scales to represent progress.

<div id="loading-screen">
  <div id="progress-container">
    <div id="progress-bar"></div>
  </div>
  <span id="progress-text">0%</span>
</div>
#loading-screen {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background-color: #1a1a1a;
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  z-index: 9999;
  transition: opacity 0.5s ease;
}

#progress-container {
  width: 300px;
  height: 10px;
  background-color: #333;
  border-radius: 5px;
  overflow: hidden;
}

#progress-bar {
  width: 0%;
  height: 100%;
  background-color: #00ff88;
  transition: width 0.1s ease;
}

#progress-text {
  margin-top: 10px;
  color: #ffffff;
  font-family: sans-serif;
  font-size: 14px;
}

2. Attaching the onProgress Callback

The onProgress callback receives three arguments:

  • url: The URL of the asset currently being loaded.
  • itemsLoaded: The number of items loaded so far.
  • itemsTotal: The total number of items to be loaded.

Configure the DefaultLoadingManager before initiating any loading processes:

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loadingScreen = document.getElementById('loading-screen');
const progressBar = document.getElementById('progress-bar');
const progressText = document.getElementById('progress-text');

// Track loading progress
THREE.DefaultLoadingManager.onProgress = function (url, itemsLoaded, itemsTotal) {
  const progressRatio = itemsLoaded / itemsTotal;
  const percentage = Math.round(progressRatio * 100);

  progressBar.style.width = `${percentage}%`;
  progressText.innerText = `${percentage}%`;
};

// Handle completion
THREE.DefaultLoadingManager.onLoad = function () {
  loadingScreen.style.opacity = '0';
  
  // Remove element after transition completes
  setTimeout(() => {
    loadingScreen.style.display = 'none';
  }, 500);
};

// Handle errors
THREE.DefaultLoadingManager.onError = function (url) {
  console.error(`There was an error loading: ${url}`);
};

3. Loading Assets

Load your models or textures as usual. Because the default manager is configured globally, you do not need to pass a loading manager into the loader instances:

const textureLoader = new THREE.TextureLoader();
const gltfLoader = new GLTFLoader();

// These calls automatically register with THREE.DefaultLoadingManager
textureLoader.load('textures/diffuse.jpg');
textureLoader.load('textures/normal.jpg');
gltfLoader.load('models/character.glb', (gltf) => {
  scene.add(gltf.scene);
});

When each file starts and finishes loading, DefaultLoadingManager.onProgress recalculates the ratio, adjusting the width of the #progress-bar until DefaultLoadingManager.onLoad fires, fading out the screen.
