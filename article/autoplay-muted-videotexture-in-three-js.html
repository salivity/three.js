Autoplay Muted VideoTexture in Three.js

Modern web browsers enforce strict autoplay policies that block media elements from playing automatically if they produce audio and lack prior user interaction. To use a VideoTexture seamlessly in Three.js without requiring a click event, you must directly configure the underlying HTML5 video element to be muted and inline-ready before binding it to the texture.

Why Browser Autoplay Policies Matter

Browsers like Chrome, Safari, and Firefox disallow unmuted audio/video playback to prevent unwanted noise and data consumption. If an unmuted video is set to play automatically via code, the browser will reject the play request, leaving your Three.js VideoTexture blank or frozen on the first frame. By setting the video element's muted property to true, the browser categorizes the media as non-intrusive and permits automatic playback.

Step-by-Step Implementation

To configure the VideoTexture properly, instantiate an HTML <video> element in JavaScript (or retrieve one from the DOM), apply the required autoplay-friendly attributes, and pass it to Three.js.

import * as THREE from 'three';

// 1. Create the HTML5 video element
const video = document.createElement('video');
video.src = 'path/to/your-video.mp4';
video.crossOrigin = 'anonymous';

// 2. Configure properties to satisfy autoplay policies
video.muted = true;          // Essential: Muting allows automatic playback
video.autoplay = true;       // Requests immediate playback
video.loop = true;           // Loops the video continuously
video.playsInline = true;    // Crucial for iOS/mobile to prevent full-screen playback

// 3. Initiate playback and handle promises
video.play().catch((error) => {
  console.error('Video autoplay was prevented:', error);
});

// 4. Create the Three.js VideoTexture
const videoTexture = new THREE.VideoTexture(video);
videoTexture.colorSpace = THREE.SRGBColorSpace;
videoTexture.minFilter = THREE.LinearFilter;
videoTexture.magFilter = THREE.LinearFilter;

// 5. Apply the texture to a material and mesh
const material = new THREE.MeshBasicMaterial({ map: videoTexture });
const geometry = new THREE.PlaneGeometry(16, 9);
const screenMesh = new THREE.Mesh(geometry, material);
scene.add(screenMesh);

Essential Attributes Breakdown

  • video.muted = true: This is the primary requirement for autoplay. Setting this programmatically bypasses the browser's audio engagement checks.
  • video.playsInline = true: Essential for mobile devices, particularly iOS Safari. Without playsinline, mobile browsers may force the video to open in the native full-screen media player instead of rendering onto your 3D geometry.
  • video.crossOrigin = 'anonymous': Required if your video is hosted on a different domain, CDN, or origin to avoid WebGL security (CORS) exceptions.
  • video.play().catch(...): Modern implementations of .play() return a Promise. Catching potential errors allows graceful fallback handling if the browser blocks playback for unexpected reasons.
