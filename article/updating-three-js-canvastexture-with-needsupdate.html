Updating Three.js CanvasTexture with needsUpdate

This article explains how to refresh a dynamic CanvasTexture in Three.js when changes are made to an underlying HTML5 2D canvas. By default, Three.js uploads texture data to the GPU once to optimize rendering performance. When you modify the canvas using the 2D rendering context, you must explicitly flag the texture with needsUpdate = true so the WebGL renderer uploads the newly drawn pixels to the GPU.

The Problem with Dynamic Canvas Textures

When you instantiate a THREE.CanvasTexture, Three.js transfers the initial image data from the CPU (the <canvas> element) to a WebGL texture buffer on the GPU. To maintain high frame rates, Three.js assumes textures are static unless instructed otherwise. Consequently, standard 2D canvas drawing methods—such as fillRect(), fillText(), or drawImage()—will alter the DOM canvas, but the changes will not appear on the 3D model automatically.

The Solution: Setting needsUpdate = true

To synchronize the canvas changes with the GPU, set the texture's needsUpdate property to true immediately after finishing your 2D draw operations.

Here is a complete implementation showing how to create, modify, and update a CanvasTexture:

import * as THREE from 'three';

// 1. Create the offscreen or DOM canvas
const canvas = document.createElement('canvas');
canvas.width = 512;
canvas.height = 512;
const ctx = canvas.getContext('2d');

// Initial draw
ctx.fillStyle = '#ffffff';
ctx.fillRect(0, 0, canvas.width, canvas.height);

// 2. Create the CanvasTexture and assign it to a material
const texture = new THREE.CanvasTexture(canvas);
const material = new THREE.MeshBasicMaterial({ map: texture });
const mesh = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), material);

// 3. Define a function to redraw the canvas and trigger the GPU upload
function updateCanvasTexture(text) {
  // Redraw onto the 2D context
  ctx.fillStyle = '#ff0000';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  ctx.fillStyle = '#ffffff';
  ctx.font = '48px sans-serif';
  ctx.fillText(text, 50, 100);

  // Instruct Three.js to upload the new canvas pixels to the GPU
  texture.needsUpdate = true;
}

// Example usage
updateCanvasTexture('Updated Text');

How It Works Internally

When the render loop executes (renderer.render(scene, camera)), Three.js inspects all active textures. If texture.needsUpdate evaluates to true, the renderer invokes WebGL's gl.texSubImage2D() or gl.texImage2D(). This operation re-reads the canvas pixel data and overwrites the existing GPU texture memory. Once the transfer is complete, Three.js automatically resets needsUpdate back to false until you set it again for subsequent updates.

Best Practices for Performance

  • Update Only When Necessary: Transferring pixel data across the CPU-to-GPU bridge is computationally expensive. Avoid setting needsUpdate = true inside a continuous animation loop unless the canvas content has actually changed that frame.
  • Canvas Sizing: Keep canvas dimensions to powers of two (e.g., 256x256, 512x512) to ensure broad compatibility and optimize GPU memory layout.
  • Batch Drawing: Complete all 2D context modifications first, and then set needsUpdate = true once at the very end of your drawing sequence.
