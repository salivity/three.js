Three.js DataArrayTexture: Setting Size and Layer Count

In Three.js, a DataArrayTexture represents a 2D texture array (a single GPU texture object containing multiple layers of identical dimensions). This article explains how to explicitly define the dimensions and layer count of a DataArrayTexture, configure the backing typed array buffer, and instantiate the texture correctly for use in custom shaders.

Constructor Syntax and Dimension Parameters

The THREE.DataArrayTexture constructor accepts four primary parameters that explicitly define its dimensions and layer count:

new THREE.DataArrayTexture( data, width, height, depth )
  • data: A typed array (such as Uint8Array or Float32Array) containing the raw pixel data for all layers packed contiguously.
  • width: The horizontal pixel resolution of each individual layer.
  • height: The vertical pixel resolution of each individual layer.
  • depth: The total number of layers (layer count) contained in the array.

Calculating the Buffer Size

The backing data buffer must be sized to accommodate all layers. The total number of elements required in the typed array is calculated as:

\[\text{Total Elements} = \text{width} \times \text{height} \times \text{depth} \times \text{channels}\]

For a standard 8-bit RGBA texture, the channel count is 4, meaning each pixel across every layer requires 4 bytes.

Complete Implementation Example

The following example initializes a 2D texture array with an explicit width of 256, height of 256, and a layer count of 8:

import * as THREE from 'three';

// 1. Explicitly define size and layer count
const width = 256;
const height = 256;
const depth = 8; // Layer count
const channels = 4; // RGBA

// 2. Allocate the typed array buffer
const size = width * height * depth * channels;
const data = new Uint8Array(size);

// 3. Populate each layer with pixel data
for (let layer = 0; layer < depth; layer++) {
  const layerOffset = layer * width * height * channels;
  
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const pixelOffset = layerOffset + (y * width + x) * channels;
      
      // Example: Fill each layer with a distinct color gradient
      data[pixelOffset + 0] = (x / width) * 255;        // Red
      data[pixelOffset + 1] = (y / height) * 255;       // Green
      data[pixelOffset + 2] = (layer / depth) * 255;     // Blue
      data[pixelOffset + 3] = 255;                      // Alpha
    }
  }
}

// 4. Instantiate the DataArrayTexture
const textureArray = new THREE.DataArrayTexture(data, width, height, depth);

// 5. Configure texture properties
textureArray.format = THREE.RGBAFormat;
textureArray.type = THREE.UnsignedByteType;
textureArray.minFilter = THREE.LinearFilter;
textureArray.magFilter = THREE.LinearFilter;
textureArray.wrapS = THREE.ClampToEdgeWrapping;
textureArray.wrapT = THREE.ClampToEdgeWrapping;
textureArray.needsUpdate = true;

Shader Access

In WebGL 2, this texture is bound to a sampler2DArray uniform. Slices are addressed using a 3D coordinate vector (vec3), where the third component specifies the zero-based layer index:

precision highp float;
precision highp sampler2DArray;

uniform sampler2DArray uTextureArray;
varying vec2 vUv;

void main() {
    float layerIndex = 2.0; // Access the third layer
    vec4 texColor = texture(uTextureArray, vec3(vUv, layerIndex));
    gl_FragColor = texColor;
}
