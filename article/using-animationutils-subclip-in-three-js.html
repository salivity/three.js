Using AnimationUtils.subclip in Three.js

This guide explains how to extract specific segments from an existing AnimationClip in Three.js using the AnimationUtils.subclip method. You will learn the method's parameter requirements, how frame-to-time conversions work, and how to implement the resulting subclip within an AnimationMixer workflow.

Understanding AnimationUtils.subclip

In Three.js, complex models often come with multiple animations combined into a single timeline (such as an idle, walk, and run sequence packed into one continuous track). The THREE.AnimationUtils.subclip method allows you to cut this single clip into smaller, targeted clips without modifying the original asset file.

Method Syntax and Parameters

The method accepts five arguments:

THREE.AnimationUtils.subclip( sourceClip, name, startFrame, endFrame, fps );
  • sourceClip (THREE.AnimationClip): The original animation clip you want to slice.
  • name (String): The unique identifier name assigned to the newly created subclip.
  • startFrame (Number): The frame index where the new clip begins.
  • endFrame (Number): The frame index where the new clip ends.
  • fps (Number, optional): The frame rate used to calculate the timeline. The default value is 30.

The method calculates the actual time boundaries by dividing the frame numbers by the specified fps value (startTime = startFrame / fps and endTime = endFrame / fps).

Step-by-Step Implementation

  1. Load or obtain your source clip: Retrieve the main AnimationClip from your loaded 3D asset (such as a GLTF model).
  2. Define frame ranges: Identify the start and end frame numbers for the specific action you wish to extract.
  3. Generate the subclip: Call THREE.AnimationUtils.subclip.
  4. Play via AnimationMixer: Pass the new clip to an AnimationMixer instance to play it.

Code Example

import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

loader.load('character.glb', (gltf) => {
    const model = gltf.scene;
    const fullClip = gltf.animations[0]; // The combined timeline clip
    const fps = 30;

    // Extract a "Walk" animation spanning frames 0 to 30
    const walkClip = THREE.AnimationUtils.subclip(fullClip, 'Walk', 0, 30, fps);

    // Extract a "Run" animation spanning frames 31 to 60
    const runClip = THREE.AnimationUtils.subclip(fullClip, 'Run', 31, 60, fps);

    // Set up the AnimationMixer
    const mixer = new THREE.AnimationMixer(model);

    // Play the extracted walk clip
    const walkAction = mixer.clipAction(walkClip);
    walkAction.setLoop(THREE.LoopRepeat);
    walkAction.play();
});

Important Considerations

  • Keyframe Interpolation: subclip copies keyframe data falling within the time window. If a keyframe does not land precisely on the start or end frame, Three.js interpolates the track values to ensure smooth looping.
  • FPS Consistency: Ensure the fps parameter matches the frame rate used when the animation was authored in your 3D software (e.g., Blender or Maya) to avoid mismatched clip start and end points.
