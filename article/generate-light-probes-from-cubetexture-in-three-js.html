Generate Light Probes from CubeTexture in Three.js

Generating light probes from an existing CubeTexture allows you to achieve realistic, indirect diffuse lighting in Three.js without the performance cost of real-time environment sampling. By utilizing the LightProbeGenerator addon, you can extract 3D spherical harmonics data directly from a cube map and apply it to a LightProbe object. This guide demonstrates how to import the generator, process a loaded CubeTexture, and incorporate the resulting light probe into your scene.

Understanding Light Probes and Spherical Harmonics

A LightProbe in Three.js approximates 3D irradiance using Spherical Harmonics (SH). Unlike an ambient light that illuminates evenly from all directions, a light probe calculates color and intensity variations based on direction. This mimics how a surrounding environment casts ambient light onto 3D objects, delivering realistic diffuse shading with minimal GPU overhead.

While a LightProbe provides diffuse irradiance, it does not handle specular reflections; pairing a light probe with an environment map on your materials produces a complete physical lighting model.

Importing LightProbeGenerator

LightProbeGenerator is an official Three.js add-on located in the examples directory. Import both the generator and the core Three.js components using standard ES modules:

import * as THREE from 'three';
import { LightProbeGenerator } from 'three/addons/lights/LightProbeGenerator.js';

Generating the Light Probe

To generate the probe, the CubeTexture must be fully loaded so that its pixel data is accessible to the generator. Use THREE.CubeTextureLoader to load your environment textures, then pass the completed texture to LightProbeGenerator.fromCubeTexture().

// 1. Initialize the scene and loader
const scene = new THREE.Scene();
const cubeTextureLoader = new THREE.CubeTextureLoader();

// 2. Load the cube map textures
const urls = [
    'px.png', 'nx.png',
    'py.png', 'ny.png',
    'pz.png', 'nz.png'
];

cubeTextureLoader.load(urls, (cubeTexture) => {
    // Set the cube texture as the background or environment if needed
    scene.background = cubeTexture;

    // 3. Generate the LightProbe from the CubeTexture
    const lightProbe = LightProbeGenerator.fromCubeTexture(cubeTexture);
    
    // 4. Adjust the probe's intensity
    lightProbe.intensity = 1.0;

    // 5. Add the probe to your scene
    scene.add(lightProbe);
});

How It Works

  1. Pixel Processing: LightProbeGenerator.fromCubeTexture() reads the pixel data from all six faces of the CubeTexture.
  2. Spherical Harmonics Calculation: The generator projects the colors into 9 spherical harmonic coefficients (order 3), which encode the directional diffuse color of the environment.
  3. Probe Creation: It returns a THREE.LightProbe pre-populated with these coefficients (lightProbe.sh).
  4. Shader Integration: Standard materials such as MeshStandardMaterial and MeshPhysicalMaterial detect the LightProbe automatically and incorporate its spherical harmonics into their diffuse rendering calculations.

Updating or Changing the Probe

If you switch environment maps at runtime, you can recalculate the coefficients and copy them over to an existing probe without instantiating a new object:

cubeTextureLoader.load(newUrls, (newCubeTexture) => {
    const tempProbe = LightProbeGenerator.fromCubeTexture(newCubeTexture);
    lightProbe.copy(tempProbe);
});

Using LightProbeGenerator ensures that your scene receives coherent ambient lighting directly matching your skybox or environment map while keeping rendering performance optimal.
