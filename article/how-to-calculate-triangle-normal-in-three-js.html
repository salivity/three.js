How to Calculate Triangle Normal in Three.js

In Three.js, determining the geometric normal of a triangular face is essential for custom lighting calculations, physics interactions, and mesh manipulation. This guide explains how to define a triangle using 3D vector coordinates and utilize the built-in Triangle.getNormal() method to compute its normalized perpendicular vector accurately and efficiently.

Understanding the Geometric Normal

A geometric normal is a unit vector that points directly perpendicular to the flat surface of a triangle. Three.js uses a right-handed coordinate system and follows the counter-clockwise winding rule by default. This means that the order in which you define vertices (A, B, C) determines whether the normal points forward or backward relative to your viewpoint.

The normal is mathematically computed using the cross product of two edges formed by the triangle's vertices:

\[\vec{N} = \frac{(\vec{B} - \vec{A}) \times (\vec{C} - \vec{A})}{\|(\vec{B} - \vec{A}) \times (\vec{C} - \vec{A})\|}\]

Three.js abstracts this calculation entirely through the getNormal method of the THREE.Triangle class.

Implementing Triangle.getNormal()

The getNormal() method requires a target THREE.Vector3 object passed as an argument. The calculated normal values are written directly into this target vector, preventing unnecessary garbage collection caused by creating new objects.

Code Example

import * as THREE from 'three';

// 1. Define the three vertices of the triangle
const vertexA = new THREE.Vector3(0, 0, 0);
const vertexB = new THREE.Vector3(1, 0, 0);
const vertexC = new THREE.Vector3(0, 1, 0);

// 2. Instantiate the Triangle using the three vertices
const triangle = new THREE.Triangle(vertexA, vertexB, vertexC);

// 3. Create a target vector to store the result
const targetNormal = new THREE.Vector3();

// 4. Calculate the normal
triangle.getNormal(targetNormal);

// Output the normalized result
console.log(targetNormal); 
// Output: THREE.Vector3 { x: 0, y: 0, z: 1 }

Extracting Normals Directly from a BufferGeometry

If you are working with an existing BufferGeometry, you can extract face normals using Triangle.getNormal() by querying the geometry’s position attribute.

import * as THREE from 'three';

function computeFaceNormal(geometry, faceIndex) {
  const positionAttribute = geometry.attributes.position;
  
  const vA = new THREE.Vector3();
  const vB = new THREE.Vector3();
  const vC = new THREE.Vector3();

  // Assuming non-indexed geometry where each face consists of 3 sequential vertices
  const i = faceIndex * 3;
  vA.fromBufferAttribute(positionAttribute, i);
  vB.fromBufferAttribute(positionAttribute, i + 1);
  vC.fromBufferAttribute(positionAttribute, i + 2);

  const triangle = new THREE.Triangle(vA, vB, vC);
  const normal = new THREE.Vector3();
  
  return triangle.getNormal(normal);
}

Key Considerations

  • Vertex Winding: Defining vertices in clockwise order inverts the direction of the normal vector. Ensure your vertices are arranged counter-clockwise relative to the intended outer surface.
  • Degenerate Triangles: If all three vertices are collinear or share identical positions, the triangle has an area of zero. In this scenario, getNormal() cannot compute a valid cross product and will return a vector of (0, 0, 0).
  • Memory Management: When computing normals repeatedly inside an animation or render loop, define the targetNormal vector once outside the loop and reuse it to maintain optimal performance.
