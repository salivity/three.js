Blend Two Textures Using mixNode in Three.js

This guide explains how to blend two distinct textures seamlessly using the mix node (MixNode) in modern Three.js. With the introduction of the WebGPU-ready Node Material system (TSL - Three.js Shading Language), developers can construct custom shaders visually and programmatically using node graphs instead of writing raw GLSL strings. Below, you will learn the setup, node configuration, and implementation details required to interpolate two textures dynamically using color, noise, or UV-based masks.

Understanding the Node System Setup

In modern Three.js, node-based shaders are driven by imports from three/nodes (or three/tsl). The node equivalent of GLSL's mix() function is the mix() operator, which creates a MixNode. It performs linear interpolation between two input values based on a third factor:

\[\text{result} = A \times (1 - \text{factor}) + B \times \text{factor}\]

When working with textures, input \(A\) and input \(B\) are texture nodes, while the factor can be a static float, a dynamic uniform, a UV coordinate, or a third grayscale mask texture.

Step-by-Step Implementation

1. Import Dependencies

To use Node materials, import the core Three.js library alongside the specific node components:

import * as THREE from 'three';
import { 
  texture, 
  mix, 
  uv, 
  oscSine, 
  timerLocal,
  MeshStandardNodeMaterial 
} from 'three/nodes';

2. Load the Source Textures

Load your base images using the standard THREE.TextureLoader:

const textureLoader = new THREE.TextureLoader();

const map1 = textureLoader.load('path/to/texture1.jpg');
const map2 = textureLoader.load('path/to/texture2.jpg');

// Ensure correct color space for color maps
map1.colorSpace = THREE.SRGBColorSpace;
map2.colorSpace = THREE.SRGBColorSpace;

3. Define Texture Nodes and the Blend Factor

Wrap the loaded textures into node representations using the texture() helper. Then, define the interpolation factor:

// Convert standard textures into node-compatible textures
const nodeTexA = texture(map1);
const nodeTexB = texture(map2);

// Option A: A static or uniform float factor (0.0 displays texture A, 1.0 displays texture B)
const blendFactor = 0.5;

// Option B: An animated factor oscillating over time
// const blendFactor = oscSine(timerLocal(1));

// Option C: A horizontal gradient across the mesh using UV coordinates
// const blendFactor = uv().x;

4. Combine Textures with the mix Function

Pass the texture nodes and your blending factor into mix():

// mix() returns a MixNode that blends nodeTexA and nodeTexB
const blendedOutput = mix(nodeTexA, nodeTexB, blendFactor);

5. Assign to a Node Material

Assign the blended node graph directly to the colorNode property of a node-compatible material such as MeshStandardNodeMaterial or MeshBasicNodeMaterial:

const material = new MeshStandardNodeMaterial();
material.colorNode = blendedOutput;

const geometry = new THREE.PlaneGeometry(5, 5);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

Using a Mask Texture for Localized Blending

To create complex surface transitions (such as terrain blending, wear-and-tear, or splat mapping), you can supply a grayscale texture as the blend factor instead of a scalar value:

const maskTexture = textureLoader.load('path/to/mask.jpg');
const nodeMask = texture(maskTexture);

// Uses the red channel of the mask image to drive the mix
const maskedBlend = mix(nodeTexA, nodeTexB, nodeMask.r);

material.colorNode = maskedBlend;

When nodeMask.r is 0.0 (black), nodeTexA renders completely; when it is 1.0 (white), nodeTexB renders. Any intermediate grayscale value produces a smooth transition between both textures without writing custom shader code.
