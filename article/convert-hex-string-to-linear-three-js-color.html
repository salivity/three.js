Convert Hex String to Linear Three.js Color

Converting dynamically typed user hex input into a linear Three.js Color object requires validating the string format, parsing it into the Three.js color instance, and ensuring it is correctly converted from the sRGB color space to Linear-sRGB. This guide provides a straightforward implementation to safely handle real-time user input and convert it into an accurate, render-ready linear color.

1. Validate and Format the Input

User input is unpredictable, meaning the string may lack a leading hash symbol (#), use shorthand syntax (such as #fff), or contain invalid characters. Use a regular expression to validate the format and ensure a leading # is present before passing it to Three.js.

function sanitizeHex(input) {
  const trimmed = input.trim();
  const hexRegex = /^#?([0-9a-fA-F]{3}|[0-9a-fA-F]{6})$/;

  if (!hexRegex.test(trimmed)) {
    return null; // Invalid hex color
  }

  return trimmed.startsWith('#') ? trimmed : `#${trimmed}`;
}

2. Handle Color Spaces in Three.js

Modern Three.js versions (r152+) enable THREE.ColorManagement by default. Hex colors represent colors in the sRGB color space. When you pass an sRGB hex string into a THREE.Color object, Three.js automatically converts the color values into Linear-sRGB for physically correct rendering.

If you are using an older version of Three.js or need explicit control over the conversion, call .convertSRGBToLinear() directly on the color instance.

3. Convert the String to a Linear Color Object

Create a reusable THREE.Color instance and update it dynamically whenever the user updates the input field.

import * as THREE from 'three';

// Ensure color management is enabled (default in modern Three.js)
THREE.ColorManagement.enabled = true;

const targetColor = new THREE.Color();

function updateColorFromInput(userInput) {
  const validHex = sanitizeHex(userInput);

  if (!validHex) {
    console.warn('Invalid hex string provided.');
    return null;
  }

  // Set the color using the hex string.
  // Modern Three.js interprets CSS hex strings as sRGB and converts to Linear automatically.
  targetColor.set(validHex);

  // Fallback for older Three.js versions without ColorManagement enabled:
  // targetColor.set(validHex).convertSRGBToLinear();

  return targetColor;
}

4. Hooking Up Dynamic User Input

Attach an event listener to your text input element to update the color on the fly without breaking the scene if the user enters an incomplete code:

const inputElement = document.querySelector('#hex-input');

inputElement.addEventListener('input', (event) => {
  const linearColor = updateColorFromInput(event.target.value);

  if (linearColor) {
    // Apply the linear color to a material or light
    myMaterial.color.copy(linearColor);
  }
});

By validating the string first and allowing THREE.Color.set() to process the normalized CSS hex value, the resulting color object accurately reflects the user's desired shade in linear space.
