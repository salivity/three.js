How to Use IOR for Refraction in Three.js

This guide explains how to use the ior (Index of Refraction) property in Three.js to realistically distort background visuals through transparent surfaces. By combining MeshPhysicalMaterial, physical transmission, and an environment map or background scene, you can simulate optical physics like glass, water, and gems with accurate light-bending behavior.

1. Enable Physical Transmission

To make a surface distort the scene behind it, you must use THREE.MeshPhysicalMaterial instead of MeshStandardMaterial. Set transmission to near 1.0 and lower the roughness to keep the surface clear.

const material = new THREE.MeshPhysicalMaterial({
  transmission: 1.0,
  roughness: 0.05,
  metalness: 0.0,
  transparent: false // Set to false; transmission handles optical transparency
});

2. Configure the IOR Property

The ior property implements Snell’s Law to determine how sharply rays bend as they enter and exit the object. Standard values include:

  • Air: 1.0
  • Water: 1.333
  • Glass: 1.5
  • Diamond: 2.417

Apply your desired index directly to the material:

material.ior = 1.5; // Simulates standard crown glass

3. Set Material Thickness

Three.js uses the thickness property to calculate how far a refracted ray travels inside the mesh before exiting. Without thickness, the distortion will appear flat or non-existent because the renderer cannot determine the volume of the geometry.

material.thickness = 1.2; // Defines the volume's depth in world units

4. Provide a Visual Background to Distort

Three.js calculates refraction by rendering the scene behind the refractive mesh into an internal transmission render target. For the distortion to be visible, ensure there are objects behind the mesh or assign an environment map to the scene.

// Load an HDR environment map for realistic background refraction
new RGBELoader().load('environment.hdr', (texture) => {
  texture.mapping = THREE.EquirectangularReflectionMapping;
  scene.background = texture;
  scene.environment = texture;
});

5. Fine-Tune Dispersion and Chromatic Aberration

In modern versions of Three.js (r163+), you can enhance visual fidelity by enabling dispersion. This splits the refracted light into spectral colors based on the IOR, creating chromatic aberration around the edges of the distortion.

material.dispersion = 0.05; // Adds subtle rainbow fringing along refractions

Complete Implementation

import * as THREE from 'three';

const geometry = new THREE.SphereGeometry(2, 64, 64);

const physicalMaterial = new THREE.MeshPhysicalMaterial({
  roughness: 0.0,
  transmission: 1.0,
  thickness: 1.5,
  ior: 1.52,
  dispersion: 0.02
});

const sphere = new THREE.Mesh(geometry, physicalMaterial);
scene.add(sphere);

Ensure your renderer has tone mapping and appropriate color space settings enabled (renderer.outputColorSpace = THREE.SRGBColorSpace) to preserve contrast and realism in the refracted light.
