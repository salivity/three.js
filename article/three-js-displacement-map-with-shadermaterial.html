Three.js Displacement Map with ShaderMaterial

Applying a displacement map directly to a custom ShaderMaterial in Three.js involves passing a texture and a scale factor as uniform variables to your shaders. This article explains how to configure a custom vertex shader to sample the displacement texture, alter the geometry's vertex positions along their normal vectors, and assemble the complete material and mesh inside Three.js.

1. Understanding the Uniforms

To displace geometry in a custom shader, the vertex shader requires access to the displacement texture and an intensity scalar. You declare these within the uniforms object passed to the ShaderMaterial:

  • uDisplacementMap: A sampler2D uniform holding the loaded texture.
  • uDisplacementScale: A float uniform controlling the magnitude of the displacement.

2. Writing the Shaders

The actual displacement happens in the vertex shader by reading the color value of the texture at the current UV coordinates and shifting the vertex position along the normal vector.

Vertex Shader

uniform sampler2D uDisplacementMap;
uniform float uDisplacementScale;

varying vec2 vUv;
varying vec3 vNormal;

void main() {
    vUv = uv;
    vNormal = normal;

    // Sample the red channel of the displacement map
    float displacement = texture2D(uDisplacementMap, uv).r;

    // Displace the vertex position along its normal vector
    vec3 displacedPosition = position + normal * (displacement * uDisplacementScale);

    gl_Position = projectionMatrix * modelViewMatrix * vec4(displacedPosition, 1.0);
}

Fragment Shader

varying vec2 vUv;
varying vec3 vNormal;

void main() {
    // Simple basic shading based on UV coordinates
    gl_FragColor = vec4(vUv, 0.5, 1.0);
}

3. Setting Up the Three.js Material and Mesh

For a displacement map to function correctly, the underlying geometry must possess enough vertices (subdivisions) to deform. A standard plane with only four vertices will not show detail; it requires multiple width and height segments.

import * as THREE from 'three';

// 1. Load the displacement texture
const textureLoader = new THREE.TextureLoader();
const displacementTexture = textureLoader.load('path/to/displacement-map.jpg');

// 2. Define uniforms
const uniforms = {
    uDisplacementMap: { value: displacementTexture },
    uDisplacementScale: { value: 2.0 }
};

// 3. Create the ShaderMaterial
const customMaterial = new THREE.ShaderMaterial({
    uniforms: uniforms,
    vertexShader: `
        uniform sampler2D uDisplacementMap;
        uniform float uDisplacementScale;
        varying vec2 vUv;

        void main() {
            vUv = uv;
            float displacement = texture2D(uDisplacementMap, uv).r;
            vec3 displacedPosition = position + normal * (displacement * uDisplacementScale);
            gl_Position = projectionMatrix * modelViewMatrix * vec4(displacedPosition, 1.0);
        }
    `,
    fragmentShader: `
        varying vec2 vUv;

        void main() {
            gl_FragColor = vec4(vUv, 1.0, 1.0);
        }
    `,
    wireframe: true // Helpful for visualizing vertex displacement
});

// 4. Create geometry with sufficient subdivisions
const geometry = new THREE.PlaneGeometry(10, 10, 128, 128);

// 5. Build the Mesh and add it to the scene
const mesh = new THREE.Mesh(geometry, customMaterial);
scene.add(mesh);

4. Dynamically Updating the Displacement

Because uniforms are reactive references, you can adjust the displacement intensity or swap textures in real time by mutating the uniform value in your animation loop or event handlers:

// Change scale dynamically
customMaterial.uniforms.uDisplacementScale.value = 3.5;

// Swap texture dynamically
customMaterial.uniforms.uDisplacementMap.value = newDisplacementTexture;
