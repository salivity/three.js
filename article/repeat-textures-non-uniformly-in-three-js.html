Repeat Textures Non-Uniformly in Three.js

In Three.js, repeating a texture non-uniformly requires configuring its wrapping modes and setting independent scaling factors along its horizontal and vertical axes. This guide explains how to set the wrapS and wrapT properties to THREE.RepeatWrapping and use the repeat property with different U and V values to achieve an asymmetric tiled pattern on 3D surfaces.

Understanding wrapS, wrapT, and Repeat

By default, Three.js textures use THREE.ClampToEdgeWrapping, which stretches the boundary pixels rather than tiling the texture. To enable tiling:

  • wrapS: Governs horizontal wrapping along the U (X) axis.
  • wrapT: Governs vertical wrapping along the V (Y) axis.

To repeat the texture across both axes, both properties must be set to THREE.RepeatWrapping (or THREE.MirroredRepeatWrapping). Once repeating is activated, non-uniform repetition is controlled via the texture's repeat vector, which accepts distinct values for horizontal and vertical tiling.

Implementation

  1. Load the Texture: Load your image asset using THREE.TextureLoader.
  2. Set Wrapping Properties: Assign THREE.RepeatWrapping to both wrapS and wrapT.
  3. Define Asymmetric Repeat Counts: Set texture.repeat.set(x, y) where x and y are different numeric values.
import * as THREE from 'three';

// Initialize loader and load image
const textureLoader = new THREE.TextureLoader();
const texture = textureLoader.load('path/to/texture.jpg');

// Enable repetition along both axes
texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;

// Apply non-uniform repeat: 4 times horizontally, 2 times vertically
texture.repeat.set(4, 2);

// Apply to a material and mesh
const material = new THREE.MeshStandardMaterial({ map: texture });
const geometry = new THREE.PlaneGeometry(10, 5);
const mesh = new THREE.Mesh(geometry, material);

Important Considerations

  • Runtime Updates: If you modify wrapS or wrapT after the texture has already been rendered in a scene, you must set texture.needsUpdate = true to force WebGL to recompile the texture configuration.
  • Texture Offsets: Non-uniform repeats can be paired with texture.offset.set(x, y) to control where the repeated pattern starts along either axis.
  • Power of Two Dimensions: While WebGL 2 supports non-power-of-two textures, using power-of-two image dimensions (such as 512×512 or 1024×1024) ensures full backward compatibility and proper mipmap generation when tiling.
