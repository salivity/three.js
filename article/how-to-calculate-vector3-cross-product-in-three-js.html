How to Calculate Vector3 Cross Product in Three.js

In Three.js, calculating the cross product of two Vector3 instances is the standard technique for deriving a third vector that is perpendicular (orthogonal) to both inputs. This article explains how the cross product works in 3D space, demonstrates the built-in Three.js methods for computing it, and highlights best practices such as normalization and avoiding unintended object mutation.

Understanding the Cross Product

The cross product of two vectors, \(\mathbf{A}\) and \(\mathbf{B}\), produces a vector \(\mathbf{C}\) that is perpendicular to the plane containing \(\mathbf{A}\) and \(\mathbf{B}\). In Three.js, this operation follows the right-hand rule. The cross product is essential for calculating surface normals, establishing local coordinate systems (like camera orientation axes), and computing rotational axes.

If the two input vectors are parallel or collinear, the cross product will yield a zero vector (0, 0, 0).

Method 1: Using crossVectors() (Recommended)

The safest and most common way to compute a perpendicular vector is using Vector3.crossVectors(a, b). This method calculates the cross product of a and b and writes the result into the calling vector without modifying the original inputs.

import * as THREE from 'three';

// Define two vectors
const vectorA = new THREE.Vector3(1, 0, 0); // Points right along the X-axis
const vectorB = new THREE.Vector3(0, 1, 0); // Points up along the Y-axis

// Create a target vector to store the result
const perpendicularVector = new THREE.Vector3();

// Calculate the cross product
perpendicularVector.crossVectors(vectorA, vectorB);

console.log(perpendicularVector); // Vector3 { x: 0, y: 0, z: 1 }

Method 2: Using cross() (In-Place Mutation)

Three.js also provides the Vector3.cross(v) method. This calculates the cross product of the current vector and another vector v, mutating the calling vector in place.

const vectorA = new THREE.Vector3(1, 0, 0);
const vectorB = new THREE.Vector3(0, 1, 0);

// vectorA will be modified directly
vectorA.cross(vectorB);

console.log(vectorA); // Vector3 { x: 0, y: 0, z: 1 }

Use cross() only when you no longer need the original values of the calling vector, or chain it with .clone() (e.g., vectorA.clone().cross(vectorB)) to avoid unintended side effects.

Normalizing the Perpendicular Vector

The magnitude (length) of the cross product equals the area of the parallelogram formed by the two vectors. If you need a unit vector (a direction vector of length 1, such as a normal), you must normalize the result using .normalize():

const normal = new THREE.Vector3()
    .crossVectors(vectorA, vectorB)
    .normalize();

Vector Order Matters

The cross product is anticommutative, meaning:

\[\mathbf{A} \times \mathbf{B} = -(\mathbf{B} \times \mathbf{A})\]

Reversing the arguments reverses the direction of the perpendicular vector:

const result1 = new THREE.Vector3().crossVectors(vectorA, vectorB); // (0, 0, 1)
const result2 = new THREE.Vector3().crossVectors(vectorB, vectorA); // (0, 0, -1)

Ensure your inputs follow the intended winding order (clockwise versus counter-clockwise) to point your resulting vector in the desired direction.
