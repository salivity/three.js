How to Configure XRControllerModelFactory in Three.js

Configuring the XRControllerModelFactory in Three.js allows your WebXR application to automatically identify a connected VR/AR headset and fetch the exact vendor-specific 3D controller model. By integrating this factory with Three.js's XR controller grip system, you eliminate the need to manually source, rig, and map controller assets for different hardware brands like Meta Quest, HTC Vive, or Valve Index. This guide walks through the required imports, setup procedures, and code implementation to automate controller model rendering.

1. Import Dependencies

To use the factory, import the standard Three.js library alongside the XRControllerModelFactory addon.

import * as THREE from 'three';
import { XRControllerModelFactory } from 'three/addons/webxr/XRControllerModelFactory.js';

2. Enable WebXR on the Renderer

Ensure your WebGLRenderer instance has WebXR enabled.

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.xr.enabled = true;
document.body.appendChild(renderer.domElement);

3. Instantiate the Model Factory

Create an instance of XRControllerModelFactory. This object leverages the standard WebXR Input Profiles loader under the hood to dynamically match the user's hardware profile string with the correct asset package.

const controllerModelFactory = new XRControllerModelFactory();

4. Bind Models to Controller Grips

Three.js differentiates between target ray controllers (used for pointing/selection) and controller grips (used for rendering the physical hardware representation). You must attach the factory-generated model to the controller grip, not the standard controller object.

// Setup controller grip 0 (typically right or primary)
const controllerGrip0 = renderer.xr.getControllerGrip(0);
const model0 = controllerModelFactory.createControllerModel(controllerGrip0);
controllerGrip0.add(model0);
scene.add(controllerGrip0);

// Setup controller grip 1 (typically left or secondary)
const controllerGrip1 = renderer.xr.getControllerGrip(1);
const model1 = controllerModelFactory.createControllerModel(controllerGrip1);
controllerGrip1.add(model1);
scene.add(controllerGrip1);

How the Automatic Detection Operates

When an XR session starts, the browser populates the XRInputSource array with hardware profile identifiers (e.g., oculus-touch-v3 or valve-index).

Passing controllerGrip to controllerModelFactory.createControllerModel() triggers an internal event listener for connected. Upon connection, the factory inspects the inputSource.profiles list, downloads the matching glTF controller model and textures from the official WebXR Input Profiles repository via CDN, and automatically binds button/trigger animations to the user's live controller input states. If the specific model cannot be found, it gracefully falls back to a generic controller model.
