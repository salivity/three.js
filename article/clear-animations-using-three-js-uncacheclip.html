Clear Animations Using Three.js uncacheClip

Managing memory effectively in Three.js is critical for maintaining high performance, especially in applications that load, swap, or discard animated 3D models dynamically. This guide explains how to properly remove obsolete animation clips from memory using the AnimationMixer.uncacheClip method, detailing why it is necessary, how to implement it, and how to ensure the garbage collector reclaims the freed resources.

Why You Need uncacheClip

When you create an AnimationAction using mixer.clipAction(clip), the AnimationMixer stores internal references, bindings, and interpolated track data for that specific AnimationClip. If you discard the model or no longer need the clip, simply setting your local JavaScript reference to null is not enough. The AnimationMixer maintains its internal cache, preventing the JavaScript garbage collector from releasing the clip’s memory and causing a memory leak.

Calling mixer.uncacheClip(clip) clears all internal memory and cached resources that the mixer allocated specifically for that AnimationClip.

How to Use uncacheClip

To completely remove an animation clip and free its memory, follow these steps:

1. Stop the Running Action

Before clearing the cache, ensure the action associated with the clip is stopped to avoid errors in the mixer's update loop.

const action = mixer.clipAction(myClip);
action.stop();

2. Uncache the Clip from the Mixer

Pass the AnimationClip instance directly into the mixer's uncacheClip method:

mixer.uncacheClip(myClip);

This instructs the mixer to remove all internal references and bindings associated with myClip.

3. Dereference the Clip

Finally, remove any lingering JavaScript references to the clip in your application so the browser's garbage collector can reclaim the memory.

myClip = null;

Complete Code Example

import * as THREE from 'three';

// Setup mixer and load animation clip
const mixer = new THREE.AnimationMixer(characterMesh);
let walkClip = gltf.animations.find(anim => anim.name === 'Walk');

// Play the animation
const walkAction = mixer.clipAction(walkClip);
walkAction.play();

// Function to safely dispose of the obsolete animation clip
function disposeAnimationClip(mixer, clip) {
    if (!clip) return;

    // Stop the action if it exists
    const action = mixer.existingAction(clip);
    if (action) {
        action.stop();
    }

    // Uncache the clip from the mixer's memory
    mixer.uncacheClip(clip);
}

// When the clip is no longer needed:
disposeAnimationClip(mixer, walkClip);
walkClip = null;

Related Uncache Methods

Depending on your disposal workflow, Three.js provides complementary uncache methods on the AnimationMixer:

  • mixer.uncacheAction(clip, optionalRoot): Removes the cached AnimationAction for a specific clip and optional root object without necessarily clearing all references to the clip itself.
  • mixer.uncacheRoot(root): Clears all memory and actions associated with a root object (for example, when a model is completely removed from the scene).
