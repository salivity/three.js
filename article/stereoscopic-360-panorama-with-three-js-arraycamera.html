Stereoscopic 360 Panorama with Three.js ArrayCamera

Rendering a stereoscopic 360-degree panorama in Three.js using THREE.ArrayCamera involves configuring two distinct sub-cameras to represent the left and right eyes, defining their respective screen viewports, and binding them to stereo-specific display layers. This article explains how to configure an ArrayCamera, manage layer-based texture separation for top-bottom or side-by-side panoramic media, and execute the rendering pipeline efficiently.

1. Understanding ArrayCamera for Stereoscopy

THREE.ArrayCamera is a specialized camera designed to render a single scene to multiple viewports within a single render pass. For stereoscopic viewing (such as VR headsets, 3D displays, or split-screen mobile viewers), you assign two THREE.PerspectiveCamera instances—one for the left eye and one for the right eye. Each sub-camera requires a customized viewport vector indicating its position and scale on the canvas.

2. Setting Up the Stereo Geometry and Layers

Stereoscopic 360 panoramas typically use an equirectangular image or video arranged in either an over-under (top-bottom) or side-by-side format. The cleanest approach to render this media without custom shaders is to create two inverted spheres and map the respective halves of the texture using UV offsets, then separate them using Three.js layers.

import * as THREE from 'three';

// Initialize scene
const scene = new THREE.Scene();

// Load the stereoscopic 360 texture (assumes Top/Bottom format)
const textureLoader = new THREE.TextureLoader();
const stereoTexture = textureLoader.load('path/to/stereo_panorama.jpg');
stereoTexture.colorSpace = THREE.SRGBColorSpace;

const geometry = new THREE.SphereGeometry(500, 60, 40);
// Invert geometry so the panorama displays on the inside
geometry.scale(-1, 1, 1);

// Left Eye Sphere (Top Half)
const textureLeft = stereoTexture.clone();
textureLeft.repeat.set(1, 0.5);
textureLeft.offset.set(0, 0.5);

const materialLeft = new THREE.MeshBasicMaterial({ map: textureLeft });
const meshLeft = new THREE.Mesh(geometry, materialLeft);
meshLeft.layers.set(1); // Layer 1: Left eye
scene.add(meshLeft);

// Right Eye Sphere (Bottom Half)
const textureRight = stereoTexture.clone();
textureRight.repeat.set(1, 0.5);
textureRight.offset.set(0, 0);

const materialRight = new THREE.MeshBasicMaterial({ map: textureRight });
const meshRight = new THREE.Mesh(geometry, materialRight);
meshRight.layers.set(2); // Layer 2: Right eye
scene.add(meshRight);

3. Creating and Configuring the Sub-Cameras

Define two PerspectiveCamera instances. Assign each sub-camera an appropriate layer mask so that it only sees its corresponding panoramic sphere, and configure the viewport property (x, y, width, height in normalized canvas coordinates between 0 and 1).

const fov = 75;
const aspect = window.innerWidth / (window.innerHeight / 2); // Split view
const near = 0.1;
const far = 1000;

// Sub-camera 1: Left Eye
const cameraLeft = new THREE.PerspectiveCamera(fov, aspect, near, far);
cameraLeft.layers.set(1);
// Viewport: Top half or Left half (Example: Side-by-side split)
cameraLeft.viewport = new THREE.Vector4(0, 0, 0.5, 1);

// Sub-camera 2: Right Eye
const cameraRight = new THREE.PerspectiveCamera(fov, aspect, near, far);
cameraRight.layers.set(2);
// Viewport: Right half
cameraRight.viewport = new THREE.Vector4(0.5, 0, 0.5, 1);

To account for inter-pupillary distance (IPD) when viewing stereoscopic content with 3D depth, offset the camera positions horizontally along the X-axis:

const ipd = 0.064; // Standard 64mm IPD
cameraLeft.position.set(-ipd / 2, 0, 0);
cameraRight.position.set(ipd / 2, 0, 0);

4. Initializing the ArrayCamera

Pass the array of sub-cameras into the THREE.ArrayCamera constructor. Note that ArrayCamera requires the sub-cameras to update their matrices before rendering.

const cameras = [cameraLeft, cameraRight];
const arrayCamera = new THREE.ArrayCamera(cameras);
arrayCamera.position.z = 0;

5. Handling Viewport Resizing and Rendering

When the browser window resizes, update the projection matrices of both sub-cameras and the root ArrayCamera. When rendering side-by-side views, adjust the sub-camera aspect ratios based on half of the total canvas width.

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(window.devicePixelRatio);
document.body.appendChild(renderer.domElement);

function onWindowResize() {
    const width = window.innerWidth;
    const height = window.innerHeight;

    renderer.setSize(width, height);

    // Half-width aspect ratio for side-by-side layout
    const subAspect = (width / 2) / height;

    cameraLeft.aspect = subAspect;
    cameraLeft.updateProjectionMatrix();

    cameraRight.aspect = subAspect;
    cameraRight.updateProjectionMatrix();
}

window.addEventListener('resize', onWindowResize);

function animate() {
    requestAnimationFrame(animate);

    // Render the scene via the ArrayCamera
    renderer.render(scene, arrayCamera);
}

animate();

By leveraging ArrayCamera, Three.js calculates the scene culling and pipeline setup once while rendering the isolated left and right panoramic views directly into their designated canvas regions.
