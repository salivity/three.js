How to Reflect a Vector off a Normal in Three.js

Calculating the reflection of a ray direction vector off a surface is a fundamental operation in computer graphics used for ray tracing, bounce physics, and custom shaders. This article explains the mathematical formula for vector reflection, demonstrates how to compute it manually using standard vector math, and covers the built-in methods provided by Three.js to achieve the calculation efficiently.

The Mathematical Reflection Formula

The reflection of an incoming vector across a surface normal is governed by the following mathematical formula:

\[\mathbf{r} = \mathbf{d} - 2(\mathbf{d} \cdot \mathbf{n})\mathbf{n}\]

Where:

  • \(\mathbf{d}\) is the incident (incoming) direction vector.
  • \(\mathbf{n}\) is the surface normal vector (must be a unit vector of length 1).
  • \(\mathbf{d} \cdot \mathbf{n}\) is the dot product of the incident vector and the normal vector.
  • \(\mathbf{r}\) is the resulting reflected vector.

For the math to work correctly, the normal vector \(\mathbf{n}\) must be normalized. The incident vector \(\mathbf{d}\) points toward the surface. The dot product calculates the projection of \(\mathbf{d}\) onto \(\mathbf{n}\), and subtracting twice that projection flips the perpendicular component while preserving the parallel component.

Using the Built-In Three.js Method

Three.js includes a built-in method on the THREE.Vector3 class called .reflect(). This method applies the reflection formula directly in place.

import * as THREE from 'three';

// 1. Define the incoming ray direction and surface normal
const rayDirection = new THREE.Vector3(1, -1, 0).normalize();
const surfaceNormal = new THREE.Vector3(0, 1, 0).normalize();

// 2. Reflect the ray direction off the normal
// Note: .reflect() mutates the vector it is called on
const reflectedVector = rayDirection.clone().reflect(surfaceNormal);

console.log(reflectedVector); // Output: Vector3 { x: 1, y: 1, z: 0 }

Manual Implementation in Three.js

If you want to implement the formula manually using low-level Three.js vector operations, you can write the dot product projection step-by-step:

import * as THREE from 'three';

function calculateReflection(direction, normal) {
    // Ensure the normal is normalized
    const n = normal.clone().normalize();
    const d = direction.clone();

    // Compute dot product: (d . n)
    const dotProduct = d.dot(n);

    // Compute 2 * (d . n) * n
    const scaledNormal = n.multiplyScalar(2 * dotProduct);

    // Compute r = d - 2(d . n)n
    return d.sub(scaledNormal);
}

const rayDir = new THREE.Vector3(1, -1, 0).normalize();
const normal = new THREE.Vector3(0, 1, 0).normalize();
const reflected = calculateReflection(rayDir, normal);

Practical Example with THREE.Raycaster

When handling collisions or ray casting in a scene, you obtain the surface normal directly from the intersection object:

import * as THREE from 'three';

const raycaster = new THREE.Raycaster(rayOrigin, rayDirection);
const intersects = raycaster.intersectObjects(scene.children);

if (intersects.length > 0) {
    const hit = intersects[0];

    // The face normal is in local coordinates, transform to world coordinates
    const normalMatrix = new THREE.Matrix3().getNormalMatrix(hit.object.matrixWorld);
    const worldNormal = hit.face.normal.clone().applyMatrix3(normalMatrix).normalize();

    // Calculate reflected ray direction
    const incomingDir = raycaster.ray.direction.clone();
    const reflectedDir = incomingDir.reflect(worldNormal);

    // The new ray starts from the intersection point
    const newRayOrigin = hit.point;
}

Ensure the normal vector is transformed into the same coordinate space (usually world space) as the ray direction before performing the reflection calculation.
