How to Decompose a Matrix4 in Three.js

Decomposing a transformation matrix in Three.js allows you to extract individual spatial transformations—translation, rotation, and scale—from a single 4x4 transformation matrix. This guide demonstrates how to use the built-in Matrix4.decompose() method to populate Vector3 and Quaternion instances with the separated translation, orientation, and scale data.

The decompose() Method

Three.js provides a native method on the Matrix4 class specifically for this purpose:

matrix.decompose(position, quaternion, scale);

This method mutates three target objects passed as arguments:

  • position: A THREE.Vector3 to receive the translation components (x, y, z).
  • quaternion: A THREE.Quaternion to receive the rotation component.
  • scale: A THREE.Vector3 to receive the scale factors along each axis (x, y, z).

Code Example

Here is a complete example demonstrating how to set up the targets and extract the components:

import * as THREE from 'three';

// 1. Create or reference an existing Matrix4
const matrix = new THREE.Matrix4();
// (Assuming matrix has been populated with transformations)

// 2. Pre-allocate the target objects to store the results
const position = new THREE.Vector3();
const quaternion = new THREE.Quaternion();
const scale = new THREE.Vector3();

// 3. Decompose the matrix into the target objects
matrix.decompose(position, quaternion, scale);

// 4. Access the extracted values
console.log('Position:', position);
console.log('Quaternion Rotation:', quaternion);
console.log('Scale:', scale);

Converting the Rotation to Euler Angles

The decompose() method outputs rotation as a THREE.Quaternion to avoid gimbal lock and preserve mathematical accuracy. If your application requires rotation in Euler angles (pitch, yaw, roll), convert the quaternion using THREE.Euler:

const euler = new THREE.Euler();
euler.setFromQuaternion(quaternion);

console.log('Euler Rotation (radians):', euler);

Decomposing an Object3D's World Matrix

If you need to extract the global transformation of a scene graph object (such as a mesh or group), ensure its world matrix is up to date before decomposing:

// Ensure parent and local matrices are calculated
myMesh.updateWorldMatrix(true, false);

const worldPosition = new THREE.Vector3();
const worldQuaternion = new THREE.Quaternion();
const worldScale = new THREE.Vector3();

myMesh.matrixWorld.decompose(worldPosition, worldQuaternion, worldScale);

Performance Best Practice

Avoid instantiating new THREE.Vector3 and THREE.Quaternion objects inside real-time loops (such as requestAnimationFrame). Instead, allocate the target objects once outside the loop and reuse them to minimize garbage collection overhead.
