Disable Mipmaps on Three.js VideoTexture

Using a video as a texture in Three.js can cause significant performance drops if the GPU recalculates a full mipmap chain for every new video frame. This article explains how to set the generateMipmaps property to false on a THREE.VideoTexture to eliminate this bottleneck, and covers the necessary texture filter adjustments required to keep your 3D scenes running at high frame rates.

Why Disable Mipmaps for Video Textures?

By default, Three.js enables mipmapping on textures. For standard static textures, mipmaps are generated once on load. However, a VideoTexture updates dynamically whenever a new frame arrives (typically 30 to 60 times per second).

If generateMipmaps remains enabled, WebGL executes an expensive gl.generateMipmap() operation every time the video updates. This creates heavy GPU and CPU overhead, leading to dropped frames and stuttering playback. Disabling mipmap generation removes this per-frame processing cost entirely.

Setting generateMipmaps to False

To disable mipmaps, initialize your THREE.VideoTexture and set its generateMipmaps property to false.

Because the default minification filter (minFilter) relies on mipmaps (THREE.LinearMipmapLinearFilter), you must also change the minFilter to either THREE.LinearFilter or THREE.NearestFilter. If you fail to update the filter, the texture may render as solid black or trigger WebGL warnings.

import * as THREE from 'three';

// 1. Get reference to your HTML video element
const video = document.getElementById('video');

// 2. Instantiate the VideoTexture
const videoTexture = new THREE.VideoTexture(video);

// 3. Disable mipmap generation
videoTexture.generateMipmaps = false;

// 4. Set non-mipmap filtering
videoTexture.minFilter = THREE.LinearFilter;
videoTexture.magFilter = THREE.LinearFilter;

// 5. Apply the texture to a material
const material = new THREE.MeshBasicMaterial({ map: videoTexture });
const mesh = new THREE.Mesh(new THREE.PlaneGeometry(16, 9), material);
scene.add(mesh);

Key Considerations

  • Visual Quality: Switching minFilter to THREE.LinearFilter provides smooth interpolation without requiring mipmaps. Some aliasing or shimmering may occur if the video is viewed from a very sharp angle or placed far away in the distance, but the performance improvement almost always outweighs the visual trade-off.
  • Format Flexibility: Disabling mipmaps also prevents texture errors in WebGL 1 environments when working with non-power-of-two (NPOT) video resolutions.
