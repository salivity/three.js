Decode Base64 to Uint8Array for Three.js DataTexture

This article explains how to convert a Base64-encoded string into a raw Uint8Array in JavaScript and pass it directly into a Three.js DataTexture. You will learn how to strip standard Data URI headers, decode the Base64 payload into binary bytes using native browser APIs, and correctly instantiate a DataTexture with the required dimensions and pixel formats.

1. Strip the Base64 Header

Base64 strings often arrive as Data URIs (for example, data:image/png;base64,... or data:application/octet-stream;base64,...). Before decoding the raw bytes, remove any metadata prefix if present:

function cleanBase64(base64String) {
  const index = base64String.indexOf(',');
  return index !== -1 ? base64String.slice(index + 1) : base64String;
}

2. Decode Base64 to a Uint8Array

Modern browsers provide the atob() function to decode Base64 strings into binary strings where each character represents a single byte. You can iterate over this binary string and fill a typed Uint8Array:

function base64ToUint8Array(base64) {
  const cleanString = cleanBase64(base64);
  const binaryString = window.atob(cleanString);
  const len = binaryString.length;
  const bytes = new Uint8Array(len);

  for (let i = 0; i < len; i++) {
    bytes[i] = binaryString.charCodeAt(i);
  }

  return bytes;
}

Note: For Node.js environments, use Buffer.from(cleanString, 'base64') instead of window.atob().

3. Create the Three.js DataTexture

A THREE.DataTexture requires raw pixel data, not an encoded image file like PNG or JPEG. The length of your Uint8Array must exactly match the expected pixel layout:

\[\text{Length} = \text{width} \times \text{height} \times \text{channels}\]

For example, standard RGBA has 4 channels (THREE.RGBAFormat), while RGB has 3 channels (THREE.RGBFormat in older versions or packed RGBA in newer releases).

Implementation

import * as THREE from 'three';

const width = 256;
const height = 256;

// 1. Decode your raw pixel Base64 string
const base64Data = "YOUR_BASE64_STRING_HERE";
const pixelData = base64ToUint8Array(base64Data);

// 2. Instantiate DataTexture
const texture = new THREE.DataTexture(
  pixelData,
  width,
  height,
  THREE.RGBAFormat,
  THREE.UnsignedByteType
);

// 3. Flag the texture for GPU upload
texture.needsUpdate = true;

// 4. Assign the texture to a material
const material = new THREE.MeshBasicMaterial({ map: texture });

Considerations

  • Dimensions: Ensure width * height * 4 (for THREE.RGBAFormat) exactly matches pixelData.length. A size mismatch will throw an internal WebGL buffer error.
  • Compressed Formats: If your Base64 string represents an encoded PNG or JPEG rather than raw pixel data, a DataTexture will not parse it. In that case, load it into an Image element or use THREE.TextureLoader instead. DataTexture is strictly for uncompressed, raw color or data channels.
