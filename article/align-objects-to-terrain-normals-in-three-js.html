Align Objects to Terrain Normals in Three.js

This article explains how to align any 3D object to the surface slope of a procedurally generated terrain using the Three.js Raycaster. You will learn how to cast a ray to find the terrain's surface intersection, retrieve and convert the face normal into world coordinates, and apply that normal vector to the object’s orientation using quaternions without causing unpredictable rotation artifacts.

1. Set Up the Raycaster

To locate the terrain below an object, position the raycaster above the object's target horizontal coordinates and cast the ray downward along the negative Y-axis.

import * as THREE from 'three';

const raycaster = new THREE.Raycaster();
const downVector = new THREE.Vector3(0, -1, 0);

// Set ray origin above the desired position (e.g., height of 100)
const origin = new THREE.Vector3(targetX, 100, targetZ);
raycaster.set(origin, downVector);

2. Intersect the Terrain and Extract the Normal

Intersect the ray against your terrain mesh. If a hit occurs, the intersection result contains both the exact contact point and the geometric normal of the intersected face.

const intersects = raycaster.intersectObject(terrainMesh);

if (intersects.length > 0) {
    const hit = intersects[0];
    
    // Set object position to the hit point
    targetObject.position.copy(hit.point);

    // Retrieve face normal
    const faceNormal = hit.face.normal.clone();
    
    // Transform normal to world space if the terrain mesh has transforms
    faceNormal.transformDirection(terrainMesh.matrixWorld);
}

3. Align Object Rotation to the Normal

An object's default local vertical axis is typically Vector3(0, 1, 0). Use a THREE.Quaternion with the setFromUnitVectors method to rotate the object from its default up-vector to match the world surface normal.

const defaultUp = new THREE.Vector3(0, 1, 0);
targetObject.quaternion.setFromUnitVectors(defaultUp, faceNormal);

4. Preserving Object Heading (Yaw)

Using setFromUnitVectors directly can cause the object's forward direction (yaw) to snap unpredictably. If the object must face a specific direction while conforming to the slope, compute an orthonormal basis:

function alignToNormalWithHeading(object, normal, headingAngle) {
    // 1. Determine the desired forward direction on the horizontal plane
    const forward = new THREE.Vector3(
        Math.sin(headingAngle),
        0,
        Math.cos(headingAngle)
    );

    // 2. Derive the right vector perpendicular to normal and forward
    const right = new THREE.Vector3().crossVectors(forward, normal).normalize();

    // 3. Recalculate true forward to ensure perfect orthogonality
    const trueForward = new THREE.Vector3().crossVectors(normal, right).normalize();

    // 4. Construct a rotation matrix and apply to the object
    const rotationMatrix = new THREE.Matrix4();
    rotationMatrix.makeBasis(right, normal, trueForward);
    object.quaternion.setFromRotationMatrix(rotationMatrix);
}

Complete Implementation Example

function updateObjectOnTerrain(object, terrainMesh, x, z, heading = 0) {
    const rayOrigin = new THREE.Vector3(x, 500, z);
    const rayDirection = new THREE.Vector3(0, -1, 0);
    
    raycaster.set(rayOrigin, rayDirection);
    const intersects = raycaster.intersectObject(terrainMesh);

    if (intersects.length > 0) {
        const hit = intersects[0];
        
        // Update position
        object.position.copy(hit.point);

        // Calculate world normal
        const normal = hit.face.normal.clone().transformDirection(terrainMesh.matrixWorld);

        // Apply orientation
        alignToNormalWithHeading(object, normal, heading);
    }
}
