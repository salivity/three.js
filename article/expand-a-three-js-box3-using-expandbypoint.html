Expand a Three.js Box3 Using expandByPoint

This article explains how to use the expandByPoint method of the Box3 class in Three.js to dynamically grow a 3D bounding box to enclose a specified point. You will learn the mechanics behind the method, how it affects the internal minimum and maximum coordinates of the bounding box, and how to implement it effectively with clear code examples.

Understanding Box3 and expandByPoint

In Three.js, THREE.Box3 represents an axis-aligned bounding box (AABB) defined by two THREE.Vector3 vectors: min and max.

The expandByPoint(point) method evaluates an arbitrary THREE.Vector3 against the current boundaries of the box. If the coordinates of the target point fall outside the existing volume, the method adjusts min and max along the X, Y, and Z axes so that the box minimally encapsulates the new point:

  • this.min.min(point): Reduces the min coordinates if the point has lower values.
  • this.max.max(point): Increases the max coordinates if the point has higher values.

Step-by-Step Implementation

1. Initializing the Bounding Box

When creating a new Box3, it is initialized as an empty box where min is set to (+Infinity, +Infinity, +Infinity) and max is set to (-Infinity, -Infinity, -Infinity). Calling expandByPoint on an empty box sets both min and max directly to the coordinates of that initial point.

import * as THREE from 'three';

// Create an empty bounding box
const box = new THREE.Box3();

// Define an initial point
const firstPoint = new THREE.Vector3(0, 0, 0);

// Expand the empty box to contain the first point
box.expandByPoint(firstPoint);

console.log(box.min); // Vector3 { x: 0, y: 0, z: 0 }
console.log(box.max); // Vector3 { x: 0, y: 0, z: 0 }

2. Expanding to Encapsulate Additional Points

To grow the box to include another arbitrary 3D coordinate, call expandByPoint with the new Vector3.

// Define an arbitrary target point
const newPoint = new THREE.Vector3(15, -10, 5);

// Expand the bounding box
box.expandByPoint(newPoint);

// The bounds now encompass both (0, 0, 0) and (15, -10, 5)
console.log(box.min); // Vector3 { x: 0, y: -10, z: 0 }
console.log(box.max); // Vector3 { x: 15, y: 0, z: 5 }

Encapsulating an Array of Arbitrary Points

expandByPoint is commonly used in loops to compute the bounding volume of dynamic point clouds, trajectory paths, or custom vertex sets:

const points = [
  new THREE.Vector3(-5, 2, 1),
  new THREE.Vector3(12, 8, -4),
  new THREE.Vector3(3, -15, 9),
  new THREE.Vector3(0, 4, 2)
];

const boundingBox = new THREE.Box3();

for (let i = 0; i < points.length; i++) {
  boundingBox.expandByPoint(points[i]);
}

// Retrieve properties of the expanded box
const size = new THREE.Vector3();
const center = new THREE.Vector3();

boundingBox.getSize(size);
boundingBox.getCenter(center);

console.log('Box Size:', size);
console.log('Box Center:', center);

Summary of Key Behaviors

  • Chainability: The method returns this, allowing method chaining (e.g., box.expandByPoint(p1).expandByPoint(p2)).
  • No Pre-Transformation: expandByPoint expects coordinates in the same coordinate space (local or world) as the Box3. If points exist in local object space, convert them to world coordinates using Vector3.applyMatrix4(object.matrixWorld) before expanding a world-space box.
