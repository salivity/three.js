Three.js Specular Only Environment Map Setup

In Three.js, assigning an environment map to a PBR material automatically calculates both diffuse irradiance (ambient light) and specular radiance (reflections). To isolate the environment map so that it exclusively generates specular highlights and mirror-like reflections without brightening the base diffuse color of the mesh, you must assign the map directly to the material's envMap property and strip the indirect diffuse irradiance pass using material.onBeforeCompile.

The Default IBL Problem

When using MeshStandardMaterial or MeshPhysicalMaterial, Three.js applies Image-Based Lighting (IBL). The lighting calculation internally splits the environment map into two components:

  1. Indirect Diffuse (Irradiance): Blurs the environment map and projects ambient color onto the object based on surface normals.
  2. Indirect Specular (Radiance): Samples the environment map based on view angle and roughness to create sharp or glossy reflections.

Setting scene.environment applies both components to every standard material in the scene. To isolate specular reflections, you must bypass the indirect diffuse calculation at the material level.

Step 1: Assign the Map Directly to the Material

Avoid applying your texture to scene.environment, as this acts globally. Instead, generate a prefiltered radiance environment map (PMREM) using PMREMGenerator and assign it directly to material.envMap:

import * as THREE from 'three';
import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';

const pmremGenerator = new THREE.PMREMGenerator(renderer);
pmremGenerator.compileEquirectangularShader();

new RGBELoader().load('environment.hdr', (texture) => {
  const envMap = pmremGenerator.fromEquirectangular(texture).texture;
  
  material.envMap = envMap;
  material.needsUpdate = true;

  texture.dispose();
  pmremGenerator.dispose();
});

Step 2: Strip Indirect Diffuse via onBeforeCompile

Because setting material.envMap still calculates diffuse irradiance, you must remove the indirect diffuse lighting call in the fragment shader.

In the standard Three.js shader pipeline, diffuse irradiance is computed inside the lights_fragment_begin chunk via the RE_IndirectDiffuse function call. You can remove or comment this line out using onBeforeCompile:

const material = new THREE.MeshStandardMaterial({
  color: 0x222222,
  roughness: 0.1,
  metalness: 0.0,
});

material.onBeforeCompile = (shader) => {
  shader.fragmentShader = shader.fragmentShader.replace(
    'RE_IndirectDiffuse( irradiance, geometryPosition, geometryNormal, geometryViewDir, geometryClearcoatNormal, material, reflectedLight );',
    '// Skipped indirect diffuse from envMap'
  );
};

Complete Implementation Example

Below is a complete implementation showing a mesh that receives directional and ambient scene lighting for its diffuse component, but exclusively sources sharp reflections from an HDR map without gaining any ambient diffuse color from it:

import * as THREE from 'three';
import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';

// Setup Renderer and Scene
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.toneMapping = THREE.ACESFilmicToneMapping;
document.body.appendChild(renderer.domElement);

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 0, 4);

// Scene lights (these provide the actual diffuse illumination)
const ambientLight = new THREE.AmbientLight(0xffffff, 0.2);
const directionalLight = new THREE.DirectionalLight(0xffffff, 1.5);
directionalLight.position.set(5, 5, 5);
scene.add(ambientLight, directionalLight);

// Material setup
const material = new THREE.MeshStandardMaterial({
  color: 0x1565c0,
  roughness: 0.15,
  metalness: 0.1,
  envMapIntensity: 1.0
});

// Remove indirect diffuse calculation from the environment map
material.onBeforeCompile = (shader) => {
  shader.fragmentShader = shader.fragmentShader.replace(
    'RE_IndirectDiffuse( irradiance, geometryPosition, geometryNormal, geometryViewDir, geometryClearcoatNormal, material, reflectedLight );',
    '/* RE_IndirectDiffuse omitted for specular-only reflections */'
  );
};

const mesh = new THREE.Mesh(new THREE.SphereGeometry(1, 64, 32), material);
scene.add(mesh);

// Load HDR Environment Map
const pmremGenerator = new THREE.PMREMGenerator(renderer);
pmremGenerator.compileEquirectangularShader();

new RGBELoader().load('path/to/environment.hdr', (hdrTexture) => {
  const envMap = pmremGenerator.fromEquirectangular(hdrTexture).texture;
  material.envMap = envMap;
  material.needsUpdate = true;

  hdrTexture.dispose();
  pmremGenerator.dispose();
});

Key Considerations

  • material.needsUpdate: If you modify onBeforeCompile after the material has already been rendered once, set material.needsUpdate = true to force re-compilation.
  • Roughness Behavior: The specular reflection honors material.roughness. Setting roughness to 0.0 yields a perfect mirror reflection, while higher values blur the reflection across the surface according to the PMREM mip levels.
  • envMapIntensity Control: You can scale the intensity of the specular reflections independently without modifying scene lights by altering material.envMapIntensity.
