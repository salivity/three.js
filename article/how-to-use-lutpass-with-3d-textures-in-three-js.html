How to Use LUTPass with 3D Textures in Three.js

This article explains how to implement non-linear, cinematic color grading in Three.js using 3D Look-Up Tables (LUTs) and LUTPass. By transforming a standard .cube file into a 3D data texture (Data3DTexture) and integrating it into Three.js's post-processing pipeline (EffectComposer), you can remap complex color spaces, contrast curves, and saturation levels in real time with minimal performance overhead.

Understanding 3D LUTs in WebGL

A Look-Up Table (LUT) is a precomputed matrix of color transformations. While 1D LUTs can only adjust individual red, green, and blue color channels independently, a 3D LUT maps RGB inputs into a three-dimensional coordinate system. This allows for complex non-linear grading, such as shifting shadow hues toward teal while pushing midtone highlights toward orange without flattening overall dynamic range.

In WebGL 2, Three.js natively supports 3D textures (Data3DTexture), allowing the GPU to perform hardware-accelerated trilinear interpolation between color lattice points.

Required Modules

To implement this pipeline, you need the core post-processing modules and the specialized LUT loader from the three/addons/ directory:

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { LUTPass } from 'three/addons/postprocessing/LUTPass.js';
import { LUTCubeLoader } from 'three/addons/loaders/LUTCubeLoader.js';

Setting Up EffectComposer and LUTPass

  1. Initialize the Renderer and Composer: Set up the WebGLRenderer with WebGL 2 enabled (default in modern Three.js) and establish the EffectComposer.
  2. Add the Base Pass: Add a RenderPass to capture the base 3D scene.
  3. Instantiate LUTPass: Initialize the LUTPass and append it to your composer chain.
// Setup renderer
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.toneMapping = THREE.ACESFilmicToneMapping;
document.body.appendChild(renderer.domElement);

// Setup composer
const composer = new EffectComposer(renderer);
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// Setup LUTPass placeholder
const lutPass = new LUTPass();
lutPass.enabled = false; // Disable until the texture loads
composer.addPass(lutPass);

Loading and Mapping the 3D Texture

The LUTCubeLoader parses Adobe standard .cube files (commonly exported from DaVinci Resolve, Premiere, or Photoshop) directly into a Data3DTexture.

Assign the resulting texture to the lut property of LUTPass:

const lutLoader = new LUTCubeLoader();

lutLoader.load('path/to/cinematic_grade.cube', (result) => {
    // result.texture is a THREE.Data3DTexture
    lutPass.lut = result.texture;
    lutPass.intensity = 1.0; // Control grading strength (0.0 to 1.0)
    lutPass.enabled = true;
});

Render Loop Integration

Replace your standard renderer.render(scene, camera) call inside your animation loop with composer.render():

function animate() {
    requestAnimationFrame(animate);

    // Render the scene through the post-processing stack
    composer.render();
}

animate();

Important Technical Considerations

  • Color Space Management: Ensure consistency between your textures and output. Set renderer.outputColorSpace = THREE.SRGBColorSpace. Most LUTs expect an sRGB input; grading linear colors directly can lead to overblown highlights or crushed shadows.
  • LUT Dimensions: A standard 3D LUT size of 32x32x32 or 64x64x64 is ideal for real-time web applications. A 32³ LUT balances high visual precision with a lightweight memory footprint (around 128 KB of raw data).
  • Dynamic Blending: You can alter lutPass.intensity dynamically at runtime to fade color grading effects in and out, or switch textures on the fly by assigning a new Data3DTexture to lutPass.lut.
