Compute SplineCurve Tangent to Orient Three.js Objects

Orienting an object along a path in Three.js requires determining the direction of travel at a given position, which is represented by the curve's tangent vector. This guide explains how to calculate the tangent vector at any point along a SplineCurve using built-in Three.js methods, convert that vector into a usable rotation angle or orientation matrix, and apply it directly to an Object3D so that it seamlessly faces forward along the trajectory.

1. Understanding getTangent vs. getTangentAt

Three.js curves provide two primary methods for calculating a normalized tangent vector at a specific progress point between 0.0 (start) and 1.0 (end):

  • curve.getTangent(t): Evaluates the tangent at position t based on the curve's internal mathematical parameterization. Movement along the curve may vary in speed across unevenly spaced control points.
  • curve.getTangentAt(u): Evaluates the tangent at position u based on the equidistant arc length of the curve. This is preferred for smooth animations because it ensures constant speed.

Both methods write into or return a normalized vector pointing in the direction of the curve at that exact location.

2. Computing the Tangent for 2D SplineCurve

Because THREE.SplineCurve is a 2D curve, its coordinates and tangents are instances of THREE.Vector2. To align an object's rotation along a 2D spline:

// Define the 2D Spline
const curve = new THREE.SplineCurve([
  new THREE.Vector2(-10, 0),
  new THREE.Vector2(-5, 5),
  new THREE.Vector2(0, 0),
  new THREE.Vector2(5, -5),
  new THREE.Vector2(10, 0)
]);

const progress = 0.5; // Progress along curve (0.0 to 1.0)

// 1. Get position and tangent
const point = new THREE.Vector2();
const tangent = new THREE.Vector2();

curve.getPointAt(progress, point);
curve.getTangentAt(progress, tangent);

// 2. Position the object
object.position.set(point.x, point.y, 0);

// 3. Compute rotation angle using atan2 and apply
const radians = Math.atan2(tangent.y, tangent.x);
object.rotation.z = radians;

3. Orienting Objects in 3D Space

If the SplineCurve represents motion across a flat plane in a 3D scene (such as the XZ ground plane), map the 2D tangent to a 3D vector:

const tangent2D = curve.getTangentAt(progress);
const tangent3D = new THREE.Vector3(tangent2D.x, 0, tangent2D.y).normalize();

// Move object to current point
const point2D = curve.getPointAt(progress);
object.position.set(point2D.x, 0, point2D.y);

// Look in the direction of the tangent vector
const target = object.position.clone().add(tangent3D);
object.lookAt(target);

4. Animating Along the Curve

To continuously orient an object as it travels, update progress inside your main render loop:

let progress = 0;
const speed = 0.002;
const tangent = new THREE.Vector2();
const point = new THREE.Vector2();

function animate() {
  requestAnimationFrame(animate);

  progress = (progress + speed) % 1;

  curve.getPointAt(progress, point);
  curve.getTangentAt(progress, tangent);

  object.position.set(point.x, point.y, 0);
  object.rotation.z = Math.atan2(tangent.y, tangent.x);

  renderer.render(scene, camera);
}

If your default object mesh does not point right along the X-axis (the zero-angle baseline for Math.atan2), offset the rotation by adding or subtracting an angle (e.g., + Math.PI / 2) to ensure its front faces the tangent direction.
