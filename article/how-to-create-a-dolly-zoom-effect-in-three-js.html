How to Create a Dolly Zoom Effect in Three.js

This guide explains how to implement the classic Vertigo effect (dolly zoom) in Three.js by mathematically synchronizing a PerspectiveCamera's field of view (FOV) with its distance from a target object. By keeping the apparent size of a central subject constant while transforming the background perspective, you create a disorienting visual distortion. Below, you will find the trigonometric principles behind the effect, the formulas required for execution, and a complete code implementation.

The Underlying Trigonometry

A dolly zoom works by altering the camera's field of view while simultaneously moving the camera forward or backward along its viewing axis. To keep the target object at an identical visual height on the screen, the camera frustum's height at the target's distance must remain constant.

In a perspective projection, the visible vertical height \(h\) at a distance \(d\) from the camera is expressed as:

\[h = 2 \times d \times \tan\left(\frac{\text{FOV}}{2}\right)\]

Where:

  • \(h\) is the visible vertical frustum height at the target plane.
  • \(d\) is the distance between the camera and the target object.
  • \(\text{FOV}\) is the camera's vertical field of view in radians.

If \(h\) remains constant, you can derive either parameter based on the other:

  1. Calculate distance from FOV: \[d = \frac{h}{2 \times \tan\left(\frac{\text{FOV} \times \pi}{360}\right)}\]

  2. Calculate FOV from distance: \[\text{FOV} = 2 \times \arctan\left(\frac{h}{2 \times d}\right) \times \left(\frac{180}{\pi}\right)\]

Step-by-Step Implementation

1. Measure the Initial Target Height

Before animating, capture the target distance and the current vertical field of view to lock in the constant frustum height.

import * as THREE from 'three';

// Assume camera and target are initialized
const camera = new THREE.PerspectiveCamera(45, window.innerWidth / window.innerHeight, 0.1, 1000);
const targetPosition = new THREE.Vector3(0, 0, 0);

// Set camera position along the Z-axis looking at the target
camera.position.set(0, 0, 10);
camera.lookAt(targetPosition);

// Calculate initial distance to target
const initialDistance = camera.position.distanceTo(targetPosition);

// Calculate and store the constant visible height at the target
const targetHeight = 2 * initialDistance * Math.tan(THREE.MathUtils.degToRad(camera.fov / 2));

2. Update FOV or Distance During Animation

You can drive the effect either by modulating the camera's Z-position and updating the FOV, or by modulating the FOV and updating the Z-position.

Approach A: Drive by Distance (Update FOV)

Moving the camera along the Z-axis and recalculating the camera's FOV dynamically:

function updateDollyZoomByDistance(newDistance) {
  // Update camera position along the Z-axis
  camera.position.z = targetPosition.z + newDistance;

  // Recalculate FOV to match the constant target height
  const fovInRadians = 2 * Math.atan(targetHeight / (2 * newDistance));
  camera.fov = THREE.MathUtils.radToDeg(fovInRadians);

  // Crucial: Update the projection matrix after modifying FOV
  camera.updateProjectionMatrix();
}
Approach B: Drive by FOV (Update Distance)

Varying the FOV directly (e.g., using a sine wave or scroll offset) and matching the camera's position:

function updateDollyZoomByFov(newFov) {
  camera.fov = newFov;

  // Recalculate distance based on new FOV
  const newDistance = targetHeight / (2 * Math.tan(THREE.MathUtils.degToRad(newFov / 2)));
  camera.position.z = targetPosition.z + newDistance;

  // Apply changes to the camera projection
  camera.updateProjectionMatrix();
}

Complete Render Loop Example

The following script integrates the dolly zoom into an active animation loop using an oscillating function:

import * as THREE from 'three';

// 1. Scene Setup
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// 2. Add Target Object and Background Context
const targetMesh = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshBasicMaterial({ color: 0xff0000, wireframe: true })
);
scene.add(targetMesh);

// Add background elements to make the perspective distortion visible
for (let i = -5; i <= 5; i++) {
  const bgMesh = new THREE.Mesh(
    new THREE.BoxGeometry(0.5, 0.5, 0.5),
    new THREE.MeshBasicMaterial({ color: 0x555555, wireframe: true })
  );
  bgMesh.position.set(i * 2, 0, -10);
  scene.add(bgMesh);
}

// 3. Initialize Dolly Zoom Parameters
const targetPosition = targetMesh.position;
camera.position.set(0, 0, 5);
camera.lookAt(targetPosition);

const initialDistance = camera.position.distanceTo(targetPosition);
const visibleHeight = 2 * initialDistance * Math.tan(THREE.MathUtils.degToRad(camera.fov / 2));

// 4. Animation Loop
function animate(time) {
  requestAnimationFrame(animate);

  // Oscillate camera distance between 2 and 10 units
  const distance = 6 + Math.sin(time * 0.002) * 4;
  
  // Set new camera position
  camera.position.z = targetPosition.z + distance;

  // Calculate new FOV based on visibleHeight constant
  const fovRad = 2 * Math.atan(visibleHeight / (2 * distance));
  camera.fov = THREE.MathUtils.radToDeg(fovRad);

  // Apply matrix update
  camera.updateProjectionMatrix();

  renderer.render(scene, camera);
}

animate(0);

Critical Rules to Remember

  • Always call camera.updateProjectionMatrix() immediately after modifying camera.fov. Three.js caches the projection matrix and will not reflect FOV changes without this call.
  • Javascript's Math.tan and Math.atan expect and return values in radians, while THREE.PerspectiveCamera.fov is defined in degrees. Convert between the two using THREE.MathUtils.degToRad and THREE.MathUtils.radToDeg.
