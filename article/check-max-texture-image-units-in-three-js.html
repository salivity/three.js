Check MAX_TEXTURE_IMAGE_UNITS in Three.js

Exceeding the maximum number of simultaneous texture units supported by a user's GPU is a common cause of fatal fragment shader compilation crashes in WebGL applications. Three.js abstracts low-level WebGL context queries through its internal capabilities module, allowing developers to inspect device limits before compiling materials. By accessing the maxTextures property directly from the renderer instance, you can dynamically budget your sampler uniforms, clamp multi-texture splatting, and ensure cross-device stability without triggering WebGL errors.

The Underlying Issue

Every GPU enforces a hard limit on how many texture image units the fragment stage can access simultaneously. In standard WebGL, this limit is retrieved via gl.getParameter(gl.MAX_TEXTURE_IMAGE_UNITS). While desktop GPUs commonly support 16 or 32 units, lower-end mobile devices might support as few as 8.

If your scene binds more sampler uniforms (such as albedo, normal, roughness, metalness, ambient occlusion, lightmaps, shadow maps, and custom effect masks) than the hardware allows, the shader fails to compile, rendering the object invisible or crashing the WebGL context entirely.

Accessing the Limit in Three.js

Three.js automatically queries the WebGL context during initialization and exposes this data via the WebGLCapabilities class attached to your renderer instance. The relevant parameter is mapped to renderer.capabilities.maxTextures.

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer();

// Access the MAX_TEXTURE_IMAGE_UNITS equivalent
const maxFragmentTextures = renderer.capabilities.maxTextures;

console.log(`Max Fragment Texture Units: ${maxFragmentTextures}`);

Implementing Dynamic Shader Guards

To prevent crashes, read this property before creating materials with variable texture counts or before defining preprocessor macros in custom ShaderMaterial instances.

import * as THREE from 'three';

function createTerrainMaterial(texturesArray, renderer) {
  const maxAvailable = renderer.capabilities.maxTextures;
  
  // Reserve texture units for standard scene passes (e.g., shadows, environment maps)
  const reservedUnits = 4;
  const safeTextureLimit = Math.max(0, maxAvailable - reservedUnits);

  // Clamp the active textures to prevent shader compilation failure
  const activeTextures = texturesArray.slice(0, safeTextureLimit);

  if (texturesArray.length > safeTextureLimit) {
    console.warn(
      `Hardware limit exceeded: Clamping textures from ${texturesArray.length} to ${safeTextureLimit}.`
    );
  }

  // Construct uniforms dynamically
  const uniforms = {};
  activeTextures.forEach((tex, index) => {
    uniforms[`layerTexture_${index}`] = { value: tex };
  });

  return new THREE.ShaderMaterial({
    defines: {
      TEXTURE_COUNT: activeTextures.length,
    },
    uniforms: uniforms,
    vertexShader: `
      varying vec2 vUv;
      void main() {
        vUv = uv;
        gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
      }
    `,
    fragmentShader: `
      varying vec2 vUv;
      #if TEXTURE_COUNT > 0
      uniform sampler2D layerTexture_0;
      #endif
      // Dynamically generated sampling logic here
      void main() {
        #if TEXTURE_COUNT > 0
        gl_FragColor = texture2D(layerTexture_0, vUv);
        #else
        gl_FragColor = vec4(1.0, 0.0, 1.0, 1.0); // Fallback color
        #endif
      }
    `,
  });
}

Key Strategies for Safe Texture Management

  • Reserve Overhead Units: Three.js uses texture units internally for features such as shadow maps, environment maps, and light probes. Never allocate 100% of maxTextures to custom user samplers.
  • Texture Atlasing: If your application regularly needs more textures than mobile GPUs provide, pack multiple visual maps into a single texture atlas to reduce the required sampler count.
  • Feature Degradation: Use the detected capability to selectively disable secondary effects—such as detail maps or ambient occlusion—on hardware where maxTextures is below a designated threshold.
