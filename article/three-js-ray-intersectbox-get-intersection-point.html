Three.js Ray.intersectBox: Get Intersection Point

In Three.js, determining where a ray strikes an axis-aligned bounding box (AABB) is a core task for collision detection, selection, and physics. The THREE.Ray.intersectBox() method calculates the exact point of contact along the ray's path. This article explains how to configure an AABB using THREE.Box3, cast a THREE.Ray, and use a target THREE.Vector3 to extract the precise 3D coordinates of the intersection.

The Method Signature

The intersectBox method is called directly on an instance of THREE.Ray:

ray.intersectBox( box, target );
  • box (THREE.Box3): The axis-aligned bounding box to test against.
  • target (THREE.Vector3): The vector that receives the resulting intersection coordinates if a hit occurs.
  • Return Value: Returns the target vector populated with the intersection point coordinates, or null if the ray does not intersect the box.

Step-by-Step Implementation

To calculate the intersection coordinate:

  1. Define the Bounding Box: Create or obtain a THREE.Box3. You can define custom minimum and maximum bounds or compute them from an existing mesh using box.setFromObject(mesh).
  2. Define the Ray: Create a THREE.Ray, defining its origin vector and a normalized direction vector.
  3. Create the Target Vector: Instantiate a THREE.Vector3 to hold the result. This prevents unnecessary memory allocation during repeated tests.
  4. Execute the Intersection: Call ray.intersectBox(box, target) and verify whether the output is non-null.

Code Example

import * as THREE from 'three';

// 1. Define the AABB (Box3)
const boxMin = new THREE.Vector3(-1, -1, -1);
const boxMax = new THREE.Vector3(1, 1, 1);
const aabb = new THREE.Box3(boxMin, boxMax);

// 2. Define the Ray
const rayOrigin = new THREE.Vector3(0, 0, 5);
const rayDirection = new THREE.Vector3(0, 0, -1).normalize();
const ray = new THREE.Ray(rayOrigin, rayDirection);

// 3. Prepare the target vector
const intersectionPoint = new THREE.Vector3();

// 4. Extract the intersection coordinate
const hit = ray.intersectBox(aabb, intersectionPoint);

if (hit !== null) {
    console.log(`Intersection found at: X: ${hit.x}, Y: ${hit.y}, Z: ${hit.z}`);
    // Output: Intersection found at: X: 0, Y: 0, Z: 1
} else {
    console.log('The ray missed the bounding box.');
}

Key Considerations

  • Coordinate Space: The THREE.Ray and THREE.Box3 must share the same coordinate space. If your mesh has world transformations, compute the box using box.setFromObject(mesh) to ensure the bounds are in world coordinates, and match them with a world-space ray.
  • Ray Origin Inside the Box: If the ray originates inside the Box3, intersectBox treats the ray's origin as the intersection point and writes the origin coordinates to the target vector.
  • Performance: Reusing a single THREE.Vector3 instance as the target argument across multiple ray checks avoids frequent garbage collection cycles, which is critical in real-time animation loops.
