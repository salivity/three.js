Computing Frenet Frames for Extrusion in Three.js

Extruding custom 2D cross-sections along 3D paths in Three.js often results in unexpected twisting, pinching, or orientation flips if the coordinate frames are calculated naively. This article explains how to compute and apply Frenet-Serret frames along a curve to establish a continuous, smooth coordinate system (Tangent, Normal, and Binormal vectors), enabling you to align and extrude custom cross-sectional geometry along any 3D path reliably.

Understanding Frenet Frames

A Frenet frame (or Frenet-Serret frame) is an orthonormal coordinate system attached to a point on a curve. It consists of three mutually perpendicular unit vectors:

  • Tangent (\(\mathbf{T}\)): Points in the direction of the curve's motion (the first derivative).
  • Normal (\(\mathbf{N}\)): Points in the direction of the curve's curvature (perpendicular to the tangent).
  • Binormal (\(\mathbf{B}\)): Orthogonal to both the tangent and the normal, computed via the cross product \(\mathbf{B} = \mathbf{T} \times \mathbf{N}\).

When extruding a 2D profile along a curve, these vectors define the orientation of the 2D shape's plane at each step, mapping local 2D \((x, y)\) coordinates to 3D world space.

Using Native Curve Methods

Three.js provides built-in methods on its THREE.Curve classes to generate these frames. Rather than calculating strict mathematical Frenet frames—which suffer from severe discontinuities and 180-degree flips at inflection points where curvature is zero—Three.js implements a parallel transport frame algorithm (minimizing rotation) via computeFrenetFrames.

To generate frames along a curve:

import * as THREE from 'three';

// 1. Define a 3D curve
const curve = new THREE.CatmullRomCurve3([
    new THREE.Vector3(-10, 0, 10),
    new THREE.Vector3(-5, 5, 5),
    new THREE.Vector3(0, 0, 0),
    new THREE.Vector3(5, -5, 5),
    new THREE.Vector3(10, 0, 10)
]);

// 2. Define the number of subdivisions along the curve
const segments = 100;
const closed = false;

// 3. Compute Frenet frames
const frenetFrames = curve.computeFrenetFrames(segments, closed);

// frenetFrames contains three arrays of THREE.Vector3:
// frenetFrames.tangents: Array of length segments + 1
// frenetFrames.normals: Array of length segments + 1
// frenetFrames.binormals: Array of length segments + 1

Aligning Cross-Sections Using the Frames

To project a 2D profile (such as a circle, rectangle, or arbitrary star shape) along the curve, iterate through the subdivision steps and apply the frame's orientation matrix to each vertex of the cross-section.

const shapeVertices = [
    new THREE.Vector2(-1, -1),
    new THREE.Vector2(1, -1),
    new THREE.Vector2(1, 1),
    new THREE.Vector2(-1, 1)
];

const extrudedPoints = [];

for (let i = 0; i <= segments; i++) {
    const u = i / segments;
    const pointOnCurve = curve.getPointAt(u);

    const N = frenetFrames.normals[i];
    const B = frenetFrames.binormals[i];
    const T = frenetFrames.tangents[i];

    // Construct a rotation matrix from the basis vectors
    const orientationMatrix = new THREE.Matrix4().makeBasis(N, B, T);

    // Transform each cross-section vertex to 3D space
    for (let j = 0; j < shapeVertices.length; j++) {
        const localVertex = new THREE.Vector3(shapeVertices[j].x, shapeVertices[j].y, 0);
        
        // Rotate the vertex according to the frame
        localVertex.applyMatrix4(orientationMatrix);
        
        // Translate to the curve position
        localVertex.add(pointOnCurve);
        
        extrudedPoints.push(localVertex);
    }
}

Addressing Extrusion Artifacts

While computeFrenetFrames mitigates sudden flips along continuous non-straight curves, straight-line segments or closed loops can still produce edge cases:

  1. Initial Vector Degeneracy: If the curve starts as a straight line along the Z-axis, the cross-product calculation used for the initial normal can fail if arbitrary reference vectors align with the tangent. You can manually seed frenetFrames.normals[0] with an explicit perpendicular vector if your path starts along a cardinal axis.
  2. Closed Loop Alignment: For closed curves (closed = true), parallel transport may cause the final frame to be rotated relative to the initial frame when returning to the start point. To fix this, calculate the angle difference between the initial and final normals and distribute an angular correction linearly across all frames along the path.
