Manual AnimationMixer Stepping with setTime in Three.js

In Three.js, skeletal and morph animations are typically advanced automatically within a requestAnimationFrame loop using mixer.update(deltaTime). However, specific use cases—such as frame-by-frame rendering, animation scrubbing, timeline scrubbing tools, or video exporting—require precise, deterministic control over the animation state. This guide demonstrates how to manually advance an AnimationMixer by a fixed increment using the absolute setTime method.

Understanding setTime vs update

The standard mixer.update(deltaTime) method receives a relative change in time and advances the mixer's internal clock automatically.

In contrast, mixer.setTime(timeInSeconds) forces the mixer to evaluate the scene at an absolute point in time. When using setTime, the mixer does not automatically increment its internal clock based on previous frames; you are entirely responsible for tracking the elapsed time and passing the desired absolute timestamp.

Implementation

To step the mixer forward manually:

  1. Maintain a variable to track the current animation time.
  2. Define your desired step increment (for example, 1 / 60 for 60 frames per second).
  3. Increase the current time variable by the increment.
  4. Pass the new time to mixer.setTime().
import * as THREE from 'three';

// 1. Setup mixer and load your action
const mixer = new THREE.AnimationMixer(model);
const action = mixer.clipAction(clip);
action.play();

// 2. Track time and define step size
let currentTime = 0;
const stepIncrement = 1 / 30; // Step forward by 1/30th of a second (~33.3ms)

// 3. Step function
function stepForward() {
  currentTime += stepIncrement;

  // Handle looping if necessary
  const duration = clip.duration;
  if (currentTime > duration) {
    currentTime = currentTime % duration;
  }

  // Set the mixer to the absolute timestamp
  mixer.setTime(currentTime);
}

Important Considerations

  • Clip Duration and Looping: If your animation is meant to loop, wrap currentTime using the modulo operator (currentTime % clip.duration) to prevent the time value from increasing indefinitely. If the animation should stop at the end, use Math.min(currentTime + stepIncrement, clip.duration) to clamp the value.
  • Rendering Updates: Calling mixer.setTime() updates the transforms of the target 3D objects, but you must still trigger renderer.render(scene, camera) afterward to visually reflect the new frame.
  • Root Motion and Events: When jumping across large intervals or stepping backwards with setTime, animation events (like loop markers or clip finish triggers) may not fire in the same sequential order as they do when using update(). Keep increments small and forward-moving if event dispatching is required.
