Customize ArcballControls Gizmos in Three.js

Three.js includes ArcballControls for intuitive, trackball-style camera manipulation, complete with built-in 3D visual gizmos that guide user rotation and orientation. While ArcballControls does not provide direct public configuration methods for its visual theme, you can customize the colors, line widths, and opacity of these gizmos by accessing and modifying the internal gizmo group. This guide outlines how to locate the gizmo structures, update their materials, target specific axes, and apply custom styling to seamlessly match your application's user interface.

Accessing the Gizmo Group

When an instance of ArcballControls is initialized, it builds an internal scene object stored under the property _gizmos. This object is a standard THREE.Group that contains all the lines, rings, and axis indicators rendered during interaction.

import * as THREE from 'three';
import { ArcballControls } from 'three/addons/controls/ArcballControls.js';

const controls = new ArcballControls(camera, renderer.domElement, scene);

Because controls._gizmos is a standard Three.js group, you can inspect and modify its contents immediately after instantiating the controls.

Traversing and Updating Gizmo Materials

To apply a uniform color or material setting across all gizmo components, traverse the children of controls._gizmos and update their material properties:

function applyGizmoTheme(controls, hexColor, opacity = 1.0) {
  controls._gizmos.traverse((child) => {
    if (child.isLine || child.isMesh) {
      if (child.material) {
        // Clone the material to prevent affecting shared resources
        child.material = child.material.clone();
        child.material.color.setHex(hexColor);
        child.material.opacity = opacity;
        child.material.transparent = opacity < 1.0;
        child.material.depthTest = false; // Ensures visibility over scene objects
      }
    }
  });
}

// Example usage:
applyGizmoTheme(controls, 0x00ffcc, 0.8);

Cloning each material ensures that your modifications apply cleanly without unintentional side effects if materials are reused internally.

Customizing Specific Components (Axes and Circles)

The _gizmos group contains multiple distinct elements:

  • The base sphere outline (circular guides representing the virtual trackball).
  • Coordinate axis lines (representing local/world orientation).
  • Dynamic interaction rings that display during rotations.

You can customize individual parts by inspecting each child element's geometry or its position within controls._gizmos.children:

controls._gizmos.children.forEach((child) => {
  if (child.isLine) {
    // Modify wireframe circles vs coordinate axes based on vertex counts or names
    const positionAttribute = child.geometry.getAttribute('position');

    if (positionAttribute && positionAttribute.count > 2) {
      // Typically the circular/curved outlines
      child.material.color.setHex(0x3b82f6); // Modern blue
      child.material.linewidth = 2; // Note: Canvas/WebGL limits apply to linewidth
    } else {
      // Typically axis indicators
      child.material.color.setHex(0xf43f5e); // Accent red
    }
  }
});

Adjusting Gizmo Size and Visibility

In addition to colors, you can control the visual presence of the gizmos using exposed methods and properties on ArcballControls:

  • controls.setGizmosVisible(boolean): Toggles whether the gizmos are displayed during interaction.
  • controls.scaleFactor: Controls the scaling factor of the gizmos relative to the canvas size. Increasing or decreasing this value changes the overall visual footprint.
  • controls.cursorRadius: Modifies the boundary area used for trackball calculations, adjusting the visual balance between screen space and interaction zones.
// Adjust the scale of the gizmos
controls.scaleFactor = 1.2;

// Hide or show gizmos dynamically
controls.setGizmosVisible(true);

Complete Styling Implementation

Below is a complete implementation showing how to initialize ArcballControls, restyle all gizmo lines with custom colors, and maintain clean rendering:

import * as THREE from 'three';
import { ArcballControls } from 'three/addons/controls/ArcballControls.js';

// Setup scene, camera, renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Initialize ArcballControls
const controls = new ArcballControls(camera, renderer.domElement, scene);

// Function to restyle the gizmo visuals
function setCustomGizmoStyle(arcballInstance, primaryColor, accentColor) {
  if (!arcballInstance._gizmos) return;

  arcballInstance._gizmos.traverse((object) => {
    if (object.material) {
      object.material = object.material.clone();
      
      // Differentiate rings from linear axes
      const isCircle = object.geometry?.attributes?.position?.count > 2;
      const targetColor = isCircle ? primaryColor : accentColor;

      object.material.color.set(targetColor);
      object.material.transparent = true;
      object.material.opacity = 0.75;
    }
  });
}

// Apply styling: Cyan primary rings, Magenta secondary axes
setCustomGizmoStyle(controls, '#06b6d4', '#d946ef');

// Position camera
camera.position.set(0, 0, 5);

// Render loop
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();
