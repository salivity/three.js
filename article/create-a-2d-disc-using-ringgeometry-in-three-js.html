Create a 2D Disc Using RingGeometry in Three.js

This article explains how to create a solid 2D disc in Three.js using the RingGeometry class. While Three.js offers a dedicated CircleGeometry, you can easily produce an identical 2D disc with RingGeometry by setting the inner radius to zero. Below, you will find the exact geometry parameters, a complete code implementation, and tips for controlling the disc's appearance and orientation.

The Concept

The THREE.RingGeometry constructor defines a two-dimensional ring flat on the XY plane. It accepts several arguments:

RingGeometry(innerRadius, outerRadius, thetaSegments, phiSegments, thetaStart, thetaLength)

To transform this ring into a solid disc, set the innerRadius parameter to 0. This collapses the center hole completely, leaving a solid circular plane spanning from the center point to the outerRadius.

Implementation Example

Here is a straightforward example of creating and adding a 2D disc to a Three.js scene:

import * as THREE from 'three';

// 1. Define geometry parameters
const innerRadius = 0;       // Set to 0 to create a solid disc
const outerRadius = 5;       // The radius of the disc
const thetaSegments = 32;    // Number of segments (higher = smoother edge)

// 2. Create the RingGeometry
const geometry = new THREE.RingGeometry(innerRadius, outerRadius, thetaSegments);

// 3. Create a material
// Using DoubleSide ensures the disc is visible from both the front and back
const material = new THREE.MeshBasicMaterial({ 
  color: 0x0077ff, 
  side: THREE.DoubleSide 
});

// 4. Combine into a mesh and add to the scene
const disc = new THREE.Mesh(geometry, material);
scene.add(disc);

Key Parameter Breakdown

  • innerRadius (Float): Setting this to 0 makes the geometry a solid disc. Any value greater than zero will cut a circular hole in the center.
  • outerRadius (Float): Controls the overall size of the disc from its center to the edge.
  • thetaSegments (Integer): Controls how many triangular segments form the perimeter. The default is 8. A value between 32 and 64 provides a smooth circular appearance for most use cases.
  • phiSegments (Integer): Specifies the number of concentric rings dividing the surface. When innerRadius is 0, the default value of 1 is usually sufficient unless you plan to deform the vertices.
  • thetaStart and thetaLength (Float): Optional values defined in radians. You can use these to render partial discs, such as a semi-circle (thetaLength: Math.PI).

Orientation and Visibility

By default, RingGeometry is constructed on the XY plane facing along the positive Z-axis.

  • Dual-sided rendering: 2D planes are one-sided by default. If the camera looks at the back of the disc, it will be invisible unless you set side: THREE.DoubleSide in your material settings.
  • Laying the disc flat: To position the disc flat on the ground (XZ plane), rotate the mesh along the X-axis:
disc.rotation.x = -Math.PI / 2;
