How to Make an Open-Ended Cone in Three.js

In Three.js, the ConeGeometry class creates 3D cone meshes that feature a closed circular base by default. This guide explains how to remove that base to create a hollow bottom by adjusting the openEnded parameter in the geometry constructor, along with key material settings required to properly render the interior surfaces.

Understanding the ConeGeometry Constructor

The ConeGeometry constructor accepts seven parameters in the following order:

ConeGeometry(radius, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)

The fifth parameter, openEnded, is a boolean value that determines whether the base of the cone is capped or left open.

  • false (default): Generates a closed cone with a solid bottom face.
  • true: Omits the base geometry entirely, creating a hollow, open-ended cone.

Configuring the Geometry

To create a hollow cone, pass true as the fifth argument when instantiating the geometry. You must explicitly define the first four parameters (radius, height, radialSegments, and heightSegments) to reach the openEnded argument.

import * as THREE from 'three';

// Define geometry parameters
const radius = 5;
const height = 10;
const radialSegments = 32;
const heightSegments = 1;
const openEnded = true;

// Create the open-ended cone geometry
const geometry = new THREE.ConeGeometry(
  radius,
  height,
  radialSegments,
  heightSegments,
  openEnded
);

Material Considerations for Hollow Geometries

When a cone is hollow, the camera can see both the exterior and interior faces. By default, Three.js materials are set to THREE.FrontSide, which culls the back faces of polygons to optimize rendering. This makes the inside of a hollow cone appear invisible.

To ensure both the outer and inner walls of the hollow cone are rendered, set the material's side property to THREE.DoubleSide:

const material = new THREE.MeshStandardMaterial({
  color: 0xff0000,
  side: THREE.DoubleSide
});

const coneMesh = new THREE.Mesh(geometry, material);
scene.add(coneMesh);

Complete Implementation

Here is a self-contained example demonstrating how to initialize a hollow cone mesh:

import * as THREE from 'three';

// 1. Create the hollow geometry
const coneGeometry = new THREE.ConeGeometry(3, 8, 32, 1, true);

// 2. Apply a material that renders both inside and outside faces
const coneMaterial = new THREE.MeshStandardMaterial({
  color: 0x0077ff,
  roughness: 0.4,
  metalness: 0.1,
  side: THREE.DoubleSide
});

// 3. Assemble the mesh and add it to the scene
const hollowCone = new THREE.Mesh(coneGeometry, coneMaterial);
scene.add(hollowCone);

By toggling openEnded to true and enabling THREE.DoubleSide on the material, the geometry renders as a hollow cone with fully visible inner and outer surfaces.
