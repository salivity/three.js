Three.js AnimationObjectGroup: Share AnimationAction

This article explores Three.js's AnimationObjectGroup, an efficient utility class designed to synchronize animations across multiple 3D objects. You will learn what AnimationObjectGroup is, how it enables several meshes to share a single AnimationAction and AnimationMixer, and how to implement it to optimize performance in your WebGL scenes.

What is an AnimationObjectGroup?

In standard Three.js implementations, an AnimationMixer is tied to a single root scene graph object (such as a mesh or a group). If you have dozens of identical objects—such as spinning coins, swaying trees, or marching units—creating a separate AnimationMixer and AnimationAction for each object introduces significant CPU overhead and redundant memory usage.

AnimationObjectGroup acts as an intermediary container that represents a collection of objects sharing the same animation state. Instead of passing an individual mesh to the AnimationMixer, you pass an instance of AnimationObjectGroup. Any animation applied to the group is automatically broadcast and applied to all member objects simultaneously.

How it Enables Shared AnimationActions

Normally, an AnimationAction controls the playback of an AnimationClip on the single root target bound to its mixer. When an AnimationObjectGroup is assigned as the root target of an AnimationMixer, the mixer's internal bindings map track outputs to the corresponding properties across all meshes registered inside the group.

As a result:

  1. Only one AnimationMixer needs to be updated in your render loop via mixer.update(delta).
  2. Only one AnimationAction evaluates the keyframe tracks.
  3. The calculated property updates (position, rotation, scale, or morph targets) are efficiently applied to every object currently in the group.

Implementation Example

Below is a step-by-step example showing how to set up and use AnimationObjectGroup:

import * as THREE from 'three';

// 1. Create your meshes
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0x00ff00 });

const meshA = new THREE.Mesh(geometry, material);
const meshB = new THREE.Mesh(geometry, material);

meshA.position.set(-2, 0, 0);
meshB.position.set(2, 0, 0);

scene.add(meshA);
scene.add(meshB);

// 2. Initialize the AnimationObjectGroup and add meshes
const animationGroup = new THREE.AnimationObjectGroup();
animationGroup.add(meshA, meshB);

// 3. Bind the AnimationMixer to the AnimationObjectGroup
const mixer = new THREE.AnimationMixer(animationGroup);

// 4. Create an AnimationClip (e.g., a simple Y-axis rotation)
const track = new THREE.QuaternionKeyframeTrack(
  '.quaternion',
  [0, 1, 2],
  [
    0, 0, 0, 1,
    0, 1, 0, 0,
    0, 0, 0, 1
  ]
);
const clip = new THREE.AnimationClip('Rotate', 2, [track]);

// 5. Create and play the shared AnimationAction
const action = mixer.clipAction(clip);
action.play();

// 6. Update the mixer in the render loop
function animate() {
  requestAnimationFrame(animate);
  mixer.update(clock.getDelta());
  renderer.render(scene, camera);
}

Dynamic Membership Management

AnimationObjectGroup supports dynamic addition and removal of objects at runtime without disrupting playback:

  • Adding an object: Call animationGroup.add(mesh). The mesh immediately snaps into sync with the current animation playback time.
  • Removing an object: Call animationGroup.remove(mesh). The animation ceases updating that specific mesh, leaving it at its last animated state.

Best Practices and Limitations

  • Uniform Object Structure: All objects added to an AnimationObjectGroup must share the property names and hierarchy defined in the AnimationClip tracks. If an animated property exists in the clip but not on an object in the group, that object will not receive the update.
  • Synchronized Playback: Because all objects share a single AnimationAction, they animate completely in sync. If you require varied time offsets or independent speeds among meshes, you must instantiate individual AnimationMixer objects for each mesh instead.
