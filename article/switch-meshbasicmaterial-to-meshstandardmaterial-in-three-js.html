Switch MeshBasicMaterial to MeshStandardMaterial in Three.js

Transitioning from MeshBasicMaterial to MeshStandardMaterial allows your Three.js objects to interact realistically with dynamic light sources using physically based rendering (PBR). This guide outlines the exact steps required to upgrade your project: replacing the material definitions, adding essential scene lights to prevent objects from rendering pitch black, configuring roughness and metalness parameters, and enabling real-time shadow maps.

1. Replace the Material Constructor

MeshBasicMaterial ignores all scene lighting. To enable lighting calculations, replace instances of MeshBasicMaterial with MeshStandardMaterial.

Before:

const material = new THREE.MeshBasicMaterial({
  color: 0xffffff,
  map: texture
});

After:

const material = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  map: texture,
  roughness: 0.5,
  metalness: 0.1
});

Common properties such as color, map, wireframe, transparent, and opacity carry over directly without modification.

2. Add Light Sources to the Scene

MeshStandardMaterial requires light to be visible. If you switch materials without adding lights, your meshes will render completely black.

At a minimum, add an ambient light for base visibility and a directional light to create depth:

// Base ambient illumination
const ambientLight = new THREE.AmbientLight(0xffffff, 0.4);
scene.add(ambientLight);

// Key dynamic light
const directionalLight = new THREE.DirectionalLight(0xffffff, 1.2);
directionalLight.position.set(5, 10, 7.5);
scene.add(directionalLight);

You can also use other dynamic lights such as THREE.PointLight or THREE.SpotLight depending on the scene requirements.

3. Tune PBR Properties

Unlike basic materials, MeshStandardMaterial calculates reflection based on physical surface properties:

  • roughness (0.0 to 1.0): Controls surface smoothness. A value of 0.0 creates mirror-like reflections, while 1.0 creates a completely diffuse, matte appearance.
  • metalness (0.0 to 1.0): Controls metallic reflection. Non-metallic surfaces (plastic, wood, stone) should generally be set to 0.0, while raw metals should be set close to 1.0.
material.roughness = 0.4;
material.metalness = 0.2;

4. Utilize Advanced Lighting Maps (Optional)

To take full advantage of dynamic lighting, leverage the additional texture slots supported by MeshStandardMaterial:

  • normalMap: Adds surface detail and bumps without increasing polygon counts.
  • roughnessMap: Varies shininess across different areas of the model.
  • metalnessMap: Defines which parts of the surface are metallic.
  • aoMap: Adds ambient occlusion to simulate contact shadows in crevices.
material.normalMap = normalTexture;
material.roughnessMap = roughnessTexture;

5. Enable Real-Time Shadows

Dynamic lights can cast real-time shadows when using MeshStandardMaterial. To enable this feature:

  1. Enable shadow maps on the WebGL renderer:
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
  1. Configure the light source:
directionalLight.castShadow = true;
directionalLight.shadow.mapSize.width = 1024;
directionalLight.shadow.mapSize.height = 1024;
  1. Enable shadow casting and receiving on your meshes:
mesh.castShadow = true;
mesh.receiveShadow = true;

6. Verify Color Space Settings

When moving to dynamic lighting and standard materials, ensure linear workflow colors are properly managed in newer Three.js versions:

renderer.outputColorSpace = THREE.SRGBColorSpace;
texture.colorSpace = THREE.SRGBColorSpace;

Using the correct color space ensures that textures and dynamic light calculations do not appear washed out or overly dark.
