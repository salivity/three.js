How to Project a Vector3 onto a Plane in Three.js

Projecting a 3D point (THREE.Vector3) onto a mathematical plane (THREE.Plane) in Three.js is straightforward thanks to built-in geometric utility methods. This process calculates the orthogonal projection of a point in 3D space, finding the closest point that lies directly on the specified plane. By utilizing the projectPoint() method provided by the THREE.Plane class, you can obtain the resulting 3D coordinates aligned with the plane's surface without having to manually calculate dot products or normal vector scaling.

Using the projectPoint Method

The THREE.Plane class provides the projectPoint(point, target) method. It takes the original Vector3 you want to project and an existing Vector3 target instance where the resulting coordinates will be stored.

import * as THREE from 'three';

// 1. Define the mathematical plane
// Example: An XZ ground plane where the normal points straight up along the Y axis
const normal = new THREE.Vector3(0, 1, 0);
const constant = 0; // Distance from the origin along the normal
const plane = new THREE.Plane(normal, constant);

// 2. Define the 3D point to project
const point = new THREE.Vector3(12, 45, -8);

// 3. Create a target vector to store the result
const projectedPoint = new THREE.Vector3();

// 4. Project the point onto the plane
plane.projectPoint(point, projectedPoint);

console.log(projectedPoint); // Outputs: Vector3 { x: 12, y: 0, z: -8 }

Creating Planes from Points

If your plane is not defined by a simple normal and constant, you can construct a THREE.Plane using existing geometry or spatial points:

  • From three coplanar points: 
    const plane = new THREE.Plane().setFromCoplanarPoints(pointA, pointB, pointC);
  • From a normal vector and a point on the plane: 
    const plane = new THREE.Plane().setFromNormalAndCoplanarPoint(normalVector, pointOnPlane);

Once created, plane.projectPoint(point, projectedPoint) works identically regardless of how the plane was initialized.

Converting the 3D Result to 2D Surface Coordinates

The projectPoint method outputs a THREE.Vector3 that lies in 3D space on the plane. If you need local 2D (u, v) coordinates on the plane itself:

  1. Establish a 2D coordinate system on the plane using an origin point and two orthogonal basis vectors lying on the plane (typically derived using the plane's normal).
  2. Calculate the difference between the projected point and your plane origin.
  3. Compute the dot product of that difference vector with each of the two basis vectors to find the local X and Y (or U and V) 2D offsets.
