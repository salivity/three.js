How to Implement Screen-Space Reflections in Three.js

Screen-space reflections (SSR) add realistic real-time reflections to 3D scenes by calculating reflected light using only the data available in the current screen buffer (depth, normals, and color). This guide explains how to implement SSR as a post-processing effect in Three.js using the built-in SSRPass and EffectComposer, detailing the required setup, material adjustments, pass configuration, and the final render loop.

1. Install and Import Dependencies

Three.js includes the SSRPass in its addons directory. To begin, import Three.js alongside EffectComposer, RenderPass, and SSRPass from the addons module.

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { SSRPass } from 'three/addons/postprocessing/SSRPass.js';

2. Scene and Renderer Setup

Configure your WebGLRenderer and ensure that your scene meshes have materials capable of reflecting light, such as MeshStandardMaterial or MeshPhysicalMaterial.

const renderer = new THREE.WebGLRenderer({ antialias: false });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
document.body.appendChild(renderer.domElement);

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 5, 10);

3. Mesh Selection for Reflections

SSRPass improves performance by allowing you to designate specific meshes that receive or generate reflections using a selection array:

const reflectiveObjects = [];

const groundGeometry = new THREE.PlaneGeometry(20, 20);
const groundMaterial = new THREE.MeshStandardMaterial({
  color: 0x222222,
  roughness: 0.1,
  metalness: 0.8
});
const ground = new THREE.Mesh(groundGeometry, groundMaterial);
ground.rotation.x = -Math.PI / 2;
scene.add(ground);

reflectiveObjects.push(ground);

4. Configuring EffectComposer and SSRPass

Create the EffectComposer pipeline, attach a base RenderPass, and instantiate SSRPass. The selects parameter dictates which meshes are included in the reflection calculations.

const composer = new EffectComposer(renderer);

// Add base scene render pass
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// Configure SSRPass options
const ssrPass = new SSRPass({
  renderer,
  scene,
  camera,
  width: window.innerWidth,
  height: window.innerHeight,
  groundReflector: null,
  selects: reflectiveObjects
});

// Fine-tune SSR visual properties
ssrPass.thickness = 0.018;
ssrPass.maxDistance = 50;
ssrPass.opacity = 0.8;
ssrPass.surfceRoughness = 0.2; // Note: specific spelling used in Three.js SSRPass

composer.addPass(ssrPass);

5. Tuning Key SSR Parameters

  • thickness: Determines how thick an object is considered during depth ray-marching. Lower values reduce ray-marching artifacts behind objects.
  • maxDistance: Sets the maximum distance a reflected ray travels. Reducing this improves performance.
  • surfceRoughness: Sets the cutoff threshold for roughness; surfaces rougher than this value will skip reflection calculations.
  • opacity: Controls the overall blending strength of the screen-space reflection over the base render.

6. Managing Window Resizing

Update both the camera aspect ratio and the sizes of the renderer and composer when the browser window changes dimensions:

window.addEventListener('resize', () => {
  const width = window.innerWidth;
  const height = window.innerHeight;

  camera.aspect = width / height;
  camera.updateProjectionMatrix();

  renderer.setSize(width, height);
  composer.setSize(width, height);
});

7. Updating the Animation Loop

Replace your standard renderer.render(scene, camera) call with composer.render() inside the request animation frame loop:

function animate() {
  requestAnimationFrame(animate);
  composer.render();
}

animate();

SSR relies strictly on geometry visible in the current camera frustum. Any elements occluded or off-screen will not appear in the reflections. Combining SSR with a static environment map ensures consistent reflection coverage across hidden areas.
