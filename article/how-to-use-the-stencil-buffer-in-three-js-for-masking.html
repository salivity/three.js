How to Use the Stencil Buffer in Three.js for Masking

This guide explains how to configure the WebGL stencil buffer in Three.js to mask out specific rendering areas. By utilizing material stencil properties, controlling render orders, and defining pass operations, you can create portals, cross-sections, and custom clipping regions that selectively show or hide geometry.

1. Enable the Stencil Buffer

The stencil buffer must be active on the WebGL renderer. While Three.js enables it by default, you can explicitly ensure it is enabled during renderer instantiation:

const renderer = new THREE.WebGLRenderer({ stencil: true });

2. Configure the Mask Material

To define the area acting as the mask, create a mesh with a material configured to write values into the stencil buffer without drawing visible color or depth.

const maskMaterial = new THREE.MeshBasicMaterial({
  colorWrite: false, // Prevents rendering visible color
  depthWrite: false, // Prevents writing to the depth buffer
  stencilWrite: true,
  stencilRef: 1,
  stencilFunc: THREE.AlwaysStencilFunc, // Always passes to write the value
  stencilZPass: THREE.ReplaceStencilOp, // Writes the stencilRef value where drawn
});

const maskMesh = new THREE.Mesh(maskGeometry, maskMaterial);
maskMesh.renderOrder = 0; // Ensure mask renders before the masked object
scene.add(maskMesh);

Key properties used:

  • stencilWrite: Enables writing to the stencil buffer.
  • stencilRef: The integer reference value to write or compare against.
  • stencilFunc: Evaluates when the stencil test passes. THREE.AlwaysStencilFunc ensures it always writes.
  • stencilZPass: Dictates what happens when both depth and stencil tests pass. THREE.ReplaceStencilOp replaces the buffer value with stencilRef.

3. Configure the Target Material

Next, configure the objects that should only be visible inside (or outside) the masked region. The target material reads from the stencil buffer and checks if pixels match the reference value.

const targetMaterial = new THREE.MeshStandardMaterial({
  color: 0x00ff00,
  stencilWrite: true,
  stencilRef: 1,
  stencilFunc: THREE.EqualStencilFunc, // Only renders where stencil buffer == 1
});

const targetMesh = new THREE.Mesh(targetGeometry, targetMaterial);
targetMesh.renderOrder = 1; // Must render after the mask writes to the buffer
scene.add(targetMesh);

Setting stencilFunc to THREE.EqualStencilFunc ensures the target mesh is only drawn on screen pixels where the stencil buffer equals 1. To invert the mask (rendering everything except inside the mask), change stencilFunc to THREE.NotEqualStencilFunc.

4. Manage Render Order and Clearing

Proper execution order is critical. The mask object must always render before the target object. Explicitly set renderOrder on meshes to control drawing priority independent of their scene graph hierarchy:

  • Assign a lower renderOrder (e.g., 0) to the mask mesh.
  • Assign a higher renderOrder (e.g., 1) to the geometry being masked.

If you are using multiple masks per frame across different render passes or viewports, clear the stencil buffer manually before each pass using renderer.clearStencil().
