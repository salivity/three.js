How to Use Matrix4.makeRotationAxis in Three.js

This guide explains how to use the Matrix4.makeRotationAxis() method in Three.js to rotate a 3D object around an arbitrary custom axis. You will learn the mechanics behind creating a rotation matrix from a normalized direction vector, how to define your rotation angle in radians, and how to apply the resulting matrix directly to an Object3D to transform your mesh accurately in 3D space.

Understanding Matrix4.makeRotationAxis

The Matrix4.makeRotationAxis(axis, theta) method sets a 4x4 matrix as a pure rotation transform around an arbitrary vector (axis) by a specified angle (theta) in radians.

For the rotation matrix to calculate correctly without introducing scaling or distortion, the axis vector must be normalized (having a unit length of 1).

Step-by-Step Implementation

To rotate an object using this method:

  1. Define the Axis: Create a THREE.Vector3 defining the direction of your custom axis and call .normalize().
  2. Define the Angle: Determine the rotation angle in radians (convert from degrees using THREE.MathUtils.degToRad() if needed).
  3. Generate the Matrix: Create an empty THREE.Matrix4 and call makeRotationAxis(axis, angle).
  4. Apply to the Object: Use object.applyMatrix4(matrix) to multiply the object's existing transformation matrix by the newly created rotation matrix.

Code Example

import * as THREE from 'three';

// 1. Create your mesh
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00, wireframe: true });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 2. Define an arbitrary rotation axis and normalize it
const customAxis = new THREE.Vector3(1, 2, -1).normalize();

// 3. Define the angle in radians (e.g., 45 degrees)
const angleInRadians = THREE.MathUtils.degToRad(45);

// 4. Create the rotation matrix
const rotationMatrix = new THREE.Matrix4();
rotationMatrix.makeRotationAxis(customAxis, angleInRadians);

// 5. Apply the matrix to the object
cube.applyMatrix4(rotationMatrix);

Continuous Rotation in an Animation Loop

When animating continuous rotation around an arbitrary axis, create the axis and matrix once outside the loop to avoid garbage collection overhead, then apply it on each frame:

const axis = new THREE.Vector3(1, 1, 0).normalize();
const stepAngle = 0.02; // Radians per frame
const stepRotationMatrix = new THREE.Matrix4().makeRotationAxis(axis, stepAngle);

function animate() {
    requestAnimationFrame(animate);

    // Incrementally rotate the object around the custom axis
    cube.applyMatrix4(stepRotationMatrix);

    renderer.render(scene, camera);
}
animate();

Crucial Considerations

  • Local Origin: applyMatrix4 rotates the object around its own local origin (0, 0, 0). If you need to rotate around an arbitrary axis located at a specific point in world space, you must translate the object to that pivot point, apply the rotation matrix, and translate it back.
  • Transform Decomposition: Calling object.applyMatrix4() automatically decomposes the resulting matrix into the object's position, quaternion, and scale properties, keeping its transform properties in sync.
