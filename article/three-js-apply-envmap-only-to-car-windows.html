Three.js: Apply EnvMap Only to Car Windows

Applying environment reflections to specific parts of a 3D model in Three.js requires isolating materials rather than assigning a global environment map to the entire scene. By loading an environment texture and attaching it directly to the window material’s envMap property while leaving the car body materials unaffected, you can achieve realistic glass reflections without impacting the rest of the vehicle.

1. Load the Environment Map Directly

Do not assign the loaded texture to scene.environment, as this automatically applies reflections to all physical and standard materials across the scene. Instead, keep the texture as an independent variable using RGBELoader (for HDR maps) or CubeTextureLoader.

import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';

let windowEnvMap = null;

new RGBELoader().load('textures/environment.hdr', (texture) => {
    texture.mapping = THREE.EquirectangularReflectionMapping;
    windowEnvMap = texture;
    applyWindowReflections(carModel);
});

2. Traverse the Model and Target Window Meshes

Load your car model using GLTFLoader. Traverse the hierarchy to find the window meshes by name, or inspect their materials to locate the glass components.

function applyWindowReflections(car) {
    car.traverse((child) => {
        if (child.isMesh) {
            // Identify window meshes by object name or material name
            if (child.name.toLowerCase().includes('window') || child.name.toLowerCase().includes('glass')) {
                setupGlassMaterial(child);
            } else {
                // Ensure car body materials do not inherit any reflection map
                if (child.material) {
                    child.material.envMap = null;
                    child.material.needsUpdate = true;
                }
            }
        }
    });
}

3. Configure the Window Material

Assign the environment map directly to the window's material. Use MeshPhysicalMaterial for the most realistic glass behavior, setting low roughness, high transmission or transparency, and assigning the envMap.

function setupGlassMaterial(mesh) {
    // Clone or replace the existing material to avoid shared material issues
    mesh.material = new THREE.MeshPhysicalMaterial({
        color: 0xffffff,
        metalness: 0.1,
        roughness: 0.05,
        transmission: 0.9,
        transparent: true,
        opacity: 1,
        ior: 1.5,
        envMap: windowEnvMap,
        envMapIntensity: 1.5
    });

    mesh.material.needsUpdate = true;
}

Key Considerations

  • Shared Materials: Exported 3D models often reuse a single material across multiple meshes. Always clone or create a new material instance for the windows so properties do not inadvertently leak to the body panels.
  • HDR Settings: If you are using an HDR environment map, ensure your renderer's toneMapping is configured properly (such as THREE.ACESFilmicToneMapping) to avoid overexposed reflections on the glass.
