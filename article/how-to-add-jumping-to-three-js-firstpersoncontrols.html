How to Add Jumping to Three.js FirstPersonControls

This article explains how to integrate a jumping mechanic into a Three.js application using FirstPersonControls. Because standard first-person controls do not include vertical physics by default, you must manage vertical velocity and gravity manually. You will learn how to configure a physics state, listen for keyboard jump commands, apply gravitational acceleration along the Y-axis, and handle ground collision inside the animation loop.

1. Define Physics and State Variables

To manage vertical motion, you must track whether the player is currently on the ground, along with constants for gravity and jump strength.

const GRAVITY = 30.0;
const JUMP_FORCE = 15.0;
const GROUND_Y = 1.6; // Typical eye height above ground

let velocityY = 0;
let canJump = true;

2. Capture the Jump Input

Listen for the Space key using a standard keydown event listener. When pressed, apply the jump impulse to velocityY only if the player is currently grounded.

window.addEventListener('keydown', (event) => {
    if (event.code === 'Space' && canJump) {
        velocityY = JUMP_FORCE;
        canJump = false;
    }
});

3. Update Y-Axis Velocity in the Animation Loop

Inside your render loop, calculate the time delta between frames. Update the camera's Y position by integrating velocity, apply gravity, and clamp the position when the camera lands on the ground.

const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();

    // Update standard FirstPersonControls for horizontal looking and movement
    controls.update(delta);

    // Apply vertical physics
    if (!canJump) {
        // Apply gravitational acceleration
        velocityY -= GRAVITY * delta;

        // Update position based on current velocity
        camera.position.y += velocityY * delta;

        // Detect landing
        if (camera.position.y <= GROUND_Y) {
            camera.position.y = GROUND_Y;
            velocityY = 0;
            canJump = true;
        }
    }

    renderer.render(scene, camera);
}

4. Important Considerations for FirstPersonControls

  • Disable Vertical Movement in Controls: Standard FirstPersonControls allows free flight via mouse positioning or specific key bindings. Set controls.movementSpeed appropriately and avoid setting vertical movement targets within the controls instance itself so it does not overwrite the manual camera.position.y modifications.
  • Delta Clamping: If the browser tab loses focus, delta can spike upon returning, causing the player to fall through the floor. Ensure delta values are clamped (e.g., Math.min(delta, 0.1)) before performing physics calculations.
