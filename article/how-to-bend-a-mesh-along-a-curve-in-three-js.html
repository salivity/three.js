How to Bend a Mesh Along a Curve in Three.js

Bending a 3D object along a spline path is a common requirement for animations like snakes, conveyor belts, cables, or flowing text. In Three.js, this is achieved using the CurveModifier utility, which provides a Flow class that deforms a mesh's vertices along a predefined 3D path using vertex shaders. This guide provides a step-by-step walkthrough for setting up a curve, preparing geometry with sufficient subdivisions, and applying the CurveModifier to make your mesh deform and travel along the path.

1. Import the CurveModifier

The CurveModifier is an official Three.js add-on. Import the Flow class from the three/addons/modifiers/CurveModifier.js module:

import * as THREE from 'three';
import { Flow } from 'three/addons/modifiers/CurveModifier.js';

2. Define the Curve

Create a curve using THREE.CatmullRomCurve3 or any class derived from THREE.Curve. Supply an array of THREE.Vector3 points that define the path:

const points = [
  new THREE.Vector3(-10, 0, 0),
  new THREE.Vector3(-5, 5, 0),
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(5, -5, 0),
  new THREE.Vector3(10, 0, 0)
];

const curve = new THREE.CatmullRomCurve3(points);

3. Prepare the Geometry

Vertex deformation requires high vertex density. If your geometry does not have enough subdivisions along its length, it will look angular or fail to bend. When creating your geometry, ensure the axis aligned with the curve has adequate segments:

// A box elongated along the X axis with 128 subdivisions on the X axis
const geometry = new THREE.BoxGeometry(10, 1, 1, 128, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0x0077ff });
const mesh = new THREE.Mesh(geometry, material);

4. Apply the Flow Modifier

Instantiate the Flow class by passing the target mesh into it. Then bind the curve to the flow instance using updateCurve() and add the flow's internal object to your scene:

// Initialize the flow modifier with the mesh
const flow = new Flow(mesh);

// Attach the curve (index 0) to the modifier
flow.updateCurve(0, curve);

// Add the modified object to the scene (instead of the original mesh)
scene.add(flow.object3D);

5. Animate Along the Curve

To move the mesh smoothly along the curve path, adjust its offset inside your animation loop using the moveAlongCurve() method:

function animate() {
  requestAnimationFrame(animate);

  // Move the mesh forward along the curve
  flow.moveAlongCurve(0.002);

  renderer.render(scene, camera);
}

animate();

If your mesh appears oriented sideways or inside out, adjust the base orientation of the original geometry before passing it to Flow by using methods like geometry.rotateZ() or geometry.rotateY().
