Extract Translation from Matrix4 in Three.js

In Three.js, a Matrix4 encapsulates 3D transformations, combining translation, rotation, and scale into a single 4x4 matrix. Extracting the translation component—the 3D world or local position—from a complex matrix is a common task when synchronizing objects, calculating distances, or handling camera transformations. This article explains the standard and most efficient methods to isolate and read the translation vector from any THREE.Matrix4 object.

Method 1: Using Vector3.setFromMatrixPosition() (Recommended)

The most direct and performance-friendly way to extract the translation is using the setFromMatrixPosition() method on a THREE.Vector3 instance. This method reads the translation column directly from the matrix without calculating rotational or scale components.

import * as THREE from 'three';

// Assume 'matrix' is your complex THREE.Matrix4 object
const matrix = new THREE.Matrix4(); 

// Create a target Vector3 to hold the translation
const position = new THREE.Vector3();

// Extract the translation component
position.setFromMatrixPosition(matrix);

console.log(position.x, position.y, position.z);

This approach avoids unnecessary memory allocation if you reuse an existing Vector3 instance, making it ideal for render loops.

Method 2: Using Matrix4.decompose()

If you need the translation along with rotation and scale, use the decompose() method. It separates the matrix into position, quaternion (rotation), and scale vectors.

import * as THREE from 'three';

const matrix = new THREE.Matrix4();

const position = new THREE.Vector3();
const quaternion = new THREE.Quaternion();
const scale = new THREE.Vector3();

// Deconstruct the matrix into its distinct components
matrix.decompose(position, quaternion, scale);

console.log('Position:', position);

While slightly more computationally expensive than setFromMatrixPosition() due to the quaternion and scale calculations, decompose() is the standard choice when a full object state needs reconstruction.

Method 3: Direct Array Access (matrix.elements)

Three.js stores matrix elements internally in a 16-element flat array using column-major order. In a standard 4x4 affine transformation matrix, translation values occupy indices 12 (X), 13 (Y), and 14 (Z).

const x = matrix.elements[12];
const y = matrix.elements[13];
const z = matrix.elements[14];

Direct array access has the lowest computational overhead, but using Vector3.setFromMatrixPosition() is generally preferred for code readability and maintainability.
