How to Create Harsh PointLight Falloff in Three.js

This article explains how to configure the distance and decay properties of a THREE.PointLight to produce an abrupt, harsh light falloff in Three.js. By default, Three.js simulates physically realistic light attenuation, where illumination dims smoothly using the inverse-square law. By overriding these physical defaults through precise combinations of range boundaries and attenuation rates, you can produce dramatic, sharp-edged lighting suited for stylized or high-contrast scenes.

The Role of distance and decay

A standard PointLight in Three.js accepts four primary arguments:

const light = new THREE.PointLight(color, intensity, distance, decay);
  • distance: Defines the maximum range of the light. When set to 0, the light travels infinitely. When set to a value greater than 0, the light’s intensity drops to zero precisely at that distance.
  • decay: Determines how fast the light attenuates along its path. The physically accurate default is 2. Lower values make the light sustain its brightness over distance, while higher values cause it to fade more quickly.

Configuring for a Harsh Falloff

To produce a harsh cutoff rather than a gradual fade, you must manipulate both properties in tandem. A harsh falloff requires the light to remain bright across its volume and then drop sharply at the perimeter.

1. Combine Non-Zero Distance with Zero Decay

Setting decay = 0 eliminates the continuous inverse-square dimming. When combined with a defined distance, the light maintains maximum brightness throughout its volume before terminating sharply at the defined boundary.

import * as THREE from 'three';

// Create a light with high intensity, a fixed radius, and no attenuation decay
const harshLight = new THREE.PointLight(0xffffff, 2, 15, 0);

harshLight.position.set(0, 5, 0);
scene.add(harshLight);

2. Using High Intensity with Tight Distance Limits

If you still want slight depth to the light while forcing a visually abrupt edge, keep decay at 1 or 2, increase the intensity, and restrict the distance to a compact radius.

// High intensity compressed into a short distance
const compactHarshLight = new THREE.PointLight(0xffaa00, 10, 6, 1);

compactHarshLight.position.set(2, 3, 2);
scene.add(compactHarshLight);

Because the high brightness must drop to absolute zero within a short span (6 units), the transition zone is compressed into a narrow band, creating the visual impression of a hard light barrier.

Summary of Best Practices

  • For stylized/arcade rendering: Set distance > 0 and decay = 0. This eliminates smooth dimming entirely and cuts the illumination off at the boundary radius.
  • For compressed gradients: Use high intensity (e.g., 5 to 15), moderate decay (1 or 2), and a small distance (e.g., 3 to 8).
  • Avoid distance = 0: Leaving distance at its default value of 0 makes the light mathematically infinite, which prevents any hard outer cutoff from forming.
