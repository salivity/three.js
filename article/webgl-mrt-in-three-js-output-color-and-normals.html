WebGL MRT in Three.js: Output Color and Normals

This guide explains how to implement WebGL Multiple Render Targets (MRT) using Three.js to write color and normal data to separate textures in a single draw call. By taking advantage of WebGL 2 features exposed by modern Three.js APIs—specifically WebGLRenderTarget with multiple texture attachments and GLSL 3.0 in ShaderMaterial—you can optimize deferred rendering pipelines and post-processing passes.

1. Set Up the Multi-Target WebGLRenderTarget

To store both color and normal information, instantiate a THREE.WebGLRenderTarget with its count property set to 2. By default, this assigns two internal textures to the target.

import * as THREE from 'three';

const width = window.innerWidth;
const height = window.innerHeight;

const mRenderTarget = new THREE.WebGLRenderTarget(width, height, {
  count: 2, // Allocates two color attachments
  minFilter: THREE.NearestFilter,
  magFilter: THREE.NearestFilter,
  type: THREE.HalfFloatType // HalfFloat or Float preserves negative normal values without packing
});

// Name textures for clarity
mRenderTarget.textures[0].name = 'color';
mRenderTarget.textures[1].name = 'normal';

2. Configure the ShaderMaterial for GLSL 3.0

MRT requires GLSL 3.0. You must set glslVersion: THREE.GLSL3 on the ShaderMaterial so you can define explicit output layout locations instead of relying on the legacy gl_FragColor.

const customShaderMaterial = new THREE.ShaderMaterial({
  glslVersion: THREE.GLSL3,
  vertexShader: `
    out vec3 vNormal;
    out vec2 vUv;

    void main() {
      vUv = uv;
      // Transform normal to view space or world space as needed
      vNormal = normalize(normalMatrix * normal);
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    precision highp float;

    in vec3 vNormal;
    in vec2 vUv;

    // Output target indices match the render target texture array indices
    layout(location = 0) out vec4 gColor;
    layout(location = 1) out vec4 gNormal;

    void main() {
      // Attachment 0: Diffuse / Albedo color
      gColor = vec4(0.2, 0.6, 1.0, 1.0);

      // Attachment 1: View-space normal
      // If using standard UnsignedByteType textures, remap: (vNormal * 0.5 + 0.5)
      gNormal = vec4(normalize(vNormal), 1.0);
    }
  `
});

3. Render the Scene to the Target

Assign the material to your meshes and execute the render loop. Redirect the renderer output to your multi-target render target.

function animate() {
  requestAnimationFrame(animate);

  // Direct render output to the MRT setup
  renderer.setRenderTarget(mRenderTarget);
  renderer.render(scene, camera);

  // Reset back to canvas default framebuffer for display or post-processing
  renderer.setRenderTarget(null);
}

4. Sampling the Textures

The outputs are immediately accessible via the textures array on your render target:

  • mRenderTarget.textures[0] contains the raw color buffer.
  • mRenderTarget.textures[1] contains the normal buffer.

You can feed these textures directly into downstream materials, compute passes, or screen-space post-processing shaders as uniform sampler inputs (sampler2D).
