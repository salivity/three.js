Optimizing Three.js TubeGeometry Polygon Count

Balancing tubularSegments and radialSegments in Three.js TubeGeometry requires matching the physical dimensions and curvature of the curve to the tessellation resolution. This guide details the mathematical relationship between the cross-sectional circumference and the path length, providing concrete formulas to produce near-equilateral polygon faces, reduce redundant vertices, and eliminate visual faceting.

The Triangle Cost Formula

In Three.js, a TubeGeometry generates faces based on a grid defined by tubularSegments (\(T\)) along the path length and radialSegments (\(R\)) around the circumference.

The total triangle count for an open tube is:

\[\text{Triangles} = 2 \times T \times R\]

The total vertex count is:

\[\text{Vertices} = (T + 1) \times (R + 1)\]

Indiscriminately increasing either parameter causes quadratic growth in GPU memory and vertex processing overhead. Optimization requires allocating segments where geometric deviation from the true shape is greatest.

Step 1: Solving for Radial Segments (\(R\))

The cross-section of a tube is a regular polygon with \(R\) sides approximating a circle of radius \(r\). The maximum geometric deviation (sagitta, or distance \(\delta\)) between the chord and the true circle is:

\[\delta = r \left(1 - \cos\left(\frac{\pi}{R}\right)\right)\]

Given a maximum acceptable error threshold in world units (\(\delta_{\text{max}}\)), solve for \(R\):

\[\cos\left(\frac{\pi}{R}\right) = 1 - \frac{\delta_{\text{max}}}{r}\]

\[R = \left\lceil \frac{\pi}{\arccos\left(1 - \frac{\delta_{\text{max}}}{r}\right)} \right\rceil\]

For real-time rendering, \(R\) usually falls between 6 and 16. A radius viewed from a distance can set \(\delta_{\text{max}}\) higher, reducing \(R\) substantially.

Step 2: Aspect Ratio Matching for Linear Tubes

Polygons display optimal shading and texturing when individual quads are square rather than elongated rectangles. To maintain a 1:1 aspect ratio across the surface grid, the longitudinal segment length (\(\Delta L\)) must equal the circumferential segment length (\(\Delta C\)).

Given curve length \(L\) and circumference \(C = 2\pi r\):

\[\Delta L = \frac{L}{T}\]

\[\Delta C = \frac{2\pi r}{R}\]

Equating \(\Delta L\) and \(\Delta C\):

\[\frac{L}{T} = \frac{2\pi r}{R}\]

Solving for \(T\):

\[T_{\text{aspect}} = \left\lceil \frac{L \cdot R}{2\pi r} \right\rceil\]

This formula ensures that when \(R\) is fixed to an acceptable smoothness level, \(T\) directly scales with the physical length of the tube.

Step 3: Accounting for Path Curvature

If the path has sharp bends, \(T_{\text{aspect}}\) may produce visible angular artifacts along the length of the tube. The path segment must satisfy an angular resolution threshold (\(\theta_{\text{max}}\)) along the curve.

Compute the total turning angle (\(\Theta_{\text{total}}\)) of the path by integrating the curvature \(\kappa(s)\) along the arc-length \(s\), or approximating it through discrete tangent vectors:

\[\Theta_{\text{total}} = \sum_{i=1}^{N-1} \arccos\left(\mathbf{T}_i \cdot \mathbf{T}_{i+1}\right)\]

Where \(\mathbf{T}_i\) is the normalized tangent vector at sampled points along the curve.

To ensure no bend exceeds \(\theta_{\text{max}}\) radians per segment:

\[T_{\text{curvature}} = \left\lceil \frac{\Theta_{\text{total}}}{\theta_{\text{max}}} \right\rceil\]

A practical value for \(\theta_{\text{max}}\) in standard 3D applications is between \(\frac{\pi}{12}\) (15 degrees) and \(\frac{\pi}{6}\) (30 degrees).

Unified Mathematical Implementation

Combine the constraints into a unified sizing procedure:

  1. Input Parameters: Tube radius (\(r\)), path length (\(L\)), total path turning angle (\(\Theta_{\text{total}}\)), and tolerance values (\(\delta_{\text{max}}\), \(\theta_{\text{max}}\)).
  2. Compute \(R\): \[R = \max\left(3, \left\lceil \frac{\pi}{\arccos\left(\max\left(-1, 1 - \frac{\delta_{\text{max}}}{r}\right)\right)} \right\rceil\right)\]
  3. Compute \(T\): \[T = \max\left( \left\lceil \frac{L \cdot R}{2\pi r} \right\rceil, \left\lceil \frac{\Theta_{\text{total}}}{\theta_{\text{max}}} \right\rceil \right)\]

JavaScript Code Implementation

import * as THREE from 'three';

function calculateOptimalTubeSegments(curve, radius, deltaMax = 0.05, thetaMax = Math.PI / 12) {
  // 1. Calculate radial segments from radius and allowed deviation
  const clampedRatio = Math.max(-1, Math.min(1, 1 - deltaMax / radius));
  const radialSegments = Math.max(3, Math.ceil(Math.PI / Math.acos(clampedRatio)));

  // 2. Sample curve for total length and turning angle
  const samples = 100;
  const points = curve.getPoints(samples);
  const length = curve.getLength();

  let totalAngle = 0;
  for (let i = 1; i < points.length - 1; i++) {
    const v1 = new THREE.Vector3().subVectors(points[i], points[i - 1]).normalize();
    const v2 = new THREE.Vector3().subVectors(points[i + 1], points[i]).normalize();
    totalAngle += v1.angleTo(v2);
  }

  // 3. Balance aspect ratio vs. bending angle
  const tubularFromAspect = Math.ceil((length * radialSegments) / (2 * Math.PI * radius));
  const tubularFromCurvature = Math.ceil(totalAngle / thetaMax);
  
  const tubularSegments = Math.max(tubularFromAspect, tubularFromCurvature, 1);

  return { tubularSegments, radialSegments };
}

// Usage
const curve = new THREE.CatmullRomCurve3([
  new THREE.Vector3(-10, 0, 0),
  new THREE.Vector3(-5, 5, 0),
  new THREE.Vector3(5, -5, 0),
  new THREE.Vector3(10, 0, 0)
]);

const radius = 0.5;
const { tubularSegments, radialSegments } = calculateOptimalTubeSegments(curve, radius, 0.02);

const geometry = new THREE.TubeGeometry(curve, tubularSegments, radius, radialSegments, false);

Applying these constraints guarantees that the resulting mesh contains no redundant sub-divisions on straight sections while maintaining smooth silhouettes along curves and cross-sections.
