Texture Array Uniforms in Three.js ShaderMaterial

Assigning an array of textures to a single uniform in a custom Three.js ShaderMaterial involves declaring a uniform containing an array of THREE.Texture objects in JavaScript and defining a corresponding sampler2D array of fixed size in your GLSL shader. This guide demonstrates how to configure the JavaScript uniform object, declare the texture array in the fragment shader, and sample the individual textures efficiently.

1. Load the Textures and Configure Uniforms

In JavaScript, load your textures using THREE.TextureLoader and assign them as a standard JavaScript array to the uniform's value property.

import * as THREE from 'three';

const loader = new THREE.TextureLoader();
const textures = [
  loader.load('path/to/texture0.jpg'),
  loader.load('path/to/texture1.jpg'),
  loader.load('path/to/texture2.jpg'),
];

const customMaterial = new THREE.ShaderMaterial({
  uniforms: {
    uTextures: { value: textures },
  },
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform sampler2D uTextures[3];
    varying vec2 vUv;

    void main() {
      // Sample individual textures by their array index
      vec4 col0 = texture2D(uTextures[0], vUv);
      vec4 col1 = texture2D(uTextures[1], vUv);
      vec4 col2 = texture2D(uTextures[2], vUv);

      // Example: Blend textures based on horizontal UV coordinates
      vec4 finalColor = mix(col0, col1, vUv.x);
      gl_FragColor = mix(finalColor, col2, vUv.y);
    }
  `
});

2. Declare the Uniform in GLSL

In your fragment shader, declare the uniform array specifying a constant, fixed size:

uniform sampler2D uTextures[3];

GLSL requires the array size to be a compile-time constant integer. It cannot be sized dynamically. The number of elements declared in GLSL must match or be smaller than the number of textures provided in the JavaScript array.

3. Sampling Dynamic Indices

In WebGL 1 (GLSL ES 1.0), indexing an array of samplers with a non-constant variable (such as an attribute or dynamically computed index) is not allowed. If you need to select a texture based on a variable index, use a series of conditional checks:

uniform sampler2D uTextures[3];
varying vec2 vUv;
uniform int uActiveIndex;

vec4 getSample(int index, vec2 uv) {
  if (index == 0) return texture2D(uTextures[0], uv);
  if (index == 1) return texture2D(uTextures[1], uv);
  return texture2D(uTextures[2], uv);
}

void main() {
  gl_FragColor = getSample(uActiveIndex, vUv);
}

In WebGL 2 (Three.js WebGLRenderer default in modern browsers) with GLSL 3.0 shaders, dynamic indexing of sampler arrays is supported natively.

Important Limitations

  • Texture Unit Limits: The total number of textures you can pass is constrained by the user's GPU limit (gl.MAX_TEXTURE_IMAGE_UNITS), which is typically 16 on mobile devices and 32 or more on desktop hardware.
  • Alternative for Many Textures: If you need to store and sample dozens or hundreds of textures with dynamic indexing, use THREE.DataArrayTexture or a 2D Texture Array (sampler2DArray in WebGL 2) instead of an array of individual samplers.
