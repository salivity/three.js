Extract Y-Axis Rotation from a Quaternion in Three.js

Extracting the rotation strictly around the Y-axis from a complex THREE.Quaternion can be achieved depending on whether you need the planar facing direction (yaw heading) or a mathematical isolation of the rotation component (twist). This guide explains the two most effective methods in Three.js: vector projection for world-space yaw, and swing-twist decomposition for isolating the exact Y-axis rotation without gimbal lock.

Method 1: Forward Vector Projection (World Yaw / Heading)

If your goal is to find the object's direction or yaw on the horizontal XZ plane, the most reliable method is to apply the quaternion to a forward vector and compute its angle using Math.atan2. This completely avoids Euler angle singularities.

import * as THREE from 'three';

function getYawFromQuaternion(quaternion) {
  // Define default forward vector (Three.js convention is negative Z)
  const forward = new THREE.Vector3(0, 0, -1);

  // Rotate the forward vector by the complex quaternion
  forward.applyQuaternion(quaternion);

  // Compute the angle on the XZ plane
  // forward.x and forward.z represent the horizontal heading
  return Math.atan2(forward.x, forward.z);
}
  • Pros: Robust, immune to gimbal lock, and guarantees the true facing direction on the horizontal plane.
  • Range: Returns an angle in radians from \(-\pi\) to \(\pi\).

Method 2: Swing-Twist Decomposition (Local Twist Around Y)

When you need to mathematically decompose a quaternion into a rotation around the Y-axis (twist) and a tilt off the Y-axis (swing), you use swing-twist decomposition.

For an axis-aligned unit vector along the Y-axis \((0, 1, 0)\), the twist quaternion simplifies to keeping only the \(y\) and \(w\) components of the original quaternion:

import * as THREE from 'three';

function getStrictYTwistAngle(quaternion) {
  // If the quaternion is not normalized, normalize it first
  const q = quaternion.clone().normalize();

  // The angle around the Y-axis can be extracted directly from y and w
  const angle = 2 * Math.atan2(q.y, q.w);

  // Normalize the angle to the range [-PI, PI]
  return THREE.MathUtils.euclideanModulo(angle + Math.PI, Math.PI * 2) - Math.PI;
}
  • Pros: Isolates the intrinsic rotation purely around the specified axis.
  • Use Case: Useful for inverse kinematics, bone constraints, and procedural animations where the twist must be isolated from the swing.

Method 3: Using Three.js Euler with 'YXZ' Order

If you prefer using standard Three.js classes, you can extract the rotation into a THREE.Euler instance. To minimize gimbal lock issues around the Y-axis, set the Euler order to 'YXZ' so that the Y rotation is calculated first.

import * as THREE from 'three';

function getEulerY(quaternion) {
  const euler = new THREE.Euler();
  
  // Set the order to YXZ to prioritize Y rotation
  euler.setFromQuaternion(quaternion, 'YXZ');

  return euler.y;
}
  • Note: While straightforward, Euler conversions can still encounter numerical instability near 90-degree pitch tilts (gimbal lock). Use Method 1 or Method 2 for production-grade character controllers or physics interactions.
