Seamless Looping in Three.js with euclideanModulo

This article explains how to implement seamless coordinate wrapping in Three.js using THREE.MathUtils.euclideanModulo. When building infinite terrains, wrapping particle fields, or looping camera paths, developers frequently encounter visual glitches caused by JavaScript's native remainder operator (%) handling negative numbers unpredictably. By replacing the standard remainder operator with Three.js's built-in Euclidean modulo function, you ensure smooth, continuous coordinate looping across both positive and negative spatial domains.

The Flaw of the Standard JavaScript % Operator

In JavaScript, the % operator calculates the remainder of an operation, not a true mathematical modulo. When working with positive numbers, it behaves as expected:

const result = 5 % 10; // returns 5

However, when dealing with negative coordinates—which occur routinely in 3D worlds as objects cross the origin—the remainder keeps the negative sign:

const result = -1 % 10; // returns -1, NOT 9

This behavior breaks spatial wrapping. If an object moves from 0 to -0.1 on an intended loop range of 0 to 10, standard remainder calculations produce -0.1 rather than wrapping around to 9.9. This produces sudden visual snaps and inverted boundaries.

The Solution: THREE.MathUtils.euclideanModulo

The Euclidean modulo always returns a value within the range [0, m - 1] (or [0, m) for floating-point values), regardless of whether the dividend is positive or negative. The mathematical definition guarantees:

\[\text{euclideanModulo}(n, m) = ((n \bmod m) + m) \bmod m\]

Three.js includes this directly inside its utility library:

import * as THREE from 'three';

const wrappedValue = THREE.MathUtils.euclideanModulo(-1, 10); // returns 9

Practical Implementation: Seamless Object Wrapping

Consider an infinite runner, scrolling background, or wrapped particle system where objects must stay bounded within an area spanning from -halfWidth to +halfWidth.

1. Zero-Based Wrapping ([0, bound))

For continuous cycling from 0 to a defined boundary L:

function updateLoopingObject(mesh, speed, boundaryLength) {
    mesh.position.x += speed;
    mesh.position.x = THREE.MathUtils.euclideanModulo(mesh.position.x, boundaryLength);
}

2. Centered Range Wrapping ([-boundary / 2, boundary / 2])

Most 3D scenes are centered at the origin (0, 0, 0). To seamlessly wrap coordinates around the center rather than starting at zero:

import * as THREE from 'three';

const BOUND_SIZE = 100; // Total world size
const HALF_BOUND = BOUND_SIZE / 2;

function wrapCoordinate(val, size) {
    const half = size / 2;
    // Shift coordinate to a 0-based range, apply modulo, then shift back
    return THREE.MathUtils.euclideanModulo(val + half, size) - half;
}

function animate() {
    requestAnimationFrame(animate);

    // Continuous movement in any direction (positive or negative)
    particle.position.x += velocity.x;
    particle.position.z += velocity.z;

    // Apply seamless wrapping across the origin
    particle.position.x = wrapCoordinate(particle.position.x, BOUND_SIZE);
    particle.position.z = wrapCoordinate(particle.position.z, BOUND_SIZE);

    renderer.render(scene, camera);
}

Key Use Cases in Three.js

  • Infinite Terrains and Grids: Offsetting terrain meshes or shader uniforms relative to camera motion without accumulating floating-point errors.
  • Particle Systems: Ensuring falling snow, moving stars, or ambient dust instantly reappear on the opposite side of the bounding volume when moving out of bounds.
  • Texture UV Scrolling: Offsetting texture UV coordinates continuously for conveyor belts, water surfaces, or animated skies without edge seams or direction-flip artifacts.
