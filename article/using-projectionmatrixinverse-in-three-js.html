Using projectionMatrixInverse in Three.js

This article explains how to access and utilize the projectionMatrixInverse property of a camera in Three.js to manually unproject 2D screen coordinates into 3D view space. You will learn how to obtain Normalized Device Coordinates (NDC), apply the inverted projection matrix, ensure the matrix is properly updated, and understand how this process compares to Three.js's built-in Vector3.unproject method.

Accessing projectionMatrixInverse

In Three.js, both PerspectiveCamera and OrthographicCamera inherit from Camera, which possesses the projectionMatrixInverse property (THREE.Matrix4). This matrix is automatically maintained by the camera to invert the projection transformation, mapping points from clip space (NDC) back into camera (view) space.

You can directly access it from your camera instance:

const invProjectionMatrix = camera.projectionMatrixInverse;

Keeping the Matrix Updated

Whenever you alter camera properties that affect projection—such as fov, aspect, near, far, or orthographic bounds—you must call camera.updateProjectionMatrix(). This method updates both camera.projectionMatrix and immediately recalculates camera.projectionMatrixInverse.

camera.aspect = window.innerWidth / window.innerHeight;
camera.updateProjectionMatrix(); // Recalculates projectionMatrix and projectionMatrixInverse

Step-by-Step: Unprojecting Coordinates to View Space

To manually unproject screen coordinates into camera space using projectionMatrixInverse, follow these steps:

1. Convert Screen Coordinates to Normalized Device Coordinates (NDC)

Screen coordinates (pixels) must be mapped to a range of [-1, 1] for both the X and Y axes, where (0, 0) represents the center of the screen:

const mouseX = event.clientX;
const mouseY = event.clientY;

const ndcX = (mouseX / window.innerWidth) * 2 - 1;
const ndcY = -(mouseY / window.innerHeight) * 2 + 1; // Invert Y axis

2. Create the Vector

Define a THREE.Vector3 using the calculated NDC values. The Z value typically ranges from -1 (near plane) to 1 (far plane) depending on the desired depth:

const targetDepth = 0.5; // Depth in NDC space
const pointInNDC = new THREE.Vector3(ndcX, ndcY, targetDepth);

3. Apply the Inverted Projection Matrix

Transform the vector from NDC space to camera/view space using applyMatrix4:

pointInNDC.applyMatrix4(camera.projectionMatrixInverse);
// pointInNDC is now in 3D camera space (relative to the camera's local origin)

Transforming from Camera Space to World Space

If your objective is to obtain world-space coordinates, the camera-space point must also be transformed by the camera's world matrix:

pointInNDC.applyMatrix4(camera.matrixWorld);
// pointInNDC is now in full 3D world space

Manual Matrix Multiplication vs. Vector3.unproject

Three.js provides a built-in helper method, Vector3.unproject(camera). Internally, this helper performs:

vector.applyMatrix4(camera.projectionMatrixInverse).applyMatrix4(camera.matrixWorld);

Accessing camera.projectionMatrixInverse directly is primarily useful when:

  • You need the coordinates in local camera space rather than global world space (e.g., custom post-processing, screen-space reflections, or depth reconstructions).
  • You are constructing custom shaders or compute passes and need to pass the view-space reconstruction matrix as a uniform.
  • You are optimizing performance inside a loop and want to avoid recomputing or applying world-matrix steps.
