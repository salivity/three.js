Check Sphere Intersection in Three.js

In Three.js, testing whether two mathematical spheres overlap is achieved using the THREE.Sphere class and its built-in intersectsSphere method. This article covers how to define mathematical sphere boundaries, compute their positions in 3D space, and execute the intersection check to return a simple boolean indicating whether a collision has occurred.

Creating Sphere Objects

The THREE.Sphere class represents a mathematical sphere defined by a center point (THREE.Vector3) and a radius (a scalar number). Unlike visual meshes, mathematical spheres do not render in the scene; they exist purely for spatial calculations.

import * as THREE from 'three';

// Define the center and radius for the first sphere
const centerA = new THREE.Vector3(0, 0, 0);
const radiusA = 2.0;
const sphereA = new THREE.Sphere(centerA, radiusA);

// Define the center and radius for the second sphere
const centerB = new THREE.Vector3(3, 0, 0);
const radiusB = 1.5;
const sphereB = new THREE.Sphere(centerB, radiusB);

Performing the Intersection Check

To verify if sphereA and sphereB overlap, call intersectsSphere on one sphere object and pass the second sphere as an argument:

const isOverlapping = sphereA.intersectsSphere(sphereB);

if (isOverlapping) {
    console.log('The spheres are overlapping.');
} else {
    console.log('The spheres do not intersect.');
}

The method returns true if the spheres touch or overlap, and false otherwise.

The Underlying Math

The intersectsSphere method works by calculating the Euclidean distance between the centers of the two spheres and comparing it to the sum of their radii:

\[\text{distance} \le \text{radius}_A + \text{radius}_B\]

To optimize performance, Three.js compares the squared distance between the centers with the squared sum of the radii, avoiding expensive square root operations:

const radiusSum = sphereA.radius + sphereB.radius;
const distanceSq = sphereA.center.distanceToSquared(sphereB.center);

const overlaps = distanceSq <= (radiusSum * radiusSum);

Checking Intersections from Meshes

If working with rendered THREE.Mesh objects, you must extract their world-space bounding spheres before running the intersection check:

// Ensure geometry has a bounding sphere computed
meshA.geometry.computeBoundingSphere();
meshB.geometry.computeBoundingSphere();

// Create bounding spheres in world coordinates
const worldSphereA = new THREE.Sphere();
const worldSphereB = new THREE.Sphere();

// Copy and apply world transformation matrices
worldSphereA.copy(meshA.geometry.boundingSphere).applyMatrix4(meshA.matrixWorld);
worldSphereB.copy(meshB.geometry.boundingSphere).applyMatrix4(meshB.matrixWorld);

// Perform the collision test
const collision = worldSphereA.intersectsSphere(worldSphereB);
