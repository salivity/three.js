Binding Animation Tracks with Three.js PropertyBinding

In Three.js, animating object properties typically relies on string paths evaluated by the animation system to locate targets within a scene hierarchy. This article explains how THREE.PropertyBinding resolves and connects animation tracks directly to target object properties, how to structure track paths for precise targeting, and how to create explicit bindings programmatically.

Understanding Property Path Syntax

Three.js uses PropertyBinding behind the scenes to map track names to real object properties. The standard syntax for a target track path follows this structure:

nodeName.propertyName[componentName]
  • nodeName: The name or uuid of the target Object3D relative to the AnimationMixer root.
  • propertyName: The property path on that object, which can include chained sub-properties (e.g., material.opacity, position, or rotation).
  • componentName (optional): An accessor for array indices or vector components (e.g., [x], [0]).

Direct Binding Using UUIDs

When object names are not unique or when an object is not easily discovered through hierarchy traversal, you can bind directly to an object instance by using its unique identifier (uuid):

import * as THREE from 'three';

const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// Bind the track directly to this specific instance using its UUID
const trackName = `${mesh.uuid}.position`;
const times = [0, 1, 2];
const values = [0, 0, 0, 0, 5, 0, 0, 0, 0];

const positionTrack = new THREE.VectorKeyframeTrack(trackName, times, values);
const clip = new THREE.AnimationClip('MoveUp', 2, [positionTrack]);

const mixer = new THREE.AnimationMixer(scene);
const action = mixer.clipAction(clip);
action.play();

Because AnimationMixer uses PropertyBinding.findNode internally, passing an object's uuid ensures direct resolution to that specific node.

Low-Level Binding with THREE.PropertyBinding

For custom animation pipelines that bypass standard AnimationClip and AnimationMixer workflows, you can instantiate and execute PropertyBinding manually.

1. Instantiate the Binding

Create a new PropertyBinding by passing the root container (or the direct object) and the path string:

const targetObject = new THREE.Mesh(geometry, material);

// Syntax: new THREE.PropertyBinding(rootNode, trackPath, parsedPath)
const binding = new THREE.PropertyBinding(targetObject, '.material.opacity');

If the first parameter is the direct target rather than a parent container, omit the node name from the path and start with a dot.

2. Bind the Target Property

Before applying values, call the bind() method to resolve references and cache property getters/setters:

binding.bind();

3. Apply Values Directly

Once bound, apply values directly from a buffer array:

const valueBuffer = [0.5];
const bufferOffset = 0;

// Sets targetObject.material.opacity to 0.5
binding.setValue(valueBuffer, bufferOffset);

4. Unbinding

To prevent memory leaks when target objects are destroyed or removed from the scene graph, detach the binding:

binding.unbind();

Parsing Complex Track Paths

If you need to inspect or manipulate property paths before binding, use the static method PropertyBinding.parseTrackName:

const parsed = THREE.PropertyBinding.parseTrackName('Armature.bones[1].rotation[x]');

console.log(parsed.nodeName);          // "Armature"
console.log(parsed.objectName);        // "bones"
console.log(parsed.objectIndex);       // "1"
console.log(parsed.propertyName);      // "rotation"
console.log(parsed.propertyIndex);     // "x"

Passing the resulting parsed object into new THREE.PropertyBinding(root, trackName, parsed) prevents redundant string parsing when creating multiple bindings for large numbers of tracks.
