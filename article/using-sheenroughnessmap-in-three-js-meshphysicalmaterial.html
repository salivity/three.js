Using sheenRoughnessMap in Three.js MeshPhysicalMaterial

This article provides a practical guide on using the sheenRoughnessMap property on a MeshPhysicalMaterial in Three.js. You will learn how sheen properties simulate fabric fuzziness, how the roughness map modulates this effect across a surface at a microscopic level, and how to configure textures and materials in code for realistic cloth rendering.

Understanding Sheen and Sheen Roughness

In physically based rendering (PBR), the sheen layer simulates the backscattering of light caused by microscopic fibers on fabrics such as velvet, satin, and cotton. While the base roughness of a material dictates standard specular reflections, sheen roughness specifically dictates how blurry or sharp the microfiber reflection appears.

By applying a sheenRoughnessMap, you can break up uniform highlights across your fabric. Areas with higher roughness scatter light broadly, appearing softer and fuzzier, while areas with lower roughness produce tighter, sharper specular highlights along grazing angles.

Texture Channel Requirements

In Three.js, sheenRoughnessMap reads values to scale the scalar sheenRoughness property.

  • Color Space: Roughness data is non-color data. Always set the texture's colorSpace to THREE.NoColorSpace (or THREE.LinearSRGBColorSpace) to prevent gamma correction from distorting the roughness values.
  • Texture Channel: Depending on your pipeline, sheenRoughnessMap typically samples the alpha channel of the assigned texture. Ensure your texture export matches this convention or supplies a dedicated grayscale map.

Step-by-Step Implementation

To enable and control sheen fuzziness using a texture map, instantiate a MeshPhysicalMaterial and configure the sheen properties:

import * as THREE from 'three';

// 1. Initialize the TextureLoader
const textureLoader = new THREE.TextureLoader();

// 2. Load the sheen roughness map
const sheenRoughnessTexture = textureLoader.load('textures/fabric_sheen_roughness.png');

// Ensure linear color space for data maps
sheenRoughnessTexture.colorSpace = THREE.NoColorSpace;
sheenRoughnessTexture.wrapS = THREE.RepeatWrapping;
sheenRoughnessTexture.wrapT = THREE.RepeatWrapping;

// 3. Create the MeshPhysicalMaterial
const fabricMaterial = new THREE.MeshPhysicalMaterial({
    color: 0x224488,
    roughness: 0.8,
    metalness: 0.0,

    // Enable Sheen
    sheen: 1.0, // Multiplier for the sheen layer strength
    sheenColor: new THREE.Color(0xffffff), // Color of the microfibers
    sheenRoughness: 1.0, // Scalar multiplier applied to the map
    sheenRoughnessMap: sheenRoughnessTexture // Dictates variation in fuzziness
});

// 4. Apply to a mesh
const geometry = new THREE.PlaneGeometry(5, 5, 64, 64);
const clothMesh = new THREE.Mesh(geometry, fabricMaterial);
scene.add(clothMesh);

Key Properties to Balance

  • sheen: Serves as the master switch and weight (from 0.0 to 1.0) for the effect. It must be greater than zero for the sheenRoughnessMap to produce visible results.
  • sheenRoughness: Acts as a uniform multiplier for the values read from sheenRoughnessMap. If this is set to 0.0, the roughness map will have no effect.
  • sheenColor or sheenColorMap: Dictates the tint of the scattered light. Combining a sheenColorMap for color variation with a sheenRoughnessMap provides the highest level of realism for patterned fabrics, wear patterns, or localized micro-abrasions.
