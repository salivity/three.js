How to Use WebGLRenderer.clear in Three.js

This article explains how to manually clear specific color, depth, and stencil buffers in Three.js using the WebGLRenderer.clear method. You will learn how to disable the default automatic clear behavior, configure selective buffer wiping using boolean parameters or dedicated helper methods, and apply these techniques to common use cases such as rendering heads-up displays (HUDs) and multi-pass scene overlays.

Disabling Automatic Clearing

By default, Three.js wipes the color, depth, and stencil buffers automatically before rendering a frame. To take manual control over buffer clearing, you must set renderer.autoClear to false:

const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Disable automatic clearing
renderer.autoClear = false;

You can also selectively disable automatic clearing for individual buffers if you only want to take over one specific buffer:

renderer.autoClearColor = true;
renderer.autoClearDepth = false;
renderer.autoClearStencil = false;

Using WebGLRenderer.clear()

The clear() method takes three optional boolean parameters corresponding to the color, depth, and stencil buffers:

renderer.clear(color, depth, stencil);
  • color (boolean): If true, clears the color buffer using the clear color and clear alpha defined by renderer.setClearColor(). Defaults to true.
  • depth (boolean): If true, clears the depth buffer, resetting depth comparisons for upcoming draw calls. Defaults to true.
  • stencil (boolean): If true, clears the stencil buffer. Defaults to true.

Examples of Selective Clearing

To clear only the color buffer:

renderer.clear(true, false, false);

To clear only the depth buffer:

renderer.clear(false, true, false);

To clear only the stencil buffer:

renderer.clear(false, false, true);

To clear color and depth, leaving stencil intact:

renderer.clear(true, true, false);

Dedicated Clearing Methods

Three.js provides shortcut methods for clearing individual buffers directly. These perform the same operations as passing booleans to renderer.clear():

// Clears only the color buffer
renderer.clearColor();

// Clears only the depth buffer
renderer.clearDepth();

// Clears only the stencil buffer
renderer.clearStencil();

Practical Implementation: HUD and Multi-Scene Rendering

The most common reason to manually clear buffers is drawing a 2D interface or overlay on top of a 3D scene without the 3D geometry clipping the overlay.

function animate() {
  requestAnimationFrame(animate);

  // 1. Manually wipe all buffers at the start of the frame
  renderer.clear();

  // 2. Render the primary 3D scene
  renderer.render(mainScene, mainCamera);

  // 3. Clear only the depth buffer so the UI renders on top
  renderer.clearDepth();

  // 4. Render the UI scene without depth interference
  renderer.render(uiScene, uiCamera);
}

animate();

In this setup, the UI elements are drawn over the 3D scene without being obscured by the depth values generated during the primary render pass.
