Why Use Line2 for Thick Lines in Three.js

This article explains the purpose of the Line2 class from the Three.js jsm/lines module and why it is the standard solution for rendering thick strokes. While the core THREE.Line object relies on native WebGL line primitives that cannot exceed a one-pixel width on most modern platforms, Line2 constructs lines as screen-space triangle ribbons. By doing so, it delivers consistent, cross-platform, adjustable-width strokes with support for modern visual features like antialiasing and dashing.

The Limitation of Standard THREE.Line

In core Three.js, lines are created using THREE.Line, THREE.LineSegments, or THREE.LineLoop combined with THREE.LineBasicMaterial. These rely directly on underlying WebGL line primitives (gl.LINES and gl.LINE_STRIP).

The WebGL and OpenGL specifications treat line width as implementation-dependent. Modern operating systems and browsers—especially those relying on the ANGLE translation layer on Windows and macOS—restrict the maximum line width (gl.lineWidth) strictly to 1.0. Consequently, changing the linewidth property in LineBasicMaterial has no visible effect on nearly all current desktop and mobile hardware.

What is the Line2 Class?

Line2 is an extended line implementation located in the Three.js add-ons directory (three/addons/lines/ or three/examples/jsm/lines/). It is part of a specialized trio of classes:

  • LineGeometry: Inherits from LineSegmentsGeometry and generates buffer data suitable for instanced screen-space rendering.
  • LineMaterial: A custom shader material that calculates line width, perspective scaling, and cap/join aesthetics on the GPU.
  • Line2: The high-level mesh-like object that binds LineGeometry and LineMaterial together for insertion into the scene graph.

Instead of native lines, Line2 draws textured triangle strips (quads). The vertex shader expands each line segment into a 2D ribbon perpendicular to the line's direction in screen space.

Why Line2 is Preferred for Thick Strokes

  1. Guaranteed Cross-Platform Line Width
    Because Line2 renders standard triangle meshes rather than native line primitives, it bypasses GPU driver limitations entirely. Strokes can be set to any arbitrary pixel width or world-space thickness and will render consistently across all browsers and operating systems.

  2. Screen-Space Sizing and Perspective Support
    LineMaterial allows developers to define line thickness in pixel dimensions (worldUnits: false) or in world units (worldUnits: true). When set to pixels, lines maintain a uniform thickness regardless of camera distance, behaving like vector strokes in 2D design software.

  3. Advanced Visual Styling
    Line2 supports features that native lines cannot provide:

  • Dash Patterns: Native WebGL does not support dashed lines natively; LineMaterial natively supports adjustable dash sizes, gap sizes, and dash offsets.
  • Per-Vertex Colors: Smooth color gradients along the stroke.
  • Alpha and Transparency: Proper blending along edges without the artifacting common to hardware line rasterization.

Important Implementation Details

To use Line2 correctly, the line material must be informed of the canvas viewport dimensions. Because the vertex shader projects coordinates into screen space, failing to pass the resolution will distort line thickness.

import { Line2 } from 'three/addons/lines/Line2.js';
import { LineMaterial } from 'three/addons/lines/LineMaterial.js';
import { LineGeometry } from 'three/addons/lines/LineGeometry.js';

// Setup geometry from flat coordinate arrays [x1, y1, z1, x2, y2, z2, ...]
const geometry = new LineGeometry();
geometry.setPositions([0, 0, 0, 1, 2, 0, 2, 0, 0]);

// Setup material with explicit resolution
const material = new LineMaterial({
  color: 0xff0000,
  linewidth: 8, // Width in pixels
  resolution: new THREE.Vector2(window.innerWidth, window.innerHeight)
});

const line = new Line2(geometry, material);
scene.add(line);

Whenever the browser window or canvas resizes, material.resolution must be updated to match the new dimensions to prevent strokes from stretching or shrinking unexpectedly.
