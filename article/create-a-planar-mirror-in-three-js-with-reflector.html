Create a Planar Mirror in Three.js with Reflector

Creating a realistic planar mirror in Three.js is best achieved using the Reflector addon object. Instead of relying on static environment maps or resource-intensive cube cameras, the Reflector uses an internal secondary camera and render target to project accurate, real-time planar reflections directly onto a flat mesh. This guide walks through importing the necessary module, constructing the geometry, fine-tuning configuration options for maximum visual fidelity, and optimizing performance.

1. Import the Reflector Module

The Reflector object is not part of the core Three.js bundle; it resides in the examples/addons directory. Import it alongside the core Three.js library using standard ES module syntax:

import * as THREE from 'three';
import { Reflector } from 'three/addons/objects/Reflector.js';

2. Define Mirror Geometry

The Reflector requires a flat geometry to accurately calculate the reflection matrix. A standard PlaneGeometry works best. Define the width and height according to your scene scale:

const mirrorWidth = 10;
const mirrorHeight = 15;
const mirrorGeometry = new THREE.PlaneGeometry(mirrorWidth, mirrorHeight);

3. Instantiate and Configure the Reflector

Pass the geometry and a configuration object to the Reflector constructor. Tuning these parameters is essential for achieving a crisp, realistic look:

const groundMirror = new Reflector(mirrorGeometry, {
  clipBias: 0.003,
  textureWidth: window.innerWidth * window.devicePixelRatio,
  textureHeight: window.innerHeight * window.devicePixelRatio,
  color: 0x777777,
  multisample: 4
});
  • clipBias: Prevents visual artifacts (z-fighting) where reflecting objects touch the mirror surface. A value between 0.001 and 0.003 is typically ideal.
  • textureWidth and textureHeight: Control the resolution of the internal render target. Matching these to the viewport dimensions multiplied by the device pixel ratio yields sharp, high-resolution reflections.
  • color: Tints the reflection. Using pure white (0xffffff) can result in an overly bright mirror, whereas a neutral grey (0x777777 or 0x888888) mimics the light absorption of real glass and silvering.
  • multisample: Enables anti-aliasing on the reflected render target. Setting this to 2 or 4 smooths out jagged edges in the reflection.

4. Position and Add to Scene

Because PlaneGeometry is created facing the positive Z-axis, orient the mirror appropriately within your scene. For a wall mirror, simply position it against a wall:

groundMirror.position.set(0, 7.5, -10);
scene.add(groundMirror);

If creating a reflective floor, rotate the plane along the X-axis:

groundMirror.rotation.x = -Math.PI / 2;
groundMirror.position.y = 0;
scene.add(groundMirror);

5. Add a Frame and Lighting for Realism

A mirror plane alone looks unnatural without physical context. Enhance realism by placing a thin border mesh around the edges using a metallic material (MeshStandardMaterial with high metalness and low roughness). Additionally, ensure your scene contains dynamic lighting, as the objects seen in the reflection rely on the scene's ambient and directional lights for proper shading.

6. Performance Optimization

The Reflector renders the entire scene a second time from the perspective of its virtual camera every frame. To maintain steady frame rates:

  • Lower textureWidth and textureHeight (e.g., to half resolution) if your target devices have lower GPU capabilities.
  • Hide distant or non-essential geometry from the mirror's rendering phase by utilizing Three.js render layers if necessary.
  • Avoid overlapping multiple Reflector instances within the same visible area, as each active instance adds an additional full-scene render pass.
