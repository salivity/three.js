Three.js localToWorld: Get Child Forward Vector

This article explains how to determine the global forward vector of a nested child object in Three.js using the Object3D.localToWorld method. Because localToWorld transforms position coordinates rather than pure directional vectors, finding a direction requires converting both the child object's origin and a forward-offset point into world space, then calculating the normalized difference between them.

Understanding localToWorld with Direction Vectors

The Object3D.localToWorld method maps a point from an object's local coordinate space to global world space using the object's accumulated matrixWorld. Because this transformation includes translation, passing a directional vector directly into localToWorld will incorporate the object's global position, resulting in an absolute world position rather than a directional vector.

To isolate the child's forward direction, you must compute two world positions: the object's world origin and a point positioned one unit forward in the child's local space. The vector pointing from the world origin to the forward world position gives the exact forward direction in global space.

Implementation Steps

  1. Update World Matrices: Ensure the scene graph matrices are up to date by calling scene.updateMatrixWorld(true) or child.updateWorldMatrix(true, false).
  2. Define Local Forward: In Three.js, default forward conventions depend on the object type. Cameras and lights typically look along -Z (0, 0, -1), while standard meshes often face +Z (0, 0, 1).
  3. Transform Points: Pass the local origin (0, 0, 0) and the local forward vector to child.localToWorld().
  4. Subtract and Normalize: Subtract the transformed origin from the transformed forward point and normalize the result.

Code Example

import * as THREE from 'three';

function getChildWorldForward(child, isNegativeZ = false) {
  // Ensure matrices are computed
  child.updateWorldMatrix(true, false);

  // Define local forward (typically -Z for cameras, +Z for standard assets)
  const localForward = new THREE.Vector3(0, 0, isNegativeZ ? -1 : 1);
  const localOrigin = new THREE.Vector3(0, 0, 0);

  // Convert both local positions to world positions
  const worldForwardPoint = child.localToWorld(localForward);
  const worldOriginPoint = child.localToWorld(localOrigin);

  // Derive the forward direction vector
  const worldForwardDirection = worldForwardPoint
    .sub(worldOriginPoint)
    .normalize();

  return worldForwardDirection;
}

// Example usage:
const forwardDirection = getChildWorldForward(childMesh);
console.log('World Forward:', forwardDirection);

Direct Alternative: getWorldDirection

While localToWorld provides an effective way to translate arbitrary local points and offsets into world space, Three.js provides a built-in helper called Object3D.getWorldDirection that extracts the world-space direction vector directly from the matrix without needing two vector transformations:

const worldForward = new THREE.Vector3();
child.getWorldDirection(worldForward);

By default, getWorldDirection extracts the direction along the object's local positive Z-axis (0, 0, 1). If your child object is aligned to negative Z, negate the result using worldForward.negate().
