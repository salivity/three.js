Adjust HalftonePass Angles for CMYK in Three.js

This guide explains how to configure screen separation angles in the Three.js HalftonePass to replicate traditional comic book halftone printing. By translating standard subtractive CMYK (Cyan, Magenta, Yellow, Key/Black) screen angles into the additive RGB properties utilized by the shader, you can prevent visual moiré patterns and produce an authentic vintage print aesthetic.

Standard Printing Angles vs. RGB Channels

Traditional offset lithography and vintage comic printing orient screen grids at specific angles to prevent overlapping dot patterns from forming distracting moiré artifacts:

  • Cyan: 15°
  • Magenta: 75°
  • Yellow: 0° (or 90°)
  • Black (Key): 45°

Because Three.js processes colors in additive RGB space rather than subtractive CMYK, HalftonePass applies dot matrices to the Red, Green, and Blue channels. Each primary additive channel corresponds inversely to a subtractive printing ink:

  • Red channel maps to Cyan (15°)
  • Green channel maps to Magenta (75°)
  • Blue channel maps to Yellow (0°)

Configuring HalftonePass Parameters

The HalftonePass accepts an options object during instantiation where angles are defined in radians. Convert the standard degree values to radians using THREE.MathUtils.degToRad() or standard JavaScript math (degrees * (Math.PI / 180)).

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { HalftonePass } from 'three/addons/postprocessing/HalftonePass.js';

// Setup composer
const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

// Define CMYK-aligned parameters
const halftoneParams = {
    shape: 1, // 1 = Dot, 2 = Ellipse, 3 = Line, 4 = Square
    radius: 4, // Dot size
    rotateR: THREE.MathUtils.degToRad(15), // Cyan equivalent
    rotateG: THREE.MathUtils.degToRad(75), // Magenta equivalent
    rotateB: THREE.MathUtils.degToRad(0),  // Yellow equivalent
    scatter: 0,
    blending: 1,
    blendingMode: 1,
    greyscale: false
};

const halftonePass = new HalftonePass(window.innerWidth, window.innerHeight, halftoneParams);
composer.addPass(halftonePass);

Modifying Angles at Runtime

If the pass has already been instantiated, modify the internal shader uniforms directly. The pass stores these values inside its uniforms dictionary:

// Dynamically update the separation angles
halftonePass.uniforms['rAngle'].value = THREE.MathUtils.degToRad(15);
halftonePass.uniforms['gAngle'].value = THREE.MathUtils.degToRad(75);
halftonePass.uniforms['bAngle'].value = THREE.MathUtils.degToRad(0);

Fine-Tuning for Comic Aesthetics

To heighten the vintage comic look alongside correct angles:

  • Dot Radius (radius): Keep dot sizes between 3 and 6 pixels. Overly large dots degrade the underlying 3D detail, while values below 2 fail to show distinct angle separations.
  • Scatter (scatter): Set this parameter between 0.05 and 0.15 to emulate minor ink bleed and paper imperfections found in vintage pulp printing.
  • Blending Mode (blendingMode): Leave at 1 (Linear blend) to let color dots visually mix in the eye, mirroring mechanical four-color process printing.
