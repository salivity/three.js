How to Set Device Pixel Ratio in Three.js

Handling the device pixel ratio in Three.js is essential for rendering sharp 3D graphics on modern mobile devices and high-density screens. Without explicitly defining this ratio, high-DPI displays (such as Apple's Retina screens) will upscale lower-resolution render targets, resulting in blurry visuals. This guide explains how to read window.devicePixelRatio, apply it using Three.js's built-in methods, and cap it effectively to prevent severe mobile performance bottlenecks.

Using renderer.setPixelRatio

Three.js provides a native method on the WebGLRenderer instance called setPixelRatio(). This method scales the internal canvas drawing buffer relative to the CSS dimensions of the canvas element.

To match the screen's native resolution, initialize the renderer and pass window.devicePixelRatio:

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);

// Apply the native device pixel ratio
renderer.setPixelRatio(window.devicePixelRatio);

document.body.appendChild(renderer.domElement);

Optimizing for Mobile Performance

While passing window.devicePixelRatio directly ensures maximum sharpness, it can cause severe performance drops on mobile devices. Modern smartphones frequently have pixel ratios of 3, 3.5, or even 4. Rendering full 3D scenes at these resolutions forces the mobile GPU to calculate millions of additional fragments, causing frame rate drops, thermal throttling, and high battery consumption.

The industry standard approach is to clamp the pixel ratio to a maximum value, typically 2:

// Limit the pixel ratio to a maximum of 2 to balance quality and performance
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

A pixel ratio of 2 provides visual clarity that is virtually indistinguishable from 3 or higher on handheld screens, while avoiding an exponential increase in pixel fill rate.

Handling Window Resizing

When a mobile device changes orientation, or a desktop browser window is dragged across monitors with different pixel densities, the pixel ratio and canvas dimensions must update dynamically:

window.addEventListener('resize', () => {
  // Update camera aspect ratio
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();

  // Update renderer size and clamped pixel ratio
  renderer.setSize(window.innerWidth, window.innerHeight);
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
});

By clamping window.devicePixelRatio and updating it alongside window resize events, your Three.js application will render crisp, efficient visuals across all mobile and desktop devices.
