Selective Bloom with Layers in Three.js

Selective bloom allows you to apply a glowing post-processing effect exclusively to designated objects while leaving the rest of the scene untouched. In Three.js, this is achieved by assigning glowing objects to a specific camera layer, using two separate EffectComposer instances—one to generate the bloom texture from the isolated layer and another to render the base scene—and combining the two passes using a custom additive blend shader.

1. Configure Camera Layers

Three.js objects and cameras possess a layers property with 32 distinct channels (0 to 31). By default, all objects and cameras belong to Layer 0. Dedicate a separate layer (such as Layer 1) exclusively to objects that should receive bloom.

const BLOOM_SCENE = 1;
const bloomLayer = new THREE.Layers();
bloomLayer.set(BLOOM_SCENE);

// Assign glowing object to the bloom layer
glowingMesh.layers.enable(BLOOM_SCENE);

2. Handle Occlusion with Material Replacement

If you only isolate the bloom layer using camera masks, non-bloomed objects will not properly occlude blooming objects sitting behind them. To resolve this, maintain a reference to a non-reflective, pure black material (MeshBasicMaterial({ color: 'black' })) to temporarily override non-bloomed meshes during the bloom generation phase.

const darkMaterial = new THREE.MeshBasicMaterial({ color: 'black' });
const materials = {};

function darkenNonBloomed(obj) {
  if (obj.isMesh && bloomLayer.test(obj.layers) === false) {
    materials[obj.uuid] = obj.material;
    obj.material = darkMaterial;
  }
}

function restoreMaterial(obj) {
  if (materials[obj.uuid]) {
    obj.material = materials[obj.uuid];
    delete materials[obj.uuid];
  }
}

3. Build the Post-Processing Composers

Set up two instances of EffectComposer:

  1. Bloom Composer: Renders the darkened scene, applies the UnrealBloomPass, and writes the result to an internal render target.
  2. Final Composer: Renders the full scene normally, followed by a custom ShaderPass that adds the bloom texture onto the final render.
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';
import { ShaderPass } from 'three/addons/postprocessing/ShaderPass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

// Setup Bloom Composer
const renderPass = new RenderPass(scene, camera);
const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(window.innerWidth, window.innerHeight),
  1.5, // strength
  0.4, // radius
  0.85 // threshold
);

const bloomComposer = new EffectComposer(renderer);
bloomComposer.renderToScreen = false;
bloomComposer.addPass(renderPass);
bloomComposer.addPass(bloomPass);

// Setup Mixing Shader Pass
const mixPass = new ShaderPass(
  new THREE.ShaderMaterial({
    uniforms: {
      baseTexture: { value: null },
      bloomTexture: { value: bloomComposer.renderTarget2.texture }
    },
    vertexShader: `
      varying vec2 vUv;
      void main() {
        vUv = uv;
        gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
      }
    `,
    fragmentShader: `
      uniform sampler2D baseTexture;
      uniform sampler2D bloomTexture;
      varying vec2 vUv;
      void main() {
        gl_FragColor = texture2D(baseTexture, vUv) + texture2D(bloomTexture, vUv);
      }
    `,
    defines: {}
  }),
  'baseTexture'
);
mixPass.needsSwap = true;

// Setup Final Composer
const finalComposer = new EffectComposer(renderer);
finalComposer.addPass(renderPass);
finalComposer.addPass(mixPass);
finalComposer.addPass(new OutputPass());

4. Execute the Render Loop

In the animation loop, switch non-bloomed materials to black, render the bloom pass to its offscreen buffer, restore the original materials, and finally render the primary composer to the screen.

function animate() {
  requestAnimationFrame(animate);

  // 1. Darken unselected objects
  scene.traverse(darkenNonBloomed);

  // 2. Render bloom offscreen
  bloomComposer.render();

  // 3. Restore materials
  scene.traverse(restoreMaterial);

  // 4. Render the blended scene to the screen
  finalComposer.render();
}

animate();

This structure ensures that bloom calculation remains constrained to Layer 1, honors spatial occlusion from foreground geometry, and correctly blends with the rest of the scene.
