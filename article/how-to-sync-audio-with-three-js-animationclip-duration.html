How to Sync Audio with Three.js AnimationClip Duration

Synchronizing audio playback with 3D character animations in Three.js requires matching the timeline of a sound file with the visual keyframes of a 3D model. This guide explains how to extract the exact duration property from a loaded THREE.AnimationClip, initialize audio playback using Three.js audio components, and coordinate both systems to play in unison.

Accessing the AnimationClip Duration

When a 3D model with animations (such as a GLTF/GLB file) is imported, the animations are parsed into an array of THREE.AnimationClip instances. Every AnimationClip contains a native duration property that represents the total length of the animation in seconds.

// Accessing the duration directly from an AnimationClip
const clipDuration = clip.duration; // Value is in seconds (e.g., 2.45)

Step-by-Step Implementation

1. Load the Model and Extract the Clip

Use GLTFLoader to import the asset. Once loaded, access the animations array from the returned GLTF object and read the duration of the target clip.

import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
let mixer;
let action;
let animationDuration = 0;

loader.load('model.glb', (gltf) => {
    const model = gltf.scene;
    scene.add(model);

    mixer = new THREE.AnimationMixer(model);

    // Get the desired clip
    const clip = gltf.animations[0];
    
    // Extract the duration in seconds
    animationDuration = clip.duration;

    action = mixer.clipAction(clip);
    
    // Proceed to initialize and synchronize audio
    initAudioAndPlay(animationDuration);
});

2. Set Up the Audio

Set up an audio listener, a positional or ambient sound object, and load the audio buffer using THREE.AudioLoader.

const listener = new THREE.AudioListener();
camera.add(listener);

const sound = new THREE.Audio(listener);
const audioLoader = new THREE.AudioLoader();

function initAudioAndPlay(clipDuration) {
    audioLoader.load('soundtrack.mp3', (buffer) => {
        sound.setBuffer(buffer);
        sound.setLoop(true);
        
        // Optional: Match playback rate if audio and animation lengths differ
        const audioDuration = buffer.duration;
        const playbackRate = audioDuration / clipDuration;
        sound.setPlaybackRate(playbackRate);

        // Start synchronized playback
        startSync();
    });
}

3. Trigger Synchronized Playback

To ensure the animation and audio start at the exact same moment, reset the animation action before playing both components simultaneously.

function startSync() {
    // Reset and start animation
    action.reset();
    action.play();

    // Start audio
    sound.play();
}

4. Maintain the Animation Loop

Keep the THREE.AnimationMixer updated inside the standard render loop using the delta time from THREE.Clock.

const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();
    if (mixer) {
        mixer.update(delta);
    }

    renderer.render(scene, camera);
}

animate();

Handling Loop Synchronization

If the animation loops, ensure the loop modes match:

  • Looping: Call sound.setLoop(true) and set action.setLoop(THREE.LoopRepeat).
  • Single Play: If the animation does not loop, call action.setLoop(THREE.LoopOnce) with action.clampWhenFinished = true, and ensure the audio is set to sound.setLoop(false).
  • Resynchronization: In complex scenes with frame drops, periodically check mixer.time % animationDuration against sound.context.currentTime to correct drift.
