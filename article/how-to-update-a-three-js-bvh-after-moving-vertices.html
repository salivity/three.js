How to Update a Three.js BVH After Moving Vertices

When manipulating mesh vertices dynamically in Three.js, any underlying Bounding Volume Hierarchy (BVH)—such as the one provided by the popular three-mesh-bvh library—becomes desynchronized from the actual geometry. To restore accurate raycasting and spatial queries, you must mark the position attribute for a GPU update, recalculate the geometry’s standard bounding volumes, and either refit or fully recompute the BVH structure. This guide explains how to properly handle this update pipeline for dynamic, deformed, or animated meshes.

1. Flag the Geometry Attribute for Update

Direct modifications to the geometry.attributes.position.array happen in CPU memory. To ensure Three.js uploads the modified vertex data to the GPU on the next render frame, set the needsUpdate flag:

// After altering the position array values
geometry.attributes.position.needsUpdate = true;

2. Update Standard Three.js Bounds

Three.js uses standard bounding spheres and bounding boxes for high-level frustum culling before executing granular BVH checks. If these are not recalculated, your mesh may disappear prematurely when its new bounds leave the camera's view frustum:

geometry.computeBoundingBox();
geometry.computeBoundingSphere();

3. Update the BVH

Depending on the extent of vertex displacement, you can update the BVH using one of two methods: refitting or rebuilding.

Method A: Refitting the Existing BVH (Recommended for Performance)

If the mesh topology remains identical and vertices only shift moderately (such as during cloth simulation, skinning, or waving vegetation), use the refit() method. Refitting updates the existing node bounds without restructuring the entire tree hierarchy, making it significantly faster and suitable for per-frame execution:

if (geometry.boundsTree) {
  geometry.boundsTree.refit();
}

Method B: Rebuilding the BVH (Recommended for Large Deformations)

If the geometry undergoes drastic deformations or topological modifications, the original tree structure may become inefficient, resulting in degraded raycasting performance. In this case, dispose of or overwrite the existing bounds tree by recalculating it entirely:

// Fully recomputes the tree structure from scratch
geometry.computeBoundsTree();

Complete Implementation Example

function updateDynamicMesh(mesh) {
  const geometry = mesh.geometry;
  const positions = geometry.attributes.position;

  // Example: Apply dynamic displacement
  for (let i = 0; i < positions.count; i++) {
    const y = positions.getY(i);
    positions.setY(i, y + Math.sin(Date.now() * 0.005 + i) * 0.01);
  }

  // 1. Notify Three.js to send data to the GPU
  positions.needsUpdate = true;

  // 2. Recompute basic Three.js culling volumes
  geometry.computeBoundingBox();
  geometry.computeBoundingSphere();

  // 3. Fast-update the BVH structure
  if (geometry.boundsTree) {
    geometry.boundsTree.refit();
  }
}
