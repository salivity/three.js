Access Shadow Map Depth Texture in Three.js

This article explains how to retrieve and use the raw depth texture generated by a light's shadow map in Three.js. You will learn the exact lifecycle requirements for when the shadow map render target is created, how to extract the underlying depth texture from the light's properties, and how to pass and read that texture inside a custom shader for depth-based effects.

1. Ensure the Shadow Map is Generated

In Three.js, a light's shadow map is not allocated immediately upon instantiation. The shadow map object (light.shadow.map) remains null until the renderer completes its first frame with shadows enabled.

To guarantee that the shadow map exists, ensure shadows are active on the renderer, the light, and any occluding objects, and force an initial render:

renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // or THREE.BasicShadowMap

const dirLight = new THREE.DirectionalLight(0xffffff, 1);
dirLight.castShadow = true;
dirLight.shadow.mapSize.width = 1024;
dirLight.shadow.mapSize.height = 1024;
scene.add(dirLight);

// Force an initial render so Three.js compiles the shadow pass and creates the target
renderer.render(scene, camera);

2. Retrieve the Depth Texture Reference

Once rendered, dirLight.shadow.map is an instance of THREE.WebGLRenderTarget. Depending on your Three.js version and configuration, depth information is stored in one of two places:

  1. light.shadow.map.depthTexture: When modern WebGL2 depth texture rendering is directly utilized by the shadow pass, this property contains the raw THREE.DepthTexture.
  2. light.shadow.map.texture: In standard shadow map implementations, Three.js binds the shadow depth target directly to this primary texture property.

To safely target the texture regardless of internal configuration:

const rawDepthTexture = dirLight.shadow.map.depthTexture || dirLight.shadow.map.texture;

If you require explicit control over a THREE.DepthTexture on the shadow map, assign a custom depth texture manually before rendering:

dirLight.shadow.map = new THREE.WebGLRenderTarget(1024, 1024, {
    minFilter: THREE.NearestFilter,
    magFilter: THREE.NearestFilter,
    format: THREE.RGBAFormat
});
dirLight.shadow.map.depthTexture = new THREE.DepthTexture(1024, 1024);
dirLight.shadow.map.depthTexture.type = THREE.UnsignedIntType;

3. Passing the Texture to a Custom Material

Pass the texture directly into your custom material's uniforms to use it in post-processing passes, volumetric light shafts, or debug displays:

const depthDebugMaterial = new THREE.ShaderMaterial({
    uniforms: {
        uShadowDepthMap: { value: null },
        uNear: { value: dirLight.shadow.camera.near },
        uFar: { value: dirLight.shadow.camera.far }
    },
    vertexShader: `
        varying vec2 vUv;
        void main() {
            vUv = uv;
            gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
        }
    `,
    fragmentShader: `
        uniform sampler2D uShadowDepthMap;
        uniform float uNear;
        uniform float uFar;
        varying vec2 vUv;

        // Linearize depth from orthographic or perspective projection
        float linearizeDepth(float depth, float near, float far) {
            return (2.0 * near) / (far + near - depth * (far - near));
        }

        void main() {
            // Sample the red channel where hardware depth is written
            float depthSample = texture2D(uShadowDepthMap, vUv).r;

            // Output visual representation of normalized depth
            gl_FragColor = vec4(vec3(depthSample), 1.0);
        }
    `
});

4. Updating in the Render Loop

Because shadow passes recreate and rebind targets dynamically when window sizes or shadow settings change, keep your material's uniform updated within your render loop:

function animate() {
    requestAnimationFrame(animate);

    // Render the scene
    renderer.render(scene, camera);

    // Update uniform with current shadow map reference
    if (dirLight.shadow.map) {
        depthDebugMaterial.uniforms.uShadowDepthMap.value = 
            dirLight.shadow.map.depthTexture || dirLight.shadow.map.texture;
    }
}
animate();
