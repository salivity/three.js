Three.js: Get Screen-Space Distance Between 3D Objects

Calculating the screen-space pixel distance between two 3D objects in Three.js requires converting their 3D world coordinates into 2D screen coordinates using the active camera, and then applying standard 2D Euclidean distance formulas. This guide explains how to extract world positions, project them to normalized device coordinates (NDC) via Vector3.project(), map those coordinates to viewport pixels, and compute the exact distance between them.

The Core Concept

A 3D object's position exists in local or world space. To find where that point renders on a 2D screen, you must:

  1. Retrieve the absolute world coordinates of both objects.
  2. Project those 3D world coordinates into Normalized Device Coordinates (NDC) where \(x\) and \(y\) range from -1 to 1.
  3. Map the NDC coordinates to actual pixel coordinates based on the renderer's canvas dimensions.
  4. Calculate the 2D distance between the two pixel points using the Pythagorean theorem (Math.hypot).

Step-by-Step Implementation

1. Retrieve World Positions

Do not use object.position directly if your objects are nested within groups or hierarchies, as this only provides local coordinates. Use getWorldPosition() instead:

const posA = new THREE.Vector3();
const posB = new THREE.Vector3();

objectA.getWorldPosition(posA);
objectB.getWorldPosition(posB);

2. Project to Normalized Device Coordinates

Pass the camera to Vector3.project(). This multiplies the vector by the camera's view and projection matrices:

posA.project(camera);
posB.project(camera);

After projection:

  • x = -1 corresponds to the left edge of the screen.
  • x = 1 corresponds to the right edge.
  • y = -1 corresponds to the bottom edge.
  • y = 1 corresponds to the top edge.
  • z > 1 indicates the object is behind the camera or beyond the far clipping plane.

3. Convert NDC to Screen Pixels

Convert the [-1, 1] range to [0, width] and [0, height]. Keep in mind that standard 2D screen space has its origin (0, 0) at the top-left, whereas NDC has (0, 0) at the center:

function ndcToScreen(ndcVector, width, height) {
    return {
        x: (ndcVector.x * 0.5 + 0.5) * width,
        y: (-(ndcVector.y * 0.5) + 0.5) * height
    };
}

4. Calculate Euclidean Distance

Use Math.hypot to compute the straight-line distance between the two 2D points:

const dx = screenPosA.x - screenPosB.x;
const dy = screenPosA.y - screenPosB.y;
const distance = Math.hypot(dx, dy);

Complete Reusable Function

Below is an optimized, production-ready function that reuses internal vectors to avoid garbage collection overhead during animation loops:

const _vA = new THREE.Vector3();
const _vB = new THREE.Vector3();

function getScreenSpaceDistance(objectA, objectB, camera, renderer) {
    // 1. Get world positions
    objectA.getWorldPosition(_vA);
    objectB.getWorldPosition(_vB);

    // 2. Project world positions to NDC
    _vA.project(camera);
    _vB.project(camera);

    // Optional: Return null or handle cases where objects are behind the camera
    if (_vA.z > 1 || _vB.z > 1) {
        return null;
    }

    // 3. Obtain canvas display size (CSS pixels)
    const canvas = renderer.domElement;
    const width = canvas.clientWidth;
    const height = canvas.clientHeight;

    // 4. Convert NDC to screen coordinates
    const screenAx = (_vA.x * 0.5 + 0.5) * width;
    const screenAy = (-(_vA.y * 0.5) + 0.5) * height;

    const screenBx = (_vB.x * 0.5 + 0.5) * width;
    const screenBy = (-(_vB.y * 0.5) + 0.5) * height;

    // 5. Calculate 2D distance
    return Math.hypot(screenBx - screenAx, screenBy - screenAy);
}

Key Considerations

  • CSS Pixels vs. Render Target Pixels: Use canvas.clientWidth and canvas.clientHeight when positioning HTML overlay elements (tooltips, UI markers). Use renderer.getSize() if you need distances relative to internal buffer pixels.
  • Objects Behind the Camera: If an object sits behind the camera's near plane, its projected coordinates will invert across the center. Always check if vector.z <= 1 before performing distance-based interactions or rendering UI labels.
