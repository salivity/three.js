Transform World to Camera Coordinates in Three.js

In Three.js, converting 3D objects from global world coordinates into local camera coordinates is a fundamental task for custom projection, occlusion culling, and spatial calculations. This article explains how to utilize the camera's matrixWorldInverse property to map any global Vector3 directly into view space (camera space). By applying this inverse matrix, you transform standard global coordinates so that the camera becomes the origin (0, 0, 0), establishing a coordinate frame where positions are relative to the camera's current point of view.

Understanding matrixWorldInverse

Every object in Three.js maintains a matrixWorld, which defines its position, rotation, and scale relative to the scene's global origin. The camera also has a matrixWorld.

The camera.matrixWorldInverse property is the mathematical inverse of the camera's matrixWorld. When you multiply a world-space point by matrixWorldInverse, it transforms that point from global space into the camera's local coordinate system (often called View Space or Eye Space). In this system:

  • (0, 0, 0) is the camera's optical center.
  • The positive X-axis points to the camera's right.
  • The positive Y-axis points up relative to the camera.
  • The negative Z-axis extends directly in front of the camera's lens.

Step-by-Step Implementation

To perform this transformation accurately, follow these three steps:

1. Update Camera Matrices

Before performing matrix calculations, ensure that the camera's spatial transform and its inverse are synchronized with its current position and orientation. While the Three.js renderer does this automatically inside the render loop, manual calculations outside or before the render call require an explicit update:

camera.updateMatrixWorld();

2. Obtain the Target World Position

Ensure your target coordinate is explicitly in world space. If the target is a child of another transformed object, extract its world coordinates using getWorldPosition():

const targetWorldPosition = new THREE.Vector3();
targetMesh.getWorldPosition(targetWorldPosition);

If you already have a static world-space vector, instantiate it directly:

const targetWorldPosition = new THREE.Vector3(10, 5, -20);

3. Apply matrixWorldInverse

Use the applyMatrix4() method on the vector to apply the transformation. This mutates the vector in place:

// Transform the point from world space to camera space
targetWorldPosition.applyMatrix4(camera.matrixWorldInverse);

console.log(`X (Right/Left): ${targetWorldPosition.x}`);
console.log(`Y (Up/Down): ${targetWorldPosition.y}`);
console.log(`Z (Depth/Distance): ${targetWorldPosition.z}`);

Complete Example Function

Here is a reusable function that takes a target vector, applies the transformation, and returns a new vector representing the camera-relative position without modifying the original coordinates:

function getCameraRelativePosition(worldVector, camera) {
    // Ensure the camera's matrix and inverse matrix are up to date
    camera.updateMatrixWorld();

    // Clone the vector to avoid mutating the original input
    const cameraRelativeVector = worldVector.clone();

    // Multiply the vector by the camera's inverse world matrix
    cameraRelativeVector.applyMatrix4(camera.matrixWorldInverse);

    return cameraRelativeVector;
}

// Usage:
const globalPoint = new THREE.Vector3(0, 2, -10);
const relativePoint = getCameraRelativePosition(globalPoint, camera);

View Space vs. Screen Space

Do not confuse matrixWorldInverse with Vector3.project(camera).

  • matrixWorldInverse converts global coordinates to View Space, retaining metric units. A point with a z value of -5 is exactly 5 units in front of the camera.
  • Vector3.project(camera) applies both matrixWorldInverse and the camera's projectionMatrix to convert coordinates into Normalized Device Coordinates (NDC), where coordinates range from -1 to 1 across the screen axes.

Use matrixWorldInverse when you need metric measurements, directional offsets, or view-aligned distance relative to the camera.
