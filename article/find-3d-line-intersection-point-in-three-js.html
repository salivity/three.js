Find 3D Line Intersection Point in Three.js

This article explains how to determine the exact intersection point of two distinct 3D lines in Three.js using parametric line equations and linear algebra. In 3D space, two arbitrary lines are usually skew (they do not intersect and are not parallel); therefore, finding an intersection requires determining the points of closest approach on each line and verifying if the distance between those points is within an acceptable floating-point tolerance.

Mathematical Formulation

A 3D line can be defined parametrically using an origin point \(\mathbf{p}\) and a normalized direction vector \(\mathbf{d}\):

\[\mathbf{L}_1(s) = \mathbf{p}_1 + s\mathbf{d}_1\] \[\mathbf{L}_2(t) = \mathbf{p}_2 + t\mathbf{d}_2\]

Where \(s\) and \(t\) are real scalar parameters.

To find where these lines intersect, we solve for the values of \(s\) and \(t\) that minimize the distance between \(\mathbf{L}_1(s)\) and \(\mathbf{L}_2(t)\). The vector connecting any two points on the lines is:

\[\mathbf{w}(s, t) = \mathbf{L}_1(s) - \mathbf{L}_2(t) = (\mathbf{p}_1 - \mathbf{p}_2) + s\mathbf{d}_1 - t\mathbf{d}_2\]

At the closest approach, \(\mathbf{w}(s, t)\) is perpendicular to both direction vectors \(\mathbf{d}_1\) and \(\mathbf{d}_2\):

\[\mathbf{d}_1 \cdot \mathbf{w}(s, t) = 0\] \[\mathbf{d}_2 \cdot \mathbf{w}(s, t) = 0\]

Let \(\mathbf{w}_0 = \mathbf{p}_1 - \mathbf{p}_2\). Expanding the dot products yields a system of two linear equations:

\[s(\mathbf{d}_1 \cdot \mathbf{d}_1) - t(\mathbf{d}_1 \cdot \mathbf{d}_2) = -\mathbf{d}_1 \cdot \mathbf{w}_0\] \[s(\mathbf{d}_2 \cdot \mathbf{d}_1) - t(\mathbf{d}_2 \cdot \mathbf{d}_2) = -\mathbf{d}_2 \cdot \mathbf{w}_0\]

Defining the scalar dot products:

  • \(a = \mathbf{d}_1 \cdot \mathbf{d}_1\)
  • \(b = \mathbf{d}_1 \cdot \mathbf{d}_2\)
  • \(c = \mathbf{d}_2 \cdot \mathbf{d}_2\)
  • \(d = \mathbf{d}_1 \cdot \mathbf{w}_0\)
  • \(e = \mathbf{d}_2 \cdot \mathbf{w}_0\)

The denominator of the system is given by:

\[D = ac - b^2\]

  1. Parallel Lines: If \(D \approx 0\), the lines are parallel or collinear and do not intersect at a single unique point.
  2. Skew or Intersecting Lines: If \(D \neq 0\), the parameters for the closest points are:

\[s = \frac{be - cd}{D}\] \[t = \frac{ae - bd}{D}\]

The closest points on each line are calculated as:

  • \(\mathbf{Q}_1 = \mathbf{p}_1 + s\mathbf{d}_1\)
  • \(\mathbf{Q}_2 = \mathbf{p}_2 + t\mathbf{d}_2\)

If the Euclidean distance \(\|\mathbf{Q}_1 - \mathbf{Q}_2\| < \epsilon\) (where \(\epsilon\) is a threshold such as \(10^{-6}\)), the lines intersect at \(\mathbf{Q}_1\).

Three.js Implementation

import * as THREE from 'three';

/**
 * Calculates the exact intersection point of two 3D lines.
 * @param {THREE.Vector3} p1 - Origin point of line 1
 * @param {THREE.Vector3} d1 - Direction vector of line 1 (must be non-zero)
 * @param {THREE.Vector3} p2 - Origin point of line 2
 * @param {THREE.Vector3} d2 - Direction vector of line 2 (must be non-zero)
 * @param {number} tolerance - Allowed deviation for floating point precision
 * @returns {THREE.Vector3|null} The intersection point, or null if no intersection exists
 */
function findLineIntersection(p1, d1, p2, d2, tolerance = 1e-6) {
    const dir1 = d1.clone().normalize();
    const dir2 = d2.clone().normalize();
    const w0 = new THREE.Vector3().subVectors(p1, p2);

    const a = dir1.dot(dir1); // Always 1 due to normalization
    const b = dir1.dot(dir2);
    const c = dir2.dot(dir2); // Always 1 due to normalization
    const d = dir1.dot(w0);
    const e = dir2.dot(w0);

    const denominator = a * c - b * b;

    // Denominator close to 0 indicates parallel lines
    if (Math.abs(denominator) < tolerance) {
        return null;
    }

    const s = (b * e - c * d) / denominator;
    const t = (a * e - b * d) / denominator;

    const pointOnLine1 = new THREE.Vector3().copy(p1).addScaledVector(dir1, s);
    const pointOnLine2 = new THREE.Vector3().copy(p2).addScaledVector(dir2, t);

    // Verify whether the two closest points are within the intersection threshold
    if (pointOnLine1.distanceTo(pointOnLine2) <= tolerance) {
        return pointOnLine1;
    }

    // Lines are skew
    return null;
}

Usage with Three.js Line Objects

When extracting line definitions from THREE.Line or THREE.LineSegments, retrieve the endpoints from the underlying geometry and calculate the direction vector:

const positions = lineMesh.geometry.attributes.position;

const p1 = new THREE.Vector3().fromBufferAttribute(positions, 0);
const end1 = new THREE.Vector3().fromBufferAttribute(positions, 1);
const d1 = new THREE.Vector3().subVectors(end1, p1);

// Apply world matrix transformations if lines belong to scene hierarchy
p1.applyMatrix4(lineMesh.matrixWorld);
d1.transformDirection(lineMesh.matrixWorld);

const intersection = findLineIntersection(p1, d1, p2, d2);

if (intersection) {
    console.log("Intersection found at:", intersection);
} else {
    console.log("Lines do not intersect.");
}
