Save Three.js Canvas with preserveDrawingBuffer

Capturing a high-quality image or screenshot from a Three.js scene often results in a blank or black file due to WebGL's default buffer management. This guide explains how to enable the preserveDrawingBuffer option when initializing the WebGLRenderer, preventing the browser from clearing the render buffer and allowing you to easily export the canvas to an image format like PNG or JPEG.

Why the Canvas Clears by Default

By default, WebGL clears its drawing buffer immediately after presenting the rendered frame to the screen to optimize memory and performance. If a user clicks a button to take a screenshot via standard HTML5 canvas methods such as toDataURL() or toBlob(), the operation reads an already cleared buffer, returning an empty image.

Enabling preserveDrawingBuffer: true forces the WebGL context to retain the contents of the drawing buffer until the next render pass, allowing asynchronous operations like user-triggered screen captures to read the pixel data successfully.

Step 1: Enable preserveDrawingBuffer

Pass the preserveDrawingBuffer flag as an option in the constructor of your THREE.WebGLRenderer:

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer({
  canvas: document.querySelector('#webgl-canvas'),
  preserveDrawingBuffer: true,
  antialias: true
});

renderer.setSize(window.innerWidth, window.innerHeight);

Step 2: Implement the Snapshot Function

Once preserveDrawingBuffer is enabled, you can read the canvas data directly using canvas.toDataURL() and trigger a file download using a temporary <a> element.

function takeSnapshot() {
  // Get the canvas element from the renderer
  const canvas = renderer.domElement;

  // Convert the canvas contents to a Base64-encoded PNG URL
  const imageURL = canvas.toDataURL('image/png');

  // Create a temporary anchor element to trigger download
  const link = document.createElement('a');
  link.download = 'threejs-snapshot.png';
  link.href = imageURL;
  
  // Append, click, and clean up
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
}

Attach this function to a button click event in your application:

document.querySelector('#snapshot-button').addEventListener('click', takeSnapshot);

Performance Consideration

Setting preserveDrawingBuffer: true can prevent certain hardware-accelerated buffer swapping optimizations on mobile and lower-end devices, which may lead to a minor drop in frame rate.

If performance is critical, you can leave preserveDrawingBuffer set to false and instead call canvas.toDataURL() synchronously immediately after your renderer.render(scene, camera) call inside your animation loop or an explicit capture function. However, for most interactive 3D applications, preserveDrawingBuffer: true is the most straightforward and reliable approach for enabling user-driven snapshots.
