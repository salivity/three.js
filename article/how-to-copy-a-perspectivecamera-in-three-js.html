How to Copy a PerspectiveCamera in Three.js

Duplicating an existing PerspectiveCamera in Three.js allows you to preserve viewing angles, aspect ratios, and spatial transforms for multi-view rendering, split screens, or state caching. This guide demonstrates how to use the native .copy() method to duplicate the exact state of a source camera into a target camera instance.

Using the .copy() Method

To duplicate a camera, instantiate a new THREE.PerspectiveCamera and call its .copy() method, passing the original camera as the argument.

import * as THREE from 'three';

// 1. Existing camera setup
const originalCamera = new THREE.PerspectiveCamera(
  60, 
  window.innerWidth / window.innerHeight, 
  0.1, 
  1000
);
originalCamera.position.set(10, 15, 20);
originalCamera.lookAt(0, 0, 0);
originalCamera.updateMatrixWorld();

// 2. Create the target camera
const cameraClone = new THREE.PerspectiveCamera();

// 3. Duplicate the state
cameraClone.copy(originalCamera);

What .copy() Duplicates

Because THREE.PerspectiveCamera inherits from THREE.Camera and THREE.Object3D, the .copy() method transfers both optical projection parameters and 3D transform properties:

  • Projection Properties: Field of view (fov), aspect ratio (aspect), near clipping plane (near), far clipping plane (far), zoom (zoom), and view offset settings (view).
  • Transform Properties: Position (position), rotation (rotation), orientation (quaternion), scale (scale), and visibility (visible).
  • Matrix States: Local transformation matrix (matrix) and world transformation matrix (matrixWorld).

Handling Hierarchies and Children

The .copy() method accepts an optional second boolean parameter, recursive, which defaults to true:

cameraClone.copy(originalCamera, false);
  • true (Default): Clones any child objects attached to the original camera (such as lights or HUD elements).
  • false: Copies only the camera’s internal properties and transforms, ignoring any attached children.

Post-Copy Considerations

  1. Projection Matrix: The .copy() implementation in Three.js internally updates the projection matrix based on the copied frustum parameters. If you manually modify the copied camera's fov, aspect, near, or far afterward, call cameraClone.updateProjectionMatrix().
  2. Scene Hierarchy: Duplicating a camera does not automatically add the clone to the scene. If your setup requires the camera to be part of the scene graph (for example, if it has children or relies on a parent transform), you must explicitly run scene.add(cameraClone).
