Load TGA Textures in Three.js with TGALoader

This guide demonstrates how to load and apply Truevision TGA (.tga) image files as textures in Three.js. Because the default THREE.TextureLoader only handles standard web formats like PNG and JPEG, you must use the specialized TGALoader add-on. Below, you will find the required imports, configuration steps, and a complete code example to map a TGA texture onto a 3D mesh.

1. Import Three.js and TGALoader

TGALoader is not included in the core Three.js bundle, so you must import it from the addons directory.

import * as THREE from 'three';
import { TGALoader } from 'three/addons/loaders/TGALoader.js';

2. Instantiate the Loader and Load the Texture

Create an instance of TGALoader and call its .load() method. The method takes the path to your .tga file and returns a texture object inside a callback function.

const loader = new TGALoader();

loader.load(
    'textures/crate.tga',
    function (texture) {
        // Correct color space for standard color maps
        texture.colorSpace = THREE.SRGBColorSpace;

        // Apply texture to a material
        const material = new THREE.MeshStandardMaterial({ map: texture });

        // Create mesh and add to scene
        const geometry = new THREE.BoxGeometry(1, 1, 1);
        const cube = new THREE.Mesh(geometry, material);
        scene.add(cube);
    },
    function (xhr) {
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    function (error) {
        console.error('An error occurred loading the TGA texture:', error);
    }
);

Complete Implementation Example

The following script sets up a basic scene, lighting, camera, and renderer, and applies a TGA texture to a rotating cube:

import * as THREE from 'three';
import { TGALoader } from 'three/addons/loaders/TGALoader.js';

// Setup Scene, Camera, and Renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 2;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Add Lighting
const ambientLight = new THREE.AmbientLight(0xffffff, 0.6);
scene.add(ambientLight);

const directionalLight = new THREE.DirectionalLight(0xffffff, 0.8);
directionalLight.position.set(2, 2, 5);
scene.add(directionalLight);

// Load TGA Texture and Create Mesh
let mesh;
const loader = new TGALoader();

loader.load('textures/example.tga', (texture) => {
    texture.colorSpace = THREE.SRGBColorSpace;
    
    const geometry = new THREE.BoxGeometry();
    const material = new THREE.MeshStandardMaterial({ map: texture });
    
    mesh = new THREE.Mesh(geometry, material);
    scene.add(mesh);
});

// Render Loop
function animate() {
    requestAnimationFrame(animate);

    if (mesh) {
        mesh.rotation.x += 0.01;
        mesh.rotation.y += 0.01;
    }

    renderer.render(scene, camera);
}

animate();

Important Notes

  • Color Management: Always assign texture.colorSpace = THREE.SRGBColorSpace for diffuse/albedo maps to ensure accurate color representation in modern Three.js versions.
  • Server Hosting: Because TGA loading uses fetch under the hood, your project must run through a local web server (such as Vite, Live Server, or Node.js) to avoid Cross-Origin Request (CORS) errors.
