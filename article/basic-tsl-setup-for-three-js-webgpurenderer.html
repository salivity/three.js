Basic TSL Setup for Three.js WebGPURenderer

This guide provides an overview and step-by-step implementation for setting up a scene using the experimental Three.js WebGPURenderer paired with the Three.js Shading Language (TSL). You will learn how to configure the asynchronous WebGPU environment, replace traditional GLSL strings with expressive, JavaScript-based node shaders, and apply a functional TSL material to a 3D mesh.

Setting Up the Environment

To use TSL and WebGPU, import the modern components directly from Three.js. Instead of the standard WebGLRenderer, you must import WebGPURenderer and the node-based materials.

import * as THREE from 'three';
import { WebGPURenderer } from 'three/webgpu';
import { color, positionLocal, time, sin, vec3 } from 'three/tsl';

Initializing the WebGPURenderer

WebGPU requires asynchronous initialization before rendering can begin. Create the renderer, configure its dimensions, append it to the DOM, and call init().

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 3;

const renderer = new WebGPURenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Initialize the WebGPU context
await renderer.init();

Constructing a TSL Material

TSL replaces raw GLSL strings with functional, composable JavaScript nodes. Instead of writing vertex and fragment shader text, you assign node expressions directly to node material properties such as colorNode or positionNode.

Here is how to create an animated, dynamic color gradient using built-in TSL functions:

// Define custom shading logic using TSL
const redComponent = sin(time.mul(2.0)).mul(0.5).add(0.5);
const animatedColor = vec3(redComponent, positionLocal.y.add(0.5), 1.0);

// Apply the nodes to a MeshBasicNodeMaterial
const material = new THREE.MeshBasicNodeMaterial();
material.colorNode = animatedColor;

In this example:

  • time provides the elapsed execution time.
  • positionLocal accesses the local vertex coordinates.
  • Math operators like .mul() (multiply) and .add() combine values into a vec3 vector node.

Adding the Mesh and Starting the Loop

Assign the material to a geometry, add it to the scene, and initiate the render loop using setAnimationLoop.

const geometry = new THREE.BoxGeometry(1, 1, 1);
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

renderer.setAnimationLoop(() => {
    cube.rotation.x += 0.01;
    cube.rotation.y += 0.01;

    renderer.render(scene, camera);
});

Complete Working Implementation

import * as THREE from 'three';
import { WebGPURenderer } from 'three/webgpu';
import { positionLocal, time, sin, vec3 } from 'three/tsl';

async function initApp() {
    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
    camera.position.z = 2.5;

    const renderer = new WebGPURenderer({ antialias: true });
    renderer.setSize(window.innerWidth, window.innerHeight);
    document.body.appendChild(renderer.domElement);

    await renderer.init();

    // TSL Shader Logic
    const dynamicGreen = sin(time.mul(3.0)).mul(0.5).add(0.5);
    const customColorNode = vec3(positionLocal.x.abs(), dynamicGreen, 0.8);

    const material = new THREE.MeshBasicNodeMaterial();
    material.colorNode = customColorNode;

    const mesh = new THREE.Mesh(new THREE.TorusKnotGeometry(0.6, 0.2, 128, 32), material);
    scene.add(mesh);

    window.addEventListener('resize', () => {
        camera.aspect = window.innerWidth / window.innerHeight;
        camera.updateProjectionMatrix();
        renderer.setSize(window.innerWidth, window.innerHeight);
    });

    renderer.setAnimationLoop(() => {
        mesh.rotation.x += 0.005;
        mesh.rotation.y += 0.01;
        renderer.render(scene, camera);
    });
}

initApp();
