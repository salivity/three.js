How to Clamp a Vector3 to a Box3 in Three.js

In Three.js, constraining 3D coordinates within specific boundaries is a common requirement for movement constraints, camera boundaries, and physics simulations. This guide demonstrates how to restrict a THREE.Vector3 position to the interior of a THREE.Box3 bounding volume using the built-in clampPoint method.

Understanding Box3.clampPoint

The clampPoint method takes an input vector, evaluates its coordinates against the minimum and maximum boundaries of an axis-aligned bounding box (Box3), and copies the clamped coordinates to a target vector.

The method signature is:

box3.clampPoint( point, target )
  • point (THREE.Vector3): The point you want to clamp within the box.
  • target (THREE.Vector3): The vector where the clamped result will be written.

The method returns the target vector, allowing for method chaining if necessary.

Step-by-Step Implementation

To clamp a point, define your boundary box, specify the point to test, and execute clampPoint.

import * as THREE from 'three';

// 1. Define the bounding box
const min = new THREE.Vector3(-5, 0, -5);
const max = new THREE.Vector3(5, 10, 5);
const boundaryBox = new THREE.Box3(min, max);

// 2. Define a point that lies outside the boundary
const originalPosition = new THREE.Vector3(12, 15, -8);

// 3. Create a target vector to store the clamped result
const clampedPosition = new THREE.Vector3();

// 4. Clamp the point inside the box
boundaryBox.clampPoint(originalPosition, clampedPosition);

console.log(clampedPosition);
// Output: Vector3 { x: 5, y: 10, z: -5 }

Overwriting the Original Vector

If you do not need to preserve the original point's values and want to save memory, you can pass the original vector as both the source and the target:

const playerPosition = new THREE.Vector3(25, 4, -30);
const arenaBounds = new THREE.Box3(
  new THREE.Vector3(-10, 0, -10),
  new THREE.Vector3(10, 10, 10)
);

// Mutates playerPosition directly
arenaBounds.clampPoint(playerPosition, playerPosition);

console.log(playerPosition);
// Output: Vector3 { x: 10, y: 4, z: -10 }

Best Practice for Animation Loops

When using clampPoint inside a render or animation loop (such as keeping a moving mesh inside a boundary), avoid instantiating new THREE.Vector3 objects on every frame to prevent unnecessary garbage collection overhead:

// Allocate reusable objects outside the render loop
const boundary = new THREE.Box3(new THREE.Vector3(-10, -10, -10), new THREE.Vector3(10, 10, 10));

function update() {
  requestAnimationFrame(update);

  // Update object position based on velocity/input
  mesh.position.add(velocity);

  // Restrict mesh position within the boundary
  boundary.clampPoint(mesh.position, mesh.position);

  renderer.render(scene, camera);
}
