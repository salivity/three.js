Grab Objects in Three.js VR Using squeezestart

This article provides a concise guide on how to implement realistic object-grabbing mechanics in virtual reality using Three.js and the WebXR Device API. By targeting the squeezestart and squeezeend controller events, you will learn how to detect when a user presses the physical grip button, find nearby or intersecting meshes, and parent them to the controller to achieve smooth pickup and release interactions.

Setting Up the Controllers

To capture grip inputs in Three.js, you need to access the XR controller instances provided by the WebGL renderer. Three.js exposes controllers through index values (0 for the first detected controller, 1 for the second).

const controller1 = renderer.xr.getController(0);
scene.add(controller1);

const controller2 = renderer.xr.getController(1);
scene.add(controller2);

Implementing squeezestart to Grab Objects

The squeezestart event fires when the user depresses the controller's grip button. To grab an object, you must determine which object is currently in range of the controller and attach it to the controller's hierarchy.

Three.js provides the attach() method, which changes an object’s parent while maintaining its current world position, rotation, and scale. This prevents the grabbed mesh from jumping or glitching upon contact.

const grabbableObjects = []; // Populate with your interactive meshes
const raycaster = new THREE.Raycaster();
const tempMatrix = new THREE.Matrix4();

function onSqueezeStart(event) {
  const controller = event.target;

  // Cast a ray or check distance to find grabbable objects
  tempMatrix.identity().extractRotation(controller.matrixWorld);
  raycaster.ray.origin.setFromMatrixPosition(controller.matrixWorld);
  raycaster.ray.direction.set(0, 0, -1).applyMatrix4(tempMatrix);

  const intersects = raycaster.intersectObjects(grabbableObjects, false);

  if (intersects.length > 0) {
    const targetObject = intersects[0].object;
    
    // Attach the object to the controller
    controller.attach(targetObject);
    controller.userData.selected = targetObject;
  }
}

Implementing squeezeend to Release Objects

When the player releases the grip button, the squeezeend event is fired. To release the object, check if the controller is holding anything, and then attach the mesh back to the root scene.

function onSqueezeEnd(event) {
  const controller = event.target;

  if (controller.userData.selected !== undefined) {
    const object = controller.userData.selected;

    // Return the object to the scene graph
    scene.attach(object);

    // Clear controller selection reference
    controller.userData.selected = undefined;
  }
}

Binding the Events

Finally, attach the functions to each controller's event listeners:

[controller1, controller2].forEach((controller) => {
  controller.addEventListener('squeezestart', onSqueezeStart);
  controller.addEventListener('squeezeend', onSqueezeEnd);
});

Using controller.attach() inside the squeezestart handler ensures precise, zero-offset grabs while simplifying transformation calculations in Three.js WebXR applications.
