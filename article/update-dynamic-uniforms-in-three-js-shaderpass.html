Update Dynamic Uniforms in Three.js ShaderPass

In Three.js post-processing pipelines, passing continuously changing values like elapsed time, screen resolution, or pointer coordinates into a custom fragment shader requires mutating the pass's uniform references on every frame. This guide details how to define custom uniforms, attach them to a ShaderPass, and update their values inside the main animation loop prior to calling the EffectComposer render step.

1. Define the Custom Shader Object

A custom ShaderPass requires an object containing a uniforms dictionary, a vertexShader, and a fragmentShader. Three.js provides default post-processing vertex shaders, but you must declare your dynamic variables alongside the default texture uniform (tDiffuse).

import * as THREE from 'three';

export const CustomDistortionShader = {
  uniforms: {
    tDiffuse: { value: null }, // Required: receives the previous pass texture
    uTime: { value: 0.0 },
    uResolution: { value: new THREE.Vector2() },
    uMouse: { value: new THREE.Vector2(0.5, 0.5) }
  },
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform sampler2D tDiffuse;
    uniform float uTime;
    uniform vec2 uResolution;
    uniform vec2 uMouse;
    varying vec2 vUv;

    void main() {
      vec2 uv = vUv;
      // Example dynamic behavior using uTime
      uv.x += sin(uv.y * 10.0 + uTime) * 0.01;
      vec4 color = texture2D(tDiffuse, uv);
      gl_FragColor = color;
    }
  `
};

2. Instantiate and Register the ShaderPass

Create an instance of ShaderPass from three/addons/postprocessing/ShaderPass.js passing in your shader definition. Add the pass to your EffectComposer.

import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { ShaderPass } from 'three/addons/postprocessing/ShaderPass.js';

// Setup Composer
const composer = new EffectComposer(renderer);
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// Setup Custom ShaderPass
const customPass = new ShaderPass(CustomDistortionShader);
composer.addPass(customPass);

3. Update Dynamic Values Inside the Animation Loop

When ShaderPass is instantiated, it clones the uniforms provided in the shader definition and binds them to an internal ShaderMaterial. You can modify these values via customPass.uniforms[name].value or customPass.material.uniforms[name].value.

To keep uniforms synced across frames, modify the .value property directly in the requestAnimationFrame callback before calling composer.render().

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const elapsedTime = clock.getElapsedTime();

  // 1. Direct uniform update
  customPass.uniforms.uTime.value = elapsedTime;

  // 2. Vector update (modify in place to avoid garbage collection)
  customPass.uniforms.uMouse.value.set(mouseCoords.x, mouseCoords.y);

  // 3. Render through the composer, not the standard renderer
  composer.render();
}

animate();

4. Handling Resizes for Dynamic Screen Dimensions

If passing viewport dimensions via a Vector2 uniform, update the uniform directly inside the window resize event handler:

window.addEventListener('resize', () => {
  const width = window.innerWidth;
  const height = window.innerHeight;

  camera.aspect = width / height;
  camera.updateProjectionMatrix();

  renderer.setSize(width, height);
  composer.setSize(width, height);

  // Update uniform dimensions
  customPass.uniforms.uResolution.value.set(width, height);
});

Key Technical Considerations

  • Direct Mutation: Mutate uniform objects in place (e.g., using Vector2.set() or Color.set()) instead of reallocating new Three.js math instances per frame to avoid memory churn and GC pauses.
  • Property Access: While both customPass.uniforms and customPass.material.uniforms refer to the same uniforms object, mutating customPass.uniforms directly is standard practice for ShaderPass.
  • Execution Order: Ensure all uniform assignments occur immediately prior to composer.render(). Calling renderer.render(scene, camera) separately will bypass the post-processing chain and uniform updates.
