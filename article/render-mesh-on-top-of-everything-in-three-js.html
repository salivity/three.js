Render Mesh on Top of Everything in Three.js

This article explains how to force a mesh to render on top of all other objects in Three.js, regardless of its distance or physical position relative to the camera. By combining material depth settings with the object’s rendering order, you can guarantee that elements like UI markers, selection highlights, or HUD components are never occluded by surrounding 3D geometry.

Method 1: Using depthTest and renderOrder

The standard and most efficient way to render a mesh on top of everything else is to disable depth testing on the material and assign a high renderOrder to the mesh.

Step-by-Step Implementation

  1. Disable depthTest on the Material: Setting depthTest to false instructs the GPU to bypass comparing the object's depth with the depth buffer, ensuring it will not be hidden behind other objects.
  2. Disable depthWrite (Recommended): Setting depthWrite to false prevents the mesh from writing its own depth values into the depth buffer, preventing visual artifacts with other transparent or overlay elements.
  3. Increase renderOrder on the Mesh: By default, Three.js renders objects based on distance and material settings. Assigning a positive integer higher than the default (0) ensures this mesh renders after all standard geometry has been drawn.
// Configure the material
mesh.material.depthTest = false;
mesh.material.depthWrite = false;

// Ensure the mesh is drawn after other objects
mesh.renderOrder = 999;

Limitation: Self-Occlusion

When depthTest is set to false, the mesh cannot perform depth tests on itself. For complex, non-flat 3D shapes, back faces or interior geometry may render on top of the front faces. If your mesh is a flat plane, a 2D billboard, or a simple outline, this method works cleanly.

Method 2: Using a Secondary Scene or Depth Clearing

If your overlay mesh is a complex 3D object that requires internal depth testing (self-occlusion) while still rendering on top of the main scene, you must clear the depth buffer between render calls.

Implementation

  1. Place your overlay objects into a separate Scene instance.
  2. Disable autoClear on the WebGL renderer.
  3. Render the main scene, clear the depth buffer manually, and then render the overlay scene.
// Render loop setup
renderer.autoClear = false;

function animate() {
  requestAnimationFrame(animate);

  // Clear color and depth buffers
  renderer.clear();

  // Render the primary scene
  renderer.render(mainScene, camera);

  // Clear depth buffer so the overlay scene renders on top
  renderer.clearDepth();

  // Render the overlay scene with proper internal depth testing
  renderer.render(overlayScene, camera);
}

In this setup, leave depthTest enabled (true) on the overlay mesh's material. The mesh will calculate its own depth correctly without being occluded by the objects rendered in the primary scene.
