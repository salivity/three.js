Force Square Particles in Three.js Using GLSL

This article explains how to render strictly square particles instead of round ones using raw GLSL in Three.js. By default, GPU point primitives are square quads, but developers frequently encounter rounded particles due to texture maps or fragment shader disc-clipping math. Below, you will learn how to construct a custom vertex and fragment shader using ShaderMaterial to ensure your Points objects render with sharp, perfectly square boundaries.

Understanding Point Rasterization

In WebGL, rendering a THREE.Points object creates screen-aligned quad primitives at each vertex location. The size of the quad on screen is governed by gl_PointSize. The fragment shader coordinates for each point range from (0.0, 0.0) at the top-left to (1.0, 1.0) at the bottom-right via the built-in variable gl_PointCoord.

Round particles are created intentionally by discarding pixels where the distance from gl_PointCoord to the center (0.5, 0.5) is greater than 0.5. To force points to be strictly square, you simply omit this circular discard logic and allow the fragment shader to fill the entire [0.0, 1.0] square coordinate space.

Vertex Shader

The vertex shader controls the position and size of each particle on the screen.

uniform float uSize;
uniform float uScale;

void main() {
    vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
    
    // Set particle size with perspective attenuation
    gl_PointSize = uSize * (uScale / -mvPosition.z);
    
    gl_Position = projectionMatrix * mvPosition;
}

If you do not want size attenuation (meaning particles stay the exact same pixel size regardless of camera distance), set gl_PointSize = uSize; directly.

Fragment Shader

To ensure the particles remain strict, solid squares, assign your color without running any radius checks against gl_PointCoord.

uniform vec3 uColor;

void main() {
    // Fill the entire square point primitive uniformly
    gl_FragColor = vec4(uColor, 1.0);
}

If you need an internal border or an inset square, evaluate the boundaries using gl_PointCoord:

uniform vec3 uColor;
uniform vec3 uBorderColor;
uniform float uBorderWidth; // e.g., 0.05

void main() {
    // Determine if the current fragment is within the square border
    bool isBorder = gl_PointCoord.x < uBorderWidth || 
                    gl_PointCoord.x > (1.0 - uBorderWidth) || 
                    gl_PointCoord.y < uBorderWidth || 
                    gl_PointCoord.y > (1.0 - uBorderWidth);

    if (isBorder) {
        gl_FragColor = vec4(uBorderColor, 1.0);
    } else {
        gl_FragColor = vec4(uColor, 1.0);
    }
}

Implementing in Three.js

Combine the shaders in a THREE.ShaderMaterial and assign it to a THREE.Points mesh:

import * as THREE from 'three';

// 1. Define geometry
const particleCount = 1000;
const geometry = new THREE.BufferGeometry();
const positions = new Float32Array(particleCount * 3);

for (let i = 0; i < particleCount * 3; i++) {
    positions[i] = (Math.random() - 0.5) * 10;
}

geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));

// 2. Define custom shader material
const material = new THREE.ShaderMaterial({
    uniforms: {
        uSize: { value: 20.0 },
        uScale: { value: window.innerHeight / 2.0 },
        uColor: { value: new THREE.Color(0x00ffcc) }
    },
    vertexShader: `
        uniform float uSize;
        uniform float uScale;

        void main() {
            vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
            gl_PointSize = uSize * (uScale / -mvPosition.z);
            gl_Position = projectionMatrix * mvPosition;
        }
    `,
    fragmentShader: `
        uniform vec3 uColor;

        void main() {
            gl_FragColor = vec4(uColor, 1.0);
        }
    `,
    transparent: false,
    depthTest: true,
    depthWrite: true
});

// 3. Create points
const points = new THREE.Points(geometry, material);
scene.add(points);

By eliminating circular alpha falloffs and avoiding circular clipping equations in the fragment stage, the GPU defaults to its native square point rasterization.
