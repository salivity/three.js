Render Fat Wireframes with WireframeGeometry2 in Three.js

Standard Three.js wireframes rely on native WebGL lines, which are restricted to a fixed width of one pixel on most modern platforms. To overcome this limitation, Three.js provides the WireframeGeometry2 class alongside the fat lines module, enabling developers to render wireframes with customizable, resolution-aware thickness. This article demonstrates how to set up WireframeGeometry2, configure LineMaterial for dynamic line widths, and integrate fat wireframes into your Three.js scenes.

Why Standard Wireframes Are Limited

Setting the wireframe property on standard materials like MeshBasicMaterial or using WireframeGeometry with LineSegments uses the native WebGL line implementation (gl.LINES). Because the WebGL specification allows implementations to clamp line width to 1.0, properties like linewidth generally have no effect. The lines extension module circumvents this by generating line segments as triangulated screen-aligned quads (ribbons), allowing arbitrary thickness and scalable anti-aliasing.

Required Imports

The fat lines components are not included in the Three.js core bundle and must be imported from the three/addons (or three/examples/jsm) path:

import * as THREE from 'three';
import { Wireframe } from 'three/addons/lines/Wireframe.js';
import { WireframeGeometry2 } from 'three/addons/lines/WireframeGeometry2.js';
import { LineMaterial } from 'three/addons/lines/LineMaterial.js';

Step-by-Step Implementation

1. Define the Source Geometry

Start with any standard BufferGeometry. This geometry provides the edge topologies used by WireframeGeometry2.

const baseGeometry = new THREE.IcosahedronGeometry(2, 1);

2. Create the WireframeGeometry2

Instantiate WireframeGeometry2 by passing the base geometry into its constructor. It extracts the edge data and structures it into attributes suitable for thick line rendering.

const wireframeGeometry = new WireframeGeometry2(baseGeometry);

3. Configure the LineMaterial

Use LineMaterial to control the visual properties, including color and thickness. To ensure that the lines calculate their screen-space dimensions correctly, provide the current viewport resolution via the resolution property.

const wireframeMaterial = new LineMaterial({
  color: 0x00ffcc,
  linewidth: 4, // Width in screen pixels
  dashed: false
});

// Define screen resolution so line widths scale properly
wireframeMaterial.resolution.set(window.innerWidth, window.innerHeight);

4. Combine into a Wireframe Mesh

Unlike standard meshes that use THREE.Mesh, fat wireframes require the Wireframe class (an extension of MeshBase).

const wireframeMesh = new Wireframe(wireframeGeometry, wireframeMaterial);
wireframeMesh.computeLineDistances();
scene.add(wireframeMesh);

Complete Code Example

import * as THREE from 'three';
import { Wireframe } from 'three/addons/lines/Wireframe.js';
import { WireframeGeometry2 } from 'three/addons/lines/WireframeGeometry2.js';
import { LineMaterial } from 'three/addons/lines/LineMaterial.js';

// Setup Scene, Camera, and Renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 0, 6);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// Base Geometry & Wireframe Setup
const geometry = new THREE.TorusKnotGeometry(1.2, 0.4, 64, 16);
const wireframeGeometry = new WireframeGeometry2(geometry);

const wireframeMaterial = new LineMaterial({
  color: 0xff5533,
  linewidth: 5, // Pixel width
  alphaToCoverage: true
});
wireframeMaterial.resolution.set(window.innerWidth, window.innerHeight);

const wireframe = new Wireframe(wireframeGeometry, wireframeMaterial);
wireframe.computeLineDistances();
scene.add(wireframe);

// Handle Window Resizing
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();

  renderer.setSize(window.innerWidth, window.innerHeight);
  wireframeMaterial.resolution.set(window.innerWidth, window.innerHeight);
});

// Render Loop
function animate() {
  requestAnimationFrame(animate);

  wireframe.rotation.x += 0.005;
  wireframe.rotation.y += 0.01;

  renderer.render(scene, camera);
}

animate();

Managing Resizing and Artifacts

  • Viewport Resizing: Always update wireframeMaterial.resolution.set(width, height) in your resize event handler. If the resolution property does not match actual canvas dimensions, lines will render disproportionately wide or narrow.
  • Z-Fighting: If overlaying a fat wireframe on top of a solid mesh, depth collisions may occur. Mitigate this by adding polygonOffset: true, polygonOffsetFactor: 1, and polygonOffsetUnits: 1 to the solid mesh material.
  • Disposal: Dispose of wireframeGeometry and wireframeMaterial via their .dispose() methods when they are no longer in use to prevent GPU memory leaks.
