Parse and Render Molecules with Three.js PDBLoader

Visualizing biological macromolecules on the web requires converting crystallographic structural data into interactive 3D elements. In Three.js, this is achieved using the PDBLoader add-on, which parses .pdb (Protein Data Bank) files into atomic coordinates, element colors, and covalent bond connections. This guide walks through configuring the loader, interpreting its parsed output, and rendering both atoms and bonds using performant mesh techniques suitable for scientific visualization.

1. Importing the Required Modules

PDBLoader is an official Three.js add-on located in the examples directory. Alongside the loader, using TrackballControls or OrbitControls is recommended for free-form scientific inspection.

import * as THREE from 'three';
import { PDBLoader } from 'three/addons/loaders/PDBLoader.js';
import { TrackballControls } from 'three/addons/controls/TrackballControls.js';

2. Understanding the PDBLoader Output

When the PDBLoader loads a file, its callback receives an object containing three main components:

  • geometryAtoms: A BufferGeometry containing the 3D coordinates (position) and standard CPK coloring (color) for every atom parsed from ATOM and HETATM records.
  • geometryBonds: A BufferGeometry containing pairs of positions representing the start and end coordinates of covalent bonds, parsed from CONECT records.
  • json: Metadata including raw atom data, element symbols, and serial numbers.

3. Rendering Atoms

Because proteins and nucleic acids often contain thousands of atoms, rendering each atom as an independent Mesh degrades performance. The recommended approach is to use InstancedMesh.

function createAtoms(geometryAtoms) {
    const sphereGeometry = new THREE.SphereGeometry(0.3, 16, 16);
    const atomMaterial = new THREE.MeshPhongMaterial({ shininess: 50 });
    
    const positions = geometryAtoms.getAttribute('position');
    const colors = geometryAtoms.getAttribute('color');
    const count = positions.count;

    const instancedMesh = new THREE.InstancedMesh(sphereGeometry, atomMaterial, count);
    const dummy = new THREE.Object3D();
    const color = new THREE.Color();

    for (let i = 0; i < count; i++) {
        dummy.position.set(
            positions.getX(i),
            positions.getY(i),
            positions.getZ(i)
        );
        dummy.updateMatrix();
        instancedMesh.setMatrixAt(i, dummy.matrix);

        color.setRGB(colors.getX(i), colors.getY(i), colors.getZ(i));
        instancedMesh.setColorAt(i, color);
    }

    instancedMesh.instanceMatrix.needsUpdate = true;
    if (instancedMesh.instanceColor) instancedMesh.instanceColor.needsUpdate = true;

    return instancedMesh;
}

4. Rendering Bonds

Bonds can be represented simply using LineSegments for wireframe models, or as cylinders for standard ball-and-stick representations.

Option A: Line Representation (Fastest)

function createWireframeBonds(geometryBonds) {
    const bondMaterial = new THREE.LineBasicMaterial({ color: 0xffffff });
    return new THREE.LineSegments(geometryBonds, bondMaterial);
}

Option B: Solid Cylinder Representation

For stick representations, calculate the midpoint, distance, and orientation between every pair of vertices in geometryBonds:

function createCylinderBonds(geometryBonds) {
    const positions = geometryBonds.getAttribute('position');
    const bondCount = positions.count / 2;

    const baseCylinder = new THREE.CylinderGeometry(0.1, 0.1, 1, 8);
    const bondMaterial = new THREE.MeshPhongMaterial({ color: 0xcccccc });
    const instancedBonds = new THREE.InstancedMesh(baseCylinder, bondMaterial, bondCount);

    const dummy = new THREE.Object3D();
    const start = new THREE.Vector3();
    const end = new THREE.Vector3();
    const direction = new THREE.Vector3();
    const up = new THREE.Vector3(0, 1, 0);

    for (let i = 0; i < positions.count; i += 2) {
        start.fromBufferAttribute(positions, i);
        end.fromBufferAttribute(positions, i + 1);

        const midpoint = new THREE.Vector3().addVectors(start, end).multiplyScalar(0.5);
        const distance = start.distanceTo(end);

        direction.subVectors(end, start).normalize();
        dummy.quaternion.setFromUnitVectors(up, direction);
        dummy.position.copy(midpoint);
        dummy.scale.set(1, distance, 1);
        dummy.updateMatrix();

        instancedBonds.setMatrixAt(i / 2, dummy.matrix);
    }

    instancedBonds.instanceMatrix.needsUpdate = true;
    return instancedBonds;
}

5. Integrating the Loader into the Scene

Assemble the components inside a container group. Centering the geometry ensures that the molecule rotates around its center of mass during inspection.

const scene = new THREE.Scene();
const root = new THREE.Group();
scene.add(root);

const loader = new PDBLoader();

loader.load('path/to/molecule.pdb', (pdb) => {
    // Center both atom and bond coordinates
    const offset = pdb.geometryAtoms.computeBoundingBox().getCenter(new THREE.Vector3()).negate();
    pdb.geometryAtoms.translate(offset.x, offset.y, offset.z);
    pdb.geometryBonds.translate(offset.x, offset.y, offset.z);

    const atomsMesh = createAtoms(pdb.geometryAtoms);
    const bondsMesh = createCylinderBonds(pdb.geometryBonds);

    root.add(atomsMesh);
    root.add(bondsMesh);
});

6. Lighting and Interaction Notes

Molecular structures require directional and ambient light sources to perceive depth properly. Combine an AmbientLight (around 0.6 intensity) with two opposing DirectionalLight sources (around 0.8 intensity). When handling large assemblies such as ribosomes or viral capsids, stick representations should be omitted in favor of space-filling (van der Waals) models using only instancedMesh atoms to preserve framerates.
