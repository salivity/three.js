Update Three.js InstancedMesh Color with setColorAt

Dynamically updating the color of individual instances in a Three.js InstancedMesh is essential for creating performant, interactive 3D applications. This guide explains how to target a specific instance by index, apply a new color using the setColorAt method, and properly trigger the GPU buffer update flag to ensure changes render immediately.

1. Initialize the InstancedMesh with Color Support

By default, an InstancedMesh does not allocate an internal instanceColor buffer until colors are explicitly assigned. To avoid runtime errors when updating colors dynamically, initialize default colors for all instances during creation.

import * as THREE from 'three';

const count = 1000;
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial();
const instancedMesh = new THREE.InstancedMesh(geometry, material, count);

const defaultColor = new THREE.Color(0xffffff);

for (let i = 0; i < count; i++) {
  // Set default transform matrix
  const matrix = new THREE.Matrix4();
  matrix.setPosition(Math.random() * 20 - 10, Math.random() * 20 - 10, Math.random() * 20 - 10);
  instancedMesh.setMatrixAt(i, matrix);

  // Initialize instanceColor buffer
  instancedMesh.setColorAt(i, defaultColor);
}

// Notify Three.js to upload the matrices and colors to the GPU
instancedMesh.instanceMatrix.needsUpdate = true;
if (instancedMesh.instanceColor) {
  instancedMesh.instanceColor.needsUpdate = true;
}

scene.add(instancedMesh);

2. Update an Instance Color Dynamically

To modify the color of an existing instance at runtime (e.g., via user interaction, raycasting, or an animation loop), follow these two steps:

  1. Call instancedMesh.setColorAt(index, color) passing the target instance index and a THREE.Color instance.
  2. Set instancedMesh.instanceColor.needsUpdate = true. Without this step, the internal WebGL buffer will not upload the new color data to the GPU.
function setInstanceColor(mesh, index, hexColor) {
  const color = new THREE.Color(hexColor);
  
  // Update the color at the specified index
  mesh.setColorAt(index, color);
  
  // Flag the color attribute buffer for a GPU upload
  mesh.instanceColor.needsUpdate = true;
}

// Example: Change the color of instance #42 to red
setInstanceColor(instancedMesh, 42, 0xff0000);

3. Handling Interactive Color Changes (Raycasting)

When using a raycaster to pick objects, Three.js provides the clicked instance index via the instanceId property of the intersection object.

const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

function onPointerDown(event) {
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObject(instancedMesh);

  if (intersects.length > 0) {
    const instanceId = intersects[0].instanceId;
    
    if (instanceId !== undefined) {
      // Highlight the clicked instance in green
      instancedMesh.setColorAt(instanceId, new THREE.Color(0x00ff00));
      instancedMesh.instanceColor.needsUpdate = true;
    }
  }
}

window.addEventListener('pointerdown', onPointerDown);

Key Considerations

  • Buffer Creation: If setColorAt is never called before the initial render, instancedMesh.instanceColor remains null. Always set an initial color for at least one instance (or all instances) before the first render call to initialize the buffer.
  • Batching Updates: If updating colors for multiple instances within the same frame, set instancedMesh.instanceColor.needsUpdate = true only once after all calls to setColorAt are complete to avoid unnecessary performance overhead.
