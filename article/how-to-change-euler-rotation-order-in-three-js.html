How to Change Euler Rotation Order in Three.js

In Three.js, 3D objects use Euler angles by default to calculate orientations around the X, Y, and Z axes in a specific sequential order. While the default rotation order is 'XYZ', certain animations, camera controls, or rigging conventions require a different sequence, such as 'ZYX' or 'YXZ', to avoid gimbal lock or match external coordinate systems. This guide explains how to define and switch the Euler rotation order using the built-in properties and methods of the THREE.Euler class.

Understanding Euler Orders in Three.js

An object's rotation in Three.js is represented by object.rotation, which is an instance of THREE.Euler. The order in which these axis rotations are applied mathematically alters the final orientation. Three.js supports six intrinsic Tait-Bryan rotation orders:

  • 'XYZ' (default)
  • 'XZY'
  • 'YXZ'
  • 'YZX'
  • 'ZXY'
  • 'ZYX'

Method 1: Setting the order Property Directly

The most straightforward way to set the order is by directly modifying the order property on an object's rotation.

// Change the rotation order on a mesh
mesh.rotation.order = 'ZYX';

// Set rotations as usual
mesh.rotation.x = Math.PI / 4;
mesh.rotation.y = Math.PI / 2;
mesh.rotation.z = 0;

Note: Changing the order property directly reinterprets the existing X, Y, and Z angle values in the new sequence, which will visually rotate the object in space if non-zero angles are already applied.

Method 2: Using reorder() to Preserve Orientation

If an object already has a specific orientation in 3D space and you need to switch the rotation order without changing how the object is currently facing, use the reorder() method. This recalculates the X, Y, and Z angles to preserve the current visual orientation under the new sequence.

// Preserve the current visual rotation while changing the order
mesh.rotation.reorder('ZYX');

Method 3: Instantiating a New THREE.Euler

You can also create an independent Euler instance with a specific order and apply it to an object.

// Define a new Euler rotation: Euler(x, y, z, order)
const customRotation = new THREE.Euler(0, Math.PI / 2, Math.PI / 4, 'YXZ');

// Apply it to the object
mesh.rotation.copy(customRotation);

Alternatively, use the .set() method on the existing rotation:

mesh.rotation.set(0, Math.PI / 2, Math.PI / 4, 'YXZ');

Common Use Cases

  • First-Person Cameras: First-person and fly camera systems typically use 'YXZ' order to allow natural horizontal panning (yaw around Y) followed by vertical tilting (pitch around X) without roll distortion.
  • CAD and Aerospace Data: Imported CAD models or flight dynamics systems often rely on 'ZYX' (yaw, pitch, roll). Setting the order to 'ZYX' ensures imported rotational data maps directly to the object without manual axis translation.
