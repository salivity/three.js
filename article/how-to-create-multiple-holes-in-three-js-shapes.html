How to Create Multiple Holes in Three.js Shapes

Defining multiple sub-paths or holes inside a single geometry for extrusion in Three.js requires combining a main THREE.Shape with an array of THREE.Path objects. By defining the outer boundary on the Shape instance and appending cutouts to its holes property, you can generate complex solid meshes with interior negative space using THREE.ExtrudeGeometry.

1. Define the Outer Boundary

The primary perimeter of the object is created using THREE.Shape. Use drawing commands such as moveTo, lineTo, or curves to define the continuous outer contour. By convention, outer paths are typically drawn in a counter-clockwise direction.

const outerShape = new THREE.Shape();

// Define a 10x10 outer rectangle
outerShape.moveTo(0, 0);
outerShape.lineTo(10, 0);
outerShape.lineTo(10, 10);
outerShape.lineTo(0, 10);
outerShape.closePath();

2. Define the Cutouts (Holes)

Each hole is an independent instance of THREE.Path rather than a THREE.Shape. Define the geometry for each cutout individually using the same drawing methods available for shapes. For optimal compatibility with Three.js's triangulation system, draw hole paths in a clockwise direction (opposite to the outer boundary).

// First hole: A small square
const hole1 = new THREE.Path();
hole1.moveTo(2, 2);
hole1.lineTo(2, 4);
hole1.lineTo(4, 4);
hole1.lineTo(4, 2);
hole1.closePath();

// Second hole: A circle
const hole2 = new THREE.Path();
hole2.absarc(7, 7, 1.5, 0, Math.PI * 2, true);

3. Add Paths to the Shape's Holes Array

Every THREE.Shape contains a holes property, which is an array of THREE.Path objects. Push all cutout paths directly into this array.

outerShape.holes.push(hole1);
outerShape.holes.push(hole2);

4. Generate the Extrusion

Pass the modified shape directly into THREE.ExtrudeGeometry. Three.js automatically triangulates the 2D plane—subtracting the areas defined in the holes array—and extrudes the resulting composite polygon along the Z-axis according to the provided extrusion settings.

const extrudeSettings = {
  depth: 2,
  bevelEnabled: false
};

const geometry = new THREE.ExtrudeGeometry(outerShape, extrudeSettings);
const material = new THREE.MeshStandardMaterial({ color: 0x0077ff });
const mesh = new THREE.Mesh(geometry, material);

scene.add(mesh);

Key Considerations

  • Path Overlap: Holes must reside entirely within the bounds of the outer shape and should not intersect each other. Overlapping paths can cause triangulation errors in the underlying Earcut tessellation algorithm.
  • Winding Order: While modern versions of Three.js handle path winding automatically in many cases, consistently maintaining a counter-clockwise outer path and clockwise inner paths ensures accurate face normals and avoids rendering artifacts.
