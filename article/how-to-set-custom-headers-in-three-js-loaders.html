How to Set Custom Headers in Three.js Loaders

This guide explains how to inject custom HTTP authorization headers, such as Bearer tokens or API keys, into network requests initiated by Three.js loaders. By leveraging the built-in setRequestHeader method present on standard loaders or pre-fetching binary data using FileLoader, you can securely load protected 3D models, textures, and external assets directly into your 3D scenes.

The Built-in setRequestHeader Method

Most modern Three.js loaders (such as FileLoader, GLTFLoader, and OBJLoader) inherit from or implement the interface of THREE.Loader, which provides the setRequestHeader() method. This method accepts a key-value object containing your HTTP headers.

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

// Inject custom authorization headers
loader.setRequestHeader({
  'Authorization': 'Bearer YOUR_AUTH_TOKEN_HERE',
  'X-Custom-Header': 'CustomValue'
});

// Load the model as usual
loader.load(
  'https://example.com/api/models/secure-asset.glb',
  (gltf) => {
    scene.add(gltf.scene);
  },
  (xhr) => {
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  (error) => {
    console.error('An error occurred during loading:', error);
  }
);

Applying Headers to Internal Loader Requests

Loaders like GLTFLoader propagate the headers configured via setRequestHeader down to their internal loaders. When loading a non-embedded .gltf file that references external .bin buffers or companion textures, those secondary requests will automatically inherit the same authorization headers.

Bypassing Header Limitations in TextureLoader

Standard Three.js TextureLoader historically relies on the browser's native Image DOM element, which performs GET requests via the browser pipeline and cannot accept custom HTTP headers.

If you must load standalone image files with an authorization header, use THREE.FileLoader to fetch the file as a blob, and pass that blob URL to TextureLoader:

const fileLoader = new THREE.FileLoader();
fileLoader.setResponseType('blob');
fileLoader.setRequestHeader({
  'Authorization': 'Bearer YOUR_AUTH_TOKEN_HERE'
});

fileLoader.load('https://example.com/api/textures/secure-texture.png', (blob) => {
  const objectURL = URL.createObjectURL(blob);
  
  const textureLoader = new THREE.TextureLoader();
  const texture = textureLoader.load(objectURL, () => {
    // Revoke URL to prevent memory leaks once loaded
    URL.revokeObjectURL(objectURL);
  });

  material.map = texture;
  material.needsUpdate = true;
});

Alternatively, use THREE.ImageBitmapLoader, which utilizes fetch() internally and natively respects headers set through setRequestHeader.
