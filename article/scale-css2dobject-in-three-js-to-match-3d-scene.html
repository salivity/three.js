Scale CSS2DObject in Three.js to Match 3D Scene

By default, Three.js's CSS2DRenderer renders HTML elements at a fixed pixel size regardless of camera distance, making labels appear static on the screen rather than integrated into the 3D space. To make a CSS2DObject scale dynamically with the 3D scene, you must calculate the perspective scale factor based on the camera's field of view and distance, then apply that scale to an inner HTML wrapper inside your animation loop.

Why CSS2DObjects Do Not Auto-Scale

Unlike CSS3DObject, which applies 3D matrix transforms to orient and scale elements directly in world space, a CSS2DObject only uses 2D screen translations (translate(-50%, -50%) translate(x, y)). Because the renderer continuously overrides the root element's style.transform property during each frame, any scale applied directly to the root element will be overwritten.

Step 1: Use an Inner HTML Wrapper

Create a parent container for the CSS2DObject and place your actual label content inside a nested child element. This ensures the renderer manages positional translation on the parent, leaving the child element free for custom CSS transforms.

// Create the outer container managed by CSS2DRenderer
const labelDiv = document.createElement('div');
labelDiv.className = 'css2d-container';

// Create the inner element that receives scaling
const innerLabel = document.createElement('div');
innerLabel.className = 'css2d-content';
innerLabel.textContent = '3D Label';
labelDiv.appendChild(innerLabel);

// Instantiate the CSS2DObject
const labelObject = new CSS2DObject(labelDiv);
labelObject.position.set(0, 2, 0);
scene.add(labelObject);

Step 2: Calculate the Perspective Scale

To make an HTML element behave like a flat 3D plane, its scale must decrease as distance from the camera increases.

For a PerspectiveCamera, the visible world height at a specific distance is:

\[\text{visibleHeight} = 2 \times \tan\left(\frac{\text{camera.fov} \times \pi}{360}\right) \times \text{distance}\]

By dividing a target world size by this visible height (multiplied by the viewport height), you get the exact scale factor needed to preserve 3D proportions.

Alternatively, a simplified distance-ratio formula can be used:

\[\text{scale} = \frac{\text{referenceDistance}}{\text{currentDistance}}\]

Step 3: Apply the Transform in the Animation Loop

Update the scale on the inner element on every frame inside your animate loop before rendering:

const referenceDistance = 10; // The distance where scale is 1.0

function animate() {
    requestAnimationFrame(animate);

    // Get current world distance between camera and label
    const worldPosition = new THREE.Vector3();
    labelObject.getWorldPosition(worldPosition);
    const distance = camera.position.distanceTo(worldPosition);

    if (distance > 0) {
        // Calculate dynamic scale factor
        const scale = referenceDistance / distance;

        // Apply scale to the inner child element
        innerLabel.style.transform = `scale(${scale})`;
        innerLabel.style.transformOrigin = 'center center';
    }

    renderer.render(scene, camera);
    css2dRenderer.render(scene, camera);
}

Clamping the Scale

If the camera gets too close or too far, text can either become illegibly small or excessively pixelated. Clamp the calculated scale between minimum and maximum bounds:

const minScale = 0.5;
const maxScale = 2.0;
const clampedScale = Math.min(Math.max(scale, minScale), maxScale);

innerLabel.style.transform = `scale(${clampedScale})`;

This approach maintains the lightweight performance benefits of CSS2DRenderer while visually anchoring your HTML labels to the depth and perspective of the 3D scene.
