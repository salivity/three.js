How to Shift Model Pivot Point in Three.js

This article explains how to shift the origin pivot point of a 3D model in Three.js using the center() method on its geometry. When importing 3D assets, transformations like rotation and scaling occur around the model's local origin, which may not align with its physical center. By using Three.js's built-in geometry methods, you can quickly recalculate vertex positions to position the pivot point directly at the center of the mesh.

Understanding the Pivot Point in Three.js

In Three.js, an object's pivot point corresponds to its local coordinate origin (0, 0, 0). When you rotate or scale an Object3D or Mesh, the transformation is computed relative to this origin.

If a model was exported from software like Blender with its origin offset from the actual geometry, rotating the mesh in Three.js causes it to orbit around that distant point rather than spinning in place.

Shifting the Pivot with geometry.center()

The BufferGeometry.center() method computes the bounding box of the geometry and translates all vertex positions so that the bounding box center aligns with the local origin (0, 0, 0).

Because this method directly alters the vertex data rather than modifying the mesh's position property, the local origin effectively becomes the exact center of the geometry.

Implementation for a Single Mesh

If your loaded model consists of a single mesh, invoke .center() directly on its geometry property:

import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

loader.load('path/to/model.glb', (gltf) => {
    const model = gltf.scene;

    model.traverse((child) => {
        if (child.isMesh) {
            // Recenter the geometry to shift the pivot point to the center
            child.geometry.center();
        }
    });

    scene.add(model);
});

How geometry.center() Works Internally

Under the hood, BufferGeometry.center() performs the following operations:

  1. Calls computeBoundingBox() to determine the minimum and maximum boundaries of the vertices.
  2. Calculates the center offset vector: offset = - (min + max) / 2.
  3. Calls translate(offset.x, offset.y, offset.z) on the geometry, shifting every vertex coordinate by that vector.

Once this executes, any subsequent transformations—such as mesh.rotation.y += 0.01—will rotate the mesh around its new, centrally located pivot.

Considerations for Multi-Mesh Models

If your loaded asset contains multiple interconnected child meshes (a hierarchy), calling child.geometry.center() on every child will center each mesh independently. This will collapse all individual parts onto the same central origin, breaking the model's visual structure.

To shift the pivot point of a complex, multi-part hierarchy without breaking the geometry:

  1. Calculate the overall bounding box of the entire hierarchy using new THREE.Box3().setFromObject(model).
  2. Extract the center vector using box.getCenter(new THREE.Vector3()).
  3. Wrap the model inside a parent THREE.Group().
  4. Offset the model's position by the negative center: model.position.sub(center).

For single-mesh objects, however, geometry.center() remains the most direct and efficient method to permanently correct pivot point alignment in Three.js.
