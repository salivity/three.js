Vertex Snapping with Three.js Geometry Index Arrays

Custom vertex snapping in Three.js allows 3D applications, CAD editors, and interactive tools to align objects or cursor projections precisely with the existing vertices of a mesh. This article covers how to extract the index array from a BufferGeometry, map those indices to the corresponding vertex coordinates within the position attribute, transform them into world coordinates, and compute distance checks against a target point to snap positions dynamically.

Understanding the Index Buffer in Three.js

In Three.js, meshes utilize BufferGeometry to store vertex data. An indexed geometry separates unique vertex coordinates stored in geometry.attributes.position from the order in which they form triangles, stored in geometry.index.

The geometry.index.array contains integer references pointing to coordinate triplets in the position buffer. Utilizing the index array rather than looping blindly through the position buffer ensures you only process valid, referenced vertices and can optimize algorithms that rely on topology.

Extracting the Index Array and Positions

To extract vertex positions using the index array, retrieve geometry.index and geometry.attributes.position. If geometry.index is null, the geometry is non-indexed, meaning the position buffer itself defines vertices sequentially (in triplets per face).

const indexAttribute = mesh.geometry.index;
const positionAttribute = mesh.geometry.attributes.position;

if (indexAttribute) {
  const indices = indexAttribute.array;
  const indexCount = indexAttribute.count;

  for (let i = 0; i < indexCount; i++) {
    const vertexIndex = indices[i];
    
    // Extract local vertex coordinates
    const x = positionAttribute.getX(vertexIndex);
    const y = positionAttribute.getY(vertexIndex);
    const z = positionAttribute.getZ(vertexIndex);
  }
}

Transforming Local Vertices to World Space

Vertex positions are defined in the mesh's local object space. For snapping calculations against arbitrary world coordinates—such as an active raycast intersection point—each vertex must be multiplied by the mesh's matrixWorld.

import * as THREE from 'three';

const localVertex = new THREE.Vector3();
const worldVertex = new THREE.Vector3();

// Ensure the mesh's world matrix is current
mesh.updateMatrixWorld();

localVertex.fromBufferAttribute(positionAttribute, vertexIndex);
worldVertex.copy(localVertex).applyMatrix4(mesh.matrixWorld);

Implementing the Custom Vertex Snapping Logic

The snapping function takes a target position (e.g., from a raycaster), iterates through unique indices, converts their positions to world space, and identifies the vertex closest to the target point within a defined threshold radius.

To avoid redundant distance checks on shared vertices, track visited indices using a Set.

import * as THREE from 'three';

function snapToClosestVertex(targetPoint, mesh, snapRadius = 0.5) {
  const geometry = mesh.geometry;
  const positionAttribute = geometry.attributes.position;
  const indexAttribute = geometry.index;

  if (!positionAttribute) return null;

  mesh.updateMatrixWorld();
  const matrixWorld = mesh.matrixWorld;

  let closestPoint = null;
  let minDistance = snapRadius;

  const tempLocal = new THREE.Vector3();
  const tempWorld = new THREE.Vector3();

  if (indexAttribute) {
    const indices = indexAttribute.array;
    const visitedIndices = new Set();

    for (let i = 0; i < indices.length; i++) {
      const vertexIndex = indices[i];

      // Skip duplicate vertices shared across faces
      if (visitedIndices.has(vertexIndex)) continue;
      visitedIndices.add(vertexIndex);

      tempLocal.fromBufferAttribute(positionAttribute, vertexIndex);
      tempWorld.copy(tempLocal).applyMatrix4(matrixWorld);

      const distance = targetPoint.distanceTo(tempWorld);

      if (distance < minDistance) {
        minDistance = distance;
        closestPoint = tempWorld.clone();
      }
    }
  } else {
    // Fallback for non-indexed geometry
    for (let i = 0; i < positionAttribute.count; i++) {
      tempLocal.fromBufferAttribute(positionAttribute, i);
      tempWorld.copy(tempLocal).applyMatrix4(matrixWorld);

      const distance = targetPoint.distanceTo(tempWorld);

      if (distance < minDistance) {
        minDistance = distance;
        closestPoint = tempWorld.clone();
      }
    }
  }

  return closestPoint; // Returns THREE.Vector3 if snapped, or null if outside radius
}

Usage Workflow

  1. Perform a standard raycast against scene meshes to retrieve an intersection point: const target = intersects[0].point;.
  2. Pass the intersection point and the intersected mesh into snapToClosestVertex(target, intersects[0].object, snapThreshold).
  3. If the function returns a THREE.Vector3, update your tool, cursor, or moving object to the returned snapped position; otherwise, fallback to the raw raycast intersection point.
