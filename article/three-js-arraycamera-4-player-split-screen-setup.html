Three.js ArrayCamera 4-Player Split-Screen Setup

This guide explains how to calculate the exact viewport array required to render a four-player split-screen layout using THREE.ArrayCamera in Three.js. By dividing the canvas into a 2x2 grid, you will configure each sub-camera's viewport vector using pixel-based coordinates, account for WebGL's bottom-left origin system, and ensure correct projection matrices for distortion-free rendering.

Understanding Viewport Coordinates in Three.js

Unlike normalized UV coordinates that scale from 0.0 to 1.0, the viewport property of an individual sub-camera in a THREE.ArrayCamera requires absolute pixel dimensions defined by a THREE.Vector4(x, y, width, height):

  • x: The horizontal pixel offset from the left edge of the render target.
  • y: The vertical pixel offset from the bottom edge of the render target.
  • width: The width of the individual viewport in pixels.
  • height: The height of the individual viewport in pixels.

Because WebGL defines (0, 0) at the bottom-left of the canvas rather than the top-left, the vertical offsets must be calculated with the bottom row starting at y = 0 and the top row starting at half of the canvas height.

Step-by-Step Viewport Calculations

To produce a balanced 2x2 grid:

  1. Determine the rendered canvas dimensions:

    const totalWidth = window.innerWidth;
const totalHeight = window.innerHeight;

  2. Calculate the dimensions of each sub-camera view:

    const subWidth = Math.floor(totalWidth / 2);
const subHeight = Math.floor(totalHeight / 2);
const aspect = subWidth / subHeight;

  3. Construct the four viewports using THREE.Vector4:

  • Player 1 (Top-Left):

    • x = 0
    • y = subHeight
    • Vector4(0, subHeight, subWidth, subHeight)

  • Player 2 (Top-Right):

    • x = subWidth
    • y = subHeight
    • Vector4(subWidth, subHeight, subWidth, subHeight)

  • Player 3 (Bottom-Left):

    • x = 0
    • y = 0
    • Vector4(0, 0, subWidth, subHeight)

  • Player 4 (Bottom-Right):

    • x = subWidth
    • y = 0
    • Vector4(subWidth, 0, subWidth, subHeight)

Implementation Example

import * as THREE from 'three';

// 1. Setup the main canvas dimensions
const width = window.innerWidth;
const height = window.innerHeight;
const subWidth = Math.floor(width / 2);
const subHeight = Math.floor(height / 2);
const aspect = subWidth / subHeight;

// 2. Define sub-camera configurations
const viewports = [
    // Top-Left (Player 1)
    new THREE.Vector4(0, subHeight, subWidth, subHeight),
    // Top-Right (Player 2)
    new THREE.Vector4(subWidth, subHeight, subWidth, subHeight),
    // Bottom-Left (Player 3)
    new THREE.Vector4(0, 0, subWidth, subHeight),
    // Bottom-Right (Player 4)
    new THREE.Vector4(subWidth, 0, subWidth, subHeight)
];

const cameras = [];

for (let i = 0; i < 4; i++) {
    const subCamera = new THREE.PerspectiveCamera(60, aspect, 0.1, 1000);
    subCamera.viewport = viewports[i];
    
    // Position cameras independently per player
    subCamera.position.set(0, 5, 10);
    subCamera.lookAt(0, 0, 0);
    subCamera.updateProjectionMatrix();
    
    cameras.push(subCamera);
}

// 3. Create the ArrayCamera container
const mainCamera = new THREE.ArrayCamera(cameras);

// 4. Handle window resizing
window.addEventListener('resize', () => {
    const newWidth = window.innerWidth;
    const newHeight = window.innerHeight;
    const newSubWidth = Math.floor(newWidth / 2);
    const newSubHeight = Math.floor(newHeight / 2);
    const newAspect = newSubWidth / newSubHeight;

    renderer.setSize(newWidth, newHeight);

    const newOffsets = [
        [0, newSubHeight],
        [newSubWidth, newSubHeight],
        [0, 0],
        [newSubWidth, 0]
    ];

    cameras.forEach((cam, index) => {
        cam.aspect = newAspect;
        cam.viewport.set(
            newOffsets[index][0],
            newOffsets[index][1],
            newSubWidth,
            newSubHeight
        );
        cam.updateProjectionMatrix();
    });
});

Essential Rendering Considerations

  • Projection Updates: Whenever the sub-camera viewports are modified during window resizing, you must recalculate aspect = subWidth / subHeight and call subCamera.updateProjectionMatrix() on all sub-cameras to prevent stretching.
  • Clear Scissor: THREE.ArrayCamera internally handles viewport offsets using WebGL scissors and viewports during its render loop. Do not manually call renderer.setScissorTest(true) or renderer.setViewport() inside the animation frame, as this interferes with the camera's internal pass.
