Using NURBS in Three.js for Complex Shapes

This article provides a practical guide on utilizing the NURBSCurve and NURBSSurface classes to generate smooth, mathematically precise curves and surfaces in Three.js. You will learn how to configure knot vectors, control points, and polynomial degrees, as well as how to convert these abstract mathematical constructs into standard Three.js renderable geometries using Line and ParametricGeometry.

Understanding NURBS Fundamentals

Non-Uniform Rational B-Splines (NURBS) are mathematical representations used in CAD and 3D modeling to define smooth curves and surfaces. Unlike standard polygon meshes, NURBS represent exact geometry using three primary elements:

  1. Degree: Defines the polynomial degree (e.g., degree 2 for quadratic, degree 3 for cubic).
  2. Control Points: Coordinates that pull the curve or surface into shape. In Three.js, these are typically represented as 4D vectors (THREE.Vector4(x, y, z, weight)), where the fourth component represents weight.
  3. Knot Vector: A non-decreasing sequence of numbers that controls where and how the control points affect the curve.

Because NURBS classes are not part of the core Three.js bundle, import them from the addons directory:

import * as THREE from 'three';
import { NURBSCurve } from 'three/addons/curves/NURBSCurve.js';
import { NURBSSurface } from 'three/addons/math/NURBSSurface.js';
import { ParametricGeometry } from 'three/addons/geometries/ParametricGeometry.js';

Implementing a NURBSCurve

A NURBSCurve creates smooth 1D paths in 3D space. To render a curve, calculate points along the spline and feed them into a THREE.BufferGeometry.

1. Define Curve Parameters

A cubic curve (degree 3) requires a knot vector with length equal to number of control points + degree + 1. Clamped end knots ensure the curve begins at the first control point and terminates at the last.

const degree = 3;
const knots = [0, 0, 0, 0, 1, 1, 1, 1]; // Clamped knots for 4 control points

const controlPoints = [
  new THREE.Vector4(-10, -10, 0, 1),
  new THREE.Vector4(-5, 15, 5, 1),
  new THREE.Vector4(5, -15, -5, 1),
  new THREE.Vector4(10, 10, 0, 1)
];

const nurbsCurve = new NURBSCurve(degree, knots, controlPoints);

2. Convert to Renderable Geometry

Since NURBSCurve inherits from THREE.Curve, you can sample points along its length:

const points = nurbsCurve.getPoints(100);
const geometry = new THREE.BufferGeometry().setFromPoints(points);
const material = new THREE.LineBasicMaterial({ color: 0x00ffff });

const curveObject = new THREE.Line(geometry, material);
scene.add(curveObject);

Implementing a NURBSSurface

A NURBSSurface expands the concept into two parametric dimensions: \(u\) and \(v\). It requires two degrees, two knot vectors, and a 2D matrix of control points.

1. Define Surface Parameters

The control point grid must be arranged in rows and columns.

const degree1 = 2; // Degree along U
const degree2 = 2; // Degree along V

const knots1 = [0, 0, 0, 1, 1, 1]; // Length: 3 control points + 2 + 1
const knots2 = [0, 0, 0, 1, 1, 1];

// 3x3 grid of control points (u x v)
const controlPoints = [
  [
    new THREE.Vector4(-10, 0, -10, 1),
    new THREE.Vector4(-10, 5, 0, 1),
    new THREE.Vector4(-10, 0, 10, 1)
  ],
  [
    new THREE.Vector4(0, 5, -10, 1),
    new THREE.Vector4(0, 15, 0, 1), // Elevated center
    new THREE.Vector4(0, 5, 10, 1)
  ],
  [
    new THREE.Vector4(10, 0, -10, 1),
    new THREE.Vector4(10, 5, 0, 1),
    new THREE.Vector4(10, 0, 10, 1)
  ]
];

const nurbsSurface = new NURBSSurface(degree1, degree2, knots1, knots2, controlPoints);

2. Generate Surface Geometry Using ParametricGeometry

ParametricGeometry generates a mesh by evaluating coordinates over a continuous \((u, v)\) domain from \(0\) to \(1\).

function getSurfacePoint(u, v, target) {
  return nurbsSurface.getPoint(u, v, target);
}

// ParametricGeometry(samplingFunction, slicesU, stacksV)
const surfaceGeometry = new ParametricGeometry(getSurfacePoint, 25, 25);
const surfaceMaterial = new THREE.MeshStandardMaterial({
  color: 0xff6600,
  side: THREE.DoubleSide,
  wireframe: false
});

const surfaceMesh = new THREE.Mesh(surfaceGeometry, surfaceMaterial);
scene.add(surfaceMesh);

Key Considerations

  • Knot Vector Sizing: Always ensure that knots.length === controlPoints.length + degree + 1. An incorrect knot length will cause rendering errors or broken matrices.
  • Weights: The w component in Vector4(x, y, z, w) pulls the surface closer to that point when greater than 1, and pushes it away when between 0 and 1, allowing for conic sections such as circles and cylinders.
  • Normal Computation: Surfaces generated via ParametricGeometry compute default vertex normals. If lighting artifacts appear, call surfaceGeometry.computeVertexNormals() after instantiating the geometry.
