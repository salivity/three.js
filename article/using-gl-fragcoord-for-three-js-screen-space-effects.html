Using gl_FragCoord for Three.js Screen-Space Effects

This guide explains how to extract and use the built-in gl_FragCoord variable within a Three.js fragment shader to create screen-space effects. You will learn what data gl_FragCoord provides, how to pass canvas resolution uniforms from Three.js to normalize your coordinates, and how to apply these coordinates to generate effects such as screen-aligned patterns, vignettes, or masks that remain static relative to the viewport.

Understanding gl_FragCoord

In GLSL, gl_FragCoord is a built-in read-only input variable available in the fragment shader. It contains the window-relative coordinates of the current fragment:

  • gl_FragCoord.x: The horizontal pixel coordinate (from 0.5 to viewport_width - 0.5).
  • gl_FragCoord.y: The vertical pixel coordinate (from 0.5 to viewport_height - 0.5), originating from the bottom-left corner of the viewport.
  • gl_FragCoord.z: The fragment depth value, mapped between 0.0 and 1.0.
  • gl_FragCoord.w: The reciprocal of the clip-space \(W\) coordinate (1.0 / clip.w).

Because gl_FragCoord.xy provides raw pixel coordinates, you must normalize them against the viewport dimensions to map them to a standard [0.0, 1.0] UV coordinate space.

Passing Resolution via Uniforms

To normalize gl_FragCoord.xy, pass the canvas resolution to your shader using a THREE.Vector2 uniform. When instantiating a THREE.ShaderMaterial, define u_resolution and account for the device pixel ratio.

const resolution = new THREE.Vector2(
  window.innerWidth * window.devicePixelRatio,
  window.innerHeight * window.devicePixelRatio
);

const customMaterial = new THREE.ShaderMaterial({
  uniforms: {
    u_resolution: { value: resolution }
  },
  vertexShader: `
    void main() {
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform vec2 u_resolution;

    void main() {
      // Normalize gl_FragCoord to [0.0, 1.0] range
      vec2 screenUV = gl_FragCoord.xy / u_resolution;

      // Output a screen-space gradient
      gl_FragColor = vec4(screenUV.x, screenUV.y, 0.5, 1.0);
    }
  `
});

Handling Window Resizing

Because gl_FragCoord tracks window pixels, dynamic resizing requires updating the u_resolution uniform whenever the renderer resizes:

window.addEventListener('resize', () => {
  const width = window.innerWidth;
  const height = window.innerHeight;
  const pixelRatio = renderer.getPixelRatio();

  renderer.setSize(width, height);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();

  customMaterial.uniforms.u_resolution.value.set(
    width * pixelRatio,
    height * pixelRatio
  );
});

Practical Screen-Space Effect Examples

1. Screen-Space Vignette

You can use the normalized coordinates to darken the edges of the display regardless of mesh rotation or camera position:

uniform vec2 u_resolution;

void main() {
  vec2 screenUV = gl_FragCoord.xy / u_resolution;
  
  // Center coordinates to [-0.5, 0.5]
  vec2 uv = screenUV - 0.5;
  
  // Calculate distance from center
  float dist = length(uv);
  
  // Create vignette falloff
  float vignette = smoothstep(0.7, 0.2, dist);

  gl_FragColor = vec4(vec3(vignette), 1.0);
}

2. Screen-Space Dither or Halftone Pattern

Because gl_FragCoord operates directly on pixel units, you can create fixed-size patterns without normalising:

void main() {
  // Generates a checkerboard pattern based on screen pixels
  float pattern = mod(floor(gl_FragCoord.x) + floor(gl_FragCoord.y), 2.0);

  if (pattern < 1.0) {
    discard; // Creates a screen-door transparency effect
  }

  gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0);
}

Important Considerations

  • Pixel Density: If renderer.setPixelRatio(...) is used, gl_FragCoord scales with the backing buffer resolution rather than CSS pixels. Always multiply your CSS dimensions by renderer.getPixelRatio() when setting u_resolution.
  • Origin Differences: WebGL defines (0, 0) at the bottom-left corner of the screen. If your effect expects the top-left corner as the origin, invert the Y axis using screenUV.y = 1.0 - screenUV.y.
