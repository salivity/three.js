Three.js DirectionalLight Target Explained

In Three.js, the DirectionalLight simulates light emitted from an infinitely distant source in parallel rays, requiring both an origin and an orientation. This orientation is controlled by the light's target property, which dictates the point in 3D space toward which the rays travel. To make this directional pointing work reliably—especially when changing the target's position dynamically—the target object itself must be explicitly added to the scene graph so Three.js can compute its world transformation matrices properly.

What Is the target Property?

A DirectionalLight requires two points in space to define the direction of its rays: its own position and its target.

By default, the target property is an instance of THREE.Object3D positioned at the world origin (0, 0, 0). The light rays shine from light.position toward light.target.position. Unlike standard objects whose rotations are manipulated via Euler angles or quaternions, a DirectionalLight ignores standard rotation adjustments and instead continuously derives its orientation by looking at this target.

Why the Target Must Be Added to the Scene

A frequent issue in Three.js is changing light.target.position and seeing no change in the light's direction or shadow mapping.

For an object's position, rotation, and scale to affect the rendering pipeline, its world matrix must be updated on each frame. In Three.js, world matrices are updated automatically by traversing the scene graph starting from the root Scene object. Because light.target is an independent Object3D, creating a DirectionalLight does not automatically make the target a child of the light or of the scene.

If the target is not a descendant of the scene, its world transformation matrix is never updated. Consequently, any changes to target.position are ignored by the light.

How to Implement It Correctly

To ensure the light tracks its target properly, add both the light and its target to the scene:

import * as THREE from 'three';

const scene = new THREE.Scene();

// 1. Create the directional light
const light = new THREE.DirectionalLight(0xffffff, 1);
light.position.set(10, 20, 10);

// 2. Adjust the target's position
light.target.position.set(2, 0, -5);

// 3. Add both the light and its target to the scene
scene.add(light);
scene.add(light.target);

Targeting Existing Meshes

If the light should track an existing object in your scene—such as a moving player mesh—reassign the light's target directly to that mesh:

const characterMesh = new THREE.Mesh(geometry, material);
scene.add(characterMesh);

// Assign the mesh as the light's target
light.target = characterMesh;
scene.add(light);

In this case, you do not need to call scene.add(light.target) separately, as characterMesh is already part of the scene graph and will have its transformation matrix updated automatically every frame.
