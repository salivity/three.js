Track Geometry Memory via Three.js WebGLRenderer.info

Monitoring geometry memory in Three.js is essential for preventing GPU memory leaks and maintaining high frame rates in complex 3D applications. While Three.js provides the native WebGLRenderer.info.memory object to monitor resource counts, this API only reports the total number of geometry buffers uploaded to the GPU rather than their footprint in bytes. To track the exact byte-level memory allocated to geometries, you must combine active polling of renderer.info.memory.geometries with an attribute byte-length calculation routine.

Understanding WebGLRenderer.info.memory

The WebGLRenderer maintains an internal diagnostic object accessible through renderer.info. The memory sub-object tracks active resources:

console.log(renderer.info.memory);
// Outputs: { geometries: 42, textures: 12 }
  • renderer.info.memory.geometries: Tracks the total number of distinct BufferGeometry instances currently compiled and held in WebGL buffer memory.
  • Update Timing: A geometry is registered in this count only after it is submitted to the GPU (typically during a renderer.render() call). Calling geometry.dispose() unbinds the WebGL buffers and decrements this count.

Calculating Exact Byte Allocation

Because renderer.info.memory.geometries only outputs a count, calculating exact memory consumption requires inspecting the underlying BufferAttribute arrays of each geometry.

In WebGL, geometry memory consists of vertex attributes (such as position, normal, uv) and index buffers. Each attribute uses a typed array (such as Float32Array or Uint16Array), which exposes a .byteLength property.

The byte size of a single BufferGeometry can be calculated with the following function:

function getGeometryByteLength(geometry) {
    let totalBytes = 0;

    // Iterate through standard attributes (position, normal, uv, etc.)
    for (const name in geometry.attributes) {
        const attribute = geometry.attributes[name];
        if (attribute && attribute.array) {
            totalBytes += attribute.array.byteLength;
        }
    }

    // Include index buffer memory if indexed
    if (geometry.index && geometry.index.array) {
        totalBytes += geometry.index.array.byteLength;
    }

    return totalBytes;
}

Implementing Active Memory Tracking

To monitor changes continuously, track scene geometries alongside renderer.info.memory.geometries within your application's render loop or a periodic diagnostic interval.

class GeometryMemoryTracker {
    constructor(renderer, scene) {
        this.renderer = renderer;
        this.scene = scene;
        this.lastGeometryCount = 0;
        this.totalByteSize = 0;
    }

    update() {
        const currentCount = this.renderer.info.memory.geometries;

        // Recalculate full byte usage if geometry count changes
        if (currentCount !== this.lastGeometryCount) {
            this.lastGeometryCount = currentCount;
            this.totalByteSize = this.calculateSceneGeometryBytes();
            
            this.logMemoryUsage();
        }
    }

    calculateSceneGeometryBytes() {
        const visitedGeometries = new Set();
        let bytes = 0;

        this.scene.traverse((object) => {
            if (object.geometry && !visitedGeometries.has(object.geometry.id)) {
                visitedGeometries.add(object.geometry.id);
                bytes += getGeometryByteLength(object.geometry);
            }
        });

        return bytes;
    }

    logMemoryUsage() {
        const megabytes = (this.totalByteSize / (1024 * 1024)).toFixed(2);
        console.log(`[GPU Memory] Geometries: ${this.lastGeometryCount} | Total Size: ${megabytes} MB`);
    }
}

Integrating into the Render Loop

Initialize the tracker and call its update() method inside your standard requestAnimationFrame loop:

const tracker = new GeometryMemoryTracker(renderer, scene);

function animate() {
    requestAnimationFrame(animate);

    renderer.render(scene, camera);

    // Actively check memory state after rendering
    tracker.update();
}

animate();

Verifying Deallocation

To confirm that GPU memory has successfully been cleared:

  1. Call geometry.dispose() on the target geometry.
  2. Remove any mesh referencing it from the scene (scene.remove(mesh)).
  3. Ensure no local references retain the geometry in JavaScript heap memory.
  4. Render at least one additional frame.

When successfully purged, renderer.info.memory.geometries will decrement automatically on the subsequent render call, and your tracking routine will recalculate the active byte consumption accordingly.
