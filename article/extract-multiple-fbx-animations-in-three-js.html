Extract Multiple FBX Animations in Three.js

When developing 3D web applications, a single FBX asset often encapsulates a base mesh alongside several distinct motion sequences, such as idle, walk, and attack cycles. This guide outlines how to load an FBX model containing multiple embedded animations using Three.js and FBXLoader, extract each AnimationClip, map them into an AnimationMixer, and execute or blend them independently during runtime.

1. Load the FBX and Inspect Embedded Clips

When FBXLoader parses an FBX file, it extracts all embedded animation tracks and assigns them as an array of THREE.AnimationClip instances directly to the returned Group under the animations property.

import * as THREE from 'three';
import { FBXLoader } from 'three/addons/loaders/FBXLoader.js';

const loader = new FBXLoader();
const animationActions = {};
let mixer;

loader.load('models/character_with_anims.fbx', (fbx) => {
    scene.add(fbx);

    // Initialize the AnimationMixer with the root FBX object
    mixer = new THREE.AnimationMixer(fbx);

    // Verify and map all embedded clips
    fbx.animations.forEach((clip) => {
        // Create an AnimationAction for each clip
        const action = mixer.clipAction(clip);
        animationActions[clip.name] = action;
    });

    // Optional: Start a default idle animation if available
    if (fbx.animations.length > 0) {
        animationActions[fbx.animations[0].name].play();
    }
});

2. Isolate and Manage Individual Clips

Each AnimationClip in fbx.animations has a name property assigned during its creation in software like Blender, Maya, or 3ds Max. If the naming in the FBX exporter was properly configured, you can reference animations by descriptive identifiers (e.g., "Idle", "Run", or "Jump").

If the export produced generic clip names (such as "Take 001"), you can inspect them via console.log(fbx.animations) and assign explicit names programmatically:

fbx.animations[0].name = 'Idle';
fbx.animations[1].name = 'Walk';

animationActions['Idle'] = mixer.clipAction(fbx.animations[0]);
animationActions['Walk'] = mixer.clipAction(fbx.animations[1]);

3. Independently Control and Blend Animations

Each AnimationAction generated by mixer.clipAction() provides dedicated methods for starting, pausing, looping, and fading clips.

Playing and Stopping Specific Animations

function playAnimation(name) {
    if (animationActions[name]) {
        animationActions[name].reset().play();
    }
}

function stopAnimation(name) {
    if (animationActions[name]) {
        animationActions[name].stop();
    }
}

Crossfading Between Clips

To prevent jarring transitions when switching from one motion sequence to another, blend the two actions using crossFadeTo:

function transitionTo(newAnimName, duration = 0.5) {
    const nextAction = animationActions[newAnimName];
    const currentAction = Object.values(animationActions).find(action => action.isRunning());

    if (!nextAction || nextAction === currentAction) return;

    nextAction.reset();
    nextAction.play();

    if (currentAction) {
        currentAction.crossFadeTo(nextAction, duration, true);
    }
}

4. Drive Playback in the Animation Loop

The AnimationMixer requires time increments to advance keyframes. Instantiate a THREE.Clock and update the mixer in your primary animation loop:

const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);

    const delta = clock.getDelta();
    if (mixer) {
        mixer.update(delta);
    }

    renderer.render(scene, camera);
}

animate();

Through this pattern, all embedded animation tracks within the original FBX file remain completely decoupled, allowing you to trigger, configure, and smoothly blend individual actions based on user input or scene states.
