How to Find Ray-Sphere Intersection in Three.js

This article explains how to determine the mathematical intersection points between an infinite ray and a sphere in Three.js. You will learn how to use Three.js's native Ray.intersectSphere() method for retrieving the closest intersection point, as well as how to implement the underlying quadratic formula to calculate both entry and exit points along an infinite line.

Using Built-in Three.js Methods

Three.js provides native classes for both rays (THREE.Ray) and spheres (THREE.Sphere). The THREE.Ray class includes an intersectSphere method that calculates the first point of contact.

import * as THREE from 'three';

// Define the sphere: center at (0, 0, 0) with radius 2
const sphere = new THREE.Sphere(new THREE.Vector3(0, 0, 0), 2);

// Define the ray: origin at (0, 0, -5) pointing along +Z axis
const rayOrigin = new THREE.Vector3(0, 0, -5);
const rayDirection = new THREE.Vector3(0, 0, 1).normalize();
const ray = new THREE.Ray(rayOrigin, rayDirection);

// Target vector to store the result
const intersectionPoint = new THREE.Vector3();

// Calculate the first intersection point
const result = ray.intersectSphere(sphere, intersectionPoint);

if (result !== null) {
    console.log('Intersection found at:', result);
} else {
    console.log('No intersection.');
}

The intersectSphere method returns null if the ray does not hit the sphere or if the sphere lies entirely behind the ray's origin.

Calculating Both Points Mathematically

Because ray.intersectSphere() only returns the nearest forward intersection point, finding both entry and exit points for an infinite ray requires solving the algebraic intersection equation directly.

The Mathematics

  1. Ray Equation:
    \[\mathbf{P}(t) = \mathbf{O} + t\mathbf{D}\]
    Where \(\mathbf{O}\) is the ray origin, \(\mathbf{D}\) is the normalized direction vector, and \(t\) is the distance scalar along the ray.

  2. Sphere Equation:
    \[\|\mathbf{P} - \mathbf{C}\|^2 = r^2\]
    Where \(\mathbf{C}\) is the sphere center and \(r\) is the radius.

  3. Substitute \(\mathbf{P}(t)\) into the sphere equation:
    \[\|(\mathbf{O} - \mathbf{C}) + t\mathbf{D}\|^2 = r^2\]

  4. Expand into standard quadratic form (\(at^2 + bt + c = 0\)):
    Let \(\mathbf{V} = \mathbf{O} - \mathbf{C}\).

    • \(a = \mathbf{D} \cdot \mathbf{D} = 1\) (since \(\mathbf{D}\) is normalized)
    • \(b = 2(\mathbf{V} \cdot \mathbf{D})\)
    • \(c = (\mathbf{V} \cdot \mathbf{V}) - r^2\)

  5. Solve using the discriminant (\(\Delta = b^2 - 4ac\)):

    • If \(\Delta < 0\), the line misses the sphere.
    • If \(\Delta = 0\), the line is tangent to the sphere (one point).
    • If \(\Delta > 0\), the line intersects at two distinct points (\(t_1\) and \(t_2\)).

Implementation in Three.js

import * as THREE from 'three';

function getInfiniteRaySphereIntersections(ray, sphere) {
    const v = new THREE.Vector3().subVectors(ray.origin, sphere.center);
    
    // Compute quadratic coefficients
    const a = ray.direction.dot(ray.direction); // Always 1 if direction is normalized
    const b = 2.0 * v.dot(ray.direction);
    const c = v.dot(v) - (sphere.radius * sphere.radius);

    const discriminant = (b * b) - (4 * a * c);

    // No real roots: line does not intersect sphere
    if (discriminant < 0) {
        return [];
    }

    // Tangent intersection: one point
    if (discriminant === 0) {
        const t = -b / (2 * a);
        const point = new THREE.Vector3().copy(ray.origin).addScaledVector(ray.direction, t);
        return [point];
    }

    // Two intersection points
    const sqrtDisc = Math.sqrt(discriminant);
    const t1 = (-b - sqrtDisc) / (2 * a);
    const t2 = (-b + sqrtDisc) / (2 * a);

    const point1 = new THREE.Vector3().copy(ray.origin).addScaledVector(ray.direction, t1);
    const point2 = new THREE.Vector3().copy(ray.origin).addScaledVector(ray.direction, t2);

    return [point1, point2];
}

// Example usage:
const sphere = new THREE.Sphere(new THREE.Vector3(0, 0, 0), 3);
const ray = new THREE.Ray(
    new THREE.Vector3(0, 10, 0), 
    new THREE.Vector3(0, -1, 0).normalize()
);

const points = getInfiniteRaySphereIntersections(ray, sphere);
console.log(points); // Returns [Vector3(0, 3, 0), Vector3(0, -3, 0)]

By allowing \(t\) to accept both positive and negative values, this implementation treats the ray as a two-way infinite geometric line, successfully capturing points that lie in front of or behind the ray origin.
