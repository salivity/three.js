How to Configure PCSS Shadows in Three.js

Percentage-Closer Soft Shadows (PCSS) produce realistic, contact-hardening shadows where blur increases as the distance between the occluder and the receiver grows. Because Three.js does not include a native THREE.PCSSShadowMap constant on the shadowMap.type property, enabling PCSS requires configuring the renderer to use standard shadow mapping and overriding the internal shadow shader chunks with custom GLSL algorithms. This article explains how to initialize the renderer, inject custom PCSS code into THREE.ShaderChunk, and tune light parameters for realistic contact shadows.

1. Configure the WebGLRenderer

To begin, enable the shadow map system on your WebGLRenderer. Set shadowMap.type to THREE.PCFSoftShadowMap or THREE.PCFShadowMap. While the custom shader injection will ultimately override the filtering algorithm, setting an active shadow map type ensures that Three.js allocates shadow buffers and injects shadow-related uniforms into standard materials.

import * as THREE from 'three';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);

// Enable shadow maps
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

2. Override the Shadow Map Shader Chunk

Three.js builds its material programs using reusable chunks stored in THREE.ShaderChunk. The shadow calculation functions reside inside THREE.ShaderChunk.shadowmap_pars_fragment.

To implement PCSS, overwrite or modify this chunk before instantiating any materials that receive shadows. The custom code must calculate two primary steps:

  1. Blocker Search: Determines the average depth of occluders between the light source and the fragment.
  2. Filtering: Scales the Percentage-Closer Filtering (PCF) kernel radius based on the ratio between the receiver depth and the average blocker depth (penumbra estimation).

Insert the following shader code replacement into your application initialization:

let pcssCustomShader = `
#define LIGHT_WORLD_SIZE 0.05
#define LIGHT_FRUSTUM_WIDTH 3.75
#define LIGHT_SIZE_UV (LIGHT_WORLD_SIZE / LIGHT_FRUSTUM_WIDTH)
#define NEAR_PLANE 1.0

#define NUM_SAMPLES 17
#define NUM_RINGS 11
#define BLOCKER_SEARCH_NUM_SAMPLES 16

vec2 poissonDisk[NUM_SAMPLES];

void initPoissonDisk( const in vec2 uv ) {
    float ANGLE_STEP = 6.28318530718 / float( NUM_SAMPLES );
    float INV_NUM_SAMPLES = 1.0 / float( NUM_SAMPLES );
    float angle = 0.0;
    float radius = INV_NUM_SAMPLES;
    float radiusStep = radius;

    for( int i = 0; i < NUM_SAMPLES; i ++ ) {
        poissonDisk[i] = vec2( cos( angle ), sin( angle ) ) * pow( radius, 0.75 );
        radius += radiusStep;
        angle += ANGLE_STEP;
    }
}

float penumbraSize( const in float zReceiver, const in float zBlocker ) {
    return (zReceiver - zBlocker) / zBlocker;
}

float findBlocker( sampler2D shadowMap, const in vec2 uv, const in float zReceiver ) {
    float searchRadius = LIGHT_SIZE_UV * ( zReceiver - NEAR_PLANE ) / zReceiver;
    float blockerSum = 0.0;
    int numBlockers = 0;

    for( int i = 0; i < BLOCKER_SEARCH_NUM_SAMPLES; i ++ ) {
        float shadowMapDepth = unpackRGBAToDepth( texture2D( shadowMap, uv + poissonDisk[i] * searchRadius ) );
        if ( shadowMapDepth < zReceiver ) {
            blockerSum += shadowMapDepth;
            numBlockers ++;
        }
    }

    if ( numBlockers == 0 ) return -1.0;
    return blockerSum / float( numBlockers );
}

float PCSS ( sampler2D shadowMap, vec4 coords ) {
    vec2 uv = coords.xy;
    float zReceiver = coords.z; // Assumes depth in [0, 1]

    initPoissonDisk( uv );

    float avgBlockerDepth = findBlocker( shadowMap, uv, zReceiver );
    if ( avgBlockerDepth == -1.0 ) return 1.0;

    float penumbraRatio = penumbraSize( zReceiver, avgBlockerDepth );
    float filterRadius = penumbraRatio * LIGHT_SIZE_UV * NEAR_PLANE / zReceiver;

    // Filter using Poisson Disk
    float sum = 0.0;
    for ( int i = 0; i < NUM_SAMPLES; i ++ ) {
        float depth = unpackRGBAToDepth( texture2D( shadowMap, uv + poissonDisk[i] * filterRadius ) );
        sum += step( zReceiver, depth );
    }

    return sum / float( NUM_SAMPLES );
}
`;

// Replace the default filtering entry point with PCSS
let shadowPars = THREE.ShaderChunk.shadowmap_pars_fragment;

shadowPars = shadowPars.replace(
    '#ifdef USE_SHADOWMAP',
    '#ifdef USE_SHADOWMAP\n' + pcssCustomShader
);

shadowPars = shadowPars.replace(
    'return getShadow( ... );', // Or target the default PCF filtering functions
    'return PCSS( shadowMap, shadowCoord );'
);

THREE.ShaderChunk.shadowmap_pars_fragment = shadowPars;

Note: In modern Three.js revisions, you can also inject this logic on a per-material basis using the material.onBeforeCompile callback to avoid global scope modifications.

3. Configure the Light and Shadow Camera

PCSS calculations depend directly on accurate projection math and depth buffers. Configure a DirectionalLight with explicit shadow camera clipping planes and resolution:

const dirLight = new THREE.DirectionalLight(0xffffff, 1.5);
dirLight.position.set(5, 12, 8);
dirLight.castShadow = true;

// Shadow map resolution
dirLight.shadow.mapSize.width = 2048;
dirLight.shadow.mapSize.height = 2048;

// Keep near and far planes tight around your scene to maximize depth precision
dirLight.shadow.camera.near = 1.0;
dirLight.shadow.camera.far = 30.0;

// Orthographic bounds must closely encompass the shadow-casting area
dirLight.shadow.camera.top = 10;
dirLight.shadow.camera.bottom = -10;
dirLight.shadow.camera.left = -10;
dirLight.shadow.camera.right = 10;

dirLight.shadow.bias = -0.0005;

scene.add(dirLight);

4. Fine-Tuning Artifacts and Performance

  • Light Size (LIGHT_WORLD_SIZE): Controls the virtual size of the light source. Increasing this constant produces wider, softer penumbras further away from contact points.
  • Sample Counts (NUM_SAMPLES and BLOCKER_SEARCH_NUM_SAMPLES): Higher numbers eliminate noise and banding at the cost of GPU fragment fill-rate. For high-performance requirements, keep samples between 16 and 32.
  • Depth Precision: Because PCSS compares linear receiver depths against blocker depths, wide disparities in camera.near and camera.far values introduce precision artifacts. Ensure shadow camera bounds tightly encapsulate only the rendered scene.
