Extract Curve Paths from 3D Text in Three.js

This article explains how to retrieve the exact mathematical vector curves used to generate 3D text in Three.js. While TextGeometry generates a triangulated 3D polygonal mesh, the underlying vector outlines originate from the font data parsed by FontLoader. By leveraging the generateShapes() method of the loaded font, you can extract the exact 2D mathematical curves—including lines, quadratic Bézier curves, and cubic Bézier curves—along with their control points, before or alongside generating 3D geometry.

Understanding Font Shapes and Curves

When Three.js constructs text via TextGeometry, it performs two sequential steps:

  1. Translates the glyph data from a Typeface JSON font into 2D vector shapes (THREE.Shape instances).
  2. Extrudes those 2D shapes along the Z-axis to create a 3D mesh via ExtrudeGeometry.

Because extrusion converts smooth curves into discrete planar polygons, extracting mathematical curves directly from an instantiated 3D mesh requires reverse-engineering triangulated edges. The mathematically precise approach is to extract the vector definitions directly from the loaded font object using font.generateShapes().

Step-by-Step Implementation

1. Load the Font and Generate Shapes

Load your typeface JSON file using FontLoader. Instead of passing the font straight to TextGeometry, invoke font.generateShapes().

import * as THREE from 'three';
import { FontLoader } from 'three/addons/loaders/FontLoader.js';

const loader = new FontLoader();

loader.load('fonts/helvetiker_regular.typeface.json', (font) => {
    const text = 'A';
    const size = 50;
    
    // Generate an array of THREE.Shape objects
    const shapes = font.generateShapes(text, size);
    
    // Extract mathematical curve definitions
    const extractedData = extractCurvesFromShapes(shapes);
    console.log(extractedData);
});

2. Traverse Outer Curves and Inner Holes

A THREE.Shape extends THREE.Path and represents the outer boundary of a glyph. Glyphs with cutouts (such as "A", "O", or "8") store internal boundaries inside the shape.holes array, which contains secondary THREE.Path objects.

Both shape.curves and hole.curves contain segments defining the glyph's perimeter.

function extractCurvesFromShapes(shapes) {
    const glyphPaths = [];

    shapes.forEach((shape, shapeIndex) => {
        const glyphData = {
            shapeIndex: shapeIndex,
            outline: parseCurveArray(shape.curves),
            holes: shape.holes.map((hole) => parseCurveArray(hole.curves))
        };
        glyphPaths.push(glyphData);
    });

    return glyphPaths;
}

3. Parse Mathematical Control Points

Each element in a curves array is an instance of a curve class derived from THREE.Curve. Inspect the type property of each curve to extract its exact mathematical coordinates:

  • LineCurve: Defined by start point v1 and end point v2.
  • QuadraticBezierCurve: Defined by start point v0, control point v1, and end point v2.
  • CubicBezierCurve: Defined by start point v0, first control point v1, second control point v2, and end point v3.
function parseCurveArray(curves) {
    return curves.map((curve) => {
        switch (curve.type) {
            case 'LineCurve':
                return {
                    type: 'Line',
                    start: { x: curve.v1.x, y: curve.v1.y },
                    end: { x: curve.v2.x, y: curve.v2.y }
                };

            case 'QuadraticBezierCurve':
                return {
                    type: 'QuadraticBezier',
                    start: { x: curve.v0.x, y: curve.v0.y },
                    control: { x: curve.v1.x, y: curve.v1.y },
                    end: { x: curve.v2.x, y: curve.v2.y }
                };

            case 'CubicBezierCurve':
                return {
                    type: 'CubicBezier',
                    start: { x: curve.v0.x, y: curve.v0.y },
                    control1: { x: curve.v1.x, y: curve.v1.y },
                    control2: { x: curve.v2.x, y: curve.v2.y },
                    end: { x: curve.v3.x, y: curve.v3.y }
                };

            default:
                return {
                    type: curve.type,
                    raw: curve
                };
        }
    });
}

Transforming 2D Curves into 3D Space

If your 3D text is extruded along the Z-axis, you can map the 2D path data into 3D world space:

  • Front Face Curves: Maintain the (x, y) values extracted from the shapes and assign z = depth / 2 (or z = 0 depending on your extrusion origin).
  • Back Face Curves: Duplicate the curves with z = -depth / 2 (or z = -depth).
  • Matrix Transformation: If your text mesh is rotated, scaled, or translated in the scene, transform each extracted vector using vector.applyMatrix4(mesh.matrixWorld).
