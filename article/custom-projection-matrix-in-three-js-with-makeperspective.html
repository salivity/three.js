Custom Projection Matrix in Three.js with makePerspective

This article explains how to manually construct a custom projection matrix in Three.js using the Matrix4.makePerspective method. You will learn the parameters required by the method, how to apply the custom matrix to a camera, and how to prevent Three.js from overwriting your custom projection calculations during rendering.

Understanding Matrix4.makePerspective

Three.js cameras typically generate their projection matrices internally based on properties such as field of view (FOV), aspect ratio, near plane, and far plane. However, the THREE.Matrix4 class provides a low-level method named makePerspective() that allows you to define a viewing frustum using explicit coordinate bounds.

The signature for the method is:

matrix.makePerspective(left, right, top, bottom, near, far)

Parameter Breakdown

  • left: Coordinate of the left clipping plane on the near plane.
  • right: Coordinate of the right clipping plane on the near plane.
  • top: Coordinate of the top clipping plane on the near plane.
  • bottom: Coordinate of the bottom clipping plane on the near plane.
  • near: Distance to the near clipping plane (must be greater than 0).
  • far: Distance to the far clipping plane (must be greater than near).

This method is especially useful for asymmetric frustums, off-axis projections, stereoscopic rendering, or multi-monitor wall displays where standard symmetric FOV parameters are insufficient.

Step-by-Step Implementation

1. Calculate Frustum Boundaries

To create a standard symmetric frustum manually, compute the bounds using your desired FOV and aspect ratio:

const fov = 60; // in degrees
const aspect = window.innerWidth / window.innerHeight;
const near = 0.1;
const far = 1000;

// Convert vertical FOV from degrees to radians and calculate bounds
const top = near * Math.tan(THREE.MathUtils.degToRad(fov) / 2);
const bottom = -top;
const right = top * aspect;
const left = -right;

For an asymmetric (off-axis) projection, you can define uneven values directly:

const left = -1.5;
const right = 0.5;
const top = 1.0;
const bottom = -1.0;
const near = 0.1;
const far = 1000;

2. Construct the Matrix and Apply to the Camera

Instantiate a THREE.Matrix4, call makePerspective(), and assign it to the camera's projectionMatrix:

import * as THREE from 'three';

// Use a basic Camera instance or PerspectiveCamera
const camera = new THREE.Camera();

// Instantiate matrix and set perspective
const customProjectionMatrix = new THREE.Matrix4();
customProjectionMatrix.makePerspective(left, right, top, bottom, near, far);

// Assign directly to the camera
camera.projectionMatrix.copy(customProjectionMatrix);
camera.projectionMatrixInverse.copy(camera.projectionMatrix).invert();

3. Prevent Matrix Overwrites

If you use a THREE.PerspectiveCamera, calling camera.updateProjectionMatrix() resets projectionMatrix using internal properties (camera.fov, camera.aspect, etc.). To prevent Three.js or third-party controls from overriding your custom matrix:

  • Use a base THREE.Camera instead of THREE.PerspectiveCamera. Base cameras do not implement an automatic updateProjectionMatrix() method.
  • If using THREE.PerspectiveCamera, override its update method:
const camera = new THREE.PerspectiveCamera();
camera.projectionMatrix.copy(customProjectionMatrix);
camera.projectionMatrixInverse.copy(camera.projectionMatrix).invert();

// Prevent automatic updates from resetting the custom matrix
camera.updateProjectionMatrix = function () {
    // Custom logic or no-op
};

Whenever you modify your custom projection matrix, always recompute camera.projectionMatrixInverse to ensure raycasting and unprojection work correctly.
