How to Create Rounded Edges in Three.js ExtrudeGeometry

Creating smooth, rounded edges on 3D extruded shapes in Three.js is achieved by configuring the bevel settings inside the THREE.ExtrudeGeometry options object. By enabling the bevel, increasing bevelSegments to add geometric subdivisions, and fine-tuning bevelThickness alongside bevelSize, you can turn sharp, flat-extruded 2D paths into models with polished, curved contours.

To create rounded edges, you must pass an options object to THREE.ExtrudeGeometry that defines the shape's extrusion depth and bevel properties. The key properties governing rounded corners are:

  • bevelEnabled: Must be set to true to activate beveling.
  • bevelThickness: Determines how deep into the Z-direction (front and back faces) the bevel goes.
  • bevelSize: Controls how far outward from the shape's outline the bevel extends. To achieve a symmetric, natural round edge, bevelThickness and bevelSize are often set to equal values.
  • bevelSegments: Sets the number of subdivision layers along the bevel curve. The default value of 3 produces a modest curve, while setting this to 5 or higher produces a smooth, circular edge. Setting it to 1 produces a flat, angled chamfer instead of a curve.
  • bevelOffset: Controls where the bevel begins relative to the shape outline. Typically left at 0.

Here is a practical implementation creating a rounded rectangular extrusion:

import * as THREE from 'three';

// 1. Define a 2D Shape
const shape = new THREE.Shape();
const width = 8;
const height = 8;
shape.moveTo(-width / 2, -height / 2);
shape.lineTo(width / 2, -height / 2);
shape.lineTo(width / 2, height / 2);
shape.lineTo(-width / 2, height / 2);
shape.closePath();

// 2. Configure Extrude Settings for Rounded Edges
const extrudeSettings = {
    depth: 4,               // Extrusion distance along the Z-axis
    bevelEnabled: true,     // Turn on beveling
    bevelThickness: 0.8,    // Depth of the bevel curve along the Z-axis
    bevelSize: 0.8,         // Distance the bevel extends from the 2D path
    bevelOffset: 0,         // Distance from the shape outline where bevel starts
    bevelSegments: 8        // Number of layers creating the rounded curve
};

// 3. Create the Geometry and Mesh
const geometry = new THREE.ExtrudeGeometry(shape, extrudeSettings);
const material = new THREE.MeshStandardMaterial({ 
    color: 0x2194ce, 
    roughness: 0.2, 
    metalness: 0.1 
});

const mesh = new THREE.Mesh(geometry, material);

Best Practices for Smooth Results

When configuring rounded edges, avoid setting bevelSize or bevelThickness too large relative to the original shape. If the bevel dimensions exceed the inner angles or total scale of your 2D geometry, the faces will self-intersect and produce rendering artifacts. Additionally, use the minimum bevelSegments necessary for your visual needs—values between 5 and 10 are usually sufficient for close-up viewing without excessively increasing polygon counts.
