Three.js getPointsHoles: Extract Shape and Hole Vectors

In Three.js, complex two-dimensional geometry often relies on THREE.Shape, which defines an outer boundary path along with optional inner cutout paths known as holes. This article explains how to retrieve both the outer boundary vertices and inner cutout coordinate vectors as THREE.Vector2 instances using Three.js path methods, focusing on the role of getPointsHoles() and its companion methods.

Understanding Shape Boundaries and Cutouts

A THREE.Shape represents an arbitrary 2D outline. It extends THREE.Path to define an outer perimeter and contains an internal array named holes, which stores secondary THREE.Path instances representing interior cutouts.

When working with physics engines, triangulation algorithms (like Earcut), or custom WebGL shaders, you frequently need the evaluated vertices of both the outer contour and its internal cutouts rather than rendering a mesh directly.

Extracting Vectors with getPoints and getPointsHoles

Three.js separates the extraction of the outer boundary from the cutouts:

  1. shape.getPoints(divisions): Samples the main path and returns an array of THREE.Vector2 points defining the outer boundary.
  2. shape.getPointsHoles(divisions): Iterates over every THREE.Path in the shape.holes array, samples each path, and returns an array of arrays containing THREE.Vector2 points representing each internal cutout.

The optional divisions parameter (defaulting to 12) determines the number of segments used to approximate curves.

Complete Implementation Example

The following code illustrates how to define a shape with an internal cutout and extract both sets of vectors:

import * as THREE from 'three';

// 1. Create the outer boundary
const shape = new THREE.Shape();
shape.moveTo(0, 0);
shape.lineTo(100, 0);
shape.lineTo(100, 100);
shape.lineTo(0, 100);
shape.closePath();

// 2. Define an internal cutout (hole)
const holePath = new THREE.Path();
holePath.moveTo(25, 25);
holePath.lineTo(75, 25);
holePath.lineTo(75, 75);
holePath.lineTo(25, 75);
holePath.closePath();

// Add the hole to the shape
shape.holes.push(holePath);

// 3. Extract boundary and cutout vectors
const divisions = 12;

// Returns Array<THREE.Vector2>
const boundaryVectors = shape.getPoints(divisions);

// Returns Array<Array<THREE.Vector2>>
const holeVectors = shape.getPointsHoles(divisions);

// Log the results
console.log('Boundary Vectors:', boundaryVectors);
holeVectors.forEach((hole, index) => {
  console.log(`Hole ${index} Vectors:`, hole);
});

Alternative: Using extractPoints()

Three.js also provides a convenience method named extractPoints(divisions) on the shape instance. Internally, extractPoints() executes both getPoints() and getPointsHoles() simultaneously:

const pointsData = shape.extractPoints(divisions);

const boundaryVectors = pointsData.shape; // Array<THREE.Vector2>
const holeVectors = pointsData.holes;     // Array<Array<THREE.Vector2>>

Output Structure

  • Boundary Vectors (shape.getPoints()): A single array of THREE.Vector2 objects ordered sequentially along the outer contour.
  • Hole Vectors (shape.getPointsHoles()): A nested two-dimensional array (THREE.Vector2[][]), where each sub-array contains the sequential points for an individual cutout path.
