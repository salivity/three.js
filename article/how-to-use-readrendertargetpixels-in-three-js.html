How to Use readRenderTargetPixels in Three.js

Extracting rendered pixel data from an off-screen target is a common task in Three.js for applications like color picking, computer vision, and texture processing. This guide explains how to use the WebGLRenderer.readRenderTargetPixels method to read RGBA values from a WebGLRenderTarget directly into a JavaScript typed array.

Prerequisites and Core Concept

To extract pixels, you need an active WebGLRenderer, a WebGLRenderTarget with content rendered to it, and a typed array buffer to receive the raw pixel bytes. By default, standard render targets use THREE.UnsignedByteType, which outputs 8-bit unsigned integer values (0–255) for Red, Green, Blue, and Alpha channels, requiring a Uint8Array.

Step-by-Step Implementation

1. Set Up the Render Target

Define the dimensions and instantiate the target:

const width = 512;
const height = 512;
const renderTarget = new THREE.WebGLRenderTarget(width, height);

2. Render to the Target

Direct your renderer to draw your scene into the render target instead of the default canvas:

renderer.setRenderTarget(renderTarget);
renderer.render(scene, camera);
renderer.setRenderTarget(null); // Reset back to default framebuffer

3. Prepare the Buffer and Read Pixels

Instantiate a Uint8Array sized to hold 4 bytes (RGBA) per pixel for the designated region. Then, call readRenderTargetPixels:

// Buffer size: width * height * 4 (RGBA)
const pixelBuffer = new Uint8Array(width * height * 4);

// Parameters: renderTarget, x, y, width, height, buffer, activeCubeFaceIndex
renderer.readRenderTargetPixels(
  renderTarget,
  0,          // X offset
  0,          // Y offset
  width,      // Read width
  height,     // Read height
  pixelBuffer
);

Accessing Individual Pixel Colors

The returned buffer stores pixel components sequentially in row-major order starting from the bottom-left corner (0, 0):

function getPixelColor(x, y, width, buffer) {
  const index = (y * width + x) * 4;
  return {
    r: buffer[index],
    g: buffer[index + 1],
    b: buffer[index + 2],
    a: buffer[index + 3]
  };
}

const pixel = getPixelColor(10, 20, width, pixelBuffer);
console.log(`R: ${pixel.r}, G: ${pixel.g}, B: ${pixel.b}, A: ${pixel.a}`);

Reading Single Pixels for Picking

If you only need the color under the cursor, avoid reading the entire texture by setting the extraction width and height to 1:

const singlePixel = new Uint8Array(4);
renderer.readRenderTargetPixels(renderTarget, mouseX, mouseY, 1, 1, singlePixel);

const [r, g, b, a] = singlePixel;

Float Type Render Targets

If your WebGLRenderTarget is configured with floating-point textures (e.g., type: THREE.FloatType), replace Uint8Array with Float32Array:

const floatRenderTarget = new THREE.WebGLRenderTarget(width, height, {
  type: THREE.FloatType
});

const floatBuffer = new Float32Array(width * height * 4);
renderer.readRenderTargetPixels(floatRenderTarget, 0, 0, width, height, floatBuffer);

Performance Considerations

Calling readRenderTargetPixels forces a synchronous GPU-to-CPU synchronization, stalling the GPU rendering pipeline until data transfer completes. To maintain optimal framerates:

  • Minimize the extracted area (e.g., sample a 1x1 region rather than the full viewport).
  • Avoid calling the method every frame unless strictly necessary.
