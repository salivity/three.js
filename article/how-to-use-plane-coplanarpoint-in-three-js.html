How to Use Plane.coplanarPoint in Three.js

In Three.js, an infinite geometric plane is mathematically defined by a unit normal vector and a signed constant distance from the origin. When working with 3D math, physics, or rendering helpers, you frequently need to find a concrete 3D coordinate that lies directly on that surface. This guide explains how the Plane.coplanarPoint() method works in Three.js and provides practical code examples showing how to calculate an arbitrary point on any plane.

Understanding the Method

The Plane.coplanarPoint(target) method calculates a point lying directly on the surface of the calling THREE.Plane and stores it in the provided THREE.Vector3 target.

Under the hood, Three.js computes this point by scaling the plane's normal vector by the negative value of the plane's constant:

\[\text{point} = -\text{constant} \times \text{normal}\]

Because this calculation yields a vector perpendicular to the plane originating from \((0, 0, 0)\), the resulting point represents the closest point on the plane to the world coordinate origin.

Signature

plane.coplanarPoint(target)
  • target (THREE.Vector3): An existing Vector3 instance where the calculated coordinates will be written.
  • Returns: The mutated target vector containing the coplanar point coordinates.

Basic Implementation

To find a point on a plane, define a THREE.Plane, instantiate a THREE.Vector3 to store the result, and call coplanarPoint().

import * as THREE from 'three';

// Define a plane facing up along the Y-axis, shifted 5 units along the normal
const normal = new THREE.Vector3(0, 1, 0);
const constant = -5;
const plane = new THREE.Plane(normal, constant);

// Create a vector to receive the coordinates
const pointOnPlane = new THREE.Vector3();

// Calculate the coplanar point
plane.coplanarPoint(pointOnPlane);

console.log(pointOnPlane); 
// Output: Vector3 { x: 0, y: 5, z: 0 }

Practical Example: Visualizing a Plane with PlaneHelper

A common application of coplanarPoint() is positioning objects, helpers, or coordinate frames relative to an arbitrary plane. While THREE.PlaneHelper automatically handles plane positioning, you can use coplanarPoint() when building custom markers or orienting meshes directly onto an abstract plane:

import * as THREE from 'three';

// Create an arbitrary angled plane
const plane = new THREE.Plane(new THREE.Vector3(1, 1, 0).normalize(), -10);

// 1. Get a point resting on the plane
const anchorPoint = new THREE.Vector3();
plane.coplanarPoint(anchorPoint);

// 2. Place a visual marker on the plane at that point
const markerGeometry = new THREE.SphereGeometry(0.2, 16, 16);
const markerMaterial = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const markerMesh = new THREE.Mesh(markerGeometry, markerMaterial);

markerMesh.position.copy(anchorPoint);
scene.add(markerMesh);

Key Considerations

  • Always Pass a Target Vector: Plane.coplanarPoint() does not allocate a new THREE.Vector3 automatically. Failing to pass a valid THREE.Vector3 as an argument will result in a runtime error.
  • Memory Optimization: In animation loops or render functions, reuse a single THREE.Vector3 variable instead of creating new instances to avoid triggering garbage collection spikes.
  • Arbitrary Point: The returned vector is only one specific point resting on the infinite plane (the projection of the origin). Any linear combination of vectors perpendicular to the normal can be added to this anchor point to reach other locations across the same plane.
