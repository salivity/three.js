How to Use Three.js Ray.distanceToPlane

This guide explains how to determine the precise distance between a camera and an infinite mathematical surface in Three.js using the THREE.Ray.distanceToPlane method. By casting a ray along the camera's viewing axis and testing it against a defined THREE.Plane, you can retrieve the exact distance to the point of intersection or detect when the plane does not lie in the camera's field of view.

Understanding the Core Components

To measure this gap, Three.js requires two primary mathematical constructs:

  1. THREE.Plane: A flat, infinite two-dimensional surface defined by a normalized normal vector and a distance constant from the world origin (\(w\)).
  2. THREE.Ray: A directed half-line defined by an origin point (Vector3) and a normalized direction vector (Vector3).

The Ray.distanceToPlane(plane) method calculates the linear distance from the ray's origin to the intersection point on the plane. If the ray points away from the plane or runs parallel to it, the method returns null.

Step-by-Step Implementation

1. Define the Mathematical Plane

Create the plane by defining its normal vector and constant. For example, to create a horizontal ground plane situated 5 units below the world origin:

import * as THREE from 'three';

// Normal points straight up (Y-axis), offset by 5 units down
const planeNormal = new THREE.Vector3(0, 1, 0);
const planeConstant = 5; 
const targetPlane = new THREE.Plane(planeNormal, planeConstant);

2. Create and Align the Ray with the Camera

Extract the camera's world position to serve as the ray's origin, and extract the camera's forward-facing direction to serve as the ray's direction.

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 10, 20);
camera.lookAt(0, 0, 0);

// Instantiate vectors to prevent memory reallocation in render loops
const cameraPosition = new THREE.Vector3();
const cameraDirection = new THREE.Vector3();

// Get world position and forward direction vector
camera.getWorldPosition(cameraPosition);
camera.getWorldDirection(cameraDirection);

// Construct the ray
const ray = new THREE.Ray(cameraPosition, cameraDirection);

3. Calculate the Distance

Pass the plane instance into the ray's distanceToPlane method:

const distance = ray.distanceToPlane(targetPlane);

if (distance !== null) {
  console.log(`Distance from camera to plane: ${distance.toFixed(2)} units`);
} else {
  console.log('The camera is facing away from or parallel to the plane.');
}

Measuring Perpendicular Distance vs. Ray Distance

It is important to distinguish between the distance along the camera's line of sight and the perpendicular distance to the plane:

  • Line of Sight (Ray Distance): Calculated via ray.distanceToPlane(plane). This represents how far light travels straight out from the camera lens to strike the plane surface at an angle.
  • Orthogonal Distance: Calculated via plane.distanceToPoint(camera.position). This measures the shortest perpendicular distance from the camera directly to the plane, regardless of where the camera is facing.

Continuous Measurement in the Animation Loop

To track this distance dynamically as the camera moves or rotates, place the calculation inside your render or update loop:

function updateDistance() {
  camera.getWorldPosition(ray.origin);
  camera.getWorldDirection(ray.direction);

  const gap = ray.distanceToPlane(targetPlane);

  if (gap !== null) {
    // Apply logic such as Level of Detail (LOD) switching, fog adjustments, or collision checks
    handleProximity(gap);
  }
}

function animate() {
  requestAnimationFrame(animate);
  updateDistance();
  renderer.render(scene, camera);
}
