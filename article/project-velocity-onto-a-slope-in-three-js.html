Project Velocity onto a Slope in Three.js

When implementing character controllers or physics in Three.js, moving across ramps and uneven terrain often causes characters to stutter, float, or clip through geometry. This article explains how to project a movement velocity Vector3 onto a sloped surface using Three.js's built-in Vector3.projectOnPlane() method. By redirecting the velocity along the surface rather than through it, you can achieve smooth, natural slope traversal.

Understanding projectOnPlane

In Three.js, the method Vector3.projectOnPlane(planeNormal) does not take a THREE.Plane object as its argument; instead, it requires the normal vector (Vector3) perpendicular to the plane.

The method subtracts the component of the velocity vector that is parallel to the surface normal, leaving only the component tangential to the slope. Mathematically, it performs:

\[\vec{v}_{\text{projected}} = \vec{v} - (\vec{v} \cdot \hat{n})\hat{n}\]

where \(\vec{v}\) is your velocity and \(\hat{n}\) is the unit normal of the slope.

Step-by-Step Implementation

  1. Obtain the Surface Normal: When your character is standing on a slope, detect the surface using a THREE.Raycaster pointing downwards. The intersection result provides the face normal of the slope in world coordinates.
  2. Project the Velocity: Call .projectOnPlane(surfaceNormal) on your velocity vector.
  3. Maintain Movement Speed (Optional): Projecting a vector reduces its length depending on the steepness of the angle. If you want the character to move at the same speed regardless of the slope's incline, re-scale the projected vector back to the original magnitude.

Complete Code Example

import * as THREE from 'three';

// 1. Define initial forward velocity (e.g., moving along the Z-axis)
const velocity = new THREE.Vector3(0, 0, 5);
const originalSpeed = velocity.length();

// 2. Define the surface normal of the slope
// In a real project, obtain this from raycaster intersects: intersect[0].face.normal
// Ensure the normal is in world space and normalized
const slopeNormal = new THREE.Vector3(0, 0.7071, 0.7071).normalize();

// 3. Project the velocity onto the plane defined by the normal
velocity.projectOnPlane(slopeNormal);

// 4. (Optional) Preserve original speed across the slope
if (velocity.lengthSq() > 0) {
    velocity.setLength(originalSpeed);
}

// 5. Apply the adjusted velocity to your object position
// mesh.position.addScaledVector(velocity, delta);

Integrating with Raycasting

In an active game loop, combine this logic with surface detection:

const downRay = new THREE.Raycaster(character.position, new THREE.Vector3(0, -1, 0));
const intersects = downRay.intersectObjects(terrainObjects, true);

if (intersects.length > 0 && intersects[0].distance < characterHeight) {
    // Transform normal to world space if the terrain mesh is rotated
    const worldNormal = intersects[0].face.normal.clone();
    worldNormal.transformDirection(intersects[0].object.matrixWorld);

    // Project velocity along the detected terrain slope
    velocity.projectOnPlane(worldNormal);
}

This ensures that the forward movement aligns parallel to the ground below the character, preventing gravity and forward acceleration from fighting the geometry.
