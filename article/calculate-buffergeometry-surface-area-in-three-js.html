Calculate BufferGeometry Surface Area in Three.js

This article explains how to compute the total surface area of an indexed BufferGeometry in Three.js. By traversing the geometry's index buffer three elements at a time, you can retrieve the corresponding vertex coordinates from the position attribute, calculate the area of each individual triangular face using vector cross products, and accumulate these values into a single total surface area.

Understanding the Geometry Structure

An indexed BufferGeometry relies on two essential attributes to define its surface:

  1. geometry.index: An array of integer pointers specifying which vertices form each triangle face. Every three sequential entries define one triangle.
  2. geometry.attributes.position: A flat array of 3D coordinates representing vertex positions [x0, y0, z0, x1, y1, z1, ...].

Because multiple triangles often share the same vertex, the index array prevents redundant coordinate data. To measure the total surface area, you must iterate over the index array rather than reading the position attribute sequentially.

Step-by-Step Implementation

To keep the calculation performant, reuse vector and triangle instances outside the loop. Allocating objects inside a loop that runs thousands of times will trigger unnecessary garbage collection and reduce runtime performance.

Here is the complete function to calculate the surface area:

import * as THREE from 'three';

function calculateIndexedGeometryArea(geometry) {
  const index = geometry.index;
  const position = geometry.attributes.position;

  if (!index) {
    throw new Error('Provided geometry does not have an index array.');
  }

  let totalArea = 0;

  // Allocate reusable objects outside the iteration loop
  const pA = new THREE.Vector3();
  const pB = new THREE.Vector3();
  const pC = new THREE.Vector3();
  const triangle = new THREE.Triangle();

  // Iterate over indices in groups of three
  for (let i = 0; i < index.count; i += 3) {
    const a = index.getX(i);
    const b = index.getX(i + 1);
    const c = index.getX(i + 2);

    // Extract vertex coordinates from the position buffer attribute
    pA.fromBufferAttribute(position, a);
    pB.fromBufferAttribute(position, b);
    pC.fromBufferAttribute(position, c);

    // Compute the area for the current triangle
    triangle.set(pA, pB, pC);
    totalArea += triangle.getArea();
  }

  return totalArea;
}

How the Math Works

The triangle.getArea() method in Three.js computes the area of a triangle formed by points \(A\), \(B\), and \(C\) using the cross product of its edge vectors:

\[\text{Area} = \frac{1}{2} \left| (B - A) \times (C - A) \right|\]

The magnitude of the cross product of two vectors yields the area of the parallelogram they span. Halving this value gives the exact area of the enclosed triangle.

Handling World Transformations

The function above computes the surface area in local object space. If your mesh has non-uniform scaling applied in the scene hierarchy, the local surface area will not match the rendered surface area.

To calculate the surface area in world space:

  1. Update the mesh's world matrix via mesh.updateMatrixWorld(true).
  2. Apply the transformation to each vertex inside the loop: 
    pA.fromBufferAttribute(position, a).applyMatrix4(mesh.matrixWorld);
pB.fromBufferAttribute(position, b).applyMatrix4(mesh.matrixWorld);
pC.fromBufferAttribute(position, c).applyMatrix4(mesh.matrixWorld);

If the mesh only uses uniform scaling, you can alternatively multiply the local surface area by the square of the uniform scale factor (\(scale^2\)).
