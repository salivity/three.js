How to Resize Three.js with ResizeObserver

This article explains how to use the modern JavaScript ResizeObserver API to seamlessly update a Three.js camera and renderer whenever their container element changes size. While developers traditionally relied on the window resize event, ResizeObserver provides element-level accuracy, making it the ideal solution for responsive layouts, split-screens, dynamic sidebars, and embedded WebGL canvases. You will learn the exact sequence of updates required to maintain crisp graphics and prevent perspective distortion.

Why Use ResizeObserver Instead of Window Events?

The standard window.addEventListener('resize', ...) only triggers when the entire browser viewport changes dimensions. It fails to detect size changes driven by CSS animations, collapsing sidebars, or dynamic UI components within a page.

ResizeObserver directly monitors changes to the canvas element or its wrapper container, providing the exact pixel dimensions directly to your rendering logic.

Step-by-Step Implementation

To correctly synchronize Three.js with an element's dimensions, you must update three distinct properties in response to an observed resize:

  1. Camera Aspect Ratio: Recalculate camera.aspect by dividing the new width by height.
  2. Camera Projection Matrix: Call camera.updateProjectionMatrix() to apply the new aspect ratio.
  3. Renderer Canvas Dimensions: Call renderer.setSize(width, height, false) to adjust the internal drawing buffer while letting CSS manage the display size.

Complete HTML and JavaScript Example

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <style>
    * {
      box-sizing: border-box;
      margin: 0;
      padding: 0;
    }
    /* Container can be sized dynamically via Grid, Flexbox, etc. */
    #canvas-container {
      width: 100vw;
      height: 100vh;
      overflow: hidden;
      position: relative;
    }
    canvas {
      width: 100%;
      height: 100%;
      display: block;
    }
  </style>
</head>
<body>
  <div id="canvas-container">
    <canvas id="webgl-canvas"></canvas>
  </div>

  <script type="module">
    import * as THREE from 'three';

    const container = document.getElementById('canvas-container');
    const canvas = document.getElementById('webgl-canvas');

    // 1. Initialize Scene, Camera, and Renderer
    const scene = new THREE.Scene();

    const camera = new THREE.PerspectiveCamera(
      75,
      container.clientWidth / container.clientHeight,
      0.1,
      1000
    );
    camera.position.z = 5;

    const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

    // Add a simple mesh
    const geometry = new THREE.BoxGeometry();
    const material = new THREE.MeshNormalMaterial();
    const cube = new THREE.Mesh(geometry, material);
    scene.add(cube);

    // 2. Set Up the ResizeObserver
    const resizeObserver = new ResizeObserver((entries) => {
      for (const entry of entries) {
        // Read dimensions from contentBoxSize or client properties
        const width = entry.contentRect.width;
        const height = entry.contentRect.height;

        // Prevent division by zero when an element is hidden
        if (width === 0 || height === 0) return;

        // Update Camera
        camera.aspect = width / height;
        camera.updateProjectionMatrix();

        // Update Renderer
        // Passing 'false' prevents setSize from modifying inline CSS styles on the canvas
        renderer.setSize(width, height, false);
      }
    });

    // Observe the parent container (not the canvas itself)
    resizeObserver.observe(container);

    // 3. Render Loop
    function animate() {
      requestAnimationFrame(animate);
      cube.rotation.x += 0.01;
      cube.rotation.y += 0.01;
      renderer.render(scene, camera);
    }
    animate();
  </script>
</body>
</html>

Key Best Practices

  • Observe the Wrapper, Not the Canvas: Observing the <canvas> directly can cause feedback loops where resizing the drawing buffer slightly alters layout dimensions, triggering infinite resize loops. Observing a parent wrapper avoids this issue.
  • Use renderer.setSize(width, height, false): The third parameter (updateStyle) defaults to true. Passing false ensures that Three.js does not write inline width and height style attributes to the canvas element, keeping CSS rules in full control of layout scaling.
  • Cap Device Pixel Ratio: Use Math.min(window.devicePixelRatio, 2) to avoid performance drops on high-density displays (such as 3x or 4x mobile devices) without noticeably degrading visual fidelity.
  • Disconnect When Finished: If you unmount or destroy the canvas dynamically, call resizeObserver.disconnect() to eliminate memory leaks.
