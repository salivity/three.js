Custom Particle Colors with Three.js RawShaderMaterial

In Three.js, rendering particles with unique colors using RawShaderMaterial requires storing color data in a custom buffer attribute on your geometry and explicitly declaring that attribute within your GLSL shaders. Because RawShaderMaterial omits Three.js's built-in GLSL prefixes and definitions, you have complete control over the pipeline. This guide demonstrates how to define a custom color BufferAttribute, configure the vertex and fragment shaders, and bind them to a Points mesh.

1. Create the Geometry and Custom Color Attribute

To assign a unique color to each particle, instantiate a standard THREE.BufferGeometry and attach a custom attribute containing color values (RGB normalized between 0.0 and 1.0).

import * as THREE from 'three';

const particleCount = 1000;
const geometry = new THREE.BufferGeometry();

const positions = new Float32Array(particleCount * 3);
const colors = new Float32Array(particleCount * 3);

for (let i = 0; i < particleCount; i++) {
  const i3 = i * 3;

  // Particle positions
  positions[i3] = (Math.random() - 0.5) * 10;
  positions[i3 + 1] = (Math.random() - 0.5) * 10;
  positions[i3 + 2] = (Math.random() - 0.5) * 10;

  // Custom colors (RGB)
  colors[i3] = Math.random();     // Red
  colors[i3 + 1] = Math.random(); // Green
  colors[i3 + 2] = Math.random(); // Blue
}

geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
geometry.setAttribute('aColor', new THREE.BufferAttribute(colors, 3));

2. Write the Shaders

RawShaderMaterial does not prepend built-in attributes, projection matrices, or precision qualifiers. You must declare them manually.

Vertex Shader

Declare your custom attribute (aColor), assign particle sizes, and pass the color to a varying variable for the fragment shader.

precision mediump float;

// Built-in attributes provided by Three.js BufferGeometry
attribute vec3 position;

// Custom attribute
attribute vec3 aColor;

// Built-in transformation uniforms
uniform mat4 modelViewMatrix;
uniform mat4 projectionMatrix;

// Varying passed to the fragment shader
varying vec3 vColor;

void main() {
    vColor = aColor;

    vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
    gl_PointSize = 10.0 / -mvPosition.z; // Size attenuation
    gl_Position = projectionMatrix * mvPosition;
}

Fragment Shader

Retrieve the varying color and assign it to gl_FragColor.

precision mediump float;

varying vec3 vColor;

void main() {
    // Optional: make the particle circular instead of square
    if (length(gl_PointCoord - vec2(0.5)) > 0.5) {
        discard;
    }

    gl_FragColor = vec4(vColor, 1.0);
}

3. Instantiate the Material and Mesh

Combine the shaders into a RawShaderMaterial and create the THREE.Points object.

const material = new THREE.RawShaderMaterial({
  vertexShader: `
    precision mediump float;
    attribute vec3 position;
    attribute vec3 aColor;
    uniform mat4 modelViewMatrix;
    uniform mat4 projectionMatrix;
    varying vec3 vColor;

    void main() {
        vColor = aColor;
        vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
        gl_PointSize = 50.0 / -mvPosition.z;
        gl_Position = projectionMatrix * mvPosition;
    }
  `,
  fragmentShader: `
    precision mediump float;
    varying vec3 vColor;

    void main() {
        if (length(gl_PointCoord - vec2(0.5)) > 0.5) discard;
        gl_FragColor = vec4(vColor, 1.0);
    }
  `,
  transparent: true,
  depthWrite: false
});

const particleSystem = new THREE.Points(geometry, material);
scene.add(particleSystem);

4. Updating Colors Dynamically

If individual particle colors need to change over time, update the typed array and flag the attribute for a GPU upload:

const colorAttribute = geometry.getAttribute('aColor');
colorAttribute.array[0] = 1.0; // Update R component of first particle
colorAttribute.needsUpdate = true;
