Three.js TessellateModifier: Subdivide Geometry

The TessellateModifier in Three.js is an essential utility for dividing long or uneven geometric faces into smaller, more uniform triangles based on a maximum edge length threshold. This article demonstrates how to import, configure, and apply the TessellateModifier to standard Three.js geometries to ensure consistent vertex density for dynamic vertex displacement, deformation, or detailed lighting calculations.

Understanding TessellateModifier

Standard geometries in Three.js often consist of large triangles spanning across flat planes. When applying vertex shaders, displacement maps, or physics simulations, these long faces fail to deform smoothly due to a lack of intermediate vertices.

The TessellateModifier recursively splits any triangle whose edge length exceeds a specified limit. It splits faces until all edge lengths are below the threshold or until a maximum iteration limit is reached, resulting in a more uniform mesh surface.

Importing the Modifier

TessellateModifier is located in the Three.js add-ons directory. Import it alongside the core Three.js library:

import * as THREE from 'three';
import { TessellateModifier } from 'three/addons/modifiers/TessellateModifier.js';

Basic Implementation

To use the modifier, instantiate it with your target edge length, then call its modify() method on a BufferGeometry.

// 1. Create a base geometry
const geometry = new THREE.PlaneGeometry(10, 10, 2, 2);

// 2. Define subdivision parameters
const maxEdgeLength = 0.5; // Triangles with edges longer than this will split
const maxIterations = 6;   // Safety cap to prevent infinite loops

// 3. Instantiate and apply the modifier
const tessellateModifier = new TessellateModifier(maxEdgeLength, maxIterations);
const tessellatedGeometry = tessellateModifier.modify(geometry);

// 4. Create the mesh
const material = new THREE.MeshStandardMaterial({ 
    color: 0x0077ff, 
    wireframe: true 
});
const mesh = new THREE.Mesh(tessellatedGeometry, material);
scene.add(mesh);

Key Parameters

  • maxEdgeLength: Defines the threshold length. Any triangle with an edge greater than this value will be subdivided into smaller triangles. Smaller values result in a higher density of vertices and a significantly larger triangle count.
  • maxIterations: Restricts the maximum number of subdivision passes. This acts as a safeguard against excessive recursion and memory overflow if the geometry contains extremely large faces relative to a very small maxEdgeLength.

Working with Geometry Formats

The TessellateModifier operates on non-indexed geometry. If you pass an indexed geometry (such as default primitives like THREE.BoxGeometry), the modifier automatically converts it to a non-indexed format internally via .toNonIndexed().

If your workflow requires smooth shading across adjoining faces after tessellation, compute the vertex normals after subdivision:

tessellatedGeometry.computeVertexNormals();

Performance Considerations

Subdividing faces exponentially increases the polygon count of your scene. Keep maxIterations constrained to values typically between 3 and 8, and benchmark the resulting vertex count using tessellatedGeometry.attributes.position.count to avoid rendering bottlenecks on lower-end devices.
