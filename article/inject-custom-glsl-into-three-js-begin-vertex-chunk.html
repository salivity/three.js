Inject Custom GLSL into Three.js begin_vertex Chunk

This article explains how to inject custom GLSL code directly into the begin_vertex shader chunk of any built-in Three.js material using the onBeforeCompile callback. By hooking into the material compilation lifecycle, you can dynamically modify vertex positions while preserving the built-in lighting, shadow, and environment map calculations provided by Three.js standard materials.

Understanding onBeforeCompile and begin_vertex

Three.js builds its native materials (such as MeshStandardMaterial or MeshPhysicalMaterial) by assembling modular code blocks called shader chunks. The #include <begin_vertex> chunk is responsible for initializing the local vertex position variable, named transformed:

vec3 transformed = vec3( position );

By intercepting the shader source code before it compiles, you can append or prepend custom GLSL operations directly to transformed.

Modifying the Shader

To alter the vertex shader, assign a function to the material's onBeforeCompile property. This function receives the internal shader object containing the vertex shader, fragment shader, and uniforms.

import * as THREE from 'three';

const material = new THREE.MeshStandardMaterial({ color: 0x0077ff });

const customUniforms = {
  uTime: { value: 0 }
};

material.onBeforeCompile = (shader) => {
  // 1. Pass custom uniforms to the shader
  shader.uniforms.uTime = customUniforms.uTime;

  // 2. Declare custom uniforms at the top of the vertex shader
  shader.vertexShader = `
    uniform float uTime;
  ` + shader.vertexShader;

  // 3. Inject logic after <begin_vertex>
  shader.vertexShader = shader.vertexShader.replace(
    '#include <begin_vertex>',
    `
    #include <begin_vertex>
    
    // Custom GLSL: apply a wave displacement along the Y axis
    transformed.y += sin(position.x * 4.0 + uTime) * 0.25;
    `
  );
};

Animating Custom Uniforms

Because the uniforms are passed by reference, you can update them inside your application's animation loop using your external reference object:

function animate(time) {
  requestAnimationFrame(animate);

  // Update time uniform (converted to seconds)
  customUniforms.uTime.value = time * 0.001;

  renderer.render(scene, camera);
}
requestAnimationFrame(animate);

Important Considerations

  1. Normals and Shadows: Directly modifying transformed does not automatically recalculate vertex normals. If your vertex displacement is significant, you may also need to modify #include <begin_normal> or #include <defaultnormal_vertex> to ensure lighting remains accurate.
  2. Shadow Maps: If the mesh casts shadows, the shadow pass uses a separate depth material. To keep shadows aligned with displaced geometry, apply the exact same vertex shader modification to the mesh's customDepthMaterial.
  3. Shader Recompilation: onBeforeCompile runs only once per unique material program. If you modify the callback logic at runtime, set material.needsUpdate = true to force Three.js to recompile the shader.
