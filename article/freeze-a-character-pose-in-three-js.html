Freeze a Character Pose in Three.js

This article explains how to freeze a 3D character in its current animated frame in Three.js using the Skeleton and AnimationMixer APIs. You will learn how the Skeleton.pose() method works, how bone transforms interact with skinned meshes, and how to capture an active animation frame to permanently or temporarily lock a character in place.

Understanding Skeleton.pose() and Bind Poses

In Three.js, a SkinnedMesh relies on a Skeleton composed of an array of Bone objects and corresponding boneInverses (the inverse bind matrices).

The Skeleton.pose() method resets every bone in the skeleton back to its original bind pose by inverting the stored boneInverses matrices. By default, calling skeleton.pose() resets your mesh to its T-pose or reference pose, rather than freezing it at an arbitrary frame.

To freeze a character in its current animated state and keep that pose as the new reference pose, you must capture the current world matrices of the bones, update the skeleton's boneInverses, and then apply skeleton.pose().

Step 1: Pause the Animation Mixer

Before modifying the skeleton matrices, halt the active animation updates. If the AnimationMixer continues running, it will overwrite your bone transforms on the next render frame.

// Pause the specific animation action
action.paused = true;

// Or stop updating the mixer entirely in your render loop
// mixer.update(deltaTime); // Comment this out or bypass it

Step 2: Update World Matrices

Ensure the character's bone transformations are fully updated to the current animation frame before reading their values:

characterMesh.updateMatrixWorld(true);

Step 3: Bake the Current Pose into boneInverses

To make skeleton.pose() recognize the current frame as the default resting pose, iterate through each bone, calculate its current transformation relative to the mesh root, and invert it into the boneInverses array.

const skeleton = characterMesh.skeleton;
const rootMatrixInverse = new THREE.Matrix4().copy(characterMesh.matrixWorld).invert();

for (let i = 0; i < skeleton.bones.length; i++) {
    const bone = skeleton.bones[i];
    
    // Compute the bone's world transform relative to the skinned mesh
    const boneMatrixWorld = bone.matrixWorld.clone();
    const relativeBoneMatrix = new THREE.Matrix4()
        .multiplyMatrices(rootMatrixInverse, boneMatrixWorld);

    // Update the inverse bind matrix for this bone
    skeleton.boneInverses[i].copy(relativeBoneMatrix).invert();
}

Step 4: Apply Skeleton.pose()

Once the boneInverses hold the inverted matrices of the current animated position, call pose() to establish this frame as the baseline:

// Re-applies the updated bind matrices to the bones
skeleton.pose();

// Detach or stop the animation mixer actions
mixer.stopAllAction();

Alternative: Temporary Visual Freezing

If you only need to pause the character visually without altering the underlying bind matrices, you do not need to rewrite boneInverses. Simply set the paused property on your AnimationAction:

// Freezes the animation on the current frame
action.paused = true;

// Unfreezes the animation
action.paused = false;

Use the boneInverses update alongside skeleton.pose() when you need to discard the animation data completely, export the posed model, or treat the current animated frame as the new rest pose for procedural physics or IK systems.
