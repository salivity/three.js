Improve Three.js SpotLight Shadows with Camera Far

Adjusting the shadow.camera.far property on a Three.js SpotLight optimizes the depth range of the shadow-casting frustum, concentrating depth buffer precision and texel allocation directly onto visible geometry. By tightening this value instead of relying on default distances, you dramatically enhance shadow sharpness, reduce aliasing, and eliminate shadow acne without the performance cost of increasing the shadow map's texture resolution.

Why shadow.camera.far Impacts Shadow Quality

A SpotLight in Three.js generates shadows using an internal perspective camera (THREE.PerspectiveCamera). The shadow map captures depth information within the volume bounded by shadow.camera.near and shadow.camera.far.

By default, shadow.camera.far defaults to 2000 or inherits a generic scene-wide clipping plane. When this value is significantly larger than the distance to your shadow-receiving surfaces:

  1. Depth Precision Dilution: Perspective shadow depth buffers allocate floating-point precision non-linearly, with precision dropping off exponentially toward the far plane. A massive far value severely compresses depth values, causing z-fighting, shadow detachment (Peter Panning), and jagged artifacts.
  2. Wasted Frustum Space: The shadow projection covers empty air beyond your scene, wasting texel resolution that could otherwise be focused strictly across your active meshes.

How to Configure shadow.camera.far

To get the highest shadow fidelity, set shadow.camera.far so that the frustum ends just past the furthest surface that will receive a shadow from that light.

import * as THREE from 'three';

// 1. Create the SpotLight
const spotLight = new THREE.SpotLight(0xffffff, 2);
spotLight.position.set(0, 15, 10);
spotLight.angle = Math.PI / 6;
spotLight.penumbra = 0.2;
spotLight.castShadow = true;

// 2. Set the maximum light attenuation distance
spotLight.distance = 25;

// 3. Tightly bind the shadow camera planes
spotLight.shadow.camera.near = 5;  // Avoid setting this too close to 0
spotLight.shadow.camera.far = 25;  // Match light.distance or furthest shadow receiver

// 4. Set balanced map dimensions
spotLight.shadow.mapSize.width = 1024;
spotLight.shadow.mapSize.height = 1024;

scene.add(spotLight);

If you modify shadow.camera.far dynamically at runtime, trigger a projection matrix recalculation to apply the changes:

spotLight.shadow.camera.far = newDistance;
spotLight.shadow.camera.updateProjectionMatrix();

Best Practices for Optimal Results

  • Align with SpotLight.distance: If your SpotLight has an attenuation limit set via the distance property, ensure shadow.camera.far matches that exact value. Any shadow calculation beyond light.distance is discarded visually, so extending the shadow camera past it wastes precision.
  • Keep near as High as Possible: Depth precision is most sensitive to the ratio between the near and far planes. Do not leave shadow.camera.near at default fractions like 0.1 if your closest shadow caster is several units away. Set it as close to the first caster as possible.
  • Visualize with CameraHelper: To ensure you are not clipping desired shadows while narrowing the distance, attach a helper to the shadow camera during development:
const shadowHelper = new THREE.CameraHelper(spotLight.shadow.camera);
scene.add(shadowHelper);

By constraining the shadow frustum directly around the active geometry, a standard 1024x1024 or 2048x2048 shadow map will deliver razor-sharp definition and stable depth testing without requiring expensive, high-resolution textures.
