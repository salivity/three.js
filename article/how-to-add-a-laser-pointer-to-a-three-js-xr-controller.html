How to Add a Laser Pointer to a Three.js XR Controller

This article explains how to create and attach a visible Line object to an XR controller in Three.js to serve as an interactive laser pointer for WebXR applications. You will learn how to initialize the controller instance, construct a line pointing along the correct local coordinate axis, assign appropriate materials, and mount it to the controller hierarchy so it tracks motion seamlessly.

Understanding Controller Orientation

In Three.js, an XR controller's default pointing direction aligns along the negative Z-axis ((0, 0, -1)). To create a natural-looking laser pointer, the line geometry must start at the controller's origin (0, 0, 0) and extend outward along the negative Z-axis to the desired distance.

Step 1: Initialize the Controller

First, retrieve the controller instance from the WebGLRenderer's XR manager and add it to the scene:

const controller = renderer.xr.getController(0);
scene.add(controller);

Step 2: Build the Laser Geometry

Use THREE.BufferGeometry and define two vertices: the start point at the controller origin and an endpoint projected forward along the Z-axis.

import * as THREE from 'three';

const laserLength = 5; // Length in meters
const geometry = new THREE.BufferGeometry().setFromPoints([
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(0, 0, -laserLength)
]);

Step 3: Define the Material and Create the Line

Create a line material specifying the color, opacity, and blending properties, then instantiate a THREE.Line object.

const material = new THREE.LineBasicMaterial({
  color: 0xff0000,
  transparent: true,
  opacity: 0.7
});

const laser = new THREE.Line(geometry, material);
laser.name = 'laser';

Step 4: Attach the Line Directly to the Controller

Because the controller is an Object3D, child objects attached to it inherit its position and rotation automatically. Mount the laser using the add method:

controller.add(laser);

Complete Implementation Example

Here is a consolidated implementation demonstrating the full setup within a standard Three.js WebXR workflow:

import * as THREE from 'three';
import { VRButton } from 'three/addons/webxr/VRButton.js';

// Setup renderer with XR enabled
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.xr.enabled = true;
document.body.appendChild(renderer.domElement);
document.body.appendChild(VRButton.createButton(renderer));

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, window.innerWidth / window.innerHeight, 0.1, 10);

// Function to generate a laser line
function createLaserPointer(length = 5, color = 0x00ff00) {
  const points = [
    new THREE.Vector3(0, 0, 0),
    new THREE.Vector3(0, 0, -length)
  ];
  const geometry = new THREE.BufferGeometry().setFromPoints(points);
  const material = new THREE.LineBasicMaterial({
    color: color,
    linewidth: 2
  });
  return new THREE.Line(geometry, material);
}

// Attach laser to Controller 0 (e.g., right hand)
const controller0 = renderer.xr.getController(0);
controller0.add(createLaserPointer(5, 0xff0000));
scene.add(controller0);

// Attach laser to Controller 1 (e.g., left hand)
const controller1 = renderer.xr.getController(1);
controller1.add(createLaserPointer(5, 0x0000ff));
scene.add(controller1);

// Animation loop
renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});

Raycasting Integration

Since the visual laser points along (0, 0, -1), it directly matches the default ray generated by THREE.Raycaster. To perform object selection or UI interactions, create a raycaster and set its origin and direction using the controller’s transformation matrix:

const raycaster = new THREE.Raycaster();
const tempMatrix = new THREE.Matrix4();

function getIntersections(controller, objects) {
  tempMatrix.identity().extractRotation(controller.matrixWorld);
  raycaster.ray.origin.setFromMatrixPosition(controller.matrixWorld);
  raycaster.ray.direction.set(0, 0, -1).applyMatrix4(tempMatrix);

  return raycaster.intersectObjects(objects, false);
}

This ensures that the visual pointer and the interaction logic remain synchronized in 3D space.
