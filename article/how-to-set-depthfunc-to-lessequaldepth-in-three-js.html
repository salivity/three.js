How to Set depthFunc to LessEqualDepth in Three.js

This article explains how to configure the depthFunc property on a Three.js material to explicitly enforce LessEqualDepth testing. By utilizing the built-in Three.js depth constants alongside the material's depth properties, you can ensure that fragments are rendered only when their depth is less than or equal to the existing value stored in the depth buffer.

Understanding depthFunc and LessEqualDepth

The depthFunc property determines the WebGL comparison function used during the depth-buffer test. Setting this property to THREE.LessEqualDepth tells WebGL to render an incoming fragment only if its depth value is less than or equal to the currently stored depth value at that pixel coordinate. While LessEqualDepth is the default behavior in standard WebGL and Three.js setups, explicitly declaring it ensures consistent depth handling across custom materials or when overriding inherited settings.

Configuration During Material Initialization

You can define depthFunc directly within the material's constructor options. Ensure that depthTest is also set to true (its default state), as disabling it bypasses depth testing entirely.

import * as THREE from 'three';

const material = new THREE.MeshStandardMaterial({
  color: 0x0077ff,
  depthTest: true,
  depthFunc: THREE.LessEqualDepth
});

Modifying depthFunc on Existing Materials

If the material has already been instantiated, you can assign the constant directly to the depthFunc property. If the assignment happens after the material has already been rendered to the scene, flag the material for an update:

material.depthFunc = THREE.LessEqualDepth;
material.needsUpdate = true;

Key Considerations

  • depthWrite Interaction: Setting depthFunc controls the testing condition, but depthWrite controls whether the material writes new values to the depth buffer. For standard depth-tested geometry, keep depthWrite: true.
  • WebGL Constant Equivalent: In WebGL, THREE.LessEqualDepth corresponds to the standard gl.LEQUAL constant (value 515).
  • Material Compatibility: The depthFunc property is inherited from the base THREE.Material class, making it available on all built-in materials (such as MeshBasicMaterial, MeshStandardMaterial, and MeshPhysicalMaterial) as well as ShaderMaterial and RawShaderMaterial.
