Three.js Physical Camera Aperture and Focal Length

Simulating a physical camera inside Three.js requires pairing its physically correct lighting pipeline with realistic lens parameters. While modern versions of Three.js utilize physically based lighting by default, achieving physical camera behavior—such as accurate field of view via focal length and optical blur via lens aperture—involves configuring the native PerspectiveCamera settings alongside post-processing passes. This guide explains how to calculate and adjust focal length, aperture, and depth of field to match real-world camera optics.

Setting Up the Physical Environment

In modern Three.js (r150+), the rendering pipeline uses physical lighting units by default (renderer.useLegacyLights = false). Photometric lights (measured in lumens or candelas) interact with physically based materials (MeshStandardMaterial or MeshPhysicalMaterial).

To match camera optics to this setup, you must configure your camera's sensor dimensions and lens focal length.

Adjusting Focal Length

By default, Three.js defines a camera's view using a vertical field of view (fov) in degrees. In real-world cinematography and photography, cameras are configured by sensor size (filmGauge) and lens focal length in millimeters.

Three.js includes built-in methods on PerspectiveCamera to translate millimeters into the internal FOV calculation:

// Define a standard 35mm full-frame camera
const camera = new THREE.PerspectiveCamera(45, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.filmGauge = 35; // Sensor width in millimeters (default is 35mm)

// Set focal length to a 50mm standard prime lens
camera.setFocalLength(50);

Whenever you alter the focal length using .setFocalLength(), Three.js recalculates camera.fov automatically based on the filmGauge. Remember to call camera.updateProjectionMatrix() if you modify related camera bounds directly.

Common real-world focal lengths include:

  • 24mm: Wide-angle (landscape, architecture)
  • 50mm: Standard view (closest to human eye perception)
  • 85mm / 105mm: Portrait lenses with tighter framing and flatter perspective

Adjusting Aperture and Depth of Field

Real-world aperture (often expressed as an f-stop like f/1.8 or f/8) controls two things: exposure (how much light enters the lens) and depth of field (the amount of background/foreground blur).

Standard WebGL rasterization renders every pixel sharply in focus regardless of lighting or camera settings. To physically simulate lens aperture, you must use post-processing—typically the BokehPass provided by the Three.js addon library.

Configuring Aperture via BokehPass

To implement aperture-based optical blur, attach a BokehPass to an EffectComposer:

import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { BokehPass } from 'three/addons/postprocessing/BokehPass.js';

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

const bokehPass = new BokehPass(scene, camera, {
    focus: 10.0,       // Distance to the focused subject in scene units
    aperture: 0.025,   // Lens aperture size (higher creates shallower depth of field)
    maxblur: 0.01      // Maximum blur intensity clamp
});
composer.addPass(bokehPass);

Controlling Physical Aperture Variables Dynamically

To update focus and aperture during runtime:

  1. Focus Distance: Adjust bokehPass.uniforms['focus'].value to match the distance from the camera to the target object.
  2. Aperture Size: Adjust bokehPass.uniforms['aperture'].value. A higher value mimics a wide lens opening (e.g., f/1.4), which yields a thin focal plane and heavy background bokeh. A lower value mimics a narrow aperture (e.g., f/16), bringing more of the scene into focus.

Complete Implementation Example

import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { BokehPass } from 'three/addons/postprocessing/BokehPass.js';

// Renderer setup
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.0;
document.body.appendChild(renderer.domElement);

const scene = new THREE.Scene();

// Camera setup with physical sensor and lens
const camera = new THREE.PerspectiveCamera(45, window.innerWidth / window.innerHeight, 0.1, 100);
camera.filmGauge = 35;
camera.setFocalLength(85); // 85mm portrait focal length
camera.position.set(0, 1.5, 5);

// Depth of field post-processing (physical aperture simulation)
const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

const bokehPass = new BokehPass(scene, camera, {
    focus: 5.0,        // Target is 5 units away
    aperture: 0.005,   // Simulated f-stop scale
    maxblur: 0.015
});
composer.addPass(bokehPass);

// Render loop using the composer instead of the default renderer
function animate() {
    requestAnimationFrame(animate);
    composer.render();
}
animate();

By standardizing filmGauge and using camera.setFocalLength() alongside depth-of-field passes, the visual output aligns directly with real-world optical measurements and physical lighting behavior.
