Export Three.js Node Material to JSON String

This article provides a direct guide on serializing and exporting a purely node-based material setup into a human-readable JSON string in Three.js. You will learn how to configure a node material graph using the modern three/nodes system, extract its serialized data structure using built-in serialization hooks, and format the output into clean JSON suitable for storage, debugging, or network transmission.

1. Creating the Node Material Graph

Three.js includes a modular node system accessible via the three/nodes entry point (or three/addons/nodes). Node materials define shaders through composable objects such as mathematical operations, colors, attributes, and procedural textures.

To serialize a setup, start by defining your material and attaching node operations to its slots:

import * as THREE from 'three';
import { 
  MeshStandardNodeMaterial, 
  color, 
  float, 
  mul, 
  oscSine, 
  timerLocal 
} from 'three/nodes';

// Instantiate the node material
const material = new MeshStandardNodeMaterial({
  roughness: 0.4,
  metalness: 0.1
});

// Build a node network
const baseColor = color(0x2194ce);
const pulse = oscSine(timerLocal(1.0));
const modulatedColor = mul(baseColor, pulse);

// Assign nodes to material slots
material.colorNode = modulatedColor;
material.roughnessNode = float(0.2);

2. Serializing with toJSON()

Every node and material in the node system implements a .toJSON() method. When invoked on a NodeMaterial, this method recursively traverses the attached node graph, gathers all node definitions, and constructs a structured JavaScript object representing the material hierarchy.

To ensure all interconnected nodes, textures, and sub-properties are indexed without duplication, pass a metadata container object to the serialization call:

// Create a metadata cache for cross-referenced nodes and textures
const meta = {
  geometries: {},
  materials: {},
  textures: {},
  images: {},
  nodes: {}
};

// Serialize the material object and its entire node graph
const serializedData = material.toJSON(meta);

If you call material.toJSON() without arguments, Three.js initializes an internal meta object automatically. Explicitly providing the object is beneficial when serializing multiple materials that share common nodes or textures.

3. Converting to a Readable JSON String

The .toJSON() method returns a raw JavaScript object. To convert this into a formatted, human-readable JSON string, use JSON.stringify() with spacing arguments:

// Indent with 2 spaces for human readability
const readableJsonString = JSON.stringify(serializedData, null, 2);

console.log(readableJsonString);

4. Inspecting the JSON Output

The resulting string includes top-level metadata, the root material configuration, and a dictionary of serialized node objects. Each node entry records:

  • uuid: The unique identifier for reference linking.
  • type: The node class name (e.g., ColorNode, OperatorNode, TimerNode).
  • input nodes: Pointers referencing the UUIDs of dependent nodes.
  • value: Stored values for static parameters (like scalar floats or hex colors).

5. Saving the JSON to a File (Optional)

To download the serialized JSON directly from the browser:

function downloadJson(jsonString, filename = 'node-material.json') {
  const blob = new Blob([jsonString], { type: 'application/json' });
  const link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = filename;
  link.click();
  URL.revokeObjectURL(link.href);
}

downloadJson(readableJsonString);

This procedure converts purely procedural or connected node graphs into a declarative format that can be stored and later reconstructed using NodeMaterialLoader.
