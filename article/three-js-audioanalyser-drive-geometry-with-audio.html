Three.js AudioAnalyser: Drive Geometry with Audio

This guide explains how to extract real-time frequency domain data using Three.js's built-in AudioAnalyser and apply it to dynamically alter 3D mesh geometry. By capturing frequency amplitudes through the Web Audio API integration and mapping these values to vertex positions or transformations inside the render loop, you can create responsive, audio-reactive visualizers in real time.

1. Set Up the Audio Listener and Analyser

Three.js abstracts the Web Audio API using THREE.AudioListener, THREE.Audio, and THREE.AudioAnalyser. The AudioAnalyser processes audio signals and computes frequency data via Fast Fourier Transform (FFT).

import * as THREE from 'three';

// Create a listener and attach it to the camera
const listener = new THREE.AudioListener();
camera.add(listener);

// Create a non-positional audio source
const sound = new THREE.Audio(listener);

// Load an audio file
const audioLoader = new THREE.AudioLoader();
audioLoader.load('track.mp3', (buffer) => {
  sound.setBuffer(buffer);
  sound.setLoop(true);
  sound.setVolume(0.5);
  sound.play();
});

// Initialize the AudioAnalyser
// fftSize must be a power of 2 (e.g., 32, 64, 128, 256, 512)
const fftSize = 128;
const analyser = new THREE.AudioAnalyser(sound, fftSize);

The frequency array will have a length equal to fftSize / 2. With an fftSize of 128, the analyser outputs 64 discrete frequency bins.

2. Define the Reactive Geometry

Create a mesh whose geometry can be deformed based on incoming audio. Store the original vertex positions so you can calculate displacements without compounding offsets each frame.

const geometry = new THREE.IcosahedronGeometry(2, 4);
const material = new THREE.MeshStandardMaterial({
  color: 0x00ffcc,
  wireframe: true,
});
const sphere = new THREE.Mesh(geometry, material);
scene.add(sphere);

// Save initial vertex positions for baseline reference
const positionAttribute = geometry.getAttribute('position');
const initialPositions = positionAttribute.array.slice();

3. Extract Frequency Data and Mutate Geometry

In your main animation loop, call analyser.getFrequencyData(). This returns a Uint8Array containing normalized frequency amplitudes between 0 and 255, where lower indices represent bass frequencies and higher indices represent treble.

To animate the geometry, iterate through its vertices, calculate displacement using the frequency values, and flag the attribute for an update:

function animate() {
  requestAnimationFrame(animate);

  // Retrieve the Uint8Array of frequency amplitudes
  const frequencyData = analyser.getFrequencyData();

  // Calculate an overall average or target specific frequency ranges
  const averageFrequency = analyser.getAverageFrequency();

  const positions = geometry.getAttribute('position');
  
  for (let i = 0; i < positions.count; i++) {
    const ix = i * 3;
    const iy = i * 3 + 1;
    const iz = i * 3 + 2;

    // Base position vector
    const uX = initialPositions[ix];
    const uY = initialPositions[iy];
    const uZ = initialPositions[iz];

    // Map a frequency bin to the vertex index
    const dataIndex = i % frequencyData.length;
    const amplitude = frequencyData[dataIndex] / 255.0; // Normalize between 0 and 1

    // Displace vertex outward along its normal
    const displacement = 1 + amplitude * 0.5;

    positions.array[ix] = uX * displacement;
    positions.array[iy] = uY * displacement;
    positions.array[iz] = uZ * displacement;
  }

  // Signal Three.js that buffer attributes have changed
  positions.needsUpdate = true;

  // Optional: Global scale adjustment using average volume
  const scale = 1 + averageFrequency / 512;
  sphere.scale.set(scale, scale, scale);

  renderer.render(scene, camera);
}

animate();

4. Performance Considerations

  • Buffer Updates: Modifying position.array directly is fast, but keep your vertex count balanced. High-density geometries updated every frame can cause CPU bottlenecks.
  • FFT Size: Smaller fftSize values (32 to 128) yield broader frequency groups and run faster. Higher values (512 to 2048) yield fine-grained data useful for visual bar equalizers.
  • Shader Alternative: For complex geometries with thousands of vertices, pass the frequency array as a DataTexture uniform to a custom vertex shader, offloading vertex displacement computation entirely to the GPU.
