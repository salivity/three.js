Fit Orthographic Camera to Scene Bounds in Three.js

Configuring the near and far clipping planes of an OrthographicCamera to tightly encompass a scene prevents visual clipping and optimizes depth buffer precision. To achieve this in Three.js, you must calculate the world-space bounding box of your target objects, transform its eight vertices into the camera's local coordinate space, and extract the minimum and maximum depths along the viewing axis.

1. Compute the World-Space Bounding Box

First, compute an axis-aligned bounding box (THREE.Box3) that encloses the entire scene or the specific collection of objects you want to render.

const box = new THREE.Box3().setFromObject(scene);

2. Transform Bounding Box Vertices to Camera Space

Because the camera can be rotated or positioned anywhere in world space, relying on world-space bounds directly will produce incorrect depth values. Instead, extract the eight corners of the bounding box and multiply each by the camera’s inverse world matrix (camera.matrixWorldInverse).

camera.updateMatrixWorld();

const corners = [
  new THREE.Vector3(box.min.x, box.min.y, box.min.z),
  new THREE.Vector3(box.min.x, box.min.y, box.max.z),
  new THREE.Vector3(box.min.x, box.max.y, box.min.z),
  new THREE.Vector3(box.min.x, box.max.y, box.max.z),
  new THREE.Vector3(box.max.x, box.min.y, box.min.z),
  new THREE.Vector3(box.max.x, box.min.y, box.max.z),
  new THREE.Vector3(box.max.x, box.max.y, box.min.z),
  new THREE.Vector3(box.max.x, box.max.y, box.max.z)
];

let minZ = Infinity;
let maxZ = -Infinity;

for (let i = 0; i < 8; i++) {
  const cornerInCameraSpace = corners[i].applyMatrix4(camera.matrixWorldInverse);
  minZ = Math.min(minZ, cornerInCameraSpace.z);
  maxZ = Math.max(maxZ, cornerInCameraSpace.z);
}

3. Calculate Near and Far Values

Three.js cameras look down their negative local Z-axis. Consequently, points in front of the camera have negative Z coordinates:

  • The closest point to the camera has the highest Z value (maxZ).
  • The farthest point from the camera has the lowest Z value (minZ).

To translate these coordinates into positive distances along the viewing ray, negate the values:

camera.near = -maxZ;
camera.far = -minZ;

4. Apply a Padding Margin and Update Projection

Floating-point precision issues or geometry sitting precisely on the planes can cause z-fighting or clipping. Apply a small safety margin and update the projection matrix:

const padding = 0.1;

camera.near = -maxZ - padding;
camera.far = -minZ + padding;

camera.updateProjectionMatrix();

Complete Implementation Function

function fitCameraPlanesToBox(camera, targetObject, padding = 0.5) {
  const box = new THREE.Box3().setFromObject(targetObject);
  
  if (box.isEmpty()) return;

  camera.updateMatrixWorld();

  const corners = [
    new THREE.Vector3(box.min.x, box.min.y, box.min.z),
    new THREE.Vector3(box.min.x, box.min.y, box.max.z),
    new THREE.Vector3(box.min.x, box.max.y, box.min.z),
    new THREE.Vector3(box.min.x, box.max.y, box.max.z),
    new THREE.Vector3(box.max.x, box.min.y, box.min.z),
    new THREE.Vector3(box.max.x, box.min.y, box.max.z),
    new THREE.Vector3(box.max.x, box.max.y, box.min.z),
    new THREE.Vector3(box.max.x, box.max.y, box.max.z)
  ];

  let minZ = Infinity;
  let maxZ = -Infinity;

  for (let i = 0; i < 8; i++) {
    const point = corners[i].applyMatrix4(camera.matrixWorldInverse);
    minZ = Math.min(minZ, point.z);
    maxZ = Math.max(maxZ, point.z);
  }

  camera.near = -maxZ - padding;
  camera.far = -minZ + padding;

  camera.updateProjectionMatrix();
}
