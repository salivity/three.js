How to Scale Instances in Three.js InstancedMesh

This guide explains how to apply individual scaling to specific instances within an InstancedMesh in Three.js. By manipulating the transformation matrix assigned to each instance, you can dynamically or statically resize targeted objects without forfeiting the high-performance rendering benefits that instancing provides.

The Core Concept: Transform Matrices

An InstancedMesh does not provide direct scale, position, or rotation properties for individual instances. Instead, every instance's transformation is stored as a 16-element array representing a 4x4 matrix inside the InstancedMesh.instanceMatrix buffer attribute.

To scale a specific instance, you must retrieve its matrix, update the scale components, write the updated matrix back to the mesh, and notify Three.js that the buffer has changed.

Method 1: Using a Dummy Object3D (Recommended)

The cleanest and most common approach is using an auxiliary THREE.Object3D as a proxy. This avoids manual matrix math and handles composition and decomposition automatically.

import * as THREE from 'three';

// 1. Create a reusable dummy object to avoid memory allocation in loops
const dummy = new THREE.Object3D();
const matrix = new THREE.Matrix4();

function setInstanceScale(instancedMesh, index, scaleX, scaleY, scaleZ) {
  // 2. Read the current transform of the target instance into the matrix
  instancedMesh.getMatrixAt(index, matrix);

  // 3. Decompose the matrix into position, rotation, and scale via dummy
  dummy.position.setFromMatrixPosition(matrix);
  dummy.quaternion.setFromRotationMatrix(matrix);
  
  // 4. Apply the new scale values
  dummy.scale.set(scaleX, scaleY, scaleZ);

  // 5. Recompute the local matrix and save it back to the InstancedMesh
  dummy.updateMatrix();
  instancedMesh.setMatrixAt(index, dummy.matrix);

  // 6. Flag the instanceMatrix attribute for a GPU update
  instancedMesh.instanceMatrix.needsUpdate = true;
}

Method 2: Direct Matrix Decomposition

If you prefer to avoid using an Object3D, you can decompose the matrix directly using Three.js math classes:

const matrix = new THREE.Matrix4();
const position = new THREE.Vector3();
const quaternion = new THREE.Quaternion();
const scale = new THREE.Vector3();

function scaleInstanceDirectly(instancedMesh, index, newScale) {
  // Retrieve the existing matrix
  instancedMesh.getMatrixAt(index, matrix);

  // Extract transform components
  matrix.decompose(position, quaternion, scale);

  // Update scale
  scale.copy(newScale);

  // Rebuild the matrix and write it back
  matrix.compose(position, quaternion, scale);
  instancedMesh.setMatrixAt(index, matrix);

  // Notify WebGL to upload the updated buffer
  instancedMesh.instanceMatrix.needsUpdate = true;
}

Important Considerations

  • needsUpdate Flag: Always set instancedMesh.instanceMatrix.needsUpdate = true after modifying instances. If this is omitted, the GPU will not receive the modified transformation data, and your changes will not be visible.
  • Batching Updates: If you are updating multiple instances simultaneously (for example, inside a render loop), iterate through all target indices and update their matrices first, then set instancedMesh.instanceMatrix.needsUpdate = true once at the end to prevent redundant uploads.
  • Bounding Volumes: Scaling an instance alters its physical dimensions, but InstancedMesh maintains a single global bounding box and sphere for frustum culling. If scaling makes instances significantly larger, call instancedMesh.computeBoundingSphere() and instancedMesh.computeBoundingBox() to prevent premature culling artifacts.
