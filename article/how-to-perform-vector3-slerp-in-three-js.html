How to Perform Vector3 Slerp in Three.js

Spherical linear interpolation (slerp) allows you to interpolate between two vectors along the surface of a sphere, preserving constant angular velocity. While the Three.js Vector3 class natively contains only the .lerp() method for linear interpolation, you can perform a spherical interpolation on standard 3D vectors by leveraging the THREE.Quaternion.slerp() method to rotate the source vector toward the target vector across an arc.

Why Three.js Handles Slerp via Quaternions

In Three.js, the .slerp() method belongs to THREE.Quaternion rather than THREE.Vector3. Standard linear interpolation with Vector3.lerp() takes a straight-line shortcut between two points in space, which causes the interpolated vector's length to shrink during the transition. To rotate along a true spherical arc with constant speed, you calculate the rotation between the two directions as a quaternion, slerp that quaternion, and apply the rotated orientation back to the vector.

Step-by-Step Implementation

To slerp a standard Vector3 using Three.js's built-in slerp() method:

  1. Store Magnitudes: Extract and linearly interpolate the lengths of the two vectors if they have different magnitudes.
  2. Normalize Directions: Normalize both vectors to isolate their directional components on the unit sphere.
  3. Calculate the Rotation: Create an identity quaternion and use setFromUnitVectors() to derive the angular delta between the two normalized directions.
  4. Perform Quaternion Slerp: Interpolate between the identity quaternion (representing zero rotation) and the target rotation using quaternion.slerp().
  5. Apply Rotation and Scale: Apply the interpolated quaternion to the original direction vector and multiply by the interpolated magnitude.

Reusable Code Example

import * as THREE from 'three';

const _v1 = new THREE.Vector3();
const _v2 = new THREE.Vector3();
const _q = new THREE.Quaternion();
const _targetQ = new THREE.Quaternion();

/**
 * Spherical linear interpolation between two Vector3 points.
 * 
 * @param {THREE.Vector3} vStart - Starting vector.
 * @param {THREE.Vector3} vEnd - Ending vector.
 * @param {number} alpha - Interpolation factor between 0 and 1.
 * @param {THREE.Vector3} [target] - Vector to receive the result.
 * @returns {THREE.Vector3}
 */
function slerpVector3(vStart, vEnd, alpha, target = new THREE.Vector3()) {
  // Handle identical vectors
  if (vStart.equals(vEnd)) {
    return target.copy(vStart);
  }

  // Copy and normalize vectors for direction calculations
  _v1.copy(vStart).normalize();
  _v2.copy(vEnd).normalize();

  // Reset base quaternion to identity (start orientation)
  _q.identity();

  // Compute total rotation needed to go from _v1 to _v2
  _targetQ.setFromUnitVectors(_v1, _v2);

  // Slerp from identity (0% rotation) to _targetQ (100% rotation)
  _q.slerp(_targetQ, alpha);

  // Interpolate magnitude linearly
  const length = THREE.MathUtils.lerp(vStart.length(), vEnd.length(), alpha);

  // Apply the slerped rotation to the normalized starting vector and scale
  return target.copy(_v1).applyQuaternion(_q).setLength(length);
}

// Example usage:
const start = new THREE.Vector3(10, 0, 0);
const end = new THREE.Vector3(0, 10, 0);
const result = new THREE.Vector3();

// Interpolate halfway (45 degrees along the arc)
slerpVector3(start, end, 0.5, result);
console.log(result); // Vector3 around (7.07, 7.07, 0)

Important Considerations

  • Opposing Vectors: If two vectors are pointing in exact opposite directions (angle of 180 degrees), setFromUnitVectors() cannot determine a unique rotational axis automatically. If opposing vectors are expected, specify an arbitrary perpendicular axis to handle the halfway rotation manually.
  • Zero Vectors: Vectors with a length of 0 cannot be normalized and will produce NaN values. Ensure vectors are non-zero before calculating directional slerp.
