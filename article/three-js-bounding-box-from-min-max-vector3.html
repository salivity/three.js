Three.js Bounding Box from Min Max Vector3

In Three.js, spatial boundaries are represented using axis-aligned bounding boxes (AABB) via the Box3 class. This guide explains how to define a bounding box using minimum and maximum Vector3 coordinates, instantiate it correctly, avoid common pitfalls, and visualize the boundary inside a 3D scene.

Understanding the Box3 Class

A bounding box in Three.js is represented by THREE.Box3. It is defined by two points in 3D space:

  • min: A THREE.Vector3 representing the lower boundary \((x_{\min}, y_{\min}, z_{\min})\).
  • max: A THREE.Vector3 representing the upper boundary \((x_{\max}, y_{\max}, z_{\max})\).

For the bounding box to be valid, every component of min must be less than or equal to the corresponding component of max (\(x_{\min} \le x_{\max}\), \(y_{\min} \le y_{\max}\), \(z_{\min} \le z_{\max}\)).

Method 1: Passing Coordinates to the Constructor

The most direct way to define a bounding box is to pass existing Vector3 objects directly into the THREE.Box3 constructor.

import * as THREE from 'three';

// Define the minimum and maximum coordinates
const min = new THREE.Vector3(-2, 0, -2);
const max = new THREE.Vector3(2, 4, 2);

// Create the bounding box
const boundingBox = new THREE.Box3(min, max);

The constructor copies the coordinate values from the provided vectors, meaning subsequent changes to min or max will not mutate the bounding box unless re-applied.

Method 2: Using the .set() Method

If you already have an instantiated Box3 object, you can set or update its boundaries using the .set() method.

import * as THREE from 'three';

const boundingBox = new THREE.Box3();

const min = new THREE.Vector3(-5, -5, -5);
const max = new THREE.Vector3(5, 5, 5);

boundingBox.set(min, max);

Visualizing the Bounding Box

To confirm that your bounding box is positioned and scaled correctly in your scene, use THREE.Box3Helper.

// Create a helper with a chosen wireframe color
const boxHelper = new THREE.Box3Helper(boundingBox, 0xffff00);

// Add the helper to the scene
scene.add(boxHelper);

Useful Box3 Operations

Once defined, a Box3 provides several built-in methods for collision detection, spatial queries, and transformations:

  • Get Dimensions: 
    const size = new THREE.Vector3();
boundingBox.getSize(size); // Stores the width, height, and depth in 'size'
  • Get Center Point: 
    const center = new THREE.Vector3();
boundingBox.getCenter(center); // Stores the center coordinates in 'center'
  • Check Point Containment: 
    const point = new THREE.Vector3(0, 1, 0);
const isInside = boundingBox.containsPoint(point); // Returns boolean
  • Check Box Intersection: 
    const collides = boundingBox.intersectsBox(otherBoundingBox); // Returns boolean
