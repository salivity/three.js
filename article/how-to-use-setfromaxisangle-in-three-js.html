How to Use setFromAxisAngle in Three.js

In Three.js, rotating 3D objects using quaternions is the standard approach to avoid gimbal lock and ensure smooth orientation changes. This guide explains how to apply an axis-angle rotation directly to a THREE.Quaternion using the setFromAxisAngle method, detailing the required parameters, the importance of vector normalization, and practical code implementations for both new and existing rotations.

Understanding the setFromAxisAngle Method

The setFromAxisAngle(axis, angle) method configures a quaternion based on an axis of rotation and an angle specified in radians.

quaternion.setFromAxisAngle(axis, angle);
  • axis (THREE.Vector3): The direction vector around which the rotation occurs. This vector must be normalized (have a length of 1).
  • angle (Float): The rotation magnitude in radians.

Setting a Quaternion Directly

To set a quaternion's rotation directly, create a normalized axis vector, define the angle, and call the method on the target quaternion.

import * as THREE from 'three';

// 1. Define the rotation axis (e.g., the Y-axis) and normalize it
const axis = new THREE.Vector3(0, 1, 0).normalize();

// 2. Define the angle in radians (e.g., 45 degrees)
const angle = THREE.MathUtils.degToRad(45);

// 3. Create a quaternion and apply the axis-angle rotation
const quaternion = new THREE.Quaternion();
quaternion.setFromAxisAngle(axis, angle);

Applying Directly to a Mesh or Object3D

Every THREE.Object3D (including meshes, cameras, and groups) has a .quaternion property. You can apply the rotation directly to the object's quaternion:

const mesh = new THREE.Mesh(geometry, material);

const axis = new THREE.Vector3(1, 0, 0).normalize(); // Rotate around X-axis
const angle = Math.PI / 2; // 90 degrees in radians

// Apply directly to the mesh
mesh.quaternion.setFromAxisAngle(axis, angle);

Applying Rotation Incrementally to an Existing Quaternion

Calling setFromAxisAngle directly on an object overwrites any existing orientation. If you want to add an axis-angle rotation to an existing rotation rather than replacing it, generate a temporary quaternion and multiply it with the existing one:

// Define the incremental rotation
const deltaAxis = new THREE.Vector3(0, 0, 1).normalize(); // Z-axis
const deltaAngle = THREE.MathUtils.degToRad(15);

const deltaRotation = new THREE.Quaternion();
deltaRotation.setFromAxisAngle(deltaAxis, deltaAngle);

// Combine with the existing rotation
mesh.quaternion.multiply(deltaRotation);

Use multiply() to apply the rotation in local object space, or premultiply() to apply the rotation in world/parent space.
