Dynamic High-Res Shadows for Close Objects in Three.js

Achieving high-resolution shadows for nearby objects in Three.js requires maximizing shadow texel density near the camera. Because native shadow map textures have fixed dimensions, rendering sharp close-up shadows is best handled either through Cascaded Shadow Maps (CSM) or by dynamically resizing the DirectionalLight shadow camera frustum each frame to tightly enclose the viewer's immediate surroundings.

Method 1: Cascaded Shadow Maps (Recommended)

Cascaded Shadow Maps split the camera view frustum into multiple depth partitions (cascades). The closest cascade covers a small area near the camera with high texel density, while distant cascades cover larger areas with lower resolution.

Three.js provides an official CSM addon found in three/addons/csm/CSM.js.

import { CSM } from 'three/addons/csm/CSM.js';

const csm = new CSM({
    maxFar: 100, // Maximum distance shadows are cast
    cascades: 4,  // Number of shadow cascades
    mode: 'practical', // Split calculation: 'uniform', 'logarithmic', or 'practical'
    parent: scene,
    shadowMapSize: 2048,
    lightDirection: new THREE.Vector3(-1, -1, -1).normalize(),
    camera: camera
});

// Inside your animation loop:
function animate() {
    requestAnimationFrame(animate);
    
    // Updates cascade frustums based on camera movement
    csm.update(); 
    
    renderer.render(scene, camera);
}

When using CSM, materials must be updated to support CSM shaders:

const material = new THREE.MeshStandardMaterial({ color: 0x808080 });
csm.setupMaterial(material);

Method 2: Dynamic Frustum Fitting

If using external addons is not an option, you can dynamically adjust the orthographic projection bounds of the standard DirectionalLight.shadow.camera to tightly hug the player or close-up subjects. Reducing the area covered by the shadow camera increases shadow sharpness without changing the actual texture size.

1. Setup the Directional Light

Initialize a directional light with a fixed, high-resolution texture map:

const dirLight = new THREE.DirectionalLight(0xffffff, 1.5);
dirLight.castShadow = true;

// Set high allocation for the shadow buffer
dirLight.shadow.mapSize.width = 2048;
dirLight.shadow.mapSize.height = 2048;

// Use PCFSoftShadowMap on the WebGLRenderer for clean edge filtering
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

scene.add(dirLight);
scene.add(dirLight.target);

2. Recalculate Bounds Per Frame

In the animation loop, position the light and its target near the camera or target object, then constrain the shadow camera extent:

const shadowDistance = 15; // Focus boundary size for close objects

function updateShadowCamera(targetPosition, lightDirection) {
    // 1. Center the light target on the subject
    dirLight.target.position.copy(targetPosition);
    
    // 2. Position light relative to target
    dirLight.position.copy(targetPosition).addScaledVector(lightDirection, 30);

    // 3. Shrink the shadow camera frustum to the immediate area
    const cam = dirLight.shadow.camera;
    cam.left = -shadowDistance;
    cam.right = shadowDistance;
    cam.top = shadowDistance;
    cam.bottom = -shadowDistance;
    cam.near = 0.1;
    cam.far = 60;

    // 4. Commit projection matrix changes
    cam.updateProjectionMatrix();
}

const lightDir = new THREE.Vector3(1, 2, 1).normalize();

function animate() {
    requestAnimationFrame(animate);

    // Track the camera position or a specific close-up mesh
    updateShadowCamera(camera.position, lightDir);

    renderer.render(scene, camera);
}

Optimizing Shadow Map Quality

To remove artifacts caused by high-resolution projection on close geometry:

  • Shadow Bias: Set dirLight.shadow.bias = -0.0005 to prevent shadow acne.
  • Normal Bias: Use dirLight.shadow.normalBias = 0.05 to eliminate self-shadowing artifacts on curved surfaces.
  • Map Size vs. Frustum Size: Prioritize reducing shadow camera bounds over increasing mapSize beyond 4096, as large textures cause significant memory overhead and GPU fill-rate penalties.
