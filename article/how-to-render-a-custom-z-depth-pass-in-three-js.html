How to Render a Custom Z-Depth Pass in Three.js

This guide explains how to render a specialized z-depth pass in Three.js for use in external compositing software like Nuke, After Effects, or DaVinci Resolve. You will learn how to initialize an off-screen render target, utilize THREE.MeshDepthMaterial with appropriate depth packing for maximum numerical precision, handle alpha-tested cutouts, and swap materials at render time without corrupting your main beauty pass.

1. Set Up a High-Precision Render Target

Standard 8-bit per-channel targets can introduce banding artifacts in depth passes. To maintain depth accuracy for compositing, create a THREE.WebGLRenderTarget configured with 32-bit floating-point textures or 16-bit half-float textures.

import * as THREE from 'three';

const width = window.innerWidth;
const height = window.innerHeight;

const depthRenderTarget = new THREE.WebGLRenderTarget(width, height, {
  minFilter: THREE.NearestFilter,
  magFilter: THREE.NearestFilter,
  type: THREE.FloatType, // Provides 32-bit float precision
  format: THREE.RGBAFormat
});

2. Configure the Depth Material

Three.js provides THREE.MeshDepthMaterial out of the box. By default, it encodes distance non-linearly across the camera's near and far planes.

Depending on your pipeline, you can use:

  • Standard Depth (Float Target): Direct depth output without packing.
  • RGBADepthPacking (8-bit Target): Packs a high-precision depth value into four 8-bit channels (RGBA) if your output format does not support floating-point textures.

For high-precision float buffers, initialize the material without packing:

const depthMaterial = new THREE.MeshDepthMaterial();

If you are writing to a standard 8-bit image format (like PNG), use packed depth:

const packedDepthMaterial = new THREE.MeshDepthMaterial({
  depthPacking: THREE.RGBADepthPacking
});

3. Handle Alpha Cutouts (Foliage and Transparent Textures)

A common issue in depth passes is that meshes with alpha-tested textures (such as leaves or chain-link fences) render as solid geometry. If your scene contains alpha cutouts, use a specialized material variant that checks the alpha map:

function createAlphaDepthMaterial(map, alphaTest = 0.5) {
  return new THREE.MeshDepthMaterial({
    depthPacking: THREE.RGBADepthPacking,
    map: map,
    alphaTest: alphaTest
  });
}

Assign this material directly to mesh.customDepthMaterial on individual meshes. When Three.js processes shadow or depth passes, it prioritizes customDepthMaterial over global overrides.

4. Execute the Depth Render Pass

The cleanest way to capture a specialized depth pass without mutating the original mesh materials is using scene.overrideMaterial. This temporarily forces every object in the scene to render with your depth material.

function renderDepthPass(renderer, scene, camera, target) {
  // 1. Direct renderer output to the off-screen buffer
  renderer.setRenderTarget(target);
  renderer.clear();

  // 2. Override scene materials
  scene.overrideMaterial = depthMaterial;

  // 3. Render the depth scene
  renderer.render(scene, camera);

  // 4. Restore the original state
  scene.overrideMaterial = null;
  renderer.setRenderTarget(null);
}

5. Extract Linear Depth for External Compositors

External compositing applications usually expect linear depth (Z-distance in world units) rather than normalized screen-space depth ([0.0, 1.0]).

To generate camera-linear depth directly on the GPU, replace MeshDepthMaterial with a custom ShaderMaterial:

const linearDepthMaterial = new THREE.ShaderMaterial({
  vertexShader: `
    varying float vViewZ;
    void main() {
      vec4 viewPosition = modelViewMatrix * vec4(position, 1.0);
      vViewZ = -viewPosition.z; // Distance along negative Z in view space
      gl_Position = projectionMatrix * viewPosition;
    }
  `,
  fragmentShader: `
    varying float vViewZ;
    uniform float near;
    uniform float far;
    void main() {
      // Normalize depth between near and far planes
      float linearDepth = (vViewZ - near) / (far - near);
      gl_FragColor = vec4(vec3(clamp(linearDepth, 0.0, 1.0)), 1.0);
    }
  `,
  uniforms: {
    near: { value: camera.near },
    far: { value: camera.far }
  }
});

Assign linearDepthMaterial to scene.overrideMaterial during your render loop.

6. Read and Export the Depth Data

To send the frame to an external pipeline, read the rendered pixels out of the target buffer:

const buffer = new Float32Array(width * height * 4);
renderer.readRenderTargetPixels(depthRenderTarget, 0, 0, width, height, buffer);

This buffer contains raw, per-pixel floating-point distance data that can be encoded into formats like OpenEXR or sent over a local WebSocket server to your external compositing host.
