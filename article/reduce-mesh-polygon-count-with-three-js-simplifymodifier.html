Reduce Mesh Polygon Count with Three.js SimplifyModifier

This article demonstrates how to dynamically reduce the polygon count of a 3D mesh in Three.js using the SimplifyModifier utility. By computing a simplified version of a model's geometry on the fly, developers can optimize rendering performance, implement Level of Detail (LOD) systems, and lower memory overhead for complex scenes.

1. Import SimplifyModifier

The SimplifyModifier is an official Three.js add-on. Import it alongside the core Three.js library and your chosen loader (such as GLTFLoader):

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { SimplifyModifier } from 'three/addons/modifiers/SimplifyModifier.js';

2. Prepare the Simplification Function

The modifier's .modify(geometry, count) method accepts a BufferGeometry and the number of vertices to remove. To simplify dynamically, create a utility function:

const modifier = new SimplifyModifier();

function simplifyMesh(mesh, percentageToRemove) {
    const originalGeometry = mesh.geometry;
    
    // Ensure geometry is a non-indexed or indexed BufferGeometry supported by the modifier
    const vertexCount = originalGeometry.attributes.position.count;
    const countToRemove = Math.floor(vertexCount * percentageToRemove);

    if (countToRemove <= 0) return;

    // Generate the simplified geometry
    const simplifiedGeometry = modifier.modify(originalGeometry, countToRemove);

    // Recompute normals for accurate lighting
    simplifiedGeometry.computeVertexNormals();

    // Replace the mesh geometry and dispose of the old one if no longer needed
    mesh.geometry.dispose();
    mesh.geometry = simplifiedGeometry;
}

3. Load the Mesh and Apply the Modifier

When loading an external model, traverse the scene hierarchy to locate the target Mesh objects and apply the simplification:

const loader = new GLTFLoader();

loader.load('path/to/model.glb', (gltf) => {
    const scene = gltf.scene;

    scene.traverse((child) => {
        if (child.isMesh) {
            // Store a clone of the original geometry if you plan to dynamically alter detail repeatedly
            child.userData.originalGeometry = child.geometry.clone();

            // Reduce vertices by 50%
            simplifyMesh(child, 0.5);
        }
    });

    // Add the optimized model to your Three.js scene
    threeScene.add(scene);
});

4. Handling Repeated Dynamic Updates

The SimplifyModifier permanently collapses edges. If you dynamically change polygon counts at runtime (for instance, based on camera distance), do not apply the modifier iteratively to an already simplified geometry. Instead, preserve a clone of the base geometry in mesh.userData.originalGeometry and generate the simplified geometry from that base version on each update:

function updateLOD(mesh, targetReductionRatio) {
    if (!mesh.userData.originalGeometry) return;

    const baseGeometry = mesh.userData.originalGeometry;
    const vertexCount = baseGeometry.attributes.position.count;
    const countToRemove = Math.floor(vertexCount * targetReductionRatio);

    const updatedGeometry = modifier.modify(baseGeometry, countToRemove);
    updatedGeometry.computeVertexNormals();

    mesh.geometry.dispose();
    mesh.geometry = updatedGeometry;
}

5. Performance Considerations

  • CPU Overhead: SimplifyModifier runs synchronously on the CPU. Performing simplification on high-poly meshes in the main render loop will cause frame drops. For real-time applications, either precompute simplified variants at load time or offload the calculation to a Web Worker.
  • UV and Texture Artifacts: Drastic polygon reduction collapses triangles and can distort UV coordinates or cause surface normal pinching. Limit simplification to a threshold where visual degradation remains acceptable.
