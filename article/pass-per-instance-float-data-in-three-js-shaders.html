Pass Per-Instance Float Data in Three.js Shaders

This article provides a direct guide on using InstancedBufferAttribute in Three.js to send unique, per-instance floating-point data to a custom vertex shader. You will learn how to create and populate a typed array, attach it to an instanced geometry, declare the corresponding attribute inside GLSL vertex code, and consume that data to produce individualized visual behaviors across instances efficiently.

1. Preparing the Instanced Geometry and Buffer

To pass custom data per instance, you need an instanced geometry—either THREE.InstancedBufferGeometry or the geometry automatically managed by THREE.InstancedMesh.

Each instance requires its own value. For a single floating-point number per instance, allocate a Float32Array with a length equal to your instance count.

const instanceCount = 1000;
const geometry = new THREE.BoxGeometry(1, 1, 1);

// Create the data array: 1 float per instance
const customFloats = new Float32Array(instanceCount);

for (let i = 0; i < instanceCount; i++) {
  // Populate with unique per-instance values (e.g., random offsets, speeds, scales)
  customFloats[i] = Math.random();
}

2. Creating the InstancedBufferAttribute

Wrap the typed array in a THREE.InstancedBufferAttribute. The constructor takes two primary arguments: the typed array and the itemSize (the number of components per vertex/instance). For a single scalar float, set itemSize to 1.

// itemSize = 1 because each instance receives a single float
const customAttribute = new THREE.InstancedBufferAttribute(customFloats, 1);

// Attach the attribute to the geometry
geometry.setAttribute('aCustomFloat', customAttribute);

If you need a 2D or 3D vector instead of a single scalar, change the array size and the itemSize accordingly (e.g., itemSize = 2 for a vec2, requiring an array length of instanceCount * 2).

3. Reading the Attribute in the Vertex Shader

Declare the attribute inside your custom vertex shader using the exact name assigned in geometry.setAttribute(). Three.js injects this value on a per-instance basis automatically.

// Custom Vertex Shader
attribute float aCustomFloat;

varying float vCustomFloat;

void main() {
    vCustomFloat = aCustomFloat;

    // Example usage: scale the vertex positions based on the per-instance float
    vec3 transformed = position * (1.0 + aCustomFloat);

    // Standard Three.js transformation chain for InstancedMesh
    #ifdef USE_INSTANCING
        transformed = (instanceMatrix * vec4(transformed, 1.0)).xyz;
    #endif

    gl_Position = projectionMatrix * modelViewMatrix * vec4(transformed, 1.0);
}

4. Updating Data Dynamically

If the per-instance values change after initialization, update the underlying array and flag the attribute for an upload before the next render:

// Modify the value
geometry.attributes.aCustomFloat.array[0] = 2.5;

// Notify Three.js to re-upload the buffer to the GPU
geometry.attributes.aCustomFloat.needsUpdate = true;
