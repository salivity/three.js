Three.js CSG: Complex 3D Boolean Operations

Constructive Solid Geometry (CSG) allows developers to build intricate 3D models in Three.js by combining simple procedural primitives using mathematical boolean operations: union, subtraction, and intersection. While Three.js does not include native boolean operations out of the box, modern libraries such as three-bvh-csg integrate seamlessly into the standard rendering pipeline. This guide walks through configuring the library, understanding core boolean operations, and generating a composite 3D mesh ready for rendering.

Core CSG Boolean Operations

Constructive Solid Geometry relies on three primary operations:

  1. Union (ADD): Merges two solid objects into a single contiguous volume, removing internal faces where the geometries overlap.
  2. Subtraction (SUBTRACT): Carves the shape of one object out of another, creating holes, grooves, or hollow cavities.
  3. Intersection (INTERSECT): Retains only the overlapping volume shared by both geometries, discarding everything else.

Prerequisites and Setup

Install Three.js and three-bvh-csg, which provides fast, robust CSG processing accelerated by Bounding Volume Hierarchy (BVH):

npm install three three-bvh-csg

Step-by-Step Implementation

To perform a boolean operation, wrap your standard Three.js meshes into Brush instances, configure an Evaluator, and execute the operation.

1. Import Dependencies

import * as THREE from 'three';
import { Evaluator, Brush, SUBTRACTION, ADDITION, INTERSECTION } from 'three-bvh-csg';

2. Create the Base Geometries and Brushes

A Brush extends THREE.Mesh and provides CSG algorithms with the vertex and spatial transformations needed to compute surface intersections.

// Base shape: A solid box
const boxGeometry = new THREE.BoxGeometry(2, 2, 2);
const boxMaterial = new THREE.MeshStandardMaterial({ color: 0x156289, roughness: 0.4 });
const baseBrush = new Brush(boxGeometry, boxMaterial);

// Cutting shape: A sphere offset from center
const sphereGeometry = new THREE.SphereGeometry(1.3, 32, 32);
const sphereMaterial = new THREE.MeshStandardMaterial({ color: 0xe74c3c, roughness: 0.4 });
const cutterBrush = new Brush(sphereGeometry, sphereMaterial);

// Position the cutter
cutterBrush.position.set(0.8, 0.8, 0.8);
cutterBrush.updateMatrixWorld();

3. Execute the Boolean Operation

Initialize the Evaluator and supply the operations. Here, we subtract the sphere from the box:

const evaluator = new Evaluator();

// Compute subtraction: baseBrush - cutterBrush
const resultMesh = evaluator.evaluate(baseBrush, cutterBrush, SUBTRACTION);

// Add the resulting mesh to your Three.js scene
scene.add(resultMesh);

4. Chaining Operations for Complex Shapes

You can feed the output of one operation directly into subsequent CSG operations to construct compound models:

// Create a cylinder to drill a central hole
const cylinderGeometry = new THREE.CylinderGeometry(0.5, 0.5, 3, 32);
const cylinderMaterial = new THREE.MeshStandardMaterial({ color: 0x2ecc71 });
const drillBrush = new Brush(cylinderGeometry, cylinderMaterial);
drillBrush.updateMatrixWorld();

// Drill through the already-carved geometry
const finalMesh = evaluator.evaluate(resultMesh, drillBrush, SUBTRACTION);

// Clean up intermediate geometries from GPU memory
baseBrush.geometry.dispose();
cutterBrush.geometry.dispose();
resultMesh.geometry.dispose();

scene.add(finalMesh);

Best Practices for Stability and Performance

  • Ensure Geometries are Manifold: CSG relies on watertight (2-manifold) meshes with consistent outward-facing normals. Open surfaces or self-intersecting meshes can produce rendering artifacts or invalid geometry.
  • Update World Matrices: Always call mesh.updateMatrixWorld() on brushes after transforming their position, rotation, or scale, ensuring accurate spatial calculation.
  • Dispose Intermediate Assets: CSG operations generate new BufferGeometry instances on each evaluation. Call .dispose() on unused geometries to prevent memory leaks in dynamic applications.
  • Precompute Static Meshes: Real-time CSG calculations on dense geometries can affect frame rates. Compute complex boolean models during initialization or in a web worker rather than inside the main animation loop.
