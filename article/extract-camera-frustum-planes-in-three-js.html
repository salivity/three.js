Extract Camera Frustum Planes in Three.js

This article explains how to extract the six boundary planes of a camera's view frustum using the THREE.Frustum class in Three.js. You will learn how to initialize a frustum, calculate the combined view-projection matrix from any perspective or orthographic camera, update the frustum with that matrix, and read the resulting individual THREE.Plane instances for use in custom culling or collision checks.

1. Prerequisites and Matrix Synchronization

To extract accurate frustum planes, the camera's transformation and projection matrices must reflect its latest position, orientation, and lens settings. If the camera has moved or changed its aspect ratio, update these matrices first:

camera.updateMatrixWorld();
camera.updateProjectionMatrix();

2. Compute the View-Projection Matrix

The Frustum class derives its boundaries from the camera's combined view-projection matrix. You obtain this by multiplying the camera's projection matrix by its inverse world matrix (matrixWorldInverse):

import * as THREE from 'three';

const projectionMatrix = new THREE.Matrix4();
projectionMatrix.multiplyMatrices(camera.projectionMatrix, camera.matrixWorldInverse);

3. Populate the Frustum

Instantiate a THREE.Frustum object and invoke setFromProjectionMatrix() using the combined matrix:

const frustum = new THREE.Frustum();
frustum.setFromProjectionMatrix(projectionMatrix);

This method automatically extracts, calculates, and normalizes the six bounding planes in world space.

4. Access the Individual Planes

The extracted planes are stored in the frustum.planes array. Three.js defines them at the following zero-based indices:

  • frustum.planes[0]: Right plane
  • frustum.planes[1]: Left plane
  • frustum.planes[2]: Bottom plane
  • frustum.planes[3]: Top plane
  • frustum.planes[4]: Far plane
  • frustum.planes[5]: Near plane

Each entry in the array is a THREE.Plane object containing a normal vector (THREE.Vector3) pointing inward toward the visible volume and a signed constant (number).

5. Complete Implementation Example

import * as THREE from 'three';

function getCameraFrustumPlanes(camera) {
  // Ensure matrices are up to date
  camera.updateMatrixWorld();
  camera.updateProjectionMatrix();

  // Combine projection matrix and view matrix
  const viewProjectionMatrix = new THREE.Matrix4();
  viewProjectionMatrix.multiplyMatrices(camera.projectionMatrix, camera.matrixWorldInverse);

  // Initialize and update the frustum
  const frustum = new THREE.Frustum();
  frustum.setFromProjectionMatrix(viewProjectionMatrix);

  // Return a labeled reference to each plane
  return {
    right:  frustum.planes[0],
    left:   frustum.planes[1],
    bottom: frustum.planes[2],
    top:    frustum.planes[3],
    far:    frustum.planes[4],
    near:   frustum.planes[5],
    rawArray: frustum.planes
  };
}

// Usage:
const planes = getCameraFrustumPlanes(camera);

// Access properties:
console.log('Near plane normal:', planes.near.normal);
console.log('Near plane distance:', planes.near.constant);

// Test an arbitrary point in space against a plane:
const point = new THREE.Vector3(0, 0, -10);
const distanceToNear = planes.near.distanceToPoint(point);
