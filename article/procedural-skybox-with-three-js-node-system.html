Procedural Skybox with Three.js Node System

This guide explains how to construct a fully procedural skybox natively in Three.js using its modern node-based material system (TSL / three/tsl). By leveraging mathematical nodes instead of static image textures, you can generate dynamic skies featuring two-tone horizon gradients and adjustable sun discs that react in real time. The following sections cover the mathematical foundation, the node setup, and the complete implementation code.

Understanding the Node Approach

Traditional skyboxes rely on cube maps or equirectangular HDR images. While visually rich, they are static and consume significant GPU memory.

Three.js's node system replaces static texture sampling with mathematical expressions evaluated directly on the GPU. To create a procedural sky, we evaluate the view direction vector of each pixel and compute:

  1. A Horizon Gradient: A linear interpolation (mix) between a zenith (top) color, horizon color, and nadir (bottom) color based on the vertical component (y) of the direction vector.
  2. A Sun Disc: A scalar value derived from the dot product between the view direction and an arbitrary sun direction vector, shaped using powers and thresholds.

Setting Up the Direction Vector

The direction vector can be determined from the world position of the geometry enclosing the scene. Using an inverted SphereGeometry with a MeshBasicNodeMaterial ensures the geometry is visible from the inside:

import * as THREE from 'three';
import {
  color,
  vec3,
  positionWorld,
  normalize,
  mix,
  smoothstep,
  dot,
  pow,
  max,
  uniform
} from 'three/tsl';

// Enclosing sphere geometry
const skyGeo = new THREE.SphereGeometry(1000, 32, 15);
skyGeo.scale(-1, 1, 1); // Invert faces to point inward

Within the node graph, the normalized world position provides the ray direction:

const rayDir = normalize(positionWorld);

Building the Procedural Sky Nodes

1. The Sky Gradient

Use the y component of the normalized ray direction to interpolate between the ground, horizon, and zenith colors:

// Color uniforms
const topColor = uniform(color('#1a4c8a'));    // Zenith
const horizonColor = uniform(color('#c5d8e8'));// Horizon
const bottomColor = uniform(color('#3b3936')); // Ground

// Normalizing Y from [-1, 1] to [0, 1] ranges
const y = rayDir.y;

// Smooth transition from ground to horizon, then to zenith
const skyTransition = smoothstep(0.0, 0.4, y);
const groundTransition = smoothstep(-0.2, 0.0, y);

const atmosphere = mix(bottomColor, horizonColor, groundTransition);
const skyColor = mix(atmosphere, topColor, skyTransition);

2. The Sun Disc

Define a normalized vector for the sun's position. Taking the dot product of the ray direction and the sun vector produces values approaching 1.0 as the camera looks directly at the sun.

const sunPosition = uniform(vec3(0.0, 0.3, -1.0).normalize());
const sunColor = uniform(color('#fff2b0'));

// Angle alignment between the pixel direction and sun direction
const sunDot = max(dot(rayDir, sunPosition), 0.0);

// Sharp disc with a soft glow
const sunGlow = pow(sunDot, 64.0).mul(0.5);
const sunDisc = smoothstep(0.998, 0.999, sunDot);

// Final color combination
const finalColor = mix(skyColor, sunColor, sunDisc).add(sunColor.mul(sunGlow));

Applying the Material

Assign the computed node graph to the colorNode property of a MeshBasicNodeMaterial:

const skyMaterial = new THREE.MeshBasicNodeMaterial({
  side: THREE.BackSide,
  depthWrite: false
});

skyMaterial.colorNode = finalColor;

const skyMesh = new THREE.Mesh(skyGeo, skyMaterial);
scene.add(skyMesh);

Alternatively, when using WebGPURenderer, you can assign the node expression directly to scene.backgroundNode without creating a sphere mesh:

scene.backgroundNode = finalColor;

Dynamic Updates

Because the values are defined using uniform() nodes, you can alter the time of day at runtime without recompiling shaders:

function updateSun(elevation, azimuth) {
  const phi = THREE.MathUtils.degToRad(90 - elevation);
  const theta = THREE.MathUtils.degToRad(azimuth);

  sunPosition.value.setFromSphericalCoords(1, phi, theta).normalize();
}

This setup provides a fully procedural, lightweight, and responsive skybox natively integrated with Three.js's node architecture.
