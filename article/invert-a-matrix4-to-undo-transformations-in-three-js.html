Invert a Matrix4 to Undo Transformations in Three.js

Inverting a 4x4 matrix in Three.js allows you to mathematically reverse a sequence of spatial transformations, including translations, rotations, and scaling. This guide explains how matrix inversion works in 3D graphics, how to use the built-in Three.js methods to calculate an inverse matrix, and how to apply that inverse to restore vectors or objects to their original coordinate spaces.

The Mechanics of Matrix Inversion

When an object undergoes transformations, Three.js combines translation (\(T\)), rotation (\(R\)), and scale (\(S\)) into a single 4x4 affine transformation matrix (\(M\)):

\[M = T \times R \times S\]

To undo this transformation, you must multiply by the mathematical inverse of the matrix (\(M^{-1}\)). The inverse reverses each individual transformation step in the opposite order:

\[M^{-1} = S^{-1} \times R^{-1} \times T^{-1}\]

Multiplying a transformed coordinate vector by \(M^{-1}\) cancels out the transformation entirely, returning the vector to its original state:

\[v_{\text{original}} = M^{-1} \times (M \times v_{\text{original}})\]

Inverting a Matrix Using Matrix4.invert()

In modern Three.js (r123 and newer), the primary method for inverting a matrix is Matrix4.invert(). This method computes the inverse of the matrix in place.

If you need to preserve the original transformation matrix, clone it first before calling invert().

import * as THREE from 'three';

// 1. Create a matrix with translation, rotation, and scale
const transformMatrix = new THREE.Matrix4();
const position = new THREE.Vector3(10, 5, -2);
const quaternion = new THREE.Quaternion().setFromAxisAngle(
    new THREE.Vector3(0, 1, 0), 
    Math.PI / 2
);
const scale = new THREE.Vector3(2, 2, 2);

// Compose the affine matrix
transformMatrix.compose(position, quaternion, scale);

// 2. Clone and invert the matrix to undo transformations
const inverseMatrix = transformMatrix.clone().invert();

Applying the Inverse Matrix to Undo Transformations

Once calculated, the inverse matrix can be applied to vectors, geometries, or other matrices to reverse spatial changes.

Undoing Vector Transformations

To return a transformed point back to its original local coordinates:

const point = new THREE.Vector3(1, 2, 3);

// Apply forward transformation
point.applyMatrix4(transformMatrix);

// Undo the transformation
point.applyMatrix4(inverseMatrix);

// 'point' is now back to roughly (1, 2, 3) within floating-point precision

Undoing Object3D Transformations

If you have an object whose world position, rotation, and scale need to be cancelled out relative to another coordinate space, you can decompose the inverse matrix back into the object's properties:

// Extract the inverted position, rotation, and scale
const invPosition = new THREE.Vector3();
const invQuaternion = new THREE.Quaternion();
const invScale = new THREE.Vector3();

inverseMatrix.decompose(invPosition, invQuaternion, invScale);

// Apply directly to an Object3D
targetObject.position.copy(invPosition);
targetObject.quaternion.copy(invQuaternion);
targetObject.scale.copy(invScale);

Edge Cases and Non-Invertible Matrices

A matrix can only be inverted if its determinant is non-zero. A determinant of zero occurs when:

  • Any component of the scale vector is set to 0.
  • The matrix collapses 3D space into a plane, line, or point (projection matrices with zero depth).

If invert() is called on a matrix with a determinant of zero, Three.js will fail to compute a valid inverse and will set the matrix to a zero matrix (all elements equal to 0). You can verify if a matrix can be inverted by checking its determinant first:

if (transformMatrix.determinant() !== 0) {
    const inverseMatrix = transformMatrix.clone().invert();
    // Safe to use inverseMatrix
} else {
    console.warn("Matrix cannot be inverted due to a zero determinant.");
}
