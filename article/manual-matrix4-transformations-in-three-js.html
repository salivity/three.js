Manual Matrix4 Transformations in Three.js

This article explains how to manually construct, combine, and sequence transformation matrices in Three.js using the THREE.Matrix4 class without relying on THREE.Object3D properties such as position, rotation, and scale. You will learn the mathematical order of matrix multiplication, how Three.js handles matrix composition via multiply() and premultiply(), and how to manually produce a standard Translation-Rotation-Scale (TRS) matrix from scratch.

Understanding Matrix Multiplication Order

In 3D graphics, transformations are applied to a column vector \(v\) in order from right to left:

\[v' = M \cdot v = (T \cdot R \cdot S) \cdot v\]

To scale an object first, rotate it second, and translate it third relative to its local coordinate space, the final transformation matrix must be multiplied in the order of Translation (\(T\)), followed by Rotation (\(R\)), followed by Scale (\(S\)).

In Three.js:

  • A.multiply(B) evaluates to \(A = A \times B\) (post-multiplication).
  • A.premultiply(B) evaluates to \(A = B \times A\) (pre-multiplication).

When using post-multiplication (multiply()), transformations are chained sequentially in local coordinate space.

Building Individual Transformation Matrices

Three.js provides helper methods on THREE.Matrix4 to initialize a matrix as a pure translation, rotation, or scale:

import * as THREE from 'three';

// 1. Translation Matrix
const translationMatrix = new THREE.Matrix4().makeTranslation(10, 5, 0);

// 2. Rotation Matrix (using Euler, Axis-Angle, or Quaternion)
const rotationMatrix = new THREE.Matrix4().makeRotationZ(Math.PI / 4);

// 3. Scale Matrix
const scaleMatrix = new THREE.Matrix4().makeScale(2, 2, 1);

Sequencing into a Final TRS Matrix

To combine these matrices manually, chain them using multiply():

const transformMatrix = new THREE.Matrix4();

// Identity * Translation = Translation
transformMatrix.multiply(translationMatrix);

// Translation * Rotation
transformMatrix.multiply(rotationMatrix);

// (Translation * Rotation) * Scale = Final TRS Matrix
transformMatrix.multiply(scaleMatrix);

Because multiply() appends the new transformation to the right of the existing one, the operations will be evaluated on object vertices in the order: Scale first, Rotation second, Translation last.

Using Local vs. World Sequencing

The sequencing approach changes based on whether a new transformation must occur in local space or world space:

  • Local-space transformation (Post-multiplication): Call matrix.multiply(newMatrix). This rotates or translates the object along its current, transformed axes.
  • World-space transformation (Pre-multiplication): Call matrix.premultiply(newMatrix). This rotates or translates the object along the global scene axes, regardless of its current orientation.
// Rotate around the local origin
transformMatrix.multiply(localRotationMatrix);

// Orbit around the global world origin
transformMatrix.premultiply(worldRotationMatrix);

Alternative: Using Matrix4.compose()

If you already have translation vectors, quaternion rotations, and scale vectors computed, Matrix4.compose() constructs the combined matrix directly into the internal 16-element array without intermediate matrix multiplications:

const position = new THREE.Vector3(10, 5, 0);
const quaternion = new THREE.Quaternion().setFromAxisAngle(new THREE.Vector3(0, 0, 1), Math.PI / 4);
const scale = new THREE.Vector3(2, 2, 1);

const finalMatrix = new THREE.Matrix4().compose(position, quaternion, scale);

Applying the Matrix

To render an object with a manually constructed matrix, disable the automatic transform updates on the target mesh:

mesh.matrixAutoUpdate = false;
mesh.matrix.copy(transformMatrix);
mesh.matrixWorldNeedsUpdate = true;

Alternatively, bake the matrix directly into the underlying buffer attributes:

geometry.applyMatrix4(transformMatrix);
