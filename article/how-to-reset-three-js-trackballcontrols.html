How to Reset Three.js TrackballControls

This article explains how to return a Three.js TrackballControls instance to its absolute default state using the built-in reset() method. You will learn how TrackballControls records its initial baseline state, the role of the camera's position and orientation during initialization, and the exact JavaScript code needed to trigger a complete reset.

How TrackballControls Stores the Default State

When you create a new instance of TrackballControls, the constructor automatically captures the attached camera's current transformation (position, rotation, and up vector) as well as the initial control target (which defaults to (0, 0, 0)). This initial snapshot serves as the baseline for the reset() method.

If the camera properties are modified after instantiating TrackballControls without saving a new state, calling reset() will revert the camera back to the values it had at the precise moment the controls were constructed.

Using the reset() Method

To reset the controls, invoke the .reset() method directly on your TrackballControls instance.

import * as THREE from 'three';
import { TrackballControls } from 'three/addons/controls/TrackballControls.js';

// 1. Setup Camera and Scene
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 10, 20);

const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// 2. Instantiate TrackballControls (Captures current camera state as default)
const controls = new TrackballControls(camera, renderer.domElement);

// Optional: Adjust control parameters
controls.rotateSpeed = 1.0;
controls.zoomSpeed = 1.2;
controls.panSpeed = 0.8;

// 3. Reset Function
function resetControlsToDefault() {
    controls.reset();
}

// Example: Trigger reset on a key press or UI button click
window.addEventListener('keydown', (event) => {
    if (event.key === 'r' || event.key === 'R') {
        resetControlsToDefault();
    }
});

// 4. Animation Loop
function animate() {
    requestAnimationFrame(animate);
    controls.update();
    renderer.render(scene, camera);
}
animate();

Redefining the Default State with saveState()

If you configure or reposition your camera programmatically after the controls have already been instantiated, you must tell TrackballControls to overwrite the initial baseline with the new configuration.

Call controls.saveState() once your desired "default" setup is complete:

// Change camera to desired default position after instantiation
camera.position.set(5, 5, 15);
camera.lookAt(0, 0, 0);

// Set the target point
controls.target.set(0, 0, 0);

// Explicitly register this layout as the reset target
controls.saveState();

// Any subsequent call to controls.reset() will return to this layout
controls.reset();

Key Considerations

  • Internal Target: The reset() method automatically resets the internal target property of TrackballControls back to the coordinates stored during creation or the last saveState() call.
  • Render Loop: Calling controls.reset() immediately alters the camera's transform vectors, but you must call controls.update() within your render loop for the viewport to display the changes.
